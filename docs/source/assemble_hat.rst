Fusion HAT zusammenbauen 
====================================

Bevor Sie das Beispiel ausführen, können Sie den Fusion HAT und den Raspberry Pi Zero 2 W auf dem RAB Holder montieren.

Der RAB Holder ist eine Grundplatte, die den Raspberry Pi Zero 2 W, ein Breadboard und den Fusion HAT aufnimmt. Er erleichtert während der Experimente das Anschließen verschiedener Sensoren und Aktoren und sorgt für einen stabilen Aufbau.

Bitte gehen Sie für die Montage wie folgt vor.

1. Setzen Sie den Raspberry Pi Zero 2 W auf den RAB Holder und befestigen Sie ihn mit Schrauben.

.. image:: img/assemble/fh_pi.jpg

2. Montieren Sie zwei Abstandshalter zur Abstützung des Fusion HAT.

.. image:: img/assemble/fh_standoff.jpg

3. Wenn Sie die Raspberry-Pi-Kamera verwenden möchten, schließen Sie die Kamera jetzt über das FPC-Kabel an den Raspberry Pi Zero 2 W an.

.. image:: img/assemble/fh_camera.jpg


4. Stecken Sie den Fusion HAT auf den Raspberry Pi Zero 2 W.

.. image:: img/assemble/fh_fh.jpg

5. Für Projekte können Sie PinPal verwenden, um die Pinbelegung (Pinout) des Raspberry Pi Zero 2 W schnell zu finden.

.. image:: img/assemble/fh_pinpal.jpg
