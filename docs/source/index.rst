SunFounder AI Fusion Lab Kit
=======================================================

**欢迎阅读 AI Fusion Lab Kit 文档**

AI Fusion Lab Kit 是一款一体化学习与开发平台，专为初学者、创客和教育工作者设计，帮助您探索 Python 编程、人工智能、计算机视觉以及交互式硬件项目。

它集成了：

* 模块化硬件套件
* 即用型软件环境
* 循序渐进的教程模块
* AI 与视觉工具，如 LLM、OpenCV 和 MediaPipe

借助此套件，您可以构建融合编程、电子技术和现代 AI 技术的项目——以动手实践、初学者友好的方式开展学习。

**如何浏览本文档**

本指南将帮助您了解套件的功能、文档的组织结构，以及如何根据您的经验水平选择合适的学习路径。无论您是初学者、教育工作者，还是有经验的创客，都能找到适合您的清晰路径。

**不知道从哪里开始？**

* **刚接触此套件？** → 始终从 :ref:`get_start` 开始
* **在 YouTube 上学习** → :ref:`youtube_list`
* **编程新手？** → :ref:`play_with_python`
* **对 AI 感兴趣？** → :ref:`play_with_llm`
* **使用摄像头？** → :ref:`play_with_opencv` 或 :ref:`play_with_mediapipe` 或 :ref:`play_with_yolo`
* **需要技术细节？** → :ref:`cpn_list`
* **遇到问题？** → :ref:`faq`

.. warning::

   MediaPipe 项目目前不支持 Debian 13 (Trixie)。
   请使用 Raspberry Pi OS (Bookworm, Debian 12) 以确保完全兼容。
