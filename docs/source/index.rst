SunFounder AI Fusion Lab Kit
=======================================================

**AI Fusion Lab Kit ドキュメンテーションへようこそ**

AI Fusion Lab Kitは、初心者、メーカー、教育者がPythonプログラミング、人工知能、コンピュータビジョン、インタラクティブハードウェアプロジェクトを探求するために設計された、オールインワンの学習・開発プラットフォームです。

このキットは以下を組み合わせています：

* モジュール式ハードウェアキット
* すぐに使えるソフトウェア環境
* ステップバイステップの学習モジュール
* LLM、OpenCV、MediaPipeなどのAI・ビジョンツール

このキットを使えば、プログラミング、電子工学、最新のAI技術を実践的で初心者に優しい方法で組み合わせたプロジェクトを構築できます。

**このドキュメンテーションの使い方**

このガイドは、キットの機能、ドキュメンテーションの構成、経験レベルに応じてどこから始めるべきかを理解するのに役立ちます。初心者、教育者、経験豊富なメーカーを問わず、自分の目標に合った明確な道筋が見つかります。

**どこから始めればよいかわからない場合：**

* **キットが初めての方** → 必ず :ref:`get_start` から始めてください
* **YouTubeで学ぶ** → :ref:`youtube_list`
* **プログラミング初心者の方** → :ref:`play_with_python`
* **AIに興味がある方** → :ref:`play_with_llm`
* **カメラを使った作業** → :ref:`play_with_opencv` または :ref:`play_with_mediapipe` または :ref:`play_with_yolo`
* **技術的な詳細が必要な方** → :ref:`cpn_list`
* **問題が発生した場合** → :ref:`faq`

.. warning::
   
   MediaPipeプロジェクトは現在 Debian 13（Trixie）をサポートしていません。
   完全な互換性を確保するために、Raspberry Pi OS（Bookworm、Debian 12）をご使用ください。
