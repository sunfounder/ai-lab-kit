はじめに（重要）
===============================

これはこのコースの最初の章です。  
AI Fusion Lab KitイメージをダウンロードしてSDカードに書き込み、Raspberry Piをセットアップし、デバイスに電源を供給して起動します。

この章が終わると、Fusion HAT+ が完全に準備され、今後のレッスンに進む準備が整います。
