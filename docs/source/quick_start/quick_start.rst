はじめに（重要）
===============================

これは本キットコースの最初の章です。  
ここでは、Raspberry Pi のセットアップ、必要なソフトウェアのインストール、Fusion の充電および電源投入を行います。

この章を完了すると、Fusion HAT+ の準備が整い、次のレッスンをすぐに開始できる状態になります。
