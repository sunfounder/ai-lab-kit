ビデオコース
================

    <a href="https://www.youtube.com/@paulmcwhorter" target="_blank">Paul McWhorter</a>

.. |link_video_courses| raw:: html

    <a href="https://www.youtube.com/playlist?list=PLGs0VKk2DiYz9lvgEK4YJSWszqexhLGc1" target="_blank">YouTube上のAI Fusion Lab Kitビデオコース</a>

このビデオチュートリアルシリーズは |link_paul| によって制作され、現在 |link_video_courses| で無料公開されています。

このシリーズは完全な初心者向けに設計されており、Raspberry PiとFusion HAT+を使用して、楽しく実用的なさまざまなプロジェクトを構築する方法を段階的に指導します。回路をゼロから設計・構築する方法だけでなく、人工知能（AI）を自分の作品に実際に応用する方法も学べます。Python、大規模言語モデル（LLM）、OpenCV、MediaPipe、YOLOなどの主要な技術とフレームワークをカバーしています。

私たちの目標は、皆さんが自分のプロジェクトを自信を持って自力で完了できるようになることです。このチュートリアルシリーズはSTEM教育に優れたリソースです。公立学校、私立学校、ホームスクール環境での学習、あるいは単に電子工学やプログラミングの世界を探求することに情熱を持つ生涯学習者にとって理想的です。

皆さまからのフィードバックを大切にし、コースに関する経験やご意見を共有していただくことを心より歓迎します！
