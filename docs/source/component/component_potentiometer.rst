Potentiometer
===============

.. image:: img/potentiometer.png
    :align: center
    :width: 150

Ein Potentiometer ist ein Widerstandselement mit drei Anschlüssen, dessen Widerstandswert in einem bestimmten Bereich kontinuierlich verändert werden kann.  

Potentiometer gibt es in vielen Formen, Größen und Widerstandswerten, sie haben jedoch stets folgende Gemeinsamkeiten:  

* Sie besitzen drei Anschlüsse (Kontaktpunkte).  
* Sie verfügen über einen Drehknopf, eine Schraube oder einen Schieberegler, mit dem sich der Widerstand zwischen dem mittleren Anschluss und einem der beiden äußeren Anschlüsse verändern lässt.  
* Der Widerstand zwischen dem mittleren Anschluss und einem der äußeren Anschlüsse reicht – abhängig von der Stellung des Reglers – von 0 Ω bis zum Maximalwert des Potentiometers.  

Hier ist das Schaltzeichen eines Potentiometers:  

.. image:: img/potentiometer_symbol.png
    :align: center
    :width: 400


Die Hauptfunktionen eines Potentiometers in einer Schaltung sind:  

#. Verwendung als Spannungsteiler  

    Ein Potentiometer ist ein kontinuierlich einstellbarer Widerstand. Wenn man die Achse oder den Schieberegler verstellt, bewegt sich der Schleifkontakt entlang des Widerstandes. Dadurch kann eine Spannung abgegriffen werden, die vom angelegten Eingangssignal sowie von der Position des Schleifkontakts abhängt.  

#. Verwendung als veränderlicher Widerstand (Rheostat)  

    Wird ein Potentiometer als Rheostat eingesetzt, verbindet man den mittleren Anschluss mit einem der beiden äußeren. So erhält man innerhalb des gesamten Verstellbereichs einen stufenlos veränderbaren Widerstandswert.  

#. Verwendung als Stromregler  

    Wenn das Potentiometer als Stromregler eingesetzt wird, muss der Schleifkontakt als einer der Ausgangsanschlüsse genutzt werden.
