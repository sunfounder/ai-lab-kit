2.2.7 Ultraschallsensormodul
==============================

**Einführung**

Das Ultraschallsensormodul misst Entfernungen mithilfe von Ultraschallwellen mit hoher Genauigkeit. Es sendet Ultraschallwellen aus und empfängt deren Echo. Aus der Zeit, die das Echo für die Rückkehr benötigt, wird die Distanz berechnet. Diese vielseitige Technologie wird häufig in Robotik, Hinderniserkennung und Distanzmessung eingesetzt.

**Code schreiben**


Der folgende Python-Code wird in diesem Projekt verwendet:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Ultrasonic,Pin
   from time import sleep

   # Initialize the DistanceSensor
   # Trigger pin is connected to GPIO 27, Echo pin to GPIO 22
   sensor = Ultrasonic(trig=Pin(27), echo=Pin(22))

   try:
      # Main loop to continuously measure and report distance
      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to gracefully exit the loop
      pass

Dieses Python-Skript nutzt einen Ultraschallsensor, um die Entfernung zu einem Objekt zu messen und das Ergebnis in der Konsole auszugeben.  

1. Der Sensor an GPIO 27 (Trigger) und GPIO 22 (Echo) misst kontinuierlich die Entfernung zum nächsten Objekt.  
2. Die Distanz wird in Meter berechnet, in Zentimeter umgerechnet und im Format ``Distance: <value> cm`` mit zwei Nachkommastellen ausgegeben.  
3. Alle 0,3 Sekunden wird der Wert aktualisiert, sodass eine nahezu Echtzeitüberwachung möglich ist.  
4. Das Programm läuft unbegrenzt, bis es mit ``Ctrl+C`` beendet wird, und beendet sich dabei sauber.  


----------------------------------------------


**Code verstehen**

1. **Imports:**


   .. code-block:: python

      from fusion_hat import Ultrasonic,Pin
      from time import sleep

   Das Skript importiert die Klasse ``Ultrasonic`` aus der Bibliothek ``fusion_hat`` zur Ansteuerung des Sensors sowie die Funktion ``sleep`` aus dem Modul ``time`` zur Verzögerungssteuerung.  


2. **Initialisierung:**

   .. code-block:: python

      sensor = Ultrasonic(trig=Pin(27), echo=Pin(22))

   Der Ultraschallsensor wird mit Echo an GPIO 22 und Trigger an GPIO 27 initialisiert. Damit kann der Raspberry Pi Signale senden und empfangen.  

3. **Hauptschleife:**


   .. code-block:: python

      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   * Misst kontinuierlich die Entfernung zum nächstgelegenen Objekt.  
   * Wandelt die Distanz von Metern in Zentimeter um.  
   * Gibt die Entfernung mit einer Genauigkeit von zwei Nachkommastellen aus.  
   * Enthält eine Verzögerung von 0,3 Sekunden, damit sich der Sensor zwischen den Messungen stabilisieren kann.  

4. **Sauberes Beenden:**

   Der ``try-except``-Block sorgt dafür, dass das Programm bei ``Ctrl+C`` ordnungsgemäß beendet wird.  



   .. code-block:: python

      except KeyboardInterrupt:
         pass


----------------------------------------------


**Fehlerbehebung**

1. **Keine Ausgabe der Distanz**:  

   - **Ursache**: Der Sensor ist nicht korrekt angeschlossen oder nicht mit Strom versorgt.  
   - **Lösung**:  

      - Stelle sicher, dass Trigger an GPIO 27 und Echo an GPIO 22 angeschlossen sind.  
      - Überprüfe die Spannungsversorgung des Sensors.  

2. **Konstante oder falsche Werte**:  

   - **Ursache**: Hindernisse sind zu nah, zu weit entfernt oder es gibt Störungen.  
   - **Lösung**:  

      - Achte darauf, dass sich Objekte im Messbereich des Sensors befinden (typischerweise 2–400 cm).  
      - Prüfe, ob Störungen durch andere Ultraschallquellen oder reflektierende Oberflächen vorliegen.  

3. **Distanz immer null**:  

   - **Ursache**: Defekter Sensor oder falsche Verdrahtung.  
   - **Lösung**: Teste den Sensor mit einer anderen GPIO-Konfiguration oder tausche ihn aus.

**Erweiterbare Ideen**

1. **Schwellwertbasierte Warnungen**: Löst eine Warnung aus, wenn die gemessene Distanz unter einen definierten Wert fällt:  

  .. code-block:: python

      if dis < 10:
          print("Warning: Object too close!")

2. **Akustisches Feedback**: Ergänze einen Buzzer, der bei Unterschreiten des Schwellwerts aktiviert wird:  

  .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(4))
      if dis < 10:
         buzzer.on()
      else:
         buzzer.off()
