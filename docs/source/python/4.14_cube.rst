4.14 Cubo Gravitazionale
=========================

**Introduzione**

In questa lezione, costruirai un **cubo 3D con riferimento gravitazionale** visualizzato su un OLED SSD1306 128x64, pilotato da un **IMU**.
Il cubo si inclina secondo l'orientamento della scheda rispetto alla gravit, usando rollio e beccheggio calcolati solo dall'accelerometro.

Caratteristiche principali:

- Renderizzazione 3D del cubo in proiezione ortografica (senza distorsione prospettica)
- Orientamento derivato dall'accelerometro rispetto a una linea di base iniziale
- Una faccia del cubo riempita per rendere facile vedere l'orientamento anteriore-posteriore
- Due flag configurabili permettono di invertire le direzioni X/Y per adattarsi al montaggio fisico

Inclinando la scheda, il cubo ruota dolcemente, fornendo una visualizzazione intuitiva dell'orientamento del dispositivo.

**Passaggi di Configurazione**

#. Installa le librerie OLED:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-ssd1306 --break

#. Installa le librerie IMU:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip install git+https://github.com/sunfounder/sunfounder-imu-python.git --break-system-packages


#. Esegui l'esempio dalla directory ``ai-lab-kit``:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 4.14_Cube.py

#. Quando lo script viene eseguito:

   * L'accelerometro fornisce dati X/Y/Z con riferimento gravitazionale.
   * Il codice calcola rollio e beccheggio relativi a una linea di base iniziale (l'orientamento corrente diventa 0, 0).
   * Un cubo wireframe con una **faccia anteriore riempita** viene disegnato sull'OLED.
   * Inclinando la scheda, il cubo ruota sullo schermo.
   * Premi **Ctrl+C** per uscire; l'OLED viene cancellato.
