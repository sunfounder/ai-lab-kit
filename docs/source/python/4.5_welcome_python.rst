4.5 Benvenuto
==============================

**Introduzione**

Hai mai notato le porte automatiche nei negozi che si aprono con un suono di benvenuto quando qualcuno si avvicina? Questo progetto replica quella funzionalità su scala ridotta. Usando un sensore PIR, un servomotore, un LED e un buzzer, creerai un sistema di "porta automatica" in miniatura. Quando viene rilevato movimento, il sistema accende un LED, "apre" la porta usando un servo e suona un motivo di benvenuto con un buzzer.

**Codice**

Qui sotto c'è lo script Python per il progetto:



.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.servo import Servo
   from fusion_hat.modules import Buzzer
   from fusion_hat.pwm import PWM
   import time

   # GPIO pin setup
   ledPin = Pin(17, Pin.OUT)

   # Initialize a PIR Module object on GPIO pin 17
   pirPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)

   buzPin = Buzzer(PWM('P0'))

   # Initialize servo with custom pulse widths
   servoPin = Servo('P4')

   # Musical tune for buzzer, with notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('C4', 0.2), ('B4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
         ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
         ('D4', 0.2), ('E4', 0.2)]

   def setAngle(angle):
      """
      Move the servo to a specified angle.
      :param angle: Angle in degrees (0-180).
      """
      servoPin.angle(angle)       # Set servo position
      time.sleep(0.001)           # Short delay for servo movement

   def doorbell():
      """
      Play a musical tune using the buzzer.
      """
      for note, duration in tune:
         buzPin.play(note,float(duration))       # Play the note
      buzPin.off()               # Stop buzzer after playing the tune

   def closedoor():
      # Turn off LED and move servo to close door
      ledPin.off()
      for i in range(180, -1, -1):
         setAngle(i)             # Move servo from 180 to 0 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait after closing door

   def opendoor():
      # Turn on LED, open door (move servo), play tune, close door
      ledPin.on()
      for i in range(0, 181):
         setAngle(i)             # Move servo from 0 to 180 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait before playing the tune
      doorbell()                  # Play the doorbell tune
      closedoor()                 # Close the door after the tune

   def loop():
      # Main loop to check for motion and operate door
      while True:
         if pirPin.value()==1:
               opendoor()               # Open door if motion detected
         time.sleep(0.1)              # Short delay in loop

   try:
      loop()
   except KeyboardInterrupt:
      # Clean up GPIO on user interrupt (e.g., Ctrl+C)
      buzPin.off()
      ledPin.off()

Questo script Python integra un sensore di movimento PIR, un servomotore, un LED e un buzzer per creare un sistema di benvenuto automatizzato. Quando eseguito:

1. **Rilevamento Movimento**: Un sensore di movimento PIR collegato al pin GPIO 22 rileva il movimento.

2. **Automazione della Porta**: Quando viene rilevato movimento:

     - Il servomotore (su PWM 4) apre una porta muovendosi da 0° a 180°.
     - Il LED (sul pin GPIO 17) si accende.
     - Un motivo di benvenuto viene suonato attraverso il buzzer (su PWM 0).
     - Il servomotore chiude la porta tornando da 180° a 0°.
     - Il LED si spegne.

3. **Monitoraggio Continuo**: Il sistema monitora continuamente il movimento e attiva la sequenza sopra ogni volta che viene rilevato movimento.

4. **Uscita Controllata**: Con ``Ctrl+C``, il buzzer e il LED vengono spenti e lo script esce in modo pulito.


----------------------------------------------

**Comprendere il Codice**

1. **Rilevamento Movimento:** Il sensore PIR rileva il movimento e attiva il sistema.

2. **Controllo Servomotore:** Il servomotore apre e chiude la porta usando angoli da 0° a 180°.

3. **Melodia del Buzzer:** Un motivo di benvenuto viene suonato usando ``Buzzer``.

4. **Reset:** Dopo il suono, il sistema chiude la porta e spegne il LED, pronto per il prossimo evento.



----------------------------------------------


**Risoluzione dei Problemi**

1. **Movimento Non Rilevato**:

   - **Causa**: Sensore PIR non cablato correttamente o interferenza ambientale.
   - **Soluzione**:

     - Assicurati che il sensore PIR sia collegato al pin GPIO 22, all'alimentazione e a massa.
     - Regola i potenziometri di sensibilità e ritardo del sensore, se disponibili.

2. **Il Servomotore Non Si Muove**:

   - **Causa**: Configurazione errata del servo o problemi di alimentazione.
   - **Soluzione**:

     - Verifica che il servomotore sia collegato a P4 e alimentato correttamente.

3. **Il Motivo Non Viene Riprodotto**:

   - **Causa**: Configurazione errata del buzzer o formato del motivo errato.
   - **Soluzione**:

     - Assicurati che il buzzer sia collegato a P0.
     - Verifica che la lista ``tune`` contenga coppie valide di nota e durata.

4. **Il LED Non Si Accende**:

   - **Causa**: Problemi di cablaggio del LED o configurazione GPIO.
   - **Soluzione**: Verifica che il LED sia collegato al pin GPIO 17 con un resistore appropriato.

**Idee Estendibili**

1. **Motivo Regolabile**: Aggiungi più melodie o permetti all'utente di selezionare diversi motivi per eventi diversi.

2. **Funzionamento Basato sull'Ora**: Disabilita il sistema durante orari specifici (ad es., di notte):

         from datetime import datetime
         if 8 <= datetime.now().hour < 22:  # Operate only between 8 AM and 10 PM
             opendoor()

             log_file.write(f"{time.strftime('%Y-%m-%d %H:%M:%S')} - Motion detected\n")

4. **Saluti Vocali**: Sostituisci il suono del buzzer con messaggi vocali preregistrati usando un altoparlante.
