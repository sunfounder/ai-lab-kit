4.5 欢迎系统
============

**简介**

您是否注意过便利店中当有人靠近时会自动打开并发出迎宾铃声的自动门？本项目将在较小规模上复制该功能。使用 PIR 传感器、舵机、LED 和蜂鸣器，您将创建一个微型"自动门"系统。当检测到运动时，系统点亮 LED，使用舵机"打开"门，并通过蜂鸣器播放迎宾铃声。

**代码**

以下是本项目的 Python 脚本：



.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.servo import Servo
   from fusion_hat.modules import Buzzer
   from fusion_hat.pwm import PWM
   import time

   # GPIO pin setup
   ledPin = Pin(17, Pin.OUT)

   # Initialize a PIR Module object on GPIO pin 17
   pirPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)

   buzPin = Buzzer(PWM('P0'))

   # Initialize servo with custom pulse widths
   servoPin = Servo('P4')

   # Musical tune for buzzer, with notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('C4', 0.2), ('B4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
         ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
         ('D4', 0.2), ('E4', 0.2)]

   def setAngle(angle):
      """
      Move the servo to a specified angle.
      :param angle: Angle in degrees (0-180).
      """
      servoPin.angle(angle)       # Set servo position
      time.sleep(0.001)           # Short delay for servo movement

   def doorbell():
      """
      Play a musical tune using the buzzer.
      """
      for note, duration in tune:
         buzPin.play(note,float(duration))       # Play the note
      buzPin.off()               # Stop buzzer after playing the tune

   def closedoor():
      # Turn off LED and move servo to close door
      ledPin.off()
      for i in range(180, -1, -1):
         setAngle(i)             # Move servo from 180 to 0 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait after closing door

   def opendoor():
      # Turn on LED, open door (move servo), play tune, close door
      ledPin.on()
      for i in range(0, 181):
         setAngle(i)             # Move servo from 0 to 180 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait before playing the tune
      doorbell()                  # Play the doorbell tune
      closedoor()                 # Close the door after the tune

   def loop():
      # Main loop to check for motion and operate door
      while True:
         if pirPin.value()==1:
               opendoor()               # Open door if motion detected
         time.sleep(0.1)              # Short delay in loop

   try:
      loop()
   except KeyboardInterrupt:
      # Clean up GPIO on user interrupt (e.g., Ctrl+C)
      buzPin.off()
      ledPin.off()

此 Python 脚本集成了 PIR 运动传感器、舵机、LED 和蜂鸣器，创建了一个自动迎宾系统。运行时：

1. **运动检测**：连接到 GPIO 引脚 22 的 PIR 运动传感器检测运动。

2. **门自动化**：检测到运动时：

     - 舵机（PWM 4）通过从 0° 移动到 180° 打开门。
     - LED（GPIO 引脚 17）亮起。
     - 通过蜂鸣器（PWM 0）播放迎宾铃声。
     - 舵机通过从 180° 移回 0° 关闭门。
     - LED 熄灭。

3. **持续监控**：系统持续监控运动，每当检测到运动时就触发上述序列。

4. **优雅退出**：按下 ``Ctrl+C`` 时，蜂鸣器和 LED 关闭，脚本安全退出。


----------------------------------------------

**理解代码**

1. **运动检测：** PIR 传感器检测运动并触发系统。

2. **舵机控制：** 舵机使用 0° 到 180° 的角度打开和关闭门。

3. **蜂鸣器旋律：** 使用 ``Buzzer`` 播放迎宾曲。

4. **重置：** 播放铃声后，系统关闭门并熄灭 LED，准备迎接下一次事件。



----------------------------------------------


**故障排除**

1. **未检测到运动**：

   - **原因**：PIR 传感器接线错误或环境干扰。
   - **解决方法**：

     - 确保 PIR 传感器连接到 GPIO 引脚 22、电源和 GND。
     - 如有可用，调整传感器的灵敏度和延时电位器。

2. **舵机不移动**：

   - **原因**：舵机配置不正确或电源问题。
   - **解决方法**：

     - 验证舵机是否连接到 P4 并正确供电。

3. **铃声不播放**：

   - **原因**：蜂鸣器配置错误或曲调格式不正确。
   - **解决方法**：

     - 确保蜂鸣器连接到 P0。
     - 验证 ``tune`` 列表包含有效的音符和持续时间对。

4. **LED 不亮**：

   - **原因**：LED 接线或 GPIO 配置问题。
   - **解决方法**：验证 LED 是否通过适当的电阻连接到 GPIO 引脚 17。
