4.5 Bienvenida
==============================

**Introducción**

¿Alguna vez has notado las puertas automáticas en las tiendas de conveniencia que se abren con un sonido de bienvenida cuando alguien se acerca? Este proyecto replica esa funcionalidad a menor escala. Usando un sensor PIR, un servomotor, un LED y un zumbador, crearás un sistema de "puerta automática" en miniatura. Cuando se detecta movimiento, el sistema enciende un LED, "abre" la puerta usando un servo y reproduce un sonido de bienvenida con un zumbador.

.. code-block:: python

   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.servo import Servo
   from fusion_hat.modules import Buzzer
   from fusion_hat.pwm import PWM
   import time

   # GPIO pin setup
   ledPin = Pin(17, Pin.OUT)

   # Initialize a PIR Module object on GPIO pin 17
   pirPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)

   buzPin = Buzzer(PWM('P0'))

   # Initialize servo with custom pulse widths
   servoPin = Servo('P4')

   # Musical tune for buzzer, with notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('C4', 0.2), ('B4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
         ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
         ('D4', 0.2), ('E4', 0.2)]

   def setAngle(angle):
      """
      Move the servo to a specified angle.
      :param angle: Angle in degrees (0-180).
      """
      servoPin.angle(angle)       # Set servo position
      time.sleep(0.001)           # Short delay for servo movement

   def doorbell():
      """
      Play a musical tune using the buzzer.
      """
      for note, duration in tune:
         buzPin.play(note,float(duration))       # Play the note
      buzPin.off()               # Stop buzzer after playing the tune

   def closedoor():
      # Turn off LED and move servo to close door
      ledPin.off()
      for i in range(180, -1, -1):
         setAngle(i)             # Move servo from 180 to 0 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait after closing door

   def opendoor():
      # Turn on LED, open door (move servo), play tune, close door
      ledPin.on()
      for i in range(0, 181):
         setAngle(i)             # Move servo from 0 to 180 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait before playing the tune
      doorbell()                  # Play the doorbell tune
      closedoor()                 # Close the door after the tune

   def loop():
      # Main loop to check for motion and operate door
      while True:
         if pirPin.value()==1:
               opendoor()               # Open door if motion detected
         time.sleep(0.1)              # Short delay in loop

   try:
      loop()
   except KeyboardInterrupt:
      # Clean up GPIO on user interrupt (e.g., Ctrl+C)
      buzPin.off()
      ledPin.off()

Este script de Python integra un sensor de movimiento PIR, un servomotor, un LED y un zumbador para crear un sistema de bienvenida automatizado. Cuando se ejecuta:

1. **Detección de Movimiento**: Un sensor de movimiento PIR conectado al pin GPIO 22 detecta movimiento.

2. **Automatización de la Puerta**: Cuando se detecta movimiento:

     - El servomotor (en PWM 4) abre una puerta moviéndose de 0° a 180°.
     - El LED (en el pin GPIO 17) se enciende.
     - Se reproduce un sonido de bienvenida a través del zumbador (en PWM 0).
     - El servomotor cierra la puerta moviéndose de vuelta de 180° a 0°.
     - El LED se apaga.

3. **Monitoreo Continuo**: El sistema monitorea continuamente el movimiento y activa la secuencia anterior cada vez que se detecta movimiento.

4. **Salida Ordenada**: Al presionar ``Ctrl+C``, el zumbador y el LED se apagan, y el script termina limpiamente.


----------------------------------------------

**Comprender el Código**

1. **Detección de Movimiento:** El sensor PIR detecta movimiento y activa el sistema.

2. **Control del Servo:** El servomotor abre y cierra la puerta usando ángulos de 0° a 180°.

3. **Melodía del Zumbador:** Se reproduce una melodía de bienvenida usando el ``Buzzer``.

4. **Reinicio:** Después del sonido, el sistema cierra la puerta y apaga el LED, listo para el siguiente evento.



----------------------------------------------


**Solución de Problemas**

1. **No Se Detecta Movimiento**:

   - **Causa**: El sensor PIR no está cableado correctamente o hay interferencia ambiental.
   - **Solución**:

     - Asegúrate de que el sensor PIR esté conectado al pin GPIO 22, alimentación y tierra.
     - Ajusta los potenciómetros de sensibilidad y retardo del sensor si están disponibles.

2. **El Servo No Se Mueve**:

   - **Causa**: Configuración incorrecta del servo o problemas de alimentación.
   - **Solución**:

     - Verifica que el servo esté conectado a P4 y alimentado correctamente.

3. **El Sonido No Se Reproduce**:

   - **Causa**: Mala configuración del zumbador o formato de melodía incorrecto.
   - **Solución**:

     - Asegúrate de que el zumbador esté conectado a P0.
     - Verifica que la lista ``tune`` contenga pares válidos de nota y duración.

4. **El LED No Se Enciende**:

   - **Causa**: Problemas de cableado del LED o configuración de GPIO.
   - **Solución**: Verifica que el LED esté conectado al pin GPIO 17 con una resistencia adecuada.

**Ideas para Extender**

1. **Sonido Ajustable**: Agrega más melodías o permite al usuario seleccionar diferentes sonidos para distintos eventos.

2. **Operación Basada en Horario**: Desactiva el sistema durante horas específicas (por ejemplo, de noche):

     .. code-block:: python

         from datetime import datetime
         if 8 <= datetime.now().hour < 22:  # Funciona solo entre 8 AM y 10 PM
             opendoor()

3. **Registro de Datos**: Guarda los eventos de detección de movimiento y las marcas de tiempo en un archivo para su análisis:

     .. code-block:: python

         with open("motion_log.txt", "a") as log_file:
             log_file.write(f"{time.strftime('%Y-%m-%d %H:%M:%S')} - Motion detected\n")

4. **Saludos de Voz**: Reemplaza el sonido del zumbador con mensajes de voz pregrabados usando un altavoz.
