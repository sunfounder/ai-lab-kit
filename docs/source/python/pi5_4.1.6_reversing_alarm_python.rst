4.1.6 Reversing Alarm
==============================

**Introduction**

Ein Auto sicher in eine Garage zu manövrieren erfordert besonders in engen Räumen präzises Navigieren. In diesem Projekt baust du ein Einpark-Warngerät mit einem Ultraschallsensor, einem LCD und einem Summer. Das System ahmt einen Parkassistenten nach und liefert visuelles sowie akustisches Feedback über den Abstand zu Hindernissen.

**Writing the Code**

.. code-block:: python

    #!/usr/bin/env python3

    import time
    from fusion_hat import Ultrasonic, Buzzer, Pin,LCD1602

    # Trigger pin is connected to GPIO 27, Echo pin to GPIO 22
    sensor = Ultrasonic(trig=Pin(27), echo=Pin(22))

    # Initialize the buzzer connected to GPIO pin 17
    buzzer = Buzzer(Pin(17))

    # Initialize the LCD with I2C address and enable backlight
    lcd = LCD1602(address=0x27, backlight=1)
    lcd.clear()  # Clear the LCD display
    # Display startup messages on LCD
    lcd.write(0, 0, 'Ultrasonic Starting')
    lcd.write(1, 1, 'By SunFounder')
    time.sleep(2)  # Wait for 2 seconds

    def distance():
        # Calculate and return the distance measured by the sensor
        dis = sensor.read() # Convert distance to centimeters
        print('Distance: {:.2f} cm'.format(dis))  # Print distance with two decimal places
        time.sleep(0.3)  # Wait for 0.3 seconds before next measurement
        return dis

    def loop():
        # Continuously measure distance and update LCD and buzzer
        while True:
            dis = distance()  # Get the current distance
            # Display distance and handle alerts based on distance
            if dis > 400:  # Check if distance is out of range
                lcd.clear()
                lcd.write(0, 0, 'Error')
                lcd.write(3, 1, 'Out of range')
                time.sleep(0.5)
            else:
                # Display current distance on LCD
                lcd.clear()
                lcd.write(0, 0, 'Distance is')
                lcd.write(5, 1, str(round(dis, 2)) + ' cm')
                # Adjust buzzer frequency based on distance
                if dis >= 50:
                    time.sleep(0.5)
                elif 20 < dis < 50:
                    # Medium distance: medium buzzer frequency
                    for _ in range(2):
                        buzzer.on()
                        time.sleep(0.05)
                        buzzer.off()
                        time.sleep(0.2)
                elif dis <= 20:
                    # Close distance: high buzzer frequency
                    for _ in range(5):
                        buzzer.on()
                        time.sleep(0.05)
                        buzzer.off()
                        time.sleep(0.05)

    try:
        loop()      # Start the measurement loop
    except KeyboardInterrupt:
        # Turn off buzzer and clear LCD on user interrupt (e.g., Ctrl+C)
        buzzer.off()
        lcd.clear()

Dieses Python-Skript kombiniert einen Ultraschall-Abstandssensor, einen Summer und ein LCD1602-Display zu einem Echtzeit-Abstandsanzeigesystem. Beim Ausführen passiert Folgendes:

1. **System Initialization**:

   - Das LCD zeigt zunächst eine Willkommensmeldung:

   .. code-block:: python

      Ultrasonic Starting
      By SunFounder


   - Die Meldung bleibt 2 Sekunden sichtbar, bevor in den Messbetrieb gewechselt wird.

2. **Distance Measurement**: Der Ultraschallsensor erfasst den Abstand zum nächstgelegenen Objekt und gibt ihn in Zentimetern aus.

3. **LCD Output**:

   - Der gemessene Abstand wird in Echtzeit auf dem LCD angezeigt:

   .. code-block:: python

      Distance is
      XX.XX cm

   - Überschreitet der Abstand 400 cm, erscheint eine Fehlermeldung:

   .. code-block:: python

      Error
      Out of range


4. **Buzzer Alerts**: Je nach Abstand:

     - **Mehr als 50 cm**: Kein Tonsignal.
     - **Zwischen 20 cm und 50 cm**: Der Summer piept zweimal mit kurzem Intervall.
     - **20 cm oder weniger**: Schnelle Pieptöne als unmittelbare Warnung.

1. **LCD Initialization:** Das LCD wird initialisiert und zeigt eine Startmeldung.

   .. code-block:: python

2. **Distance Measurement:** Der Ultraschallsensor berechnet den Abstand, der anschließend auf dem LCD ausgegeben wird.

3. **Auditory Alerts:** Die Summer-Frequenz variiert abhängig von der Hindernisnähe:

   * **>50 cm:** Kein Ton.
   * **20–50 cm:** Zweimaliges Piepen mit mittleren Abständen.
   * **≤20 cm:** Schnelles Piepen als dringende Warnung.

**Troubleshooting**

1. **LCD zeigt nichts an**:

   - **Ursache**: Falsche I²C-Adresse oder Verdrahtung.
   - **Lösung**:

     - I²C-Adresse des LCD mit ``i2cdetect -y 1`` prüfen und die Adresse in ``LCD1602`` entsprechend anpassen.
     - Sicherstellen, dass SDA- und SCL-Leitungen korrekt verbunden sind.

2. **Abstand wird nicht gemessen**:

   - **Ursache**: Falsche Verdrahtung oder defekter Sensor.
   - **Lösung**:

     - Prüfen, ob ``echo`` und ``trigger`` an GPIO 22 bzw. GPIO 27 angeschlossen sind.
     - Sensor separat testen, um die Funktion zu verifizieren.

3. **Summer bleibt stumm**:

   - **Ursache**: Summer nicht angeschlossen oder defekt.
   - **Lösung**:

     - Anschlüsse an GPIO 17 und Masse prüfen.
     - Funktionstest manuell auslösen:
       
       .. code-block:: python

           buzzer.on()
           time.sleep(1)
           buzzer.off()

4. **LCD zeigt ständig 'Out of range'**:

   - **Ursache**: Sensor erkennt keine Objekte im Arbeitsbereich.
   - **Lösung**:

     - Sicherstellen, dass keine Hindernisse oder Störungen im Messfeld liegen.
     - Objekte innerhalb des effektiven Messbereichs (typisch 2–400 cm) platzieren.

**Extendable Ideas**

1. **Anpassbare Schwellwerte**: Benutzerdefinierte Abstandsschwellen für die Summer-Warnungen festlegen.

2. **Datenlogging**: Messwerte zur späteren Analyse in eine Datei schreiben:

   .. code-block:: python

      with open("distance_log.txt", "a") as log_file:
            log_file.write(f"{time.time():.3f}, {dis:.2f} cm\n")

3. **Visuelle Warnstufen**: LEDs in unterschiedlichen Farben für die Distanzbereiche einsetzen (z. B. Grün = sicher, Gelb = Vorsicht, Rot = Gefahr).

4. **Dynamische Meldungen**: Abhängig vom Abstand benutzerdefinierte LCD-Texte anzeigen, z. B.:

   - ``Too Close!``
   - ``Safe Distance``
