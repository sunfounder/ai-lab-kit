2.9 Photoresistance
========================

**Introduction**

Une photoresistance, egalement connue sous le nom de resistance dependante de la lumiere (LDR), est un composant qui detecte l'intensite lumineuse. Sa resistance diminue a mesure que l'intensite lumineuse augmente, ce qui la rend utile dans des dispositifs comme les lampes automatiques de nuit et les controleurs de lumiere ambiante.

Ce projet montre comment utiliser une photoresistance avec le Fusion HAT+ pour ajuster la luminosite d'une LED en fonction du niveau de lumiere ambiante. Le principe de fonctionnement est similaire a celui d'un potentiometre, sauf que l'entree est la lumiere au lieu d'un reglage manuel.

Ce script Python lit en continu la valeur de la photoresistance, la mappe a une plage appropriee pour definir la luminosite de la LED et ajuste la luminosite de la LED en consequence. Le script inclut egalement un mecanisme d'arret propre pour eteindre la LED lorsqu'il est interrompu par l'utilisateur. Lors de l'execution :

1. Le Fusion HAT+ lit en continu les valeurs de la photoresistance depuis son canal d'entree (allant de 0 a 4095).
2. La valeur analogique, representant l'intensite lumineuse, est affichee sur la console sous la forme ``result =  <value>``.
3. Le script mappe la valeur analogique a un signal PWM pour ajuster la luminosite de la LED.
4. La luminosite de la LED change dynamiquement en fonction de l'entree ADC, avec des mises a jour toutes les 0,2 secondes.
5. Le programme s'execute indefiniment jusqu'a ce qu'il soit interrompu avec ``Ctrl+C``, moment auquel la LED s'eteint.

**Code**

Voici le code Python utilise dans ce projet :

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Initialize a PWM LED
   led = PWM('P0')

   # Set up the potentiometer
   photoresistor = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = photoresistor.read()
         print('result = %d ' %result)

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**Depannage**

1. **La LED ne s'allume pas** :

   - **Cause** : Connexion GPIO incorrecte ou cablage de la LED.
   - **Solution** : Verifiez que la LED est connectee a P0 avec une resistance pour eviter tout dommage.

2. **Les valeurs ADC sont toujours a zero ou au maximum** :

   - **Cause** : Cablage incorrect.
   - **Solution** : Verifiez la broche ADC et assurez-vous qu'elle est connectee a la photoresistance.

3. **La luminosite de la LED ne change pas** :

   - **Cause** : Les valeurs ADC ne sont pas correctement mappees a la plage PWM.
   - **Solution** : Assurez-vous que la fonction de mappage met correctement a l'echelle la valeur ADC a la plage PWM (0 a 100).
