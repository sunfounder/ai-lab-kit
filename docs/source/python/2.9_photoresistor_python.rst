2.9 Fotoresistore
===========================

**Introduzione**

Un fotoresistore, noto anche come resistore dipendente dalla luce (LDR), è un componente che rileva l'intensità luminosa. La sua resistenza diminuisce all'aumentare dell'intensità luminosa, rendendolo utile in dispositivi come lampade notturne automatiche e regolatori di luce ambientale.

Questo progetto dimostra come usare un fotoresistore con Fusion HAT+ per regolare la luminosità di un LED in base ai livelli di luce ambientale. Il principio di funzionamento è simile a un potenziometro, tranne per il fatto che l'ingresso è la luce invece della regolazione manuale.

Tutto il codice di esempio usato in questo tutorial è disponibile nella directory ``ai-lab-kit``.
Segui questi passaggi per eseguire l'esempio:

.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/python/
   sudo python3 2.9_Photoresistor.py

Questo script Python legge continuamente il valore del fotoresistore, lo mappa in un intervallo adatto per impostare la luminosità del LED e regola la luminosità del LED di conseguenza. Lo script include anche un meccanismo di uscita controllata per spegnere il LED quando viene interrotto dall'utente. Quando eseguito:

1. Fusion HAT+ legge continuamente i valori del fotoresistore dal suo canale di ingresso (da 0 a 4095).
2. Il valore analogico, che rappresenta l'intensità luminosa o un altro ingresso variabile, viene stampato sulla console come ``result = <value>``.
3. Lo script mappa il valore analogico in un segnale PWM per regolare la luminosità del LED.
4. La luminosità del LED cambia dinamicamente in base all'ingresso ADC, con aggiornamenti ogni 0,2 secondi.
5. Il programma viene eseguito indefinitamente fino a quando non viene interrotto con ``Ctrl+C``, a quel punto il LED si spegne.

**Codice**

Qui sotto c'è il codice Python usato in questo progetto:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Initialize a PWM LED
   led = PWM('P0')

   # Set up the potentiometer
   photoresistor = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = photoresistor.read()
         print('result = %d ' %result)

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**Risoluzione dei Problemi**

1. **Il LED Non Si Accende**:

   - **Causa**: Connessione GPIO errata o cablaggio del LED.
   - **Soluzione**: Verifica che il LED sia collegato a P0 con un resistore per evitare danni.

2. **Valori ADC Sempre Zero o al Massimo**:

   - **Causa**: Cablaggio errato.
   - **Soluzione**: Controlla il pin ADC e assicurati che sia collegato al fotoresistore.

3. **La Luminosità del LED Non Cambia**:

   - **Causa**: I valori ADC non sono mappati correttamente all'intervallo PWM.
   - **Soluzione**: Assicurati che la funzione di mappatura ridimensioni correttamente il valore ADC all'intervallo PWM (da 0 a 100).
