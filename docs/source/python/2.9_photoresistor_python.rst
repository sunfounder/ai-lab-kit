2.9 Fotoresistencia
===========================

**Introducción**

Un fotoresistor, también conocido como resistor dependiente de la luz (LDR), es un componente que detecta la intensidad de la luz. Su resistencia disminuye a medida que aumenta la intensidad de la luz, lo que lo hace útil en dispositivos como lámparas nocturnas automáticas y controladores de luz ambiental.

Este proyecto demuestra cómo usar un fotoresistor con Fusion HAT+ para ajustar el brillo de un LED según los niveles de luz ambiental. El principio de funcionamiento es similar al de un potenciómetro, excepto que la entrada es luz en lugar de ajuste manual.

Este script de Python lee continuamente el valor del fotoresistor, lo mapea a un rango adecuado para ajustar el brillo del LED y ajusta el brillo del LED en consecuencia. El script también incluye un mecanismo de salida segura para apagar el LED cuando es interrumpido por el usuario. Al ejecutarse:

1. El Fusion HAT+ lee continuamente los valores del fotoresistor desde su canal de entrada (con un rango de 0 a 4095).
2. El valor analógico, que representa la intensidad de la luz u otra entrada variable, se imprime en la consola como ``result = <valor>``.
3. El script mapea el valor analógico a una señal PWM para ajustar el brillo del LED.
4. El brillo del LED cambia dinámicamente según la entrada del ADC, con actualizaciones cada 0.2 segundos.
5. El programa se ejecuta indefinidamente hasta que se interrumpe con ``Ctrl+C``, momento en el cual el LED se apaga.

**Código**

A continuación se muestra el código Python utilizado en este proyecto:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Initialize a PWM LED
   led = PWM('P0')

   # Set up the potentiometer
   photoresistor = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = photoresistor.read()
         print('result = %d ' %result)

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**Solución de Problemas**

1. **El LED no se enciende**:

   - **Causa**: Conexión incorrecta del GPIO o cableado del LED.
   - **Solución**: Verifica que el LED esté conectado a P0 con una resistencia para evitar daños.

2. **Los valores del ADC son siempre cero o máximos**:

   - **Causa**: Cableado incorrecto.
   - **Solución**: Revisa el pin del ADC y asegúrate de que esté conectado al fotoresistor.

3. **El brillo del LED no cambia**:

   - **Causa**: Los valores del ADC no se están mapeando correctamente al rango PWM.
   - **Solución**: Asegúrate de que la función de mapeo escale correctamente el valor del ADC al rango PWM (0 a 100).
