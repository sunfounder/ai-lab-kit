2.9 光敏电阻
=============

**介绍**

光敏电阻（也称为光依赖电阻LDR）是一种检测光线强度的元件。其阻值随着光线强度的增加而降低，使其适用于自动夜灯和环境光控制器等设备。

本项目演示了如何使用光敏电阻配合Fusion HAT+，根据环境光线水平调整LED的亮度。其工作原理与电位器类似，只是输入信号是光线而非手动调节。

此Python脚本持续读取光敏电阻的值，将其映射到适合设置LED亮度的范围，并相应调整LED的亮度。脚本还包含一个优雅退出机制，可在被用户中断时关闭LED。执行时：

1. Fusion HAT+持续从其输入通道读取光敏电阻的值（范围0到4095）。
2. 代表光线强度的模拟值以\ ``result = <value>``\ 的格式打印到控制台。
3. 脚本将模拟值映射为PWM信号，以调整LED的亮度。
4. LED亮度根据ADC输入动态变化，每0.2秒更新一次。
5. 程序无限运行，直到用\ ``Ctrl+C``\ 中断，此时LED熄灭。

**代码**

以下是本项目使用的Python代码：

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Initialize a PWM LED
   led = PWM('P0')

   # Set up the potentiometer
   photoresistor = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = photoresistor.read()
         print('result = %d ' %result)

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**理解代码**

1. **导入：**


   .. code-block:: python

      from fusion_hat.adc import ADC
      from fusion_hat.pwm import PWM
      import time


   脚本导入读取模拟值和控制LED亮度所需的模块。

2. **初始化：**


   .. code-block:: python

      # Initialize a PWM LED
      led = PWM('P0')

      # Set up the potentiometer
      photoresistor = ADC('A0')

   连接到GPIO引脚P0的LED被初始化，A0被设置为从光敏电阻读取模拟值。


3. **映射函数：**

   .. code-block:: python

       def MAP(x, in_min, in_max, out_min, out_max):
           return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   ``MAP``\ 函数将ADC值（0-4095）转换为适合PWM控制的范围（0到100）。



4. **主循环：**

   .. code-block:: python

      while True:
         # Get the current reading from the ADC port
         result = photoresistor.read()
         print('result = %d ' %result)

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   - 持续从光敏电阻读取光线强度值。
   - 根据检测到的光线强度按比例调整LED亮度。
   - 包含短暂延迟以减少CPU使用率，并允许LED亮度发生可见变化。


5. **优雅退出：**

   .. code-block:: python

      try:
         ...
      except KeyboardInterrupt:
         led.pulse_width_percent(0)  # Turn off the LED

   程序确保在脚本被中断时（例如通过\ ``Ctrl+C``\ ）关闭LED。

**故障排除**

1. **LED不亮**：

   - **原因**：GPIO连接或LED接线错误。
   - **解决方案**：确认LED连接到P0并带有电阻以防止损坏。

2. **ADC值始终为零或最大**：

   - **原因**：接线错误。
   - **解决方案**：检查ADC引脚，确保其连接到光敏电阻。

3. **LED亮度不变**：

   - **原因**：ADC值未正确映射到PWM范围。
   - **解决方案**：确保映射函数正确地将ADC值缩放到PWM范围（0到100）。
