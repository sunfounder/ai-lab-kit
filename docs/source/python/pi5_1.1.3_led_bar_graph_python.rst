**Writing the Code**

Das folgende Python-Skript lässt die LEDs in verschiedenen Mustern aufleuchten – ungerade, gerade sowie alle LEDs nacheinander. Speichern und starten Sie das Skript, um die Effekte zu beobachten:


.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat import Pin
   from time import sleep

   # Define GPIO pins where LEDs are connected
   led_pins = [4, 17, 27, 22, 23, 24, 25, 5, 13, 26]

   # Create LED objects for each pin
   leds = [Pin(pin, Pin.OUT) for pin in led_pins]

   def all_led_bar_graph():
      # Sequentially light up all LEDs one by one
      for led in leds:
         led.high()       # Turn on LED
         sleep(0.3)     # Delay for visual effect
         led.low()      # Turn off LED

   def turn_off_all_leds():
      # Turn off all LEDs at once
      for led in leds:
         led.low()

   try:
      # Main loop to cycle through LED patterns
      while True:
         all_led_bar_graph()   # Activate all LEDs
         sleep(0.3)            # Pause before restarting

   except KeyboardInterrupt:
      # Handle interruption (Ctrl+C) gracefully
      turn_off_all_leds()      # Ensure all LEDs are turned off on exit
      pass

Dieses Python-Skript steuert eine Reihe von LEDs, die an bestimmte GPIO-Pins eines Raspberry Pi angeschlossen sind. Beim Ausführen leuchten die LEDs nacheinander auf, jeweils eine nach der anderen.

Nach Abschluss der Sequenz legt das Skript eine kurze Pause ein und startet den Zyklus erneut. Das Programm läuft unbegrenzt, bis es vom Benutzer mit ``Ctrl+C`` beendet wird.

**Understanding the Code**

1. **Importing Libraries**

   Die Bibliothek ``fusion_hat`` dient zur LED-Steuerung, und die Bibliothek ``time`` erzeugt Pausen.

   .. code-block:: python


      from fusion_hat import Pin
      from time import sleep


2. **Defining GPIO Pins**

   ``led_pins`` legt die GPIO-Pins für die LEDs fest, und ``leds`` erstellt die zugehörigen ``LED``-Objekte.

   .. code-block:: python

      # Define GPIO pins where LEDs are connected
      led_pins = [4, 17, 27, 22, 23, 24, 25, 5, 13, 26]

      # Create LED objects for each pin
      leds = [Pin(pin, Pin.OUT) for pin in led_pins]


3. **LED Pattern**

   Lässt alle LEDs der Reihe nach aufleuchten.

   .. code-block:: python

       def all_led_bar_graph():
           for led in leds:
               led.on()
               sleep(0.3)
               led.off()

4. **Handling Interruptions**

   Stellt sicher, dass beim Abbruch alle LEDs ausgeschaltet werden.

   .. code-block:: python

       def turn_off_all_leds():
           for led in leds:
               led.off()

----------------------------------------------

**Troubleshooting**

1. **LEDs leuchten nicht**  

   - **Ursache**: Falsche Verdrahtung oder fehlerhafte GPIO-Konfiguration.  
   - **Lösung**: Prüfen Sie, ob die LEDs an die in ``led_pins`` angegebenen GPIO-Pins angeschlossen sind und ein Vorwiderstand zur LED-Schutzbeschaltung verwendet wird.

2. **KeyboardInterrupt funktioniert nicht korrekt**  

   - **Ursache**: LEDs bleiben nach dem Abbruch eingeschaltet.  
   - **Lösung**: Stellen Sie sicher, dass ``turn_off_all_leds()`` im Block ``except KeyboardInterrupt`` ausgeführt wird.

3. **GPIO nicht korrekt eingerichtet**  

   - **Ursache**: Die Bibliothek ``fusion_hat`` ist nicht installiert.  
   - **Lösung**: Siehe :ref:`download_the_lib`.

4. **Zeit- oder Flackerprobleme**  

   - **Ursache**: Unzureichende Stromversorgung oder instabile Verbindungen.  
   - **Lösung**: Überprüfen Sie die Spannungsquelle und die Steckverbindungen.

**Extendable Ideas**

1. **Eigene LED-Muster**  

   Erstellen Sie weitere Muster, indem Sie Funktionen anpassen oder neue hinzufügen. Beispielsweise einen „Wellen“-Effekt:  

.. code-block:: python

   def wave_pattern():
       for led in leds:
           led.on()
           sleep(0.2)
           led.off()


2. **Dynamische Benutzersteuerung**  

   Lassen Sie den Nutzer Muster interaktiv auswählen:  

.. code-block:: python

   while True:
       choice = input("Enter pattern (odd/even/all/wave): ")
       if choice == 'odd':
           odd_led_bar_graph()
       elif choice == 'even':
           even_led_bar_graph()
       elif choice == 'all':
           all_led_bar_graph()
       elif choice == 'wave':
           wave_pattern()


3. **Odd LED Pattern**

   Lässt LEDs an ungeraden Indizes nacheinander aufleuchten.

.. code-block:: python

   def odd_led_bar_graph():
      for i in range(5):
         j = i * 2
         leds[j].on()
         sleep(0.3)
         leds[j].off()

4. **Even LED Pattern**

   Lässt LEDs an geraden Indizes nacheinander aufleuchten.

.. code-block:: python

   def even_led_bar_graph():
      for i in range(5):
         j = i * 2 + 1
         leds[j].on()
         sleep(0.3)
         leds[j].off()
