2.7 Sensore PIR
=================

**Introduzione**

Il sensore PIR (Passive Infrared) è un dispositivo di rilevamento del movimento che percepisce la radiazione infrarossa emessa da esseri umani e animali. In questo progetto, useremo il sensore PIR per rilevare il movimento.

Questo script Python monitora un sensore di movimento PIR (Passive Infrared) basato sul rilevamento del movimento. Quando eseguito:

1. **Quando viene Rilevato Movimento**: Stampa "Detected Barrier!" sulla console.

2. **Quando Non viene Rilevato Movimento**: Stampa "No Barrier" sulla console.

3. Il programma viene eseguito indefinitamente, in attesa di eventi di movimento. Può essere terminato premendo Ctrl+C.

**Codice**

Qui sotto c'è il codice Python per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   # Initialize a PIR Module object on GPIO pin 17
   pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   def detect():
      if pir.value() == 1:  # Check if the PIR Module is triggered
         print("Detected Barrier!")
      else:
         print("No Barrier")

   try:
      pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
      pir.when_deactivated = detect

      # Run an event loop that waits for button events and keeps the script running
      print("CTRL + C to exit")
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Comprendere il Codice**

1. **Importazioni:**

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module

   Lo script usa la libreria ``fusion_hat`` per controllare il sensore PIR e il modulo ``signal`` per gestire la terminazione del programma.


2. **Inizializzazione:**

   .. code-block:: python

      pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   In questa riga, un sensore PIR viene inizializzato sul pin 17 con un resistore pull-down interno abilitato.


3. **Ciclo Principale:**

   .. code-block:: python

      def detect():
         if pir.value() == 1:  # Check if the PIR Module is triggered
            print("Detected Barrier!")
         else:
            print("No Barrier")

      try:
         pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
         pir.when_deactivated = detect

         # Run an event loop that waits for button events and keeps the script running
         print("CTRL + C to exit")
         pause()

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass


   * Controlla continuamente la presenza di movimento rilevato dal sensore PIR.
   * Se viene rilevato movimento, viene stampato il messaggio "Detected Barrier!".
   * Se non viene rilevato movimento, viene stampato il messaggio "No Barrier".


----------------------------------------------


**Risoluzione dei Problemi**


1. **Movimento Non Rilevato**:

   - **Causa**: Il sensore PIR non è cablato o configurato correttamente.
   - **Soluzione**:

     - Assicurati che il sensore PIR sia collegato al pin GPIO 17, all'alimentazione e a massa.
     - Regola i potenziometri di sensibilità e ritardo del sensore, se disponibili.
