2.7 PIR传感器
==============

**介绍**

被动红外（PIR）传感器是一种运动检测设备，可以感知人体和动物发出的红外辐射。在本项目中，我们将使用PIR传感器检测运动。

**代码**

以下是本项目的Python代码：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   # Initialize a PIR Module object on GPIO pin 17
   pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   def detect():
      if pir.value() == 1:  # Check if the PIR Module is triggered
         print("Detected Barrier!")
      else:
         print("No Barrier")

   try:
      pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
      pir.when_deactivated = detect

      # Run an event loop that waits for button events and keeps the script running
      print("CTRL + C to exit")
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**理解代码**

1. **导入：**

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module

   脚本使用\ ``fusion_hat``\ 库控制PIR传感器，使用\ ``signal``\ 模块处理程序终止。


2. **初始化：**

   .. code-block:: python

      pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   在这一行中，PIR传感器在引脚17上初始化，并启用了内部下拉电阻。


3. **主循环：**

   .. code-block:: python

      def detect():
         if pir.value() == 1:  # Check if the PIR Module is triggered
            print("Detected Barrier!")
         else:
            print("No Barrier")

      try:
         pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
         pir.when_deactivated = detect

         # Run an event loop that waits for button events and keeps the script running
         print("CTRL + C to exit")
         pause()

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass


   * 持续检查PIR传感器检测到的运动。
   * 如果检测到运动，打印消息"Detected Barrier!"。
   * 如果未检测到运动，打印消息"No Barrier"。

**故障排除**


1. **未检测到运动**：

   - **原因**：PIR传感器接线或配置不正确。
   - **解决方案**：

     - 确保PIR传感器连接到GPIO 17引脚、电源和地。
     - 如果可用，调节传感器的灵敏度和延迟电位器。
