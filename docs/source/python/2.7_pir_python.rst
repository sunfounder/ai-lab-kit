2.7 Capteur PIR
===================

**Introduction**

Le capteur infrarouge passif (PIR) est un dispositif de detection de mouvement qui detecte le rayonnement infrarouge emis par les humains et les animaux. Dans ce projet, nous utiliserons le capteur PIR pour detecter le mouvement.

Ce script Python surveille un capteur de mouvement PIR (infrarouge passif) base sur la detection de mouvement. Lors de l'execution :

1. **Lorsque le mouvement est detecte** : Affiche "Detected Barrier!" sur la console.

2. **Lorsqu'aucun mouvement n'est detecte** : Affiche "No Barrier" sur la console.

3. Le programme s'execute indefiniment, attendant les evenements de mouvement. Il peut etre termine en appuyant sur Ctrl+C.


----------------------------------------------


**Code**

Voici le code Python pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   # Initialize a PIR Module object on GPIO pin 17
   pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   def detect():
      if pir.value() == 1:  # Check if the PIR Module is triggered
         print("Detected Barrier!")
      else:
         print("No Barrier")

   try:
      pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
      pir.when_deactivated = detect

      # Run an event loop that waits for button events and keeps the script running
      print("CTRL + C to exit")
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Comprendre le code**

1. **Importations :**

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module

   Le script utilise la bibliotheque ``fusion_hat`` pour controler le capteur PIR et le module ``signal`` pour gerer la terminaison du programme.


2. **Initialisation :**

   .. code-block:: python

      pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   Dans cette ligne, un capteur PIR est initialise sur la broche 17 avec une resistance pull-down interne activee.


3. **Boucle principale :**

      def detect():
         if pir.value() == 1:  # Check if the PIR Module is triggered
            print("Detected Barrier!")
         else:
            print("No Barrier")

      try:
         pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
         pir.when_deactivated = detect

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully

   * Verifie en continu le mouvement detecte par le capteur PIR.
   * Si un mouvement est detecte, le message "Detected Barrier!" est affiche.
   * Si aucun mouvement n'est detecte, le message "No Barrier" est affiche.


----------------------------------------------


**Depannage**


1. **Mouvement non detecte** :

   - **Cause** : Le capteur PIR n'est pas correctemente cabler ou configure.
   - **Solution** :

     - Assurez-vous que le capteur PIR est connecte a la broche GPIO 17, a l'alimentation et a la masse.
     - Ajustez les potentiometres de sensibilite et de delai du capteur s'ils sont disponibles.
