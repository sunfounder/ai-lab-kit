4.2 Camera de capture automatique
=========================================

**Introduction**

Imaginez que vous vous absentez et qu’un petit ecureuil curieux visite votre rebord de fenetre. Avec ce projet, vous pouvez creer une camera de capture automatique pour prendre des photos de ces moments charmants. A l’aide d’un capteur de mouvement, la camera detecte les deplacements et capture des photos a intervalles reguliers.

#. Executez le script pour demarrer la camera :

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 4.2_AutomaticCaptureCamera.py

#. Apres l’execution du script :

   * La camera demarre et surveille en continu le capteur de mouvement PIR connecte a la GPIO 17.
   * Lorsque le capteur PIR detecte un mouvement et que sa sortie passe a HIGH, la camera capture une photo et l’enregistre dans le dossier Pictures avec un nom de fichier incremental.
   * Apres chaque capture, le programme attend brievement pour eviter les photos repetees.
   * Le systeme continue de surveiller les mouvements et fonctionne jusqu’a ce que vous appuyiez sur Ctrl + C pour quitter.

**Code**

Voici le code Python utilise pour ce projet :

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize PIR sensor (GPIO 17)
   pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nMotion detected! Capturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
            camera.start_preview(Preview.QT)
            preview_started = True
         except Exception as e:
            print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("PIR sensor monitoring on GPIO 17.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
            if pir.value():        # PIR detects motion (HIGH)
               take_photo()        # Take one photo
               time.sleep(2)       # Delay to avoid repeated shots

            time.sleep(0.1)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         try:
            camera.stop()
         except Exception:
            pass

         if preview_started:
            try:
               camera.stop_preview()
            except Exception:
               pass

         try:
            camera.close()
         except Exception:
            pass

   if __name__ == "__main__":
      main()

      from fusion_hat.pin import Pin, Mode, Pull

   Le script importe les bibliotheques pour la gestion des fichiers (``os``), le controle du temps (``time``), la securite des threads (``threading``), le fonctionnement de la camera (``Picamera2``) et le controle GPIO (``Pin``).

   .. code-block:: python

      REAL_USER = os.getenv("SUDO_USER") or os.getlogin()

      PICTURES_DIR = os.path.join(USER_HOME, "Pictures")

   Cette section determine le repertoire personnel correct de l’utilisateur et garantit que le dossier ``Pictures`` existe pour enregistrer les photos.

5. **Initialisation du capteur PIR :**

   .. code-block:: python

   Le capteur de mouvement PIR est connecte a la GPIO 17 et configure comme entree avec une resistance de tirage vers le bas.

6. **Fonction de capture photo :**

   .. code-block:: python

      def take_photo():

   Cette fonction capture une seule photo et l’enregistre dans le repertoire ``Pictures`` chaque fois qu’un mouvement est detecte.

7. **Gestion de l’apercu et demarrage de la camera :**

   .. code-block:: python

   Le programme surveille en continu le capteur PIR. Lorsqu’un mouvement est detecte (HIGH), une photo est prise, suivie d’une breve temporisation pour eviter les captures repetees.

9. **Sortie du programme et nettoyage :**

**Depannage**

1. **Les photos ne sont pas capturees** :

   - **Cause :** Le capteur de mouvement PIR ne fonctionne pas ou est mal branche.
   - **Solution :**

     - Verifiez que le capteur PIR est connecte a la broche GPIO 17, a l’alimentation et a la masse.
     - Ajustez les potentiometres de sensibilite et de delai du capteur PIR si disponibles.

2. **Le capteur PIR detecte toujours un mouvement** :

   - **Cause :** Capteur PIR defectueux ou interference environnementale excessive.
   - **Solution :**

     - Testez le capteur avec un multimetre pour vous assurer qu’il detecte correctement les mouvements.
     - Placez le capteur dans un environnement stable et controle pour eviter les faux positifs.

3. **Le script plante avec une erreur de camera** :

   - **Cause :** La camera n’est pas correctement initialisee ou est utilisee par un autre processus.
   - **Solution :**

     - Assurez-vous que la camera est connectee et activee via ``raspi-config``.
     - Redemarrez le Raspberry Pi pour liberer les processus conflictuels.
