4.2 自动抓拍摄像头
==================

**简介**

想象一下，当您外出时，一只好奇的小松鼠造访了您的窗台。有了这个项目，您可以创建一个自动抓拍摄像头来捕捉这些愉快的瞬间。利用运动传感器，摄像头可以检测运动并按固定间隔拍摄照片。

   * :ref:`remote_desktop`：使用\ **VNC**\ 获得完整的桌面体验。
   * |link_rpi_connect|：使用\ **Raspberry Pi Connect**\ 从任何浏览器安全地访问树莓派。

#. 打开终端并进入代码文件夹：

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. 运行脚本启动摄像头：

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 4.2_AutomaticCaptureCamera.py

#. 运行脚本后：

   * 摄像头启动并持续监控连接到 GPIO 17 的 PIR 运动传感器。
   * 当 PIR 传感器检测到运动且输出变为 HIGH 时，摄像头拍摄一张照片，并以递增的文件名保存到 Pictures 文件夹。
   * 每次拍摄后，程序会短暂等待以避免重复拍照。
   * 系统持续监控运动，一直运行直到按 Ctrl + C 退出。

**代码**

以下是本项目使用的 Python 代码：

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize PIR sensor (GPIO 17)
   pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nMotion detected! Capturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
            camera.start_preview(Preview.QT)
            preview_started = True
         except Exception as e:
            print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("PIR sensor monitoring on GPIO 17.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
            if pir.value():        # PIR detects motion (HIGH)
               take_photo()        # Take one photo
               time.sleep(2)       # Delay to avoid repeated shots

            time.sleep(0.1)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         try:
            camera.stop()
         except Exception:
            pass

         if preview_started:
            try:
               camera.stop_preview()
            except Exception:
               pass

         try:
            camera.close()
         except Exception:
            pass

   if __name__ == "__main__":
      main()

**理解代码**

1. **导入：**

   .. code-block:: python

      import os
      import time
      import threading
      from picamera2 import Picamera2, Preview
      from fusion_hat.pin import Pin, Mode, Pull

   脚本导入了文件处理（``os``）、定时控制（``time``）、线程安全（``threading``）、摄像头操作（``Picamera2``）和 GPIO 控制（``Pin``）等库。

2. **路径设置：**

   .. code-block:: python

      REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
      USER_HOME = f"/home/{REAL_USER}"
      PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
      os.makedirs(PICTURES_DIR, exist_ok=True)

   此部分确定正确的用户主目录，并确保用于保存照片的 ``Pictures`` 文件夹存在。

3. **摄像头初始化：**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   摄像头被初始化并配置为 800 × 600 的预览分辨率。

4. **照片计数器和线程锁：**

   .. code-block:: python

      photo_index = 1
      photo_lock = threading.Lock()

   使用照片计数器创建连续的文件名，并使用锁确保拍照时的安全访问。

5. **PIR 传感器初始化：**

   .. code-block:: python

      pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   PIR 运动传感器连接到 GPIO 17，设置为带有下拉电阻的输入。

6. **拍照功能：**

   .. code-block:: python

      def take_photo():
         """Capture one photo and increment the index."""
         global photo_index
         with photo_lock:
            filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
            print(f"\nMotion detected! Capturing: {filepath}")
            camera.capture_file(filepath)
            print("Saved.")
            photo_index += 1

   此功能在检测到运动时拍摄一张照片并保存到 ``Pictures`` 目录。

7. **预览处理和摄像头启动：**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
         try:
            camera.start_preview(Preview.QT)
            preview_started = True
         except Exception as e:
            print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")


   仅当图形显示可用时才启动摄像头预览；否则，脚本以无头模式运行。

8. **主循环（运动检测）：**

   .. code-block:: python

      while True:
         if pir.value():
            take_photo()
            time.sleep(2)

   程序持续监控 PIR 传感器。当检测到运动（HIGH）时，拍摄一张照片，然后短暂延时以防止重复捕获。

9. **程序退出和清理：**

   .. code-block:: python

      except KeyboardInterrupt:
         camera.stop()
         camera.close()

   当用户按下 ``Ctrl + C`` 时，程序优雅退出，安全地停止并关闭摄像头。

**故障排除**

1. **未拍摄照片**：

   - **原因**：PIR 运动传感器不工作或接线错误。
   - **解决方法**：

     - 验证 PIR 传感器是否连接到 GPIO 引脚 17、电源和 GND。
     - 如有可用，调整 PIR 传感器的灵敏度和延时电位器。

2. **PIR 传感器始终检测到运动**：

   - **原因**：PIR 传感器故障或环境干扰过多。
   - **解决方法**：

     - 使用万用表测试传感器，确保其能正确检测运动。
     - 将传感器放置在稳定、可控的环境中，避免误报。

3. **脚本因摄像头错误崩溃**：

   - **原因**：摄像头未正确初始化或被其他进程使用。
   - **解决方法**：

     - 确保摄像头已连接并通过 ``raspi-config`` 启用。
     - 重启树莓派以释放冲突进程。
