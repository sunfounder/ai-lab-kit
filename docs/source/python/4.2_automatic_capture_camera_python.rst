4.2 Cámara de Captura Automática
===================================

**Introducción**

Imagina que estás fuera de casa y una pequeña ardilla curiosa visita tu ventana. Con este proyecto, puedes crear una cámara de captura automática para fotografiar estos momentos encantadores. Usando un sensor de movimiento, la cámara detecta movimiento y captura fotos a intervalos regulares.

   .. raw:: html

   .. code-block:: shell

      sudo python3 4.2_AutomaticCaptureCamera.py

#. Después de ejecutar el script:

   * La cámara se inicia y monitorea continuamente el sensor de movimiento PIR conectado al GPIO 17.
   * Cuando el sensor PIR detecta movimiento y su salida pasa a HIGH, la cámara captura una foto y la guarda en la carpeta Pictures con un nombre de archivo incremental.
   * Después de cada captura, el programa espera brevemente para evitar fotos repetidas.
   * El sistema sigue monitoreando el movimiento y se ejecuta hasta que presiones Ctrl + C para salir.

**Código**

Aquí está el código Python utilizado para este proyecto:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize PIR sensor (GPIO 17)
   pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nMotion detected! Capturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
            camera.start_preview(Preview.QT)
            preview_started = True
         except Exception as e:
            print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("PIR sensor monitoring on GPIO 17.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
            if pir.value():        # PIR detects motion (HIGH)
               take_photo()        # Take one photo
               time.sleep(2)       # Delay to avoid repeated shots

            time.sleep(0.1)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         try:
            camera.stop()
         except Exception:
            pass

         if preview_started:
            try:
               camera.stop_preview()
            except Exception:
               pass

         try:
            camera.close()
         except Exception:
            pass

   if __name__ == "__main__":
      main()

      import threading
      from picamera2 import Picamera2, Preview
      from fusion_hat.pin import Pin, Mode, Pull

   El script importa librerías para el manejo de archivos (``os``), control de tiempo (``time``), seguridad de hilos (``threading``), operación de la cámara (``Picamera2``) y control de GPIO (``Pin``).

   El sensor de movimiento PIR está conectado al GPIO 17 y configurado como entrada con una resistencia de pull-down.

**Solución de Problemas**

1. **No Se Capturan Fotos**:

   - **Causa**: El sensor de movimiento PIR no funciona o está mal cableado.
   - **Solución**:

     - Verifica que el sensor PIR esté conectado al pin GPIO 17, alimentación y tierra.
     - Ajusta los potenciómetros de sensibilidad y retardo del sensor PIR si están disponibles.

2. **El Sensor PIR Siempre Detecta Movimiento**:

   - **Causa**: Sensor PIR defectuoso o interferencia ambiental excesiva.
   - **Solución**:

     - Prueba el sensor con un multímetro para asegurarte de que detecta movimiento correctamente.
     - Coloca el sensor en un entorno estable y controlado para evitar falsos positivos.

3. **El Script Falló con Error de Cámara**:

   - **Causa**: La cámara no está correctamente inicializada o está en uso por otro proceso.
   - **Solución**:

     - Asegúrate de que la cámara esté conectada y habilitada mediante ``raspi-config``.
     - Reinicia la Raspberry Pi para liberar cualquier proceso conflictivo.
