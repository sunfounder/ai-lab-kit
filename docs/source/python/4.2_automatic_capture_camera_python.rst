4.2 Fotocamera ad Acquisizione Automatica
=========================================

**Introduzione**

Immagina di essere via, e un piccolo scoiattolo curioso visita il tuo davanzale. Con questo progetto, puoi creare una fotocamera ad acquisizione automatica per catturare questi momenti deliziosi. Usando un sensore di movimento, la fotocamera rileva il movimento e acquisisce foto a intervalli regolari.

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 4.2_AutomaticCaptureCamera.py

#. Dopo aver eseguito lo script:

   * La fotocamera si avvia e monitora continuamente il sensore di movimento PIR collegato a GPIO 17.
   * Quando il sensore PIR rileva movimento e la sua uscita diventa HIGH, la fotocamera acquisisce una foto e la salva nella cartella Pictures con un nome file incrementale.
   * Dopo ogni acquisizione, il programma attende brevemente per evitare foto ripetute.
   * Il sistema continua a monitorare il movimento e funziona fino a quando non premi Ctrl + C per uscire.

**Codice**

Ecco il codice Python usato per questo progetto:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize PIR sensor (GPIO 17)
   pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nMotion detected! Capturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
            camera.start_preview(Preview.QT)
            preview_started = True
         except Exception as e:
            print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("PIR sensor monitoring on GPIO 17.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
            if pir.value():        # PIR detects motion (HIGH)
               take_photo()        # Take one photo
               time.sleep(2)       # Delay to avoid repeated shots

            time.sleep(0.1)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         try:
            camera.stop()
         except Exception:
            pass

         if preview_started:
            try:
               camera.stop_preview()
            except Exception:
               pass

         try:
            camera.close()
         except Exception:
            pass

   if __name__ == "__main__":
      main()

**Comprendere il Codice**

1. **Importazioni:**

   .. code-block:: python

      import os
      import time
      import threading
      from picamera2 import Picamera2, Preview
      from fusion_hat.pin import Pin, Mode, Pull

   Lo script importa librerie per la gestione dei file (``os``), controllo temporale (``time``), sicurezza dei thread (``threading``), operazioni sulla fotocamera (``Picamera2``) e controllo GPIO (``Pin``).

2. **Configurazione del Percorso:**

   .. code-block:: python

      REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
      USER_HOME = f"/home/{REAL_USER}"
      PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
      os.makedirs(PICTURES_DIR, exist_ok=True)

   Questa sezione determina la directory home corretta dell'utente e assicura che la cartella ``Pictures`` esista per salvare le foto.

3. **Inizializzazione della Fotocamera:**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   La fotocamera viene inizializzata e configurata con una risoluzione di anteprima di 800 × 600.

4. **Contatore Foto e Blocco Thread:**

   .. code-block:: python

      photo_index = 1
      photo_lock = threading.Lock()

   Un contatore foto viene usato per creare nomi file sequenziali, e un blocco garantisce un accesso sicuro durante l'acquisizione delle foto.

5. **Inizializzazione del Sensore PIR:**

   .. code-block:: python

      pir = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   Il sensore di movimento PIR è collegato a GPIO 17 e impostato come ingresso con un resistore pull-down.

6. **Funzione di Acquisizione Foto:**

   .. code-block:: python

      def take_photo():
         """Capture one photo and increment the index."""
         global photo_index
         with photo_lock:
            filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
            print(f"\nMotion detected! Capturing: {filepath}")
            camera.capture_file(filepath)
            print("Saved.")
            photo_index += 1

   Questa funzione acquisisce una singola foto e la salva nella directory ``Pictures`` ogni volta che viene rilevato movimento.

7. **Gestione dell'Anteprima e Avvio della Fotocamera:**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
         try:
            camera.start_preview(Preview.QT)
            preview_started = True
         except Exception as e:
            print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")


   Un'anteprima della fotocamera viene avviata solo quando è disponibile un display grafico; altrimenti, lo script funziona in modalità headless.

8. **Ciclo Principale (Rilevamento Movimento):**

   .. code-block:: python

      while True:
         if pir.value():
            take_photo()
            time.sleep(2)

   Il programma monitora continuamente il sensore PIR. Quando viene rilevato movimento (HIGH), viene acquisita una foto, seguita da un breve ritardo per prevenire acquisizioni ripetute.

9. **Uscita dal Programma e Pulizia:**

   .. code-block:: python

      except KeyboardInterrupt:
         camera.stop()
         camera.close()

   Quando l'utente preme ``Ctrl + C``, il programma esce in modo controllato e ferma e chiude in sicurezza la fotocamera.

**Risoluzione dei Problemi**

1. **Le Foto Non Vengono Acquisite**:

   - **Causa**: Il sensore di movimento PIR non funziona o è cablato erroneamente.
   - **Soluzione**:

     - Verifica che il sensore PIR sia collegato al pin GPIO 17, all'alimentazione e a massa.
     - Regola i potenziometri di sensibilità e ritardo del sensore PIR, se disponibili.

2. **Il Sensore PIR Rileva Sempre Movimento**:

   - **Causa**: Sensore PIR difettoso o interferenza ambientale eccessiva.
   - **Soluzione**:

     - Testa il sensore con un multimetro per assicurarti che rilevi correttamente il movimento.
     - Posiziona il sensore in un ambiente stabile e controllato per evitare falsi positivi.

3. **Lo Script si Arresta con Errore della Fotocamera**:

   - **Causa**: La fotocamera non è inizializzata correttamente o è in uso da un altro processo.
   - **Soluzione**:

     - Assicurati che la fotocamera sia collegata e abilitata tramite ``raspi-config``.
     - Riavvia il Raspberry Pi per rilasciare eventuali processi in conflitto.
