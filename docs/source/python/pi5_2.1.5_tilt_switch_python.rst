2.1.5 Neigungsschalter
==============================

**Introduction**

In diesem Projekt beschäftigen wir uns mit dem Neigungsschalter-Modul – einem Kugel-Neigungsschalter, der eine kleine Metallkugel enthält. Dieser Schalter ist für das Erkennen kleinster Neigungen ausgelegt und eignet sich für Anwendungen wie Bewegungserkennung, Winkelmessung und Lageüberwachung.

**Writing the Code**

Nachfolgend das Python-Skript zur Ansteuerung des Neigungsschalters und der LEDs:

.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin
   from signal import pause  # Import pause function from signal module

   TiltPin = Pin(17,Pin.IN, pull=Pin.PULL_DOWN)  # Tilt sensor connected to GPIO pin 17
   green_led = Pin(27, Pin.OUT)  # Green LED connected to GPIO pin 27
   red_led = Pin(22, Pin.OUT)   # Red LED connected to GPIO pin 22

   def detect():
      """
      Detect the tilt sensor state and control the LEDs.
      Turns on the red LED and turns off the green LED when tilted.
      Turns off the red LED and turns on the green LED when not tilted.
      """
      if TiltPin.value() == 1:  # Check if the sensor is tilted
         print('    *************')
         print('    *   Tilt!   *')
         print('    *************')
         red_led.high()   # Turn on red LED
         green_led.low()  # Turn off green LED
      else:  # If the sensor is not tilted
         red_led.low()  # Turn off red LED
         green_led.high()  # Turn on green LED

   try:
      # Set up a callback to detect changes in the tilt sensor state
      TiltPin.when_activated = detect 
      TiltPin.when_deactivated = detect  
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass


Dieses Python-Skript verwendet einen Neigungssensor, um zwei LEDs zu steuern und Statusmeldungen in der Konsole auszugeben. Beim Ausführen gilt:

1. Erkennt der Neigungssensor (an GPIO-Pin 17) eine Neigung:

   - Es wird eine Meldung in der Konsole ausgegeben.
   - Die rote LED (GPIO-Pin 22) leuchtet.
   - Die grüne LED (GPIO-Pin 27) erlischt.

2. Wird keine Neigung erkannt:

   - Die rote LED erlischt.
   - Die grüne LED leuchtet.

3. Das Programm überwacht den Sensorzustand kontinuierlich und passt die LEDs entsprechend an.

4. Das Skript läuft unbegrenzt, bis es mit ``Ctrl+C`` beendet wird.


----------------------------------------------

**Understanding the Code**

1. **Imports**

   Das Skript importiert die benötigten Klassen zur LED- und Taster-Steuerung und initialisiert sie mit den entsprechenden GPIO-Pins.

   .. code-block:: python

      from fusion_hat import Pin
      from signal import pause

2. **Initialization**

   Konfigurieren Sie den Neigungsschalter und die LEDs an den GPIO-Pins 17, 27 und 22.

   .. code-block:: python

      TiltPin = Pin(17,Pin.IN, pull=Pin.PULL_DOWN)  # Tilt sensor connected to GPIO pin 17
      green_led = Pin(27, Pin.OUT)  # Green LED connected to GPIO pin 27
      red_led = Pin(22, Pin.OUT)   # Red LED connected to GPIO pin 22

3. **Detect Function**

   Die Funktion ``detect`` prüft den Zustand des Neigungsschalters und aktualisiert die LEDs entsprechend. Bei Neigung leuchtet die rote LED, die grüne geht aus.

   .. code-block:: python

      def detect():
         """
         Detect the tilt sensor state and control the LEDs.
         Turns on the red LED and turns off the green LED when tilted.
         Turns off the red LED and turns on the green LED when not tilted.
         """
         if TiltPin.value() == 1:  # Check if the sensor is tilted
            red_led.high()   # Turn on red LED
            green_led.low()  # Turn off green LED
         else:  # If the sensor is not tilted
            red_led.low()  # Turn off red LED
            green_led.high()  # Turn on green LED

4. **Main Loop**

   Weisen Sie ``detect`` den Ereignissen ``when_pressed`` und ``when_released`` (hier: ``when_activated``/``when_deactivated``) des Neigungssensors zu. Die Schleife läuft bis zur Unterbrechung weiter.

   .. code-block:: python

      try:
         # Set up a callback to detect changes in the tilt sensor state
         TiltPin.when_activated = detect 
         TiltPin.when_deactivated = detect  
         pause()

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass

**Troubleshooting**

1. **Skript reagiert nicht auf Neigung**  

   - **Ursache**: Ereignis-Handler (``when_activated`` / ``when_deactivated`` ) greifen nicht.  
   - **Lösung**: Prüfen Sie, ob ``detect()`` korrekt beiden Ereignissen zugewiesen ist.


2. **LEDs flackern**  

   - **Ursache**: Sensorausrauschen bzw. fehlende Entprellung.  
   - **Lösung**: Kurze Verzögerung zur Stabilisierung hinzufügen:


   .. code-block:: python


      from time import sleep
      def detect():
            sleep(0.05)  # Debounce delay
            if TiltPin.value() == 1: 
               red_led.on()
               green_led.off()
            else:
               red_led.off()
               green_led.on()

**Extendable Ideas**

1. **Akustisches Feedback**  

   Fügen Sie einen Buzzer hinzu, der bei aktivem Neigungssensor einen Ton ausgibt:
   
   .. code-block:: python

      from fusion_hat import Buzzer,Pin
      buzzer = Buzzer(Pin(4))
      if TiltPin.value() == 1:
         buzzer.on()
      else:
         buzzer.off()


2. **Zeitgesteuerte Warnung**  

   Lösen Sie einen Alarm aus, wenn der Sensor für eine bestimmte Dauer gekippt bleibt:

   .. code-block:: python

      from threading import Timer
      def alert():
         print("Tilt detected for too long!")
         red_led.on()
         sleep(0.5)
         red_led.off()

      if TiltPin.value() == 1:
         Timer(5, alert).start()  # Trigger alert if tilted for 5 seconds
