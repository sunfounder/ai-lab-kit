1.1.2 RGB-LED
====================

**Einführung**

In diesem Projekt lernen wir, wie man eine RGB-LED mit einem Raspberry Pi und GPIO-Programmierung steuert, um verschiedene Farben darzustellen.  
RGB-LEDs sind vielseitige Bauteile, die durch die Mischung von rotem, grünem und blauem Licht in unterschiedlichen Intensitäten ein breites Farbspektrum erzeugen können.

**Schaltplan**

Verbinden Sie die R-, G- und B-Pins der RGB-LED jeweils über Vorwiderstände mit PWM0, PWM1 und PWM2.  
Der längste Pin der LED (GND) wird mit dem GND-Pin des Raspberry Pi verbunden. Unterschiedliche PWM-Werte auf den drei Pins erzeugen verschiedene Farben.

.. image:: img/fzz/1.1.2_sch.png
   :width: 800
   :align: center

----------------------------------------------

**Verdrahtungsplan**

Folgen Sie diesen Schritten, um die Schaltung aufzubauen:

1. Platzieren Sie die RGB-LED auf dem Breadboard.  
2. Verbinden Sie die roten, grünen und blauen Pins der LED über Widerstände mit P0, P1 und P2.  
3. Schließen Sie den längsten Pin (GND) der LED an den GND des Raspberry Pi an.

**Code schreiben**

Das folgende Python-Skript lässt die RGB-LED durch verschiedene Farben wechseln, indem es unterschiedliche PWM-Werte für die roten, grünen und blauen Komponenten setzt:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import RGB_LED,PWM
   from time import sleep

   # Initialize an RGB LED. Connect the red component to P0, green to P1, and blue to P2.
   rgb_led = RGB_LED(PWM('P0'), PWM('P1'), PWM('P2'),common=RGB_LED.CATHODE)

   try:
      # Set the RGB LED to red.
      rgb_led.color((255, 0, 0))
      sleep(1)

      # Set the RGB LED to green.
      rgb_led.color("#00FF22") 
      sleep(1)

      # Set the RGB LED to purple.
      rgb_led.color(0xFF00FF)  
      sleep(1)

      # Set the RGB LED to black.
      rgb_led.color(0x000000)  

   except KeyboardInterrupt:
      # Handle a KeyboardInterrupt (Ctrl+C) to exit.
      rgb_led.color(0x000000)  
      pass


Dieses Skript zeigt, wie eine RGB-LED mit der Fusion-HAT-Bibliothek gesteuert wird.  
Die LED wird über die PWM-Pins initialisiert und anschließend nacheinander in verschiedene Farben geschaltet.


----------------------------------------------


**Den Code verstehen**


Führen Sie das Skript auf einem kompatiblen Gerät mit angeschlossener RGB-LED aus. Die LED wechselt dabei nacheinander zu Rot, Grün und Violett, bevor sie ausgeschaltet wird.


1. **Benötigte Module importieren**
   
   .. code:: python

      from fusion_hat import RGB_LED, PWM
      from time import sleep
   
   Hier werden die benötigten Module importiert. ``RGB_LED`` und ``PWM`` aus der Bibliothek ``fusion_hat`` steuern die LED, während ``sleep`` für die zeitliche Steuerung zuständig ist.

2. **Initialisierung der RGB-LED**
   
   .. code:: python

      rgb_led = RGB_LED(PWM('P0'), PWM('P1'), PWM('P2'), common=RGB_LED.CATHODE)
   
   Die RGB-LED wird so konfiguriert, dass ihre roten, grünen und blauen Pins mit den PWM-Pins ``P0``, ``P1`` und ``P2`` verbunden sind. Hierbei wird eine gemeinsame Kathode genutzt.

3. **Farben nacheinander einstellen**
   
   .. code:: python

      rgb_led.color((255, 0, 0))  # Rot
      sleep(1)
      
      rgb_led.color("#00FF22")  # Grün
      sleep(1)
      
      rgb_led.color(0xFF00FF)  # Violett
      sleep(1)
   
   Das Skript zeigt drei verschiedene Möglichkeiten, Farben zu definieren:

   - ``(255, 0, 0)``: RGB-Tupel für Rot  
   - ``"#00FF22"``: Hexadezimal-String für ein helles Grün  
   - ``0xFF00FF``: Hexadezimal-Wert für Violett  

4. **LED ausschalten**
   
   .. code:: python

      rgb_led.color(0x000000)
   
   Mit dem Wert ``0x000000`` wird die LED auf Schwarz gesetzt, was einem Ausschalten entspricht.

5. **Unterbrechungen abfangen**
   
   .. code:: python

      except KeyboardInterrupt:
         rgb_led.color(0x000000)
         pass
   
   Falls das Skript mit ``Ctrl+C`` beendet wird, wird die LED zuvor ausgeschaltet.


----------------------------------------------


**Fehlerbehebung**

1. **LED leuchtet nicht**  

   - **Ursache**: Falsche Verdrahtung oder falsche Pinbelegung.  
   - **Lösung**: Prüfen Sie, ob die roten, grünen und blauen Pins korrekt verbunden sind und ob Kathode oder Anode ordnungsgemäß angeschlossen ist.


2. **Flackernde oder instabile Farben**  

   - **Ursache**: Unstabile Stromversorgung oder fehlende Widerstände.  
   - **Lösung**: Verwenden Sie geeignete Widerstände und stellen Sie eine stabile Spannungsversorgung sicher.

3. **GPIO nicht korrekt eingerichtet**  

   - **Ursache**: Die Fusion-HAT-Bibliothek ist nicht installiert.  
   - **Lösung**: Siehe :ref:`download_the_lib`.

----------------------------------------------


**Erweiterungsmöglichkeiten**

1. **Eigene Farbsequenzen**  

   Fügen Sie zusätzliche Farben in die ``COLORS``-Liste ein, auch abgeschwächte Varianten wie ``(125, 50, 200)`` für weichere Töne.



2. **Benutzerdefinierte Farben**  

   Lassen Sie den Nutzer eigene RGB-Werte eingeben:  

   .. code-block:: python

        while True:
            user_color = input("Enter RGB values (e.g., 125,0,0): ")
            r, g, b = map(int, user_color.split(","))
            rgb_led.color = (r, g, b)



3. **Zufällige Farben**  

   Erzeugen Sie zufällige Farben, um eine dynamische und unvorhersehbare Lichtshow zu gestalten:  

   .. code-block:: python

      from random import randint
      while True:
         rgb_led.color = (randint(1,255) , randint(1,255) , randint(1,255) )
         sleep(1)


----------------------------------------------

**Fazit**

Mit diesem Projekt haben Sie gelernt, wie man eine RGB-LED mit einem Raspberry Pi und Python steuert.  
Dabei haben Sie die Grundlagen von PWM und Farbmischung kennengelernt, die sich zu komplexeren Lichteffekten erweitern oder als Basis für interaktive Projekte nutzen lassen.
