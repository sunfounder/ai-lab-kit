4.12 Monitor Ambientale
==============================================

**Introduzione**

In questa lezione, costruirai un **Dashboard di Monitoraggio Ambientale** che legge temperatura, umidit e livello di luce ambientale e visualizza tutti i valori in tempo reale su uno schermo OLED 128x64.

Questo progetto utilizza:

- **Sensore DHT11** per misurare temperatura e umidit
- **LDR (Fotoresistore)** collegato all'ADC di Fusion HAT+ per misurare il livello di luce
- **OLED SSD1306** per visualizzare i dati ambientali e una barra luminosa dinamica

Lo schermo si aggiorna continuamente e mostra un indicatore di stato (``OK`` o ``TIMEOUT``) a seconda che il DHT11 fornisca una lettura valida.

**Passaggi di Configurazione**

#. Installa le librerie richieste:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-ssd1306 --break

#. Esegui il codice di esempio dalla directory ``ai-lab-kit``:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 4.12_RoomMonitor.py

#. Quando lo script viene eseguito:

   * L'OLED mostra temperatura, umidit e percentuale di luce
   * Un grafico a barre orizzontale mostra il livello di luce corrente
   * "OK" o "TIMEOUT" indica lo stato di lettura del DHT11
   * I dati si aggiornano ogni 0,5 secondi
   * Premi **Ctrl+C** per uscire e cancellare il display
