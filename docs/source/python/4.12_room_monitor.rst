4.12 Monitor Ambiental
==============================================

**Introducción**

En esta lección, construirás un **Panel de Monitor Ambiental** que lee temperatura, humedad y nivel de luz ambiente, y muestra todos los valores en tiempo real en una pantalla OLED de 128×64.

Este proyecto utiliza:

- **Sensor DHT11** para medir temperatura y humedad
- **LDR (Fotorresistor)** conectado al ADC del Fusion HAT+ para medir el nivel de luz
- **OLED SSD1306** para mostrar datos ambientales y una barra de luz dinámica

La pantalla se actualiza continuamente y muestra un indicador de estado (``OK`` o ``TIMEOUT``) dependiendo de si el DHT11 proporciona una lectura válida.

**Código**

Aquí está el script de Python para el panel de monitor ambiental:

.. raw:: html

   <run></run>

.. code-block:: python

   import time
   from statistics import mean
   from fusion_hat.modules import DHT11
   from fusion_hat.adc import ADC
   from PIL import Image, ImageDraw, ImageFont
   import adafruit_ssd1306
   import board

   # ---------- Hardware configuration ----------
   DHT_PIN = 17          # BCM numbering for the DHT11 data pin
   LDR_CH  = 0           # ADC channel for LDR (e.g., 0,1, ...)
   I2C_ADDR = 0x3C       # OLED I2C address (commonly 0x3C)

   # ---------- OLED setup ----------
   WIDTH, HEIGHT = 128, 64
   i2c = board.I2C()
   oled = adafruit_ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c, addr=I2C_ADDR)
   oled.fill(0)
   oled.show()

   # Framebuffer
   image = Image.new("1", (WIDTH, HEIGHT))
   draw = ImageDraw.Draw(image)
   font  = ImageFont.load_default()

   def text_size(font, text):
      l, t, r, b = font.getbbox(text)
      return (r - l, b - t)

   # ---------- Sensors ----------
   dht = DHT11(pin=DHT_PIN)
   ldr = ADC(LDR_CH)

   # ---------- Light normalization ----------
   # Map ADC raw (0..4095) to percentage (0..100). You can adjust the calibration
   # range to your circuit by putting typical min/max readings below:
   LDR_RAW_MIN = 0       # raw value in darkness  (tune if needed)
   LDR_RAW_MAX = 4095    # raw value in bright light (tune if needed)

   def clamp(v, vmin, vmax):
      return vmax if v > vmax else vmin if v < vmin else v

   def linear_map(x, in_min, in_max, out_min, out_max):
      if in_max == in_min:
         return out_min
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   # Simple moving average for light to reduce flicker
   _light_window = []

   def light_percent(raw):
      """Convert raw ADC to smoothed light percentage."""
      global _light_window
      # Windowed average of last few samples
      _light_window.append(raw)
      if len(_light_window) > 5:
         _light_window.pop(0)
      smooth_raw = int(mean(_light_window))
      pct = linear_map(smooth_raw, LDR_RAW_MIN, LDR_RAW_MAX, 0, 100)
      return int(clamp(pct, 0, 100)), smooth_raw

   # ---------- UI drawing ----------
   BAR_W, BAR_H = WIDTH - 16, 10   # width/height for the light bar
   BAR_X, BAR_Y = 8, HEIGHT - 12   # position of the light bar

   def draw_bar(x, y, w, h, percent):
      """Draw a horizontal bar [0..100]%."""
      # Border
      draw.rectangle((x, y, x + w, y + h), outline=255, fill=0)
      # Fill
      fill_w = int((w - 2) * percent / 100.0)
      if fill_w > 0:
         draw.rectangle((x + 1, y + 1, x + 1 + fill_w, y + h - 1), outline=0, fill=255)

   def render_screen(temp_c, hum_pct, light_pct, raw_adc, status_text="OK"):
      """Render all text and graphics to the framebuffer."""
      draw.rectangle((0, 0, WIDTH, HEIGHT), outline=0, fill=0)

      # Title
      title = "Env Monitor"
      tw, th = text_size(font, title)
      draw.text(((WIDTH - tw) // 2, 0), title, font=font, fill=255)

      # Temperature & Humidity lines
      line1 = f"Temp: {temp_c:.1f} degC"
      line2 = f"Hum : {hum_pct:.1f} %"
      draw.text((2, 16), line1, font=font, fill=255)
      draw.text((2, 28), line2, font=font, fill=255)

      # Light line and bar
      line3 = f"Light: {light_pct:3d}%  (raw {raw_adc})"
      draw.text((2, 40), line3, font=font, fill=255)
      draw_bar(BAR_X, BAR_Y, BAR_W, BAR_H, light_pct)

      # Status (e.g., "OK" or "TIMEOUT")
      sw, sh = text_size(font, status_text)
      draw.text((WIDTH - sw - 2, 0), status_text, font=font, fill=255)

   # ---------- Main loop ----------
   # Keep last good readings so display stays meaningful if a DHT read times out
   last_temp = 0.0
   last_hum  = 0.0

   try:
      while True:
         # Read DHT11 (may return None / timeout)
         status = "OK"
         result = dht.read()
         if result:
               hum, temp = result  # order per your DHT11 wrapper: (humidity, temperature)
               last_temp, last_hum = float(temp), float(hum)
         else:
               status = "TIMEOUT"

         # Read LDR
         raw = ldr.read()
         light_pct, raw_smooth = light_percent(raw)

         # Draw to OLED
         render_screen(last_temp, last_hum, light_pct, raw_smooth, status_text=status)
         oled.image(image)
         oled.show()

         # Console log (optional)
         # print(f"T={last_temp:.1f}C  H={last_hum:.1f}%  Light={light_pct}% (raw {raw_smooth})  [{status}]")

         time.sleep(0.5)

   except KeyboardInterrupt:
      oled.fill(0)
      oled.show()
      print("\nExited.")

**Comprender el Código**

1. **Importaciones**

   El script utiliza varios módulos:

   - ``DHT11`` para la detección de temperatura/humedad
   - ``ADC`` para leer el brillo del LDR desde la entrada analógica
   - ``PIL`` para el dibujo en el OLED
   - ``adafruit_ssd1306`` para el control del OLED
   - ``mean()`` para suavizar las lecturas de luz


2. **Configuración del OLED**

   Se inicializa un OLED SSD1306 de 128×64 usando I2C.
   Se utiliza un framebuffer (imagen Pillow) para dibujar todos los elementos de la interfaz antes de enviarlos a la pantalla.

   .. code-block:: python

3. **Lectura de Sensores**

   - El DHT11 puede fallar ocasionalmente. Cuando esto ocurre, el script muestra ``TIMEOUT`` pero conserva los últimos valores válidos.
   - La lectura bruta del LDR (0..4095) se suaviza usando un promedio móvil para reducir el parpadeo.

   .. code-block:: python

      # Read DHT11 (may return None / timeout)

4. **Mapeo de Luz**

   ``linear_map()`` convierte el valor ADC bruto en un porcentaje (0..100%).
   ``clamp()`` asegura que el valor final se mantenga dentro del rango.

   .. code-block:: python

5. **Renderizado del Panel**

   El OLED muestra:

   - Título
   - Temperatura (°C)
   - Humedad (%)
   - Porcentaje de luz y valor ADC bruto
   - Un gráfico de barras horizontal para la intensidad de luz
   - Texto de estado que indica la salud del sensor


   .. code-block:: python

6. **Bucle Principal**

   Cada 0.5 segundos:

   - Se lee el DHT11
   - Se lee y suaviza el LDR
   - Se actualiza la pantalla
   - Se pueden imprimir registros de depuración opcionales

7. **Apagado Gracioso**

   Al presionar Ctrl+C:

   - El OLED se limpia
   - Se imprime un mensaje

----------------------------------------------

**Solución de Problemas**

- **El DHT11 devuelve TIMEOUT con frecuencia**

  - Aumenta el retardo entre lecturas
  - Verifica el cableado y el pin de señal
  - Asegúrate de usar una resistencia pull-up si es necesario

- **El OLED permanece en blanco**

  - Verifica la dirección I2C (``0x3C``)
  - Revisa el cableado SDA/SCL
  - Asegúrate de que las librerías estén instaladas correctamente

- **El porcentaje de luz parece invertido**

  - Intercambia ``LDR_RAW_MIN`` y ``LDR_RAW_MAX``
  - Revisa la orientación del circuito LDR (divisor de voltaje)

- **Parpadeo en la pantalla**

  - Aumenta la ventana de suavizado de luz
  - Reduce la tasa de refresco (usa ``time.sleep(1.0)``)
