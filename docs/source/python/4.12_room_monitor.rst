4.12 Moniteur d’environnement
==========================================

**Introduction**

Dans cette lecon, vous allez construire un **Tableau de bord de moniteur d’environnement** qui lit la temperature, l’humidite et le niveau de lumiere ambiante, et affiche toutes les valeurs en temps reel sur un ecran OLED 128×64.

Ce projet utilise :

- **Capteur DHT11** pour mesurer la temperature et l’humidite
- **LDR (photoresistance)** connectee a l’ADC du Fusion HAT+ pour mesurer le niveau de lumiere
- **OLED SSD1306** pour afficher les donnees environnementales et une barre de lumiere dynamique

L’ecran se met a jour en continu et affiche un indicateur d’etat (``OK`` ou ``TIMEOUT``) selon que le DHT11 fournit une lecture valide ou non.

**Code**

Here is the Python script for the environment monitor dashboard:

.. raw:: html

   <run></run>

.. code-block:: python

   import time
   from statistics import mean
   from fusion_hat.modules import DHT11
   from fusion_hat.adc import ADC
   from PIL import Image, ImageDraw, ImageFont
   import adafruit_ssd1306
   import board

   # ---------- Hardware configuration ----------
   DHT_PIN = 17          # BCM numbering for the DHT11 data pin
   LDR_CH  = 0           # ADC channel for LDR (e.g., 0,1, ...)
   I2C_ADDR = 0x3C       # OLED I2C address (commonly 0x3C)

   # ---------- OLED setup ----------
   WIDTH, HEIGHT = 128, 64
   i2c = board.I2C()
   oled = adafruit_ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c, addr=I2C_ADDR)
   oled.fill(0)
   oled.show()

   # Framebuffer
   image = Image.new("1", (WIDTH, HEIGHT))
   draw = ImageDraw.Draw(image)
   font  = ImageFont.load_default()

   def text_size(font, text):
      l, t, r, b = font.getbbox(text)
      return (r - l, b - t)

   # ---------- Sensors ----------
   dht = DHT11(pin=DHT_PIN)
   ldr = ADC(LDR_CH)

   # ---------- Light normalization ----------
   # Map ADC raw (0..4095) to percentage (0..100). You can adjust the calibration
   # range to your circuit by putting typical min/max readings below:
   LDR_RAW_MIN = 0       # raw value in darkness  (tune if needed)
   LDR_RAW_MAX = 4095    # raw value in bright light (tune if needed)

   def clamp(v, vmin, vmax):
      return vmax if v > vmax else vmin if v < vmin else v

   def linear_map(x, in_min, in_max, out_min, out_max):
      if in_max == in_min:
         return out_min
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   # Simple moving average for light to reduce flicker
   _light_window = []

   def light_percent(raw):
      """Convert raw ADC to smoothed light percentage."""
      global _light_window
      # Windowed average of last few samples
      _light_window.append(raw)
      if len(_light_window) > 5:
         _light_window.pop(0)
      smooth_raw = int(mean(_light_window))
      pct = linear_map(smooth_raw, LDR_RAW_MIN, LDR_RAW_MAX, 0, 100)
      return int(clamp(pct, 0, 100)), smooth_raw

   # ---------- UI drawing ----------
   BAR_W, BAR_H = WIDTH - 16, 10   # width/height for the light bar
   BAR_X, BAR_Y = 8, HEIGHT - 12   # position of the light bar

   def draw_bar(x, y, w, h, percent):
      """Draw a horizontal bar [0..100]%."""
      # Border
      draw.rectangle((x, y, x + w, y + h), outline=255, fill=0)
      # Fill
      fill_w = int((w - 2) * percent / 100.0)
      if fill_w > 0:
         draw.rectangle((x + 1, y + 1, x + 1 + fill_w, y + h - 1), outline=0, fill=255)

   def render_screen(temp_c, hum_pct, light_pct, raw_adc, status_text="OK"):
      """Render all text and graphics to the framebuffer."""
      draw.rectangle((0, 0, WIDTH, HEIGHT), outline=0, fill=0)

      # Title
      title = "Env Monitor"
      tw, th = text_size(font, title)
      draw.text(((WIDTH - tw) // 2, 0), title, font=font, fill=255)

      # Temperature & Humidity lines
      line1 = f"Temp: {temp_c:.1f} degC"
      line2 = f"Hum : {hum_pct:.1f} %"
      draw.text((2, 16), line1, font=font, fill=255)
      draw.text((2, 28), line2, font=font, fill=255)

      # Light line and bar
      line3 = f"Light: {light_pct:3d}%  (raw {raw_adc})"
      draw.text((2, 40), line3, font=font, fill=255)
      draw_bar(BAR_X, BAR_Y, BAR_W, BAR_H, light_pct)

      # Status (e.g., "OK" or "TIMEOUT")
      sw, sh = text_size(font, status_text)
      draw.text((WIDTH - sw - 2, 0), status_text, font=font, fill=255)

   # ---------- Main loop ----------
   # Keep last good readings so display stays meaningful if a DHT read times out
   last_temp = 0.0
   last_hum  = 0.0

   try:
      while True:
         # Read DHT11 (may return None / timeout)
         status = "OK"
         result = dht.read()
         if result:
               hum, temp = result  # order per your DHT11 wrapper: (humidity, temperature)
               last_temp, last_hum = float(temp), float(hum)
         else:
               status = "TIMEOUT"

         # Read LDR
         raw = ldr.read()
         light_pct, raw_smooth = light_percent(raw)

         # Draw to OLED
         render_screen(last_temp, last_hum, light_pct, raw_smooth, status_text=status)
         oled.image(image)
         oled.show()

         # Console log (optional)
         # print(f"T={last_temp:.1f}C  H={last_hum:.1f}%  Light={light_pct}% (raw {raw_smooth})  [{status}]")

         time.sleep(0.5)

   except KeyboardInterrupt:
      oled.fill(0)
      oled.show()
      print("\nExited.")

**Comprendre le code**

1. **Importations**

   Le script utilise plusieurs modules :

   - ``DHT11`` pour la detection de temperature/humidite
   - ``ADC`` pour lire la luminosite de la LDR a partir de l'entree analogique
   - ``PIL`` pour le dessin sur l'OLED
   - ``adafruit_ssd1306`` pour le controle de l'OLED
   - ``mean()`` pour lisser les lectures de lumiere


2. **Configuration OLED**

   Un OLED SSD1306 128×64 est initialise via I2C.
   Un tampon d'image (Pillow) est utilise pour dessiner tous les elements de l'interface avant de les envoyer a l'affichage.

   .. code-block:: python

3. **Lecture des capteurs**

   - Le DHT11 peut parfois echouer. Lorsque cela se produit, le script affiche ``TIMEOUT`` mais conserve les dernieres valeurs valides.
   - La lecture brute de la LDR (0..4095) est lisse a l'aide d'une moyenne mobile pour reduire le scintillement.

   .. code-block:: python

      # Read DHT11 (may return None / timeout)
      status = "OK"
      result = dht.read()

         hum, temp = result  # order per your DHT11 wrapper: (humidity, temperature)

      else:
         status = "TIMEOUT"

      # Read LDR
      raw = ldr.read()
      light_pct, raw_smooth = light_percent(raw)


4. **Mappage de la lumiere**

   ``linear_map()`` convertit la valeur ADC brute en pourcentage (0..100%).
   ``clamp()`` garantit que la valeur finale reste dans la plage.

   .. code-block:: python

         return int(clamp(pct, 0, 100)), smooth_raw


5. **Rendu du tableau de bord**

   L'OLED affiche :

   - Le titre
   - La temperature (°C)
   - L'humidite (%)
   - Le pourcentage de lumiere et la valeur ADC brute
   - Un graphique a barres horizontal pour l'intensite lumineuse
   - Un texte d'etat indiquant la sante du capteur


   .. code-block:: python

6. **Boucle principale**

   Toutes les 0,5 secondes :

   - Le DHT11 est lu
   - La LDR est lue et lisse
   - L'ecran est mis a jour
   - Des journaux de debogage facultatifs peuvent etre imprimes

7. **Arret propre**

   Sur Ctrl+C :

   - L'OLED est efface
   - Un message est imprime

----------------------------------------------

**Depannage**

- **Le DHT11 retourne TIMEOUT frequent**

  - Augmentez le delai entre les lectures
  - Verifiez le cablage et la broche de signal
  - Assurez-vous qu'une resistance de tirage est utilisee si necessaire

- **L'OLED reste vide**

  - Verifiez l'adresse I2C (``0x3C``)
  - Verifiez le cablage SDA/SCL
  - Assurez-vous que les bibliotheques sont installees correctement

- **Le pourcentage de lumiere semble inverse**

  - Echangez ``LDR_RAW_MIN`` et ``LDR_RAW_MAX``
  - Verifiez l'orientation du circuit de la LDR (diviseur de tension)

- **Scintillement de l'affichage**

  - Augmentez la fenetre de lissage de la lumiere
  - Reduisez le taux de rafraichissement (utilisez ``time.sleep(1.0)``)
