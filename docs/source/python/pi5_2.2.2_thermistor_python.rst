2.2.2 Thermistor
===================

**Einführung**

Ein Thermistor ist ein temperaturabhängiger Widerstand, der häufig in Anwendungen zur Temperaturmessung und -regelung eingesetzt wird. Im Gegensatz zu Photoresistoren, die auf Licht reagieren, reagieren Thermistoren auf Temperaturänderungen, indem sie ihren Widerstand anpassen. Dadurch eignen sie sich ideal für Projekte wie Hitzewarnungen, Thermostate oder Temperaturüberwachungssysteme. In diesem Projekt nutzen wir einen Thermistor, um die Umgebungstemperatur zu messen und sowohl in Celsius als auch in Fahrenheit darzustellen.

**Code schreiben**

Der folgende Python-Code wird in diesem Projekt verwendet:


.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat import ADC
   import time
   import math

   thermistor = ADC('A3')

   # Run the process in a try-except block
   try:
      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
            print("Please check the sensor")
            continue
         else:
            Rt = 10000 * Vr / (3.3 - Vr)
            temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25))) # Calculate the temperature in Kelvin
            Cel = temp - 273.15 # Convert Kelvin to Celsius
            Fah = Cel * 1.8 + 32 # Convert Celsius to Fahrenheit
            print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
            time.sleep(0.2)

   # Handle KeyboardInterrupt for graceful termination
   except KeyboardInterrupt:
      pass

Dieses Python-Skript liest ein analoges Signal von einem Thermistor über den Fusion HAT aus und berechnet die entsprechende Temperatur. Beim Ausführen:  

1. Das Skript liest kontinuierlich die Spannung ein.  
2. Es berechnet den Widerstand des Thermistors (``Rt``) und bestimmt die Temperatur in Kelvin, Celsius und Fahrenheit.  
3. Die berechneten Temperaturen werden mit zwei Nachkommastellen im Format ``Celsius: <Wert> C  Fahrenheit: <Wert> F`` ausgegeben.  
4. Der Prozess wiederholt sich alle 0,2 Sekunden, bis das Skript mit ``Ctrl+C`` unterbrochen wird.  


----------------------------------------------


**Code verstehen**

1. **Imports:**

   .. code-block:: python

      from fusion_hat import ADC
      import time
      import math


   Das Skript importiert die benötigten Module: ``ADC`` aus der ``fusion_hat``-Bibliothek zum Auslesen der Spannung, ``time`` für Wartezeiten und ``math`` für mathematische Berechnungen.  


2. **Initialisierung:**

   .. code-block:: python

      thermistor = ADC('A3')

   Initialisiert das ADC-Objekt am Pin A3.  

3. **Datenverarbeitung:**

   .. code-block:: python

      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
            print("Please check the sensor")
            continue
         else:
            Rt = 10000 * Vr / (3.3 - Vr)
            temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25))) # Calculate the temperature in Kelvin
            Cel = temp - 273.15 # Convert Kelvin to Celsius
            Fah = Cel * 1.8 + 32 # Convert Celsius to Fahrenheit

   - Liest die Spannung des Thermistors ein.  
   - Berechnet den Widerstand des Thermistors.  
   - Nutzt die Steinhart-Hart-Gleichung zur Berechnung der Temperatur in Kelvin.  
   - Wandelt Kelvin in Celsius und Fahrenheit um.  


4. **Ausgabe:**

   .. code-block:: python

      print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
      time.sleep(0.2)

   Die berechnete Temperatur wird sowohl in Celsius als auch in Fahrenheit auf dem Bildschirm angezeigt. Eine kurze Pause verhindert übermäßige CPU-Belastung und sorgt für stabilisierte Werte.  



----------------------------------------------


**Fehlerbehebung**


1. **Temperaturwerte sind falsch oder instabil**:  

   - **Ursache**: Falsche Thermistorparameter oder Störungen im Eingangssignal.  
   - **Lösung**:  

     - Stelle sicher, dass der Widerstand bei 25°C (``10000`` im Skript) und der B-Wert ``3950`` deinem Thermistormodell entsprechen.  
     - Verwende einen Kondensator oder Software-Filterung zur Reduzierung von Signalrauschen.  

2. **Divide-by-Zero-Fehler**:  

   - **Ursache**: Die Spannung ``Vr`` liegt zu nahe bei 0 oder 3,3V, was zu einer Division durch Null führt.  
   - **Lösung**: Stelle sicher, dass die ADC-Spannung im Bereich 0–3,3V bleibt und überprüfe die Verbindungen auf Kurzschlüsse oder Unterbrechungen.

**Erweiterbare Ideen**

1. **Temperaturanzeige auf LCD oder OLED**: Werte direkt auf einem Display darstellen.  

2. **Datenaufzeichnung**: Messwerte in einer Datei speichern:  

   .. code-block:: python

      with open("temperature_log.txt", "a") as log_file:
         log_file.write(f"Celsius: {Cel:.2f}, Fahrenheit: {Fah:.2f}\n")

3. **Schwellenwertbasierte Alarme**: Warnmeldungen auslösen, wenn die Temperatur einen Grenzwert überschreitet:  

   .. code-block:: python

      if Cel > 30:
         print("Warning: High temperature!")

4. **LED- oder Summer-Feedback**: Visuelles oder akustisches Feedback basierend auf Temperaturwerten:  

   .. code-block:: python

      from fusion_hat import Pin
      led = Pin(27.Pin.OUT)
      if Cel > 30:
            led.on()
      else:
            led.off()
