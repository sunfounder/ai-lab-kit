**Writing the Code**

Der folgende Python-Code steuert die Drehrichtung und Laufzeit des Motors:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from time import sleep
   from fusion_hat import Motor, PWM

   """
   Initialize a motor

   motor = Motor(pwmA, pwmB, is_reversed=False)

   :param pwmA pwmB: Motor speed control pwm pin
   :type pwm: fusion_hat.pwm.PWM

   :param is_reversed: Motor direction control
   :type is_reversed: True or False
   :default: False
   """

   motor = Motor(PWM('P8'), PWM('P9'))

   try:
      while True:
         motor.speed(0)
         sleep(0.5)
         motor.speed(-50)
         sleep(1)
         motor.speed(0)
         sleep(0.5)
         motor.speed(75)
         sleep(1)
   finally:
      motor.stop()
      sleep(.1)



----------------------------------------------

**Understanding the Code**

1. **Library Import**

   Die Bibliothek ``fusion_hat`` vereinfacht die Arbeit mit den GPIO-Pins, während ``time`` für Verzögerungen sorgt.

   .. code-block:: python

      from time import sleep
      from fusion_hat import Motor, PWM

2. **Motor Initialization**

   Das Objekt ``Motor`` wird mit den Pins M0 initialisiert.

   .. code-block:: python

      motor = Motor(PWM('P8'), PWM('P9'))

3. **Motor Actions**

   Die Motorgeschwindigkeit wird nacheinander auf 0, -50 und 75 gesetzt. Mit ``sleep`` wird das Programm jeweils pausiert.

   .. code-block:: python

      while True:
         motor.speed(0)
         sleep(0.5)
         motor.speed(-50)
         sleep(1)
         motor.speed(0)
         sleep(0.5)
         motor.speed(75)
         sleep(1)

4. **Interrupt Handling**

   Der ``try-except``-Block sorgt dafür, dass das Programm bei einer Unterbrechung mit ``Ctrl+C`` sauber beendet werden kann.

   .. code-block:: python

       except KeyboardInterrupt:
           pass


----------------------------------------------

**Troubleshooting**

1. **Motor bewegt sich nicht**  

   - **Ursache**: Falsche Verkabelung oder fehlerhafte GPIO-Konfiguration.  
   - **Lösung**: Prüfen Sie die Spannungsversorgung und stellen Sie sicher, dass der Enable-Pin korrekt angeschlossen ist.

2. **Nur eine Drehrichtung funktioniert**  

   - **Ursache**: Fehlerhafte Verbindung zum Vorwärts- oder Rückwärts-Pin.  
   - **Lösung**: Überprüfen Sie, ob alle Pins korrekt mit dem Fusion HAT verbunden sind.

3. **Motor dreht sich dauerhaft ohne zu stoppen**  

   - **Ursache**: Die Funktion ``stop()`` wird nicht korrekt ausgeführt.  
   - **Lösung**: Stellen Sie sicher, dass die Methode ``motor.stop()`` tatsächlich aufgerufen wird.


----------------------------------------------

**Extendable Ideas**


1. **Benutzersteuerung in Echtzeit**  

   Ermöglichen Sie eine direkte Steuerung des Motors über die Tastatur:

   .. code-block:: python

      while True:
         num = int(input("The speed percentage (-100~100): "))
         if num >= -100 and num <= 100:
            motor.speed(num)
         else:
            print("Invalid action!")


2. **Zeitgesteuerte Motorsteuerung**  

   Lassen Sie den Motor für eine benutzerdefinierte Dauer laufen:

   .. code-block:: python

      duration = int(input("Enter duration (seconds): "))
      motor.speed(50)
      sleep(duration)
      motor.stop()
