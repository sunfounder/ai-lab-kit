4.1.4 Zählgerät
=======================

**Introduction**

In diesem Projekt baust du ein Personen-Zählsystem mit einem PIR-Bewegungssensor und einer 4-stelligen 7-Segment-Anzeige. Jedes Mal, wenn der PIR-Sensor eine Bewegung registriert, erhöht sich der auf der Anzeige dargestellte Zähler. Das Projekt eignet sich ideal zur Überwachung des Durchgangsverkehrs in Fluren oder Eingangsbereichen und bietet praktische Erfahrungen mit GPIO-Programmierung und Anzeigeansteuerung.

**Writing the Code**


Nachfolgend das in diesem Projekt verwendete Python-Skript:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin

   # Initialize PIR motion sensor on GPIO 22
   pir = Pin(22, Pin.IN, pull= Pin.PULL_DOWN)

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17,Pin.OUT)   # Serial Data Input
   RCLK = Pin(4,Pin.OUT)  # Register Clock
   SRCLK = Pin(27,Pin.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,Pin.OUT) for pin in (23, 24, 25, 12)]

   # Define digit codes for 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Counter for the displayed number
   counter = 0

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift a byte of data to the 74HC595 shift register. """
      for i in range(8):
         SDI.value(0x80 & (data << i))  # Set SDI high/low based on data bit
         SRCLK.high()  # Pulse the Shift Register Clock
         SRCLK.low()
      RCLK.high()  # Latch data on the output by pulsing Register Clock
      RCLK.low()

   def pickDigit(digit):
      """ Select a digit for display on the 7-segment display. """
      for pin in placePin:
         pin.low()  # Turn off all digit selection pins
      placePin[digit].high()  # Turn on the selected digit


   def display():
      # Updates the display with the current counter value
      global counter
      clearDisplay()
      pickDigit(3)
      hc595_shift(number[counter % 10])

      clearDisplay()
      pickDigit(2)
      hc595_shift(number[counter % 100//10])

      clearDisplay()
      pickDigit(1)
      hc595_shift(number[counter % 1000//100])

      clearDisplay()
      pickDigit(0)
      hc595_shift(number[counter % 10000//1000])

   def loop():
      # Main loop to update display and check for motion
      global counter
      currentState = 0
      lastState = 0
      while True:
         display()
         currentState = 1 if pir.value()==1 else 0
         if currentState == 1 and lastState == 0:
               counter += 1
         lastState = currentState

   try:
      loop()
   except KeyboardInterrupt:
      # Turn off all pins when the script is interrupted
      SDI.low()
      SRCLK.low()
      RCLK.low()
      pass

Dieses Python-Skript verbindet einen PIR-Bewegungssensor mit einer über einen 74HC595 angesteuerten 7-Segment-Anzeige. Es führt Folgendes aus:

1. **Motion Detection**: Ein an GPIO **22** angeschlossener PIR-Sensor erkennt Bewegungen. Bei jeder Erkennung erhöht sich der Zähler.

2. **Number Display**:

   - Der aktuelle Zählerwert wird auf einer 4-stelligen 7-Segment-Anzeige dargestellt.
   - Die Anzeige aktualisiert sich dynamisch bei erkannter Bewegung.

3. **Continuous Monitoring**: Das Skript überwacht kontinuierlich Bewegungen und aktualisiert die Anzeige in Echtzeit.

4. **Graceful Exit**: Bei ``Ctrl+C`` werden alle Pins deaktiviert, um das Skript sauber zu beenden.


----------------------------------------------

**Understanding the Code**

1. **Motion Detection:**
   
   Der PIR-Sensor meldet Bewegungen und löst eine Erhöhung des Zählers aus.

2. **Display Update:**
   
   Die Funktionen ``hc595_shift`` und ``pickDigit`` steuern gemeinsam die 7-Segment-Anzeige und aktualisieren den Zählerwert in Echtzeit.

3. **Main Loop:**
   
   Die Funktion ``loop`` prüft fortlaufend den PIR-Sensor und aktualisiert die Anzeige beim Erkennen einer Bewegung.

4. **Interrupt Handling:**
   
   Bei einer Unterbrechung stellt das Skript sicher, dass alle GPIO-Pins sicher deaktiviert werden, um unerwartetes Verhalten zu vermeiden.



----------------------------------------------


**Troubleshooting**

1. **Anzeige funktioniert nicht**:

   - **Ursache**: Falsche Verdrahtung der 7-Segment-Anzeige oder des Schieberegisters.
   - **Lösung**:

     - Verbindungen zwischen GPIO und den Pins SDI, SRCLK und RCLK des 74HC595 prüfen.
     - Sicherstellen, dass alle ``placePin``-Leitungen den richtigen Stellen entsprechen.

2. **Bewegungssensor löst nicht aus**:

   - **Ursache**: PIR-Verdrahtung oder Umgebungsstörungen.
   - **Lösung**:

     - Anschlüsse des PIR-Sensors an GPIO **22**, Versorgung und Masse prüfen.
     - Empfindlichkeit und Verzögerung am PIR-Sensor (falls vorhanden) justieren.

3. **Zähler erhöht sich nicht**:

   - **Ursache**: Zustandswechsel des Sensors werden nicht erkannt.
   - **Lösung**:

     - Prüfen, ob ``pir.value()`` korrekt wechselt.
     - Debug-Ausgaben in ``loop()`` hinzufügen, um Zustandsänderungen zu verifizieren.

4. **Flackernde Anzeige**:

   - **Ursache**: Unzureichende Verzögerung bzw. Timing in der Anzeigeaktualisierung.
   - **Lösung**: Eine kurze Pause in ``display()`` einfügen, um die Anzeige zu stabilisieren:

       .. code-block:: python

           import time
           time.sleep(0.01)

**Extendable Ideas**

1. **Bidirektionaler Zähler**: Einen zweiten PIR-Sensor hinzufügen, um Bewegungen in Gegenrichtung zu erfassen und den Zähler zu verringern:

   .. code-block:: python

      pir2 = Pin(16, Pin.IN, pull= Pin.PULL_DOWN)
      if pir2.value()==1:
         counter -= 1

2. **Schwellwert-Benachrichtigungen**: Ab einem Grenzwert einen Alarm (z. B. LED oder Buzzer) auslösen:

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if counter > 50:
            buzzer.on()
      else:
            buzzer.off()

3. **Datenlogging**: Zählerstand und Zeitstempel in eine Datei schreiben:

   .. code-block:: python

      with open("motion_log.txt", "a") as log_file:
            log_file.write(f"{time.time():.3f}, Counter: {counter}\n")

4. **Zeitbasierter Reset**: Zähler nach einer definierten Inaktivitätsdauer zurücksetzen:

   .. code-block:: python

      last_motion_time = time.time()
      if time.time() - last_motion_time > 300:  # 5 minutes
            counter = 0

5. **Ereignisgesteuerte Aktionen**: Bestimmte Aktionen (z. B. Gerätesteuerung) auslösen, wenn definierte Zählerstände erreicht werden.
