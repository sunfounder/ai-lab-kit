1.2 RGB LED
=============

**介绍**

在这个项目中，我们将探索如何通过Raspberry Pi和GPIO编程来控制RGB LED显示各种颜色。RGB LED是多功能组件，通过混合不同强度的红、绿、蓝光来发出光谱中的各种颜色。

**电路图**

将RGB LED的R、G、B引脚连接到限流电阻后，再将这几个电阻分别连接到PWM0、PWM1和PWM2。LED最长的引脚（GND）连接到Raspberry Pi的GND引脚。三个引脚的不同PWM值可以产生各种颜色。

**代码**

以下Python代码通过为红、绿、蓝三色设置不同的PWM值，使RGB LED循环显示各种颜色：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import RGB_LED
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize an RGB LED. Connect the red component to P0, green to P1, and blue to P2.
   rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   try:
      # Set the RGB LED to red.
      rgb_led.color((255, 0, 0))
      sleep(1)

      # Set the RGB LED to green.
      rgb_led.color("#00FF22")
      sleep(1)

      # Set the RGB LED to purple.
      rgb_led.color(0xFF00FF)
      sleep(1)

      # Set the RGB LED to black.
      rgb_led.color(0x000000)

   except KeyboardInterrupt:
      # Handle a KeyboardInterrupt (Ctrl+C) to exit.
      rgb_led.color(0x000000)
      pass


此脚本演示了如何使用Fusion Hat库控制RGB LED。它使用特定的PWM引脚初始化RGB LED，并依次设置不同的颜色。


----------------------------------------------


**理解代码**


在连接了RGB LED的兼容设备上运行脚本。LED将循环显示红色、绿色和紫色，然后熄灭。


1. **导入依赖**

   .. code:: python

      from fusion_hat.modules import RGB_LED
      from fusion_hat.pwm import PWM
      from time import sleep

   导入所需模块。\ ``RGB_LED``\ 和\ ``PWM``\ 来自\ ``fusion_hat``\ 库，用于管理RGB LED；\ ``sleep``\ 用于定时。

2. **初始化RGB LED**

   .. code:: python

      rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   RGB LED被初始化，其红、绿、蓝三色分别连接到PWM引脚\ ``P0``\ 、\ ``P1``\ 和\ ``P2``\ 。该LED使用共阴极配置。

3. **顺序设置颜色**

   .. code:: python

      rgb_led.color((255, 0, 0))  # Red
      sleep(1)

      rgb_led.color("#00FF22")  # Green
      sleep(1)

      rgb_led.color(0xFF00FF)  # Purple
      sleep(1)

   脚本使用不同格式将RGB LED设置为不同颜色：

   - ``(255, 0, 0)``：表示红色的RGB元组。
   - ``"#00FF22"``：表示绿色的十六进制字符串。
   - ``0xFF00FF``：表示紫色的十六进制整数。

4. **关闭LED**

   .. code:: python

      rgb_led.color(0x000000)

   脚本将LED颜色设置为黑色（\ ``0x000000``\ ），即将其关闭。

5. **处理中断**

   .. code:: python

      except KeyboardInterrupt:
         rgb_led.color(0x000000)
         pass

   如果用户使用\ ``Ctrl+C``\ 中断脚本，则捕获异常，在退出前关闭LED。


----------------------------------------------


**故障排除**

1. **LED不亮**

   - **原因**：接线错误或GPIO引脚不匹配。
   - **解决方案**：确认RGB LED的红、绿、蓝引脚连接到正确的引脚，并且LED的共阴极或共阳极正确连接。


2. **颜色闪烁或不稳定**

   - **原因**：电源不稳定或电阻使用不当。
   - **解决方案**：使用合适的电阻并确保稳定的电源。

3. **GPIO设置错误**

   - **原因**：未安装Fusion_hat库。
   - **解决方案**：参见\ :ref:`install_fusion_hat`\ 。

        while True:

            r, g, b = map(int, user_color.split(","))
            rgb_led.color = (r, g, b)

   生成随机颜色，创建动态且不可预测的灯光显示：

   .. code-block:: python

      from random import randint
      while True:
         rgb_led.color = (randint(1,255) , randint(1,255) , randint(1,255) )
         sleep(1)
