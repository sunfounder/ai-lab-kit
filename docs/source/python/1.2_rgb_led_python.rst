1.2 LED RGB
================

**Introducción**

En este proyecto, exploraremos cómo controlar un LED RGB para mostrar varios colores utilizando una Raspberry Pi y programación GPIO. Los LED RGB son componentes versátiles que pueden emitir un espectro de colores mezclando luz roja, verde y azul a diferentes intensidades.

**Código**

El siguiente código Python recorre varios colores en el LED RGB estableciendo diferentes valores PWM para los componentes rojo, verde y azul:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import RGB_LED
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize an RGB LED. Connect the red component to P0, green to P1, and blue to P2.
   rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   try:
      # Set the RGB LED to red.
      rgb_led.color((255, 0, 0))
      sleep(1)

      # Set the RGB LED to green.
      rgb_led.color("#00FF22")
      sleep(1)

      # Set the RGB LED to purple.
      rgb_led.color(0xFF00FF)
      sleep(1)

      # Set the RGB LED to black.
      rgb_led.color(0x000000)

   except KeyboardInterrupt:
      # Handle a KeyboardInterrupt (Ctrl+C) to exit.
      rgb_led.color(0x000000)
      pass


Este script demuestra cómo controlar un LED RGB usando la librería Fusion Hat. Inicializa el LED RGB con pines PWM específicos y establece diferentes colores secuencialmente.


----------------------------------------------


**Comprender el Código**


Ejecuta el script en un dispositivo compatible con un LED RGB conectado. El LED recorrerá los colores rojo, verde y púrpura antes de apagarse.


1. **Importación de Dependencias**

   .. code:: python

      from fusion_hat.modules import RGB_LED
      from fusion_hat.pwm import PWM
      from time import sleep

   Los módulos requeridos se importan. ``RGB_LED`` y ``PWM`` de la librería ``fusion_hat`` gestionan el LED RGB, y ``sleep`` se usa para la temporización.

2. **Inicialización del LED RGB**

   .. code:: python

      rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   El LED RGB se inicializa con sus componentes rojo, verde y azul conectados a los pines PWM ``P0``, ``P1`` y ``P2``, respectivamente. El LED utiliza una configuración de cátodo común.

3. **Establecer Colores Secuencialmente**

   .. code:: python

      rgb_led.color((255, 0, 0))  # Red
      sleep(1)

      rgb_led.color("#00FF22")  # Green
      sleep(1)

      rgb_led.color(0xFF00FF)  # Purple
      sleep(1)

   El script establece el LED RGB a diferentes colores usando distintos formatos:

   - ``(255, 0, 0)``: Tupla que representa el rojo en RGB.
   - ``"#00FF22"``: Cadena hexadecimal que representa un color verdoso.
   - ``0xFF00FF``: Entero hexadecimal para el púrpura.

4. **Apagar el LED**

   .. code:: python

      rgb_led.color(0x000000)

   El script establece el color del LED a negro (``0x000000``), apagándolo efectivamente.

5. **Manejo de Interrupciones**

   .. code:: python

      except KeyboardInterrupt:
         rgb_led.color(0x000000)
         pass

   Si el usuario interrumpe el script usando ``Ctrl+C``, la excepción se captura y el LED se apaga antes de salir.


----------------------------------------------


**Solución de Problemas**

1. **El LED No se Enciende**

   - **Causa**: Cableado incorrecto o pin GPIO incorrecto.
   - **Solución**: Verifica que los pines rojo, verde y azul del LED RGB estén conectados a los pines correctos y que el cátodo o ánodo común del LED esté correctamente conectado.


2. **Colores Parpadeantes o Inestables**

   - **Causa**: Fuente de alimentación inestable o uso incorrecto de resistencias.
   - **Solución**: Utiliza resistencias adecuadas y asegura una fuente de alimentación estable.

3. **Configuración GPIO Incorrecta**

   - **Causa**: La librería Fusion_hat no está instalada.
   - **Solución**: Consulta :ref:`install_fusion_hat`.

**Ideas para Extender**

1. **Secuencias de Colores Personalizadas**

   Agrega más colores a la lista ``COLORS``, incluyendo variaciones más tenues, como ``(125, 50, 200)`` para un tono más suave.



2. **Colores Definidos por el Usuario**

   Permite al usuario introducir valores RGB personalizados:

   .. code-block:: python

        while True:
            user_color = input("Enter RGB values (e.g., 125,0,0): ")
            r, g, b = map(int, user_color.split(","))
            rgb_led.color = (r, g, b)



3. **Colores Aleatorios**

   Genera colores aleatorios para crear una exhibición de luces dinámica e impredecible:

   .. code-block:: python

      from random import randint
      while True:
         rgb_led.color = (randint(1,255) , randint(1,255) , randint(1,255) )
         sleep(1)
