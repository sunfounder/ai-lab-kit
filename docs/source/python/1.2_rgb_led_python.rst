1.2 LED RVB
================

**Introduction**

Dans ce projet, nous allons explorer comment controler une LED RVB pour afficher diverses couleurs en utilisant un Raspberry Pi et la programmation GPIO. Les LED RVB sont des composants polyvalents qui peuvent emettre un spectre de couleurs en melangeant la lumiere rouge, verte et bleue a differentes intensites.

**Schema de circuit**

Apres avoir connecte les broches R, G et B de la LED RVB a des resistances de limitation de courant, connectez ces resistances a PWM0, PWM1 et PWM2 respectivement. La broche la plus longue de la LED (GND) est connectee a la broche GND du Raspberry Pi. Differentes valeurs PWM pour les trois broches produisent diverses couleurs.

**Schema de cablage**

2. Connectez les broches rouge, verte et bleue de la LED a P0, P1 et P2 via des resistances.
3. Connectez la broche la plus longue (GND) de la LED au GND du Raspberry Pi.

**Code**

Le code Python suivant parcourt differentes couleurs sur la LED RVB en definissant differentes valeurs PWM pour les composants rouge, vert et bleu :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import RGB_LED
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize an RGB LED. Connect the red component to P0, green to P1, and blue to P2.
   rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   try:
      # Set the RGB LED to red.
      rgb_led.color((255, 0, 0))
      sleep(1)

      # Set the RGB LED to green.
      rgb_led.color("#00FF22")
      sleep(1)

      # Set the RGB LED to purple.
      rgb_led.color(0xFF00FF)
      sleep(1)

      # Set the RGB LED to black.
      rgb_led.color(0x000000)

   except KeyboardInterrupt:
      # Handle a KeyboardInterrupt (Ctrl+C) to exit.
      rgb_led.color(0x000000)
      pass


Ce script montre comment controler une LED RVB en utilisant la bibliotheque Fusion Hat. Il initialise la LED RVB avec des broches PWM specifiques et definit differentes couleurs de maniere sequentielle.


----------------------------------------------


**Comprendre le code**


Executez le script sur un appareil compatible avec une LED RVB connectee. La LED parcourra le rouge, le vert et le violet avant de s'eteindre.


1. **Importation des dependances**

   .. code:: python

      from fusion_hat.modules import RGB_LED
      from fusion_hat.pwm import PWM
      from time import sleep

   Les modules requis sont importes. ``RGB_LED`` et ``PWM`` de la bibliotheque ``fusion_hat`` gerent la LED RVB, et ``sleep`` est utilise pour le temporisation.

2. **Initialisation de la LED RVB**

   .. code:: python

      rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   La LED RVB est initialisee avec ses composants rouge, vert et bleu connectes aux broches PWM ``P0``, ``P1`` et ``P2`` respectivement. La LED utilise une configuration de cathode commune.

3. **Definition sequentielle des couleurs**

   .. code:: python

      rgb_led.color((255, 0, 0))  # Red
      sleep(1)

      rgb_led.color("#00FF22")  # Green
      sleep(1)

      rgb_led.color(0xFF00FF)  # Purple
      sleep(1)

   Le script definit la LED RVB a differentes couleurs en utilisant differents formats :

   - ``(255, 0, 0)`` : Tuple representant le rouge en RVB.
   - ``"#00FF22"`` : Chaine hexadecimale representant une couleur verdatre.
   - ``0xFF00FF`` : Entier hexadecimal pour le violet.

4. **Extinction de la LED**

   .. code:: python

      rgb_led.color(0x000000)

   Le script definit la couleur de la LED en noir (``0x000000``), l'eteignant ainsi efficacement.

5. **Gestion des interruptions**

   .. code:: python

      except KeyboardInterrupt:
         rgb_led.color(0x000000)
         pass

   Si l'utilisateur interrompt le script avec ``Ctrl+C``, l'exception est capturee et la LED est eteinte avant de quitter.


----------------------------------------------


**Depannage**

1. **La LED ne s'allume pas**

   - **Cause** : Cablage incorrect ou mauvaise correspondance des broches GPIO.
   - **Solution** : Verifiez que les broches rouge, verte et bleue de la LED RVB sont connectees aux bonnes broches et que la cathode ou l'anode commune de la LED est correctement connectee.


2. **Couleurs scintillantes ou instables**

   - **Cause** : Alimentation instable ou utilisation incorrecte des resistances.
   - **Solution** : Utilisez des resistances appropriees et assurez-vous d'avoir une source d'alimentation stable.

3. **Configuration GPIO incorrecte**

   - **Cause** : La bibliotheque Fusion_hat n'est pas installee.
   - **Solution** : Voir :ref:`install_fusion_hat`.

**Idees d'extension**

1. **Sequences de couleurs personnalisees**

   Ajoutez plus de couleurs a la liste ``COLORS``, y compris des variations plus sombres, comme ``(125, 50, 200)`` pour un ton plus doux.



2. **Couleurs definies par l'utilisateur**

   Permettez a l'utilisateur de saisir des valeurs RVB personnalisees :

   .. code-block:: python

        while True:
            user_color = input("Enter RGB values (e.g., 125,0,0): ")
            r, g, b = map(int, user_color.split(","))
            rgb_led.color = (r, g, b)



3. **Couleurs aleatoires**

   Generer des couleurs aleatoires pour creer un affichage lumineux dynamique et imprevisible :

   .. code-block:: python

      from random import randint
      while True:
         rgb_led.color = (randint(1,255) , randint(1,255) , randint(1,255) )
         sleep(1)
