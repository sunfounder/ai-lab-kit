1.2 LED RGB
====================

**Introduzione**

In questo progetto, esploreremo come controllare un LED RGB per visualizzare vari colori usando un Raspberry Pi e la programmazione GPIO. I LED RGB sono componenti versatili che possono emettere uno spettro di colori mescolando luce rossa, verde e blu a diverse intensità.

**Schema Elettrico**

Dopo aver collegato i pin R, G e B del LED RGB a resistori limitatori di corrente, collega questi resistori rispettivamente a PWM0, PWM1 e PWM2. Il pin più lungo del LED (GND) è collegato al pin GND del Raspberry Pi. Diversi valori PWM per i tre pin producono vari colori.

**Schema di Cablaggio**

Segui i passaggi qui sotto per costruire il circuito:

1. Posiziona il LED RGB sulla breadboard.
2. Collega i pin rosso, verde e blu del LED a P0, P1 e P2 tramite resistori.
3. Collega il pin più lungo (GND) del LED al GND del Raspberry Pi.

**Codice**

Il seguente codice Python cicla attraverso vari colori sul LED RGB impostando diversi valori PWM per i componenti rosso, verde e blu:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import RGB_LED
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize an RGB LED. Connect the red component to P0, green to P1, and blue to P2.
   rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   try:
      # Set the RGB LED to red.
      rgb_led.color((255, 0, 0))
      sleep(1)

      # Set the RGB LED to green.
      rgb_led.color("#00FF22")
      sleep(1)

      # Set the RGB LED to purple.
      rgb_led.color(0xFF00FF)
      sleep(1)

      # Set the RGB LED to black.
      rgb_led.color(0x000000)

   except KeyboardInterrupt:
      # Handle a KeyboardInterrupt (Ctrl+C) to exit.
      rgb_led.color(0x000000)
      pass


Questo script dimostra come controllare un LED RGB usando la libreria Fusion Hat. Inizializza il LED RGB con pin PWM specifici e imposta diversi colori in sequenza.


----------------------------------------------


**Comprendere il Codice**


Esegui lo script su un dispositivo compatibile con un LED RGB collegato. Il LED ciclerà attraverso rosso, verde e viola prima di spegnersi.


1. **Importazione delle Dipendenze**

   .. code:: python

      from fusion_hat.modules import RGB_LED
      from fusion_hat.pwm import PWM
      from time import sleep

   I moduli richiesti vengono importati. ``RGB_LED`` e ``PWM`` dalla libreria ``fusion_hat`` gestiscono il LED RGB, e ``sleep`` viene usato per la temporizzazione.

2. **Inizializzazione del LED RGB**

   .. code:: python

      rgb_led = RGB_LED(PWM(0), PWM(1), PWM(2), common=RGB_LED.CATHODE)

   Il LED RGB viene inizializzato con i suoi componenti rosso, verde e blu collegati rispettivamente ai pin PWM ``P0``, ``P1`` e ``P2``. Il LED utilizza una configurazione a catodo comune.

3. **Impostazione dei Colori in Sequenza**

   .. code:: python

      rgb_led.color((255, 0, 0))  # Red
      sleep(1)

      rgb_led.color("#00FF22")  # Green
      sleep(1)

      rgb_led.color(0xFF00FF)  # Purple
      sleep(1)

   Lo script imposta il LED RGB su diversi colori usando formati differenti:

   - ``(255, 0, 0)``: Tupla che rappresenta il rosso in RGB.
   - ``"#00FF22"``: Stringa esadecimale che rappresenta un colore verdastro.
   - ``0xFF00FF``: Intero esadecimale per il viola.

4. **Spegnimento del LED**

   .. code:: python

      rgb_led.color(0x000000)

   Lo script imposta il colore del LED a nero (``0x000000``), spegnendolo effettivamente.

5. **Gestione delle Interruzioni**

   .. code:: python

      except KeyboardInterrupt:
         rgb_led.color(0x000000)
         pass

   Se l'utente interrompe lo script usando ``Ctrl+C``, l'eccezione viene catturata e il LED viene spento prima di uscire.


----------------------------------------------


**Risoluzione dei Problemi**

1. **Il LED Non Si Accende**

   - **Causa**: Cablaggio errato o pin GPIO non corrispondente.
   - **Soluzione**: Verifica che i pin rosso, verde e blu del LED RGB siano collegati ai pin corretti e che il catodo o anodo comune del LED sia collegato correttamente.


2. **Colori Sfarfallanti o Instabili**

   - **Causa**: Alimentazione instabile o uso improprio dei resistori.
   - **Soluzione**: Usa resistori appropriati e assicura una fonte di alimentazione stabile.

3. **Configurazione GPIO Errata**

   - **Causa**: La libreria Fusion_hat non è installata.
   - **Soluzione**: Vedi :ref:`install_fusion_hat`.

**Idee Estendibili**

1. **Sequenze di Colori Personalizzate**

   Aggiungi più colori alla lista ``COLORS``, incluse variazioni più scure, come ``(125, 50, 200)`` per un tono più morbido.



2. **Colori Definiti dall'Utente**

   Permetti all'utente di inserire valori RGB personalizzati:

   .. code-block:: python

        while True:
            user_color = input("Enter RGB values (e.g., 125,0,0): ")
            r, g, b = map(int, user_color.split(","))
            rgb_led.color = (r, g, b)



3. **Colori Casuali**

   Genera colori casuali per creare uno spettacolo luminoso dinamico e imprevedibile:

   .. code-block:: python

      from random import randint
      while True:
         rgb_led.color = (randint(1,255) , randint(1,255) , randint(1,255) )
         sleep(1)
