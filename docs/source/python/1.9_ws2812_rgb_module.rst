1.9 NeoPixel LED灯带
=====================

**介绍**

在本项目中，我们将学习如何使用Raspberry Pi上的SPI通信控制可寻址RGB LED灯带（NeoPixel）。NeoPixel是智能RGB LED，内置驱动芯片，可以对链条中的每个LED进行独立控制。本项目演示了基本的颜色控制以及用不同颜色填充整个灯带。

**代码**

以下Python代码控制NeoPixel LED灯带，循环显示不同颜色：

.. raw:: html

   <run></run>

.. code-block:: python

   import time               # Used for delays
   import board              # Provides board-specific pin definitions
   import neopixel_spi as neopixel   # NeoPixel SPI driver

   # Create an SPI object using the default SPI bus of the board
   spi = board.SPI()

   LED_COUNT = 12  # Number of LED pixels in the strip
   PIXEL_ORDER = neopixel.GRB  # Color order used by the LEDs (Green, Red, Blue)

   # Create a NeoPixel strip object over SPI
   # auto_write=False means we must call strip.show() to update the LEDs
   strip = neopixel.NeoPixel_SPI(spi, LED_COUNT, pixel_order=PIXEL_ORDER, auto_write=False)

   time.sleep(0.01)   # Short delay to ensure the strip is ready

   strip.fill(0)      # Turn all pixels off (color value 0 = off)
   strip.show()       # Send the data to the LED strip

   try:
      while True:
         print("RGB test")

         # Display red on all LEDs
         print("Red")
         strip.fill((255, 0, 0))  # Full red, no green, no blue
         strip.show()
         time.sleep(1)

         # Display green on all LEDs
         print("Green")
         strip.fill((0, 255, 0))  # Full green
         strip.show()
         time.sleep(1)

         # Display blue on all LEDs
         print("Blue")
         strip.fill((0, 0, 255))  # Full blue
         strip.show()
         time.sleep(1)

         # Turn all LEDs off
         # print("Off for 10 seconds")
         strip.fill((0, 0, 0))    # All channels 0 = off
         strip.show()
         time.sleep(1)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

此Python脚本演示了使用NeoPixel SPI驱动程序控制12灯珠WS2812环形LED。执行时：

1. 脚本初始化SPI接口并准备WS2812 LED环形灯。
2. 所有LED以1秒间隔循环显示红、绿、蓝。
3. 每次颜色变化都会打印到控制台以供调试。
4. LED在每次循环之间短暂熄灭。
5. 程序持续循环，直到用\ ``Ctrl+C``\ 中断。

**理解代码**

1. **库导入**

   脚本使用\ ``neopixel_spi``\ 库通过Raspberry Pi的SPI接口控制WS2812 LED。

   .. code-block:: python

      import time
      import board
      import neopixel_spi as neopixel

2. **SPI和NeoPixel设置**

   SPI总线被初始化，NeoPixel环形灯配置为12个LED和所需的颜色顺序（GRB）。

   .. code-block:: python

       spi = board.SPI()
       LED_COUNT = 12
       PIXEL_ORDER = neopixel.GRB

       strip = neopixel.NeoPixel_SPI(
           spi,
           LED_COUNT,
           pixel_order=PIXEL_ORDER,
           auto_write=False
       )

3. **初始LED重置**

   短暂延迟确保LED就绪，然后关闭所有像素。

   .. code-block:: python

       time.sleep(0.01)
       strip.fill(0)
       strip.show()

4. **主颜色循环**

   在无限循环内，脚本依次用红色、绿色和蓝色填充LED环形灯。每种颜色显示一秒钟。

   .. code-block:: python

       while True:
           strip.fill((255, 0, 0))  # Red
           strip.show()
           time.sleep(1)
           # Similar code for green and blue...

5. **颜色格式**

   颜色使用RGB元组定义：\ ``(red, green, blue)``\ ，每个值为0–255之间。

   .. code-block:: python

       strip.fill((0, 255, 0))  # Example: green

故障排除
--------

* **LED环形灯不亮**

  - **原因：** 接线错误或供电不足
  - **解决方案：** 确保VCC为5V，GND共地，数据线连接到DIN（有时标记为RGB）

* **颜色不正确**

  - **原因：** LED颜色顺序不匹配
  - **解决方案：** 尝试不同的像素顺序，如\ ``neopixel.RGB``\ 或\ ``neopixel.GRBW``

* **SPI不工作**

  - **原因：** SPI被禁用或硬件冲突
  - **解决方案：** 通过\ ``sudo raspi-config``\ 启用SPI

* **库导入失败**

  - **原因：** 缺少依赖
  - **解决方案：**

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-neopixel-spi --break

扩展思路
--------

* 你可以用不同颜色点亮特定LED，以创建简单图案或突出环形灯上的特定位置。

  .. code-block:: python

      strip[0] = (255, 0, 0)
      strip.show()

* 通过循环计算RGB值，你可以在所有LED上生成平滑的彩虹过渡。

  .. code-block:: python

      strip.fill(wheel(50))
      strip.show()

* 一次点亮一个LED，同时保持其他LED熄灭，创建追逐效果。

  .. code-block:: python

      strip[i] = (0, 255, 0)
      strip.show()

* 你可以通过调整亮度属性来调暗或调亮整个LED环形灯。

  .. code-block:: python

      strip.brightness = 0.3

总结
----

本示例演示了如何使用Raspberry Pi上的SPI控制WS2812 12-LED环形灯。仅需几行代码，你就可以循环显示颜色、创建动画并探索单个LED控制。这使得WS2812环形灯非常适合用于指示灯、机器人、装饰效果和交互式视觉项目。
