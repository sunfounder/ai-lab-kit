1.9  Striscia LED NeoPixel
===========================

**Introduzione**

In questo progetto, impareremo come controllare una striscia LED RGB indirizzabile (NeoPixel) usando la comunicazione SPI su un Raspberry Pi. I NeoPixel sono LED RGB intelligenti che contengono i propri driver, permettendo il controllo individuale di ogni LED in una catena. Questo progetto dimostra il controllo base dei colori e il riempimento dell'intera striscia con diversi colori.

**Codice**

Il seguente codice Python controlla una striscia LED NeoPixel, ciclando attraverso diversi colori:

.. raw:: html

   <run></run>

.. code-block:: python

   import time               # Used for delays
   import board              # Provides board-specific pin definitions
   import neopixel_spi as neopixel   # NeoPixel SPI driver

   # Create an SPI object using the default SPI bus of the board
   spi = board.SPI()

   LED_COUNT = 12  # Number of LED pixels in the strip
   PIXEL_ORDER = neopixel.GRB  # Color order used by the LEDs (Green, Red, Blue)

   # Create a NeoPixel strip object over SPI
   # auto_write=False means we must call strip.show() to update the LEDs
   strip = neopixel.NeoPixel_SPI(spi, LED_COUNT, pixel_order=PIXEL_ORDER, auto_write=False)

   time.sleep(0.01)   # Short delay to ensure the strip is ready

   strip.fill(0)      # Turn all pixels off (color value 0 = off)
   strip.show()       # Send the data to the LED strip

   try:
      while True:
         print("RGB test")

         # Display red on all LEDs
         print("Red")
         strip.fill((255, 0, 0))  # Full red, no green, no blue
         strip.show()
         time.sleep(1)

         # Display green on all LEDs
         print("Green")
         strip.fill((0, 255, 0))  # Full green
         strip.show()
         time.sleep(1)

         # Display blue on all LEDs
         print("Blue")
         strip.fill((0, 0, 255))  # Full blue
         strip.show()
         time.sleep(1)

         # Turn all LEDs off
         # print("Off for 10 seconds")
         strip.fill((0, 0, 0))    # All channels 0 = off
         strip.show()
         time.sleep(1)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

Questo script Python dimostra il controllo base di un anello WS2812 a 12 LED usando il driver NeoPixel SPI. Quando eseguito:

1. Lo script inizializza l'interfaccia SPI e prepara l'anello LED WS2812.
2. Tutti i LED ciclano attraverso rosso, verde e blu con intervalli di 1 secondo.
3. Ogni cambiamento di colore viene stampato sulla console per il debug.
4. I LED si spengono brevemente tra i cicli.
5. Il programma viene eseguito in loop continuamente fino a quando non viene interrotto con Ctrl+C.

----------------------------------------------

**Comprendere il Codice**

1. **Importazione della Libreria**

   Lo script usa la libreria ``neopixel_spi`` per controllare i LED WS2812 attraverso l'interfaccia SPI del Raspberry Pi.

   .. code-block:: python

      import time
      import board
      import neopixel_spi as neopixel

2. **Configurazione SPI e NeoPixel**

   Il bus SPI viene inizializzato e l'anello NeoPixel viene configurato con 12 LED e l'ordine dei colori richiesto (GRB).

   .. code-block:: python

       spi = board.SPI()
       LED_COUNT = 12
       PIXEL_ORDER = neopixel.GRB

       strip = neopixel.NeoPixel_SPI(
           spi,
           LED_COUNT,
           pixel_order=PIXEL_ORDER,
           auto_write=False
       )

3. **Reset Iniziale dei LED**

   Un breve ritardo assicura che i LED siano pronti, poi tutti i pixel vengono spenti.

   .. code-block:: python

       time.sleep(0.01)
       strip.fill(0)
       strip.show()

4. **Ciclo Principale di Cambio Colore**

   All'interno del ciclo infinito, lo script riempie l'anello LED con rosso, verde e blu solidi in sequenza. Ogni cambiamento viene visualizzato per un secondo.

   .. code-block:: python

       while True:
           strip.fill((255, 0, 0))  # Red
           strip.show()
           time.sleep(1)
           # Similar code for green and blue...

**5. Formato Colore**

   I colori sono definiti usando una tupla RGB: ``(red, green, blue)`` con ogni valore tra 0-255.

   .. code-block:: python

       strip.fill((0, 255, 0))  # Example: green

Risoluzione dei Problemi
---------------

* **L'Anello LED Non si Illumina Correttamente**

  - **Causa:** Cablaggio errato o alimentazione insufficiente
  - **Soluzione:** Assicurati che VCC sia a 5V, GND sia condiviso e la linea dati sia collegata a DIN (a volte etichettato RGB)

* **Colori Errati**

  - **Causa:** Discrepanza nell'ordine dei colori dei LED
  - **Soluzione:** Prova diversi ordini di pixel come ``neopixel.RGB`` o ``neopixel.GRBW``

* **SPI Non Funziona**

  - **Causa:** SPI disabilitato o conflitto hardware
  - **Soluzione:** Abilita SPI tramite ``sudo raspi-config``

* **Importazione della Libreria Fallisce**

  - **Causa:** Dipendenza mancante
  - **Soluzione:**

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-neopixel-spi --break

Idee Estendibili
------------------

* Puoi accendere LED specifici con colori diversi per creare semplici schemi o evidenziare determinate posizioni sull'anello.

  .. code-block:: python

      strip[0] = (255, 0, 0)
      strip.show()

* Ciclando attraverso valori RGB calcolati, puoi generare una transizione arcobaleno uniforme su tutti i LED.

  .. code-block:: python

      strip.fill(wheel(50))
      strip.show()

* Crea un effetto di inseguimento accendendo un LED alla volta mentre gli altri rimangono spenti.

  .. code-block:: python

      strip[i] = (0, 255, 0)
      strip.show()

* Puoi attenuare o aumentare la luminosità dell'intero anello LED regolando l'attributo di luminosità.

  .. code-block:: python

      strip.brightness = 0.3
