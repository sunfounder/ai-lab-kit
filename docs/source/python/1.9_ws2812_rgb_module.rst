1.9 Bande de LED NeoPixel
==============================

**Introduction**

Dans ce projet, nous allons apprendre a controler une bande de LED RVB adressables (NeoPixel) en utilisant la communication SPI sur un Raspberry Pi. Les NeoPixels sont des LED RVB intelligentes qui contiennent leurs propres pilotes, permettant un controle individuel de chaque LED dans une chaine. Ce projet montre le controle de couleur de base et le remplissage de toute la bande avec differentes couleurs.

   Le terminal affiche le nom de la couleur actuelle pendant le deroulement du motif.

**Code**

Le code Python suivant controle une bande de LED NeoPixel, parcourant differentes couleurs :

.. raw:: html

   <run></run>

.. code-block:: python

   import time               # Used for delays
   import board              # Provides board-specific pin definitions
   import neopixel_spi as neopixel   # NeoPixel SPI driver

   # Create an SPI object using the default SPI bus of the board
   spi = board.SPI()

   LED_COUNT = 12  # Number of LED pixels in the strip
   PIXEL_ORDER = neopixel.GRB  # Color order used by the LEDs (Green, Red, Blue)

   # Create a NeoPixel strip object over SPI
   # auto_write=False means we must call strip.show() to update the LEDs
   strip = neopixel.NeoPixel_SPI(spi, LED_COUNT, pixel_order=PIXEL_ORDER, auto_write=False)

   time.sleep(0.01)   # Short delay to ensure the strip is ready

   strip.fill(0)      # Turn all pixels off (color value 0 = off)
   strip.show()       # Send the data to the LED strip

   try:
      while True:
         print("RGB test")

         # Display red on all LEDs
         print("Red")
         strip.fill((255, 0, 0))  # Full red, no green, no blue
         strip.show()
         time.sleep(1)

         # Display green on all LEDs
         print("Green")
         strip.fill((0, 255, 0))  # Full green
         strip.show()
         time.sleep(1)

         # Display blue on all LEDs
         print("Blue")
         strip.fill((0, 0, 255))  # Full blue
         strip.show()
         time.sleep(1)

         # Turn all LEDs off
         # print("Off for 10 seconds")
         strip.fill((0, 0, 0))    # All channels 0 = off
         strip.show()
         time.sleep(1)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

Ce script Python montre le controle de base d'un anneau WS2812 de 12 LED en utilisant le pilote NeoPixel SPI. Lors de l'execution :

1. Le script initialise l'interface SPI et prepare l'anneau de LED WS2812.
2. Toutes les LED parcourent le rouge, le vert et le bleu avec des intervalles d'1 seconde.
3. Chaque changement de couleur est affiche sur la console pour le debogage.
4. Les LED s'eteignent brievement entre les cycles.
5. Le programme boucle en continu jusqu'a ce qu'il soit interrompu avec Ctrl+C.

**Comprendre le code**

1. **Importation de la bibliotheque**

   Le script utilise la bibliotheque ``neopixel_spi`` pour controler les LED WS2812 via l'interface SPI du Raspberry Pi.

   .. code-block:: python

      import time
      import board
      import neopixel_spi as neopixel

2. **Configuration SPI et NeoPixel**

   Le bus SPI est initialise et l'anneau NeoPixel est configure avec 12 LED et l'ordre de couleurs requis (GRB).

   .. code-block:: python

       spi = board.SPI()
       LED_COUNT = 12
       PIXEL_ORDER = neopixel.GRB

       strip = neopixel.NeoPixel_SPI(
           spi,
           LED_COUNT,
           pixel_order=PIXEL_ORDER,
           auto_write=False
       )

3. **Reinitialisation initiale des LED**

   Une breve pause garantit que les LED sont prettes, puis tous les pixels sont eteints.

   .. code-block:: python

       time.sleep(0.01)
       strip.fill(0)
       strip.show()

4. **Boucle principale de changement de couleurs**

   Dans la boucle infinie, le script remplit l'anneau de LED avec du rouge, du vert et du bleu uni en sequence. Chaque changement est affiche pendant une seconde.

   .. code-block:: python

       while True:
           strip.fill((255, 0, 0))  # Red
           strip.show()
           time.sleep(1)
           # Similar code for green and blue...

**5. Format des couleurs**

   Les couleurs sont definies en utilisant un tuple RVB : ``(red, green, blue)`` avec chaque valeur entre 0 et 255.

   .. code-block:: python

       strip.fill((0, 255, 0))  # Example: green

Depannage
---------------

* **L'anneau de LED ne s'allume pas correctement**

  - **Cause :** Cablage incorrect ou alimentation insuffisante
  - **Solution :** Assurez-vous que VCC est en 5V, GND est partage, et la ligne de donnees est connectee a DIN (parfois etiquette RGB)

* **Couleurs incorrectes**

  - **Cause :** Inadequation de l'ordre des couleurs des LED
  - **Solution :** Essayez differents ordres de pixels comme ``neopixel.RGB`` ou ``neopixel.GRBW``

* **SPI ne fonctionne pas**

  - **Cause :** SPI desactive ou conflit materiel
  - **Solution :** Activez SPI via ``sudo raspi-config``

* **Echec de l'importation de la bibliotheque**

  - **Cause :** Dependance manquante
  - **Solution :**

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-neopixel-spi --break

Idees d'extension
------------------

* Vous pouvez allumer des LED specifiques avec differentes couleurs pour creer des motifs simples ou mettre en evidence certaines positions sur l'anneau.

  .. code-block:: python

      strip[0] = (255, 0, 0)
      strip.show()

* En parcourant des valeurs RVB calculees, vous pouvez generer une transition arc-en-ciel fluide sur toutes les LED.

  .. code-block:: python

      strip.fill(wheel(50))
      strip.show()

* Creez un effet de poursuite en allumant une LED a la fois tout en gardant les autres eteintes.

  .. code-block:: python

      strip[i] = (0, 255, 0)
      strip.show()

* Vous pouvez diminuer ou augmenter la luminosite de tout l'anneau de LED en ajustant l'attribut de luminosite.

  .. code-block:: python

      strip.brightness = 0.3

Conclusion
----------

Cet exemple montre comment controler un anneau de 12 LED WS2812 en utilisant SPI sur un Raspberry Pi. Cela rend les anneaux WS2812 ideaux pour les voyants lumineux, la robotique, les effets decoratifs et les projets visuels interactifs.
