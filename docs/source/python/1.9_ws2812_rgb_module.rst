1.9  NeoPixel LED Strip
===========================

**Introduction**

In this project, we will learn how to control an addressable RGB LED strip (NeoPixel) using SPI communication on a Raspberry Pi. NeoPixels are intelligent RGB LEDs that contain their own drivers, allowing individual control of each LED in a chain. This project demonstrates basic color control and filling the entire strip with different colors.

**Circuit Diagram**

The circuit connects the NeoPixel strip to the Raspberry Pi's SPI interface. The strip requires three connections: power (5V), ground, and data input. A level shifter may be needed for reliable data transmission, as NeoPixels typically require 5V logic levels while the Raspberry Pi uses 3.3V.

**Wiring Diagram**

Follow these steps to build the circuit:

1. Connect the 5V pin from Fusion HAT+ to VCC of NeoPixel strip
2. Connect the GND pin from Fusion HAT+ to GND of NeoPixel strip  
3. Connect the SPI (MO) from Fusion HAT+ to DATA IN of NeoPixel strip
4. For longer strips, use an external 5V power supply:

   - Connect external 5V to NeoPixel VCC
   - Connect external GND to both NeoPixel GND and Fusion HAT+ GND

**Writing the Code**

The following Python code controls a NeoPixel LED strip, cycling through different colors:

.. raw:: html

   <run></run>

.. code-block:: python

   # pip3 install adafruit-circuitpython-neopixel-spi

   import time
   import board
   import neopixel_spi as neopixel

   spi = board.SPI()
   LED_COUNT = 12  # Number of LED pixels.
   PIXEL_ORDER = neopixel.GRB

   strip = neopixel.NeoPixel_SPI(spi, LED_COUNT, pixel_order=PIXEL_ORDER, auto_write=False)
   time.sleep(0.01)
   strip.fill(0)
   strip.show()

   while True:
       print("RGB test")
       print("Red")
       strip.fill((255, 0, 0))
       strip.show()
       time.sleep(1)
       print("Green")
       strip.fill((0, 255, 0))
       strip.show()
       time.sleep(1)
       print("Blue")
       strip.fill((0, 0, 255))
       strip.show()
       time.sleep(1)
       #print("Off for 10 seconds")
       strip.fill((0, 0, 0))
       strip.show()
       time.sleep(1)

This Python script creates a color cycling demonstration on a NeoPixel LED strip. When executed:

1. The script initializes communication with the NeoPixel strip using SPI
2. It cycles through primary colors (Red, Green, Blue) with 1-second intervals
3. Each color change is announced in the console
4. The strip turns off briefly between cycles
5. The program runs continuously until interrupted with Ctrl+C

**Troubleshooting**

1. **LEDs Not Lighting or Flickering**

   - **Cause**: Insufficient power, incorrect wiring, or logic level mismatch.
   - **Solution**: Use external 5V power supply for longer strips, verify all connections, and consider using a level shifter for data line.

2. **Wrong Colors Displayed**

   - **Cause**: Incorrect pixel order configuration.
   - **Solution**: Change ``PIXEL_ORDER`` to ``neopixel.GRB``, ``neopixel.RGB``, or other orders depending on your LED model.

3. **SPI Communication Errors**

   - **Cause**: SPI not enabled or conflicts with other devices.
   - **Solution**: Enable SPI in Raspberry Pi configuration (``sudo raspi-config``) and ensure no other devices are using the SPI bus.

4. **Library Installation Issues**

   - **Cause**: Missing dependencies or permission issues.
   - **Solution**: Install required dependencies: ``sudo apt-get install python3-pip`` and run with sudo privileges.

**Extendable Ideas**

1. **Individual LED Control**

   Control each LED individually instead of filling the entire strip:

   .. code-block:: python

      # Set individual pixels to different colors
      strip[0] = (255, 0, 0)    # First LED red
      strip[1] = (0, 255, 0)    # Second LED green
      strip[2] = (0, 0, 255)    # Third LED blue
      strip.show()

2. **Color Wheel and Smooth Transitions**

   Create smooth color transitions using HSV to RGB conversion:

   .. code-block:: python

      def wheel(pos):
          # Input a value 0-255 to get a rainbow color
          if pos < 85:
              return (pos * 3, 255 - pos * 3, 0)
          elif pos < 170:
              pos -= 85
              return (255 - pos * 3, 0, pos * 3)
          else:
              pos -= 170
              return (0, pos * 3, 255 - pos * 3)

      for i in range(255):
          strip.fill(wheel(i))
          strip.show()
          time.sleep(0.05)

3. **Running Light Effect**

   Create chasing or running light patterns:

   .. code-block:: python

      while True:
          for i in range(LED_COUNT):
              strip.fill((0, 0, 0))  # Turn all off
              strip[i] = (0, 255, 0)  # Turn current LED green
              strip.show()
              time.sleep(0.1)

4. **Brightness Control**

   Adjust overall brightness of the strip:

   .. code-block:: python

      strip.brightness = 0.5  # Set to 50% brightness
      strip.fill((255, 0, 0))
      strip.show()
