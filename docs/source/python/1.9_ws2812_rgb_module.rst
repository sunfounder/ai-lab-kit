1.9 Tira de LED NeoPixel
================================

**Introducción**

En este proyecto, aprenderemos cómo controlar una tira de LED RGB direccionable (NeoPixel) usando comunicación SPI en una Raspberry Pi. Los NeoPixels son LED RGB inteligentes que contienen sus propios controladores, permitiendo el control individual de cada LED en una cadena. Este proyecto demuestra el control básico de color y el llenado de toda la tira con diferentes colores.

**Pasos de Configuración**

#. Antes de ejecutar el código, necesitas instalar la librería requerida:

   Esta librería proporciona las funciones necesarias para controlar los LED NeoPixel mediante comunicación SPI.

   .. raw:: html

      <run></run>

        sudo pip3 install adafruit-circuitpython-neopixel-spi --break

#. Todos los ejemplos de código utilizados en este tutorial están disponibles en el directorio ``ai-lab-kit``. Sigue estos pasos para ejecutar el ejemplo:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 1.9_NeoPixel.py

#. Cuando este script se ejecuta, el módulo de LED WS2812 recorre tres colores sólidos:

   * Todos los LED se vuelven **rojos** durante un segundo
   * Todos los LED se vuelven **verdes** durante un segundo
   * Todos los LED se vuelven **azules** durante un segundo

   Después de mostrar cada color, los LED se apagan brevemente antes de repetir el ciclo.
   La terminal imprime el nombre del color actual mientras se ejecuta el patrón.

**Código**

El siguiente código Python controla una tira de LED NeoPixel, recorriendo diferentes colores:

.. raw:: html

   <run></run>

.. code-block:: python

   import time               # Used for delays
   import board              # Provides board-specific pin definitions
   import neopixel_spi as neopixel   # NeoPixel SPI driver

   # Create an SPI object using the default SPI bus of the board
   spi = board.SPI()

   LED_COUNT = 12  # Number of LED pixels in the strip
   PIXEL_ORDER = neopixel.GRB  # Color order used by the LEDs (Green, Red, Blue)

   # Create a NeoPixel strip object over SPI
   # auto_write=False means we must call strip.show() to update the LEDs
   strip = neopixel.NeoPixel_SPI(spi, LED_COUNT, pixel_order=PIXEL_ORDER, auto_write=False)

   time.sleep(0.01)   # Short delay to ensure the strip is ready

   strip.fill(0)      # Turn all pixels off (color value 0 = off)
   strip.show()       # Send the data to the LED strip

   try:
      while True:
         print("RGB test")

         # Display red on all LEDs
         print("Red")
         strip.fill((255, 0, 0))  # Full red, no green, no blue
         strip.show()
         time.sleep(1)

         # Display green on all LEDs
         print("Green")
         strip.fill((0, 255, 0))  # Full green
         strip.show()
         time.sleep(1)

         # Display blue on all LEDs
         print("Blue")
         strip.fill((0, 0, 255))  # Full blue
         strip.show()
         time.sleep(1)

         # Turn all LEDs off
         # print("Off for 10 seconds")
         strip.fill((0, 0, 0))    # All channels 0 = off
         strip.show()
         time.sleep(1)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

Este script Python demuestra el control básico de un anillo de 12 LED WS2812 usando el controlador NeoPixel SPI. Cuando se ejecuta:

1. El script inicializa la interfaz SPI y prepara el anillo de LED WS2812.
2. Todos los LED recorren los colores rojo, verde y azul con intervalos de 1 segundo.
3. Cada cambio de color se imprime en la consola para fines de depuración.
4. Los LED se apagan brevemente entre ciclos.
5. El programa se ejecuta en bucle continuamente hasta que se interrumpe con Ctrl+C.

**Comprender el Código**

1. **Importación de Librerías**

   El script utiliza la librería ``neopixel_spi`` para controlar los LED WS2812 a través de la interfaz SPI de la Raspberry Pi.

   .. code-block:: python

      import time
      import board
      import neopixel_spi as neopixel

2. **Configuración SPI y NeoPixel**

   El bus SPI se inicializa y el anillo NeoPixel se configura con 12 LED y el orden de color requerido (GRB).

   .. code-block:: python

       spi = board.SPI()
       LED_COUNT = 12
       PIXEL_ORDER = neopixel.GRB

       strip = neopixel.NeoPixel_SPI(
           spi,
           LED_COUNT,
           pixel_order=PIXEL_ORDER,
           auto_write=False
       )

3. **Reinicio Inicial de los LED**

   Un breve retardo asegura que los LED estén listos, luego todos los píxeles se apagan.

   .. code-block:: python

       time.sleep(0.01)
       strip.fill(0)
       strip.show()

4. **Bucle Principal de Cambio de Color**

   Dentro del bucle infinito, el script llena el anillo de LED con rojo, verde y azul sólidos en secuencia. Cada cambio se muestra durante un segundo.

   .. code-block:: python

       while True:
           strip.fill((255, 0, 0))  # Red
           strip.show()
           time.sleep(1)
           # Similar code for green and blue...

**5. Formato de Color**

   Los colores se definen usando una tupla RGB: ``(red, green, blue)`` con cada valor entre 0 y 255.

   .. code-block:: python

       strip.fill((0, 255, 0))  # Example: green

Solución de Problemas
-----------------------

* **El Anillo de LED No se Ilumina Correctamente**

  - **Causa:** Cableado incorrecto o alimentación insuficiente
  - **Solución:** Asegúrate de que VCC sea 5V, GND esté compartido y la línea de datos esté conectada a DIN (a veces etiquetada como RGB)

* **Colores Incorrectos**

  - **Causa:** Desajuste en el orden de colores del LED
  - **Solución:** Prueba diferentes órdenes de píxeles como ``neopixel.RGB`` o ``neopixel.GRBW``

* **SPI No Funciona**

  - **Causa:** SPI deshabilitado o conflicto de hardware
  - **Solución:** Habilita SPI mediante ``sudo raspi-config``

* **Error al Importar la Librería**

  - **Causa:** Dependencia faltante
  - **Solución:**

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-neopixel-spi --break

Ideas para Extender
---------------------

* Puedes iluminar LED específicos con diferentes colores para crear patrones simples o resaltar ciertas posiciones en el anillo.

  .. code-block:: python

      strip[0] = (255, 0, 0)
      strip.show()

* Recorriendo valores RGB calculados, puedes generar una transición de arcoíris suave a través de todos los LED.

  .. code-block:: python

      strip.fill(wheel(50))
      strip.show()

* Crea un efecto de persecución iluminando un LED a la vez mientras mantienes los otros apagados.

  .. code-block:: python

      strip[i] = (0, 255, 0)
      strip.show()

* Puedes atenuar o brillar todo el anillo de LED ajustando el atributo de brillo.

  .. code-block:: python

      strip.brightness = 0.3

Conclusión
----------

Este ejemplo demuestra cómo controlar un anillo de 12 LED WS2812 usando SPI en una Raspberry Pi. Con solo unas pocas líneas de código, puedes recorrer colores, crear animaciones y explorar el control individual de LED. Esto hace que los anillos WS2812 sean ideales para luces indicadoras, robótica, efectos decorativos y proyectos visuales interactivos.
