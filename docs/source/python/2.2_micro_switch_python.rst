2.2 Micro Interrupteur
==========================

**Introduction**

Dans ce projet, nous allons explorer comment utiliser un micro interrupteur pour controler deux LED. Un micro interrupteur est un composant tres sensible qui necessite une compression minimale pour s'activer. Il est souvent utilise dans les systemes de securite pour empecher le fonctionnement de machines ou de portes dans des conditions dangereuses.

**Schema de circuit**

Le micro interrupteur est connecte a GPIO17, et deux LED sont connectees a GPIO22 et GPIO27. Lorsque le micro interrupteur est presse, la LED rouge s'allume ; lorsqu'il est relache, la LED jaune s'allume.


.. image:: img/fzz/2.1.2_sch.png
   :width: 80%
   :align: center


----------------------------------------------

**Schema de cablage**

Suivez ces etapes pour construire le circuit :

1. Connectez une borne du micro interrupteur a GPIO17 et l'autre a la masse (GND).
2. Connectez les anodes des deux LED a GPIO22 (jaune) et GPIO27 (rouge) via des resistances de limitation de courant.
3. Connectez les cathodes des deux LED a GND.

Ce script Python controle deux LED en fonction de l'etat d'un micro interrupteur connecte a un Raspberry Pi. Lors de l'execution :

1. **Micro interrupteur presse** :

   - LED1 (connectee a la broche GPIO 22) s'allume.
   - LED2 (connectee a la broche GPIO 27) s'eteint.

2. **Micro interrupteur relache** :

   - LED1 s'eteint.
   - LED2 s'allume.

3. Le programme verifie en continu l'etat du micro interrupteur toutes les 0,5 secondes et ajuste les LED en consequence.

4. Le script s'execute indefiniment jusqu'a ce qu'il soit interrompu en appuyant sur ``Ctrl+C``.

----------------------------------------------

**Code**

Le code Python suivant alterne entre deux LED en fonction de l'etat du micro interrupteur :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep function for delays

   # Initialize micro switch on GPIO pin 17
   micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously check the state of the micro switch and control LEDs accordingly
      while True:
         if micro_switch.value() == 1:  # If the micro switch is pressed
               led1.high()       # Turn on LED1
               led2.low()      # Turn off LED2
         else:  # If the micro switch is not pressed
               led1.low()      # Turn off LED1
               led2.high()       # Turn on LED2

         sleep(0.5)  # Pause for 0.5 seconds before checking the switch again

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Comprendre le code**

1. **Importation de la bibliotheque**

   La bibliotheque ``fusion_hat`` fournit un controle GPIO simple, et la bibliotheque ``time`` permet les pauses.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep function for delays

2. **Initialisation des composants**

   Le micro interrupteur est connecte a GPIO17 avec la pull-up desactivee, tandis que les LED sont connectees a GPIO22 et GPIO27.

   .. code-block:: python

      # Initialize micro switch on GPIO pin 17
      micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **Gestion de l'etat de l'interrupteur**

   Le programme verifie l'etat du micro interrupteur dans une boucle. Lorsqu'il est presse, LED1 s'allume et LED2 s'eteint. Lorsqu'il est relache, LED1 s'eteint et LED2 s'allume.

   .. code-block:: python

      while True:
         if micro_switch.value() == 1:
            led1.on()
            led2.off()
         else:
            led1.off()
            led2.on()
         sleep(0.5)

4. **Gestion des interruptions**

   Le bloc ``try-except`` garantit que le script se termine proprement lorsqu'il est interrompu avec Ctrl+C.

   .. code-block:: python

      except KeyboardInterrupt:
         pass


----------------------------------------------


**Depannage**

1. **Les LED ne repondent pas**

   - **Cause** : Cablage GPIO incorrect ou configuration de broche.
   - **Solution** : Assurez-vous que LED1 est connectee a la broche GPIO 22, LED2 a la broche GPIO 27, et que les deux LED ont des resistances appropriees. Verifiez la connexion du micro interrupteur a la broche GPIO 17.

2. **Micro interrupteur non detecte**

   - **Cause** : Le micro interrupteur peut ne pas etre configure correctement ou necessite une resistance pull-up/pull-down.
   - **Solution** : Confirmez que ``pull = Pin.PULL_UP`` correspond a la configuration de votre interrupteur. Si l'interrupteur necessite une pull-up, activez-la dans l'initialisation.

3. **Les LED scintillent ou se comportent de maniere erratique**

   - **Cause** : Problemes d'anti-rebond du bouton.
   - **Solution** : Ajoutez un anti-rebond logiciel en introduisant une breve pause apres la detection d'une pression :


   .. code-block:: python

      if micro_switch.value() == 1:
         sleep(0.05)  # Debounce delay

**Idees d'extension**

1. **Pause ajustable**

   Permettez a l'utilisateur de modifier la pause dynamiquement pour affiner la reactivite des LED :

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      while True:
         sleep(delay)



2. **Retour sonore**

   Ajoutez un buzzer pour fournir un signal sonore lorsque l'interrupteur est presse ou relache :

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if micro_switch.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
