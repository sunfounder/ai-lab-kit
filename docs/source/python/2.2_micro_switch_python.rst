2.2 Microinterruttore
=====================

**Introduzione**

In questo progetto, esploreremo come usare un microinterruttore per controllare due LED. Un microinterruttore è un componente altamente sensibile che richiede una compressione minima per attivarsi. Viene spesso utilizzato nei sistemi di sicurezza per impedire il funzionamento di macchinari o porte in condizioni non sicure.

**Schema Elettrico**

Il microinterruttore è collegato a GPIO17, e due LED sono collegati a GPIO22 e GPIO27. Quando il microinterruttore viene premuto, il LED rosso si accende; quando viene rilasciato, il LED giallo si accende.

   :width: 80%
   :align: center


----------------------------------------------

**Schema di Cablaggio**

Segui questi passaggi per costruire il circuito:

1. Collega un terminale del microinterruttore a GPIO17 e l'altro a massa (GND).
2. Collega gli anodi dei due LED a GPIO22 (giallo) e GPIO27 (rosso) tramite resistori limitatori di corrente.
3. Collega i catodi di entrambi i LED a GND.

Questo script Python controlla due LED in base allo stato di un microinterruttore collegato a un Raspberry Pi. Quando eseguito:

1. **Microinterruttore Premuto**:

   - LED1 (collegato al pin GPIO 22) si accende.
   - LED2 (collegato al pin GPIO 27) si spegne.

2. **Microinterruttore Rilasciato**:

   - LED1 si spegne.
   - LED2 si accende.

3. Il programma controlla continuamente lo stato del microinterruttore ogni 0,5 secondi e regola i LED di conseguenza.

4. Lo script viene eseguito indefinitamente fino a quando non viene interrotto premendo ``Ctrl+C``.

----------------------------------------------

**Codice**

Il seguente codice Python alterna tra due LED in base allo stato del microinterruttore:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep function for delays

   # Initialize micro switch on GPIO pin 17
   micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously check the state of the micro switch and control LEDs accordingly
      while True:
         if micro_switch.value() == 1:  # If the micro switch is pressed
               led1.high()       # Turn on LED1
               led2.low()      # Turn off LED2
         else:  # If the micro switch is not pressed
               led1.low()      # Turn off LED1
               led2.high()       # Turn on LED2

         sleep(0.5)  # Pause for 0.5 seconds before checking the switch again

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Comprendere il Codice**

1. **Importazione della Libreria**

   La libreria ``fusion_hat`` fornisce un semplice controllo GPIO, e la libreria ``time`` permette i ritardi.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep function for delays

2. **Inizializzazione dei Componenti**

   Il microinterruttore è collegato a GPIO17 con pull-down, mentre i LED sono collegati a GPIO22 e GPIO27.

   .. code-block:: python

      # Initialize micro switch on GPIO pin 17
      micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **Gestione dello Stato dell'Interruttore**

   Il programma controlla lo stato del microinterruttore in un ciclo. Quando premuto, LED1 si accende e LED2 si spegne. Quando rilasciato, LED1 si spegne e LED2 si accende.

   .. code-block:: python

      while True:
         if micro_switch.value() == 1:
            led1.on()
            led2.off()
         else:
            led1.off()
            led2.on()
         sleep(0.5)

4. **Gestione dell'Interruzione**

   Il blocco ``try-except`` assicura che lo script esca pulitamente quando interrotto usando Ctrl+C.

   .. code-block:: python

      except KeyboardInterrupt:
         pass


----------------------------------------------


**Risoluzione dei Problemi**

1. **I LED Non Rispondono**

   - **Causa**: Cablaggio GPIO errato o configurazione dei pin.
   - **Soluzione**: Assicurati che LED1 sia collegato al pin GPIO 22, LED2 al pin GPIO 27, ed entrambi i LED abbiano resistori appropriati. Verifica la connessione del microinterruttore al pin GPIO 17.

2. **Microinterruttore Non Rilevato**

   - **Causa**: Il microinterruttore potrebbe non essere configurato correttamente o necessita di un resistore pull-up/pull-down.
   - **Soluzione**: Conferma che ``pull = Pin.PULL_UP`` corrisponda alla configurazione del tuo interruttore. Se l'interruttore richiede un pull-up, abilitalo nell'inizializzazione.

3. **I LED Sfarfallano o si Comportano in Modo Irregolare**

   - **Causa**: Problemi di debounce del pulsante.
   - **Soluzione**: Aggiungi debounce software introducendo un breve ritardo dopo aver rilevato una pressione:

   .. code-block:: python

      if micro_switch.value() == 1:
         sleep(0.05)  # Debounce delay

**Idee Estendibili**

1. **Ritardo Regolabile**

   Permetti all'utente di cambiare il ritardo dinamicamente per ottimizzare la reattività dei LED:

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      while True:
         sleep(delay)



2. **Feedback Audio**

   Aggiungi un buzzer per fornire un segnale acustico quando l'interruttore viene premuto o rilasciato:

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if micro_switch.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
