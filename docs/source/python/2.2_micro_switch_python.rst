2.2 Microinterruptor
=====================

**Introducción**

En este proyecto, exploraremos cómo usar un Microinterruptor para controlar dos LEDs. Un Microinterruptor es un componente altamente sensible que requiere una compresión mínima para activarse. Se utiliza a menudo en sistemas de seguridad para evitar que maquinaria o puertas funcionen en condiciones inseguras.

**Diagrama de Conexiones**

Sigue estos pasos para construir el circuito:

1. Conecta un terminal del Microinterruptor a GPIO17 y el otro a tierra (GND).
2. Conecta los ánodos de los dos LEDs a GPIO22 (amarillo) y GPIO27 (rojo) mediante resistencias limitadoras de corriente.
3. Conecta los cátodos de ambos LEDs a GND.

Este script de Python controla dos LEDs según el estado de un microinterruptor conectado a una Raspberry Pi. Cuando se ejecuta:

1. **Microinterruptor Presionado**:

   - LED1 (conectado al pin GPIO 22) se enciende.
   - LED2 (conectado al pin GPIO 27) se apaga.

2. **Microinterruptor Liberado**:

   - LED1 se apaga.
   - LED2 se enciende.

3. El programa verifica continuamente el estado del microinterruptor cada 0.5 segundos y ajusta los LEDs en consecuencia.

4. El script se ejecuta indefinidamente hasta que se interrumpe presionando ``Ctrl+C``.

----------------------------------------------

**Código**

El siguiente código de Python alterna entre dos LEDs según el estado del Microinterruptor:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep function for delays

   # Initialize micro switch on GPIO pin 17
   micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously check the state of the micro switch and control LEDs accordingly
      while True:
         if micro_switch.value() == 1:  # If the micro switch is pressed
               led1.high()       # Turn on LED1
               led2.low()      # Turn off LED2
         else:  # If the micro switch is not pressed
               led1.low()      # Turn off LED1
               led2.high()       # Turn on LED2

         sleep(0.5)  # Pause for 0.5 seconds before checking the switch again

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Comprender el Código**

1. **Importación de Librerías**

   La librería ``fusion_hat`` proporciona un control GPIO simple, y la librería ``time`` permite retardos.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep function for delays

2. **Inicialización de Componentes**

   El Microinterruptor está conectado a GPIO17 con pull-up deshabilitado, mientras que los LEDs están conectados a GPIO22 y GPIO27.

   .. code-block:: python

      # Initialize micro switch on GPIO pin 17
      micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **Manejo del Estado del Interruptor**

   El programa verifica el estado del Microinterruptor en un bucle. Cuando está presionado, LED1 se enciende y LED2 se apaga. Cuando se suelta, LED1 se apaga y LED2 se enciende.

   .. code-block:: python

      while True:
         if micro_switch.value() == 1:
            led1.on()
            led2.off()
         else:
            led1.off()
            led2.on()
         sleep(0.5)

4. **Manejo de Interrupciones**

   El bloque ``try-except`` asegura que el script termine correctamente cuando se interrumpe usando Ctrl+C.

   .. code-block:: python

      except KeyboardInterrupt:
         pass


----------------------------------------------


**Solución de Problemas**

1. **Los LEDs No Responden**

   - **Causa**: Cableado GPIO incorrecto o configuración de pines.
   - **Solución**: Asegúrate de que LED1 esté conectado al pin GPIO 22, LED2 al pin GPIO 27, y ambos LEDs tengan resistencias adecuadas. Verifica la conexión del microinterruptor al pin GPIO 17.

2. **Microinterruptor No Detectado**

   - **Causa**: El microinterruptor puede no estar configurado correctamente o necesita una resistencia pull-up/pull-down.
   - **Solución**: Confirma que ``pull = Pin.PULL_UP`` coincida con la configuración de tu interruptor. Si el interruptor requiere pull-up, actívalo en la inicialización.

3. **Los LEDs Parpadean o se Comportan de Forma Errática**

   - **Causa**: Problemas de debounce del botón.
   - **Solución**: Añade debounce por software introduciendo un breve retardo después de detectar una presión:


   .. code-block:: python

      if micro_switch.value() == 1:
         sleep(0.05)  # Debounce delay



----------------------------------------------

**Ideas para Extender**

1. **Retardo Ajustable**

   Permite al usuario cambiar el retardo dinámicamente para ajustar la respuesta del LED:

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      while True:
         sleep(delay)



2. **Retroalimentación de Audio**

   Añade un zumbador para proporcionar una señal audible cuando se presiona o suelta el interruptor:

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if micro_switch.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
