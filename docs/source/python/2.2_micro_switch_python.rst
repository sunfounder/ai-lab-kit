2.2 微动开关
=============

**介绍**

在本项目中，我们将探索如何使用微动开关控制两个LED。微动开关是一种高度敏感的组件，只需极小的按压即可触发。它常用于安全系统，以防止机器或门在不安全条件下运行。

此Python脚本根据连接到Raspberry Pi的微动开关状态控制两个LED。执行时：

1. **微动开关按下**：

   - LED1（连接到GPIO 22引脚）点亮。
   - LED2（连接到GPIO 27引脚）熄灭。

2. **微动开关释放**：

   - LED1熄灭。
   - LED2点亮。

3. 程序每0.5秒持续检查微动开关的状态并相应调整LED。

4. 脚本无限运行，直到按下\ ``Ctrl+C``\ 中断。

**代码**

以下Python代码根据微动开关的状态在两个LED之间切换：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep function for delays

   # Initialize micro switch on GPIO pin 17
   micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously check the state of the micro switch and control LEDs accordingly
      while True:
         if micro_switch.value() == 1:  # If the micro switch is pressed
               led1.high()       # Turn on LED1
               led2.low()      # Turn off LED2
         else:  # If the micro switch is not pressed
               led1.low()      # Turn off LED1
               led2.high()       # Turn on LED2

         sleep(0.5)  # Pause for 0.5 seconds before checking the switch again

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass



----------------------------------------------

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库提供了简单的GPIO控制，\ ``time``\ 库用于实现延迟。

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep function for delays

2. **组件初始化**

   微动开关连接到GPIO17，禁用上拉电阻，而LED分别连接到GPIO22和GPIO27。

   .. code-block:: python

      # Initialize micro switch on GPIO pin 17
      micro_switch = Pin(17, mode=Mode.IN, pull=Pull.DOWN)
      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **开关状态处理**

   程序在循环中检查微动开关的状态。按下时，LED1亮、LED2灭。释放时，LED1灭、LED2亮。

   .. code-block:: python

      while True:
         if micro_switch.value() == 1:
            led1.on()
            led2.off()
         else:
            led1.off()
            led2.on()
         sleep(0.5)

4. **中断处理**

   ``try-except``\ 块确保脚本在使用\ ``Ctrl+C``\ 中断时能干净退出。

   .. code-block:: python

      except KeyboardInterrupt:
         pass


----------------------------------------------


**故障排除**

1. **LED无响应**

   - **原因**：GPIO接线或引脚配置不正确。
   - **解决方案**：确保LED1连接到GPIO 22引脚，LED2连接到GPIO 27引脚，且两个LED都使用了合适的电阻。确认微动开关连接到GPIO 17引脚。

2. **微动开关未被检测到**

   - **原因**：微动开关可能未正确配置，或需要上拉/下拉电阻。
   - **解决方案**：确认\ ``pull = Pin.PULL_UP``\ 与你的开关配置匹配。如果开关需要上拉，请在初始化中启用。

3. **LED闪烁或行为异常**

   - **原因**：按钮消抖问题。
   - **解决方案**：通过在检测到按下后引入短暂延迟来添加软件消抖：


   .. code-block:: python

      if micro_switch.value() == 1:
         sleep(0.05)  # Debounce delay

1. **可调延迟**

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      while True:

2. **声音反馈**

   添加蜂鸣器，在开关按下或释放时提供声音信号：

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if micro_switch.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
