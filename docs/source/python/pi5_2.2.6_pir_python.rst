2.2.6 PIR-Sensor
=================

**Einführung**

Der Passive-Infrarot-Sensor (PIR) ist ein Bewegungsmelder, der Infrarotstrahlung von Menschen und Tieren erkennt. In diesem Projekt nutzen wir den PIR-Sensor, um Bewegungen zu detektieren.

**Code schreiben**

Der folgende Python-Code wird in diesem Projekt verwendet:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin  
   from signal import pause  # Import pause function from signal module

   # Initialize a PIR Module object on GPIO pin 17
   pir = Pin(17, Pin.IN, pull= Pin.PULL_DOWN)

   def detect():
      if pir.value() == 1:  # Check if the PIR Module is triggered
         print("Detected Barrier!")
      else:
         print("No Barrier")

   try:
      pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
      pir.when_deactivated = detect  

      # Run an event loop that waits for button events and keeps the script running
      print("CTRL + C to exit")
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass



Dieses Python-Skript überwacht einen PIR-Bewegungssensor.  

1. **Bei Bewegung**: Gibt „Detected Barrier!“ in der Konsole aus.  

2. **Ohne Bewegung**: Gibt „No Barrier“ in der Konsole aus.  

3. Das Programm läuft endlos und wartet auf Bewegungsereignisse. Es kann mit Ctrl+C beendet werden.  

----------------------------------------------

**Code verstehen**

1. **Imports:**

   .. code-block:: python

      from fusion_hat import Pin  
      from signal import pause  # Import pause function from signal module

   Das Skript nutzt die Bibliothek ``fusion_hat`` zur Steuerung des PIR-Sensors sowie das Modul ``signal`` zur Programmunterbrechung.  


2. **Initialisierung:**

   .. code-block:: python

      pir = Pin(17, Pin.IN, pull= Pin.PULL_DOWN)

   Hier wird der PIR-Sensor an GPIO-Pin 17 mit aktiviertem Pull-Down-Widerstand initialisiert.  


3. **Hauptschleife:**

   .. code-block:: python

      def detect():
         if pir.value() == 1:  # Check if the PIR Module is triggered
            print("Detected Barrier!")
         else:
            print("No Barrier")

      try:
         pir.when_activated = detect  # Set up an interrupt to detect changes in the pir sensor state
         pir.when_deactivated = detect  

         # Run an event loop that waits for button events and keeps the script running
         print("CTRL + C to exit")
         pause()

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass


   * Erkennt kontinuierlich Bewegungen.  
   * Bei Bewegung wird „Detected Barrier!“ ausgegeben.  
   * Ohne Bewegung erscheint „No Barrier“.  


----------------------------------------------


**Fehlerbehebung**


1. **Keine Bewegung erkannt**:  

   - **Ursache**: Der PIR-Sensor ist falsch verdrahtet oder nicht korrekt konfiguriert.  
   - **Lösung**:  

     - Stelle sicher, dass der Sensor mit GPIO-Pin 17, Stromversorgung und Masse verbunden ist.  
     - Passe Empfindlichkeit und Verzögerung mit den Potentiometern des Sensors an.  

----------------------------------------------

**Erweiterbare Ideen**

1. **Akustisches Feedback**: Füge einen Buzzer hinzu, der bei Bewegungserkennung ein Signal ausgibt:  

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if pir.value() == 1:
         buzzer.on()
      else:
         buzzer.off()

2. **Datenaufzeichnung**: Protokolliere Bewegungsereignisse mit Zeitstempeln in einer Datei:  

   .. code-block:: python

      with open("motion_log.txt", "a") as log_file:
         log_file.write(f"Motion detected at {time.time():.3f}\n")

**Fazit**

Dieses Projekt zeigt, wie ein PIR-Sensor genutzt werden kann. Mit diesem Grundlagenwissen lassen sich erweiterte Anwendungen wie Sicherheitssysteme, automatische Beleuchtung oder interaktive Geräte realisieren. Die Vielseitigkeit und einfache Handhabung machen den PIR-Sensor zu einer ausgezeichneten Komponente für zahlreiche DIY- und professionelle Projekte.
