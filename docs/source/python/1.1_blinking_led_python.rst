1.1 LED Lampeggiante
====================

**Introduzione**

Benvenuto nel tuo primo progetto! In questo tutorial impareremo come far lampeggiare un LED utilizzando la programmazione Python e i pin GPIO. Questo progetto è un'eccellente introduzione all'integrazione hardware-software, dimostrando come codice semplice possa interagire con componenti del mondo reale.

Prima di iniziare, spieghiamo brevemente le basi:

* **Cos'è un LED?**

  Un LED (Light Emitting Diode) è un piccolo componente elettronico che si illumina quando una corrente elettrica lo attraversa. I LED sono ampiamente utilizzati in elettronica perché sono efficienti e durevoli.

* **Cos'è un pin GPIO?**

  GPIO sta per **General Purpose Input/Output** (Ingresso/Uscita per Scopi Generali). Questi pin permettono al Raspberry Pi di comunicare con dispositivi esterni, come LED, sensori o pulsanti. Ogni pin può essere programmato per inviare segnali (uscita) o leggere segnali (ingresso).

In questo tutorial, collegheremo un LED a un pin GPIO e scriveremo un programma Python per farlo lampeggiare. Iniziamo!

**Codice**

Ecco lo script Python completo per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   from time import sleep

   # Initialize an LED connected to GPIO pin 17 as an output pin.
   led = Pin(17,mode=Mode.OUT)

   try:
      # Start an infinite loop to toggle the LED state.
      while True:
         # Turn on the LED and print a message to the console.
         led.high()
         print('...LED ON')

         # Wait for 0.5 seconds with the LED on.
         sleep(0.5)

         # Turn off the LED and print a message to the console.
         led.low()
         print('LED OFF...')

         # Wait for 0.5 seconds with the LED off.
         sleep(1)

   except KeyboardInterrupt:
      # Gracefully handle a keyboard interrupt (Ctrl+C) by breaking the loop.
      pass


Questo script Python controlla un LED collegato al pin GPIO 17 di un Raspberry Pi. Quando eseguito, il LED alterna tra acceso e spento a intervalli di mezzo secondo. Contemporaneamente, la console stampa "LED is ON" e "LED is OFF" per indicare lo stato attuale del LED. Il programma viene eseguito indefinitamente fino a quando non viene interrotto dall'utente premendo ``Ctrl+C``.

**Comprendere il Codice**

1. **Importazioni:**

   La libreria ``fusion_hat`` semplifica il controllo dei dispositivi GPIO. La classe ``Pin`` permette di controllare un LED con metodi base come ``on()`` e ``off()``. La funzione ``sleep`` introduce ritardi tra i comandi.

   .. note:: Per l'utilizzo di fusion-hat, fare riferimento a |link_api_fusion_hat|.


2. **Inizializzazione:**

   La riga ``led = Pin(17,mode=Mode.OUT)`` dice al Raspberry Pi che un LED è collegato al pin GPIO 17.

3. **Ciclo Principale:**

   All'interno del ciclo ``while True``: Il LED si accende (``led.on()``) e si spegne (``led.off()``) con una pausa di 0,5 secondi (``sleep(0.5)``) intermedia.

4. **Uscita Controllata:**

   Il blocco ``try...except`` assicura che il programma si arresti in modo pulito quando viene interrotto (ad esempio, premendo ``Ctrl+C``).



----------------------------------------------


**Risoluzione dei Problemi**

1. **Il LED Non Si Accende**

   - **Causa**: Pin GPIO errato o cablaggio difettoso.
   - **Soluzione**: Ricontrolla il collegamento del LED al pin GPIO 17 e verifica che il resistore sia posizionato correttamente per evitare danni al LED.


2. **KeyboardInterrupt Non Funziona**

   - **Causa**: Il programma non esce correttamente.
   - **Soluzione**: Assicurati che lo script sia eseguito in un terminale dove ``Ctrl+C`` viene catturato, non come processo in background.

3. **Configurazione GPIO Errata**

   - **Causa**: La libreria ``fusion_hat`` non è installata.
   - **Soluzione**: Vedi :ref:`install_fusion_hat`.

4. **Il LED Sfarfalla o si Comporta in Modo Irregolare**

   - **Causa**: Alimentazione instabile o connessioni scarse.
   - **Soluzione**: Assicura una fonte di alimentazione stabile e un cablaggio sicuro.
