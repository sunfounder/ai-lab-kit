1.1 LED Parpadeante
======================

**Introducción**

Bienvenido a tu primer proyecto. En este tutorial, aprenderemos a hacer parpadear un LED utilizando programación Python y los pines GPIO. Este proyecto es una excelente introducción a la integración de hardware y software, demostrando cómo un código simple puede interactuar con componentes del mundo real.

Antes de comenzar, expliquemos brevemente los conceptos básicos:

* **¿Qué es un LED?**

  Un LED (diodo emisor de luz) es un pequeño componente electrónico que se ilumina cuando una corriente eléctrica fluye a través de él. Los LED se utilizan ampliamente en electrónica porque son eficientes y duraderos.

* **¿Qué es un pin GPIO?**

  GPIO significa **General Purpose Input/Output** (Entrada/Salida de Propósito General). Estos pines permiten que la Raspberry Pi se comunique con dispositivos externos, como LED, sensores o botones. Cada pin puede programarse para enviar señales (salida) o leer señales (entrada).

En este tutorial, conectaremos un LED a un pin GPIO y escribiremos un programa en Python para hacerlo parpadear. ¡Comencemos!

**Código**

Aquí está el script Python completo para este proyecto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   from time import sleep

   # Initialize an LED connected to GPIO pin 17 as an output pin.
   led = Pin(17,mode=Mode.OUT)

   try:
      # Start an infinite loop to toggle the LED state.
      while True:
         # Turn on the LED and print a message to the console.
         led.high()
         print('...LED ON')

         # Wait for 0.5 seconds with the LED on.
         sleep(0.5)

         # Turn off the LED and print a message to the console.
         led.low()
         print('LED OFF...')

         # Wait for 0.5 seconds with the LED off.
         sleep(1)

   except KeyboardInterrupt:
      # Gracefully handle a keyboard interrupt (Ctrl+C) by breaking the loop.
      pass


Este script Python controla un LED conectado al pin GPIO 17 de una Raspberry Pi. Cuando se ejecuta, el LED alterna entre encenderse y apagarse en intervalos de medio segundo. Simultáneamente, la consola imprime "LED is ON" y "LED is OFF" para indicar el estado actual del LED. El programa se ejecuta indefinidamente hasta que el usuario lo interrumpe presionando ``Ctrl+C``.

**Comprender el Código**

1. **Importaciones:**

   La librería ``fusion_hat`` simplifica el control de dispositivos GPIO. La clase ``Pin`` te permite controlar un LED con métodos básicos como ``on()`` y ``off()``. La función ``sleep`` introduce retrasos entre comandos.

   .. note:: Para el uso de fusion-hat, consulta |link_api_fusion_hat|.


2. **Inicialización:**

   La línea ``led = Pin(17,mode=Mode.OUT)`` le indica a la Raspberry Pi que hay un LED conectado al pin GPIO 17.

3. **Bucle Principal:**

   Dentro del bucle ``while True``: El LED se enciende (``led.on()``) y se apaga (``led.off()``) con una pausa de 0.5 segundos (``sleep(0.5)``) entre cada acción.

4. **Salida Controlada:**

   El bloque ``try...except`` asegura que el programa se detenga de forma limpia cuando sea interrumpido (por ejemplo, presionando ``Ctrl+C``).



----------------------------------------------


**Solución de Problemas**

1. **El LED No se Enciende**

   - **Causa**: Pin GPIO incorrecto o cableado defectuoso.
   - **Solución**: Verifica la conexión del LED al pin GPIO 17 y asegúrate de que la resistencia esté colocada correctamente para evitar daños al LED.


2. **KeyboardInterrupt No Funciona**

   - **Causa**: El programa no sale de forma controlada.
   - **Solución**: Asegúrate de que el script se ejecute en una terminal donde se capture ``Ctrl+C``, no como un proceso en segundo plano.

3. **Configuración GPIO Incorrecta**

   - **Causa**: La librería ``fusion_hat`` no está instalada.
   - **Solución**: Consulta :ref:`install_fusion_hat`.

4. **El LED Parpadea o se Comporta de Forma Errática**

   - **Causa**: Fuente de alimentación inestable o conexiones deficientes.
   - **Solución**: Asegura una fuente de alimentación estable y un cableado seguro.
