1.1 LED Clignotante
======================

**Introduction**

Bienvenue dans votre premier projet ! Dans ce tutoriel, nous allons apprendre a faire clignoter une LED en utilisant la programmation Python et les broches GPIO. Ce projet est une excellente introduction a l'integration materiel-logiciel, demontrant comment un code simple peut interagir avec des composants du monde reel.

Avant de commencer, expliquons brievement les bases :

* **Qu'est-ce qu'une LED ?**

  Une LED (Diode Electroluminescente) est un petit composant electronique qui s'allume lorsqu'un courant electrique le traverse. Les LED sont largement utilisees en electronique car elles sont efficaces et durables.

* **Qu'est-ce qu'une broche GPIO ?**

  GPIO signifie **General Purpose Input/Output** (Entree/Sortie a usage general). Ces broches permettent au Raspberry Pi de communiquer avec des dispositifs externes, tels que des LED, des capteurs ou des boutons. Chaque broche peut etre programmee pour envoyer des signaux (sortie) ou lire des signaux (entree).

Dans ce tutoriel, nous allons connecter une LED a une broche GPIO et ecrire un programme Python pour la faire clignoter. Commencons !

**Code**

Voici le script Python complet pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   from time import sleep

   # Initialize an LED connected to GPIO pin 17 as an output pin.
   led = Pin(17,mode=Mode.OUT)

   try:
      # Start an infinite loop to toggle the LED state.
      while True:
         # Turn on the LED and print a message to the console.
         led.high()
         print('...LED ON')

         # Wait for 0.5 seconds with the LED on.
         sleep(0.5)

         # Turn off the LED and print a message to the console.
         led.low()
         print('LED OFF...')

         # Wait for 0.5 seconds with the LED off.
         sleep(1)

   except KeyboardInterrupt:
      # Gracefully handle a keyboard interrupt (Ctrl+C) by breaking the loop.
      pass


Ce script Python controle une LED connectee a la broche GPIO 17 d'un Raspberry Pi. Lors de l'execution, la LED alterne entre allumee et eteinte a intervalles d'une demi-seconde. Simultanement, la console affiche "LED is ON" et "LED is OFF" pour indiquer l'etat actuel de la LED. Le programme s'execute indefiniment jusqu'a ce qu'il soit interrompu par l'utilisateur en appuyant sur ``Ctrl+C``.



----------------------------------------------

**Comprendre le code**

1. **Importations :**

   La bibliotheque ``fusion_hat`` simplifie le controle des peripheriques GPIO. La classe ``Pin`` vous permet de controler une LED avec des methodes de base comme ``on()`` et ``off()``. La fonction ``sleep`` introduit des pauses entre les commandes.

   .. note:: Pour l'utilisation de fusion-hat, veuillez vous referer a la |link_api_fusion_hat|.


2. **Initialisation :**

   La ligne ``led = Pin(17,mode=Mode.OUT)`` indique au Raspberry Pi qu'une LED est connectee a la broche GPIO 17.

3. **Boucle principale :**

   Dans la boucle ``while True`` : la LED s'allume (``led.on()``) et s'eteint (``led.off()``) avec une pause de 0,5 seconde (``sleep(0.5)``) entre chaque.

4. **Arret propre :**

   Le bloc ``try...except`` garantit que le programme s'arrete proprement lorsqu'il est interrompu (par exemple, en appuyant sur ``Ctrl+C``).



----------------------------------------------


**Depannage**

1. **La LED ne s'allume pas**

   - **Cause** : Broche GPIO incorrecte ou cablage defectueux.
   - **Solution** : Verifiez la connexion de la LED a la broche GPIO 17 et assurez-vous que la resistance est correctement placee pour eviter d'endommager la LED.


2. **KeyboardInterrupt ne fonctionne pas**

   - **Cause** : Le programme ne se termine pas correctement.
   - **Solution** : Assurez-vous que le script s'execute dans un terminal ou ``Ctrl+C`` est capture, et non en tant que processus en arriere-plan.

3. **Configuration GPIO incorrecte**

   - **Cause** : La bibliotheque ``fusion_hat`` n'est pas installee.
   - **Solution** : Voir :ref:`install_fusion_hat`.

4. **La LED scintille ou se comporte de maniere erratique**

   - **Cause** : Alimentation instable ou mauvaises connexions.
   - **Solution** : Assurez-vous d'avoir une source d'alimentation stable et un cablage securise.
