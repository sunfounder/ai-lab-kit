1.1 闪烁LED
============

**介绍**

欢迎来到你的第一个项目！在本教程中，我们将学习如何使用Python编程和GPIO引脚让LED闪烁。这个项目是硬件与软件集成的一个极好入门，展示了简单的代码如何与现实世界的组件进行交互。

在开始之前，让我们简要介绍一下基础知识：

* **什么是LED？**

  LED（发光二极管）是一种在电流通过时会发光的微型电子元件。LED因其高效和长寿命而被广泛应用于电子产品中。

* **什么是GPIO引脚？**

  GPIO代表**通用输入输出**。这些引脚允许Raspberry Pi与外部设备（如LED、传感器或按钮）进行通信。每个引脚都可以编程发送信号（输出）或读取信号（输入）。

在本教程中，我们将把LED连接到GPIO引脚，并编写一个Python程序使其闪烁。让我们开始吧！

**代码**

以下是本项目的完整Python脚本：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   from time import sleep

   # Initialize an LED connected to GPIO pin 17 as an output pin.
   led = Pin(17,mode=Mode.OUT)

   try:
      # Start an infinite loop to toggle the LED state.
      while True:
         # Turn on the LED and print a message to the console.
         led.high()
         print('...LED ON')

         # Wait for 0.5 seconds with the LED on.
         sleep(0.5)

         # Turn off the LED and print a message to the console.
         led.low()
         print('LED OFF...')

         # Wait for 0.5 seconds with the LED off.
         sleep(1)

   except KeyboardInterrupt:
      # Gracefully handle a keyboard interrupt (Ctrl+C) by breaking the loop.
      pass


此Python脚本控制连接到Raspberry Pi的GPIO 17引脚的LED。执行后，LED将以0.5秒的间隔交替亮灭。同时，控制台打印"LED is ON"和"LED is OFF"来指示LED的当前状态。程序将无限运行，直到用户按下\ ``Ctrl+C``\ 中断。

**理解代码**

1. **导入：**

   ``fusion_hat``\ 库简化了GPIO设备的控制。\ ``Pin``\ 类允许你使用基本的\ ``on()``\ 和\ ``off()``\ 方法来控制LED。\ ``sleep``\ 函数用于在命令之间引入延迟。

   .. note:: 关于fusion-hat的使用，请参考\ |link_api_fusion_hat|\ 。


2. **初始化：**

   代码行\ ``led = Pin(17,mode=Mode.OUT)``\ 告诉Raspberry Pi有一个LED连接到GPIO 17引脚。

3. **主循环：**

   在\ ``while True``\ 循环内部：LED以0.5秒的暂停（\ ``sleep(0.5)``\ ）间隔亮起（\ ``led.on()``\ ）和熄灭（\ ``led.off()``\ ）。

4. **优雅退出：**

   ``try...except``\ 块确保程序在被中断时（例如按下\ ``Ctrl+C``\ ）能干净地停止。



----------------------------------------------


**故障排除**

1. **LED不亮**

   - **原因**：GPIO引脚错误或接线故障。
   - **解决方案**：仔细检查LED到GPIO 17引脚的连接，并确保电阻正确放置以防止损坏LED。


2. **KeyboardInterrupt不起作用**

   - **原因**：程序未正常退出。
   - **解决方案**：确保脚本在能捕获\ ``Ctrl+C``\ 的终端中运行，而不是作为后台进程运行。

3. **GPIO设置错误**

   - **原因**：未安装\ ``fusion_hat``\ 库。
   - **解决方案**：参见\ :ref:`install_fusion_hat`\ 。

4. **LED闪烁或行为异常**

   - **原因**：电源不稳定或连接不良。
   - **解决方案**：确保稳定的电源和牢固的接线。
