4.10 色调旋钮
==============

**简介**

在本课程中，您将构建一个**色调旋钮** —— 一个使用旋转编码器来调节圆形 WS2812 LED 模块色调的交互式颜色控制器。
此 WS2812 LED 模块包含 12 个独立可寻址的 WS2812 RGB LED，通过 Fusion HAT+ 的基于 SPI 的 NeoPixel 接口驱动。
外部旋转编码器通过标准 GPIO 引脚提供实时用户输入。

旋转编码器时，12 个 LED 平滑地循环显示完整的 RGB 色彩光谱。
按下编码器的内置按钮可将色调重置回起始值。

   * LED 从红色开始（色调 0°）。
   * 旋转编码器平滑地循环显示完整的 RGB 色轮。颜色连续过渡（红 → 黄 → 绿 → 蓝 → 紫 → 红）。终端打印当前的色调和 RGB 值。

   * 按 Ctrl+C 退出。所有 LED 在程序关闭前熄灭。

**代码**

以下是交通灯模拟的 Python 脚本：

.. raw:: html

   <run></run>

.. code-block:: python


   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   currentTemp = None
   markTemp = None

   PRINT_INTERVAL = 1.0
   _last_print = 0.0

   button_event = False  # flag: button was pressed

   def temperature(samples=5, delay=0.01):
      """Read thermistor multiple times and return averaged Celsius (float) or None."""
      vals = []
      for _ in range(samples):
         analogVal = thermistor.read()
         Vr = 3.3 * float(analogVal) / 4095.0
         if (3.3 - Vr) <= 0.1:
               return None
         Rt = 10000.0 * Vr / (3.3 - Vr)
         tempK = 1.0 / (((math.log(Rt / 10000.0)) / 3950.0) + (1.0 / (273.15 + 25.0)))
         vals.append(tempK - 273.15)
         sleep(delay)
      return sum(vals) / len(vals)

   def motor_run(lv):
      lv = max(0, min(4, lv))
      motor.power(0 if lv == 0 else lv * 25)
      return lv

   def changeLevel():
      """Button press: cycle level 0~4 and set a flag for main loop to print."""
      global level, button_event
      level = (level + 1) % 5
      button_event = True

   BtnPin.when_activated = changeLevel

   def main():
      global level, currentTemp, markTemp, _last_print, button_event

      markTemp = temperature()
      while True:
         currentTemp = temperature()
         if currentTemp is None:
               print("Sensor read failed. Please check the sensor.")
               sleep(0.5)
               continue

         # Handle button event in main loop (stable timing)
         if button_event:
               button_event = False
               markTemp = currentTemp
               print(f"[Button] Level -> {level} | Temp: {currentTemp:.2f} °C | Mark: {markTemp:.2f} °C")

         # Periodic temperature print
         now = time()
         if now - _last_print >= PRINT_INTERVAL:
               if markTemp is None:
                  markTemp = currentTemp
               print(f"Temp: {currentTemp:.2f} °C | Mark: {markTemp:.2f} °C | Level: {level}")
               _last_print = now

         # Auto adjust level based on ±5°C
         if markTemp is None:
               markTemp = currentTemp

         if level != 0:
               diff = currentTemp - markTemp
               if diff <= -5:
                  level = max(0, level - 1)
                  markTemp = currentTemp
                  print(f"[Auto] Temp down -> Level {level} (Temp: {currentTemp:.2f} °C)")
               elif diff >= 5:
                  level = min(4, level + 1)
                  markTemp = currentTemp
                  print(f"[Auto] Temp up   -> Level {level} (Temp: {currentTemp:.2f} °C)")

         level = motor_run(level)
         sleep(0.5)

   try:
      main()
   except KeyboardInterrupt:
      print("\nExiting...")
   finally:
      motor.stop()
      sleep(0.1)

**理解代码**

1. **NeoPixel 初始化**

   - 脚本使用 SPI 控制 NeoPixel LED 环/条（``LED_COUNT = 12``）。
   - 启用 ``auto_write=False``，使得仅在调用 ``strip.show()`` 时更新 LED，这可以防止闪烁并提高性能。
   - LED 在启动时使用 ``strip.fill(0)`` 和 ``strip.show()`` 清除。

2. **旋转编码器硬件设置**

   - 使用三个 GPIO 引脚：
     - ``CLK_PIN`` 和 ``DT_PIN`` 提供用于旋转方向和步数的正交信号。
     - ``SW_PIN`` 是编码器按钮输入。
   - 所有引脚使用内部上拉电阻（``Pull.UP``），按钮为**低电平有效**（按下 = ``0``）。

3. **关键参数（调节行为）**

   - ``DETENTS_PER_CYCLE`` 定义完成一次完整的色调旋转（0-360°）需要多少个物理"咔嗒"。
     - 值越大，颜色控制越精细。
   - ``TRANSITIONS_PER_DETENT`` 将原始正交转换转换为"一个定位点 = 一个计数"。
     - 许多编码器每个定位点输出 2 次转换，但有些产生 4 次。调整此值可提高精度。

4. ``hue_to_rgb()``

   - 将范围 ``0.0 ~ 1.0`` 内的色调值转换为 RGB 元组 ``(R, G, B)``，数值范围为 ``0 ~ 255``。
   - 这使得使用 HSV 颜色模型生成平滑的颜色变化变得容易。

5. ``apply_color_from_detent()``

   - 使用取模将编码器定位点计数映射到色调索引：
     - ``hue_idx = detent % DETENTS_PER_CYCLE``
   - 将色调转换为 RGB 颜色，并使用 ``strip.fill(color)`` 后跟 ``strip.show()`` 更新所有 LED。
   - 使用 ``last_hue_idx`` 避免在计算的色调未变化时刷新 LED，从而减少不必要的更新。
   - 打印当前色调角度、定位点值和 RGB 颜色，用于调试/反馈。

6. ``reset_all()``

   - 重置内部计数器状态：
     - ``raw``\ （原始转换计数）
     - ``last_detent``\ （最后显示的定位点）
     - ``last_hue_idx``\ （最后显示的色调索引）
   - 调用 ``apply_color_from_detent(0)`` 立即将 LED 恢复为起始颜色（色调 = 0°）。

7. **主循环（轮询 + 方向检测）**

   - 程序持续轮询 ``CLK`` 并检查变化：
     - 如果 ``CLK`` 发生变化，表示编码器在正交序列中移动了一步。
   - 通过比较 DT 与 CLK 确定方向：
     - ``dt.value() != c`` 表示一个旋转方向（递增）
     - 否则递减
   - 原始转换计数转换为定位点：
     - ``detent = raw // TRANSITIONS_PER_DETENT``
   - 仅在定位点值变化时更新 LED 颜色。

8. **按钮重置和去抖动**

   - 按下按钮时（``sw.value() == 0``），程序调用 ``reset_all()``。
   - 应用短去抖动延时，脚本等待按钮松开以防止单次按下多次重置。

9. **安全退出**

   - 按 ``Ctrl + C`` 退出程序。
   - 在 ``finally`` 块中，所有 LED 关闭（``strip.fill(0)`` 和 ``strip.show()``），使硬件保持在安全状态。

**故障排除**
-------------------

- **LED 不亮**

  - 检查 WS2812 LED 模块的接线。
  - 确保 Fusion HAT+ SPI NeoPixel 接口已启用。
  - 确保您使用的是受支持的 WS2812/WS2812B LED 模块。

- **颜色变化过快或过慢**

  - 调整 ``STEPS_PER_CYCLE`` 以调整或提高灵敏度。

- **按下按钮不重置色调**

  - 验证 SW 是否连接到 GPIO27。
  - 确保引脚配置了 ``pull=Pin.PULL_UP``。

- **脚本立即退出**

  - 确认 ``pause()`` 已从 ``signal`` 导入。
  - 确保没有其他进程正在使用 SPI。


**自己尝试**
-------------------

想要进一步扩展此项目？试试这些想法：

1. **添加亮度控制**

   使用另一个变量（例如编码器按下 + 旋转）来调整 LED 亮度（0-255）。

2. **添加多种显示模式**

   按编码器循环切换模式：

   - 纯色（默认）
   - 彩虹动画
   - 呼吸效果
   - 颜色擦除

3. **添加电源开关**

   长按编码器按钮打开/关闭 LED 环。

4. **使色调变化更平滑**

   增加 ``STEPS_PER_CYCLE`` 或添加插值以实现丝滑的过渡。

5. **显示方向反馈**

   顺时针旋转时亮一个绿色 LED，逆时针旋转时亮一个红色 LED。

这些小小的扩展将简单的"色调旋钮"变成了一个多功能 RGB 控制界面。
