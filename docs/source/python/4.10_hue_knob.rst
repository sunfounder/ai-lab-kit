4.10 Manopola Colore
==============================

**Introduzione**

In questa lezione, costruirai una **Manopola Colore** -- un controller di colore interattivo che usa un encoder rotativo per regolare la tonalità di un modulo LED circolare WS2812.
Questo modulo LED WS2812 contiene 12 LED RGB WS2812 indirizzabili individualmente, pilotati tramite l'interfaccia NeoPixel basata su SPI di Fusion HAT+.
L'encoder rotativo esterno fornisce input utente in tempo reale tramite pin GPIO standard.

Ruotando l'encoder, i 12 LED ciclano dolcemente attraverso l'intero spettro cromatico RGB.
Premendo il pulsante integrato dell'encoder si resetta la tonalità al valore iniziale.

#. Quando lo script viene eseguito, l'anello del modulo WS2812 risponde all'encoder rotativo:

   * I LED iniziano in rosso (Tonalità 0°).
   * Ruota l'encoder per ciclare dolcemente attraverso l'intera ruota cromatica RGB. I colori transitano continuamente (rosso → giallo → verde → blu → viola → rosso). Il terminale stampa la tonalità corrente e i valori RGB.
   * Premi il pulsante dell'encoder per resettare la tonalità a 0° (rosso).
   * Premi Ctrl+C per uscire. Tutti i LED si spengono prima della chiusura del programma.

**Codice**

Ecco lo script Python per la simulazione semaforica:

.. raw:: html

   <run></run>

.. code-block:: python


   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   currentTemp = None
   markTemp = None

   PRINT_INTERVAL = 1.0
   _last_print = 0.0

   button_event = False  # flag: button was pressed

   def temperature(samples=5, delay=0.01):
      """Read thermistor multiple times and return averaged Celsius (float) or None."""
      vals = []
      for _ in range(samples):
         analogVal = thermistor.read()
         Vr = 3.3 * float(analogVal) / 4095.0
         if (3.3 - Vr) <= 0.1:
               return None
         Rt = 10000.0 * Vr / (3.3 - Vr)
         tempK = 1.0 / (((math.log(Rt / 10000.0)) / 3950.0) + (1.0 / (273.15 + 25.0)))
         vals.append(tempK - 273.15)
         sleep(delay)
      return sum(vals) / len(vals)

   def motor_run(lv):
      lv = max(0, min(4, lv))
      motor.power(0 if lv == 0 else lv * 25)
      return lv

   def changeLevel():
      """Button press: cycle level 0~4 and set a flag for main loop to print."""
      global level, button_event
      level = (level + 1) % 5
      button_event = True

   BtnPin.when_activated = changeLevel

   def main():
      global level, currentTemp, markTemp, _last_print, button_event

      markTemp = temperature()
      while True:
         currentTemp = temperature()
         if currentTemp is None:
               print("Sensor read failed. Please check the sensor.")
               sleep(0.5)
               continue

         # Handle button event in main loop (stable timing)
         if button_event:
               button_event = False
               markTemp = currentTemp
               print(f"[Button] Level -> {level} | Temp: {currentTemp:.2f} C | Mark: {markTemp:.2f} C")

         # Periodic temperature print
         now = time()
         if now - _last_print >= PRINT_INTERVAL:
               if markTemp is None:
                  markTemp = currentTemp
               print(f"Temp: {currentTemp:.2f} C | Mark: {markTemp:.2f} C | Level: {level}")
               _last_print = now

         # Auto adjust level based on +/-5C
         if markTemp is None:
               markTemp = currentTemp

         if level != 0:
               diff = currentTemp - markTemp
               if diff <= -5:
                  level = max(0, level - 1)
                  markTemp = currentTemp
                  print(f"[Auto] Temp down -> Level {level} (Temp: {currentTemp:.2f} C)")
               elif diff >= 5:
                  level = min(4, level + 1)
                  markTemp = currentTemp
                  print(f"[Auto] Temp up   -> Level {level} (Temp: {currentTemp:.2f} C)")

         level = motor_run(level)
         sleep(0.5)

   try:
      main()
   except KeyboardInterrupt:
      print("\nExiting...")
   finally:
      motor.stop()
      sleep(0.1)

**Risoluzione dei Problemi**

- **I LED non si accendono**

  - Controlla il cablaggio al modulo LED WS2812.
  - Assicurati che l'interfaccia NeoPixel SPI di Fusion HAT+ sia abilitata.
  - Assicurati di usare un modulo LED WS2812/WS2812B supportato.

- **I colori cambiano troppo velocemente o troppo lentamente**

  - Regola ``STEPS_PER_CYCLE`` per perfezionare o aumentare la sensibilità.

- **La pressione del pulsante non resetta la tonalità**

  - Verifica che SW sia collegato a GPIO27.
  - Assicurati che il pin sia configurato con ``pull=Pin.PULL_UP``.

- **Lo script esce immediatamente**

  - Conferma che ``pause()`` sia importato da ``signal``.
  - Assicurati che nessun altro processo stia usando SPI.


**Prova Tu Stesso**

Vuoi estendere ulteriormente questo progetto? Prova queste idee:

1. **Aggiungi Controllo Luminosità**

   Usa un'altra variabile (ad es., pressione encoder + rotazione) per regolare la luminosità dei LED da 0-255.

2. **Aggiungi Modalità Display Multiple**

   Premi l'encoder per ciclare attraverso le modalit:
   - Colore solido (predefinito)
   - Animazione arcobaleno
   - Effetto respiro
   - Scolorimento colore

3. **Aggiungi un Interruttore di Accensione**

   Tieni premuto il pulsante dell'encoder per accendere/spegnere l'anello LED.

4. **Rendi il Cambio di Tonalit pi Fluido**

   Aumenta ``STEPS_PER_CYCLE`` o aggiungi interpolazione per transizioni morbidissime.

5. **Mostra Feedback di Direzione**

   Illumina un LED verde quando si ruota in senso orario, rosso quando in senso antiorario.

Queste piccole estensioni trasformano la semplice "Manopola Colore" in un'interfaccia di controllo RGB versatile.
