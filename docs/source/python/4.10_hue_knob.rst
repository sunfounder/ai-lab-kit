4.10 Control de Tono (Hue Knob)
================================

**Introducción**

En esta lección, construirás un **Control de Tono (Hue Knob)** — un controlador de color interactivo que utiliza un codificador rotatorio para ajustar el tono de un módulo LED WS2812 circular.
Este módulo LED WS2812 contiene 12 LEDs RGB WS2812 direccionables individualmente, controlados a través de la interfaz NeoPixel basada en SPI del Fusion HAT+.
El codificador rotatorio externo proporciona entrada de usuario en tiempo real a través de pines GPIO estándar.

A medida que giras el codificador, los 12 LEDs recorren suavemente todo el espectro de colores RGB.
Al presionar el botón incorporado del codificador, se restablece el tono al valor inicial.

#. Todo el código de ejemplo utilizado en este tutorial está disponible en el directorio ``ai-lab-kit``. Sigue estos pasos para ejecutar el ejemplo:


   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 4.10_Hue_Knob.py

#. Cuando el script se ejecuta, el anillo del módulo WS2812 responde al codificador rotatorio:

   * Los LEDs comienzan en rojo (Tono 0°).
   * Gira el codificador para recorrer suavemente toda la rueda de colores RGB. Los colores transicionan continuamente (rojo → amarillo → verde → azul → violeta → rojo). La terminal imprime el tono actual y los valores RGB.
   * Presiona el botón del codificador para restablecer el tono a 0° (rojo).
   * Presiona Ctrl+C para salir. Todos los LEDs se apagan antes de que el programa se cierre.

**Código**

Aquí está el script de Python para la simulación de semáforo:

.. raw:: html

   <run></run>

.. code-block:: python


   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   currentTemp = None
   markTemp = None

   PRINT_INTERVAL = 1.0
   _last_print = 0.0

   button_event = False  # flag: button was pressed

   def temperature(samples=5, delay=0.01):
      """Read thermistor multiple times and return averaged Celsius (float) or None."""
      vals = []
      for _ in range(samples):
         analogVal = thermistor.read()
         Vr = 3.3 * float(analogVal) / 4095.0
         if (3.3 - Vr) <= 0.1:
               return None
         Rt = 10000.0 * Vr / (3.3 - Vr)
         tempK = 1.0 / (((math.log(Rt / 10000.0)) / 3950.0) + (1.0 / (273.15 + 25.0)))
         vals.append(tempK - 273.15)
         sleep(delay)
      return sum(vals) / len(vals)

   def motor_run(lv):
      lv = max(0, min(4, lv))
      motor.power(0 if lv == 0 else lv * 25)
      return lv

   def changeLevel():
      """Button press: cycle level 0~4 and set a flag for main loop to print."""
      global level, button_event
      level = (level + 1) % 5
      button_event = True

   BtnPin.when_activated = changeLevel

   def main():
      global level, currentTemp, markTemp, _last_print, button_event

      markTemp = temperature()
      while True:
         currentTemp = temperature()
         if currentTemp is None:
               print("Sensor read failed. Please check the sensor.")
               sleep(0.5)
               continue

         # Handle button event in main loop (stable timing)
         if button_event:
               button_event = False
               markTemp = currentTemp
               print(f"[Button] Level -> {level} | Temp: {currentTemp:.2f} °C | Mark: {markTemp:.2f} °C")

         # Periodic temperature print
         now = time()
         if now - _last_print >= PRINT_INTERVAL:
               if markTemp is None:
                  markTemp = currentTemp
               print(f"Temp: {currentTemp:.2f} °C | Mark: {markTemp:.2f} °C | Level: {level}")
               _last_print = now

         # Auto adjust level based on ±5°C
         if markTemp is None:
               markTemp = currentTemp

         if level != 0:
               diff = currentTemp - markTemp
               if diff <= -5:
                  level = max(0, level - 1)
                  markTemp = currentTemp
                  print(f"[Auto] Temp down -> Level {level} (Temp: {currentTemp:.2f} °C)")
               elif diff >= 5:
                  level = min(4, level + 1)
                  markTemp = currentTemp
                  print(f"[Auto] Temp up   -> Level {level} (Temp: {currentTemp:.2f} °C)")

         level = motor_run(level)
         sleep(0.5)

   try:
      main()
   except KeyboardInterrupt:
      print("\nExiting...")
   finally:
      motor.stop()
      sleep(0.1)

**Comprender el Código**

1. **Inicialización de NeoPixel**

   - El script usa SPI para controlar un anillo/tira de LEDs NeoPixel (``LED_COUNT = 12``).
   - ``auto_write=False`` está habilitado para que los LEDs se actualicen solo cuando se llama a ``strip.show()``, lo que evita parpadeos y mejora el rendimiento.
   - Los LEDs se limpian al inicio usando ``strip.fill(0)`` y ``strip.show()``.

2. **Configuración del Hardware del Codificador Rotatorio**

   - Se utilizan tres pines GPIO:
     - ``CLK_PIN`` y ``DT_PIN`` proporcionan las señales en cuadratura para la dirección y los pasos de rotación.
     - ``SW_PIN`` es la entrada del botón del codificador.
   - Todos los pines usan resistencias pull-up internas (``Pull.UP``), y el botón está en **estado BAJO activo** (presionado = ``0``).

3. **Parámetros Clave (Ajuste de Comportamiento)**

   - ``DETENTS_PER_CYCLE`` define cuántos "clics" físicos se necesitan para completar una rotación completa de tono (0–360°).
     - Un valor mayor proporciona un control de color más fino.
   - ``TRANSITIONS_PER_DETENT`` convierte las transiciones en cuadratura brutas en "un detent = un conteo".
     - Muchos codificadores producen 2 transiciones por detent, pero algunos generan 4. Ajustar este valor mejora la precisión.

4. ``hue_to_rgb()``

   - Convierte un valor de tono en el rango ``0.0 ~ 1.0`` en una tupla RGB ``(R, G, B)`` con valores ``0 ~ 255``.
   - Esto facilita la generación de cambios de color suaves usando el modelo de color HSV.

5. ``apply_color_from_detent()``

   - Mapea el conteo de detents del codificador a un índice de tono usando módulo:
     - ``hue_idx = detent % DETENTS_PER_CYCLE``
   - Convierte el tono en un color RGB y actualiza todos los LEDs con ``strip.fill(color)`` seguido de ``strip.show()``.
   - Usa ``last_hue_idx`` para evitar refrescar los LEDs cuando el tono calculado no cambia, lo que reduce actualizaciones innecesarias.
   - Imprime el ángulo de tono actual, el valor de detent y el color RGB para depuración/retroalimentación.

6. ``reset_all()``

   - Restablece el estado del contador interno:
     - ``raw`` (conteo bruto de transiciones)
     - ``last_detent`` (último detent mostrado)
     - ``last_hue_idx`` (último índice de tono mostrado)
   - Llama a ``apply_color_from_detent(0)`` para restaurar inmediatamente los LEDs al color inicial (Tono = 0°).

7. **Bucle Principal (Polleo + Detección de Dirección)**

   - El programa consulta ``CLK`` continuamente y verifica cambios:
     - Si ``CLK`` cambia, el codificador se movió un paso en la secuencia de cuadratura.
   - La dirección se determina comparando DT con CLK:
     - ``dt.value() != c`` significa una dirección de rotación (incremento)
     - de lo contrario, decremento
   - El conteo bruto de transiciones se convierte en detents:
     - ``detent = raw // TRANSITIONS_PER_DETENT``
   - El color del LED se actualiza solo cuando cambia el valor de detent.

8. **Restablecimiento por Botón y Antirrebote**

   - Cuando se presiona el botón (``sw.value() == 0``), el programa llama a ``reset_all()``.
   - Se aplica un breve retardo de antirrebote, y el script espera hasta que se suelte el botón para evitar múltiples restablecimientos desde una sola pulsación.

9. **Salida Limpia**

   - Presionar ``Ctrl + C`` sale del programa.
   - En el bloque ``finally``, todos los LEDs se apagan (``strip.fill(0)`` y ``strip.show()``) para que el hardware quede en un estado seguro.

**Solución de Problemas**
-------------------

- **Los LEDs no se encienden**

  - Verifica el cableado al módulo LED WS2812.
  - Asegúrate de que la interfaz SPI NeoPixel del Fusion HAT+ esté habilitada.
  - Asegúrate de estar usando un módulo LED WS2812/WS2812B compatible.

- **Los colores cambian demasiado rápido o demasiado lento**

  - Ajusta ``STEPS_PER_CYCLE`` para refinar o aumentar la sensibilidad.

- **La pulsación del botón no restablece el tono**

  - Verifica que SW esté conectado al GPIO27.
  - Asegúrate de que el pin esté configurado con ``pull=Pin.PULL_UP``.

- **El script sale inmediatamente**

  - Confirma que ``pause()`` esté importado desde ``signal``.
  - Asegúrate de que ningún otro proceso esté usando SPI.


**Pruébalo Tú Mismo**
-------------------

¿Quieres extender este proyecto aún más? Prueba estas ideas:

1. **Agregar Control de Brillo**

   Usa otra variable (por ejemplo, presión del codificador + rotación) para ajustar el brillo de los LEDs de 0 a 255.

2. **Agregar Múltiples Modos de Visualización**

   Presiona el codificador para recorrer modos:

   - Color sólido (predeterminado)
   - Animación arcoíris
   - Efecto de respiración
   - Barrido de color

3. **Agregar un Interruptor de Encendido**

   Mantén presionado el botón del codificador para encender/apagar el anillo LED.

4. **Hacer el Cambio de Tono más Suave**

   Aumenta ``STEPS_PER_CYCLE`` o agrega interpolación para transiciones ultra suaves.

5. **Mostrar Retroalimentación de Dirección**

   Ilumina un LED en verde al girar en sentido horario, rojo al girar en sentido antihorario.

Estas pequeñas extensiones convierten el simple "Control de Tono (Hue Knob)" en una interfaz de control RGB versátil.
