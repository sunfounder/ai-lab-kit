1.1.6 LED-Punktmatrix
========================

**Introduction**

Eine LED-Punktmatrix ist ein Raster aus LEDs, das Zeichen, Symbole oder Animationen darstellen kann. In diesem Projekt zeigen wir, wie Sie eine LED-Punktmatrix ansteuern, um statische Formen anzuzeigen.

    rgb_matrix = LedMatrix(rotate=0)

Dieses Skript zeigt, wie Sie eine LED-Matrix mit der Fusion-HAT-Bibliothek ansteuern. Es initialisiert die Matrix und gibt ein vordefiniertes Muster aus.

Führen Sie das Skript auf einem kompatiblen Gerät mit angeschlossener LED-Matrix aus. Die Matrix zeigt das definierte Muster an, bis Sie das Skript manuell beenden.


----------------------------------------------


**Understanding the Code**


1. **Importing Dependencies**
   
   .. code:: python

      from fusion_hat import LedMatrix
   
   Das benötigte Modul ``LedMatrix`` aus der Bibliothek ``fusion_hat`` wird importiert, um die LED-Matrix zu steuern.

2. **Initializing the LED Matrix**
   
   .. code:: python

      rgb_matrix = LedMatrix(rotate=0)
   
   Die LED-Matrix wird mit einer Rotation von ``0`` initialisiert. Ändern Sie diesen Parameter bei Bedarf, um die Anzeige zu drehen.

3. **Defining a Display Pattern**
   
   .. code:: python

      pattern = [
          0b01111110,
          0b01000000,
          0b00111100,
          0b00000010,
          0b00000001,
          0b00000001,
          0b01000010,
          0b00111100
      ]
   
   Das Muster ist als Liste aus 8-Bit-Binärwerten definiert; jedes Bit repräsentiert den Zustand einer LED (1 = EIN, 0 = AUS). Das gewählte Muster ergibt auf einer 8×8-Matrix eine bestimmte Form.

4. **Displaying the Pattern**
   
   .. code:: python

      rgb_matrix.display_pattern(pattern)
   
   Das Muster wird an die LED-Matrix gesendet und angezeigt.

5. **Keeping the Display Active**
   
   .. code:: python

      input("Press Enter to exit...")
   
   Das Skript wartet auf eine Benutzereingabe, bevor es beendet wird, sodass das Muster sichtbar bleibt, bis Sie es schließen.




----------------------------------------------


**Troubleshooting**

1. **Keine Ausgabe auf der LED-Matrix**  

   - **Ursache**: Fehlerhafte SPI-Verbindung oder Initialisierungsprobleme.  
   - **Lösung**: Prüfen Sie die SPI-Verbindungen zwischen Raspberry Pi und Matrix. Stellen Sie sicher, dass die korrekten ``port``- und ``device``-Werte an ``spi()`` übergeben werden.

2. **Text oder Formen wirken verzerrt**  

   - **Ursache**: Falsche Rotation oder Gerätekonfiguration.  
   - **Lösung**: Passen Sie den Parameter ``rotate`` bei der Initialisierung von ``max7219()`` an die physische Ausrichtung der Matrix an.


----------------------------------------------

**Extendable Ideas**

1. **Dynamische Musteranimation**  

   - Implementieren Sie mehrere Muster und schalten Sie in einer Schleife zwischen ihnen um.  
   - Fügen Sie weiche Übergänge hinzu, um Animationen zu erzeugen.  

2. **Benutzerdefinierte Muster**  

   - Ermöglichen Sie die Eingabe eigener Muster über eine Konfigurationsdatei oder ein einfaches UI.  
   - Nutzen Sie eine textbasierte Darstellung, um neue Designs leicht zu definieren.  

3. **Interaktion in Echtzeit**  

   - Setzen Sie Tasten ein, um zwischen Mustern zu wechseln.  
   - Integrieren Sie einen Joystick oder eine Touch-Eingabe, um die Matrix dynamisch zu steuern.  

4. **Lauftext-Anzeige**  

   - Entwickeln Sie eine Funktion, die Nachrichten über die Matrix scrollen lässt.  
   - Erlauben Sie die dynamische Texteingabe und die zeichenweise Ausgabe.  


----------------------------------------------


**Conclusion**


Dieses Skript ist ein einfaches Beispiel für die Musteranzeige auf einer LED-Matrix mit der Fusion-HAT-Bibliothek. Passen Sie das Muster an, um eigene visuelle Designs zu erstellen.
