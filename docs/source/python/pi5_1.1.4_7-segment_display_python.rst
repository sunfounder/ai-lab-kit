1.1.4 7-Segment-Anzeige
=============================

**Introduction**

In diesem Projekt steuern wir eine 7-Segment-Anzeige, um nacheinander die Zahlen von 0 bis 9 sowie die Buchstaben A bis F darzustellen. Dabei wird gezeigt, wie sich ein 74HC595-Schieberegister einsetzen lässt, um mehrere Segmente effizient mit wenigen GPIO-Pins anzusteuern.

**Circuit Diagram**

Die Schaltung nutzt ein 74HC595-Schieberegister zur Steuerung der 7-Segment-Anzeige. Die Verbindungen sind wie folgt:

- RCLK (Storage Register Clock) des 74HC595 wird mit Pin 4 des Raspberry Pi verbunden.
- SRCLK (Shift Register Clock) wird mit Pin 27 verbunden.
- SER (Serial Data Input, SDI) wird mit Pin 17 verbunden.
- Die Ausgangspins des 74HC595 steuern die jeweiligen Segmente der 7-Segment-Anzeige.

Durch diese Konfiguration wird die Anzahl benötigter GPIO-Pins reduziert, da die serielle Ansteuerung die parallelen Ausgänge des Schieberegisters kontrolliert.

   :width: 800
   :align: center



----------------------------------------------

**Wiring Diagram**

So bauen Sie die Schaltung auf:

1. Platzieren Sie die 7-Segment-Anzeige und den 74HC595 auf dem Breadboard.  
2. Verbinden Sie die Ausgänge des Schieberegisters mit den Segmenten der Anzeige.  
3. Schließen Sie die Eingänge des Schieberegisters an die angegebenen GPIO-Pins des Raspberry Pi an.  
4. Fügen Sie Vorwiderstände hinzu, um den Strom für die Segmente zu begrenzen.

**Writing the Code**

Der folgende Python-Code zeigt nacheinander die hexadezimalen Zeichen (0–9, A–F) auf der 7-Segment-Anzeige an:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin
   from time import sleep

   # GPIO pins connected to 74HC595 shift register
   SDI = Pin(17,Pin.OUT)   # Serial Data Input
   RCLK = Pin(4,Pin.OUT)  # Memory Clock Input (Register Clock)
   SRCLK = Pin(27,Pin.OUT) # Shift Register Clock

   # Hexadecimal digit codes for a common cathode 7-segment display
   segCode = [
      0x3f, 0x06, 0x5b, 0x4f, 0x66, 0x6d, 0x7d,
      0x07, 0x7f, 0x6f, 0x77, 0x7c, 0x39, 0x5e, 0x79, 0x71
   ]

   def hc595_shift(data):
      # Shift 8 bits of data into the 74HC595
      for bit in range(8):
         # Set SDI high or low based on data bit
         SDI.value(0x80 & (data << bit))
         # Trigger shift register clock
         SRCLK.high()
         sleep(0.001)
         SRCLK.low()
      # Latch data to output by triggering memory clock
      RCLK.high()
      sleep(0.001)
      RCLK.low()

   def display_all_on():
      # Function to turn all segments on (for common cathode 7-segment display)
      all_on_code = 0x3f
      hc595_shift(all_on_code)
      print("Displaying all segments on")

   try:
      while True:
         # Display each hexadecimal digit on 7-segment display
         for code in segCode:
               hc595_shift(code)  # Shift the code into 74HC595
               # Print the displayed segment code
               print(f"Displaying segCode[{segCode.index(code)}]: 0x{code:02X}")
               sleep(0.5)  # Pause between displaying each digit

   except KeyboardInterrupt:
      # Gracefully handle script interruption (e.g., Ctrl+C)
      pass

Dieses Python-Skript steuert eine 7-Segment-Anzeige, die über ein 74HC595-Schieberegister mit dem Raspberry Pi verbunden ist. Bei der Ausführung:

1. Durchläuft das Skript nacheinander die hexadezimalen Zeichen (0–9, A–F).  
2. Jedes Zeichen wird für 0,5 Sekunden angezeigt.  
3. Gleichzeitig wird der angezeigte Wert im Konsolenfenster im Hexadezimalformat ausgegeben.  

Das Programm läuft in einer Endlosschleife, bis es vom Benutzer mit ``Ctrl+C`` beendet wird.

**Understanding the Code**

1. **Importing Libraries**

   Die Bibliothek ``fusion_hat`` vereinfacht die GPIO-Steuerung, während ``time`` für Pausen sorgt.

   .. code-block:: python

      #!/usr/bin/env python3
      from fusion_hat import Pin
      from time import sleep


2. **Defining GPIO Pins**

   Die GPIO-Pins werden den Eingängen SDI, RCLK und SRCLK des Schieberegisters zugewiesen.

   .. code-block:: python

      # GPIO pins connected to 74HC595 shift register
      SDI = Pin(17,Pin.OUT)   # Serial Data Input
      RCLK = Pin(4,Pin.OUT)  # Memory Clock Input (Register Clock)
      SRCLK = Pin(27,Pin.OUT) # Shift Register Clock


3. **Hexadecimal Codes**

   Jeder hexadezimale Wert besitzt einen eigenen Code zur Steuerung der Segmente.

   .. code-block:: python

      segCode = [
         0x3f, 0x06, 0x5b, 0x4f, 0x66, 0x6d, 0x7d,
         0x07, 0x7f, 0x6f, 0x77, 0x7c, 0x39, 0x5e, 0x79, 0x71
      ]

4. **Data Shifting Function**

   Die Funktion ``hc595_shift`` überträgt 8 Bit an das Schieberegister.

   .. code-block:: python

       def hc595_shift(data):
           for bit in range(8):
               SDI.value = bool(0x80 & (data << bit))
               SRCLK.on()
               sleep(0.001)
               SRCLK.off()
           RCLK.on()
           sleep(0.001)
           RCLK.off()

5. **Main Loop**

   Die Hauptschleife durchläuft die Codes und zeigt jedes Zeichen auf der 7-Segment-Anzeige an.

   .. code-block:: python

      try:
         while True:
            for code in segCode:
                  hc595_shift(code)
                  print(f"Displaying: {segCode.index(code):X}")
                  sleep(0.5)
      except KeyboardInterrupt:
         pass

**Troubleshooting**

1. **7-Segment-Anzeige reagiert nicht**  

   - **Ursache**: Falsche Verdrahtung zwischen Fusion HAT, 74HC595 und Anzeige.  
   - **Lösung**: Prüfen Sie, ob die GPIO-Pins (17, 4, 27) korrekt mit ``SDI``, ``RCLK`` und ``SRCLK`` verbunden sind und ob die Ausgänge des 74HC595 richtig an die Segmente angeschlossen sind.  

2. **Falsche Zeichen werden angezeigt**  

   - **Ursache**: Die Werte in ``segCode`` stimmen nicht mit der Verdrahtung überein.  
   - **Lösung**: Stellen Sie sicher, dass das Pin-Mapping der Segmente zu den Codes passt.  


3. **Keine Aktivität auf der Anzeige**  

   - **Ursache**: Das Schieberegister empfängt keine Daten.  
   - **Lösung**: Überprüfen Sie die Taktsignale (``RCLK``, ``SRCLK``) sowie die Datenübertragung über ``SDI``.  

4. **Timing-Probleme**  

   - **Ursache**: Die Verzögerung (``sleep(0.001)``) ist zu kurz.  
   - **Lösung**: Erhöhen Sie die Verzögerung leicht (z. B. auf ``sleep(0.002)``).
