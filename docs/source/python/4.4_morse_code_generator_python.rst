4.4 摩斯密码生成器
==================

**简介**

在本项目中，我们将使用树莓派创建一个摩斯密码生成器。您可以通过终端输入一系列字符，系统将使用蜂鸣器和 LED 输出对应的摩斯密码信号。该项目不仅演示了基本的 GPIO 控制，还介绍了摩斯密码这一历史上用于电报通信的迷人通信方法。

* 每个点（dot）由短促的蜂鸣/闪烁表示，每个划（dash）由较长的蜂鸣/闪烁表示。

* 程序会持续等待新的输入消息，并在您按下 ``Ctrl + C`` 时安全停止，同时关闭蜂鸣器和 LED。

**代码**

以下是本项目的 Python 代码：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   import time

   # Initialize Buzzer and LED to GPIO pins
   BeepPin = Pin(22, mode=Mode.OUT)
   ALedPin = Pin(17, mode=Mode.OUT)

   # Morse code representation for characters
   MORSECODE = {
      'A': '01', 'B': '1000', 'C': '1010', 'D': '100', 'E': '0', 'F': '0010', 'G': '110',
      'H': '0000', 'I': '00', 'J': '0111', 'K': '101', 'L': '0100', 'M': '11', 'N': '10',
      'O': '111', 'P': '0110', 'Q': '1101', 'R': '010', 'S': '000', 'T': '1',
      'U': '001', 'V': '0001', 'W': '011', 'X': '1001', 'Y': '1011', 'Z': '1100',
      '1': '01111', '2': '00111', '3': '00011', '4': '00001', '5': '00000',
      '6': '10000', '7': '11000', '8': '11100', '9': '11110', '0': '11111',
      '?': '001100', '/': '10010', ',': '110011', '.': '010101', ';': '101010',
      '!': '101011', '@': '011010', ':': '111000',
   }

   # Timing (seconds)
   UNIT = 0.25                 # base unit
   DOT = UNIT / 2              # dot length
   DASH = UNIT                 # dash length
   INTRA_SYMBOL_GAP = UNIT / 2 # gap between dot/dash in one letter
   LETTER_GAP = UNIT           # gap between letters
   WORD_GAP = UNIT * 2         # gap between words (space)

   def on():
      """Turn on the buzzer and LED."""
      BeepPin.on()
      ALedPin.on()

   def off():
      """Turn off the buzzer and LED."""
      BeepPin.off()
      ALedPin.off()

   def beep(duration):
      """Beep (and flash LED) for 'duration' seconds."""
      on()
      time.sleep(duration)
      off()

   def play_symbol(symbol):
      """Play one morse symbol: '0' (dot) or '1' (dash)."""
      if symbol == '0':
         beep(DOT)
      elif symbol == '1':
         beep(DASH)
      time.sleep(INTRA_SYMBOL_GAP)

   def morsecode(text):
      """
      Convert text to Morse code and output via buzzer+LED.
      Supports spaces between words and ignores unsupported characters.
      """
      for ch in text:
         if ch == ' ':
               # Space means word gap
               time.sleep(WORD_GAP)
               continue

         # Skip unsupported characters instead of crashing
         if ch not in MORSECODE:
               continue

         pattern = MORSECODE[ch]
         for sym in pattern:
               play_symbol(sym)

         # Pause between letters
         time.sleep(LETTER_GAP)

   def destroy():
      """Ensure buzzer and LED are turned off."""
      BeepPin.off()
      ALedPin.off()
      print("")

   try:
      while True:
         code = input("Please input the messenger:").upper()
         print(code)
         morsecode(code)
   except KeyboardInterrupt:
      destroy()



此 Python 脚本将用户输入的消息转换为摩斯密码，并使用蜂鸣器和 LED 进行信号输出。其工作原理如下：

1. **摩斯密码转换**：脚本使用预定义的 ``MORSECODE`` 字典将输入文本（字母、数字和一些特殊字符）转换为摩斯密码。

2. **视听摩斯密码输出**：

   - 对于每个点（``0``），蜂鸣器和 LED 在短时间内激活（停顿时间的一半）。
   - 对于每个划（``1``），蜂鸣器和 LED 在较长时间内激活（等于停顿时间）。

3. **用户交互**：

   - 用户输入消息，系统转换并发出相应的摩斯密码。
   - 程序持续请求新消息，直到被中断。

4. **优雅退出**：按下 ``Ctrl+C`` 时，脚本停止，关闭蜂鸣器和 LED，然后安全退出。

----------------------------------------------

**理解代码**

1. **组件设置：**

   蜂鸣器和 LED 分别初始化为 GPIO 引脚 22 和 17。

2. **摩斯密码字典：**

   摩斯密码使用 '0' 表示点（短信号），'1' 表示划（长信号）。例如，'A' 表示为 "01"。

3. **信号函数：**

   * ``on()`` 和 ``off()`` 函数激活或停用蜂鸣器和 LED。
   * ``beep()`` 函数结合这些操作创建指定时长的信号。

4. **摩斯密码转换：**

   ``morsecode()`` 函数处理输入消息中的每个字母。它使用摩斯密码字典为每个字符发出一系列信号。

5. **主循环：**

   程序持续提示用户输入，并将输入转换为摩斯密码信号。循环可通过 ``Ctrl+C`` 安全终止。


----------------------------------------------


**故障排除**

1. **蜂鸣器或 LED 不工作**：

   - **原因**：接线或 GPIO 引脚配置不正确。
   - **解决方法**：

     - 验证蜂鸣器是否连接到 GPIO 22，LED 是否连接到 GPIO 17。
     - 使用简单的 GPIO 控制脚本独立测试蜂鸣器和 LED。

2. **摩斯密码输出不准确**：

   - **原因**：输入字符不在 ``MORSECODE`` 字典中。
   - **解决方法**：

     - 确保输入仅包含支持的字符（A-Z、0-9 和选定符号）。
     - 扩展 ``MORSECODE`` 字典以包含更多字符。

3. **信号过快或重叠**：

   - **原因**：停顿或信号持续时间设置不当。
   - **解决方法**：调整 ``morsecode()`` 函数中的 ``pause`` 变量以获得更清晰的信号：

       .. code-block:: python

           pause = 0.5  # 增加停顿时间以获得更慢的输出

4. **未检测到输入**：

   - **原因**：运行环境中的输入问题（例如没有控制台）。
   - **解决方法**：确保脚本在支持 ``input()`` 的终端或环境中运行。
