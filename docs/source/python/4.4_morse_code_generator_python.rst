4.4 Generatore di Codice Morse
===============================

**Introduzione**

In questo progetto, creeremo un generatore di codice Morse usando un Raspberry Pi. Puoi inserire una serie di caratteri tramite il terminale e il sistema emetterà i corrispondenti segnali in codice Morse usando un buzzer e un LED. Questo progetto non solo dimostra il controllo GPIO di base, ma introduce anche il codice Morse, un affascinante metodo di comunicazione storicamente usato per la telegrafia.

**Codice**

Qui sotto c'è il codice Python per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   import time

   # Initialize Buzzer and LED to GPIO pins
   BeepPin = Pin(22, mode=Mode.OUT)
   ALedPin = Pin(17, mode=Mode.OUT)

   # Morse code representation for characters
   MORSECODE = {
      'A': '01', 'B': '1000', 'C': '1010', 'D': '100', 'E': '0', 'F': '0010', 'G': '110',
      'H': '0000', 'I': '00', 'J': '0111', 'K': '101', 'L': '0100', 'M': '11', 'N': '10',
      'O': '111', 'P': '0110', 'Q': '1101', 'R': '010', 'S': '000', 'T': '1',
      'U': '001', 'V': '0001', 'W': '011', 'X': '1001', 'Y': '1011', 'Z': '1100',
      '1': '01111', '2': '00111', '3': '00011', '4': '00001', '5': '00000',
      '6': '10000', '7': '11000', '8': '11100', '9': '11110', '0': '11111',
      '?': '001100', '/': '10010', ',': '110011', '.': '010101', ';': '101010',
      '!': '101011', '@': '011010', ':': '111000',
   }

   # Timing (seconds)
   UNIT = 0.25                 # base unit
   DOT = UNIT / 2              # dot length
   DASH = UNIT                 # dash length
   INTRA_SYMBOL_GAP = UNIT / 2 # gap between dot/dash in one letter
   LETTER_GAP = UNIT           # gap between letters
   WORD_GAP = UNIT * 2         # gap between words (space)

   def on():
      """Turn on the buzzer and LED."""
      BeepPin.on()
      ALedPin.on()

   def off():
      """Turn off the buzzer and LED."""
      BeepPin.off()
      ALedPin.off()

   def beep(duration):
      """Beep (and flash LED) for 'duration' seconds."""
      on()
      time.sleep(duration)
      off()

   def play_symbol(symbol):
      """Play one morse symbol: '0' (dot) or '1' (dash)."""
      if symbol == '0':
         beep(DOT)
      elif symbol == '1':
         beep(DASH)
      time.sleep(INTRA_SYMBOL_GAP)

   def morsecode(text):
      """
      Convert text to Morse code and output via buzzer+LED.
      Supports spaces between words and ignores unsupported characters.
      """
      for ch in text:
         if ch == ' ':
               # Space means word gap
               time.sleep(WORD_GAP)
               continue

         # Skip unsupported characters instead of crashing
         if ch not in MORSECODE:
               continue

         pattern = MORSECODE[ch]
         for sym in pattern:
               play_symbol(sym)

         # Pause between letters
         time.sleep(LETTER_GAP)

   def destroy():
      """Ensure buzzer and LED are turned off."""
      BeepPin.off()
      ALedPin.off()
      print("")

   try:
      while True:
         code = input("Please input the messenger:").upper()
         print(code)
         morsecode(code)
   except KeyboardInterrupt:
      destroy()



Questo script Python converte un messaggio fornito dall'utente in codice Morse e lo segnala usando un buzzer e un LED. Ecco come funziona:

1. **Conversione in Codice Morse**: Lo script traduce il testo di input (lettere, numeri e alcuni caratteri speciali) in codice Morse usando un dizionario predefinito ``MORSECODE``.

2. **Uscita Audio-Visiva del Codice Morse**:

   - Per ogni punto (``0``), il buzzer e il LED vengono attivati per una durata breve (metà del tempo di pausa).
   - Per ogni linea (``1``), il buzzer e il LED vengono attivati per una durata più lunga (uguale al tempo di pausa).

3. **Interazione con l'Utente**:

   - Gli utenti inseriscono un messaggio e il sistema converte ed emette il corrispondente codice Morse.
   - Il programma chiede continuamente nuovi messaggi fino a quando non viene interrotto.

4. **Uscita Controllata**: Con ``Ctrl+C``, lo script si ferma, spegne il buzzer e il LED ed esce in modo pulito.

----------------------------------------------

**Comprendere il Codice**

1. **Configurazione dei Componenti:**

   Il buzzer e il LED vengono inizializzati rispettivamente sui pin GPIO 22 e 17.

2. **Dizionario del Codice Morse:**

   Il codice Morse è rappresentato usando '0' per i punti (segnali brevi) e '1' per le linee (segnali lunghi). Ad esempio, 'A' è rappresentato come "01".

3. **Funzioni di Segnale:**

   * Le funzioni ``on()`` e ``off()`` attivano o disattivano il buzzer e il LED.
   * La funzione ``beep()`` combina queste per creare un segnale con una durata specificata.

4. **Conversione in Codice Morse:**

   La funzione ``morsecode()`` elabora ogni lettera del messaggio di input. Emette una serie di segnali per ogni carattere usando il dizionario del codice Morse.

5. **Ciclo Principale:**

   Il programma richiede continuamente input all'utente e converte l'input in segnali in codice Morse. Il ciclo può essere terminato in sicurezza con ``Ctrl+C``.

**Risoluzione dei Problemi**

1. **Il Buzzer o il LED Non Funzionano**:

   - **Causa**: Cablaggio errato o configurazione errata del pin GPIO.
   - **Soluzione**:

     - Verifica che il buzzer sia collegato a GPIO 22 e il LED a GPIO 17.
     - Testa il buzzer e il LED indipendentemente usando script di controllo GPIO semplici.

2. **L'Uscita in Codice Morse è Imprecisa**:

   - **Causa**: Caratteri di input non presenti nel dizionario ``MORSECODE``.
   - **Soluzione**:

     - Assicurati che l'input contenga solo caratteri supportati (A-Z, 0-9 e simboli selezionati).
     - Estendi il dizionario ``MORSECODE`` per includere caratteri aggiuntivi.

3. **Segnali Veloci o Sovrapposti**:

   - **Causa**: Temporizzazione inadeguata per le pause o le durate dei segnali.
   - **Soluzione**: Regola la variabile ``pause`` nella funzione ``morsecode()`` per una segnalazione più chiara:

       .. code-block:: python

           pause = 0.5  # Increase pause duration for slower output

4. **Input Non Rilevato**:

   - **Causa**: Problemi di input nell'ambiente di esecuzione (ad es., nessuna console).
   - **Soluzione**: Assicurati che lo script sia eseguito in un terminale o ambiente che supporti ``input()``.
