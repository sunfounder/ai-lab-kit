4.4 Generateur de code Morse
====================================

**Introduction**

Dans ce projet, nous allons creer un generateur de code Morse a l’aide d’un Raspberry Pi. Vous pouvez saisir une serie de caracteres via le terminal, et le systeme emettra les signaux Morse correspondants a l’aide d’un buzzer et d’une LED. Ce projet demontre non seulement le controle GPIO de base, mais introduit egalement le code Morse, une methode de communication fascinante utilisee historiquement pour la telegraphe.

* Apres avoir execute le script, vous pouvez taper un message dans le terminal et le systeme le traduira en code Morse a l’aide d’un buzzer et d’une LED.
* Chaque point est indique par un bref bip/clignotement, et chaque trait par un bip/clignotement plus long.

**Code**

Voici le code Python pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   import time

   # Initialize Buzzer and LED to GPIO pins
   BeepPin = Pin(22, mode=Mode.OUT)
   ALedPin = Pin(17, mode=Mode.OUT)

   # Morse code representation for characters
   MORSECODE = {
      'A': '01', 'B': '1000', 'C': '1010', 'D': '100', 'E': '0', 'F': '0010', 'G': '110',
      'H': '0000', 'I': '00', 'J': '0111', 'K': '101', 'L': '0100', 'M': '11', 'N': '10',
      'O': '111', 'P': '0110', 'Q': '1101', 'R': '010', 'S': '000', 'T': '1',
      'U': '001', 'V': '0001', 'W': '011', 'X': '1001', 'Y': '1011', 'Z': '1100',
      '1': '01111', '2': '00111', '3': '00011', '4': '00001', '5': '00000',
      '6': '10000', '7': '11000', '8': '11100', '9': '11110', '0': '11111',
      '?': '001100', '/': '10010', ',': '110011', '.': '010101', ';': '101010',
      '!': '101011', '@': '011010', ':': '111000',
   }

   # Timing (seconds)
   UNIT = 0.25                 # base unit
   DOT = UNIT / 2              # dot length
   DASH = UNIT                 # dash length
   INTRA_SYMBOL_GAP = UNIT / 2 # gap between dot/dash in one letter
   LETTER_GAP = UNIT           # gap between letters
   WORD_GAP = UNIT * 2         # gap between words (space)

   def on():
      """Turn on the buzzer and LED."""
      BeepPin.on()
      ALedPin.on()

   def off():
      """Turn off the buzzer and LED."""
      BeepPin.off()
      ALedPin.off()

   def beep(duration):
      """Beep (and flash LED) for 'duration' seconds."""
      on()
      time.sleep(duration)
      off()

   def play_symbol(symbol):
      """Play one morse symbol: '0' (dot) or '1' (dash)."""
      if symbol == '0':
         beep(DOT)
      elif symbol == '1':
         beep(DASH)
      time.sleep(INTRA_SYMBOL_GAP)

   def morsecode(text):
      """
      Convert text to Morse code and output via buzzer+LED.
      Supports spaces between words and ignores unsupported characters.
      """
      for ch in text:
         if ch == ' ':
               # Space means word gap
               time.sleep(WORD_GAP)
               continue

         # Skip unsupported characters instead of crashing
         if ch not in MORSECODE:
               continue

         pattern = MORSECODE[ch]
         for sym in pattern:
               play_symbol(sym)

         # Pause between letters
         time.sleep(LETTER_GAP)

   def destroy():
      """Ensure buzzer and LED are turned off."""
      BeepPin.off()
      ALedPin.off()
      print("")

   try:
      while True:
         code = input("Please input the messenger:").upper()
         print(code)
         morsecode(code)
   except KeyboardInterrupt:
      destroy()



Ce script Python convertit un message fourni par l'utilisateur en code Morse et le signale a l'aide d'un buzzer et d'une LED. Voici comment il fonctionne :

1. **Conversion en code Morse** : Le script traduit le texte saisi (lettres, chiffres et certains caracteres speciaux) en code Morse a l'aide d'un dictionnaire predefini ``MORSECODE``.

2. **Sortie audio-visuelle du code Morse** :

   - Pour chaque point (``0``), le buzzer et la LED sont actives pendant une courte duree (moitie du temps de pause).
   - Pour chaque trait (``1``), le buzzer et la LED sont actives pendant une duree plus longue (egale au temps de pause).

3. **Interaction utilisateur** :

   - Les utilisateurs saisissent un message et le systeme le convertit et emet le code Morse correspondant.
   - Le programme demande continuellement de nouveaux messages jusqu'a ce qu'il soit interrompu.

4. **Sortie propre** : Sur ``Ctrl+C``, le script s'arrete, eteint le buzzer et la LED, et se termine correctement.

----------------------------------------------

**Comprendre le code**

1. **Configuration des composants :**

   Le buzzer et la LED sont initialises sur les broches GPIO 22 et 17 respectivement.

2. **Dictionnaire du code Morse :**

   Le code Morse est represente en utilisant '0' pour les points (signaux courts) et '1' pour les traits (signaux longs). Par exemple, 'A' est represente par "01".

3. **Fonctions de signalisation :**

   * Les fonctions ``on()`` et ``off()`` activent ou desactivent le buzzer et la LED.
   * La fonction ``beep()`` les combine pour creer un signal d'une duree specifiee.

4. **Conversion en code Morse :**

   La fonction ``morsecode()`` traite chaque lettre du message saisi. Elle emet une serie de signaux pour chaque caractere a l'aide du dictionnaire de code Morse.

5. **Boucle principale :**

   Le programme invite continuellement l'utilisateur a saisir du texte et convertit la saisie en signaux de code Morse. La boucle peut etre interrompue en toute securite avec ``Ctrl+C``.


----------------------------------------------


**Depannage**

1. **Le buzzer ou la LED ne fonctionne pas** :

   - **Cause :** Cablage incorrect ou configuration des broches GPIO erronee.
   - **Solution :**

     - Verifiez que le buzzer est connecte a la GPIO 22 et la LED a la GPIO 17.
     - Testez le buzzer et la LED independamment a l'aide de simples scripts de controle GPIO.

2. **La sortie du code Morse est inexacte** :

   - **Cause :** Caracteres saisis non presents dans le dictionnaire ``MORSECODE``.
   - **Solution :**

     - Assurez-vous que la saisie ne contient que des caracteres supportes (A-Z, 0-9 et certains symboles).
     - Etendez le dictionnaire ``MORSECODE`` pour inclure des caracteres supplementaires.

3. **Signaux rapides ou qui se chevauchent** :

   - **Cause :** Temporisation inadequate pour les pauses ou les durees des signaux.
   - **Solution :** Ajustez la variable ``pause`` dans la fonction ``morsecode()`` pour un signalement plus clair :

       .. code-block:: python

           pause = 0.5  # Augmentez la duree de pause pour une sortie plus lente

4. **Saisie non detectee** :

   - **Cause :** Problemes de saisie dans l'environnement d'execution (par exemple, pas de console).
   - **Solution :** Assurez-vous que le script est execute dans un terminal ou un environnement qui supporte ``input()``.

**Idees d'extension**

1. **Vitesse reglable** : Permettez aux utilisateurs de definir la vitesse de signalisation du code Morse en saisissant une valeur de pause personnalisee.

     .. code-block:: python

         pause = float(input("Entrez la duree de pause (secondes) : "))

2. **Sortie multi-peripheriques** : Ajoutez une autre LED ou un autre buzzer pour afficher le code Morse simultanement sur differents peripheriques.

3. **Journalisation du code Morse** : Enregistrez la sequence de code Morse dans un fichier pour chaque message :

     .. code-block:: python

         with open("morse_log.txt", "a") as log_file:
             log_file.write(f"{message} -> {morse_sequence}\n")
