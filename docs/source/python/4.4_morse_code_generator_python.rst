4.4 Generador de Código Morse
===============================

**Introducción**

En este proyecto, crearemos un generador de código Morse usando una Raspberry Pi. Puedes ingresar una serie de caracteres a través del terminal, y el sistema emitirá las señales de código Morse correspondientes usando un zumbador y un LED. Este proyecto no solo demuestra el control básico de GPIO, sino que también introduce el código Morse, un fascinante método de comunicación utilizado históricamente para la telegrafía.

**Código**

A continuación se muestra el código Python para este proyecto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   import time

   # Initialize Buzzer and LED to GPIO pins
   BeepPin = Pin(22, mode=Mode.OUT)
   ALedPin = Pin(17, mode=Mode.OUT)

   # Morse code representation for characters
   MORSECODE = {
      'A': '01', 'B': '1000', 'C': '1010', 'D': '100', 'E': '0', 'F': '0010', 'G': '110',
      'H': '0000', 'I': '00', 'J': '0111', 'K': '101', 'L': '0100', 'M': '11', 'N': '10',
      'O': '111', 'P': '0110', 'Q': '1101', 'R': '010', 'S': '000', 'T': '1',
      'U': '001', 'V': '0001', 'W': '011', 'X': '1001', 'Y': '1011', 'Z': '1100',
      '1': '01111', '2': '00111', '3': '00011', '4': '00001', '5': '00000',
      '6': '10000', '7': '11000', '8': '11100', '9': '11110', '0': '11111',
      '?': '001100', '/': '10010', ',': '110011', '.': '010101', ';': '101010',
      '!': '101011', '@': '011010', ':': '111000',
   }

   # Timing (seconds)
   UNIT = 0.25                 # base unit
   DOT = UNIT / 2              # dot length
   DASH = UNIT                 # dash length
   INTRA_SYMBOL_GAP = UNIT / 2 # gap between dot/dash in one letter
   LETTER_GAP = UNIT           # gap between letters
   WORD_GAP = UNIT * 2         # gap between words (space)

   def on():
      """Turn on the buzzer and LED."""
      BeepPin.on()
      ALedPin.on()

   def off():
      """Turn off the buzzer and LED."""
      BeepPin.off()
      ALedPin.off()

   def beep(duration):
      """Beep (and flash LED) for 'duration' seconds."""
      on()
      time.sleep(duration)
      off()

   def play_symbol(symbol):
      """Play one morse symbol: '0' (dot) or '1' (dash)."""
      if symbol == '0':
         beep(DOT)
      elif symbol == '1':
         beep(DASH)
      time.sleep(INTRA_SYMBOL_GAP)

   def morsecode(text):
      """
      Convert text to Morse code and output via buzzer+LED.
      Supports spaces between words and ignores unsupported characters.
      """
      for ch in text:
         if ch == ' ':
               # Space means word gap
               time.sleep(WORD_GAP)
               continue

         # Skip unsupported characters instead of crashing
         if ch not in MORSECODE:
               continue

         pattern = MORSECODE[ch]
         for sym in pattern:
               play_symbol(sym)

         # Pause between letters
         time.sleep(LETTER_GAP)

   def destroy():
      """Ensure buzzer and LED are turned off."""
      BeepPin.off()
      ALedPin.off()
      print("")

   try:
      while True:
         code = input("Please input the messenger:").upper()
         print(code)
         morsecode(code)
   except KeyboardInterrupt:
      destroy()



Este script de Python convierte un mensaje proporcionado por el usuario en código Morse y lo señala usando un zumbador y un LED. Así es como funciona:

1. **Conversión a Código Morse**: El script traduce el texto de entrada (letras, números y algunos caracteres especiales) a código Morse usando un diccionario predefinido ``MORSECODE``.

2. **Salida Audiovisual de Código Morse**:

   - Para cada punto (``0``), el zumbador y el LED se activan durante un período corto (la mitad del tiempo de pausa).
   - Para cada raya (``1``), el zumbador y el LED se activan durante un período más largo (igual al tiempo de pausa).

3. **Interacción con el Usuario**:

   - Los usuarios ingresan un mensaje, y el sistema lo convierte y emite el código Morse correspondiente.
   - El programa solicita continuamente nuevos mensajes hasta que se interrumpe.

4. **Salida Ordenada**: Al presionar ``Ctrl+C``, el script se detiene, apaga el zumbador y el LED, y sale limpiamente.

----------------------------------------------

**Comprender el Código**

1. **Configuración de Componentes:**

   El zumbador y el LED se inicializan en los pines GPIO 22 y 17, respectivamente.

2. **Diccionario de Código Morse:**

   El código Morse se representa usando '0' para puntos (señales cortas) y '1' para rayas (señales largas). Por ejemplo, 'A' se representa como "01".

3. **Funciones de Señal:**

   * Las funciones ``on()`` y ``off()`` activan o desactivan el zumbador y el LED.
   * La función ``beep()`` las combina para crear una señal con una duración específica.

4. **Conversión de Código Morse:**

   La función ``morsecode()`` procesa cada letra del mensaje de entrada. Emite una serie de señales para cada carácter usando el diccionario de código Morse.

5. **Bucle Principal:**

   El programa solicita continuamente la entrada del usuario y convierte la entrada en señales de código Morse. El bucle se puede terminar de forma segura con ``Ctrl+C``.


----------------------------------------------


**Solución de Problemas**

1. **El Zumbador o el LED No Funcionan**:

   - **Causa**: Cableado incorrecto o configuración de pines GPIO.
   - **Solución**:

     - Verifica que el zumbador esté conectado a GPIO 22 y el LED a GPIO 17.
     - Prueba el zumbador y el LED de forma independiente usando scripts simples de control GPIO.

2. **La Salida de Código Morse es Incorrecta**:

   - **Causa**: Caracteres de entrada que no están en el diccionario ``MORSECODE``.
   - **Solución**:

     - Asegúrate de que la entrada contenga solo caracteres compatibles (A-Z, 0-9 y símbolos seleccionados).
     - Extiende el diccionario ``MORSECODE`` para incluir caracteres adicionales.

3. **Señales Rápidas o Superpuestas**:

   - **Causa**: Tiempo inadecuado para las pausas o duraciones de las señales.
   - **Solución**: Ajusta la variable ``pause`` en la función ``morsecode()`` para una señalización más clara:

       .. code-block:: python

           pause = 0.5  # Aumenta la duración de la pausa para una salida más lenta

4. **Entrada No Detectada**:

   - **Causa**: Problemas de entrada en el entorno de ejecución (por ejemplo, sin consola).
   - **Solución**: Asegúrate de que el script se ejecute en un terminal o entorno que admita ``input()``.

**Ideas para Extender**

1. **Velocidad Ajustable**: Permite a los usuarios establecer la velocidad de señalización del código Morse ingresando un valor de pausa personalizado.

     .. code-block:: python

2. **Salida Multi-dispositivo**: Agrega otro LED o zumbador para mostrar el código Morse simultáneamente en diferentes dispositivos.

3. **Registro de Código Morse**: Guarda la secuencia de código Morse en un archivo para cada mensaje:

     .. code-block:: python

         with open("morse_log.txt", "a") as log_file:
             log_file.write(f"{message} -> {morse_sequence}\n")
