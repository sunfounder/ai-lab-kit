4.1.1 Kamera
===================

**Introduction**

Dieses Projekt zeigt, wie man mit dem Raspberry Pi Zero ein einfaches Kamerasystem mit Auslösetaste erstellt. Beim Drücken der Taste nimmt die Kamera ein Foto auf, während eine LED blinkt, um die Aktion anzuzeigen. Dies ist eine hervorragende Möglichkeit, praktische Erfahrungen mit GPIO-Steuerung und dem Raspberry Pi Kameramodul zu sammeln.

**Writing the Code**

Hier ist der für dieses Projekt verwendete Python-Code:



.. raw:: html

   <run></run>

.. code-block:: python

   from picamera2 import Picamera2, Preview
   from fusion_hat import Pin
   import time
   import os

   # Get the current user's login name and home directory
   user = os.getlogin()
   user_home = os.path.expanduser(f'~{user}')

   # Initialize the camera
   camera = Picamera2()
   camera.start()

   # Initialize a variable to track the camera's status
   global status
   status = False

   # Set up LED and button with their GPIO pin numbers
   led = Pin(17, Pin.OUT)
   button = Pin(4, Pin.IN, Pin.PULL_DOWN)

   def takePhotos(pin):
      """Function to set the camera's status to True when the button is pressed."""
      global status
      status = True

   try:
      # Assign the function to be called when the button is pressed
      button.when_activated = takePhotos
     
      # Main loop
      while True:
         # Check if the button has been pressed
         if status:
               # Blink the LED five times
               for i in range(5):
                  led.on()
                  time.sleep(0.1)
                  led.off()
                  time.sleep(0.1)
               # Capture and save a photo
               camera.capture_file(f'{user_home}/my_photo.jpg')
               print('Take a photo!')          
               # Reset the status
               status = False
         else:
               # Turn off the LED if not capturing
               led.off()
        
         # Wait for a short period before checking the button status again
         time.sleep(1)

   except KeyboardInterrupt:
      # Stop the camera and turn off the LED if a KeyboardInterrupt occurs
      camera.stop_preview()
      led.off()
      pass


Dieses Python-Skript kombiniert eine Raspberry-Pi-Kamera mit LED und Taster, um ein interaktives Fotosystem zu realisieren. Beim Ausführen gilt:

1. **Initial Setup**:

   - Die Kamera wird gestartet und ist aufnahmebereit.
   - Eine LED (GPIO 17) und ein Taster (GPIO 4) werden initialisiert.

2. **Photo Capture Trigger**:

   - Wird der Taster gedrückt, blinkt die LED als Indikator für die Aufnahme.
   - Die Kamera speichert ein Foto im Home-Verzeichnis des Benutzers unter ``my_photo.jpg``.
   - Im Terminal erscheint die Meldung ``Photo captured!``.

3. **Continuous Monitoring**:

   - Das Skript überwacht kontinuierlich das Tastensignal, um Fotos auszulösen.

4. **Graceful Exit**:

   - Bei ``Ctrl+C`` beendet das Skript die Kameravorschau und schaltet die LED aus.

Um das Foto auf deinen PC herunterzuladen, siehe :ref:`filezilla`.

**Troubleshooting**

1. **Foto wird nicht aufgenommen**:

   - **Ursache**: Taster falsch verdrahtet oder Kamera nicht initialisiert.
   - **Lösung**:

     - Prüfe die Verbindung von Taster an GPIO 4 und GND.
     - Stelle sicher, dass die Kamera korrekt verbunden und in ``raspi-config`` aktiviert ist.

2. **LED blinkt nicht**:

   - **Ursache**: Fehlerhafte LED-Verdrahtung oder GPIO-Konfiguration.
   - **Lösung**:

     - Verbinde die LED mit GPIO 17 über einen geeigneten Widerstand.
     - Teste die LED separat.

3. **Foto wird überschrieben**:

   - **Ursache**: Die Datei ``my_photo.jpg`` wird bei jeder Aufnahme ersetzt.
   - **Lösung**: Fotos mit eindeutigen Dateinamen speichern, z. B. mit Zeitstempeln:

     .. code-block:: python

         timestamp = time.strftime("%Y%m%d-%H%M%S")
         camera.capture_file(f'{user_home}/photo_{timestamp}.jpg')

4. **Skript stürzt mit Kamera-Fehler ab**:

   - **Ursache**: Kameramodul wird nicht erkannt oder ist von einem anderen Prozess belegt.
   - **Lösung**:

     - Prüfe die Verbindung und starte den Raspberry Pi neu.
     - Suche nach Konflikten mit ``sudo lsof /dev/video*``.

**Extendable Ideas**

1. **Mehrere Fotos**: Mehrfachaufnahmen mit fortlaufenden Dateinamen ermöglichen:

     .. code-block:: python

         counter = 0
         camera.capture_file(f'{user_home}/photo_{counter}.jpg')
         counter += 1

2. **Videoaufnahme**: Funktion erweitern, um Videos per Tastendruck aufzuzeichnen:

     .. code-block:: python

         camera.start_recording(f'{user_home}/my_video.h264')
         time.sleep(10)
         camera.stop_recording()

3. **LED-Statusanzeige**: LED als Zustandsanzeige nutzen:

     - Dauerlicht: Kamera bereit  
     - Blinken: Fotoaufnahme

4. **Fotoverwaltung**: Fotos in Ordnern nach Datum oder Ereignis sortieren.

5. **Zeitrafferfotografie**: Fotos in Intervallen aufnehmen:

     .. code-block:: python

         for i in range(10):
             camera.capture_file(f'{user_home}/timelapse_{i}.jpg')
             time.sleep(5)
