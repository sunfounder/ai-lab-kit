2.1.1 Button
===============

**Introduction**

In diesem Projekt lernen wir, wie man mit einem Taster eine LED steuert. Taster sind grundlegende Eingabegeräte, die in zahlreichen Elektronikprojekten genutzt werden, um mit Schaltungen und Systemen zu interagieren.

**Wiring Diagram**

So bauen Sie die Schaltung auf:

1. Verbinden Sie die Anode (langes Bein) der LED über einen Vorwiderstand mit GPIO22.  
2. Verbinden Sie die Kathode (kurzes Bein) der LED mit Masse (GND).  
3. Schließen Sie ein Ende des Tasters an GPIO17 und das andere Ende an Masse (GND) an.

**Writing the Code**

Der folgende Python-Code schaltet die LED je nach Tastendruck oder -loslassen ein oder aus:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin  
   from signal import pause  # Import pause function from signal module

   # Initialize an LED object on GPIO pin 22
   led = Pin(22,Pin.OUT)
   # Initialize a Button object on GPIO pin 17
   button = Pin(17, Pin.IN, pull= Pin.PULL_DOWN)

   # # Link the button's "when_activated" event to the LED's high() method
   button.when_activated = led.high

   # # Link the button's "when_deactivated" event to the LED's low() method
   button.when_deactivated = led.low

   # Run an event loop that waits for button events and keeps the script running
   print("CTRL + C to exit")
   pause()


Dieses Python-Skript zeigt ein interaktives Beispiel, bei dem ein Taster eine LED steuert. Beim Ausführen gilt:

1. Drücken des Tasters (an GPIO17) schaltet die LED (an GPIO22) ein.  
2. Loslassen des Tasters schaltet die LED wieder aus.  
3. Das Programm läuft unbegrenzt weiter und reagiert auf Tastendrücke und -freigaben.  


----------------------------------------------

**Understanding the Code**

1. **Library Import**

   Die Bibliothek ``fusion_hat`` bietet eine einfache Schnittstelle zur GPIO-Steuerung. Mit dem Modul ``signal`` wird das Programm dauerhaft aktiv gehalten.

   .. code-block:: python

      from fusion_hat import Pin  
      from signal import pause 

2. **Component Initialization**

   Die LED ist mit GPIO22 verbunden, der Taster mit GPIO17.

   .. code-block:: python

      # Initialize an LED object on GPIO pin 22
      led = Pin(22,Pin.OUT)
      # Initialize a Button object on GPIO pin 17
      button = Pin(17, Pin.IN, pull= Pin.PULL_DOWN)

3. **Event Handling**

   Die Events ``when_activated`` und ``when_deactivated`` werden mit den Methoden ``high()`` und ``low()`` der LED verknüpft. Dadurch leuchtet die LED, wenn der Taster gedrückt wird, und geht aus, wenn er losgelassen wird.

   .. code-block:: python

       button.when_activated = led.high
       button.when_deactivated = led.low

4. **Event Loop**

   Mit der Funktion ``pause()`` bleibt das Programm aktiv und wartet auf Taster-Ereignisse.

   .. code-block:: python

       pause()

----------------------------------------------

**Troubleshooting**

1. **LED leuchtet nicht**  

   - **Ursache**: Falsche GPIO-Verbindung oder LED falsch angeschlossen.  
   - **Lösung**: Sicherstellen, dass die Anode der LED an GPIO22 und die Kathode über einen Widerstand an Masse angeschlossen ist.  

2. **Tastendruck hat keine Wirkung**  

   - **Ursache**: Fehlerhafte Tasterverdrahtung oder falsche GPIO-Konfiguration.  
   - **Lösung**: Prüfen Sie, ob der Taster korrekt zwischen GPIO17 und GND angeschlossen ist.  

3. **LED bleibt dauerhaft an oder aus**  

   - **Ursache**: Das Taster-Event wird nicht korrekt ausgelöst.  
   - **Lösung**: Testen Sie den Taster separat, z. B. mit einem Multimeter oder einer einfachen Schaltung.

**Extendable Ideas**

1. **LED-Zustand umschalten**  

   Ändern Sie das Skript so, dass die LED bei jedem Tastendruck ihren Zustand wechselt:

   .. code-block:: python
    
      def toggle():
         if led.value() == 1:
            led.off()
         else:
            led.on()

      button.when_activated = toggle

2. **Mehrere LEDs**  

   Steuern Sie mehrere LEDs mit einem einzigen Taster und schalten Sie zwischen verschiedenen Mustern um:

   .. code-block:: python

      leds = [LED(17), LED(27), LED(22)]
      current_led = 0

      def cycle_leds():
         global current_led
         leds[current_led].off()
         current_led = (current_led + 1) % len(leds)
         leds[current_led].on()

      button.when_activated = cycle_leds

3. **Unterscheidung nach Tastdauer**  

   Führen Sie verschiedene Aktionen abhängig davon aus, wie lange der Taster gedrückt gehalten wird:

   .. code-block:: python

      from time import time

      press_time = None

      def start_timer():
         global press_time
         press_time = time()

      def check_duration():
         global press_time
         duration = time() - press_time
         if duration < 2:
            led.on()
         else:
            led.off()

      button.when_activated = start_timer
      button.when_deactivated = check_duration

4. **Entprellen (Debouncing)**  

   Implementieren Sie eine Software-Entprellung, um Tastendrücke zuverlässiger zu erfassen:

   .. code-block:: python

      from time import time

      press_time = None
      debounce_time = 0.2

      def press():
         global press_time
         press_time = time()

      def debounce():
         global press_time
         current_time = time()
         duration = current_time - press_time
         if duration < debounce_time:
            return
         else:
            led.on()

      button.when_activated = press
      button.when_deactivated = debounce
