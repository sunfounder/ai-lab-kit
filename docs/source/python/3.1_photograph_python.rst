3.1 拍照模块
============

**简介**

本项目将介绍如何使用树莓派摄像头模块拍摄照片。摄像头模块可以拍摄高质量静态图像和视频，使其成为从摄影到计算机视觉等多种项目的多功能工具。

**实验步骤**

#. 为方便使用摄像头模块，建议先\ :ref:`assemble_fusion_hat_pan_tilt`\ 。

   .. note::

     安装云台可能会遮挡部分引脚，因此建议仅在使用摄像头时安装，或在安装后将其置于外侧。


   .. image:: ../quick_start/img/gimbal_assemble.png

#. 访问树莓派桌面：

   * :ref:`remote_desktop`：使用\ **VNC**\ 获得完整的桌面体验。
   * |link_rpi_connect|：使用\ **Raspberry Pi Connect**\ 从任何浏览器安全地访问树莓派。

#. 打开终端并进入代码文件夹：

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. 运行脚本启动摄像头：

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 3.1_Photograph.py

#. 脚本启动后，按下\ **Fusion HAT+ USR 按钮**\ 拍照。

   .. image:: img/3.1_user_button.png
      :width: 50%

   * 每次按下按钮拍摄一张照片。
   * 照片保存至 ``~/user/Pictures`` 目录，文件名为 ``my_photo.jpg``。
   * 按 ``Ctrl+C`` 停止脚本。

   .. image:: img/3.1_take_photo.jpg
      :width: 70%

.. note::
   QT 预览需要桌面环境。
   如果无法启动预览（例如通过 SSH 连接），
   摄像头仍可正常拍摄和保存照片。

**代码**

以下是本项目使用的 Python 代码：

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   import os, time, pwd
   from picamera2 import Picamera2, Preview
   from fusion_hat.user_button import UserButton

   u = os.getenv("SUDO_USER")
   home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
   os.makedirs(f"{home}/Pictures", exist_ok=True)
   photo = f"{home}/Pictures/my_photo.jpg"

   camera = Picamera2()
   camera.configure(camera.create_preview_configuration())

   def shot():
      camera.capture_file(photo)
      print(f"Saved: {photo}")

   UserButton().set_on_click(shot)

   # Start preview only when a GUI display is available
   preview_started = False
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception as e:
         print(f"Preview disabled: {e}")

   camera.start()
   print("Press USR to take photo. Ctrl+C to exit.")
   try:
      while True: time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      try: camera.stop()
      except: pass
      if preview_started:
         try: camera.stop_preview()
         except: pass
      try: camera.close()
      except: pass


----------------------------------------------

**理解代码**

1. **导入与目的**

   .. code-block:: python

      import os, time, pwd
      from picamera2 import Picamera2, Preview
      from fusion_hat.user_button import UserButton

   这些模块提供以下功能：

   - ``os`` 和 ``pwd``：用于正确查找真实用户的主目录，
     即使在程序使用 ``sudo`` 运行时也能正常工作。
   - ``time``：保持程序在循环中运行。
   - ``Picamera2`` 和 ``Preview``：控制树莓派摄像头和预览模式。
   - ``UserButton``：读取 Fusion HAT+ USR 按钮。

2. **解析保存路径**

   .. code-block:: python

      u = os.getenv("SUDO_USER")
      home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
      os.makedirs(f"{home}/Pictures", exist_ok=True)
      photo = f"{home}/Pictures/my_photo.jpg"

   此部分确定照片的保存位置：

   - 如果脚本使用 ``sudo`` 运行，则使用 ``SUDO_USER`` 查找
     原始用户的主目录。
   - 否则，使用当前用户的主目录。
   - 如果 ``Pictures`` 文件夹不存在，则自动创建。
   - 所有照片保存为 ``my_photo.jpg``（每张新照片会覆盖上一张）。

3. **摄像头初始化**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration())

   创建摄像头对象并使用默认预览配置进行设置。
   此配置在有或没有可见预览窗口的情况下均可工作。

4. **拍照功能**

   .. code-block:: python

      def shot():
          camera.capture_file(photo)
          print(f"Saved: {photo}")

   每当按下 USR 按钮时调用此函数。
   它拍摄一张照片并保存到预定义路径，然后打印
   保存位置。

5. **USR 按钮绑定**

   .. code-block:: python

      UserButton().set_on_click(shot)

   Fusion HAT+ USR 按钮与 ``shot`` 函数关联。
   每次按钮按下触发一次拍照。

6. **条件预览启动**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception as e:
              print(f"Preview disabled: {e}")

   - 程序检查图形化显示是否可用。
   - 如果存在显示器，则尝试启动 QT 预览窗口。
   - 如果显示器不可用（例如通过 SSH 运行时），
     则跳过预览，不停止程序。

7. **摄像头启动与主循环**

   .. code-block:: python

      camera.start()
      print("Press USR to take photo. Ctrl+C to exit.")

      try:
          while True:
              time.sleep(0.1)

   摄像头启动，程序进入无限循环以保持运行并监听按钮按下。

8. **安全退出与资源清理**

   .. code-block:: python

      except KeyboardInterrupt:
          pass
      finally:
          try: camera.stop()
          except: pass
          if preview_started:
              try: camera.stop_preview()
              except: pass
          try: camera.close()
          except: pass

   按下 ``Ctrl+C`` 时：

   - 停止摄像头。
   - 仅在预览已成功启动时才停止预览。
   - 干净地释放摄像头资源。

   无论是否使用了预览窗口，这都能确保程序无错误信息地退出。

-------------------------

**故障排除**


1. **无预览窗口**

   - **原因：** 未启用摄像头、缺少显示器或未安装 Picamera2。
   - **解决方法：** 在有显示器的系统上运行（非纯 SSH），并用简单脚本测试 Picamera2。

2. **USR 按钮不工作**

   - **原因：** Fusion HAT+ 未正确安装、按钮未被检测到或检查了错误的照片文件夹。
   - **解决方法：** 重新连接 HAT，使用 ``sudo`` 运行脚本，并检查 ``~/Pictures`` 下的照片。

3. **照片保存到错误位置**

   - **原因：** 使用 ``sudo`` 运行可能会混淆主目录。
   - **解决方法：** 脚本已处理此问题；如果不确定可打印 ``REAL_USER`` 或 ``PICTURES_DIR``。

4. **预览卡死**

   - **原因：** 摄像头被其他应用程序使用或系统资源不足。
   - **解决方法：** 关闭其他应用程序、更新系统或重启树莓派。

--------------

**总结**

本脚本让您可以使用 Fusion HAT+ USR 按钮拍摄照片，并自动保存到 ``~/Pictures`` 目录。
此设置非常适合简单的摄像头项目，并可扩展用于延时摄影、DIY 相机搭建或课堂演示。
