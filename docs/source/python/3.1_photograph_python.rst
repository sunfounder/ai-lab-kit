3.1 Modulo Fotografia
==========================

**Introduzione**

Questo progetto ti introduce all'uso del modulo telecamera del Raspberry Pi per catturare una fotografia. Il modulo telecamera può scattare immagini fisse e video di alta qualità, rendendolo uno strumento versatile per progetti che spaziano dalla fotografia alla visione artificiale.

**Procedure Sperimentali**

#. Per usare il modulo telecamera comodamente, si consiglia :ref:`assemble_fusion_hat_pan_tilt`.

   .. note::

     L'assemblaggio del pan-tilt potrebbe oscurare alcuni pin, quindi si consiglia di assemblarlo solo quando si usa la telecamera, o di posizionarlo all'esterno dopo l'assemblaggio.


   .. image:: ../quick_start/img/gimbal_assemble.png

#. Accedi al Desktop del Raspberry Pi:

   * :ref:`remote_desktop`: Usa **VNC** per un'esperienza desktop completa.
   * |link_rpi_connect|: Usa **Raspberry Pi Connect** per accedere al tuo Pi in modo sicuro da qualsiasi browser.

#. Apri un Terminale e vai alla cartella del codice:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. Esegui lo script per avviare la telecamera:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 3.1_Photograph.py

#. Dopo l'avvio dello script, premi il **pulsante USR di Fusion HAT+** per scattare foto.

   .. image:: img/3.1_user_button.png
      :width: 50%

   * Ogni pressione cattura una foto.
   * Le foto vengono salvate in ``~/user/Pictures`` come ``my_photo.jpg``.
   * Premi ``Ctrl+C`` per fermare lo script.

   .. image:: img/3.1_take_photo.jpg
      :width: 70%

.. note::
   L'anteprima QT richiede un ambiente desktop.
   Se l'anteprima non può essere avviata (ad esempio, tramite SSH),
   la telecamera può comunque catturare e salvare le foto normalmente.

**Codice**

Qui sotto c'è il codice Python usato per questo progetto:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   import os, time, pwd
   from picamera2 import Picamera2, Preview
   from fusion_hat.user_button import UserButton

   u = os.getenv("SUDO_USER")
   home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
   os.makedirs(f"{home}/Pictures", exist_ok=True)
   photo = f"{home}/Pictures/my_photo.jpg"

   camera = Picamera2()
   camera.configure(camera.create_preview_configuration())

   def shot():
      camera.capture_file(photo)
      print(f"Saved: {photo}")

   UserButton().set_on_click(shot)

   # Start preview only when a GUI display is available
   preview_started = False
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception as e:
         print(f"Preview disabled: {e}")

   camera.start()
   print("Press USR to take photo. Ctrl+C to exit.")
   try:
      while True: time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      try: camera.stop()
      except: pass
      if preview_started:
         try: camera.stop_preview()
         except: pass
      try: camera.close()
      except: pass


----------------------------------------------

**Comprendere il Codice**

1. **Importazioni e Scopo**

   .. code-block:: python

      import os, time, pwd
      from picamera2 import Picamera2, Preview
      from fusion_hat.user_button import UserButton

   Questi moduli forniscono:

   - ``os`` e ``pwd``: usati per individuare correttamente la directory home dell'utente reale, anche quando il programma viene eseguito con ``sudo``.
   - ``time``: mantiene il programma in esecuzione in un ciclo.
   - ``Picamera2`` e ``Preview``: controllano la telecamera del Raspberry Pi e le modalità di anteprima.
   - ``UserButton``: legge il pulsante USR di Fusion HAT+.

2. **Risoluzione del Percorso di Salvataggio**

   .. code-block:: python

      u = os.getenv("SUDO_USER")
      home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
      os.makedirs(f"{home}/Pictures", exist_ok=True)
      photo = f"{home}/Pictures/my_photo.jpg"

   Questa sezione determina dove vengono salvate le foto:

   - Se lo script viene eseguito con ``sudo``, ``SUDO_USER`` viene usato per trovare la directory home dell'utente originale.
   - Altrimenti, viene usata la directory home dell'utente corrente.
   - Una cartella ``Pictures`` viene creata se non esiste già.
   - Tutte le foto vengono salvate come ``my_photo.jpg`` (ogni nuova foto sovrascrive l'ultima).

3. **Inizializzazione della Telecamera**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration())

   L'oggetto telecamera viene creato e configurato con un'impostazione di anteprima predefinita. Questa configurazione funziona sia con che senza una finestra di anteprima visibile.

4. **Funzione di Acquisizione Foto**

   .. code-block:: python

      def shot():
          camera.capture_file(photo)
          print(f"Saved: {photo}")

   Questa funzione viene chiamata ogni volta che viene premuto il pulsante USR. Acquisisce una foto e la salva nel percorso predefinito, poi stampa la posizione di salvataggio.

5. **Collegamento del Pulsante USR**

   .. code-block:: python

      UserButton().set_on_click(shot)

   Il pulsante USR di Fusion HAT+ viene collegato alla funzione ``shot``. Ogni pressione del pulsante attiva l'acquisizione di una foto.

6. **Avvio Condizionale dell'Anteprima**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception as e:
              print(f"Preview disabled: {e}")

   - Il programma verifica se è disponibile un display grafico.
   - Se esiste un display, tenta di avviare una finestra di anteprima QT.
   - Se non è disponibile un display (ad esempio, quando si esegue tramite SSH), l'anteprima viene saltata senza fermare il programma.

7. **Avvio della Telecamera e Ciclo Principale**

   .. code-block:: python

      camera.start()
      print("Press USR to take photo. Ctrl+C to exit.")

      try:
          while True:
              time.sleep(0.1)

   La telecamera viene avviata e il programma entra in un ciclo infinito per rimanere in esecuzione e ascoltare le pressioni del pulsante.

8. **Uscita Pulita e Pulizia delle Risorse**

   .. code-block:: python

      except KeyboardInterrupt:
          pass
      finally:
          try: camera.stop()
          except: pass
          if preview_started:
              try: camera.stop_preview()
              except: pass
          try: camera.close()
          except: pass

   Quando viene premuto ``Ctrl+C``:

   - La telecamera viene fermata.
   - L'anteprima viene fermata solo se era stata avviata con successo.
   - Le risorse della telecamera vengono rilasciate in modo pulito.

   Questo assicura che il programma esca senza messaggi di errore, indipendentemente dal fatto che sia stata usata una finestra di anteprima.

-------------------------

**Risoluzione dei Problemi**


1. **Nessuna Finestra di Anteprima**

   - **Causa:** Telecamera non abilitata, display mancante o Picamera2 non installato.
   - **Soluzione:** Esegui su un sistema con display (non solo SSH) e testa Picamera2 con uno script semplice.

2. **Il Pulsante USR Non Funziona**

   - **Causa:** Fusion HAT+ non inserito correttamente, pulsante non rilevato o cartella foto errata controllata.
   - **Soluzione:** Ricollega HAT, esegui lo script con ``sudo`` e controlla le foto in ``~/Pictures``.

3. **Foto Salvate nella Posizione Sbagliata**

   - **Causa:** L'esecuzione con ``sudo`` potrebbe confondere le directory home.
   - **Soluzione:** Lo script gestisce già questo; stampa ``REAL_USER`` o ``PICTURES_DIR`` in caso di dubbi.

4. **L'Anteprima si Blocca**

   - **Causa:** Telecamera in uso da un'altra app o risorse di sistema insufficienti.
   - **Soluzione:** Chiudi altre app, aggiorna il sistema o riavvia il Pi.

--------------

**Conclusione**

Questo script ti permette di catturare foto usando il pulsante USR di Fusion HAT+ e salvarle automaticamente in ``~/Pictures``.
La configurazione è ideale per progetti fotografici semplici e può essere estesa per timelapse, costruzioni fotografiche fai-da-te o dimostrazioni in classe.
