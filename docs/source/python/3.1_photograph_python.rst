3.1 Módulo de Fotografía
==========================

**Introducción**

Este proyecto te introduce al uso del módulo de cámara Raspberry Pi para capturar una fotografía. El módulo de cámara puede tomar imágenes fijas y videos de alta calidad, lo que lo convierte en una herramienta versátil para proyectos que van desde la fotografía hasta la visión artificial.

**Procedimientos Experimentales**

#. Para usar el módulo de cámara de forma conveniente, se recomienda :ref:`assemble_fusion_hat_pan_tilt`.

   .. note::

     El montaje del pan-tilt puede obstruir algunos pines, por lo que se recomienda ensamblarlo solo cuando se use la cámara, o colocarlo en la parte exterior después del montaje.


   .. image:: ../quick_start/img/gimbal_assemble.png

#. Accede al escritorio de Raspberry Pi:

   * :ref:`remote_desktop`: Usa **VNC** para una experiencia de escritorio completa.
   * |link_rpi_connect|: Usa **Raspberry Pi Connect** para acceder a tu Pi de forma segura desde cualquier navegador.

#. Abre una Terminal y dirígete a la carpeta de código:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. Ejecuta el script para iniciar la cámara:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 3.1_Photograph.py

#. Después de que el script se inicie, presiona el **botón USR de Fusion HAT+** para tomar fotos.

   .. image:: img/3.1_user_button.png
      :width: 50%

   * Cada pulsación captura una imagen.
   * Las fotos se guardan en ``~/user/Pictures`` como ``my_photo.jpg``.
   * Presiona ``Ctrl+C`` para detener el script.

   .. image:: img/3.1_take_photo.jpg
      :width: 70%

.. note::
   La vista previa QT requiere un entorno de escritorio.
   Si la vista previa no se puede iniciar (por ejemplo, a través de SSH),
   la cámara aún puede capturar y guardar fotos con normalidad.

**Código**

A continuación se muestra el código Python utilizado para este proyecto:

.. raw:: html

   <run></run>
   
.. code-block:: python

   #!/usr/bin/env python3
   import os, time, pwd
   from picamera2 import Picamera2, Preview
   from fusion_hat.user_button import UserButton

   u = os.getenv("SUDO_USER")
   home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
   os.makedirs(f"{home}/Pictures", exist_ok=True)
   photo = f"{home}/Pictures/my_photo.jpg"

   camera = Picamera2()
   camera.configure(camera.create_preview_configuration())

   def shot():
      camera.capture_file(photo)
      print(f"Saved: {photo}")

   UserButton().set_on_click(shot)

   # Start preview only when a GUI display is available
   preview_started = False
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception as e:
         print(f"Preview disabled: {e}")

   camera.start()
   print("Press USR to take photo. Ctrl+C to exit.")
   try:
      while True: time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      try: camera.stop()
      except: pass
      if preview_started:
         try: camera.stop_preview()
         except: pass
      try: camera.close()
      except: pass


----------------------------------------------

**Comprender el Código**

1. **Importaciones y Propósito**

   .. code-block:: python

      import os, time, pwd
      from picamera2 import Picamera2, Preview
      from fusion_hat.user_button import UserButton

   Estos módulos proporcionan lo siguiente:

   - ``os`` y ``pwd``: se usan para localizar correctamente el directorio principal del usuario real,
     incluso cuando el programa se ejecuta con ``sudo``.
   - ``time``: mantiene el programa ejecutándose en un bucle.
   - ``Picamera2`` y ``Preview``: controlan la cámara Raspberry Pi y los modos de vista previa.
   - ``UserButton``: lee el botón USR de Fusion HAT+.

2. **Resolución de la Ruta de Guardado**

   .. code-block:: python

      u = os.getenv("SUDO_USER")
      home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
      os.makedirs(f"{home}/Pictures", exist_ok=True)
      photo = f"{home}/Pictures/my_photo.jpg"

   Esta sección determina dónde se guardan las fotos:

   - Si el script se ejecuta con ``sudo``, se usa ``SUDO_USER`` para encontrar el
     directorio principal del usuario original.
   - De lo contrario, se usa el directorio principal del usuario actual.
   - Se crea una carpeta ``Pictures`` si aún no existe.
   - Todas las fotos se guardan como ``my_photo.jpg`` (cada nueva foto sobrescribe la anterior).

3. **Inicialización de la Cámara**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration())

   Se crea y configura el objeto de la cámara con una configuración de vista previa predeterminada.
   Esta configuración funciona tanto con una ventana de vista previa visible como sin ella.

4. **Función de Captura de Foto**

   .. code-block:: python

      def shot():
          camera.capture_file(photo)
          print(f"Saved: {photo}")

   Esta función se llama cada vez que se presiona el botón USR.
   Captura una foto y la guarda en la ruta predefinida, luego imprime
   la ubicación de guardado.

5. **Vinculación del Botón USR**

   .. code-block:: python

      UserButton().set_on_click(shot)

   El botón USR de Fusion HAT+ está vinculado a la función ``shot``.
   Cada pulsación del botón activa una captura de foto.

6. **Inicio Condicional de la Vista Previa**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception as e:
              print(f"Preview disabled: {e}")

   - El programa verifica si hay una pantalla gráfica disponible.
   - Si existe una pantalla, intenta iniciar una ventana de vista previa QT.
   - Si no hay pantalla disponible (por ejemplo, al ejecutarse a través de SSH),
     la vista previa se omite sin detener el programa.

7. **Inicio de la Cámara y Bucle Principal**

   .. code-block:: python

      camera.start()
      print("Press USR to take photo. Ctrl+C to exit.")

      try:
          while True:
              time.sleep(0.1)

   La cámara se inicia y el programa entra en un bucle infinito para
   mantenerse ejecutándose y escuchando las pulsaciones de botones.

8. **Salida Limpia y Liberación de Recursos**

   .. code-block:: python

      except KeyboardInterrupt:
          pass
      finally:
          try: camera.stop()
          except: pass
          if preview_started:
              try: camera.stop_preview()
              except: pass
          try: camera.close()
          except: pass

   Cuando se presiona ``Ctrl+C``:

   - La cámara se detiene.
   - La vista previa se detiene solo si se inició correctamente.
   - Los recursos de la cámara se liberan limpiamente.

   Esto garantiza que el programa termine sin mensajes de error,
   independientemente de si se usó una ventana de vista previa.

-------------------------

**Solución de Problemas**


1. **Sin Ventana de Vista Previa**

   - **Causa:** Cámara no habilitada, pantalla faltante o Picamera2 no instalado.
   - **Solución:** Ejecuta en un sistema con pantalla (no solo SSH) y prueba Picamera2 con un script simple.

2. **El Botón USR No Funciona**

   - **Causa:** Fusion HAT+ no está bien colocado, el botón no se detecta o se revisó la carpeta de fotos incorrecta.
   - **Solución:** Vuelve a conectar el HAT, ejecuta el script con ``sudo`` y verifica las fotos en ``~/Pictures``.

3. **Fotos Guardadas en la Ubicación Incorrecta**

   - **Causa:** Ejecutar con ``sudo`` puede confundir los directorios principales.
   - **Solución:** El script ya maneja esto; imprime ``REAL_USER`` o ``PICTURES_DIR`` si no estás seguro.

4. **La Vista Previa se Congela**

   - **Causa:** Cámara en uso por otra aplicación o recursos bajos del sistema.
   - **Solución:** Cierra otras aplicaciones, actualiza el sistema o reinicia la Pi.

--------------

**Conclusión**

Este script te permite capturar fotos usando el botón USR de Fusion HAT+ y guardarlas automáticamente en ``~/Pictures``.
La configuración es ideal para proyectos simples de cámara y se puede ampliar para time-lapses, construcciones de cámaras DIY o demostraciones en clase.
