3.1 Module Photographie
==============================

**Introduction**

Ce projet vous initie a l’utilisation du module camera Raspberry Pi pour prendre une photographie. Le module camera peut capturer des images fixes et des videos de haute qualite, ce qui en fait un outil polyvalent pour des projets allant de la photographie a la vision par ordinateur.

#. Accedez au bureau Raspberry Pi :

   * :ref:`remote_desktop` : Utilisez **VNC** pour une experience de bureau complete.
   * |link_rpi_connect| : Utilisez **Raspberry Pi Connect** pour acceder a votre Pi en toute securite depuis n’importe quel navigateur.

#. Ouvrez un terminal et rendez-vous dans le dossier des codes :

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. Executez le script pour demarrer la camera :

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 3.1_Photograph.py

#. Apres le demarrage du script, appuyez sur le **bouton USR du Fusion HAT+** pour prendre des photos.

   .. image:: img/3.1_user_button.png
      :width: 50%

   * Chaque pression capture une image.
   * Les photos sont enregistrees dans ``~/user/Pictures`` sous le nom ``my_photo.jpg``.
   * Appuyez sur ``Ctrl+C`` pour arreter le script.

   .. image:: img/3.1_take_photo.jpg
      :width: 70%

.. note::
   L’apercu QT necessite un environnement de bureau.
   Si l’apercu ne peut pas etre lance (par exemple, via SSH),
   la camera peut toujours capturer et enregistrer des photos normalement.

**Code**

Voici le code Python utilise pour ce projet :

.. raw:: html

   <run></run>
   
.. code-block:: python

   #!/usr/bin/env python3
   import os, time, pwd
   from picamera2 import Picamera2, Preview
   from fusion_hat.user_button import UserButton

   u = os.getenv("SUDO_USER")
   home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
   os.makedirs(f"{home}/Pictures", exist_ok=True)
   photo = f"{home}/Pictures/my_photo.jpg"

   camera = Picamera2()
   camera.configure(camera.create_preview_configuration())

   def shot():
      camera.capture_file(photo)
      print(f"Saved: {photo}")

   UserButton().set_on_click(shot)

   # Start preview only when a GUI display is available
   preview_started = False
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception as e:
         print(f"Preview disabled: {e}")

   camera.start()
   print("Press USR to take photo. Ctrl+C to exit.")
   try:
      while True: time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      try: camera.stop()
      except: pass
      if preview_started:
         try: camera.stop_preview()
         except: pass
      try: camera.close()
      except: pass


----------------------------------------------

**Comprendre le code**

1. **Importations et objectif**

   .. code-block:: python

      import os, time, pwd
      from picamera2 import Picamera2, Preview
      from fusion_hat.user_button import UserButton

   Ces modules fournissent :

   - ``os`` et ``pwd`` : utilises pour localiser correctement le repertoire personnel de l’utilisateur reel,
     meme lorsque le programme est execute avec ``sudo``.
   - ``time`` : maintient le programme en execution dans une boucle.
   - ``Picamera2`` et ``Preview`` : controlent la camera Raspberry Pi et les modes d’apercu.
   - ``UserButton`` : lit le bouton USR du Fusion HAT+.

2. **Resolution du chemin de sauvegarde**

   .. code-block:: python

      u = os.getenv("SUDO_USER")
      home = pwd.getpwnam(u).pw_dir if u else os.path.expanduser("~")
      os.makedirs(f"{home}/Pictures", exist_ok=True)
      photo = f"{home}/Pictures/my_photo.jpg"

   Cette section determine ou les photos sont enregistrees :

   - Si le script est execute avec ``sudo``, ``SUDO_USER`` est utilise pour trouver le
     repertoire personnel de l’utilisateur d’origine.
   - Sinon, le repertoire personnel de l’utilisateur actuel est utilise.
   - Un dossier ``Pictures`` est cree s’il n’existe pas deja.
   - Toutes les photos sont enregistrees sous ``my_photo.jpg`` (chaque nouvelle photo ecrase la precedente).

3. **Initialisation de la camera**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration())

   L’objet camera est cree et configure avec une configuration d’apercu par defaut.
   Cette configuration fonctionne avec ou sans fenetre d’apercu visible.

4. **Fonction de capture photo**

   .. code-block:: python

      def shot():
          camera.capture_file(photo)
          print(f"Saved: {photo}")

   Cette fonction est appelee chaque fois que le bouton USR est presse.
   Elle capture une photo et l’enregistre dans le chemin predefini, puis affiche
   l’emplacement de sauvegarde.

5. **Liaison du bouton USR**

   .. code-block:: python

      UserButton().set_on_click(shot)

   Le bouton USR du Fusion HAT+ est lie a la fonction ``shot``.
   Chaque pression sur le bouton declenche une capture photo.

6. **Demarrage conditionnel de l’apercu**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception as e:
              print(f"Preview disabled: {e}")

   - Le programme verifie si un affichage graphique est disponible.
   - Si un affichage existe, il tente de demarrer une fenetre d’apercu QT.
   - Si aucun affichage n’est disponible (par exemple, lors d’une connexion via SSH),
     l’apercu est ignore sans arreter le programme.

7. **Demarrage de la camera et boucle principale**

   .. code-block:: python

      camera.start()
      print("Press USR to take photo. Ctrl+C to exit.")

      try:
          while True:
              time.sleep(0.1)

   La camera est demarree et le programme entre dans une boucle infinie pour
   rester actif et ecouter les pressions sur le bouton.

8. **Sortie propre et nettoyage des ressources**

   .. code-block:: python

      except KeyboardInterrupt:
          pass
      finally:
          try: camera.stop()
          except: pass
          if preview_started:
              try: camera.stop_preview()
              except: pass
          try: camera.close()
          except: pass

   Lorsque ``Ctrl+C`` est presse :

   - La camera est arretee.
   - L’apercu est arrete seulement s’il a ete demarre avec succes.
   - Les ressources de la camera sont liberees proprement.

   Cela garantit que le programme se termine sans messages d’erreur, independamment
   de l’utilisation ou non d’une fenetre d’apercu.

-------------------------

**Depannage**


1. **Pas de fenetre d’apercu**

   - **Cause :** Camera non activee, affichage manquant ou Picamera2 non installe.
   - **Solution :** Executez sur un systeme avec un affichage (pas uniquement SSH) et testez Picamera2 avec un script simple.

2. **Le bouton USR ne fonctionne pas**

   - **Cause :** Fusion HAT+ mal insere, bouton non detecte ou mauvais dossier de photos consulte.
   - **Solution :** Reconnectez le HAT, executez le script avec ``sudo`` et verifiez les photos dans ``~/Pictures``.

3. **Photos enregistrees au mauvais endroit**

   - **Cause :** L’execution avec ``sudo`` peut perturber les repertoires personnels.
   - **Solution :** Le script gere deja cela ; imprimez ``REAL_USER`` ou ``PICTURES_DIR`` en cas de doute.

4. **L’apercu se fige**

   - **Cause :** Camera utilisee par une autre application ou ressources systeme insuffisantes.
   - **Solution :** Fermez les autres applications, mettez a jour le systeme ou redemarrez le Pi.

--------------

**Conclusion**

Ce script vous permet de capturer des photos a l’aide du bouton USR du Fusion HAT+ et de les enregistrer automatiquement dans ``~/Pictures``.
La configuration est ideale pour des projets de camera simples et peut etre etendue pour des timelapses, des constructions de camera DIY ou des demonstrations en classe.
