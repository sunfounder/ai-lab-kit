1.2.2 Passiver Summer
===========================

**Introduction**

In diesem Projekt lernen wir, wie ein passiver Summer über unterschiedliche Frequenzen angesteuert wird, um Melodien zu erzeugen. Im Gegensatz zu aktiven Summern benötigen passive Summer ein externes Signal, um Töne auszugeben.

**Circuit Diagram**

Die Schaltung verwendet einen passiven Summer, einen NPN-Transistor und einen 1-kΩ-Widerstand. Der Widerstand schützt den Transistor vor zu hohem Basisstrom. Durch Variation der Frequenz am mit dem Transistor verbundenen GPIO-Pin erzeugt der Summer unterschiedliche Töne – so lassen sich Melodien abspielen.

.. image:: img/fzz/1.2.2_sch.png


----------------------------------------------

**Wiring Diagram**

Gehen Sie wie folgt vor, um die Schaltung aufzubauen:

1. Verbinden Sie die Basis des NPN-Transistors über den Widerstand mit PWM0.  
2. Verbinden Sie den Emitter des Transistors mit der Stromversorgung (+).  
3. Schließen Sie den Kollektor des Transistors an einen Anschluss des passiven Summers an.  
4. Verbinden Sie den anderen Anschluss des Summers mit Masse (-).

**Writing the Code**

Der folgende Python-Code erzeugt über einen passiven Summer musikalische Noten:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Buzzer,PWM
   from time import sleep

   # Initialize a TonalBuzzer connected to PWM 0
   tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

   print("test")

   def play(tune):
      """
      Play a musical tune using the buzzer.
      :param tune: List of tuples (note, duration), where each tuple represents a note and its duration.
      """
      for note, duration in tune:
         print(note)  # Output the current note being played
         tb.play(note,float(duration))  # Play the note on the buzzer
      tb.off()  # Stop playing after the tune is complete

   # Define a musical tune as a sequence of notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('C4', 0.2), ('B4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
      ('A4', 0.2), ('G4', 0.2), ('E4', 0.2), 
      ('D4', 0.2), ('E4', 0.2)]


   try:
      play(tune)  # Execute the play function to start playing the tune

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt for graceful termination
      pass


Dieses Python-Skript spielt über einen an PWM0 angeschlossenen passiven Summer eine Melodie ab. Beim Ausführen gilt:

1. Das Skript iteriert durch eine vordefinierte Folge musikalischer Noten (``tune``) und spielt jede Note für die angegebene Dauer.  
2. Die jeweils gespielte Note wird zur Kontrolle in der Konsole ausgegeben.  
3. Nach dem letzten Eintrag endet die Wiedergabe automatisch; bei Pausen (``None``) bleibt der Summer stumm.  
4. Das Programm kann jederzeit mit ``Ctrl+C`` sauber beendet werden.


----------------------------------------------

**Understanding the Code**

1. **Library Import**

   Die Klasse ``Buzzer`` aus ``fusion_hat`` erzeugt Töne, ``time.sleep`` steuert die Notendauern.

   .. code-block:: python

      from fusion_hat import Buzzer,PWM
      from time import sleep

2. **Buzzer Initialization**

   Der ``Buzzer`` wird zur Tongenerierung mit PWM0 verknüpft.

   .. code-block:: python

      # Initialize a TonalBuzzer connected to PWM 0
      tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

3. **Playing Notes**

   Die Funktion ``play`` durchläuft eine Liste aus Tupeln (Note, Dauer), spielt jede Note und schaltet danach ab.

   .. code-block:: python

      def play(tune):
         for note, duration in tune:
            print(note)  # Output the current note being played
            tb.play(note,float(duration))  # Play the note on the buzzer
         tb.off()  # Stop playing after the tune is complete

4. **Tune Definition**

   ``tune`` enthält die Abfolge von Noten (z. B. 'C#4') und Dauerangaben (z. B. 0,2 Sekunden).

   .. code-block:: python

       tune = [
           ('C#4', 0.2), ('D4', 0.2), (None, 0.2),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('C4', 0.2), ('B4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
           ('A4', 0.2), ('G4', 0.2), ('E4', 0.2), 
           ('D4', 0.2), ('E4', 0.2)
       ]

5. **Keyboard Interrupt Handling**

   Ein ``try-except``-Block sorgt für ein sauberes Beenden bei Unterbrechung (z. B. ``Ctrl+C``).

   .. code-block:: python

       try:
           play(tune)
       except KeyboardInterrupt:
           pass



----------------------------------------------

**Troubleshooting**

1. **Kein Ton aus dem Summer**  

   - **Ursache**: Falsche GPIO-Zuordnung oder inkompatibler Summer.  
   - **Lösung**: Stellen Sie sicher, dass der Ton-Summer an PWM0 angeschlossen ist.

2. **Unterbrechungen oder stotternder Klang**  

   - **Ursache**: Unstimmigkeiten bei den Wartezeiten (``sleep()``).  
   - **Lösung**: Prüfen Sie die Dauerangaben in ``tune`` und passen Sie sie für gleichmäßige Übergänge an.

**Extendable Ideas**

1. **Eigene Melodien**  

   Erlauben Sie die Eingabe einer eigenen Notenfolge samt Dauern:

   .. code-block:: python

      user_tune = []
      while True:
         note = input("Enter a note (or 'stop' to finish): ")
         if note.lower() == 'stop':
            break
         duration = float(input("Enter duration for the note: "))
         user_tune.append((note, duration))
      play(user_tune)


2. **Mehrere Melodien**  

   Hinterlegen Sie vordefinierte Melodien und lassen Sie die Nutzenden wählen:

   .. code-block:: python

      tunes = {
         "tune1": [('C4', 0.5), ('D4', 0.5), (None, 0.5)],
         "tune2": [('G4', 0.3), ('A4', 0.3), (None, 0.3)]
      }
      choice = input("Choose a tune (tune1/tune2): ")
      play(tunes[choice])


3. **Echtzeit-Interaktion**  

   Nutzen Sie Taster oder die Tastatur, um Noten live zu spielen – der Summer wird zum einfachen Instrument.

4. **Verkettete Melodien**  

   Mehrere Melodien automatisch hintereinander abspielen, um längere Stücke zu erzeugen.

5. **Dynamische Geschwindigkeitsanpassung**  

   Passen Sie die Abspielgeschwindigkeit zur Laufzeit an, indem Sie die Dauern skalieren:

   .. code-block:: python

      speed_factor = float(input("Enter speed factor (e.g., 1.0 for normal, 0.5 for faster): "))
      adjusted_tune = [(note, duration * speed_factor) for note, duration in tune]
      play(adjusted_tune)

----------------------------------------------

**Conclusion**

Dieses Projekt zeigt, wie ein passiver Summer zum Abspielen musikalischer Noten genutzt wird. Durch das Zusammenspiel von Hardware und Software lassen sich vielfältige Klänge und Melodien für interaktive Projekte erzeugen.
