2.11 摇杆
==========

**介绍**

摇杆是一种输入设备，常用于游戏、机器人和导航系统。它通常有两个轴（X和Y）用于方向控制，以及一个按钮（Btn或SW）用于额外输入。在本项目中，你将学习摇杆的工作原理，通过操作它并在屏幕上显示X、Y和按钮状态的相应值。

此Python脚本读取并实时显示Fusion HAT+上的摇杆数据。执行时：

1. 脚本持续从Fusion HAT+读取X和Y值。
2. 监测连接到GPIO 17引脚的按钮，检测其是否被按下。
3. X、Y和按钮状态值以\ ``X: <value>  Y: <value>  Btn: <value>``\ 的格式打印到控制台，其中：

   - ``X``\ 和\ ``Y``\ 是ADC芯片的模拟读数。
   - ``Btn``\ 在未按下时为\ ``1``\ ，按下时为\ ``0``\ 。

4. 脚本每0.2秒更新一次，持续运行直到用\ ``Ctrl+C``\ 中断。

**代码**

以下是本项目使用的Python代码：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.adc import ADC
   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # Initialize the Joystick
   BtnPin = Pin(17, mode=Mode.IN, pull=Pull.UP)
   xAxis = ADC('A1')
   yAxis = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      # Main loop to read and print ADC values and button state
      while True:
         # Read X and Y values from ADC channels
         x_val = MAP(xAxis.read(),0,4095,-100,100)
         y_val = MAP(yAxis.read(),0,4095,-100,100)

         # Read the state of the button (pressed or not)
         Btn_val = BtnPin.value()

         # Print the X, Y, and button values
         print('X: %d  Y: %d  Btn: %d' % (x_val, y_val, Btn_val))

         # Delay of 0.2 seconds before the next read
         time.sleep(0.2)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

**理解代码**

1. **导入：**

   .. code-block:: python

      from fusion_hat.adc import ADC
      from fusion_hat.pin import Pin, Mode, Pull
      import time

   脚本导入所需模块：\ ``fusion_hat``\ 用于GPIO功能，\ ``time``\ 用于添加延迟。

2. **初始化：**

   .. code-block:: python

      # Initialize the Joystick
      BtnPin = Pin(17, mode=Mode.IN, pull=Pull.UP)
      xAxis = ADC('A1')
      yAxis = ADC('A0')

   脚本通过创建\ ``Pin``\ 和\ ``ADC``\ 类的实例来初始化摇杆。按钮设置为输入模式，启用内部上拉电阻；X和Y轴分别设置为从ADC通道A1和A0读取。


3. **主循环：**

   .. code-block:: python

      try:
         # Main loop to read and print ADC values and button state
         while True:
            # Read X and Y values from ADC channels
            x_val = MAP(xAxis.read(),0,4095,-100,100)
            y_val = MAP(yAxis.read(),0,4095,-100,100)

            # Read the state of the button (pressed or not)
            Btn_val = BtnPin.value()

            # Print the X, Y, and button values
            print('X: %d  Y: %d  Btn: %d' % (x_val, y_val, Btn_val))

            # Delay of 0.2 seconds before the next read
            time.sleep(0.2)

      # Gracefully handle script termination (e.g., via KeyboardInterrupt)
      except KeyboardInterrupt:
         pass

   - 分别从ADC通道0和1读取X和Y值。
   - 读取按钮状态（按下或未按下）来自SW引脚。
   - 每0.2秒将X、Y和按钮值打印到屏幕上。

**故障排除**


1. **ADC值不在预期范围内**：

   - **原因**：ADC通道配置错误或接线问题。
   - **解决方案**：确认ADC通道配置和接线。确保摇杆连接到正确的ADC通道。

2. **按钮状态始终为0**：

   - **原因**：按钮接线或上拉/下拉配置错误。
   - **解决方案**：检查按钮接线。检查上拉/下拉配置，确保按钮正确连接到SW引脚。

3. **ADC值恒定不变**：

   - **原因**：ADC通道未连接到任何输入。
   - **解决方案**：将摇杆连接到ADC通道0和1以提供可变输入。
