2.11 Joystick
=================

**Introduction**

Un joystick est un dispositif d'entree couramment utilise pour les jeux, la robotique et les systemes de navigation. Il comporte generalement deux axes (X et Y) pour le controle directionnel et un bouton (Btn ou SW) pour une entree supplementaire. Dans ce projet, vous apprendrez comment fonctionne un joystick en le manipulant et en affichant les valeurs correspondantes des etats X, Y et du bouton a l'ecran.

Ce script Python lit et affiche les donnees du joystick en temps reel sur un Fusion HAT+. Lors de l'execution :

1. Le script lit en continu les valeurs X et Y du Fusion HAT+.
2. Il surveille le bouton connecte a la broche GPIO 17 pour detecter s'il est presse ou non.
3. Les valeurs X, Y et l'etat du bouton sont affichees sur la console au format ``X: <value>  Y: <value>  Btn: <value>``, ou :

   - ``X`` et ``Y`` sont les lectures analogiques de la puce ADC.
   - ``Btn`` est ``1`` lorsque le bouton n'est pas presse et ``0`` lorsqu'il est presse.

4. Le script se met a jour toutes les 0,2 secondes, fonctionnant en continu jusqu'a ce qu'il soit interrompu avec ``Ctrl+C``.

**Code**

Voici le code Python utilise pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.adc import ADC
   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # Initialize the Joystick
   BtnPin = Pin(17, mode=Mode.IN, pull=Pull.UP)
   xAxis = ADC('A1')
   yAxis = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      # Main loop to read and print ADC values and button state
      while True:
         # Read X and Y values from ADC channels
         x_val = MAP(xAxis.read(),0,4095,-100,100)
         y_val = MAP(yAxis.read(),0,4095,-100,100)

         # Read the state of the button (pressed or not)
         Btn_val = BtnPin.value()

         # Print the X, Y, and button values
         print('X: %d  Y: %d  Btn: %d' % (x_val, y_val, Btn_val))

         # Delay of 0.2 seconds before the next read
         time.sleep(0.2)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

   Le script importe les modules necessaires : ``fusion_hat`` pour les fonctionnalites GPIO, et ``time`` pour ajouter des pauses.

   .. code-block:: python

      xAxis = ADC('A1')
      yAxis = ADC('A0')

   Le script initialise le joystick en creant des instances des classes ``Pin`` et ``ADC``. Le bouton est configure en mode entree avec une resistance pull-up interne activee, et les axes X et Y sont configures pour lire les canaux ADC A0 et A1 respectivement.


3. **Boucle principale :**

   .. code-block:: python

   - Lit les valeurs X et Y des canaux ADC 0 et 1 respectivement.
   - Lit l'etat du bouton (presse ou non) a partir de la broche SW.

**Depannage**


1. **Valeurs ADC hors de la plage attendue** :

   - **Cause** : Configuration de canal ADC incorrecte ou problemes de cablage.
   - **Solution** : Verifiez la configuration du canal ADC et le cablage. Assurez-vous que le joystick est connecte aux canaux ADC corrects.

2. **Etat du bouton toujours a 0** :

   - **Cause** : Cablage incorrect du bouton ou configuration pull-up/pull-down.
   - **Solution** : Verifiez le cablage du bouton. Verifiez la configuration pull-up/pull-down pour vous assurer que le bouton est correctement connecte a la broche SW.

3. **Les valeurs ADC sont constantes** :

   - **Cause** : Les canaux ADC ne sont connectes a aucune entree.
   - **Solution** : Connectez les joysticks aux canaux ADC 0 et 1 pour fournir des entrees variables.
