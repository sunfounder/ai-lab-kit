2.11 Joystick
=========================

**Introducción**

Un joystick es un dispositivo de entrada comúnmente utilizado para juegos, robótica y sistemas de navegación. Típicamente tiene dos ejes (X e Y) para control direccional y un botón (Btn o SW) para entrada adicional. En este proyecto, aprenderás cómo funciona un joystick manipulándolo y mostrando los valores correspondientes de los estados X, Y y del botón en la pantalla.

Este script de Python lee y muestra datos del joystick en tiempo real en un Fusion HAT+. Al ejecutarse:

1. El script lee continuamente los valores X e Y del Fusion HAT+.
2. Monitorea el botón conectado al pin GPIO 17 para detectar si está presionado o no.
3. Los valores de X, Y y el estado del botón se imprimen en la consola en el formato ``X: <valor>  Y: <valor>  Btn: <valor>``, donde:

   - ``X`` e ``Y`` son las lecturas analógicas del chip ADC.
   - ``Btn`` es ``1`` cuando el botón no está presionado y ``0`` cuando está presionado.

4. El script se actualiza cada 0.2 segundos, ejecutándose continuamente hasta que se interrumpe con ``Ctrl+C``.

**Código**

A continuación se muestra el código Python utilizado en este proyecto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.adc import ADC
   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # Initialize the Joystick
   BtnPin = Pin(17, mode=Mode.IN, pull=Pull.UP)
   xAxis = ADC('A1')
   yAxis = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      # Main loop to read and print ADC values and button state
      while True:
         # Read X and Y values from ADC channels
         x_val = MAP(xAxis.read(),0,4095,-100,100)
         y_val = MAP(yAxis.read(),0,4095,-100,100)

         # Read the state of the button (pressed or not)
         Btn_val = BtnPin.value()

         # Print the X, Y, and button values
         print('X: %d  Y: %d  Btn: %d' % (x_val, y_val, Btn_val))

         # Delay of 0.2 seconds before the next read
         time.sleep(0.2)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

**Solución de Problemas**


1. **Los valores del ADC no están en el rango esperado**:

   - **Causa**: Configuración incorrecta del canal ADC o problemas de cableado.
   - **Solución**: Verifica la configuración del canal ADC y el cableado. Asegúrate de que el joystick esté conectado a los canales ADC correctos.

2. **El estado del botón es siempre 0**:

   - **Causa**: Cableado incorrecto del botón o configuración de pull-up/pull-down.
   - **Solución**: Verifica el cableado del botón. Revisa la configuración de pull-up/pull-down para asegurarte de que el botón esté correctamente conectado al pin SW.

3. **Los valores del ADC son constantes**:

   - **Causa**: Los canales ADC no están conectados a ninguna entrada.
   - **Solución**: Conecta el joystick a los canales ADC 0 y 1 para proporcionar entradas variables.
