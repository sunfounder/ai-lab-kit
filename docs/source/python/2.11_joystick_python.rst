2.11 Joystick
=========================

**Introduzione**

Un joystick è un dispositivo di input comunemente usato per giochi, robotica e sistemi di navigazione. Ha tipicamente due assi (X e Y) per il controllo direzionale e un pulsante (Btn o SW) per input aggiuntivi. In questo progetto, imparerai come funziona un joystick manipolandolo e visualizzando i corrispondenti valori degli stati X, Y e del pulsante sullo schermo.

Questo script Python legge e visualizza i dati del joystick in tempo reale su Fusion HAT+. Quando eseguito:

1. Lo script legge continuamente i valori X e Y da Fusion HAT+.
2. Monitora il pulsante collegato al pin GPIO 17 per rilevare se è premuto o meno.
3. I valori X, Y e lo stato del pulsante vengono stampati sulla console nel formato ``X: <value>  Y: <value>  Btn: <value>``, dove:

   - ``X`` e ``Y`` sono le letture analogiche dal chip ADC.
   - ``Btn`` è ``1`` quando il pulsante non è premuto e ``0`` quando è premuto.

4. Lo script si aggiorna ogni 0,2 secondi, funzionando continuamente fino a quando non viene interrotto con ``Ctrl+C``.

**Codice**

Qui sotto c'è il codice Python usato per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.adc import ADC
   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # Initialize the Joystick
   BtnPin = Pin(17, mode=Mode.IN, pull=Pull.UP)
   xAxis = ADC('A1')
   yAxis = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      # Main loop to read and print ADC values and button state
      while True:
         # Read X and Y values from ADC channels
         x_val = MAP(xAxis.read(),0,4095,-100,100)
         y_val = MAP(yAxis.read(),0,4095,-100,100)

         # Read the state of the button (pressed or not)
         Btn_val = BtnPin.value()

         # Print the X, Y, and button values
         print('X: %d  Y: %d  Btn: %d' % (x_val, y_val, Btn_val))

         # Delay of 0.2 seconds before the next read
         time.sleep(0.2)

   # Gracefully handle script termination (e.g., via KeyboardInterrupt)
   except KeyboardInterrupt:
      pass

1. **Importazioni:**

   .. code-block:: python

      from fusion_hat.adc import ADC
      from fusion_hat.pin import Pin, Mode, Pull
      import time

   Lo script importa i moduli necessari: ``fusion_hat`` per le funzionalità GPIO e ``time`` per aggiungere ritardi.

2. **Inizializzazione:**

   .. code-block:: python

      BtnPin = Pin(17, mode=Mode.IN, pull=Pull.UP)
      xAxis = ADC('A1')
      yAxis = ADC('A0')

   Lo script inizializza il joystick creando istanze delle classi ``Pin`` e ``ADC``. Il pulsante è impostato in modalità ingresso con un resistore pull-up interno abilitato, e gli assi X e Y sono impostati per leggere dai canali ADC A0 e A1, rispettivamente.

   - Stampa i valori X, Y e del pulsante sullo schermo ogni 0,2 secondi.

**Risoluzione dei Problemi**


1. **Valori ADC Non nell'Intervallo Previsto**:

   - **Causa**: Configurazione errata del canale ADC o problemi di cablaggio.
   - **Soluzione**: Verifica la configurazione del canale ADC e il cablaggio. Assicurati che il joystick sia collegato ai canali ADC corretti.

2. **Stato del Pulsante Sempre 0**:

   - **Causa**: Cablaggio errato del pulsante o configurazione pull-up/pull-down.
   - **Soluzione**: Verifica il cablaggio del pulsante. Controlla la configurazione pull-up/pull-down per assicurarti che il pulsante sia correttamente collegato al pin SW.

3. **Valori ADC Costanti**:

   - **Causa**: I canali ADC non sono collegati a nessun ingresso.
   - **Soluzione**: Collega i joystick ai canali ADC 0 e 1 per fornire ingressi variabili.
