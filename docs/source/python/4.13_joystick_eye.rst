4.13 Occhio Controllato da Joystick
===================================

**Introduzione**

In questa lezione, costruirai un **Occhio Controllato da Joystick**, visualizzato su uno schermo OLED SSD1306 128x64.
Un joystick analogico a due assi fornisce il movimento X/Y, letto usando i canali ADC di Fusion HAT+.
L'OLED mostra un "occhio" stilizzato la cui pupilla segue dolcemente la direzione del joystick.

Il progetto dimostra:

- Lettura di input analogico multi-asse
- Normalizzazione fluida dei valori e gestione della zona morta
- Vincoli geometrici usando un'ellisse
- Renderizzazione grafica in tempo reale su un OLED monocromatico

Muovendo il joystick, l'iride e la pupilla scivolano all'interno dell'occhio senza oltrepassare il bordo esterno della sclera.

**Passaggi di Configurazione**

#. Installa le librerie richieste:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-ssd1306 --break

#. Esegui l'esempio dalla directory ``ai-lab-kit``:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 4.13_JoystickEye.py

#. Quando lo script viene eseguito:

   * Muovendo il joystick a sinistra/destra/su/giu, la pupilla si muove di conseguenza
   * Il movimento della pupilla è fluido e vincolato all'interno di un occhio ellittico
   * Il display si aggiorna a circa **50 FPS**
   * Premi **Ctrl+C** per uscire
