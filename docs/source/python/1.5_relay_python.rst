1.5 Controle de Relais
===========================

**Introduction**

Dans ce projet, nous allons apprendre a controler un module relais en utilisant un Raspberry Pi. Les relais sont des interrupteurs a commande electrique qui permettent a des circuits de faible puissance de controler en toute securite des dispositifs de haute puissance. Ce projet montre comment activer et desactiver un relais a intervalles reguliers.

**Schema de circuit**

Le signal GPIO passe par une resistance de 1 kΩ jusqu'a la base du transistor, permettant au transistor de commuter la bobine du relais. Lorsque GPIO17 emet un niveau HAUT, le transistor s'allume, le courant traverse la bobine du relais, le relais s'active et la LED (via la resistance de 220 Ω) s'allume. Lorsque GPIO17 emet un niveau BAS, le transistor s'eteint, la bobine du relais est desactivee, le relais se libere et la LED s'eteint. Une diode de roue libre est placee aux bornes de la bobine du relais pour proteger le circuit des pics de tension.

**Code**

Le code Python suivant controle un module relais, l'activant et le desactivant :

.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat.pin import Pin, Mode
    from time import sleep  # Import the sleep function for delay

    # Initialize the relay connected to GPIO pin 17
    relay = Pin(17,mode=Mode.OUT)

    try:
        # Loop to continuously toggle the relay's state every second
        while True:
            print('Relay open...')  # Inform that the relay is being activated
            relay.high()  # Turn on the relay
            sleep(1)   # Maintain the relay in the on state for 1 second

            print('...Relay close')  # Inform that the relay is being deactivated
            relay.low()  # Turn off the relay
            sleep(1)   # Maintain the relay in the off state for 1 second

    except KeyboardInterrupt:
        # Handle a keyboard interrupt (Ctrl+C) to exit the loop
        relay.off()  # Ensure the relay is turned off before exiting
        pass


Ce script Python controle un module relais connecte a la broche GPIO 17. Lors de l'execution :

1. Le script entre dans une boucle infinie qui alterne l'etat du relais chaque seconde.
2. Lorsque le relais est active (HIGH), "Relay open..." est affiche sur la console.
3. Lorsque le relais est desactive (LOW), "...Relay close" est affiche sur la console.
4. Le programme peut etre interrompu proprement avec ``Ctrl+C``, ce qui garantit que le relais est eteint avant de quitter.

----------------------------------------------

**Comprendre le code**

1. **Importation de la bibliotheque**

   La classe ``Pin`` de la bibliotheque ``fusion_hat`` est utilisee pour controler les broches GPIO, et ``time.sleep`` introduit des pauses entre les changements d'etat.

   .. code-block:: python

        from fusion_hat.pin import Pin, Mode
        from time import sleep  # Import the sleep function for delay

2. **Initialisation du relais**

   Le relais est initialise sur la broche GPIO 17 et configure en mode sortie.

   .. code-block:: python

      # Initialize the relay connected to GPIO pin 17
      relay = Pin(17,mode=Mode.OUT)

3. **Boucle de controle principale**

   La boucle ``while True`` alterne en continu l'etat du relais avec des intervalles d'1 seconde.

   .. code-block:: python

      while True:
          print('Relay open...')  # Inform that the relay is being activated
          relay.high()  # Turn on the relay
          sleep(1)   # Maintain the relay in the on state for 1 second

          print('...Relay close')  # Inform that the relay is being deactivated
          relay.low()  # Turn off the relay
          sleep(1)   # Maintain the relay in the off state for 1 second

4. **Gestion des interruptions clavier**

   Le bloc ``try-except`` garantit que le programme s'arrete proprement lorsqu'il est interrompu (par exemple, Ctrl+C), et eteint le relais avant de quitter.

   .. code-block:: python

      except KeyboardInterrupt:
          # Handle a keyboard interrupt (Ctrl+C) to exit the loop
          relay.off()  # Ensure the relay is turned off before exiting
          pass

**Depannage**

1. **Le relais ne repond pas**

   - **Cause** : Cablage incorrect ou configuration de broche GPIO erronee.
   - **Solution** : Verifiez que toutes les connexions correspondent au schema de cablage et confirmez que GPIO 17 est correctement specifie.

2. **Le relais reste allume ou eteint**

   - **Cause** : Inadequation du niveau logique ou problemes d'alimentation.
   - **Solution** : Assurez-vous que le module relais est compatible avec les niveaux logiques 3,3 V et verifiez que l'alimentation est adequate.

3. **Le programme ne se termine pas proprement**

   - **Cause** : L'interruption clavier n'est pas correctement prise en charge.
   - **Solution** : Assurez-vous d'utiliser ``Ctrl+C`` pour terminer le programme et verifiez que le code de gestion d'exception est present.

**Idees d'extension**

1. **Controle programmé**

   Modifiez le code pour controler le relais selon un horaire, l'allumant et l'eteignant a des heures specifiques :

   .. code-block:: python

      import datetime

      # Turn relay on during specific hours
      current_time = datetime.datetime.now().time()
      if datetime.time(9, 0) <= current_time <= datetime.time(17, 0):
          relay.high()
      else:
          relay.low()

2. **Controle par capteur**

   Connectez un capteur (comme un capteur de temperature ou de mouvement) et controler le relais en fonction des lectures du capteur :

   .. code-block:: python

      # Pseudocode for sensor-controlled relay
      if temperature_sensor.read() > 25:  # If temperature exceeds 25°C
          relay.high()  # Turn on cooling device
      else:
          relay.low()   # Turn off cooling device

3. **Controle de relais multiples**

   Etendez le projet pour controler plusieurs relais simultanement :

   .. code-block:: python

      # Initialize multiple relays
      relays = {
          'light': Pin(17, Pin.OUT),
          'fan': Pin(18, Pin.OUT),
          'pump': Pin(19, Pin.OUT)
      }

      # Control individual relays
      relays['light'].high()
      relays['fan'].low()
