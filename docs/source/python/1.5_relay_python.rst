1.5 Controllo Relè
===========================

**Introduzione**

In questo progetto, impareremo come controllare un modulo relè usando un Raspberry Pi. I relè sono interruttori a comando elettrico che permettono a circuiti a bassa potenza di controllare dispositivi ad alta potenza in sicurezza. Questo progetto dimostra come attivare e disattivare un relè a intervalli regolari.

**Schema Elettrico**

Il segnale GPIO passa attraverso un resistore da 1 kΩ alla base del transistor, permettendo al transistor di commutare la bobina del relè. Quando GPIO17 emette HIGH, il transistor si accende, la corrente fluisce attraverso la bobina del relè, il relè si attiva e il LED (attraverso il resistore da 220 Ω) si accende. Quando GPIO17 emette LOW, il transistor si spegne, la bobina del relè viene diseccitata, il relè si rilascia e il LED si spegne. Un diodo flyback è posizionato attraverso la bobina del relè per proteggere il circuito da picchi di tensione.

**Codice**

Il seguente codice Python controlla un modulo relè, attivandolo e disattivandolo:

.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat.pin import Pin, Mode
    from time import sleep  # Import the sleep function for delay

    # Initialize the relay connected to GPIO pin 17
    relay = Pin(17,mode=Mode.OUT)

    try:
        # Loop to continuously toggle the relay's state every second
        while True:
            print('Relay open...')  # Inform that the relay is being activated
            relay.high()  # Turn on the relay
            sleep(1)   # Maintain the relay in the on state for 1 second

            print('...Relay close')  # Inform that the relay is being deactivated
            relay.low()  # Turn off the relay
            sleep(1)   # Maintain the relay in the off state for 1 second

    except KeyboardInterrupt:
        # Handle a keyboard interrupt (Ctrl+C) to exit the loop
        relay.off()  # Ensure the relay is turned off before exiting
        pass


Questo script Python controlla un modulo relè collegato al pin GPIO 17. Quando eseguito:

1. Lo script entra in un ciclo infinito che attiva e disattiva il relè ogni secondo
2. Quando il relè è attivato (HIGH), "Relay open..." viene stampato sulla console
3. Quando il relè è disattivato (LOW), "...Relay close" viene stampato sulla console
4. Il programma può essere interrotto in modo controllato usando ``Ctrl+C``, che assicura che il relè venga spento prima di uscire

**Comprendere il Codice**

1. **Importazione della Libreria**

   La classe ``Pin`` della libreria ``fusion_hat`` viene usata per controllare i pin GPIO, e ``time.sleep`` introduce ritardi tra i cambiamenti di stato.

   .. code-block:: python

        from fusion_hat.pin import Pin, Mode
        from time import sleep  # Import the sleep function for delay

2. **Inizializzazione del Relè**

   Il relè viene inizializzato sul pin GPIO 17 e impostato in modalità uscita.

   .. code-block:: python

      # Initialize the relay connected to GPIO pin 17
      relay = Pin(17,mode=Mode.OUT)

3. **Ciclo Principale di Controllo**

   Il ciclo ``while True`` attiva e disattiva continuamente lo stato del relè con intervalli di 1 secondo.

   .. code-block:: python

      while True:
          print('Relay open...')  # Inform that the relay is being activated
          relay.high()  # Turn on the relay
          sleep(1)   # Maintain the relay in the on state for 1 second

          print('...Relay close')  # Inform that the relay is being deactivated
          relay.low()  # Turn off the relay
          sleep(1)   # Maintain the relay in the off state for 1 second

4. **Gestione dell'Interruzione da Tastiera**

   Il blocco ``try-except`` assicura che il programma si fermi in modo controllato quando viene interrotto (ad es., Ctrl+C), e spegne il relè prima di uscire.

   .. code-block:: python

      except KeyboardInterrupt:
          # Handle a keyboard interrupt (Ctrl+C) to exit the loop
          relay.off()  # Ensure the relay is turned off before exiting
          pass

**Risoluzione dei Problemi**

1. **Il Relè Non Risponde**

   - **Causa**: Cablaggio errato o configurazione errata del pin GPIO.
   - **Soluzione**: Verifica che tutte le connessioni corrispondano allo schema di cablaggio e conferma che GPIO 17 sia specificato correttamente.

2. **Il Relè Rimane Acceso o Spento**

   - **Causa**: Discrepanza del livello logico o problemi di alimentazione.
   - **Soluzione**: Assicurati che il modulo relè sia compatibile con i livelli logici a 3,3V e verifica che l'alimentazione sia adeguata.

3. **Il Programma Non Esce in Modo Pulito**

   - **Causa**: Interruzione da tastiera non gestita correttamente.
   - **Soluzione**: Assicurati di usare ``Ctrl+C`` per terminare il programma e verifica che il codice di gestione delle eccezioni sia presente.

**Idee Estendibili**

1. **Controllo Programmato**

   Modifica il codice per controllare il relè in base a un programma, accendendolo e spegnendolo a orari specifici:

   .. code-block:: python

      import datetime

      # Turn relay on during specific hours
      current_time = datetime.datetime.now().time()
      if datetime.time(9, 0) <= current_time <= datetime.time(17, 0):
          relay.high()
      else:
          relay.low()

2. **Controllo Attivato da Sensore**

   Collega un sensore (come un sensore di temperatura o movimento) e controlla il relè in base alle letture del sensore:

   .. code-block:: python

      # Pseudocode for sensor-controlled relay
      if temperature_sensor.read() > 25:  # If temperature exceeds 25°C
          relay.high()  # Turn on cooling device
      else:
          relay.low()   # Turn off cooling device

3. **Controllo Multiplo di Relè**

   Espandi il progetto per controllare più relè simultaneamente:

   .. code-block:: python

      # Initialize multiple relays
      relays = {
          'light': Pin(17, Pin.OUT),
          'fan': Pin(18, Pin.OUT),
          'pump': Pin(19, Pin.OUT)
      }

      # Control individual relays
      relays['light'].high()
      relays['fan'].low()
