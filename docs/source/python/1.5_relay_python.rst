1.5 Control de Relé
=============================

**Introducción**

En este proyecto, aprenderemos cómo controlar un módulo de relé utilizando una Raspberry Pi. Los relés son interruptores accionados eléctricamente que permiten que circuitos de baja potencia controlen dispositivos de alta potencia de forma segura. Este proyecto demuestra cómo activar y desactivar un relé a intervalos regulares.

**Diagrama de Circuito**

La señal GPIO pasa a través de una resistencia de 1 kΩ a la base del transistor, permitiendo que el transistor active y desactive la bobina del relé. Cuando GPIO17 emite HIGH, el transistor se enciende, la corriente fluye a través de la bobina del relé, el relé se activa y el LED (a través de la resistencia de 220 Ω) se enciende. Cuando GPIO17 emite LOW, el transistor se apaga, la bobina del relé se desenergiza, el relé se desactiva y el LED se apaga. Un diodo de retorno se coloca a través de la bobina del relé para proteger el circuito de picos de voltaje.

**Código**

El siguiente código Python controla un módulo de relé, activándolo y desactivándolo:

.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat.pin import Pin, Mode
    from time import sleep  # Import the sleep function for delay

    # Initialize the relay connected to GPIO pin 17
    relay = Pin(17,mode=Mode.OUT)

    try:
        # Loop to continuously toggle the relay's state every second
        while True:
            print('Relay open...')  # Inform that the relay is being activated
            relay.high()  # Turn on the relay
            sleep(1)   # Maintain the relay in the on state for 1 second

            print('...Relay close')  # Inform that the relay is being deactivated
            relay.low()  # Turn off the relay
            sleep(1)   # Maintain the relay in the off state for 1 second

    except KeyboardInterrupt:
        # Handle a keyboard interrupt (Ctrl+C) to exit the loop
        relay.off()  # Ensure the relay is turned off before exiting
        pass


Este script Python controla un módulo de relé conectado al pin GPIO 17. Cuando se ejecuta:

1. El script entra en un bucle infinito que alterna el estado del relé cada segundo
2. Cuando el relé se activa (HIGH), se imprime "Relay open..." en la consola
3. Cuando el relé se desactiva (LOW), se imprime "...Relay close" en la consola
4. El programa puede interrumpirse de forma controlada usando ``Ctrl+C``, lo que asegura que el relé se apague antes de salir

**Comprender el Código**

1. **Importación de Librerías**

   La clase ``Pin`` de la librería ``fusion_hat`` se utiliza para controlar los pines GPIO, y ``time.sleep`` introduce retrasos entre cambios de estado.

   .. code-block:: python

        from fusion_hat.pin import Pin, Mode
        from time import sleep  # Import the sleep function for delay

2. **Inicialización del Relé**

   El relé se inicializa en el pin GPIO 17 y se configura en modo de salida.

   .. code-block:: python

      # Initialize the relay connected to GPIO pin 17
      relay = Pin(17,mode=Mode.OUT)

3. **Bucle de Control Principal**

   El bucle ``while True`` alterna continuamente el estado del relé con intervalos de 1 segundo.

   .. code-block:: python

      while True:
          print('Relay open...')  # Inform that the relay is being activated
          relay.high()  # Turn on the relay
          sleep(1)   # Maintain the relay in the on state for 1 second

          print('...Relay close')  # Inform that the relay is being deactivated
          relay.low()  # Turn off the relay
          sleep(1)   # Maintain the relay in the off state for 1 second

4. **Manejo de Interrupción por Teclado**

   El bloque ``try-except`` asegura que el programa se detenga de forma controlada cuando sea interrumpido (por ejemplo, Ctrl+C), y apaga el relé antes de salir.

   .. code-block:: python

      except KeyboardInterrupt:
          # Handle a keyboard interrupt (Ctrl+C) to exit the loop
          relay.off()  # Ensure the relay is turned off before exiting
          pass

**Solución de Problemas**

1. **El Relé No Responde**

   - **Causa**: Cableado incorrecto o configuración errónea del pin GPIO.
   - **Solución**: Verifica que todas las conexiones coincidan con el diagrama de conexiones y confirma que GPIO 17 esté correctamente especificado.

2. **El Relé Se Queda Encendido o Apagado**

   - **Causa**: Desajuste de nivel lógico o problemas de alimentación.
   - **Solución**: Asegúrate de que el módulo de relé sea compatible con niveles lógicos de 3.3V y verifica que la fuente de alimentación sea adecuada.

3. **El Programa No Sale de Forma Limpia**

   - **Causa**: La interrupción por teclado no se maneja correctamente.
   - **Solución**: Asegúrate de usar ``Ctrl+C`` para terminar el programa y verifica que el código de manejo de excepciones esté presente.

**Ideas para Extender**

1. **Control Programado**

   Modifica el código para controlar el relé según un horario, encendiéndolo y apagándolo en momentos específicos:

   .. code-block:: python

      import datetime

      # Turn relay on during specific hours
      current_time = datetime.datetime.now().time()
      if datetime.time(9, 0) <= current_time <= datetime.time(17, 0):
          relay.high()
      else:
          relay.low()

2. **Control Activado por Sensor**

   Conecta un sensor (como un sensor de temperatura o movimiento) y controla el relé según las lecturas del sensor:

   .. code-block:: python

      # Pseudocode for sensor-controlled relay
      if temperature_sensor.read() > 25:  # If temperature exceeds 25°C
          relay.high()  # Turn on cooling device
      else:
          relay.low()   # Turn off cooling device

3. **Control de Múltiples Relés**

   Expande el proyecto para controlar múltiples relés simultáneamente:

   .. code-block:: python

      # Initialize multiple relays
      relays = {
          'light': Pin(17, Pin.OUT),
          'fan': Pin(18, Pin.OUT),
          'pump': Pin(19, Pin.OUT)
      }

      # Control individual relays
      relays['light'].high()
      relays['fan'].low()
