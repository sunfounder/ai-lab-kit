4.15 Gioco della Talpa
======================

**Introduzione**

In questa lezione, costruirai un **Gioco della Talpa** usando Fusion HAT+.
Quattro LED pilotati da PWM fungono da "talpe", attenuandosi dolcemente in un ciclo di 1 secondo.
Il tuo obiettivo è colpire il pulsante corretto quando il suo LED corrispondente si accende. Un buzzer fornisce feedback acustico:

- **Buca corretta -> breve beep acuto**
- **Buca sbagliata -> GAME OVER (beep grave)**

Un display OLED SSD1306 mostra il tuo **punteggio corrente** durante il gioco e un **punteggio finale** al game over.

Questo progetto combina modellazione della luminosit PWM, rilevamento dei fronti dei pulsanti, cicli di temporizzazione e una semplice macchina a stati del gioco.

**Passaggi di Configurazione**

#. Installa le librerie richieste:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo pip3 install adafruit-circuitpython-ssd1306 --break

#. Esegui il gioco dalla directory ``ai-lab-kit``:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 4.15_WhackAMole.py

#. Quando lo script viene eseguito:

   * Un LED si accende/spegne (onda triangolare).
   * Premi **solo il pulsante del LED acceso** entro la finestra di 1 secondo:

     - Corretto -> punteggio aumenta, appare la talpa successiva
     - Errato -> il buzzer suona un tono di errore -> **GAME OVER**
   * L'OLED mostra solo il punteggio corrente (in gioco)
   * L'OLED mostra "GAME OVER" + punteggio finale quando si perde
   * Premi Ctrl+C per uscire
