1.3.2 Servo
==============================

**Introduction**

In diesem Projekt lernen wir, wie man mit einem Raspberry Pi einen Servomotor steuert. Servomotoren werden häufig in Robotik und Automatisierung eingesetzt, um Bewegungen präzise im gewünschten Winkel auszuführen.

**Writing the Code**

Der folgende Python-Code zeigt, wie der Servomotor zwischen verschiedenen Winkeln bewegt wird:


.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat import Servo
   from time import sleep

   servo = Servo('P0')

   while True:
      for i in range(-90, 91, 10):
         servo.angle(i)
         sleep(0.1)
      for i in range(90, -91, -10):
         servo.angle(i)
         sleep(0.1)


Dieses Python-Skript steuert einen Servomotor, der an PWM 0 angeschlossen ist. Beim Ausführen gilt:

1. Der Servo bewegt sich von -90 Grad bis 90 Grad in 10-Grad-Schritten.  
2. Zwischen jeder Bewegung pausiert er 0,1 Sekunden.  
3. Anschließend bewegt er sich wieder zurück von 90 Grad bis -90 Grad.  
4. Dieser Ablauf wiederholt sich ununterbrochen.  


----------------------------------------------

**Understanding the Code**

1. **Library Import**

   Die Bibliothek ``fusion_hat`` vereinfacht die GPIO-Steuerung, während ``time`` für Pausen sorgt.

   .. code-block:: python

      from fusion_hat import Servo
      from time import sleep

2. **Servo Initialization**

   Das ``Servo``-Objekt wird mit PWM 0 initialisiert.

   .. code-block:: python

      servo = Servo('P0')

3. **Servo Movement**

   Der Servo wird in einer Schleife auf unterschiedliche Winkel gesetzt. Mit ``angle`` wird die Position bestimmt, während ``sleep`` kurze Verzögerungen einfügt.

   .. code-block:: python

      while True:
         for i in range(-90, 91, 10):
            servo.angle(i)
            sleep(0.1)
         for i in range(90, -91, -10):
            servo.angle(i)
            sleep(0.1)


----------------------------------------------

**Troubleshooting**

1. **Servo bewegt sich nicht**  

   - **Ursache**: Falsche GPIO-Verbindung oder Probleme mit der Spannungsversorgung.  
   - **Lösung**: Prüfen Sie die Verbindung zum PWM-0-Pin und stellen Sie eine stabile Spannungsversorgung sicher.  

2. **Servo bewegt sich ruckartig oder reagiert nicht**  

   - **Ursache**: Unzureichende Stromversorgung für den Servo.  
   - **Lösung**: Nutzen Sie bei Bedarf eine externe Spannungsquelle, falls der Fusion HAT nicht genügend Strom liefert.  

----------------------------------------------


**Extendable Ideas**


1. **Benutzergesteuerte Servo-Steuerung**  

   Ermöglichen Sie eine interaktive Steuerung der Servoposition über Tastatureingaben:

   .. code-block:: python

      while True:
         position = float(input("Enter position (-90 to 90): "))
         servo.angle(position)


2. **Servo-Positionsaufzeichnung**  

   Erfassen Sie die Servo-Positionen über die Zeit und visualisieren Sie die Bewegung:

   .. code-block:: python

      positions = []
      for i in range(-90, 91, 10):
         servo.angle(i)
         sleep(0.1)
         positions.append(servo.angle())
      plt.plot(positions)
      plt.show()
