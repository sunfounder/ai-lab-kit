2.15 GY-87 IMU Module
==========================

The GY-87 module integrates three powerful sensor chips—**MPU6050**, **QMC5883L**, and **BMP180**—each providing a different sensing capability:

- **MPU6050**: A 6-axis IMU combining a **3-axis accelerometer** and a **3-axis gyroscope**, ideal for motion detection and orientation sensing.
- **QMC5883L**: A **3-axis magnetometer** used for compass heading and directional measurement.
- **BMP180**: A **barometric pressure and temperature sensor**, commonly used for weather data and altitude estimation.

All three sensors communicate via the **I2C protocol**, and each chip has its own unique I2C address:

- MPU6050 → ``0x68``  
- QMC5883L → ``0x0D``  
- BMP180 → ``0x77``

#. Assemble the circuit as shown in the wiring diagram below:

      :align: center

#. Calibrate the QMC5883L magnetometer before use. Refer to :ref:`qmc5883l_calibrate`.

#. Open the ``2.15_GY87.py`` file:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo nano 2.15_GY87.py

#. Replace the placeholder calibration values with the values obtained from your calibration result:

   .. code-block:: python

      mag_offsets = (OFFSET_X, OFFSET_Y, OFFSET_Z)
      mag_scales  = (SCALE_X,  SCALE_Y,  SCALE_Z)

   Make sure to copy the **exact numbers** printed by the calibration script.

#. Save and exit Nano by pressing ``Ctrl+X``, then ``Y``, and then ``Enter``.

#. Run the script to read **real-time data** from all three sensors:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 2.15_GY87.py

When you run the script, the Raspberry Pi will begin reading data from all three sensors on the GY-87 module.  
The terminal will continuously display:

* **Temperature** from the BMP180  
* **Pressure & Altitude** from the BMP180  
* **Accelerometer + Gyroscope** readings from the MPU6050  
* **Heading angle** from the QMC5883L (using your calibration values)

The output will look similar to the following:

.. code-block:: text

    --- BMP180 ---
    Temp:  25.12 °C | Pressure: 100842.55 Pa | Altitude:  15.32 m

    --- MPU6050 ---
    ACC: +0.001g  +0.012g  +1.002g
    GYRO: +0.12deg/s  -0.05deg/s  +0.03deg/s

    --- QMC5883L (Compass) ---
    Heading: 143.27°

The values update several times per second.

* **Accel readings** will change when the module is moved.  
* **Gyroscope values** will increase when the module rotates.  
* **Heading** will rotate smoothly from **0° to 360°** as you turn the module flat on a table.  
* **Pressure and altitude** may drift slightly depending on the environment.

Press ``Ctrl+C`` at any time to stop the script. The program will exit cleanly.


---------------------------------------------

**Code**

Below is the complete Python script used to read data from BMP180, MPU6050, and QMC5883L simultaneously:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   """
   Read data from all three sensors on the GY-87 module:
   - BMP180: temperature, pressure, altitude
   - MPU6050: temperature, accelerometer, gyroscope
   - QMC5883L (via Magnetometer): compass heading

   Gracefully exits when Ctrl+C is pressed.
   """

   from smbus2 import SMBus
   from time import sleep
   import math

   # Import Fusion HAT+ sensor modules
   from fusion_hat.modules import bmp180, MPU6050
   from fusion_hat.modules.magnetometer import Magnetometer


   def main():
      # --- Initialize BMP180 (pressure / temperature / altitude) ---
      bus = SMBus(1)  # I2C bus 1 on Raspberry Pi
      bmp_sensor = bmp180.BMP180(bus, oversampling=3)

      # --- Initialize MPU6050 (accelerometer / gyroscope / temperature) ---
      mpu = MPU6050()

      # --- Initialize Magnetometer (QMC5883L / others auto-detected) ---
      mag = Magnetometer()

      # TODO: replace these with your own calibration values
      # from the QMC5883L calibration script.
      mag_offsets = (0.0, 0.0, 0.0)   # (OFFSET_X, OFFSET_Y, OFFSET_Z)
      mag_scales  = (1.0, 1.0, 1.0)   # (SCALE_X,  SCALE_Y,  SCALE_Z)

      print("Starting combined GY-87 sensor readout...")
      print("Press Ctrl+C to stop.\n")

      try:
         while True:
               # ---------- BMP180 readings ----------
               temp_bmp, pressure, altitude = bmp_sensor.read()

               # ---------- MPU6050 readings ----------
               temp_mpu = mpu.get_temp()
               acc_x, acc_y, acc_z = mpu.get_accel_data()
               gyro_x, gyro_y, gyro_z = mpu.get_gyro_data()

               # ---------- Magnetometer / heading ----------
               mag_data = mag.read()
               if mag_data is not None:
                  mx_raw, my_raw, mz_raw = mag_data

                  # Apply hard-iron and soft-iron calibration
                  mx = (mx_raw - mag_offsets[0]) * mag_scales[0]
                  my = (my_raw - mag_offsets[1]) * mag_scales[1]
                  mz = (mz_raw - mag_offsets[2]) * mag_scales[2]

                  # Heading in degrees (0–360)
                  heading = math.degrees(math.atan2(my, mx))
                  if heading < 0:
                     heading += 360.0
               else:
                  mx = my = mz = 0.0
                  heading = float("nan")

               # ---------- Print all readings ----------
               print(
                  f"BMP180: Temp={temp_bmp:6.2f} °C"
                  f" | Pressure={pressure:10.2f} Pa"
                  f" | Alt={altitude:7.2f} m"
               )
               print(
                  f"MPU6050: Temp={temp_mpu:6.2f} °C"
                  f" | ACC=({acc_x:7.4f}g, {acc_y:7.4f}g, {acc_z:7.4f}g)"
                  f" | GYRO=({gyro_x:7.2f}dps, {gyro_y:7.2f}dps, {gyro_z:7.2f}dps)"
               )
               print(
                  f"Magnetometer: mx={mx:7.4f} G, my={my:7.4f} G, mz={mz:7.4f} G"
                  f" | Heading={heading:6.2f}°"
               )
               print("-" * 80)

               sleep(0.5)

      except KeyboardInterrupt:
         print("\nExiting combined GY-87 sensor program...")


   if __name__ == "__main__":
      main()
