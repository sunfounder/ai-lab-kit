2.2.8 MPU6050 Modul
====================

**Introduction**

Das MPU6050 ist ein hochintegriertes 6-Achsen-Bewegungserfassungsmodul, das ein 3-Achsen-Gyroskop und einen 3-Achsen-Beschleunigungssensor kombiniert. Aufgrund seiner kompakten Bauweise, des geringen Energieverbrauchs und der hohen Leistungsfähigkeit wird es häufig in Smartphones, Tablets und Wearables eingesetzt. In diesem Projekt lernst du, wie du den MPU6050 über das I2C-Protokoll ansteuerst, um Beschleunigungs- und Winkelgeschwindigkeitsdaten auszulesen und diese anschließend auf dem Bildschirm anzuzeigen.

   from fusion_hat import MPU6050
   from time import sleep

   mpu = MPU6050()

   # mpu.set_accel_range(MPU6050.ACCEL_RANGE_2G)

Dieses Python-Skript nutzt den MPU6050-Sensor, der häufig in Drohnen, Smartphones oder Spielekonsolen zur Bewegungserfassung eingesetzt wird. Es liest kontinuierlich Temperatur-, Beschleunigungs- und Gyroskopdaten aus und gibt sie formatiert in der Konsole aus.

**Understanding the Code**



1. **Importing Libraries**

   .. code-block:: python

      from fusion_hat import MPU6050
      from time import sleep


   Hier werden die erforderlichen Python-Bibliotheken importiert. ``fusion_hat`` enthält die Klasse ``MPU6050`` für die Kommunikation mit dem Sensor. Mit ``sleep`` aus dem Modul ``time`` wird eine Pause in der Schleife realisiert.  

2. **Initializing the Sensor**

   .. code-block:: python

      mpu = MPU6050()


   Erstellt eine Instanz der Klasse ``MPU6050`` und initialisiert damit den Sensor, sodass Daten erfasst werden können.  

3. **Main Loop**

   .. code-block:: python

      while True:
         temp = mpu.get_temp()
         acc_x, acc_y, acc_z = mpu.get_accel_data()
         gyro_x, gyro_y, gyro_z = mpu.get_gyro_data()
         print(
            f"Temp: {temp:0.2f} 'C",
            f"  |  ACC: {acc_x:8.5f}g {acc_y:8.5f}g {acc_z:8.5f}g",
            f"  |  GYRO: {gyro_x:8.5f}deg/s {gyro_y:8.5f}deg/s {gyro_z:8.5f}deg/s"
         )
         sleep(0.2)


   - **Endlosschleife**: Mit ``while True`` läuft die Schleife unbegrenzt weiter.  

   - **Sensordaten auslesen**:  

     - ``temp = mpu.get_temp()`` liest die aktuelle Temperatur.  
     - ``acc_x, acc_y, acc_z = mpu.get_accel_data()`` liefert die Beschleunigungswerte auf den Achsen x, y, z.  
     - ``gyro_x, gyro_y, gyro_z = mpu.get_gyro_data()`` gibt die Winkelgeschwindigkeit auf den Achsen zurück.  

   - **Ausgabe**: Die Daten werden formatiert in der Konsole ausgegeben.  

   - **Pause**: ``sleep(0.2)`` sorgt für eine Verzögerung von 0,2 Sekunden, um die CPU-Last zu reduzieren und eine saubere Ausgabe zu gewährleisten.  

4. **Additional Comments**

   Die folgenden, auskommentierten Zeilen erlauben es, den Messbereich von Beschleunigungssensor und Gyroskop anzupassen:

   .. code-block:: python

      # mpu.set_accel_range(MPU6050.ACCEL_RANGE_2G)
      # mpu.set_gyro_range(MPU6050.GYRO_RANGE_250DEG)

   Wenn du diese Zeilen einkommentierst, kannst du die Empfindlichkeit des Beschleunigungs- und Gyroskopsensors anpassen. Zum Beispiel konfiguriert ``ACCEL_RANGE_2G`` den Beschleunigungssensor so, dass er bis ±2g messen kann, während ``GYRO_RANGE_250DEG`` den Gyroskopbereich auf ±250 Grad pro Sekunde setzt. Standardmäßig wird das MPU6050-Modul mit den Voreinstellungen ±2g (Beschleunigung) und ±250 Grad pro Sekunde (Gyroskop) initialisiert.  

   Du kannst diese Bereiche an die Anforderungen deiner Anwendung anpassen. Die möglichen Einstellungen sind:  

   - **Accelerometer Ranges**:

      - ``MPU6050.ACCEL_RANGE_2G``: ±2g  
      - ``MPU6050.ACCEL_RANGE_4G``: ±4g  
      - ``MPU6050.ACCEL_RANGE_8G``: ±8g  
      - ``MPU6050.ACCEL_RANGE_16G``: ±16g  

   - **Gyroscope Ranges**:

      - ``MPU6050.GYRO_RANGE_250DEG``: ±250 Grad pro Sekunde  
      - ``MPU6050.GYRO_RANGE_500DEG``: ±500 Grad pro Sekunde  
      - ``MPU6050.GYRO_RANGE_1000DEG``: ±1000 Grad pro Sekunde  
      - ``MPU6050.GYRO_RANGE_2000DEG``: ±2000 Grad pro Sekunde

**Troubleshooting**

1. **Keine Ausgabe oder Sensor wird nicht erkannt**:

   - **Ursache**: Fehlerhafte I2C-Konfiguration oder Verdrahtung.  
   - **Lösung**:  

      - Stelle sicher, dass der MPU6050 korrekt mit den I2C-Pins des Raspberry Pi verbunden ist (SDA, SCL, Stromversorgung, Masse).  
      - Überprüfe die I2C-Adresse mit dem Tool ``i2cdetect``:  

      .. code-block:: shell

         sudo i2cdetect -y 1
         
      - Stelle sicher, dass die erkannte Geräteadresse ``0x68`` im Skript entspricht.  

2. **Falsche oder instabile Werte**:

   - **Ursache**: Kalibrierungsprobleme oder eine störanfällige Umgebung.  
   - **Lösung**:  

     - Platziere den MPU6050 auf einer stabilen Oberfläche, um Störungen zu minimieren.  
     - Kalibriere Gyroskop und Beschleunigungssensor, um präzisere Werte zu erhalten.  

3. **ImportError: No Module Named ``smbus``**:

   - **Ursache**: Die Bibliothek ``smbus`` ist nicht installiert.  
   - **Lösung**: Installiere die Bibliothek mit:  

   .. code-block:: shell

     sudo apt-get install python3-smbus
