4.6 Dispositivo di Conteggio
=============================

**Introduzione**

In questo progetto, costruirai un sistema di conteggio persone usando un sensore di movimento PIR e un display a 7 segmenti a 4 cifre. Il sistema incrementa il conteggio visualizzato ogni volta che il sensore PIR rileva movimento. Questo progetto è ideale per monitorare il traffico pedonale in un corridoio o ingresso e fornisce esperienza pratica con la programmazione GPIO e il controllo del display.

Questo script Python integra un sensore di movimento PIR e un display a 7 segmenti pilotato da un registro a scorrimento 74HC595. Lo script esegue le seguenti operazioni:

1. **Rilevamento Movimento**: Un sensore di movimento PIR collegato a GPIO 26 rileva il movimento. Ogni rilevamento movimento incrementa un contatore.

2. **Visualizzazione Numerica**:

   - Il valore corrente del contatore viene visualizzato su un display a 7 segmenti a 4 cifre.
   - Il display si aggiorna dinamicamente man mano che viene rilevato movimento, incrementando il valore.

3. **Monitoraggio Continuo**: Lo script monitora continuamente il movimento e aggiorna il display in tempo reale.

4. **Uscita Controllata**: Con ``Ctrl+C``, tutti i pin vengono spenti, garantendo un arresto pulito dello script.

**Codice**


Qui sotto c'è lo script Python usato in questo progetto:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull

   # Initialize PIR motion sensor on GPIO 22 (input with pull-down)
   pir = Pin(22, mode=Mode.IN, pull=Pull.DOWN)

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17, mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4, mode=Mode.OUT)   # Register Clock (latch)
   SRCLK = Pin(27, mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins used to select one of the 4 digits on the 7-segment display
   placePin = [Pin(pin, mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Segment code table for digits 0-9 (common-cathode 7-segment display)
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Counter to display the number of detections
   counter = 0

   def clearDisplay():
      """Clear the 7-segment display by shifting out 'all off' bits."""
      for _ in range(8):
         SDI.high()     # Send a high bit
         SRCLK.high()   # Clock it in
         SRCLK.low()
      RCLK.high()        # Latch output
      RCLK.low()

   def hc595_shift(data):
      """Shift a full byte of data into the 74HC595 to control the segments."""
      for i in range(8):
         SDI.value(0x80 & (data << i))  # Output next bit of the data
         SRCLK.high()                   # Pulse shift clock
         SRCLK.low()
      RCLK.high()                        # Latch data to display
      RCLK.low()

   def pickDigit(digit):
      """Enable one specific digit (0-3) on the multiplexed display."""
      for pin in placePin:
         pin.low()                      # Disable all digits
      placePin[digit].high()             # Activate the selected digit

   def display():
      """Display the current 4-digit counter value on the 7-segment display."""
      global counter

      # Display ones place
      clearDisplay()
      pickDigit(3)
      hc595_shift(number[counter % 10])

      # Display tens place
      clearDisplay()
      pickDigit(2)
      hc595_shift(number[counter % 100 // 10])

      # Display hundreds place
      clearDisplay()
      pickDigit(1)
      hc595_shift(number[counter % 1000 // 100])

      # Display thousands place
      clearDisplay()
      pickDigit(0)
      hc595_shift(number[counter % 10000 // 1000])

   def loop():
      """Main loop: continuously update display and detect PIR motion transitions."""
      global counter
      currentState = 0
      lastState = 0

      while True:
         display()                                      # Refresh 7-segment display
         currentState = 1 if pir.value() == 1 else 0    # Read PIR output

         # Detect rising edge: motion detected now, but not in last cycle
         if currentState == 1 and lastState == 0:
               counter += 1                               # Increase the count

         lastState = currentState                        # Save state for next loop

   try:
      loop()                                             # Start main loop
   except KeyboardInterrupt:
      # Clean up GPIO pins when exiting
      SDI.low()
      SRCLK.low()
      RCLK.low()
      pass


----------------------------------------------

**Comprendere il Codice**

1. **Rilevamento Movimento:**

   Il sensore PIR rileva il movimento e invia un segnale per incrementare il contatore.

2. **Aggiornamento del Display:**

   Le funzioni ``hc595_shift`` e ``pickDigit`` lavorano insieme per controllare il display a 7 segmenti e aggiornare il contatore in tempo reale.

3. **Ciclo Principale:**

   La funzione ``loop`` controlla continuamente il sensore PIR e aggiorna il display quando viene rilevato movimento.

4. **Gestione dell'Interruzione:**

   Lo script assicura che tutti i pin GPIO siano spenti in sicurezza quando interrotto, prevenendo comportamenti imprevisti.



----------------------------------------------


**Risoluzione dei Problemi**

1. **Display Non Funzionante**:

   - **Causa**: Cablaggio errato del display a 7 segmenti o del registro a scorrimento.
   - **Soluzione**:

     - Verifica le connessioni tra i pin GPIO e i pin SDI, SRCLK e RCLK del registro a scorrimento.
     - Assicurati che tutte le connessioni ``placePin`` corrispondano ai pin delle cifre corrispondenti.

2. **Sensore di Movimento Non Attivato**:

   - **Causa**: Cablaggio del sensore PIR o interferenza ambientale.
   - **Soluzione**:

     - Controlla le connessioni del sensore PIR a GPIO 26, alimentazione e massa.
     - Regola i potenziometri di sensibilità e ritardo sul sensore PIR, se disponibili.

3. **Il Contatore Non Incrementa**:

   - **Causa**: I cambiamenti di stato del sensore di movimento non vengono rilevati.
   - **Soluzione**:

     - Assicurati che il valore ``pir.value()`` si aggiorni correttamente.
     - Aggiungi stampe di debug per confermare le transizioni di stato nella funzione ``loop()``.

4. **Display Sfarfallante**:

   - **Causa**: Ritardo insufficiente o temporizzazione impropria nell'aggiornamento del display.
   - **Soluzione**: Aggiungi un piccolo ritardo nella funzione ``display()`` per stabilizzare il display:

       .. code-block:: python

           import time
           time.sleep(0.01)

**Idee Estendibili**

1. **Contatore Bidirezionale**: Aggiungi un altro sensore PIR per rilevare il movimento in direzioni opposte e decrementare il contatore:

   .. code-block:: python

      pir2 = Pin(16, Pin.IN, pull= Pin.PULL_DOWN)
      if pir2.value()==1:
         counter -= 1

2. **Avvisi Basati su Soglia**: Attiva un avviso (ad es., LED o buzzer) quando il contatore supera un valore predefinito:

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if counter > 50:
            buzzer.on()
      else:
            buzzer.off()

3. **Registrazione Dati**: Registra il valore del contatore e i timestamp in un file per l'analisi:

   .. code-block:: python

      with open("motion_log.txt", "a") as log_file:
            log_file.write(f"{time.time():.3f}, Counter: {counter}\n")

4. **Reset Basato su Timer**: Reimposta il contatore dopo un periodo specifico di inattività:

   .. code-block:: python

      last_motion_time = time.time()
      if time.time() - last_motion_time > 300:  # 5 minutes
            counter = 0

5. **Attivazioni Basate su Eventi**: Attiva azioni specifiche (ad es., controllo di elettrodomestici) quando il contatore raggiunge valori specifici.
