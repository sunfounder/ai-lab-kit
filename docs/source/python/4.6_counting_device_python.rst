4.6 Dispositif de comptage
=================================

**Introduction**

Dans ce projet, vous allez construire un systeme de comptage de personnes utilisant un capteur de mouvement PIR et un afficheur 7 segments a 4 chiffres. Le systeme incremente le compteur affiche chaque fois que le capteur PIR detecte un mouvement. Ce projet est ideal pour surveiller le passage dans un couloir ou une entree et offre une experience pratique avec la programmation GPIO et le controle d’affichage.

Ce script Python integre un capteur de mouvement PIR et un afficheur 7 segments pilote par un registre a decalage 74HC595. Le script effectue les operations suivantes :

1. **Detection de mouvement** : Un capteur de mouvement PIR connecte a la GPIO 26 detecte les mouvements. Chaque detection de mouvement incremente un compteur.

2. **Affichage du nombre** :

   - La valeur actuelle du compteur est affichee sur un afficheur 7 segments a 4 chiffres.
   - L’affichage se met a jour dynamiquement a chaque detection de mouvement, incrementant la valeur.

3. **Surveillance continue** : Le script surveille en permanence les mouvements et met a jour l’affichage en temps reel.

4. **Sortie propre** : Sur ``Ctrl+C``, toutes les broches sont eteintes, garantissant un arret propre du script.

**Code**


Below is the Python script used in this project:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull

   # Initialize PIR motion sensor on GPIO 22 (input with pull-down)
   pir = Pin(22, mode=Mode.IN, pull=Pull.DOWN)

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17, mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4, mode=Mode.OUT)   # Register Clock (latch)
   SRCLK = Pin(27, mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins used to select one of the 4 digits on the 7-segment display
   placePin = [Pin(pin, mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Segment code table for digits 0–9 (common-cathode 7-segment display)
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Counter to display the number of detections
   counter = 0

   def clearDisplay():
      """Clear the 7-segment display by shifting out 'all off' bits."""
      for _ in range(8):
         SDI.high()     # Send a high bit
         SRCLK.high()   # Clock it in
         SRCLK.low()
      RCLK.high()        # Latch output
      RCLK.low()

   def hc595_shift(data):
      """Shift a full byte of data into the 74HC595 to control the segments."""
      for i in range(8):
         SDI.value(0x80 & (data << i))  # Output next bit of the data
         SRCLK.high()                   # Pulse shift clock
         SRCLK.low()
      RCLK.high()                        # Latch data to display
      RCLK.low()

   def pickDigit(digit):
      """Enable one specific digit (0–3) on the multiplexed display."""
      for pin in placePin:
         pin.low()                      # Disable all digits
      placePin[digit].high()             # Activate the selected digit

   def display():
      """Display the current 4-digit counter value on the 7-segment display."""
      global counter

      # Display ones place
      clearDisplay()
      pickDigit(3)
      hc595_shift(number[counter % 10])

      # Display tens place
      clearDisplay()
      pickDigit(2)
      hc595_shift(number[counter % 100 // 10])

      # Display hundreds place
      clearDisplay()
      pickDigit(1)
      hc595_shift(number[counter % 1000 // 100])

      # Display thousands place
      clearDisplay()
      pickDigit(0)
      hc595_shift(number[counter % 10000 // 1000])

   def loop():
      """Main loop: continuously update display and detect PIR motion transitions."""
      global counter
      currentState = 0
      lastState = 0

      while True:
         display()                                      # Refresh 7-segment display
         currentState = 1 if pir.value() == 1 else 0    # Read PIR output

         # Detect rising edge: motion detected now, but not in last cycle
         if currentState == 1 and lastState == 0:
               counter += 1                               # Increase the count

         lastState = currentState                        # Save state for next loop

   try:
      loop()                                             # Start main loop
   except KeyboardInterrupt:
      # Clean up GPIO pins when exiting
      SDI.low()
      SRCLK.low()
      RCLK.low()
      pass


----------------------------------------------

**Comprendre le code**

1. **Detection de mouvement :**

   Le capteur PIR detecte le mouvement et envoie un signal pour incrementer le compteur.

2. **Mise a jour de l'affichage :**

   Les fonctions ``hc595_shift`` et ``pickDigit`` travaillent ensemble pour controler l'afficheur 7 segments et mettre a jour le compteur en temps reel.

3. **Boucle principale :**

   La fonction ``loop`` verifie en permanence le capteur PIR et met a jour l'affichage lorsqu'un mouvement est detecte.

4. **Gestion des interruptions :**

   Le script garantit que toutes les broches GPIO sont eteintes en toute securite en cas d'interruption, evitants ainsi un comportement inattendu.



----------------------------------------------


**Depannage**

1. **L'affichage ne fonctionne pas** :

   - **Cause :** Cablage incorrect de l'afficheur 7 segments ou du registre a decalage.
   - **Solution :**

     - Verifiez les connexions entre les broches GPIO et les broches SDI, SRCLK et RCLK du registre a decalage.
     - Assurez-vous que toutes les connexions ``placePin`` correspondent aux broches de chiffres correspondantes.

2. **Le capteur de mouvement ne se declenche pas** :

   - **Cause :** Cablage du capteur PIR ou interference environnementale.
   - **Solution :**

     - Verifiez les connexions du capteur PIR a la GPIO 26, a l'alimentation et a la masse.
     - Ajustez les potentiometres de sensibilite et de delai du capteur PIR si disponibles.

3. **Le compteur n'augmente pas** :

   - **Cause :** Changements d'etat du capteur de mouvement non detectes.
   - **Solution :**

     - Assurez-vous que la valeur ``pir.value()`` se met correctement a jour.
     - Ajoutez des impressions de debogage pour confirmer les transitions d'etat dans la fonction ``loop()``.

4. **Affichage scintillant** :

   - **Cause :** Temporisation insuffisante ou minutage incorrect dans la mise a jour de l'affichage.
   - **Solution :** Ajoutez une petite temporisation dans la fonction ``display()`` pour stabiliser l'affichage :

       .. code-block:: python

           import time
           time.sleep(0.01)

**Idees d'extension**

1. **Compteur bidirectionnel** : Ajoutez un autre capteur PIR pour detecter le mouvement dans les deux sens et decrementer le compteur :

   .. code-block:: python

      pir2 = Pin(16, Pin.IN, pull= Pin.PULL_DOWN)
      if pir2.value()==1:
         counter -= 1

2. **Alertes basees sur un seuil** : Declenchez une alerte (par exemple, LED ou buzzer) lorsque le compteur depasse une valeur predefinie :

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if counter > 50:
            buzzer.on()
      else:
            buzzer.off()

3. **Journalisation des donnees** : Enregistrez la valeur du compteur et les horodatages dans un fichier pour analyse :

   .. code-block:: python

      with open("motion_log.txt", "a") as log_file:
            log_file.write(f"{time.time():.3f}, Counter: {counter}\n")

4. **Reinitialisation temporisee** : Reinitialisez le compteur apres une periode d'inactivite specifique :

   .. code-block:: python

      last_motion_time = time.time()
      if time.time() - last_motion_time > 300:  # 5 minutes
            counter = 0

5. **Declencheurs evenementiels** : Declenchez des actions specifiques (par exemple, controler des appareils) lorsque le compteur atteint des valeurs specifiques.
