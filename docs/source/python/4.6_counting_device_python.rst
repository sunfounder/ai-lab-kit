4.6 Dispositivo de Conteo
============================

**Introducción**

En este proyecto, construirás un sistema de conteo de personas usando un sensor de movimiento PIR y un display de 7 segmentos de 4 dígitos. El sistema incrementa el conteo mostrado cada vez que el sensor PIR detecta movimiento. Este proyecto es ideal para monitorear el tráfico peatonal en un pasillo o entrada, y proporciona experiencia práctica con programación GPIO y control de displays.

Este script de Python integra un sensor de movimiento PIR y un display de 7 segmentos controlado por un registro de desplazamiento 74HC595. El script realiza lo siguiente:

1. **Detección de Movimiento**: Un sensor de movimiento PIR conectado a GPIO 26 detecta movimiento. Cada detección de movimiento incrementa un contador.

2. **Visualización del Número**:

   - El valor actual del contador se muestra en un display de 7 segmentos de 4 dígitos.
   - El display se actualiza dinámicamente a medida que se detecta movimiento, incrementando el valor.

3. **Monitoreo Continuo**: El script monitorea continuamente el movimiento y actualiza el display en tiempo real.

4. **Salida Ordenada**: Al presionar ``Ctrl+C``, todos los pines se apagan, asegurando un cierre limpio del script.

**Código**


A continuación se muestra el script de Python utilizado en este proyecto:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull

   # Initialize PIR motion sensor on GPIO 22 (input with pull-down)
   pir = Pin(22, mode=Mode.IN, pull=Pull.DOWN)

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17, mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4, mode=Mode.OUT)   # Register Clock (latch)
   SRCLK = Pin(27, mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins used to select one of the 4 digits on the 7-segment display
   placePin = [Pin(pin, mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Segment code table for digits 0–9 (common-cathode 7-segment display)
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Counter to display the number of detections
   counter = 0

   def clearDisplay():
      """Clear the 7-segment display by shifting out 'all off' bits."""
      for _ in range(8):
         SDI.high()     # Send a high bit
         SRCLK.high()   # Clock it in
         SRCLK.low()
      RCLK.high()        # Latch output
      RCLK.low()

   def hc595_shift(data):
      """Shift a full byte of data into the 74HC595 to control the segments."""
      for i in range(8):
         SDI.value(0x80 & (data << i))  # Output next bit of the data
         SRCLK.high()                   # Pulse shift clock
         SRCLK.low()
      RCLK.high()                        # Latch data to display
      RCLK.low()

   def pickDigit(digit):
      """Enable one specific digit (0–3) on the multiplexed display."""
      for pin in placePin:
         pin.low()                      # Disable all digits
      placePin[digit].high()             # Activate the selected digit

   def display():
      """Display the current 4-digit counter value on the 7-segment display."""
      global counter

      # Display ones place
      clearDisplay()
      pickDigit(3)
      hc595_shift(number[counter % 10])

      # Display tens place
      clearDisplay()
      pickDigit(2)
      hc595_shift(number[counter % 100 // 10])

      # Display hundreds place
      clearDisplay()
      pickDigit(1)
      hc595_shift(number[counter % 1000 // 100])

      # Display thousands place
      clearDisplay()
      pickDigit(0)
      hc595_shift(number[counter % 10000 // 1000])

   def loop():
      """Main loop: continuously update display and detect PIR motion transitions."""
      global counter
      currentState = 0
      lastState = 0

      while True:
         display()                                      # Refresh 7-segment display
         currentState = 1 if pir.value() == 1 else 0    # Read PIR output

         # Detect rising edge: motion detected now, but not in last cycle
         if currentState == 1 and lastState == 0:
               counter += 1                               # Increase the count

         lastState = currentState                        # Save state for next loop

   try:
      loop()                                             # Start main loop
   except KeyboardInterrupt:
      # Clean up GPIO pins when exiting
      SDI.low()
      SRCLK.low()
      RCLK.low()
      pass


----------------------------------------------

**Comprender el Código**

1. **Detección de Movimiento:**

   El sensor PIR detecta movimiento y envía una señal para incrementar el contador.

2. **Actualización del Display:**

   Las funciones ``hc595_shift`` y ``pickDigit`` trabajan juntas para controlar el display de 7 segmentos y actualizar el contador en tiempo real.

3. **Bucle Principal:**

   La función ``loop`` verifica continuamente el sensor PIR y actualiza el display cuando se detecta movimiento.

4. **Manejo de Interrupciones:**

   El script asegura que todos los pines GPIO se apaguen de forma segura al ser interrumpido, evitando comportamientos inesperados.



----------------------------------------------


**Solución de Problemas**

1. **El Display No Funciona**:

   - **Causa**: Cableado incorrecto del display de 7 segmentos o del registro de desplazamiento.
   - **Solución**:

     - Verifica las conexiones entre los pines GPIO y los pines SDI, SRCLK y RCLK del registro de desplazamiento.
     - Asegúrate de que todas las conexiones ``placePin`` coincidan con los pines de dígitos correspondientes.

2. **El Sensor de Movimiento No Se Activa**:

   - **Causa**: Cableado del sensor PIR o interferencia ambiental.
   - **Solución**:

     - Verifica las conexiones del sensor PIR a GPIO 26, alimentación y tierra.
     - Ajusta los potenciómetros de sensibilidad y retardo del sensor PIR si están disponibles.

3. **El Contador No Incrementa**:

   - **Causa**: No se detectan cambios en el estado del sensor de movimiento.
   - **Solución**:

     - Asegúrate de que el valor ``pir.value()`` se actualice correctamente.
     - Agrega impresiones de depuración para confirmar las transiciones de estado en la función ``loop()``.

4. **El Display Parpadea**:

   - **Causa**: Retardo insuficiente o temporización incorrecta en la actualización del display.
   - **Solución**: Agrega un pequeño retardo en la función ``display()`` para estabilizar el display:

       .. code-block:: python

           import time
           time.sleep(0.01)

----------------------------------------------

**Ideas para Extender**

1. **Contador Bidireccional**: Agrega otro sensor PIR para detectar movimiento en direcciones opuestas y decrementar el contador:

   .. code-block:: python

      pir2 = Pin(16, Pin.IN, pull= Pin.PULL_DOWN)
      if pir2.value()==1:
         counter -= 1

2. **Alertas Basadas en Umbrales**: Activa una alerta (por ejemplo, LED o zumbador) cuando el contador supere un valor predefinido:

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if counter > 50:
            buzzer.on()
      else:
            buzzer.off()

3. **Registro de Datos**: Guarda el valor del contador y las marcas de tiempo en un archivo para su análisis:

   .. code-block:: python

      with open("motion_log.txt", "a") as log_file:
            log_file.write(f"{time.time():.3f}, Counter: {counter}\n")

4. **Reinicio Basado en Temporizador**: Reinicia el contador después de un período específico de inactividad:

   .. code-block:: python

      last_motion_time = time.time()
      if time.time() - last_motion_time > 300:  # 5 minutes
            counter = 0

5. **Disparadores Basados en Eventos**: Activa acciones específicas (por ejemplo, controlar electrodomésticos) cuando el contador alcanza valores específicos.
