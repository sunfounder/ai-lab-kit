2.8 电位器
===========

**介绍**

ADC（模数转换器）功能对于将模拟信号转换为数字信号至关重要。在本实验中，我们使用Fusion HAT+实现此转换，利用电位器。电位器调节电压这一物理量，然后ADC将其数字化。本实验还演示了电位器如何控制LED的亮度。

此Python脚本使用Fusion HAT+读取模拟输入并控制PWM LED的亮度。执行时：

1. Fusion HAT+持续读取模拟信号，将其转换为0到4095之间的数字值。
2. 该值映射到0到100之间，代表LED的亮度百分比。
3. PWM LED的亮度根据映射值动态调整。
4. 原始ADC值和电压实时打印到控制台。
5. 程序无限运行，直到用\ ``Ctrl+C``\ 中断，此时LED熄灭。

**代码**

以下是本实验的代码：


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Set up the potentiometer
   pot = ADC(0)

   # Initialize a PWM LED
   led = PWM(0)

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = pot.read()
         voltage = pot.read_voltage()
         print('result = %d voltage = %.2f' %(result,voltage))

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**理解代码**

1. **导入：**


   .. code-block:: python

      from fusion_hat.adc import ADC
      from fusion_hat.pwm import PWM
      import time

   脚本使用\ ``fusion_hat``\ 进行PWM LED控制和模数转换，使用\ ``time``\ 实现延迟。

2. **初始化：**


   .. code-block:: python

      # Set up the potentiometer
      pot = ADC(0)

      # Initialize a PWM LED
      led = PWM(0)

   脚本在\ ``P0``\ 引脚上初始化一个PWM LED，在\ ``A0``\ 引脚上初始化一个ADC。

3. **MAP函数：**

   .. code-block:: python

       def MAP(x, in_min, in_max, out_min, out_max):
           return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   ``MAP``\ 函数将值从一个范围转换到另一个范围，对于将ADC读数映射到LED亮度至关重要。


4. **主循环：**


   .. code-block:: python

      try:
         while True:
            # Get the current reading from the ADC port
            result = pot.read()
            voltage = pot.read_voltage()
            print('result = %d voltage = %.2f' %(result,voltage))

            # Map the ADC value to a range suitable for setting LED brightness
            value = MAP(result, 0, 4095, 0, 100)

            # Set the LED brightness
            led.pulse_width_percent(value)

            # Wait for 1 seconds before reading again
            time.sleep(0.2)

      # Graceful exit when 'Ctrl+C' is pressed
      except KeyboardInterrupt:
         led.pulse_width_percent(0)  # Turn off the LED

   - 持续读取ADC值。
   - 将ADC读数（0-4095）映射到亮度级别（0-100）。
   - 调整LED亮度并等待0.2秒后重复。

**故障排除**

1. **LED无响应**

   - **原因**：接线错误或GPIO引脚配置不正确。
   - **解决方案**：确保LED连接到PWM 0并带有合适的电阻。

2. **ADC值始终为零**

   - **原因**：传感器接线错误。
   - **解决方案**：检查传感器连接。确保输入传感器正常工作。

3. **映射问题**

   - **原因**：\ ``MAP()``\ 函数参数不正确。
   - **解决方案**：确保输入范围（\ ``in_min``\ 、\ ``in_max``\ ）匹配输出范围（0-4095），且输出范围（\ ``out_min``\ 、\ ``out_max``\ ）适合LED亮度控制（0-100）。
