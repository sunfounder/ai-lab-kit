2.8 Potenziometro
===================

**Introduzione**

La funzione ADC (Convertitore Analogico-Digitale) è essenziale per convertire segnali analogici in digitali. In questo esperimento, usiamo Fusion HAT+ per realizzare questa conversione, utilizzando un potenziometro. Il potenziometro regola la tensione, una grandezza fisica, che l'ADC poi digitalizza. Questo esperimento dimostra anche come il potenziometro possa controllare la luminosità di un LED.

   cd ~/ai-lab-kit/python/
   sudo python3 2.8_Potentiometer.py

Questo script Python usa un Fusion HAT+ per leggere l'ingresso analogico e controllare la luminosità di un LED PWM. Quando eseguito:

1. Fusion HAT+ legge continuamente un segnale analogico, convertendolo in un valore digitale tra 0 e 4095.
2. Questo valore viene mappato in un intervallo tra 0 e 100, che rappresenta la percentuale di luminosità del LED.
3. La luminosità del LED PWM viene regolata dinamicamente in base al valore mappato.
4. Il valore ADC grezzo e la tensione vengono stampati sulla console in tempo reale.
5. Il programma viene eseguito indefinitamente fino a quando non viene interrotto con ``Ctrl+C``, a quel punto il LED si spegne.

**Codice**

Qui sotto c'è il codice per l'esperimento:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Set up the potentiometer
   pot = ADC(0)

   # Initialize a PWM LED
   led = PWM(0)

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = pot.read()
         voltage = pot.read_voltage()
         print('result = %d voltage = %.2f' %(result,voltage))

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**Comprendere il Codice**

1. **Importazioni:**


   .. code-block:: python

      from fusion_hat.adc import ADC
      from fusion_hat.pwm import PWM
      import time

   Lo script usa ``fusion_hat`` per il controllo del LED PWM e la conversione analogico-digitale, e ``time`` per implementare i ritardi.

2. **Inizializzazione:**


   .. code-block:: python

      # Set up the potentiometer
      pot = ADC(0)

      # Initialize a PWM LED
      led = PWM(0)

   Lo script inizializza un LED PWM sul pin ``P0`` e un ADC sul pin ``A0``.

3. **Funzione MAP:**

   .. code-block:: python

       def MAP(x, in_min, in_max, out_min, out_max):
           return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   La funzione ``MAP`` converte valori da un intervallo a un altro, essenziale per mappare le letture ADC alla luminosità del LED.


4. **Ciclo Principale:**


   .. code-block:: python

      try:
         while True:
            # Get the current reading from the ADC port
            result = pot.read()
            voltage = pot.read_voltage()
            print('result = %d voltage = %.2f' %(result,voltage))

            # Map the ADC value to a range suitable for setting LED brightness
            value = MAP(result, 0, 4095, 0, 100)

            # Set the LED brightness
            led.pulse_width_percent(value)

            # Wait for 1 seconds before reading again
            time.sleep(0.2)

      # Graceful exit when 'Ctrl+C' is pressed
      except KeyboardInterrupt:
         led.pulse_width_percent(0)  # Turn off the LED

   - Legge continuamente i valori ADC.
   - Mappa le letture ADC (0-4095) a livelli di luminosità (0-100).
   - Regola la luminosità del LED e attende 0,2 secondi prima di ripetere.

**Risoluzione dei Problemi**

1. **Il LED Non Risponde**

   - **Causa**: Cablaggio errato o configurazione errata del pin GPIO.
   - **Soluzione**: Assicurati che il LED sia collegato a PWM 0 con un resistore appropriato.

2. **Valori ADC Sempre Zero**

   - **Causa**: Cablaggio errato del sensore.
   - **Soluzione**: Verifica le connessioni del sensore. Assicurati che il sensore di ingresso funzioni.

3. **Problemi di Mappatura**

   - **Causa**: Parametri errati della funzione ``MAP()``.
   - **Soluzione**: Assicurati che l'intervallo di ingresso (``in_min``, ``in_max``) corrisponda all'intervallo di uscita (0-4095) e che l'intervallo di uscita (``out_min``, ``out_max``) sia adatto per il controllo della luminosità del LED (0-100).
