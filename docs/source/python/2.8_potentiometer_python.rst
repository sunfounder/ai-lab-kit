2.8 Potentiometre
====================

**Introduction**

La fonction CAN (Convertisseur Analogique-Numerique) est essentielle pour convertir les signaux analogiques en signaux numeriques. Dans cette experience, nous utilisons le Fusion HAT+ pour realiser cette conversion, en utilisant un potentiometre. Le potentiometre ajuste la tension, une grandeur physique, que le CAN numerise ensuite. Cette experience montre egalement comment le potentiometre peut controler la luminosite d'une LED.

Ce script Python utilise un Fusion HAT+ pour lire une entree analogique et controler la luminosite d'une LED PWM. Lors de l'execution :

1. Le Fusion HAT+ lit en continu un signal analogique, le convertissant en une valeur numerique entre 0 et 4095.
2. Cette valeur est mappee a une plage comprise entre 0 et 100, representant le pourcentage de luminosite de la LED.
3. La luminosite de la LED PWM est ajustee dynamiquement en fonction de la valeur mappee.
4. La valeur ADC brute et la tension sont affichees sur la console en temps reel.
5. Le programme s'execute indefiniment jusqu'a ce qu'il soit interrompu avec ``Ctrl+C``, moment auquel la LED s'eteint.

**Code**

Voici le code pour l'experience :


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Set up the potentiometer
   pot = ADC(0)

   # Initialize a PWM LED
   led = PWM(0)

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = pot.read()
         voltage = pot.read_voltage()
         print('result = %d voltage = %.2f' %(result,voltage))

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**Comprendre le code**

1. **Importations :**


   .. code-block:: python

      from fusion_hat.adc import ADC
      from fusion_hat.pwm import PWM
      import time

   Le script utilise ``fusion_hat`` pour le controle de la LED PWM et la conversion analogique-numerique, et ``time`` pour implementer les pauses.

2. **Initialisation :**


   .. code-block:: python

      # Set up the potentiometer
      pot = ADC(0)

      # Initialize a PWM LED
      led = PWM(0)

   Le script initialise une LED PWM sur la broche ``P0`` et un CAN sur la broche ``A0``.

3. **Fonction MAP :**

   .. code-block:: python

       def MAP(x, in_min, in_max, out_min, out_max):
           return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   La fonction ``MAP`` convertit les valeurs d'une plage a une autre, essentielle pour mapper les lectures ADC a la luminosite de la LED.


4. **Boucle principale :**


   .. code-block:: python

      try:
         while True:
            # Get the current reading from the ADC port
            result = pot.read()
            voltage = pot.read_voltage()
            print('result = %d voltage = %.2f' %(result,voltage))

            # Map the ADC value to a range suitable for setting LED brightness

            # Wait for 1 seconds before reading again
            time.sleep(0.2)

         led.pulse_width_percent(0)  # Turn off the LED

   - Lit en continu les valeurs ADC.
   - Mappe les lectures ADC (0-4095) aux niveaux de luminosite (0-100).
   - Ajuste la luminosite de la LED et attend 0,2 seconde avant de repeter.


----------------------------------------------

**Depannage**

1. **La LED ne repond pas**

   - **Cause** : Cablage incorrect ou configuration de broche GPIO.
   - **Solution** : Assurez-vous que la LED est connectee a PWM 0 avec une resistance appropriee.

2. **Les valeurs ADC sont toujours a zero**

   - **Cause** : Cablage incorrect du capteur.
   - **Solution** : Verifiez les connexions du capteur. Assurez-vous que le capteur d'entree fonctionne.

3. **Problemes de mappage**

   - **Cause** : Parametres de fonction ``MAP()`` incorrects.
   - **Solution** : Assurez-vous que la plage d'entree (``in_min``, ``in_max``) correspond a la plage de sortie (0-4095) et que la plage de sortie (``out_min``, ``out_max``) est adaptee au controle de luminosite de la LED (0-100).
