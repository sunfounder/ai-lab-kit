2.8 Potenciómetro
===================

**Introducción**

La función ADC (Convertidor Analógico-Digital) es esencial para convertir señales analógicas en digitales. En este experimento, utilizamos el Fusion HAT+ para lograr esta conversión, empleando un potenciómetro. El potenciómetro ajusta el voltaje, una magnitud física, que el ADC luego digitaliza. Este experimento también demuestra cómo el potenciómetro puede controlar el brillo de un LED.

Este script de Python utiliza un Fusion HAT+ para leer una entrada analógica y controlar el brillo de un LED PWM. Cuando se ejecuta:

1. El Fusion HAT+ lee continuamente una señal analógica, convirtiéndola en un valor digital entre 0 y 4095.
2. Este valor se mapea a un rango entre 0 y 100, que representa el porcentaje de brillo del LED.
3. El brillo del LED PWM se ajusta dinámicamente según el valor mapeado.
4. El valor ADC bruto y el voltaje se imprimen en la consola en tiempo real.
5. El programa se ejecuta indefinidamente hasta que se interrumpe con ``Ctrl+C``, momento en el cual el LED se apaga.

**Código**

A continuación se muestra el código del experimento:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.adc import ADC
   from fusion_hat.pwm import PWM
   import time

   # Set up the potentiometer
   pot = ADC(0)

   # Initialize a PWM LED
   led = PWM(0)

   def MAP(x, in_min, in_max, out_min, out_max):

      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = pot.read()
         voltage = pot.read_voltage()
         print('result = %d voltage = %.2f' %(result,voltage))

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt:
      led.pulse_width_percent(0)  # Turn off the LED

**Comprender el Código**

1. **Importaciones:**


   .. code-block:: python

      from fusion_hat.adc import ADC
      from fusion_hat.pwm import PWM
      import time

   El script utiliza ``fusion_hat`` para el control del LED PWM y la conversión analógico-digital, y ``time`` para implementar retardos.

2. **Inicialización:**


   .. code-block:: python

      pot = ADC(0)

      # Initialize a PWM LED
      led = PWM(0)

   El script inicializa un LED PWM en el pin ``P0`` y un ADC en el pin ``A0``.

3. **Función MAP:**

   .. code-block:: python

           return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   La función ``MAP`` convierte valores de un rango a otro, esencial para mapear las lecturas del ADC al brillo del LED.


4. **Bucle Principal:**

**Solución de Problemas**

1. **El LED No Responde**

   - **Causa**: Cableado incorrecto o configuración del pin GPIO.
   - **Solución**: Asegúrate de que el LED esté conectado a PWM 0 con una resistencia adecuada.

2. **Los Valores ADC Son Siempre Cero**

   - **Causa**: Cableado incorrecto del sensor.
   - **Solución**: Verifica las conexiones del sensor. Asegúrate de que el sensor de entrada esté funcionando.

3. **Problemas de Mapeo**

   - **Causa**: Parámetros incorrectos de la función ``MAP()``.
   - **Solución**: Asegúrate de que el rango de entrada (``in_min``, ``in_max``) coincida con el rango de salida (0-4095) y que el rango de salida (``out_min``, ``out_max``) sea adecuado para el control de brillo del LED (0-100).
