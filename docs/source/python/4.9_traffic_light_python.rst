4.9 Simulazione Semaforo
==============================

**Introduzione**

Questo progetto dimostra l'uso di LED e un display a 7 segmenti a 4 cifre per simulare un sistema semaforico reale. I LED rappresentano le luci rossa, gialla e verde, mentre il display a 7 segmenti conta alla rovescia il tempo rimanente per ogni luce. Fornisce un modo coinvolgente per imparare il controllo GPIO, la temporizzazione e i display a 7 segmenti in un contesto educativo o prototipale.

**Codice**


Ecco lo script Python per la simulazione semaforica:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.pin import Pin, Mode
   import threading

   # Setup GPIO pins for 74HC595 shift register
   SDI = Pin(17,mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4,mode=Mode.OUT)  # Register Clock
   SRCLK = Pin(27,mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Segment codes for numbers 0-9 on 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Setup GPIO pins for traffic light LEDs
   ledPinR = Pin(5,mode=Mode.OUT) # Red LED
   ledPinG = Pin(6,mode=Mode.OUT)  # Green LED
   ledPinY = Pin(13,mode=Mode.OUT)  # Yellow LED

   # Duration settings for traffic lights
   greenLight = 30
   yellowLight = 5
   redLight = 60

   # Traffic light color names
   lightColor = ("Red", "Green", "Yellow")

   # Initialize state variables
   colorState = 0
   counter = 60
   timer1 = None

   def setup():
      """ Initialize the traffic light system and start the timer. """
      global timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift data to the 74HC595 shift register for digit display. """
      for i in range(8):
         SDI.value(0x80 & (data << i))
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def pickDigit(digit):
      """ Select a specific digit to display on the 7-segment display. """
      for pin in placePin:
         pin.low()
      placePin[digit].high()

   def timer():
      """ Handle the timing for traffic light changes. """
      global counter, colorState, timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()
      counter -= 1
      if counter == 0:
         counter = [greenLight, yellowLight, redLight][colorState]
         colorState = (colorState + 1) % 3
      print(f"counter : {counter}    color: {lightColor[colorState]}")

   def lightup():
      """ Update the traffic light LED based on the current state. """
      global colorState
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()
      [ledPinR, ledPinG, ledPinY][colorState].high()

   def display():
      """ Display the current counter value on the 7-segment display. """
      global counter

      for i in range(4):
         digit = counter // (10 ** (3 - i)) % 10
         if i == 0 and digit == 0:
               continue
         clearDisplay()
         pickDigit(i)
         hc595_shift(number[digit])

   def loop():
      """ Main loop to continuously update display and lights. """
      while True:
         display()
         lightup()

   def destroy():
      """ Clean up resources when the script is terminated. """
      global timer1
      timer1.cancel()
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()

   try:
      setup()
      loop()
   except KeyboardInterrupt:
      destroy()

**Comprendere il Codice**

1. **Inizializzazione:**

   * Configura i pin GPIO per il registro a scorrimento, il display a 7 segmenti e i LED del semaforo.
   * Definisce le costanti per le durate delle luci e inizializza le variabili di stato.

2. **Funzioni del Display a 7 Segmenti:**

   * ``clearDisplay``: Cancella tutti i segmenti sul display.
   * ``hc595_shift``: Invia dati al registro a scorrimento per controllare i segmenti del display.
   * ``pickDigit``: Attiva una cifra specifica per il multiplexing.

3. **Funzione Timer:**

   * Gestisce il conto alla rovescia e le transizioni tra gli stati delle luci.

4. **Controllo del Semaforo:**

   * Aggiorna i LED in base allo stato corrente.

5. **Ciclo Principale:**

   * Aggiorna continuamente il display e i LED.

6. **Pulizia:**

   * Assicura che tutte le risorse siano rilasciate correttamente alla terminazione.


----------------------------------------------


**Risoluzione dei Problemi**

1. **Semafori Non Funzionanti**:

   - **Causa**: Cablaggio errato o LED difettosi.
   - **Soluzione**:

     - Verifica che i LED siano correttamente collegati ai pin GPIO 5 (Rosso), 6 (Verde) e 13 (Giallo).
     - Testa ogni LED individualmente usando uno script di controllo GPIO semplice.

2. **Il Display a 7 Segmenti Non Mostra il Conto Alla Rovescia**:

   - **Causa**: Cablaggio errato o configurazione del registro a scorrimento.
   - **Soluzione**:

     - Assicurati che i pin ``SDI``, ``RCLK`` e ``SRCLK`` del registro a scorrimento siano correttamente collegati rispettivamente a GPIO 17, 4 e 27.
     - Verifica che i pin di selezione delle cifre corrispondano alla configurazione ``placePin``.

3. **Il Timer del Conto Alla Rovescia si Blocca**:

   - **Causa**: Il thread del timer non si riavvia correttamente.
   - **Soluzione**: Assicurati che la funzione ``timer()`` chiami ``timer1.start()`` per riavviare il thread del timer.

4. **Durata Luci Errata**:

   - **Causa**: Valori di durata errati o transizioni di stato.
   - **Soluzione**:

     - Verifica le durate ``redLight``, ``greenLight`` e ``yellowLight``.
     - Controlla la logica della funzione ``timer()`` per assicurare transizioni di stato corrette.

**Idee Estendibili**

1. **Attraversamento Pedonale**: Aggiungi un pulsante per attraversamento pedonale che interrompe temporaneamente il ciclo semaforico per permettere ai pedoni di attraversare in sicurezza.

   .. code-block:: python

      from fusion_hat import Pin
      pedestrian_button = Pin(22, Pin.IN, Pin.PULL_DOWN)

      def handle_pedestrian():
            global colorState, counter
            if colorState == 1:  # If Green Light
               counter = 5  # Shorten green light duration
      pedestrian_button.when_activated = handle_pedestrian

2. **Temporizzazione Adattiva**: Regola le durate delle luci del semaforo dinamicamente in base alla densità del traffico in tempo reale.

3. **Registrazione Eventi**: Registra i cambiamenti di stato del semaforo con timestamp in un file per l'analisi:
