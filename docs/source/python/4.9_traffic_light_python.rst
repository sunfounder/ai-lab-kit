4.9 Simulación de Semáforo
==============================

**Introducción**

Este proyecto demuestra el uso de LEDs y un display de 7 segmentos de 4 dígitos para simular un sistema de semáforo real. Los LEDs representan las luces roja, amarilla y verde, mientras que el display de 7 segmentos cuenta regresivamente el tiempo restante para cada luz. Proporciona una forma atractiva de aprender sobre el control de GPIO, temporización y displays de 7 segmentos en un entorno educativo o de prototipado.

**Código**


Aquí está el script de Python para la simulación de semáforo:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.pin import Pin, Mode
   import threading

   # Setup GPIO pins for 74HC595 shift register
   SDI = Pin(17,mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4,mode=Mode.OUT)  # Register Clock
   SRCLK = Pin(27,mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Segment codes for numbers 0-9 on 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Setup GPIO pins for traffic light LEDs
   ledPinR = Pin(5,mode=Mode.OUT) # Red LED
   ledPinG = Pin(6,mode=Mode.OUT)  # Green LED
   ledPinY = Pin(13,mode=Mode.OUT)  # Yellow LED

   # Duration settings for traffic lights
   greenLight = 30
   yellowLight = 5
   redLight = 60

   # Traffic light color names
   lightColor = ("Red", "Green", "Yellow")

   # Initialize state variables
   colorState = 0
   counter = 60
   timer1 = None

   def setup():
      """ Initialize the traffic light system and start the timer. """
      global timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift data to the 74HC595 shift register for digit display. """
      for i in range(8):
         SDI.value(0x80 & (data << i))
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def pickDigit(digit):
      """ Select a specific digit to display on the 7-segment display. """
      for pin in placePin:
         pin.low()
      placePin[digit].high()

   def timer():
      """ Handle the timing for traffic light changes. """
      global counter, colorState, timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()
      counter -= 1
      if counter == 0:
         counter = [greenLight, yellowLight, redLight][colorState]
         colorState = (colorState + 1) % 3
      print(f"counter : {counter}    color: {lightColor[colorState]}")

   def lightup():
      """ Update the traffic light LED based on the current state. """
      global colorState
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()
      [ledPinR, ledPinG, ledPinY][colorState].high()

   def display():
      """ Display the current counter value on the 7-segment display. """
      global counter

      for i in range(4):
         digit = counter // (10 ** (3 - i)) % 10
         if i == 0 and digit == 0:
               continue
         clearDisplay()
         pickDigit(i)
         hc595_shift(number[digit])

   def loop():
      """ Main loop to continuously update display and lights. """
      while True:
         display()
         lightup()

   def destroy():
      """ Clean up resources when the script is terminated. """
      global timer1
      timer1.cancel()
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()

   try:
      setup()
      loop()
   except KeyboardInterrupt:
      destroy()

**Comprender el Código**

1. **Inicialización:**

   * Configura los pines GPIO para el registro de desplazamiento, el display de 7 segmentos y los LEDs del semáforo.
   * Define las constantes para las duraciones de las luces e inicializa las variables de estado.

2. **Funciones del Display de 7 Segmentos:**

   * ``clearDisplay``: Limpia todos los segmentos en el display.
   * ``hc595_shift``: Envía datos al registro de desplazamiento para controlar los segmentos del display.
   * ``pickDigit``: Activa un dígito específico para multiplexación.

3. **Función de Temporización:**

   * Maneja la cuenta regresiva y las transiciones entre estados de las luces.

4. **Control del Semáforo:**

   * Actualiza los LEDs según el estado actual.

5. **Bucle Principal:**

   * Actualiza continuamente el display y los LEDs.

6. **Limpieza:**

   * Asegura que todos los recursos se liberen correctamente al finalizar.


----------------------------------------------


**Solución de Problemas**

1. **Los Semáforos No Funcionan**:

   - **Causa**: Cableado incorrecto o LEDs defectuosos.
   - **Solución**:

     - Verifique que los LEDs estén correctamente conectados a los pines GPIO 5 (Rojo), 6 (Verde) y 13 (Amarillo).
     - Pruebe cada LED individualmente usando un script simple de control GPIO.

2. **El Display de 7 Segmentos No Muestra la Cuenta Regresiva**:

   - **Causa**: Cableado incorrecto o configuración del registro de desplazamiento.
   - **Solución**:

     - Asegúrese de que los pines ``SDI``, ``RCLK`` y ``SRCLK`` del registro de desplazamiento estén correctamente conectados a GPIO 17, 4 y 27, respectivamente.
     - Verifique que los pines de selección de dígitos coincidan con la configuración de ``placePin``.

3. **El Temporizador de Cuenta Regresiva se Congela**:

   - **Causa**: El hilo del temporizador no se reinicia correctamente.
   - **Solución**: Asegúrese de que la función ``timer()`` llame a ``timer1.start()`` para reiniciar el hilo del temporizador.

4. **Duraciones de Luz Incorrectas**:

   - **Causa**: Valores de duración incorrectos o transiciones de estado.
   - **Solución**:

     - Verifique las duraciones de ``redLight``, ``greenLight`` y ``yellowLight``.
     - Revise la lógica de la función ``timer()`` para asegurar transiciones de estado correctas.

**Ideas para Extender**

1. **Paso de Peatones**: Agregue un botón de paso de peatones que interrumpa temporalmente el ciclo del semáforo para permitir que los peatones crucen de forma segura.

   .. code-block:: python

      from fusion_hat import Pin
      pedestrian_button = Pin(22, Pin.IN, Pin.PULL_DOWN)

      def handle_pedestrian():
            global colorState, counter
            if colorState == 1:  # If Green Light
               counter = 5  # Shorten green light duration
      pedestrian_button.when_activated = handle_pedestrian

2. **Temporización Adaptativa**: Ajuste las duraciones de las luces del semáforo dinámicamente según la densidad del tráfico en tiempo real.

3. **Registro de Eventos**: Registre los cambios de estado del semáforo con marcas de tiempo en un archivo para su análisis:

   .. code-block:: python

      with open("traffic_log.txt", "a") as log_file:
            log_file.write(f"{time.strftime('%Y-%m-%d %H:%M:%S')} - {lightColor[colorState]} light\n")
