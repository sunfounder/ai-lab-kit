4.9 Simulation de feux de circulation
=============================================

**Introduction**

Ce projet demontre l’utilisation de LEDs et d’un afficheur 7 segments a 4 chiffres pour simuler un systeme de feux de circulation reel. Les LEDs representent les lumieres rouge, jaune et verte, tandis que l’afficheur 7 segments compte a rebours le temps restant pour chaque feu. Cela offre une facon engageante d’apprendre le controle GPIO, le chronometrage et les afficheurs 7 segments dans un cadre educatif ou de prototypage.

**Code**


Voici le script Python pour la simulation de feux de circulation :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.pin import Pin, Mode
   import threading

   # Setup GPIO pins for 74HC595 shift register
   SDI = Pin(17,mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4,mode=Mode.OUT)  # Register Clock
   SRCLK = Pin(27,mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Segment codes for numbers 0-9 on 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Setup GPIO pins for traffic light LEDs
   ledPinR = Pin(5,mode=Mode.OUT) # Red LED
   ledPinG = Pin(6,mode=Mode.OUT)  # Green LED
   ledPinY = Pin(13,mode=Mode.OUT)  # Yellow LED

   # Duration settings for traffic lights
   greenLight = 30
   yellowLight = 5
   redLight = 60

   # Traffic light color names
   lightColor = ("Red", "Green", "Yellow")

   # Initialize state variables
   colorState = 0
   counter = 60
   timer1 = None

   def setup():
      """ Initialize the traffic light system and start the timer. """
      global timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift data to the 74HC595 shift register for digit display. """
      for i in range(8):
         SDI.value(0x80 & (data << i))
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def pickDigit(digit):
      """ Select a specific digit to display on the 7-segment display. """
      for pin in placePin:
         pin.low()
      placePin[digit].high()

   def timer():
      """ Handle the timing for traffic light changes. """
      global counter, colorState, timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()
      counter -= 1
      if counter == 0:
         counter = [greenLight, yellowLight, redLight][colorState]
         colorState = (colorState + 1) % 3
      print(f"counter : {counter}    color: {lightColor[colorState]}")

   def lightup():
      """ Update the traffic light LED based on the current state. """
      global colorState
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()
      [ledPinR, ledPinG, ledPinY][colorState].high()

   def display():
      """ Display the current counter value on the 7-segment display. """
      global counter

      for i in range(4):
         digit = counter // (10 ** (3 - i)) % 10
         if i == 0 and digit == 0:
               continue
         clearDisplay()
         pickDigit(i)
         hc595_shift(number[digit])

   def loop():
      """ Main loop to continuously update display and lights. """
      while True:
         display()
         lightup()

   def destroy():
      """ Clean up resources when the script is terminated. """
      global timer1
      timer1.cancel()
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()

   try:
      setup()
      loop()
   except KeyboardInterrupt:
      destroy()

**Comprendre le code**

1. **Initialisation :**

   * Configure les broches GPIO pour le registre a decalage, l’afficheur 7 segments et les LEDs de feux de circulation.
   * Definit les constantes pour les durees des feux et initialise les variables d’etat.

2. **Fonctions de l’afficheur 7 segments :**

   * ``clearDisplay`` : Efface tous les segments de l’afficheur.
   * ``hc595_shift`` : Envoie les donnees au registre a decalage pour controler les segments de l’afficheur.
   * ``pickDigit`` : Active un chiffre specifique pour le multiplexage.

3. **Fonction de chronometre :**

   * Gere le compte a rebours et les transitions entre les etats des feux.

4. **Controle des feux de circulation :**

   * Met a jour les LEDs en fonction de l’etat actuel.

5. **Boucle principale :**

   * Met a jour en continu l’affichage et les LEDs.

6. **Nettoyage :**

   * Garantit que toutes les ressources sont correctement liberees a la terminaison.


----------------------------------------------


**Depannage**

1. **Les feux de circulation ne fonctionnent pas** :

   - **Cause :** Cablage incorrect ou LEDs defectueuses.
   - **Solution :**

     - Verifiez que les LEDs sont correctement connectees aux broches GPIO 5 (Rouge), 6 (Vert) et 13 (Jaune).
     - Testez chaque LED individuellement a l’aide d’un simple script de controle GPIO.

2. **L’afficheur 7 segments n’affiche pas le compte a rebours** :

   - **Cause :** Cablage incorrect ou configuration du registre a decalage.
   - **Solution :**

     - Assurez-vous que les broches ``SDI``, ``RCLK`` et ``SRCLK`` du registre a decalage sont correctement connectees aux GPIO 17, 4 et 27 respectivement.
     - Verifiez que les broches de selection de chiffres correspondent a la configuration ``placePin``.

3. **Le chronometre se fige** :

   - **Cause :** Le thread du chronometre ne redemarre pas correctement.
   - **Solution :** Assurez-vous que la fonction ``timer()`` appelle ``timer1.start()`` pour redemarrer le thread du chronometre.

4. **Durees des feux incorrectes** :

   - **Cause :** Valeurs de duree incorrectes ou transitions d’etat erronees.
   - **Solution :**

     - Verifiez les durees ``redLight``, ``greenLight`` et ``yellowLight``.
     - Verifiez la logique de la fonction ``timer()`` pour garantir des transitions d’etat correctes.

**Idees d’extension**

1. **Passage pieton** : Ajoutez un bouton de passage pieton qui interrompt temporairement le cycle de circulation pour permettre aux pietons de traverser en toute securite.

   .. code-block:: python

      from fusion_hat import Pin
      pedestrian_button = Pin(22, Pin.IN, Pin.PULL_DOWN)

      def handle_pedestrian():
            global colorState, counter
            if colorState == 1:  # Si feu vert
               counter = 5  # Reduire la duree du feu vert
      pedestrian_button.when_activated = handle_pedestrian

2. **Temporisation adaptative** : Ajustez les durees des feux de circulation dynamiquement en fonction de la densite du trafic en temps reel.

3. **Journalisation des evenements** : Enregistrez les changements d’etat des feux avec des horodatages dans un fichier pour analyse :
