QMC5883L
==========================

In this lesson, we focus on the QMC5883L sensor built into the GY-87 module.
In this lesson, you will learn how to read magnetic field data, calibrate the sensor, and compute an accurate compass heading using your Raspberry Pi.  
This sensor is widely used in robotics, drones, and navigation projects because it provides reliable direction information when properly calibrated.

Calibrating the QMC5883L
--------------------------------------

Before using the QMC5883L magnetometer on the GY-87 module, it must be calibrated.  
Calibration removes magnetic distortion and ensures accurate heading readings.

Follow these steps to complete the calibration process:

#. Run the calibration script:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 2.15_GY87_QMC5883L_Calibrate.py

   If the sensor is detected, you will see output such as:

   .. code-block::

      Magnetometer: QMC5883L @0x0D
      Calibration starts in 3 seconds...

#. Rotate the sensor in all directions.

   When prompted, gently rotate the GY-87 module:

   - Move it slowly in **every** direction  
   - Rotate it in **roll**, **pitch**, and **yaw**  
   - Try to draw a **large sphere** in the air  
     
   This helps the calibration tool capture the full magnetic range on the X, Y, and Z axes.

   During rotation, the terminal will continuously update values such as:

   .. code-block::

      X[-0.0461,+0.0283]  Y[-0.0104,+0.0587]  Z[-0.0795,-0.0100]

   Allow the script to collect data for the full duration.

#. Wait for the calibration to finish.

   When the process completes, the tool will output the calibration parameters:

   .. code-block::

      mag_offsets = (-0.008875, 0.024125, -0.044750)
      mag_scales  = (0.954087, 1.027744, 1.021583)

   These values include:

   - Offsets (hard-iron correction)
   - Scale factors (soft-iron correction)

Your QMC5883L magnetometer is now corrected and ready for accurate heading calculations.



Accurate Heading Calculations
--------------------------------------------------

After completing the calibration, you must apply the calibration values in your heading-reading script.  
Follow the steps below to update and verify the result:

#. Open the ``2.15_GY87_QMC5883L.py`` file and edit it:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo nano 2.15_GY87_QMC5883L.py

#. Replace the placeholder calibration values with the ones you obtained from the calibration tool.

   .. code-block:: python

      mag_offsets = (OFFSET_X, OFFSET_Y, OFFSET_Z)
      mag_scales  = (SCALE_X,  SCALE_Y,  SCALE_Z)

   Make sure you paste the exact numbers from your calibration output.

#. Press ``Ctrl+X``, then ``Y`` to save the file, and press ``Enter`` to exit Nano.

#. Run the script to test the heading results:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python/
      sudo python3 2.15_GY87_QMC5883L.py

#. Once the program starts, you should see output similar to:

   .. code-block:: text

      Bypass enabled: USER_CTRL=0x00, INT_PIN_CFG=0x02
      MPU6050 bypass enabled
      Magnetometer: QMC5883L @0x0D
      Heading:  41.39°
      Heading:  43.12°
      Heading:  45.88°

   Place the module flat on a table and slowly rotate it 360°.  
   Observe how the heading changes.

#. Evaluate the heading accuracy:

   * Good signs that calibration worked:

     - The heading smoothly changes from **0° → 360° → 0°** as you rotate the sensor.
     - When you complete a full rotation, the heading should return close to the original angle.
     - Turning clockwise / counterclockwise should change the angle in a clear, intuitive direction.

   * You should redo the calibration if:

     - The rotation during calibration was uneven (you did not reach all directions).
     - The heading is significantly inaccurate or wrong in certain directions.
     - The sensor’s environment has changed (e.g., placed near motors, metal cases, strong magnets, power supplies, etc.).


**Code**

Below is an example showing how to apply the magnetometer calibration values  
to compute a corrected heading angle.

.. raw:: html
   
   <run></run>
   
.. code-block:: python

   from fusion_hat.modules.magnetometer import Magnetometer
   import math
   import time

   # Initialize the magnetometer (auto-detects QMC5883L / QMC5883P / HMC5883L / QMC6310)
   mag = Magnetometer()

   mag_offsets = (OFFSET_X, OFFSET_Y, OFFSET_Z)
   mag_scales  = (SCALE_X,  SCALE_Y,  SCALE_Z)

   try:
      while True:
         # Read raw magnetic field values (Gauss)
         mx, my, mz = mag.read()

         # Apply hard-iron offset and soft-iron scaling to each axis
         mx = (mx - mag_offsets[0]) * mag_scales[0]   # Corrected X
         my = (my - mag_offsets[1]) * mag_scales[1]   # Corrected Y
         mz = (mz - mag_offsets[2]) * mag_scales[2]   # Corrected Z (not used for heading)

         # Compute heading angle (atan2 gives angle from +X axis)
         heading = math.degrees(math.atan2(my, mx))

         # Convert negative angles into a 0–360° range
         if heading < 0:
               heading += 360

         # Print heading in degrees
         print(f"Heading: {heading:6.2f}°")

         # Small delay between updates
         time.sleep(0.2)

   except KeyboardInterrupt:
      # Graceful exit when user presses Ctrl+C
      print("\nHeading measurement stopped by user.")


**Understanding the Code**

1. **Import Modules**

   .. code-block:: python

      from fusion_hat.modules.magnetometer import Magnetometer
      import math, time

   - ``Magnetometer`` reads data from QMC5883L / QMC5883P / HMC5883L / QMC6310.  
   - ``math`` is used for heading angle calculation.

2. **Create Magnetometer Object**

   .. code-block:: python

      mag = Magnetometer()

   Automatically detects which compass chip exists on the GY-87 board.

3. **Load Calibration Values**

   .. code-block:: python

      mag_offsets = (...)
      mag_scales  = (...)

   These values correct:

   - **Hard-iron distortion** (constant offset)  
   - **Soft-iron distortion** (scale differences)

4. **Read and Calibrate Magnetometer Data**

   .. code-block:: python

      mx, my, mz = mag.read()

      mx = (mx - mag_offsets[0]) * mag_scales[0]
      my = (my - mag_offsets[1]) * mag_scales[1]
      mz = (mz - mag_offsets[2]) * mag_scales[2]

   First remove the offset, then apply the scale multiplier.

5. **Compute Heading Angle**

   .. code-block:: python

      heading = math.degrees(math.atan2(my, mx))
      if heading < 0:
          heading += 360

   ``atan2(y, x)`` gives an angle in radians, which is converted to degrees.  
   Values are normalized to **0–360°**.

6. **Graceful Exit**

   .. code-block:: python

      except KeyboardInterrupt:
          print("\nStopped by user.")

   Allows the program to stop cleanly when pressing **Ctrl + C**.

Troubleshooting
--------------------------

#. **No Magnetic Data or All Zeros**

   - **Cause**: The magnetometer is not detected on the I2C bus.
   - **Solutions**:

     * Run ``i2cdetect -y 1`` and make sure address **0x0D** (QMC5883L) appears.
     * Ensure the MPU6050 bypass mode is enabled (the driver does this automatically).
     * Check wiring and confirm SDA/SCL are properly connected.

#. **Heading Drifts or Seems Unstable**

   - **Cause**: Sensor not calibrated or placed near magnetic interference.
   - **Solutions**:

     * Perform the full calibration procedure again.
     * Keep the sensor away from motors, speakers, batteries, metal cases, or magnets.

#. **Heading Jumps or Does Not Cover 0–360° Smoothly**

   - **Cause**: Incorrect offsets or scale factors.
   - **Solutions**:

     * Repeat the calibration while ensuring you rotate the module in *all* orientations.
     * Verify you correctly copied the calibration values into your project.

#. **Incorrect Rotation Direction**

   - **Cause**: Your coordinate system or axis placement does not match your project.
   - **Solutions**:

     * Adjust the ``atan2(my, mx)`` axis order.
     * Invert axes (multiply by -1) if physical orientation differs.
