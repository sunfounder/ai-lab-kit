**Codice**

Il seguente codice Python dimostra come controllare il servomotore spostandolo tra vari angoli:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.servo import Servo   # Import Servo class
   from time import sleep               # Import sleep for delays

   # Initialize servo on channel 0
   servo = Servo(0)

   try:
      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)

   except KeyboardInterrupt:
      # Stop the program safely when Ctrl+C is pressed
      servo.angle(0)        # Return servo to center position
      sleep(0.1)


Questo script Python controlla un servomotore collegato a PWM 0. Quando eseguito:

1. Il servomotore si sposta da -90 gradi a 90 gradi in incrementi di 10 gradi.
2. Si ferma per 0,1 secondi tra ogni movimento.
3. Poi inverte la direzione e si sposta da 90 gradi a -90 gradi in incrementi di 10 gradi.
4. Il processo si ripete indefinitamente.

**Comprendere il Codice**

1. **Importazione della Libreria**

   La libreria ``fusion_hat`` semplifica le interazioni GPIO, mentre la libreria ``time`` fornisce funzioni di ritardo.

   .. code-block:: python

      from fusion_hat.servo import Servo   # Import the Servo class for controlling servos
      from time import sleep               # Import sleep for timing delays


2. **Inizializzazione del Servomotore**

   L'oggetto ``Servo`` viene inizializzato con PWM 0.

   .. code-block:: python

      servo = Servo(0)

3. **Movimento del Servomotore**

   Il servomotore viene spostato a diversi angoli in un ciclo. Il metodo ``angle`` imposta la posizione del servo, e ``sleep`` mette in pausa il ciclo per una durata specificata.

   .. code-block:: python

      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)

**Risoluzione dei Problemi**

1. **Il Servomotore Non Si Muove**

   - **Causa**: Collegamento errato del pin GPIO o problemi di alimentazione.
   - **Soluzione**: Assicurati che il servomotore sia collegato a PWM 0 e verifica l'alimentazione.

2. **Il Movimento del Servomotore è Irregolare o Non Risponde**

   - **Causa**: Alimentazione insufficiente al servomotore.
   - **Soluzione**: Usa una fonte di alimentazione esterna per il servomotore se Fusion HAT+ non fornisce abbastanza potenza.
