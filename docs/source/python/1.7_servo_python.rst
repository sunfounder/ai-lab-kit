**代码**

以下Python代码演示了如何通过在不同角度之间移动来控制舵机：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.servo import Servo   # Import Servo class
   from time import sleep               # Import sleep for delays

   # Initialize servo on channel 0
   servo = Servo(0)

   try:
      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)

   except KeyboardInterrupt:
      # Stop the program safely when Ctrl+C is pressed
      servo.angle(0)        # Return servo to center position
      sleep(0.1)


此Python脚本控制连接到PWM 0的舵机。执行时：

1. 舵机以10度为增量从-90度移动到90度。
2. 每次移动之间暂停0.1秒。
3. 然后反向，以10度为增量从90度移动到-90度。
4. 过程无限重复。

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库简化了GPIO交互，而\ ``time``\ 库提供了延迟功能。

   .. code-block:: python

      from fusion_hat.servo import Servo   # Import the Servo class for controlling servos
      from time import sleep               # Import sleep for timing delays


2. **舵机初始化**

   ``Servo``\ 对象使用PWM 0初始化。

   .. code-block:: python

      servo = Servo(0)

3. **舵机移动**

   舵机在循环中被移动到不同角度。\ ``angle``\ 方法设置舵机位置，\ ``sleep``\ 将循环暂停指定时间。

   .. code-block:: python

      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)


----------------------------------------------

**故障排除**

1. **舵机不转**

   - **原因**：GPIO引脚连接错误或电源问题。
   - **解决方案**：确保舵机连接到PWM 0并检查电源。

2. **舵机运动不稳定或无响应**

   - **原因**：舵机供电不足。
   - **解决方案**：如果Fusion HAT+供电不足，请为舵机使用外部电源。

      positions = []

         sleep(0.1)
         positions.append(servo.angle())
      plt.plot(positions)
      plt.show()
