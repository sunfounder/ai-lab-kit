**Código**

El siguiente código Python demuestra cómo controlar el servomotor moviéndolo entre varios ángulos:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.servo import Servo   # Import Servo class
   from time import sleep               # Import sleep for delays

   # Initialize servo on channel 0
   servo = Servo(0)

   try:
      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)

   except KeyboardInterrupt:
      # Stop the program safely when Ctrl+C is pressed
      servo.angle(0)        # Return servo to center position
      sleep(0.1)


Este script Python controla un servomotor conectado a PWM 0. Cuando se ejecuta:

1. El servomotor se mueve de -90 grados a 90 grados en incrementos de 10 grados.
2. Hace una pausa de 0.1 segundos entre cada movimiento.
3. Luego invierte la dirección y se mueve de 90 grados a -90 grados en incrementos de 10 grados.
4. El proceso se repite indefinidamente.

**Comprender el Código**

1. **Importación de Librerías**

   La librería ``fusion_hat`` simplifica las interacciones GPIO, mientras que la librería ``time`` proporciona funciones de retardo.

   .. code-block:: python

      from fusion_hat.servo import Servo   # Import the Servo class for controlling servos
      from time import sleep               # Import sleep for timing delays


2. **Inicialización del Servomotor**

   El objeto ``Servo`` se inicializa con PWM 0.

   .. code-block:: python

      servo = Servo(0)

3. **Movimiento del Servomotor**

   El servomotor se mueve a diferentes ángulos en un bucle. El método ``angle`` establece la posición del servomotor, y ``sleep`` pausa el bucle durante una duración especificada.

   .. code-block:: python

      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)


----------------------------------------------

**Solución de Problemas**

1. **El Servomotor No se Mueve**

   - **Causa**: Conexión incorrecta del pin GPIO o problemas de alimentación.
   - **Solución**: Asegúrate de que el servomotor esté conectado a PWM 0 y verifica la fuente de alimentación.

2. **El Movimiento del Servomotor es Errático o No Responde**

   - **Causa**: Alimentación insuficiente para el servomotor.
   - **Solución**: Utiliza una fuente de alimentación externa para el servomotor si la Fusion HAT+ no proporciona suficiente potencia.

**Ideas para Extender**


1. **Servomotor Controlado por el Usuario**

   Permite a los usuarios controlar la posición del servomotor de forma interactiva a través de la entrada por teclado:

   .. code-block:: python

      while True:
         position = float(input("Enter position (-90 to 90): "))
         servo.angle(position)


2. **Seguimiento de la Posición del Servomotor**

   Registra la posición del servomotor a lo largo del tiempo y traza la trayectoria:

   .. code-block:: python

      positions = []
      for i in range(-90, 91, 10):
         servo.angle(i)
         sleep(0.1)
         positions.append(servo.angle())
      plt.plot(positions)
      plt.show()
