**Code**

Le code Python suivant montre comment controler le servomoteur en le deplacant a differents angles :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.servo import Servo   # Import Servo class
   from time import sleep               # Import sleep for delays

   # Initialize servo on channel 0
   servo = Servo(0)

   try:
      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)

   except KeyboardInterrupt:
      # Stop the program safely when Ctrl+C is pressed
      servo.angle(0)        # Return servo to center position
      sleep(0.1)


Ce script Python controle un servomoteur connecte a PWM 0. Lors de l'execution :

1. Le servo se deplace de -90 degres a 90 degres par increments de 10 degres.
2. Il marque une pause de 0,1 seconde entre chaque mouvement.
3. Il inverse ensuite la direction et se deplace de 90 degres a -90 degres par increments de 10 degres.
4. Le processus se repete indefiniment.

**Comprendre le code**

1. **Importation de la bibliotheque**

   La bibliotheque ``fusion_hat`` simplifie les interactions GPIO, tandis que la bibliotheque ``time`` fournit des fonctions de temporisation.

   .. code-block:: python

      from fusion_hat.servo import Servo   # Import the Servo class for controlling servos
      from time import sleep               # Import sleep for timing delays


2. **Initialisation du servo**

   L'objet ``Servo`` est initialise avec PWM 0.

   .. code-block:: python

      servo = Servo(0)

3. **Mouvement du servo**

   Le servo est deplace a differents angles dans une boucle. La methode ``angle`` definit la position du servo, et ``sleep`` suspend la boucle pendant une duree specifiee.

   .. code-block:: python

      while True:
         # Sweep from -90° to +90° in steps of 10°
         for angle in range(-90, 91, 10):
               servo.angle(angle)
               sleep(0.1)   # Smooth movement delay

         # Sweep back from +90° to -90° in steps of 10°
         for angle in range(90, -91, -10):
               servo.angle(angle)
               sleep(0.1)


----------------------------------------------

**Depannage**

1. **Le servo ne bouge pas**

   - **Cause** : Connexion de broche GPIO incorrecte ou problemes d'alimentation.
   - **Solution** : Assurez-vous que le servo est connecte a PWM 0 et verifiez l'alimentation.

2. **Le mouvement du servo est erratique ou ne repond pas**

   - **Cause** : Alimentation insuffisante du servo.
   - **Solution** : Utilisez une source d'alimentation externe pour le servo si le Fusion HAT+ ne fournit pas assez de puissance.
