4.1.11 Passwortschloss
==========================

**Introduction**

In diesem Projekt erstellen wir ein Zahlenschloss mit einem Keypad und einem LCD. Das LCD fordert zur Passworteingabe auf, und das System vergleicht die Eingabe mit einem vordefinierten Wert. Ist das Passwort korrekt, zeigt das LCD „Correct“ an; andernfalls erscheint eine Fehlermeldung.

Das Projekt lässt sich leicht erweitern, z. B. um Buzzer oder LEDs für zusätzliches Feedback bei der Eingabe.

**Writing the Code**


Hier ist das Python-Skript für das Passwortschloss:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat import Pin,Keypad,LCD1602
   from time import sleep

   # Password verification setup
   LENS = 4
   password = ['1', '9', '8', '4']  # Preset password
   testword = ['0', '0', '0', '0']  # User input storage
   keyIndex = 0  # Index for input keys

   def check():
      """
      Check if the entered password matches the preset password.
      :return: 1 if match, 0 otherwise.
      """
      for i in range(LENS):
         if password[i] != testword[i]:
               return 0
      return 1


   def loop():
      """
      Main loop for handling keypad input and password verification.
      """
      global keyIndex, last_key_pressed
      while True:
         pressed_keys = keypad.read()
         if pressed_keys and pressed_keys != last_key_pressed:
               if keyIndex < LENS:
                  lcd.clear()
                  lcd.write(0, 0, "Enter password:")
                  lcd.write(15 - keyIndex, 1, pressed_keys[0])
                  testword[keyIndex] = pressed_keys[0]
                  keyIndex += 1

               if keyIndex == LENS:
                  if check() == 0:
                     lcd.clear()
                     lcd.write(3, 0, "WRONG KEY!")
                     lcd.write(0, 1, "please try again")
                  else:
                     lcd.clear()
                     lcd.write(4, 0, "CORRECT!")
                     lcd.write(2, 1, "welcome back")
                  keyIndex = 0  # Reset key index after checking

         last_key_pressed = pressed_keys
         sleep(0.1)


   # Pin configuration for keypad
   rows_pins = [4, 17, 27, 22]
   cols_pins = [23, 24, 25, 12]
   keys = ["1", "2", "3", "A",
         "4", "5", "6", "B",
         "7", "8", "9", "C",
         "*", "0", "#", "D"]

   # Initialize keypad and LCD
   keypad = Keypad(rows_pins, cols_pins, keys)
   last_key_pressed = []
   lcd = LCD1602(address=0x27, backlight=1)
   lcd.clear()
   lcd.write(0, 0, 'WELCOME!')
   lcd.write(2, 1, 'Enter password')
   sleep(2)

   try:
      loop()
   except KeyboardInterrupt:
      lcd.clear()  # Clear LCD display on interrupt


Dieses Python-Skript implementiert eine Passwortprüfung mit einem 4×4-Keypad und einem LCD1602. Es bietet folgende Funktionen:

1. **Passworteingabe**:

   - Nutzer geben ein vordefiniertes vierstelliges Passwort über das Keypad ein.
   - Jeder Tastendruck wird auf dem LCD angezeigt; die eingegebene Ziffer erscheint im Passwortfeld.

2. **Passwortvalidierung**: Sobald vier Zeichen eingegeben wurden, vergleicht das Skript die Eingabe mit dem hinterlegten Passwort:
     
   - Ist das Passwort korrekt, zeigt das LCD:

      .. code-block:: python
         
         CORRECT!
         Welcome back

   - Ist es falsch, zeigt das LCD:

      .. code-block:: python

         WRONG KEY!
         Please try again


3. **LCD-Anzeige**:

   - Während der Eingabe liefert das LCD Feedback und blendet das Label mit den aktuell eingegebenen Ziffern in Echtzeit ein:

   .. code-block:: python

      Enter password:
   
4. **Dauerbetrieb**: Das System wartet fortlaufend auf Eingaben, setzt nach jedem Versuch zurück und erlaubt beliebig viele Versuche.

5. **Sauberes Beenden**: Bei ``Ctrl+C`` wird das LCD geleert und das Programm ordentlich beendet.


----------------------------------------------

**Understanding the Code**

1. **Keypad Class:**  

   Eine Klasse, die die Zeilen- und Spaltenpins des Keypads verwaltet und Tastendrücke erfasst.  

2. **Password Logic:**  

   * ``password``: Das vordefinierte Passwort.  
   * ``testword``: Puffer für die Nutzereingabe.  
   * ``check()``: Vergleicht Eingabe und Referenzpasswort.

3. **LCD Display:**  

   Das LCD zeigt Benutzersignale und Rückmeldungen abhängig von der Eingabe an.

4. **Main Loop:**  

   Die Hauptschleife prüft kontinuierlich Tastendrücke, aktualisiert die Anzeige und validiert die Eingabe.


----------------------------------------------


**Troubleshooting**

1. **Keypad Does Not Respond**:

   - **Cause**: Falsche Verdrahtung oder GPIO-Konfiguration.
   - **Solution**:

     - Prüfe, ob die Zeilen- und Spaltenpins gemäß ``rows_pins`` und ``cols_pins`` verbunden sind.
     - Teste das Keypad separat, um die Funktion sicherzustellen.

2. **LCD Display Does Not Show Output**:

   - **Cause**: Falsche I²C-Adresse oder Verdrahtung.
   - **Solution**:

     - Überprüfe die I²C-Adresse mit ``i2cdetect -y 1`` und passe ``lcd = LCD1602(address=0x27, backlight=1)`` ggf. an.
     - Stelle sicher, dass SDA und SCL korrekt verbunden sind.

3. **Incorrect Password Always Detected**:

   - **Cause**: Abweichung zwischen ``password`` und ``testword`` oder Fehler in der Eingabelogik.
   - **Solution**:

     - Verifiziere, dass das vordefinierte ``password`` der erwarteten Eingabe entspricht.
     - Füge Debug-Ausgaben hinzu, um die Werte in ``testword`` nachzuvollziehen:

       .. code-block:: python

           print(f"Testword: {testword}")

4. **LCD Shows Incomplete Characters**:

   - **Cause**: Tastendrücke werden nicht sauber erfasst.
   - **Solution**: Erhöhe die Entprellzeit, z. B. mit ``sleep(0.2)`` in der ``loop()``-Funktion.

----------------------------------------------


**Extendable Ideas**

1. **Changeable Password**: Ermögliche das Ändern des vordefinierten Passworts nach erfolgreicher Authentifizierung.

   .. code-block:: python

      if check():
            lcd.write(0, 0, "Set new password")
            # Logic for capturing new password input

2. **Logging Attempts**: Protokolliere erfolgreiche und fehlgeschlagene Versuche mit Zeitstempel:

   .. code-block:: python

      with open("attempts_log.txt", "a") as log_file:
            log_file.write(f"{time.strftime('%Y-%m-%d %H:%M:%S')} - {'Success' if check() else 'Failure'}\n")

3. **Enhanced Feedback**: Ergänze akustisches/visuelles Feedback per Buzzer oder LED für Erfolg bzw. Fehler.

4. **Multiple Users**: Unterstütze mehrere Nutzer mit individuellen Passwörtern und personalisierten Begrüßungen.

5. **Max Attempts Lockout**: Sperre das System nach einer definierten Zahl falscher Versuche bis zum Reset.

6. **Additional Security**: Füge eine Wartezeit zwischen Fehlversuchen hinzu, um schnelles Raten zu verhindern.
