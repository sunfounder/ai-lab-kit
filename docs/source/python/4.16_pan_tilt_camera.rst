4.16 Sistema di Controllo Fotocamera Pan-Tilt
==========================================================

**Introduzione**

In questo progetto, creerai un sistema di controllo della fotocamera in grado di ruotare (movimento orizzontale) e inclinare (movimento verticale) usando un joystick. Il sistema ti permette di controllare remotamente la direzione di una fotocamera montata su servomotori, visualizzare l'anteprima della fotocamera in tempo reale e scattare foto con la pressione del pulsante del joystick. Questo progetto è perfetto per applicazioni di sorveglianza, progetti fotografici o per imparare il controllo dei servomotori e l'integrazione della fotocamera.

**Esecuzione dell'Esempio**


1. Accedi al Desktop del Raspberry Pi:

   * :ref:`remote_desktop`: Usa **VNC** per un'esperienza desktop completa.
   * |link_rpi_connect|: Usa **Raspberry Pi Connect** per accedere al tuo Pi in modo sicuro da qualsiasi browser.

2. Apri un Terminale e vai alla cartella del codice:

   .. raw:: html

        <run></run>

   .. code-block:: shell

       cd ~/ai-lab-kit/python

3. Esegui lo script per avviare la fotocamera:

   .. raw:: html

        <run></run>

   .. code-block:: shell

       sudo python3 pan_tilt_camera.py

4. Dopo aver eseguito lo script, il sistema fotocamera pan-tilt si avvia e inizializza la fotocamera e i servomotori.

   * Se un display è disponibile, viene mostrata un'anteprima dal vivo della fotocamera; altrimenti, il programma funziona normalmente in modalit headless.

   * Muovendo il joystick a sinistra o destra si ruota la fotocamera orizzontalmente (pan), mentre muovendolo su o gi si inclina la fotocamera verticalmente (tilt).

   * Quando il pulsante del joystick viene premuto, la fotocamera acquisisce una foto e la salva nella directory ``Pictures/camera_pan_tilt`` usando un nome file sequenziale semplice come ``photo_001.jpg``.

   * Il sistema continua a funzionare e a rispondere all'input dell'utente fino a quando non si ferma il programma premendo Ctrl + C.
