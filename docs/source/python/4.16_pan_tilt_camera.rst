4.16 Systeme de controle de camera panoramique-inclinable
======================================================================

**Introduction**

Dans ce projet, vous allez creer un systeme de controle de camera qui peut effectuer un mouvement panoramique (horizontal) et d'inclinaison (vertical) a l'aide d'un joystick. Le systeme vous permet de controler a distance la direction d'une camera montee sur des servomoteurs, de previsualiser le flux de la camera en temps reel et de capturer des photos en appuyant sur le bouton du joystick. Ce projet est parfait pour les applications de surveillance, les projets photographiques ou l'apprentissage du controle des servomoteurs et de l'integration de camera.

3. Executez le script pour demarrer la camera :

   .. raw:: html

        <run></run>

   .. code-block:: shell

       sudo python3 pan_tilt_camera.py

4. Apres l'execution du script, le systeme de camera panoramique-inclinable demarre et initialise la camera et les servomoteurs.

   * Si un affichage est disponible, un apercu en direct de la camera est montre ; sinon, le programme fonctionne normalement en mode sans tete.

   * Deplacer le joystick a gauche ou a droite fait pivoter la camera horizontalement (panoramique), tandis que le deplacer vers le haut ou le bas incline la camera verticalement (inclinaison).

   * Lorsque le bouton du joystick est presse, la camera capture une photo et l'enregistre dans le repertoire ``Pictures/camera_pan_tilt`` en utilisant un nom de fichier sequentiel simple comme ``photo_001.jpg``.

   * Le systeme continue de fonctionner et de repondre aux entrees utilisateur jusqu'a ce que vous arretez le programme en appuyant sur Ctrl + C.

.. code-block:: python

    #!/usr/bin/env python3
    import os, time
    from picamera2 import Picamera2, Preview
    from fusion_hat.adc import ADC
    from fusion_hat.pin import Pin, Mode, Pull
    from fusion_hat.servo import Servo

    # Servo channels for pan (horizontal) and tilt (vertical)
    PAN_CHANNEL, TILT_CHANNEL = 2, 3

    # Joystick ADC pins (X/Y axis) and button pin
    X_PIN, Y_PIN = "A1", "A0"
    BTN_PIN = 17

    # Angle limits to protect servos
    PAN_MIN, PAN_MAX = -90, 90
    TILT_MIN, TILT_MAX = -45, 45

    # Deadzone ignores small joystick movement
    DEADZONE = 15
    MOVE_SPEED = 3
    LOOP_DELAY = 0.05

    # Photo save directory (works with sudo)
    REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
    PHOTO_DIR = os.path.join(f"/home/{REAL_USER}", "Pictures", "camera_pan_tilt")
    os.makedirs(PHOTO_DIR, exist_ok=True)

    # Initialize servos
    pan_servo = Servo(PAN_CHANNEL)
    tilt_servo = Servo(TILT_CHANNEL)

    # Initialize joystick and button (active-low)
    x_adc = ADC(X_PIN)
    y_adc = ADC(Y_PIN)
    joystick_button = Pin(BTN_PIN, mode=Mode.IN, pull=Pull.UP)  # pressed -> 0

    # Initialize camera
    camera = Picamera2()
    camera.configure(camera.create_preview_configuration(main={"size": (1280, 720)}))

    preview_started = False
    photo_count = 1
    current_pan = 0
    current_tilt = 0
    last_button_state = 1  # Used for edge detection

    def clamp(v, vmin, vmax):
        # Limit value to a safe range
        return max(vmin, min(vmax, v))

    def map_value(value, in_min, in_max, out_min, out_max):
        # Map ADC value to a new range
        return (value - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

    def apply_deadzone(v, dz):
        # Ignore small joystick movement
        return 0 if (-dz < v < dz) else v

    def read_joystick():
        # Read joystick X/Y position
        x = map_value(x_adc.read(), 0, 4095, -100, 100)
        y = map_value(y_adc.read(), 0, 4095, -100, 100)
        return x, y

    def check_button_press():
        # Detect button press (HIGH -> LOW)
        global last_button_state
        current_state = joystick_button.value()
        if last_button_state == 1 and current_state == 0:
            last_button_state = current_state
            return True
        last_button_state = current_state
        return False

    def take_photo():
        # Capture and save one photo
        global photo_count
        filename = f"photo_{photo_count:03d}.jpg"
        filepath = os.path.join(PHOTO_DIR, filename)
        camera.capture_file(filepath)
        print("Saved:", filepath)
        photo_count += 1

    def start_preview_if_available():
        # Start camera preview only if a display is available
        global preview_started
        preview_started = False
        if os.getenv("DISPLAY"):
            try:
                camera.start_preview(Preview.QT)
                preview_started = True
            except Exception:
                preview_started = False

    def cleanup():
        # Safely stop camera and release resources
        try:
            camera.stop()
        except Exception:
            pass
        if preview_started:
            try:
                camera.stop_preview()
            except Exception:
                pass
        try:
            camera.close()
        except Exception:
            pass

    def main():
        global current_pan, current_tilt

        start_preview_if_available()
        camera.start()

        # Center camera at startup
        pan_servo.angle(0)
        tilt_servo.angle(0)

        try:
            while True:
                # Read joystick and move camera
                x, y = read_joystick()
                x = apply_deadzone(x, DEADZONE)
                y = apply_deadzone(y, DEADZONE)

                new_pan = current_pan + (MOVE_SPEED if x > DEADZONE else -MOVE_SPEED if x < -DEADZONE else 0)
                new_tilt = current_tilt + (MOVE_SPEED if y > DEADZONE else -MOVE_SPEED if y < -DEADZONE else 0)

                new_pan = clamp(new_pan, PAN_MIN, PAN_MAX)
                new_tilt = clamp(new_tilt, TILT_MIN, TILT_MAX)

                if new_pan != current_pan:
                    current_pan = new_pan
                    pan_servo.angle(current_pan)

                if new_tilt != current_tilt:
                    current_tilt = new_tilt
                    tilt_servo.angle(current_tilt)

                # Take photo when button is pressed
                if check_button_press():
                    take_photo()

                time.sleep(LOOP_DELAY)

        except KeyboardInterrupt:
            pass
        finally:
            cleanup()

    if __name__ == "__main__":
        main()


----------------------------------------------

**Comprendre le code**

#. **Initialisation materielle**

   - Deux servomoteurs sont initialises pour controler le mouvement panoramique (horizontal) et d’inclinaison (vertical) de la camera
   - Le joystick utilise des canaux ADC pour lire les valeurs analogiques X et Y, et une broche GPIO pour detecter les pressions sur le bouton
   - Le module camera est initialise et configure pour le mode apercu, prenant en charge le fonctionnement avec et sans affichage

#. **Lecture et traitement du joystick**

   - ``read_joystick()`` lit les valeurs analogiques brutes des axes X et Y du joystick
   - ``map_value()`` convertit les valeurs ADC (0-4095) en une plage utilisable de -100 a 100
   - ``apply_deadzone()`` filtre les petits mouvements du joystick pour empecher la derive indesirable de la camera

#. **Controle du mouvement de la camera**

   - L’entree du joystick est traduite en changements incrementiels des angles panoramique et d’inclinaison
   - ``clamp()`` garantit que les angles restent dans des limites sures pour proteger les servomoteurs
   - Les servomoteurs sont mis a jour uniquement lorsque l’angle change, offrant un mouvement fluide et stable

#. **Detection de pression sur le bouton**

   - Le bouton du joystick est configure comme une entree active a LOW en utilisant une resistance de tirage vers le haut
   - ``check_button_press()`` detecte une pression sur le bouton en utilisant la detection de front (HIGH → LOW)
   - Cela garantit qu’une seule photo est prise par pression sur le bouton, meme si le bouton est maintenu enfonce

#. **Capture et stockage des photos**

   - ``take_photo()`` capture une image a l’aide du module camera
   - Les photos sont enregistrees avec des noms de fichiers sequentiels (par exemple, ``photo_001.jpg``)
   - Toutes les images sont stockees dans le repertoire ``Pictures/camera_pan_tilt`` de l’utilisateur

#. **Gestion de l’apercu de la camera**


   - Un apercu en direct de la camera est demarre uniquement lorsqu’un affichage graphique est disponible
   - Le script continue de fonctionner normalement lorsqu’il est execute sans affichage

#. **Boucle principale et nettoyage**


   - La boucle principale lit en continu l’entree du joystick et repond en temps reel
   - Lorsque le programme se termine avec ``Ctrl + C``, la camera est arretee en toute securite
   - Toutes les ressources materielles sont correctement liberees pour garantir un arret propre

**Depannage**

1. **Les servomoteurs ne bougent pas** :

   - **Cause :** Connexions de servomoteurs incorrectes ou probleme d’alimentation
   - **Solution :**

     - Verifiez que les servomoteurs sont connectes aux bons canaux (2 et 3)
     - Assurez-vous que le Fusion HAT est correctement alimente
     - Verifiez le cablage des servomoteurs pour les connexions desserrees

2. **L’apercu de la camera ne s’affiche pas** :

   - **Cause :** Module camera non detecte ou configuration incorrecte
   - **Solution :**

     - Assurez-vous que le cable de la camera est solidement connecte au port CSI
     - Verifiez si la camera est activee dans la configuration du Raspberry Pi
     - Verifiez la compatibilite du module camera

3. **Le joystick ne repond pas** :

   - **Cause :** Affectations de broches incorrectes ou problemes ADC
   - **Solution :**

     - Verifiez les connexions du joystick a A0, A1 et GPIO 17
     - Testez les lectures ADC avec des instructions d’affichage simples
     - Verifiez si l’ADC du Fusion HAT fonctionne

4. **Les photos ne sont pas sauvegardees** :

   - **Cause :** Problemes de permissions ou de repertoire
   - **Solution :**

     - Verifiez si le repertoire Pictures existe dans le dossier personnel de l’utilisateur
     - Verifiez les permissions d’ecriture pour le repertoire de photos
     - Essayez d’executer avec sudo si les problemes de permissions persistent

5. **Mouvement erratique du servomoteur** :

   - **Cause :** Fluctuations d’alimentation ou problemes de temporisation logicielle
   - **Solution :**

     - Assurez une alimentation stable au Fusion HAT
     - Ajustez les valeurs ``MOVE_SPEED`` et de delai
     - Ajoutez des condensateurs aux lignes d’alimentation des servomoteurs si necessaire
