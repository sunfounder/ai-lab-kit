4.16 Sistema de Control de Cámara Pan-Tilt
==========================================================

**Introducción**

En este proyecto, crearás un sistema de control de cámara que puede girar (moverse horizontalmente) e inclinarse (moverse verticalmente) usando un joystick. El sistema te permite controlar remotamente la dirección de una cámara montada en servomotores, previsualizar la transmisión de la cámara en tiempo real y capturar fotos con la pulsación del botón del joystick. Este proyecto es perfecto para aplicaciones de vigilancia, proyectos de fotografía o para aprender sobre control de servomotores e integración de cámaras.

   * |link_rpi_connect|: Usa **Raspberry Pi Connect** para acceder a tu Pi de forma segura desde cualquier navegador.

2. Abre una Terminal y ve a la carpeta del código:

   .. raw:: html

        <run></run>

   .. code-block:: shell

       cd ~/ai-lab-kit/python

3. Ejecuta el script para iniciar la cámara:

   .. raw:: html

        <run></run>

   .. code-block:: shell

       sudo python3 pan_tilt_camera.py

4. Después de ejecutar el script, el sistema de cámara pan-tilt se inicia y inicializa la cámara y los servomotores.

   * Si hay una pantalla disponible, se muestra una vista previa de la cámara en vivo; de lo contrario, el programa funciona normalmente en modo sin pantalla.

   * Mover el joystick hacia la izquierda o derecha rota la cámara horizontalmente (pan), mientras que moverlo hacia arriba o abajo inclina la cámara verticalmente (tilt).

   * Cuando se presiona el botón del joystick, la cámara captura una foto y la guarda en el directorio ``Pictures/camera_pan_tilt`` usando un nombre de archivo secuencial simple como ``photo_001.jpg``.

   * El sistema continúa funcionando y respondiendo a la entrada del usuario hasta que detengas el programa presionando Ctrl + C.

**Código**

A continuación se muestra el script de Python utilizado en este proyecto:

.. code-block:: python

    #!/usr/bin/env python3
    import os, time
    from picamera2 import Picamera2, Preview
    from fusion_hat.adc import ADC
    from fusion_hat.pin import Pin, Mode, Pull
    from fusion_hat.servo import Servo

    # Servo channels for pan (horizontal) and tilt (vertical)
    PAN_CHANNEL, TILT_CHANNEL = 2, 3

    # Joystick ADC pins (X/Y axis) and button pin
    X_PIN, Y_PIN = "A1", "A0"
    BTN_PIN = 17

    # Angle limits to protect servos
    PAN_MIN, PAN_MAX = -90, 90
    TILT_MIN, TILT_MAX = -45, 45

    # Deadzone ignores small joystick movement
    DEADZONE = 15
    MOVE_SPEED = 3
    LOOP_DELAY = 0.05

    # Photo save directory (works with sudo)
    REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
    PHOTO_DIR = os.path.join(f"/home/{REAL_USER}", "Pictures", "camera_pan_tilt")
    os.makedirs(PHOTO_DIR, exist_ok=True)

    # Initialize servos
    pan_servo = Servo(PAN_CHANNEL)
    tilt_servo = Servo(TILT_CHANNEL)

    # Initialize joystick and button (active-low)
    x_adc = ADC(X_PIN)
    y_adc = ADC(Y_PIN)
    joystick_button = Pin(BTN_PIN, mode=Mode.IN, pull=Pull.UP)  # pressed -> 0

    # Initialize camera
    camera = Picamera2()
    camera.configure(camera.create_preview_configuration(main={"size": (1280, 720)}))

    preview_started = False
    photo_count = 1
    current_pan = 0
    current_tilt = 0
    last_button_state = 1  # Used for edge detection

    def clamp(v, vmin, vmax):
        # Limit value to a safe range
        return max(vmin, min(vmax, v))

    def map_value(value, in_min, in_max, out_min, out_max):
        # Map ADC value to a new range
        return (value - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

    def apply_deadzone(v, dz):
        # Ignore small joystick movement
        return 0 if (-dz < v < dz) else v

    def read_joystick():
        # Read joystick X/Y position
        x = map_value(x_adc.read(), 0, 4095, -100, 100)
        y = map_value(y_adc.read(), 0, 4095, -100, 100)
        return x, y

    def check_button_press():
        # Detect button press (HIGH -> LOW)
        global last_button_state
        current_state = joystick_button.value()
        if last_button_state == 1 and current_state == 0:
            last_button_state = current_state
            return True
        last_button_state = current_state
        return False

    def take_photo():
        # Capture and save one photo
        global photo_count
        filename = f"photo_{photo_count:03d}.jpg"
        filepath = os.path.join(PHOTO_DIR, filename)
        camera.capture_file(filepath)
        print("Saved:", filepath)
        photo_count += 1

    def start_preview_if_available():
        # Start camera preview only if a display is available
        global preview_started
        preview_started = False
        if os.getenv("DISPLAY"):
            try:
                camera.start_preview(Preview.QT)
                preview_started = True
            except Exception:
                preview_started = False

    def cleanup():
        # Safely stop camera and release resources
        try:
            camera.stop()
        except Exception:
            pass
        if preview_started:
            try:
                camera.stop_preview()
            except Exception:
                pass
        try:
            camera.close()
        except Exception:
            pass

    def main():
        global current_pan, current_tilt

        start_preview_if_available()
        camera.start()

        # Center camera at startup
        pan_servo.angle(0)
        tilt_servo.angle(0)

        try:
            while True:
                # Read joystick and move camera
                x, y = read_joystick()
                x = apply_deadzone(x, DEADZONE)
                y = apply_deadzone(y, DEADZONE)

                new_pan = current_pan + (MOVE_SPEED if x > DEADZONE else -MOVE_SPEED if x < -DEADZONE else 0)
                new_tilt = current_tilt + (MOVE_SPEED if y > DEADZONE else -MOVE_SPEED if y < -DEADZONE else 0)

                new_pan = clamp(new_pan, PAN_MIN, PAN_MAX)
                new_tilt = clamp(new_tilt, TILT_MIN, TILT_MAX)

                if new_pan != current_pan:
                    current_pan = new_pan
                    pan_servo.angle(current_pan)

                if new_tilt != current_tilt:
                    current_tilt = new_tilt
                    tilt_servo.angle(current_tilt)

                # Take photo when button is pressed
                if check_button_press():
                    take_photo()

                time.sleep(LOOP_DELAY)

        except KeyboardInterrupt:
            pass
        finally:
            cleanup()

    if __name__ == "__main__":
        main()

**Comprender el Código**

#. **Inicialización del Hardware**

   - Se inicializan dos servomotores para controlar el movimiento de pan (horizontal) y tilt (vertical) de la cámara
   - El joystick usa canales ADC para leer los valores analógicos X e Y, y un pin GPIO para detectar las pulsaciones del botón
   - El módulo de cámara se inicializa y configura para el modo de vista previa, soportando tanto operación con pantalla como sin ella

#. **Lectura y Procesamiento del Joystick**

   - ``read_joystick()`` lee los valores analógicos brutos de los ejes X e Y del joystick
   - ``map_value()`` convierte los valores ADC (0–4095) en un rango utilizable de −100 a 100
   - ``apply_deadzone()`` filtra los pequeños movimientos del joystick para evitar derivas no deseadas de la cámara

#. **Control de Movimiento de la Cámara**

   - La entrada del joystick se traduce en cambios incrementales en los ángulos de pan y tilt
   - ``clamp()`` asegura que los ángulos se mantengan dentro de límites seguros para proteger los servomotores
   - Los servos se actualizan solo cuando el ángulo cambia, proporcionando un movimiento suave y estable

#. **Detección de Pulsación del Botón**

   - El botón del joystick está configurado como una entrada activa en bajo usando una resistencia pull-up
   - ``check_button_press()`` detecta una pulsación del botón usando detección de flanco (HIGH → LOW)
   - Esto asegura que solo se tome una foto por pulsación, incluso si el botón se mantiene presionado

#. **Captura y Almacenamiento de Fotos**

   - ``take_photo()`` captura una imagen usando el módulo de cámara
   - Las fotos se guardan con nombres de archivo secuenciales (por ejemplo, ``photo_001.jpg``)
   - Todas las imágenes se almacenan en el directorio ``Pictures/camera_pan_tilt`` del usuario

#. **Manejo de la Vista Previa de la Cámara**

   - La vista previa de la cámara en vivo se inicia solo cuando hay una pantalla gráfica disponible
   - El script continúa funcionando normalmente cuando se ejecuta sin pantalla

#. **Bucle Principal y Limpieza**

   - El bucle principal lee continuamente la entrada del joystick y responde en tiempo real
   - Cuando el programa sale usando ``Ctrl + C``, la cámara se detiene de forma segura
   - Todos los recursos de hardware se liberan adecuadamente para garantizar un apagado limpio

**Solución de Problemas**

1. **Los Servomotores No Se Mueven**:

   - **Causa**: Conexiones incorrectas del servo o problemas de alimentación
   - **Solución**:

     - Verifica que los servos estén conectados a los canales correctos (2 y 3)
     - Asegúrate de que el Fusion HAT esté correctamente alimentado
     - Revisa el cableado del servo para detectar conexiones sueltas

2. **La Vista Previa de la Cámara No Se Muestra**:

   - **Causa**: Módulo de cámara no detectado o configuración incorrecta
   - **Solución**:

     - Asegúrate de que el cable de la cámara esté firmemente conectado al puerto CSI
     - Verifica que la cámara esté habilitada en la configuración de Raspberry Pi
     - Confirma la compatibilidad del módulo de cámara

3. **El Joystick No Responde**:

   - **Causa**: Asignaciones de pines incorrectas o problemas con el ADC
   - **Solución**:

     - Verifica las conexiones del joystick a A0, A1 y GPIO 17
     - Prueba las lecturas del ADC con declaraciones print simples
     - Comprueba si el ADC del Fusion HAT está funcionando

4. **Las Fotos No Se Guardan**:

   - **Causa**: Problemas de permisos o de directorio
   - **Solución**:

     - Verifica que el directorio Pictures exista en el directorio de inicio del usuario
     - Confirma los permisos de escritura para el directorio de fotos
     - Intenta ejecutar con sudo si persisten los problemas de permisos

5. **Movimiento Errático del Servo**:

   - **Causa**: Fluctuaciones de alimentación o problemas de temporización del software
   - **Solución**:

     - Asegura una fuente de alimentación estable para el Fusion HAT
     - Ajusta los valores de ``MOVE_SPEED`` y retardo
     - Agrega capacitores a las líneas de alimentación del servo si es necesario
