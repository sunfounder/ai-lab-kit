4.1.3 SPIEL – 10-Sekunden-Challenge
=======================================

**Introduction**

Teste deine Konzentration und dein Timing mit dem Spiel „10-Sekunden-Challenge“! In diesem Projekt baust du dir einen Zauberstab, indem du einen Neigungsschalter an einem Stab befestigst. Schüttle den Stab, um einen Timer auf einer 4-stelligen Segmentanzeige zu starten. Schüttle ihn erneut, um den Timer zu stoppen. Ziel ist es, den Timer so nah wie möglich an **10.00 seconds** zu stoppen. Miss dich mit Freundinnen und Freunden und finde heraus, wer der ultimative Zeitmagier ist!

**Writing the Code**


Hier ist der Python-Code für das Projekt:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat import Pin
   import time
   import threading

   # Initialize the button connected to GPIO 26
   sensorPin = Pin(22, Pin.IN, Pin.PULL_DOWN)

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17,Pin.OUT)   # Serial Data Input
   RCLK = Pin(4,Pin.OUT)  # Register Clock
   SRCLK = Pin(27,Pin.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,Pin.OUT) for pin in (23, 24, 25, 12)]

   # Define segment codes for numbers 0 to 9 on the 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Counter and timer variables
   counter = 0
   timer1 = None
   gameState = 0

   def clearDisplay():
      """ Clear all segments on the 7-segment display. """
      for _ in range(8):
         SDI.on()
         SRCLK.on()
         SRCLK.off()
      RCLK.on()
      RCLK.off()

   def hc595_shift(data):
      """ Shift data to the 74HC595 shift register to display a digit. """
      for i in range(8):
         SDI.value(0x80 & (data << i))
         SRCLK.on()
         SRCLK.off()
      RCLK.on()
      RCLK.off()

   def pickDigit(digit):
      """ Select which digit to display on the 7-segment display. """
      for pin in placePin:
         pin.off()
      placePin[digit].on()

   def display():
      """ Display the current counter value on the 7-segment display. """
      global counter
      clearDisplay()
      pickDigit(3)
      hc595_shift(number[counter % 10])

      clearDisplay()
      pickDigit(2)
      hc595_shift(number[counter % 100 // 10])

      clearDisplay()
      pickDigit(1)
      hc595_shift(number[counter % 1000 // 100] - 0x80)

      clearDisplay()
      pickDigit(0)
      hc595_shift(number[counter % 10000 // 1000])

   def stateChange():
      """ Handle state changes for the counter based on button presses. """
      global gameState, counter, timer1
      if gameState == 0:
         counter = 0
         time.sleep(1)
         timer()
      elif gameState == 1 and timer1 is not None:
         timer1.cancel()
         time.sleep(1)
      gameState = (gameState + 1) % 2

   def loop():
      """ Main loop to check for button presses and update the display. """
      global counter
      currentState = 0
      lastState = 0
      while True:
         display()
         currentState = sensorPin.value()
         if (currentState == 0) and (lastState == 1):
               stateChange()
         lastState = currentState

   def timer():
      """ Timer function that increments the counter every 0.01 second. """
      global counter, timer1
      timer1 = threading.Timer(0.01, timer)
      timer1.start()
      counter += 1

   try:
      loop()
   except KeyboardInterrupt:
      if timer1:
         timer1.cancel()


#. Schüttle den Zauberstab, um den Timer auf der 4-stelligen Segmentanzeige zu starten.

#. Schüttle den Zauberstab erneut, um den Timer zu stoppen.

#. Wenn der Timer 10.00 seconds anzeigt, gewinnst du die Runde!

#. Schüttle den Zauberstab noch einmal, um das Spiel zurückzusetzen und eine neue Runde zu starten.

**Understanding the Code**

1. **Button Input:**  
   Der Neigungsschalter ist an GPIO-Pin 22 angeschlossen und erkennt, wenn der Stab geschüttelt wird.

2. **74HC595 Shift Register:**  
   Das Schieberegister steuert, welche Stellen der 7-Segment-Anzeige aktiviert werden.

3. **Timer Logic:**  
   Ein Thread-Timer erhöht den Zähler alle 0,01 Sekunden und sorgt so für präzises Timing.

4. **State Management:**  
   Das Spiel wechselt anhand der Tastereingabe zwischen Zuständen (Start, Stopp) und setzt den Zähler bei Bedarf zurück.

5. **Display Update:**  
   Die 7-Segment-Anzeige zeigt den Timerwert formatiert mit zwei Dezimalstellen an.


----------------------------------------------

**Troubleshooting**

1. **7-Segment-Anzeige zeigt keine Zahlen**:

   - **Ursache**: Falsche Verdrahtung oder GPIO-Konfiguration.
   - **Lösung**:

     - Verbindungen zum 74HC595 und zur 7-Segment-Anzeige prüfen.
     - Sicherstellen, dass die ``number``-Segmentcodes zur Anzeige passen.

2. **Neigungsschalter wird nicht erkannt**:

   - **Ursache**: Verdrahtungsfehler oder fehlende Entprellung.
   - **Lösung**:
     - Prüfen, ob der Neigungsschalter an GPIO 22 angeschlossen ist.
     - Eine kurze Entprell-Pause in ``loop()`` hinzufügen:

       .. code-block:: python

           time.sleep(0.05)

3. **Zähler erhöht sich nicht**:

   - **Ursache**: Timerfunktion startet nicht korrekt.
   - **Lösung**:

     - ``timer()`` prüfen und sicherstellen, dass ``timer1.start()`` aufgerufen wird.
     - Testweise den ``counter`` innerhalb von ``timer()`` ausgeben.

4. **Anzeige zeigt falsche Ziffern**:

   - **Ursache**: Segmentcodes in ``number`` stimmen nicht mit der Hardware überein.
   - **Lösung**: Einzelne Ziffern mit festen Segmentmustern testen, um die Zuordnung zu verifizieren.


----------------------------------------------

**Extendable Ideas**

1. **Einstellbare Timergeschwindigkeit**: Möglichkeit hinzufügen, die Schrittweite des Timers zu ändern (z. B. per zweitem Taster zwischen 0,01 s, 0,1 s und 1 s umschalten).

2. **Countdown-Modus**: Einen Countdown implementieren, der von einem voreingestellten Wert bis 0 herunterzählt.

3. **Pause und Fortsetzen**: Separaten Taster zum Pausieren und Fortsetzen ohne Zurücksetzen hinzufügen.

4. **Akustisches Feedback**: Einen Buzzer einsetzen, der bei bestimmten Meilensteinen piept (z. B. Vielfache von 10).
