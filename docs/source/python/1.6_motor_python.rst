运行脚本后，连接到端口M0的电机在一个循环中反复启停。它先停止0.5秒，然后以-50%功率运行1秒，再次停止0.5秒，最后以75%功率运行1秒。此序列不断重复。程序退出时，电机安全停止。

**代码**

以下Python代码控制电机的旋转方向和时序：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from time import sleep
   from fusion_hat.motor import Motor

   # Motor on port M0, reverse direction if needed
   motor = Motor("M0", is_reversed=True)

   try:
      while True:
         motor.power(0)
         sleep(0.5)

         motor.power(-50)
         sleep(1)

         motor.power(0)
         sleep(0.5)

         motor.power(75)
         sleep(1)

   except KeyboardInterrupt:
      # Ctrl + C to stop
      print("\nStopped by user.")

   finally:
      # Always stop the motor safely
      motor.stop()
      sleep(0.1)

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库简化了GPIO交互，而\ ``time``\ 库提供了延迟功能。

   .. code-block:: python

      from time import sleep
      from fusion_hat.motor import Motor

2. **电机初始化**

   ``Motor``\ 对象使用M0引脚创建。

   .. code-block:: python

      motor = Motor('M0', is_reversed=True)

3. **电机动作**

   电机速度分别设置为0、-50和75。\ ``sleep``\ 函数将程序暂停指定的时间。

   .. code-block:: python

      try:
         # Loop forever
         while True:
            motor.power(0)       # Stop the motor
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(-50)     # Run the motor at -50% power
            sleep(1)             # Run for 1 second

            motor.power(0)       # Stop again
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(75)      # Run the motor at 75% power
            sleep(1)             # Run for 1 second

**故障排除**

1. **电机不转**

   - **原因**：接线错误或GPIO引脚配置不正确。
   - **解决方案**：确保电机已通电且使能引脚已正确连接。

2. **只有一个方向能工作**

   - **原因**：正向或反向引脚连接故障。
   - **解决方案**：确保引脚牢固连接到Fusion HAT+。

3. **电机持续旋转不停**

   - **原因**：\ ``stop()``\ 函数可能未正确执行。
   - **解决方案**：确认已调用\ ``motor.stop()``\ 方法。

      while True:

            motor.speed(num)
         else:

   .. code-block:: python

      motor.speed(50)
      sleep(duration)
      motor.stop()
