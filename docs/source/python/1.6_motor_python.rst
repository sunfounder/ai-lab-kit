**Ejecutar el Ejemplo**


Todos los ejemplos de código utilizados en este tutorial están disponibles en el directorio ``ai-lab-kit``.
Sigue estos pasos para ejecutar el ejemplo:


.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/python/
   sudo python3 1.6_Motor.py

Después de ejecutar el script, el motor conectado al puerto M0 se inicia y detiene repetidamente en un bucle. Primero se detiene durante 0.5 segundos, luego funciona al −50% de potencia durante 1 segundo, se detiene nuevamente durante 0.5 segundos y finalmente funciona al 75% de potencia durante 1 segundo. Esta secuencia se repite continuamente. Cuando el programa termina, el motor se detiene de forma segura.

**Código**

El siguiente código Python controla la dirección de rotación y la temporización del motor:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from time import sleep
   from fusion_hat.motor import Motor

   # Motor on port M0, reverse direction if needed
   motor = Motor("M0", is_reversed=True)

   try:
      while True:
         motor.power(0)
         sleep(0.5)

         motor.power(-50)
         sleep(1)

         motor.power(0)
         sleep(0.5)

         motor.power(75)
         sleep(1)

   except KeyboardInterrupt:
      # Ctrl + C to stop
      print("\nStopped by user.")

   finally:
      # Always stop the motor safely
      motor.stop()
      sleep(0.1)


----------------------------------------------

**Comprender el Código**

1. **Importación de Librerías**

   La librería ``fusion_hat`` simplifica las interacciones GPIO, mientras que la librería ``time`` proporciona funciones de retardo.

   .. code-block:: python

      from time import sleep
      from fusion_hat.motor import Motor

2. **Inicialización del Motor**

   El objeto ``Motor`` se crea usando los pines M0.

   .. code-block:: python

      motor = Motor('M0', is_reversed=True)

3. **Acciones del Motor**

   La velocidad del motor se establece en 0, -50 y 75, respectivamente. La función ``sleep`` pausa el programa durante una duración especificada.

   .. code-block:: python

      try:
         # Loop forever
         while True:
            motor.power(0)       # Stop the motor
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(-50)     # Run the motor at -50% power
            sleep(1)             # Run for 1 second

            motor.power(0)       # Stop again
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(75)      # Run the motor at 75% power
            sleep(1)             # Run for 1 second

**Solución de Problemas**

1. **El Motor No se Mueve**

   - **Causa**: Cableado incorrecto o configuración del pin GPIO.
   - **Solución**: Asegúrate de que el motor esté recibiendo alimentación y que el pin de habilitación esté conectado correctamente.

2. **Solo Funciona una Dirección**

   - **Causa**: Conexión defectuosa al pin de avance o retroceso.
   - **Solución**: Asegúrate de que los pines estén firmemente conectados a la Fusion HAT+.

3. **El Motor Gira Continuamente Sin Detenerse**

   - **Causa**: La función ``stop()`` puede no ejecutarse correctamente.
   - **Solución**: Confirma que se llame al método ``motor.stop()``.

**Ideas para Extender**


1. **Acciones Controladas por el Usuario**

   Permite al usuario controlar el motor en tiempo real mediante entrada por teclado:

   .. code-block:: python

      while True:
         num = int(input("The speed percentage (-100~100): "))
         if num >= -100 and num <= 100:
            motor.speed(num)
         else:
            print("Invalid action!")


3. **Control Temporizado del Motor**

   Agrega funcionalidad para hacer funcionar el motor durante una duración especificada por el usuario:

   .. code-block:: python

      duration = int(input("Enter duration (seconds): "))
      motor.speed(50)
      sleep(duration)
      motor.stop()
