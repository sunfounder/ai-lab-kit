**Executer l'exemple**


Tous les exemples de code utilises dans ce tutoriel sont disponibles dans le repertoire ``ai-lab-kit``.
Suivez ces etapes pour executer l'exemple :


.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/python/
   sudo python3 1.6_Motor.py

Apres avoir execute le script, le moteur connecte au port M0 demarre et s'arrete repetitivement en boucle. Il s'arrete d'abord pendant 0,5 seconde, puis tourne a -50% de puissance pendant 1 seconde, s'arrete a nouveau pendant 0,5 seconde, et enfin tourne a 75% de puissance pendant 1 seconde. Cette sequence se repete en continu. Lorsque le programme se termine, le moteur est arrete en toute securite.

**Code**

Le code Python suivant controle la direction et la temporisation du moteur :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from time import sleep
   from fusion_hat.motor import Motor

   # Motor on port M0, reverse direction if needed
   motor = Motor("M0", is_reversed=True)

   try:
      while True:
         motor.power(0)
         sleep(0.5)

         motor.power(-50)
         sleep(1)

         motor.power(0)
         sleep(0.5)

         motor.power(75)
         sleep(1)

   except KeyboardInterrupt:
      # Ctrl + C to stop
      print("\nStopped by user.")

   finally:
      # Always stop the motor safely
      motor.stop()
      sleep(0.1)

**Comprendre le code**

1. **Importation de la bibliotheque**

   La bibliotheque ``fusion_hat`` simplifie les interactions GPIO, tandis que la bibliotheque ``time`` fournit des fonctions de temporisation.

   .. code-block:: python

      from time import sleep
      from fusion_hat.motor import Motor

2. **Initialisation du moteur**

   L'objet ``Motor`` est cree en utilisant les broches M0.

   .. code-block:: python

      motor = Motor('M0', is_reversed=True)

3. **Actions du moteur**

   La vitesse du moteur est definie a 0, -50 et 75 respectivement. La fonction ``sleep`` suspend le programme pendant une duree specifiee.

   .. code-block:: python

      try:
         # Loop forever
         while True:
            motor.power(0)       # Stop the motor
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(-50)     # Run the motor at -50% power
            sleep(1)             # Run for 1 second

            motor.power(0)       # Stop again
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(75)      # Run the motor at 75% power
            sleep(1)             # Run for 1 second

**Depannage**

1. **Le moteur ne tourne pas**

   - **Cause** : Cablage incorrect ou configuration de broche GPIO.
   - **Solution** : Assurez-vous que le moteur recoit de l'alimentation et que la broche d'activation est correctement connectee.

2. **Une seule direction fonctionne**

   - **Cause** : Connexion defectueuse a la broche avant ou arriere.
   - **Solution** : Assurez-vous que les broches sont solidement connectees au Fusion HAT+.

3. **Le moteur tourne en continu sans s'arreter**

   - **Cause** : La fonction ``stop()`` peut ne pas etre executee correctement.
   - **Solution** : Confirmez que la methode ``motor.stop()`` est appelee.

**Idees d'extension**


1. **Actions controlees par l'utilisateur**

   Permettez a l'utilisateur de controler le moteur en temps reel via le clavier :

   .. code-block:: python

      while True:
         num = int(input("The speed percentage (-100~100): "))
         if num >= -100 and num <= 100:
            motor.speed(num)
         else:
            print("Invalid action!")


2. **Controle temporise du moteur**

   Ajoutez la possibilite de faire tourner le moteur pendant une duree specifiee par l'utilisateur :

   .. code-block:: python

      duration = int(input("Enter duration (seconds): "))
      motor.speed(50)
      sleep(duration)
      motor.stop()
