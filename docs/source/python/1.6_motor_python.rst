   cd ~/ai-lab-kit/python/
   sudo python3 1.6_Motor.py

Dopo aver eseguito lo script, il motore collegato alla porta M0 si avvia e si ferma ripetutamente in un ciclo. Prima si ferma per 0,5 secondi, poi funziona al -50% di potenza per 1 secondo, si ferma di nuovo per 0,5 secondi e infine funziona al 75% di potenza per 1 secondo. Questa sequenza si ripete continuamente. Quando il programma esce, il motore viene fermato in sicurezza.

**Codice**

Il seguente codice Python controlla la direzione di rotazione e i tempi del motore:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from time import sleep
   from fusion_hat.motor import Motor

   # Motor on port M0, reverse direction if needed
   motor = Motor("M0", is_reversed=True)

   try:
      while True:
         motor.power(0)
         sleep(0.5)

         motor.power(-50)
         sleep(1)

         motor.power(0)
         sleep(0.5)

         motor.power(75)
         sleep(1)

   except KeyboardInterrupt:
      # Ctrl + C to stop
      print("\nStopped by user.")

   finally:
      # Always stop the motor safely
      motor.stop()
      sleep(0.1)


----------------------------------------------

**Comprendere il Codice**

1. **Importazione della Libreria**

   La libreria ``fusion_hat`` semplifica le interazioni GPIO, mentre la libreria ``time`` fornisce funzioni di ritardo.

   .. code-block:: python

      from time import sleep
      from fusion_hat.motor import Motor

2. **Inizializzazione del Motore**

   L'oggetto ``Motor`` viene creato usando i pin M0.

   .. code-block:: python

      motor = Motor('M0', is_reversed=True)

3. **Azioni del Motore**

   La velocità del motore viene impostata rispettivamente a 0, -50 e 75. La funzione ``sleep`` mette in pausa il programma per una durata specificata.

   .. code-block:: python

      try:
         # Loop forever
         while True:
            motor.power(0)       # Stop the motor
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(-50)     # Run the motor at -50% power
            sleep(1)             # Run for 1 second

            motor.power(0)       # Stop again
            sleep(0.5)           # Wait 0.5 seconds

            motor.power(75)      # Run the motor at 75% power
            sleep(1)             # Run for 1 second

**Risoluzione dei Problemi**

1. **Il Motore Non Si Muove**

   - **Causa**: Cablaggio errato o configurazione errata del pin GPIO.
   - **Soluzione**: Assicurati che il motore riceva alimentazione e che il pin di abilitazione sia collegato correttamente.

2. **Funziona Solo una Direzione**

   - **Causa**: Connessione difettosa al pin avanti o indietro.
   - **Soluzione**: Assicurati che i pin siano saldamente collegati a Fusion HAT+.

3. **Il Motore Gira Continuamente Senza Fermarsi**

   - **Causa**: La funzione ``stop()`` potrebbe non essere eseguita correttamente.
   - **Soluzione**: Conferma che il metodo ``motor.stop()`` venga chiamato.

**Idee Estendibili**


1. **Azioni Controllate dall'Utente**

   Permetti all'utente di controllare il motore in tempo reale tramite input da tastiera:

   .. code-block:: python

      while True:
         num = int(input("The speed percentage (-100~100): "))
         if num >= -100 and num <= 100:
            motor.speed(num)
         else:
            print("Invalid action!")


3. **Controllo Temporizzato del Motore**

   Aggiungi funzionalità per far funzionare il motore per una durata specificata dall'utente:

   .. code-block:: python

      duration = int(input("Enter duration (seconds): "))
      motor.speed(50)
      sleep(duration)
      motor.stop()
