3.3 Haut-parleur du Fusion HAT+
======================================

**Introduction**

Le Fusion HAT+ comprend un haut-parleur integre, ce qui le rend ideal pour les invites vocales, les alarmes et autres applications audio AI/IoT.
Cette lecon vous montre comment activer, tester et utiliser le haut-parleur avec la synthese vocale.

.. note::
   Ce guide suppose que le systeme d’exploitation Raspberry Pi est installe et que les pilotes du Fusion HAT+ sont correctement configures.

**Verifier si le haut-parleur est reconnu**

Verifiez si le peripherique audio du Fusion HAT+ est detecte par le systeme :

.. raw:: html

   <run></run>

.. code-block:: shell

   aplay -l

Vous devriez voir un peripherique audio similaire a :

.. code-block:: text

   card 3: voicehat [Fusion HAT+ Audio], device 0: ...

Si un peripherique nomme ``voicehat`` (ou similaire) apparait sous **n’importe quel numero de carte**,
le materiel audio du Fusion HAT+ est reconnu avec succes.

------------------------------------------------------------


**Executer le programme exemple**

La facon la plus fiable de tester le haut-parleur est d’executer l’exemple de synthese vocale.

.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/llm
   sudo python3 tts_espeak.py

Vous devriez entendre : “Hello! I’m Espeak TTS.”

Essayez d’ajuster les parametres TTS dans le script pour entendre differents effets vocaux.

------------------------------------------------------------

**Exemple de code**

.. code-block:: python

   from fusion_hat.tts import Espeak

   tts = Espeak()
   tts.set_amp(200)
   tts.set_speed(150)
   tts.set_gap(1)
   tts.set_pitch(80)

   tts.say(“Hello! I’m Espeak TTS.”)

**Explication du code**

* ``set_amp(0–200)`` — volume
* ``set_speed(80–260)`` — vitesse de parole
* ``set_gap(0–200)`` — pause entre les mots
* ``set_pitch(0–99)`` — hauteur de la voix
* ``say()`` — convertir le texte en parole et le jouer

.. tip::

   Augmentez la vitesse et la hauteur pour rendre la voix joyeuse ;
   diminuez les deux pour un ton plus grave et plus serieux.


------------------------------------------------------------

**Depannage**

* **Aucune sortie sonore**

  - Assurez-vous que le peripherique audio du Fusion HAT+ est detecte :

   .. raw:: html

      <run></run>

   .. code-block:: shell

       aplay -l

    Vous devriez voir un peripherique audio nomme ``voicehat`` (ou similaire).
    Si le peripherique n’est pas liste, eteignez le Raspberry Pi, reinserez le
    Fusion HAT+ et redemarrez.

  - Si le peripherique n’est toujours pas detecte, reinstallez le pilote audio :

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo /opt/setup_fusion_hat_audio.sh

* **La synthese vocale semble trop rapide ou robotique**

  - Ajustez les parametres de parole dans le code :

    .. code-block:: python

       tts.set_speed(120)
       tts.set_pitch(60)

* **Erreur de permission refusee**

  - Executez le script avec les privileges de superutilisateur :

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo python3 tts_espeak.py



------------------------------------------------------------

**Resume**

Dans cette lecon, vous avez appris a :

- Verifier que le haut-parleur du Fusion HAT+ est reconnu
- Utiliser Espeak TTS pour generer de la parole sur le Raspberry Pi

Le haut-parleur du Fusion HAT+ offre un moyen simple et puissant d’ajouter de l’audio a vos projets Raspberry Pi.
