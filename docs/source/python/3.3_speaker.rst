3.3 Fusion HAT+ 扬声器
=======================

**简介**

Fusion HAT+ 包含一个内置扬声器，非常适合语音提示、警报和其他 AI/IoT 音频应用。
本课程将向您展示如何启用、测试和使用扬声器进行文本转语音。

.. note::
   本指南假设已安装树莓派操作系统，并且 Fusion HAT+ 驱动程序已正确设置。

**检查扬声器是否被识别**

检查系统是否检测到 Fusion HAT+ 音频设备：

.. raw:: html

   <run></run>

.. code-block:: shell

   aplay -l

您应该会看到类似以下的音频设备：

.. code-block:: text

   card 3: voicehat [Fusion HAT+ Audio], device 0: ...

如果在**任意卡号**下出现名为 ``voicehat``\ （或类似名称）的设备，
则 Fusion HAT+ 音频硬件已成功被识别。

------------------------------------------------------------


**运行示例程序**

测试扬声器最可靠的方法是运行文本转语音示例。

.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/llm
   sudo python3 tts_espeak.py

您应该会听到："Hello! I'm Espeak TTS."

尝试调整脚本中的 TTS 参数，以听到不同的语音效果。

------------------------------------------------------------

**示例代码**

.. code-block:: python

   from fusion_hat.tts import Espeak

   tts = Espeak()
   tts.set_amp(200)
   tts.set_speed(150)
   tts.set_gap(1)
   tts.set_pitch(80)

   tts.say("Hello! I'm Espeak TTS.")

**代码说明**

* ``set_amp(0–200)`` — 音量
* ``set_speed(80–260)`` — 语速
* ``set_gap(0–200)`` — 单词间的停顿
* ``set_pitch(0–99)`` — 音调
* ``say()`` — 将文本转换为语音并播放

.. tip::

   提高速度和音调可使声音听起来更欢快；
   降低两者则可获得更深沉、更严肃的音色。


------------------------------------------------------------

**故障排除**

* **没有声音输出**

  - 确保 Fusion HAT+ 音频设备已被检测到：

   .. raw:: html

      <run></run>

   .. code-block:: shell

       aplay -l

    您应该看到一个名为 ``voicehat``（或类似名称）的音频设备。
    如果设备未列出，请关闭树莓派电源，重新插拔 Fusion HAT+，然后重新启动。

  - 如果设备仍未被检测到，请重新安装音频驱动程序：

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo /opt/setup_fusion_hat_audio.sh

* **文本转语音听起来太快或太机械**

  - 调整代码中的语音参数：

    .. code-block:: python

       tts.set_speed(120)
       tts.set_pitch(60)

* **权限拒绝错误**

  - 使用超级用户权限运行脚本：

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo python3 tts_espeak.py
