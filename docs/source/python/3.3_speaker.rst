3.3 Altoparlante Fusion HAT+
==============================

**Introduzione**

Fusion HAT+ include un altoparlante integrato, che lo rende ideale per prompt vocali, allarmi e altre applicazioni audio AI/IoT.
Questa lezione mostra come abilitare, testare e usare l'altoparlante con la sintesi vocale.

.. note::
   Questa guida presuppone che Raspberry Pi OS sia installato e che i driver Fusion HAT+ siano configurati correttamente.

**Verifica se l'Altoparlante è Riconosciuto**

Controlla se il dispositivo audio Fusion HAT+ viene rilevato dal sistema:

.. raw:: html

   <run></run>

.. code-block:: shell

   aplay -l

Dovresti vedere un dispositivo audio simile a:

.. code-block:: text

   card 3: voicehat [Fusion HAT+ Audio], device 0: ...

Se un dispositivo chiamato ``voicehat`` (o simile) appare sotto **qualsiasi numero di scheda**,
l'hardware audio Fusion HAT+ è riconosciuto con successo.

------------------------------------------------------------


**Esegui il Programma di Esempio**

Il modo più affidabile per testare l'altoparlante è eseguire l'esempio di sintesi vocale.

.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/llm
   sudo python3 tts_espeak.py

Dovresti sentire: "Hello! I'm Espeak TTS."

Prova a regolare i parametri TTS nello script per sentire diversi effetti vocali.

------------------------------------------------------------

**Codice di Esempio**

.. code-block:: python

   from fusion_hat.tts import Espeak

   tts = Espeak()
   tts.set_amp(200)
   tts.set_speed(150)
   tts.set_gap(1)
   tts.set_pitch(80)

   tts.say("Hello! I'm Espeak TTS.")

**Spiegazione del Codice**

* ``set_amp(0-200)`` — volume
* ``set_speed(80-260)`` — velocità di eloquio
* ``set_gap(0-200)`` — pausa tra le parole
* ``set_pitch(0-99)`` — altezza della voce
* ``say()`` — converte il testo in voce e lo riproduce

.. tip::

   Aumenta velocità e altezza per rendere la voce allegra;
   abbassa entrambe per un tono più profondo e serio.


------------------------------------------------------------

**Risoluzione dei Problemi**

* **Nessun suono in uscita**

  - Assicurati che il dispositivo audio Fusion HAT+ sia rilevato:

   .. raw:: html

      <run></run>

   .. code-block:: shell

       aplay -l

    Dovresti vedere un dispositivo audio chiamato ``voicehat`` (o simile).
    Se il dispositivo non è elencato, spegni il Raspberry Pi, reinserisci
    Fusion HAT+ e riavvia.

  - Se il dispositivo non viene ancora rilevato, reinstalla il driver audio:

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo /opt/setup_fusion_hat_audio.sh

* **La sintesi vocale è troppo veloce o robotica**

  - Regola i parametri di eloquio nel codice:

    .. code-block:: python

       tts.set_speed(120)
       tts.set_pitch(60)

* **Errore di permesso negato**

  - Esegui lo script con privilegi di superutente:

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo python3 tts_espeak.py



------------------------------------------------------------

**Riepilogo**

In questa lezione, hai imparato come:

- Verificare che l'altoparlante Fusion HAT+ sia riconosciuto
- Usare Espeak TTS per generare voce sul Raspberry Pi

L'altoparlante Fusion HAT+ fornisce un modo semplice e potente per aggiungere audio ai tuoi progetti Raspberry Pi.
