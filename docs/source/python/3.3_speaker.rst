3.3 Altavoz de Fusion HAT+
==============================

**Introducción**

El Fusion HAT+ incluye un altavoz integrado, lo que lo hace ideal para avisos de voz, alarmas y otras aplicaciones de audio para IA/IoT.
Esta lección te muestra cómo habilitar, probar y usar el altavoz con conversión de texto a voz.

.. note::
   Esta guía asume que Raspberry Pi OS está instalado y que los controladores de Fusion HAT+ están configurados correctamente.

**Verificar si el Altavoz es Reconocido**

Verifica si el dispositivo de audio Fusion HAT+ es detectado por el sistema:

.. raw:: html

   <run></run>

.. code-block:: shell

   aplay -l

Deberías ver un dispositivo de audio similar a:

.. code-block:: text

   card 3: voicehat [Fusion HAT+ Audio], device 0: ...

Si aparece un dispositivo llamado ``voicehat`` (o similar) bajo **cualquier número de tarjeta**,
el hardware de audio de Fusion HAT+ se ha reconocido correctamente.

------------------------------------------------------------


**Ejecutar el Programa de Ejemplo**

La forma más fiable de probar el altavoz es ejecutar el ejemplo de conversión de texto a voz.

.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/llm
   sudo python3 tts_espeak.py

Deberías escuchar: "Hello! I'm Espeak TTS."

Intenta ajustar los parámetros de TTS en el script para escuchar diferentes efectos de voz.

------------------------------------------------------------

**Código de Ejemplo**

.. code-block:: python

   from fusion_hat.tts import Espeak

   tts = Espeak()
   tts.set_amp(200)
   tts.set_speed(150)
   tts.set_gap(1)
   tts.set_pitch(80)

   tts.say("Hello! I'm Espeak TTS.")

**Explicación del Código**

* ``set_amp(0–200)`` — volumen
* ``set_speed(80–260)`` — velocidad de habla
* ``set_gap(0–200)`` — pausa entre palabras
* ``set_pitch(0–99)`` — tono de la voz
* ``say()`` — convertir texto a voz y reproducirlo

.. tip::

   Aumenta la velocidad y el tono para hacer la voz más alegre;
   redúcelos para un tono más grave y serio.


------------------------------------------------------------

**Solución de Problemas**

* **Sin salida de sonido**

  - Asegúrate de que el dispositivo de audio Fusion HAT+ esté detectado:

   .. raw:: html

      <run></run>

   .. code-block:: shell

       aplay -l

    Deberías ver un dispositivo de audio llamado ``voicehat`` (o similar).
    Si el dispositivo no aparece, apaga la Raspberry Pi, vuelve a colocar
    el Fusion HAT+ y reinicia.

  - Si el dispositivo aún no se detecta, reinstala el controlador de audio:

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo /opt/setup_fusion_hat_audio.sh

* **El texto a voz suena demasiado rápido o robótico**

  - Ajusta los parámetros de habla en el código:

    .. code-block:: python

       tts.set_speed(120)
       tts.set_pitch(60)

* **Error de permiso denegado**

  - Ejecuta el script con privilegios de superusuario:

   .. raw:: html

      <run></run>

   .. code-block:: shell

       sudo python3 tts_espeak.py



------------------------------------------------------------

**Resumen**

En esta lección, aprendiste cómo:

- Verificar que el altavoz de Fusion HAT+ sea reconocido
- Usar Espeak TTS para generar voz en la Raspberry Pi

El altavoz de Fusion HAT+ proporciona una forma simple y potente de añadir audio a tus proyectos con Raspberry Pi.
