2.5 Module Interrupteur Tactile
=====================================

**Introduction**

Dans ce projet, nous explorons l'utilisation d'un module interrupteur tactile. Ce composant remplace les interrupteurs mecaniques traditionnels et offre des avantages tels qu'un controle precis, une sensibilite tactile fine et une usure mecanique minimale. Les interrupteurs tactiles sont couramment utilises dans les appareils modernes ou la fiabilite et la facilite d'utilisation sont essentielles.

**Schema de cablage**

1. Connectez la broche de sortie du module interrupteur tactile a GPIO17.
2. Connectez l'anode de LED1 a GPIO22 et l'anode de LED2 a GPIO27 via des resistances appropriees.

Ce script Python utilise un capteur tactile pour controler deux LED connectees a un Raspberry Pi. Lors de l'execution :

1. **Capteur tactile presse** :

   - Affiche "You touch it!" sur la console.
   - Eteint LED1 (connectee a la broche GPIO 22).
   - Allume LED2 (connectee a la broche GPIO 27).

2. **Capteur tactile non presse** :

   - LED1 s'allume.
   - LED2 s'eteint.

3. Le programme surveille en continu l'etat du capteur tactile toutes les 0,5 secondes et ajuste les LED en consequence.

4. Le script s'execute indefiniment jusqu'a ce qu'il soit interrompu en appuyant sur ``Ctrl+C``.

**Code**

Le code Python suivant controle deux LED en fonction de l'etat du module interrupteur tactile :


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize touch sensor (Button) on GPIO pin 17
   touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the touch sensor and control LEDs accordingly
      while True:
         if touch_sensor.value() == 1:  # Check if the touch sensor is pressed
               print('You touch it!')  # Output message indicating sensor activation
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

----------------------------------------------


**Comprendre le code**

1. **Importation de la bibliotheque**

   La bibliotheque ``fusion_hat`` est utilisee pour simplifier le controle GPIO, et la fonction ``sleep`` fournit la fonctionnalite de pause.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep for delay


2. **Initialisation des composants**

   Le capteur tactile est configure comme un bouton sur GPIO17, et deux LED sont initialisees sur GPIO22 et GPIO27.

   .. code-block:: python

      # Initialize touch sensor (Button) on GPIO pin 17
      touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **Boucle principale**

   Le programme verifie en continu l'etat du module interrupteur tactile. Lorsqu'il est touche, LED2 s'allume et LED1 s'eteint ; sinon, LED1 est allumee et LED2 est eteinte.

   .. code-block:: python

       while True:
           if touch_sensor.value() == 1:
               led1.off()
               led2.on()
           else:
               led1.on()
               led2.off()
           sleep(0.5)

4. **Gestion des interruptions**

   Un bloc ``try-except`` garantit que le programme se termine proprement lors de la reception d'une interruption clavier (Ctrl+C).

   .. code-block:: python

       except KeyboardInterrupt:
           pass

----------------------------------------------

**Depannage**

1. **Aucune reponse du capteur tactile**

   - **Cause** : Cablage incorrect ou configuration de broche GPIO.
   - **Solution** : Assurez-vous que le capteur tactile est connecte a la broche GPIO 17 et a la masse, et verifiez que ``PULL_DOWN`` correspond a la configuration active-low du capteur.

2. **Le capteur lit toujours presse ou non presse**

   - **Cause** : Capteur ou cablage defectueux.
   - **Solution** : Testez le capteur avec un multimetre ou remplacez-le. Verifiez les connexions desserrees ou incorrectes.


3. **Les LED scintillent ou se comportent de maniere erratique**

   - **Cause** : Problemes d'anti-rebond du bouton.
   - **Solution** : Ajoutez un anti-rebond logiciel pour stabiliser le signal d'entree :

   .. code-block:: python

      if touch_sensor.value() == 1:
         sleep(0.05)  # Debounce delay


----------------------------------------------

**Idees d'extension**

1. **Detection de la duree du toucher**

   Ajoutez la possibilite de detecter la duree pendant laquelle le capteur tactile est presse et ajustez le comportement des LED :

   .. code-block:: python

      from time import time
      start_time = None

      def handle_touch():
         global start_time
         if touch_sensor.value() == 1:
            start_time = time()
         else:
            duration = time() - start_time
            print(f"Sensor was touched for {duration:.2f} seconds")

2. **Pause ajustable**

   Permettez a l'utilisateur de modifier la pause dynamiquement pour affiner la reactivite :

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      sleep(delay)
