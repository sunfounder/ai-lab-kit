2.5 Modulo Interruttore Tattile
================================

**Introduzione**

In questo progetto, esploriamo l'uso di un modulo interruttore tattile. Questo componente sostituisce i tradizionali interruttori meccanici e offre vantaggi come controllo preciso, sensibilità al tatto fine e usura meccanica minima. Gli interruttori tattili sono comunemente usati in elettrodomestici e dispositivi moderni dove affidabilità e facilità d'uso sono essenziali.

Questo script Python usa un sensore tattile per controllare due LED collegati a un Raspberry Pi. Quando eseguito:

1. **Sensore Tattile Premuto**:

   - Stampa "You touch it!" sulla console.
   - Spegne LED1 (collegato al pin GPIO 22).
   - Accende LED2 (collegato al pin GPIO 27).

2. **Sensore Tattile Non Premuto**:

   - LED1 si accende.
   - LED2 si spegne.

3. Il programma monitora continuamente lo stato del sensore tattile ogni 0,5 secondi e regola i LED di conseguenza.

4. Lo script viene eseguito indefinitamente fino a quando non viene interrotto premendo ``Ctrl+C``.

**Codice**

Il seguente codice Python controlla due LED in base allo stato del modulo interruttore tattile:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize touch sensor (Button) on GPIO pin 17
   touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the touch sensor and control LEDs accordingly
      while True:
         if touch_sensor.value() == 1:  # Check if the touch sensor is pressed
               print('You touch it!')  # Output message indicating sensor activation
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

**Comprendere il Codice**

1. **Importazione della Libreria**

   La libreria ``fusion_hat`` viene usata per semplificare il controllo GPIO, e la funzione ``sleep`` fornisce funzionalità di ritardo.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep for delay


2. **Inizializzazione dei Componenti**

   Il sensore tattile viene configurato come pulsante su GPIO17, e due LED vengono inizializzati su GPIO22 e GPIO27.

   .. code-block:: python

      # Initialize touch sensor (Button) on GPIO pin 17
      touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **Ciclo Principale**

   Il programma controlla continuamente lo stato del modulo interruttore tattile. Quando viene toccato, LED2 si accende e LED1 si spegne; altrimenti, LED1 è acceso e LED2 spento.

   .. code-block:: python

       while True:
           if touch_sensor.value() == 1:
               led1.off()
               led2.on()
           else:
               led1.on()
               led2.off()
           sleep(0.5)

4. **Gestione dell'Interruzione**

   Un blocco ``try-except`` assicura che il programma esca pulitamente alla ricezione di un'interruzione da tastiera (Ctrl+C).

   .. code-block:: python

       except KeyboardInterrupt:
           pass

**Risoluzione dei Problemi**

1. **Nessuna Risposta dal Sensore Tattile**

   - **Causa**: Cablaggio errato o configurazione errata del pin GPIO.
   - **Soluzione**: Assicurati che il sensore tattile sia collegato al pin GPIO 17 e a massa, e verifica che ``PULL_DOWN`` corrisponda alla configurazione active-low del sensore.

2. **Il Sensore Legge Sempre Premuto o Non Premuto**

   - **Causa**: Sensore o cablaggio difettoso.
   - **Soluzione**: Testa il sensore con un multimetro o sostituiscilo. Controlla la presenza di connessioni allentate o errate.


3. **I LED Sfarfallano o si Comportano in Modo Irregolare**

   - **Causa**: Problemi di debounce del pulsante.
   - **Soluzione**: Aggiungi debounce software per stabilizzare il segnale di ingresso:

   .. code-block:: python

      if touch_sensor.value() == 1:
         sleep(0.05)  # Debounce delay

**Idee Estendibili**

1. **Rilevamento della Durata del Tocco**

   Aggiungi funzionalità per rilevare per quanto tempo il sensore tattile viene premuto e regola il comportamento dei LED:

   .. code-block:: python

      from time import time
      start_time = None

      def handle_touch():
         global start_time
         if touch_sensor.value() == 1:
            start_time = time()
         else:
            duration = time() - start_time
            print(f"Sensor was touched for {duration:.2f} seconds")

2. **Ritardo Regolabile**

   Permetti all'utente di modificare il ritardo dinamicamente per ottimizzare la reattività:

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      sleep(delay)
