2.5 触摸开关模块
=================

**介绍**

在本项目中，我们将探索触摸开关模块的使用。该组件替代了传统的机械开关，具有精确控制、精细触摸灵敏度和最小机械磨损等优点。触摸开关常用于对可靠性和操作便捷性要求较高的现代电器和设备中。

此Python脚本使用触摸传感器控制连接到Raspberry Pi的两个LED。执行时：

1. **触摸传感器按下**：

   - 在控制台打印"You touch it!"。
   - 熄灭LED1（连接到GPIO 22引脚）。
   - 点亮LED2（连接到GPIO 27引脚）。

2. **触摸传感器未按下**：

   - LED1点亮。
   - LED2熄灭。

3. 程序每0.5秒持续监测触摸传感器的状态并相应调整LED。

4. 脚本无限运行，直到按下\ ``Ctrl+C``\ 中断。

**代码**

以下Python代码根据触摸开关模块的状态控制两个LED：


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize touch sensor (Button) on GPIO pin 17
   touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the touch sensor and control LEDs accordingly
      while True:
         if touch_sensor.value() == 1:  # Check if the touch sensor is pressed
               print('You touch it!')  # Output message indicating sensor activation
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库用于简化GPIO控制，\ ``sleep``\ 函数提供延迟功能。

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep for delay


2. **组件初始化**

   触摸传感器配置为GPIO17上的按钮，两个LED在GPIO22和GPIO27上初始化。

   .. code-block:: python

      # Initialize touch sensor (Button) on GPIO pin 17
      touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **主循环**

   程序持续检查触摸开关模块的状态。触摸时，LED2亮、LED1灭；否则LED1亮、LED2灭。

   .. code-block:: python

       while True:
           if touch_sensor.value() == 1:
               led1.off()
               led2.on()
           else:
               led1.on()
               led2.off()
           sleep(0.5)

4. **中断处理**

   ``try-except``\ 块确保程序在收到键盘中断（\ ``Ctrl+C``\ ）时能干净退出。

   .. code-block:: python

       except KeyboardInterrupt:
           pass

----------------------------------------------

**故障排除**

1. **触摸传感器无响应**

   - **原因**：接线错误或GPIO引脚配置不正确。
   - **解决方案**：确保触摸传感器连接到GPIO 17引脚和地，并确认\ ``PULL_DOWN``\ 与传感器的低电平有效配置匹配。

2. **传感器始终读为按下或未按下**

   - **原因**：传感器或接线故障。
   - **解决方案**：使用万用表测试传感器或更换传感器。检查连接是否松动或错误。

3. **LED闪烁或行为异常**

   - **原因**：按钮消抖问题。
   - **解决方案**：添加软件消抖以稳定输入信号：

   .. code-block:: python

      if touch_sensor.value() == 1:
         sleep(0.05)  # Debounce delay

**扩展思路**

1. **触摸时长检测**

   添加检测触摸传感器按下时长的功能，并相应调整LED行为：

   .. code-block:: python

      from time import time
      start_time = None

      def handle_touch():
         global start_time
         if touch_sensor.value() == 1:
            start_time = time()
         else:
            duration = time() - start_time
            print(f"Sensor was touched for {duration:.2f} seconds")

2. **可调延迟**

   允许用户动态修改延迟以微调响应速度：

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      sleep(delay)
