2.5 Módulo de Interruptor Táctil
================================

**Introducción**

En este proyecto, exploramos el uso de un Módulo de Interruptor Táctil. Este componente reemplaza los interruptores mecánicos tradicionales y ofrece beneficios como control preciso, sensibilidad táctil fina y desgaste mecánico mínimo. Los interruptores táctiles se utilizan comúnmente en electrodomésticos y dispositivos modernos donde la fiabilidad y la facilidad de operación son esenciales.

Este script de Python utiliza un sensor táctil para controlar dos LEDs conectados a una Raspberry Pi. Cuando se ejecuta:

1. **Sensor Táctil Presionado**:

   - Imprime "You touch it!" en la consola.
   - Apaga LED1 (conectado al pin GPIO 22).
   - Enciende LED2 (conectado al pin GPIO 27).

2. **Sensor Táctil No Presionado**:

   - LED1 se enciende.
   - LED2 se apaga.

3. El programa monitorea continuamente el estado del sensor táctil cada 0.5 segundos y ajusta los LEDs en consecuencia.

4. El script se ejecuta indefinidamente hasta que se interrumpe presionando ``Ctrl+C``.

**Código**

El siguiente código de Python controla dos LEDs según el estado del Módulo de Interruptor Táctil:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize touch sensor (Button) on GPIO pin 17
   touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the touch sensor and control LEDs accordingly
      while True:
         if touch_sensor.value() == 1:  # Check if the touch sensor is pressed
               print('You touch it!')  # Output message indicating sensor activation
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

**Comprender el Código**

1. **Importación de Librerías**

   La librería ``fusion_hat`` se utiliza para simplificar el control de GPIO, y la función ``sleep`` proporciona funcionalidad de retardo.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep for delay


2. **Inicialización de Componentes**

   El sensor táctil se configura como un botón en GPIO17, y dos LEDs se inicializan en GPIO22 y GPIO27.

   .. code-block:: python

      # Initialize touch sensor (Button) on GPIO pin 17
      touch_sensor = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **Bucle Principal**

   El programa verifica continuamente el estado del Módulo de Interruptor Táctil. Cuando se toca, LED2 se enciende y LED1 se apaga; de lo contrario, LED1 está encendido y LED2 apagado.

   .. code-block:: python

       while True:
           if touch_sensor.value() == 1:
               led1.off()
               led2.on()
           else:
               led1.on()
               led2.off()
           sleep(0.5)

4. **Manejo de Interrupciones**

   Un bloque ``try-except`` asegura que el programa termine correctamente al recibir una interrupción de teclado (Ctrl+C).

   .. code-block:: python

       except KeyboardInterrupt:
           pass

----------------------------------------------

**Solución de Problemas**

1. **Sin Respuesta del Sensor Táctil**

   - **Causa**: Cableado incorrecto o configuración del pin GPIO.
   - **Solución**: Asegúrate de que el sensor táctil esté conectado al pin GPIO 17 y a tierra, y verifica que ``PULL_DOWN`` coincida con la configuración activa en bajo del sensor.

2. **El Sensor Siempre Lee Presionado o No Presionado**

   - **Causa**: Sensor o cableado defectuoso.
   - **Solución**: Prueba el sensor con un multímetro o reemplázalo. Verifica si hay conexiones sueltas o incorrectas.


3. **Los LEDs Parpadean o se Comportan de Forma Errática**

   - **Causa**: Problemas de debounce del botón.
   - **Solución**: Añade debounce por software para estabilizar la señal de entrada:

   .. code-block:: python

      if touch_sensor.value() == 1:
         sleep(0.05)  # Debounce delay

**Ideas para Extender**

1. **Detección de Duración del Toque**

   Añade funcionalidad para detectar cuánto tiempo se presiona el sensor táctil y ajustar el comportamiento del LED:

   .. code-block:: python

      from time import time
      start_time = None

      def handle_touch():
         global start_time
         if touch_sensor.value() == 1:
            start_time = time()
         else:
            duration = time() - start_time
            print(f"Sensor was touched for {duration:.2f} seconds")

2. **Retardo Ajustable**

   Permite al usuario modificar el retardo dinámicamente para ajustar la capacidad de respuesta:

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      sleep(delay)
