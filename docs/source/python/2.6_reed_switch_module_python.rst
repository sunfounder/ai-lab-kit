2.6 Interrupteur Reed
=========================

**Introduction**

Dans ce projet, nous allons apprendre a utiliser un interrupteur reed comme capteur de champ magnetique pour controler des LED. Un interrupteur reed est un interrupteur electrique actionne par un champ magnetique applique, couramment utilise dans les systemes de securite, les capteurs de porte/fenetre et la detection de position. Ce projet montre comment detecter l'etat d'un interrupteur reed et fournir un retour visuel en utilisant deux LED.

**Schema de circuit**

Le circuit utilise un interrupteur reed connecte a une broche d'entree GPIO avec une resistance pull-down. Deux LED sont connectees a des broches de sortie GPIO separees, chacune avec une resistance de limitation de courant. Lorsqu'un aimant s'approche de l'interrupteur reed, il ferme le circuit, declenchant le changement d'etat des indicateurs LED.

.. image:: img/fzz/2.2.4_sch.png

----------------------------------------------

**Schema de cablage**

Suivez ces etapes pour construire le circuit :

1. Connectez la broche GND et VCC de l'interrupteur reed a GND et 3,3V.
2. Connectez la broche D0 de l'interrupteur reed a GPIO 17.
3. Connectez la cathode de LED1 a GPIO 22 via une resistance de 220Ω.
4. Connectez l'anode de LED1 a GND.
5. Connectez la cathode de LED2 a GPIO 27 via une resistance de 220Ω.
6. Connectez l'anode de LED2 a GND.

Ce script Python cree un systeme de detection de champ magnetique en utilisant un interrupteur reed et deux LED d'etat. Lors de l'execution :

1. Le script surveille en continu l'etat de l'interrupteur reed.
2. Lorsqu'un aimant est detecte (interrupteur reed ferme), LED1 s'eteint et LED2 s'allume.
3. Lorsqu'aucun aimant n'est detecte (interrupteur reed ouvert), LED1 s'allume et LED2 s'eteint.
4. Cela cree une indication visuelle claire de la presence du champ magnetique.
5. Le programme peut etre interrompu proprement avec ``Ctrl+C``.

**Code**

Le code Python suivant surveille un interrupteur reed et controle deux LED en fonction de son etat :

.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat.pin import Pin, Mode, Pull
    from time import sleep  # Import sleep for delay

    # Initialize reed switch (Button) on GPIO pin 17
    reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

    # Initialize LED1 connected to GPIO pin 22
    led1 = Pin(22,mode=Mode.OUT)
    # Initialize LED2 connected to GPIO pin 27
    led2 = Pin(27,mode=Mode.OUT)

    try:
        # Continuously monitor the state of the reed switch and control LEDs accordingly
        while True:
            if reed.value() == 0:  # Check if the reed switch is activated
                led1.off()  # Turn off LED1
                led2.on()   # Turn on LED2
            else:  # If the sensor is not activated
                led1.on()   # Turn on LED1
                led2.off()  # Turn off LED2

    except KeyboardInterrupt:
        # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
        pass

**Comprendre le code**

1. **Importation de la bibliotheque**

   La classe ``Pin`` de la bibliotheque ``fusion_hat`` est utilisee pour controler les broches GPIO, et ``time.sleep`` est importee pour les operations de temporisation.

   .. code-block:: python

        from fusion_hat.pin import Pin, Mode, Pull
        from time import sleep  # Import sleep for delay

2. **Initialisation de l'interrupteur reed**

   L'interrupteur reed est initialise sur la broche GPIO 17 en tant qu'entree avec une resistance pull-down pour garantir un etat BAS stable lorsque l'interrupteur est ouvert.

   .. code-block:: python

        # Initialize reed switch (Button) on GPIO pin 17
        reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **Initialisation des LED**

   Deux LED sont initialisees sur les broches GPIO 22 et 27 en tant que sorties pour fournir un retour visuel.

   .. code-block:: python

        # Initialize LED1 connected to GPIO pin 22
        led1 = Pin(22,mode=Mode.OUT)
        # Initialize LED2 connected to GPIO pin 27
        led2 = Pin(27,mode=Mode.OUT)

4. **Boucle de surveillance principale**

   La boucle ``while True`` verifie en continu l'etat de l'interrupteur reed et controle les LED en consequence, creant un systeme d'indication d'etat clair.

   .. code-block:: python

      while True:
          if reed.value() == 0:  # Check if the reed switch is activated
              led1.off()  # Turn off LED1
              led2.on()   # Turn on LED2
          else:  # If the sensor is not activated
              led1.on()   # Turn on LED1
              led2.off()  # Turn off LED2

5. **Gestion des interruptions clavier**

   Le bloc ``try-except`` garantit que le programme s'arrete proprement lorsqu'il est interrompu.

   .. code-block:: python

      except KeyboardInterrupt:
          # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
          pass

**Depannage**

1. **L'interrupteur reed ne detecte pas l'aimant**

   - **Cause** : Problemes de polarite de l'aimant, force magnetique insuffisante ou problemes de cablage.
   - **Solution** : Essayez de retourner l'aimant, utilisez un aimant plus fort ou verifiez toutes les connexions.

2. **Les LED ne s'allument pas**

   - **Cause** : Assignations de broches GPIO incorrectes, polarite de la LED inversee ou courant insuffisant.
   - **Solution** : Verifiez les assignations des broches, assurez-vous que les LED sont connectees avec la polarite correcte (anode vers GPIO) et verifiez les valeurs des resistances.

3. **Lectures instables**

   - **Cause** : Bruit electrique ou entree flottante lorsque l'interrupteur reed est ouvert.
   - **Solution** : La resistance pull-down integree devrait stabiliser l'entree, mais assurez-vous d'une mise a la masse correcte et verifiez la presence de sources d'interference electromagnetique a proximite.

**Idees d'extension**

1. **Systeme de securite**

   Creez une alarme de porte/fenetre simple qui se declenche lorsqu'un aimant s'eloigne de l'interrupteur reed :

   .. code-block:: python

      # Add a buzzer for audible alarm
      from fusion_hat import Buzzer, PWM
      buzzer = Buzzer(PWM('P0'))

      while True:
          if reed.value() == 1:  # Door opened (magnet moved away)
              buzzer.play('C6', 0.5)  # Sound alarm
              led1.on()  # Red alert LED
          else:
              led2.on()  # Green safe LED
          sleep(0.1)

2. **Compteur de position**

   Comptez combien de fois un aimant passe devant l'interrupteur reed, utile pour la mesure de vitesse de rotation :

   .. code-block:: python

      counter = 0
      last_state = 0

      while True:
          current_state = reed.value()
          if last_state == 0 and current_state == 1:  # Detect rising edge
              counter += 1
              print(f"Count: {counter}")
          last_state = current_state
          sleep(0.01)  # Short delay for debouncing
