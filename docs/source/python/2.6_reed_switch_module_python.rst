2.6 干簧管
===========

**介绍**

在本项目中，我们将学习如何使用干簧管作为磁场传感器来控制LED。干簧管是一种由外加磁场操作的电子开关，常用于安全系统、门窗传感器和位置检测。本项目演示如何检测干簧管的状态并使用两个LED提供视觉反馈。

**电路图**

该电路使用一个连接到GPIO输入引脚的干簧管，并带有一个下拉电阻。两个LED分别连接到独立的GPIO输出引脚，每个都带有限流电阻。当磁铁靠近干簧管时，电路闭合，触发LED指示器改变状态。

.. image:: img/fzz/2.2.4_sch.png

----------------------------------------------

**接线图**

请按照以下步骤搭建电路：

1. 将干簧管的GND和VCC引脚分别连接到GND和3.3V。
2. 将干簧管的D0引脚连接到GPIO 17。
3. 通过220Ω电阻将LED1的负极连接到GPIO 22。
4. 将LED1的正极连接到GND。
5. 通过220Ω电阻将LED2的负极连接到GPIO 27。
6. 将LED2的正极连接到GND。

**代码**

以下Python代码监测干簧管并根据其状态控制两个LED：

.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat.pin import Pin, Mode, Pull
    from time import sleep  # Import sleep for delay

    # Initialize reed switch (Button) on GPIO pin 17
    reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

    # Initialize LED1 connected to GPIO pin 22
    led1 = Pin(22,mode=Mode.OUT)
    # Initialize LED2 connected to GPIO pin 27
    led2 = Pin(27,mode=Mode.OUT)

    try:
        # Continuously monitor the state of the reed switch and control LEDs accordingly
        while True:
            if reed.value() == 0:  # Check if the reed switch is activated
                led1.off()  # Turn off LED1
                led2.on()   # Turn on LED2
            else:  # If the sensor is not activated
                led1.on()   # Turn on LED1
                led2.off()  # Turn off LED2

    except KeyboardInterrupt:
        # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
        pass

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库中的\ ``Pin``\ 类用于控制GPIO引脚，\ ``time.sleep``\ 导入用于可能的延迟操作。

   .. code-block:: python

        from fusion_hat.pin import Pin, Mode, Pull
        from time import sleep  # Import sleep for delay

2. **干簧管初始化**

   干簧管在GPIO 17引脚上初始化为输入，并带有一个下拉电阻，以确保开关断开时保持稳定的低电平状态。

   .. code-block:: python

        # Initialize reed switch (Button) on GPIO pin 17
        reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **LED初始化**

   两个LED在GPIO 22和27引脚上初始化为输出，以提供视觉反馈。

   .. code-block:: python

        # Initialize LED1 connected to GPIO pin 22
        led1 = Pin(22,mode=Mode.OUT)
        # Initialize LED2 connected to GPIO pin 27
        led2 = Pin(27,mode=Mode.OUT)

4. **主监测循环**

   ``while True``\ 循环持续检查干簧管状态并相应控制LED，创建了一个清晰的状态指示系统。

   .. code-block:: python

      while True:
          if reed.value() == 0:  # Check if the reed switch is activated
              led1.off()  # Turn off LED1
              led2.on()   # Turn on LED2
          else:  # If the sensor is not activated
              led1.on()   # Turn on LED1
              led2.off()  # Turn off LED2

5. **键盘中断处理**

   ``try-except``\ 块确保程序在被中断时优雅地停止。

   .. code-block:: python

      except KeyboardInterrupt:
          # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
          pass

**故障排除**

1. **干簧管未检测到磁铁**

   - **原因**：磁铁极性问题、磁力不足或接线问题。
   - **解决方案**：尝试翻转磁铁、使用更强的磁铁或检查所有连接。

2. **LED不亮**

   - **原因**：GPIO引脚分配错误、LED极性接反或电流不足。
   - **解决方案**：检查引脚分配，确保LED以正确的极性连接（正极接GPIO），并确认电阻值。

3. **读数不稳定**

   - **原因**：干簧管断开时存在电气噪声或浮动输入。
   - **解决方案**：内置下拉电阻应能稳定输入，但请确保正确接地并检查附近是否有电磁干扰源。
