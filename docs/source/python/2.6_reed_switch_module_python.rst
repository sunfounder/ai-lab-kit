2.6 Interruptor de Lengüeta (Reed)
==================================

**Introducción**

En este proyecto, aprenderemos cómo usar un interruptor de lengüeta (reed) como sensor de campo magnético para controlar LEDs. Un interruptor de lengüeta es un interruptor eléctrico operado por un campo magnético aplicado, comúnmente utilizado en sistemas de seguridad, sensores de puerta/ventana y detección de posición. Este proyecto demuestra cómo detectar el estado de un interruptor de lengüeta y proporcionar retroalimentación visual usando dos LEDs.

**Diagrama de Circuito**

El circuito utiliza un interruptor de lengüeta conectado a un pin de entrada GPIO con una resistencia pull-down. Dos LEDs están conectados a pines GPIO de salida separados, cada uno con una resistencia limitadora de corriente. Cuando un imán se acerca al interruptor de lengüeta, cierra el circuito, haciendo que los indicadores LED cambien de estado.

.. image:: img/fzz/2.2.4_sch.png

----------------------------------------------

**Diagrama de Conexiones**

Sigue estos pasos para construir el circuito:

1. Conecta el pin GND y VCC del interruptor de lengüeta a GND y 3.3V
2. Conecta el pin D0 del interruptor de lengüeta a GPIO 17
3. Conecta el cátodo de LED1 a GPIO 22 mediante una resistencia de 220Ω
4. Conecta el ánodo de LED1 a GND
5. Conecta el cátodo de LED2 a GPIO 27 mediante una resistencia de 220Ω
6. Conecta el ánodo de LED2 a GND

Este script de Python crea un sistema de detección de campo magnético utilizando un interruptor de lengüeta y dos LEDs de estado. Cuando se ejecuta:

1. El script monitorea continuamente el estado del interruptor de lengüeta.
2. Cuando se detecta un imán (interruptor de lengüeta cerrado), LED1 se apaga y LED2 se enciende.

5. El programa se puede interrumpir de forma segura usando ``Ctrl+C``.

**Código**

El siguiente código de Python monitorea un interruptor de lengüeta y controla dos LEDs según su estado:

.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat.pin import Pin, Mode, Pull
    from time import sleep  # Import sleep for delay

    # Initialize reed switch (Button) on GPIO pin 17
    reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

    # Initialize LED1 connected to GPIO pin 22
    led1 = Pin(22,mode=Mode.OUT)
    # Initialize LED2 connected to GPIO pin 27
    led2 = Pin(27,mode=Mode.OUT)

    try:
        # Continuously monitor the state of the reed switch and control LEDs accordingly
        while True:
            if reed.value() == 0:  # Check if the reed switch is activated
                led1.off()  # Turn off LED1
                led2.on()   # Turn on LED2
            else:  # If the sensor is not activated
                led1.on()   # Turn on LED1
                led2.off()  # Turn off LED2

    except KeyboardInterrupt:
        # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
        pass

**Comprender el Código**

1. **Importación de Librerías**

   La clase ``Pin`` de la librería ``fusion_hat`` se utiliza para controlar los pines GPIO, y se importa ``time.sleep`` para posibles operaciones de retardo.

   .. code-block:: python

        from fusion_hat.pin import Pin, Mode, Pull
        from time import sleep  # Import sleep for delay

2. **Inicialización del Interruptor de Lengüeta**

   El interruptor de lengüeta se inicializa en el pin GPIO 17 como una entrada con una resistencia pull-down para asegurar un estado LOW estable cuando el interruptor está abierto.

   .. code-block:: python

        # Initialize reed switch (Button) on GPIO pin 17
        reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **Inicialización de LEDs**

   Se inicializan dos LEDs en los pines GPIO 22 y 27 como salidas para proporcionar retroalimentación visual.

   .. code-block:: python

        # Initialize LED1 connected to GPIO pin 22
        led1 = Pin(22,mode=Mode.OUT)
        # Initialize LED2 connected to GPIO pin 27
        led2 = Pin(27,mode=Mode.OUT)

4. **Bucle Principal de Monitoreo**

   El bucle ``while True`` verifica continuamente el estado del interruptor de lengüeta y controla los LEDs en consecuencia, creando un sistema de indicación de estado claro.

   .. code-block:: python

      while True:
          if reed.value() == 0:  # Check if the reed switch is activated
              led1.off()  # Turn off LED1
              led2.on()   # Turn on LED2
          else:  # If the sensor is not activated
              led1.on()   # Turn on LED1
              led2.off()  # Turn off LED2

5. **Manejo de Interrupción de Teclado**

   El bloque ``try-except`` asegura que el programa se detenga correctamente cuando se interrumpe.

   .. code-block:: python

      except KeyboardInterrupt:
          # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
          pass

**Solución de Problemas**

1. **El Interruptor de Lengüeta No Detecta el Imán**

   - **Causa**: Problemas de polaridad del imán, fuerza magnética insuficiente o problemas de cableado.
   - **Solución**: Intenta invertir el imán, usa un imán más fuerte o verifica todas las conexiones.

2. **Los LEDs No Encienden**

   - **Causa**: Asignaciones incorrectas de pines GPIO, polaridad del LED invertida o corriente insuficiente.
   - **Solución**: Verifica las asignaciones de pines, asegúrate de que los LEDs estén conectados con la polaridad correcta (ánodo a GPIO) y verifica los valores de las resistencias.

3. **Lecturas Inestables**

   - **Causa**: Ruido eléctrico o entrada flotante cuando el interruptor de lengüeta está abierto.
   - **Solución**: La resistencia pull-down incorporada debería estabilizar la entrada, pero asegúrate de tener una conexión a tierra adecuada y verifica si hay fuentes cercanas de interferencia electromagnética.

**Ideas para Extender**

1. **Sistema de Seguridad**

   Crea una alarma simple de seguridad para puerta/ventana que se active cuando un imán se aleje del interruptor de lengüeta:

   .. code-block:: python

      # Add a buzzer for audible alarm
      from fusion_hat import Buzzer, PWM
      buzzer = Buzzer(PWM('P0'))

      while True:
          if reed.value() == 1:  # Door opened (magnet moved away)
              buzzer.play('C6', 0.5)  # Sound alarm
              led1.on()  # Red alert LED
          else:
              led2.on()  # Green safe LED
          sleep(0.1)

2. **Contador de Posición**

   Cuenta cuántas veces un imán pasa por el interruptor de lengüeta, útil para la medición de velocidad rotacional:

   .. code-block:: python

      counter = 0
      last_state = 0

      while True:
          current_state = reed.value()
          if last_state == 0 and current_state == 1:  # Detect rising edge
              counter += 1
              print(f"Count: {counter}")
          last_state = current_state
          sleep(0.01)  # Short delay for debouncing

3. **Detección de Dos Sensores**
