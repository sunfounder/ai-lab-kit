2.6 Interruttore Reed
===========================

**Introduzione**

In questo progetto, impareremo come usare un interruttore reed come sensore di campo magnetico per controllare LED. Un interruttore reed è un interruttore elettrico azionato da un campo magnetico applicato, comunemente usato in sistemi di sicurezza, sensori di porta/finestra e rilevamento di posizione. Questo progetto dimostra come rilevare lo stato di un interruttore reed e fornire feedback visivo usando due LED.

**Schema Elettrico**

Il circuito usa un interruttore reed collegato a un pin di ingresso GPIO con un resistore pull-down. Due LED sono collegati a pin di uscita GPIO separati, ciascuno con un resistore limitatore di corrente. Quando un magnete si avvicina all'interruttore reed, chiude il circuito, attivando il cambiamento di stato degli indicatori LED.

.. image:: img/fzz/2.2.4_sch.png

----------------------------------------------

**Schema di Cablaggio**

Segui questi passaggi per costruire il circuito:

1. Collega il pin GND e VCC dell'interruttore reed a GND e 3,3V
2. Collega il pin D0 dell'interruttore reed a GPIO 17
3. Collega il catodo di LED1 a GPIO 22 tramite un resistore da 220Ω
4. Collega l'anodo di LED1 a GND
5. Collega il catodo di LED2 a GPIO 27 tramite un resistore da 220Ω
6. Collega l'anodo di LED2 a GND

Questo script Python crea un sistema di rilevamento del campo magnetico usando un interruttore reed e due LED di stato. Quando eseguito:

1. Lo script monitora continuamente lo stato dell'interruttore reed
2. Quando viene rilevato un magnete (interruttore reed chiuso), LED1 si spegne e LED2 si accende
3. Quando non viene rilevato alcun magnete (interruttore reed aperto), LED1 si accende e LED2 si spegne
4. Questo crea una chiara indicazione visiva della presenza del campo magnetico
5. Il programma può essere interrotto in modo controllato usando ``Ctrl+C``

**Codice**

Il seguente codice Python monitora un interruttore reed e controlla due LED in base al suo stato:

.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat.pin import Pin, Mode, Pull
    from time import sleep  # Import sleep for delay

    # Initialize reed switch (Button) on GPIO pin 17
    reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

    # Initialize LED1 connected to GPIO pin 22
    led1 = Pin(22,mode=Mode.OUT)
    # Initialize LED2 connected to GPIO pin 27
    led2 = Pin(27,mode=Mode.OUT)

    try:
        # Continuously monitor the state of the reed switch and control LEDs accordingly
        while True:
            if reed.value() == 0:  # Check if the reed switch is activated
                led1.off()  # Turn off LED1
                led2.on()   # Turn on LED2
            else:  # If the sensor is not activated
                led1.on()   # Turn on LED1
                led2.off()  # Turn off LED2

    except KeyboardInterrupt:
        # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
        pass

**Comprendere il Codice**

1. **Importazione della Libreria**

   La classe ``Pin`` della libreria ``fusion_hat`` viene usata per controllare i pin GPIO, e ``time.sleep`` viene importato per potenziali operazioni di ritardo.

   .. code-block:: python

        from fusion_hat.pin import Pin, Mode, Pull
        from time import sleep  # Import sleep for delay

2. **Inizializzazione dell'Interruttore Reed**

   L'interruttore reed viene inizializzato sul pin GPIO 17 come ingresso con un resistore pull-down per garantire uno stato LOW stabile quando l'interruttore è aperto.

   .. code-block:: python

        # Initialize reed switch (Button) on GPIO pin 17
        reed = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **Inizializzazione dei LED**

   Due LED vengono inizializzati sui pin GPIO 22 e 27 come uscite per fornire feedback visivo.

   .. code-block:: python

        # Initialize LED1 connected to GPIO pin 22
        led1 = Pin(22,mode=Mode.OUT)
        # Initialize LED2 connected to GPIO pin 27
        led2 = Pin(27,mode=Mode.OUT)

4. **Ciclo Principale di Monitoraggio**

   Il ciclo ``while True`` controlla continuamente lo stato dell'interruttore reed e controlla i LED di conseguenza, creando un sistema di indicazione dello stato chiaro.

   .. code-block:: python

      while True:
          if reed.value() == 0:  # Check if the reed switch is activated
              led1.off()  # Turn off LED1
              led2.on()   # Turn on LED2
          else:  # If the sensor is not activated
              led1.on()   # Turn on LED1
              led2.off()  # Turn off LED2

5. **Gestione dell'Interruzione da Tastiera**

   Il blocco ``try-except`` assicura che il programma si fermi in modo controllato quando viene interrotto.

   .. code-block:: python

      except KeyboardInterrupt:
          # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
          pass

**Risoluzione dei Problemi**

1. **L'Interruttore Reed Non Rileva il Magnete**

   - **Causa**: Problemi di polarità del magnete, forza magnetica insufficiente o problemi di cablaggio.
   - **Soluzione**: Prova a capovolgere il magnete, usa un magnete più forte o verifica tutte le connessioni.

2. **I LED Non si Accendono**

   - **Causa**: Assegnazioni errate dei pin GPIO, polarità del LED invertita o corrente insufficiente.
   - **Soluzione**: Controlla le assegnazioni dei pin, assicurati che i LED siano collegati con la polarità corretta (anodo a GPIO) e verifica i valori dei resistori.

3. **Letture Instabili**

   - **Causa**: Rumore elettrico o ingresso flottante quando l'interruttore reed è aperto.
   - **Soluzione**: Il resistore pull-down integrato dovrebbe stabilizzare l'ingresso, ma assicura una messa a terra corretta e controlla la presenza di fonti vicine di interferenza elettromagnetica.

1. **Sistema di Sicurezza**

   Crea un semplice allarme di sicurezza per porta/finestra che si attiva quando un magnete si allontana dall'interruttore reed:

   .. code-block:: python

      # Add a buzzer for audible alarm
      from fusion_hat import Buzzer, PWM
      buzzer = Buzzer(PWM('P0'))

      while True:
          if reed.value() == 1:  # Door opened (magnet moved away)
              buzzer.play('C6', 0.5)  # Sound alarm
              led1.on()  # Red alert LED
          else:
              led2.on()  # Green safe LED
          sleep(0.1)

2. **Contatore di Posizione**

   Conta quante volte un magnete passa davanti all'interruttore reed, utile per la misurazione della velocità di rotazione:

   .. code-block:: python

      counter = 0
      last_state = 0

      while True:
          current_state = reed.value()
          if last_state == 0 and current_state == 1:  # Detect rising edge
              counter += 1
              print(f"Count: {counter}")
          last_state = current_state
          sleep(0.01)  # Short delay for debouncing
