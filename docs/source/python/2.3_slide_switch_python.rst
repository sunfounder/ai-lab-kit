2.3 滑动开关
=============

**介绍**

在本项目中，我们将学习如何使用滑动开关控制两个LED。滑动开关通常用作电子电路中的电源开关。这里，我们使用面包板设置来演示其功能。虽然滑动开关通常焊接在PCB上以增加稳定性，但我们将以灵活的面包板配置来使用它，以便更好地理解其工作原理。

此Python脚本演示了使用滑动开关控制Fusion HAT+上的两个LED。执行时：

1. **滑动开关激活**：

   - 熄灭LED1（连接到GPIO 22引脚）。
   - 点亮LED2（连接到GPIO 27引脚）。

2. **滑动开关未激活**：

   - 点亮LED1。
   - 熄灭LED2。

3. 程序每0.5秒持续检查滑动开关的状态并相应调整LED。

4. 脚本无限运行，直到按下\ ``Ctrl+C``\ 中断。

**代码**

以下是根据滑动开关状态控制LED的Python代码：


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize slider (Button) on GPIO pin 17
   slider = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the slider and control LEDs accordingly
      while True:
         if slider.value() == 1:  # Check if the slider is pressed
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

**理解代码**

1. **库导入**

   导入GPIO控制和添加延迟所需的库。

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep for delay

2. **组件初始化**

   将滑动开关配置为按钮，并初始化连接到GPIO 22和27引脚的两个LED。

   .. code-block:: python

      # Initialize slider (Button) on GPIO pin 17
      slider = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **状态监测和LED控制**

   在主循环中，程序监测滑动开关的状态。当开关切换时，它在LED1和LED2之间交替点亮。

   .. code-block:: python

      # Continuously monitor the state of the slider and control LEDs accordingly
      while True:
         if slider.value() == 1:  # Check if the slider is pressed
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1

4. **优雅退出**

   脚本在使用\ ``Ctrl+C``\ 中断时优雅地终止。

**故障排除**


1. **滑动开关无响应**

   - **原因**：滑动开关未正确连接，或上拉电阻配置不正确。
   - **解决方案**：确认滑动开关连接到GPIO 17引脚和地。确保\ ``PULL_DOWN``\ 与开关配置匹配。

2. **LED闪烁或行为异常**

   - **原因**：滑动开关的消抖问题。
   - **解决方案**：添加软件消抖以稳定输入信号：

   .. code-block:: python

      if slider.value() == 1:
         sleep(0.05)  # Debounce delay

   .. code-block:: python

         buzzer.on()
      else:
         buzzer.off()
