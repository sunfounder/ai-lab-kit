2.3 Interruttore a Scorrimento
==============================================

**Introduzione**

In questo progetto, impareremo come usare un interruttore a scorrimento per controllare due LED. Gli interruttori a scorrimento sono comunemente usati come interruttori di alimentazione nei circuiti elettronici. Qui ne dimostriamo la funzionalità usando una configurazione su breadboard. Sebbene gli interruttori a scorrimento siano spesso saldati su PCB per stabilità, li useremo in una configurazione flessibile su breadboard per comprenderne meglio il funzionamento.

**Schema Elettrico**

Il pin centrale dell'interruttore a scorrimento è collegato a GPIO17, mentre due LED sono collegati a GPIO22 e GPIO27. L'interruttore alterna tra i due LED, accendendoli alternativamente.

.. image:: img/fzz/2.1.4_sch.png
   :width: 80%
   :align: center




----------------------------------------------

**Schema di Cablaggio**

Segui questi passaggi per costruire il circuito:

1. Collega il pin centrale dell'interruttore a scorrimento a GPIO17.
2. Collega un pin laterale dell'interruttore a scorrimento a GND e l'altro a VCC.
3. Collega l'anodo di LED1 a GPIO22 tramite un resistore limitatore di corrente.
4. Collega l'anodo di LED2 a GPIO27 tramite un resistore limitatore di corrente.
5. Collega i catodi di entrambi i LED a GND.

Questo script Python dimostra l'uso di un interruttore a scorrimento per controllare due LED su Fusion HAT+. Quando eseguito:

1. **Interruttore a Scorrimento Attivato**:

   - Spegne LED1 (collegato al pin GPIO 22).
   - Accende LED2 (collegato al pin GPIO 27).

2. **Interruttore a Scorrimento Non Attivato**:

   - Accende LED1.
   - Spegne LED2.

3. Il programma controlla continuamente lo stato dell'interruttore a scorrimento ogni 0,5 secondi e regola i LED di conseguenza.

4. Lo script viene eseguito indefinitamente fino a quando non viene interrotto premendo ``Ctrl+C``.

**Codice**

Ecco il codice Python per controllare i LED in base allo stato dell'interruttore a scorrimento:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize slider (Button) on GPIO pin 17
   slider = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the slider and control LEDs accordingly
      while True:
         if slider.value() == 1:  # Check if the slider is pressed
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

**Comprendere il Codice**

1. **Importazione delle Librerie**

   Importa le librerie necessarie per il controllo GPIO e l'aggiunta di ritardi.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from time import sleep  # Import sleep for delay

2. **Inizializzazione dei Componenti**

   Configura l'interruttore a scorrimento come pulsante e inizializza due LED collegati ai pin GPIO 22 e 27.

   .. code-block:: python

      # Initialize slider (Button) on GPIO pin 17
      slider = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,mode=Mode.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,mode=Mode.OUT)

3. **Monitoraggio dello Stato e Controllo dei LED**

   Nel ciclo principale, il programma monitora lo stato dell'interruttore a scorrimento. Quando l'interruttore viene azionato, alterna tra l'accensione di LED1 e LED2.

   .. code-block:: python

      # Continuously monitor the state of the slider and control LEDs accordingly

   Lo script termina in modo controllato quando interrotto usando Ctrl+C.

**Risoluzione dei Problemi**


1. **L'Interruttore a Scorrimento Non Risponde**

   - **Causa**: L'interruttore a scorrimento non è collegato correttamente, o la configurazione del resistore pull-up è errata.
   - **Soluzione**: Conferma che l'interruttore a scorrimento sia collegato al pin GPIO 17 e a massa. Assicurati che ``PULL_DOWN`` corrisponda alla configurazione dell'interruttore.


2. **I LED Sfarfallano o si Comportano in Modo Irregolare**

   - **Causa**: Problemi di debounce con l'interruttore a scorrimento.
   - **Soluzione**: Aggiungi debounce software per stabilizzare il segnale di ingresso:

   .. code-block:: python

      if slider.value() == 1:
         sleep(0.05)  # Debounce delay

**Idee Estendibili**

2. **Feedback Audio**

   Aggiungi un buzzer che suona quando l'interruttore a scorrimento viene attivato:

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if slider.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
