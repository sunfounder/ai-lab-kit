2.3 Interruptor Deslizante
==============================================

**Introducción**

En este proyecto, aprenderemos cómo usar un interruptor deslizante para controlar dos LEDs. Los interruptores deslizantes se utilizan comúnmente como interruptores de alimentación en circuitos electrónicos. Aquí, demostramos su funcionalidad usando una configuración con placa de pruebas. Aunque los interruptores deslizantes suelen soldarse en PCBs para mayor estabilidad, los usaremos en una configuración flexible de placa de pruebas para comprender mejor su funcionamiento.

**Diagrama de Conexiones**

Sigue estos pasos para construir el circuito:

1. Conecta el pin central del Interruptor Deslizante a GPIO17.
2. Conecta un pin lateral del Interruptor Deslizante a GND y el otro a VCC.
3. Conecta el ánodo de LED1 a GPIO22 mediante una resistencia limitadora de corriente.
4. Conecta el ánodo de LED2 a GPIO27 mediante una resistencia limitadora de corriente.
5. Conecta los cátodos de ambos LEDs a GND.

Este script de Python demuestra el uso de un interruptor deslizante para controlar dos LEDs en el Fusion HAT+. Cuando se ejecuta:

1. **Interruptor Deslizante Activado**:

   - Apaga LED1 (conectado al pin GPIO 22).
   - Enciende LED2 (conectado al pin GPIO 27).

2. **Interruptor Deslizante No Activado**:

   - Enciende LED1.
   - Apaga LED2.

3. El programa verifica continuamente el estado del interruptor deslizante cada 0.5 segundos y ajusta los LEDs en consecuencia.

4. El script se ejecuta indefinidamente hasta que se interrumpe presionando ``Ctrl+C``.

**Código**

Aquí está el código de Python para controlar los LEDs según el estado del Interruptor Deslizante:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize slider (Button) on GPIO pin 17
   slider = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the slider and control LEDs accordingly
      while True:
         if slider.value() == 1:  # Check if the slider is pressed
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

**Solución de Problemas**


1. **El Interruptor Deslizante No Responde**

   - **Causa**: El interruptor deslizante no está conectado correctamente, o la configuración de la resistencia pull-up es incorrecta.
   - **Solución**: Confirma que el interruptor deslizante esté conectado al pin GPIO 17 y a tierra. Asegúrate de que ``PULL_DOWN`` coincida con la configuración del interruptor.


2. **Los LEDs Parpadean o se Comportan de Forma Errática**

   - **Causa**: Problemas de debounce con el interruptor deslizante.
   - **Solución**: Añade debounce por software para estabilizar la señal de entrada:

   .. code-block:: python

      if slider.value() == 1:
         sleep(0.05)  # Debounce delay
