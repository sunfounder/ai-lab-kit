2.3 Interrupteur a glissiere
=================================

**Introduction**

Dans ce projet, nous allons apprendre a utiliser un interrupteur a glissiere pour controler deux LED. Les interrupteurs a glissiere sont couramment utilises comme interrupteurs d'alimentation dans les circuits electroniques. Ici, nous montrons leur fonctionnement en utilisant une plaque d'essai. Bien que les interrupteurs a glissiere soient souvent soudees sur des PCB pour la stabilite, nous les utiliserons dans une configuration flexible sur plaque d'essai pour mieux comprendre leur fonctionnement.

**Schema de circuit**

La broche centrale de l'interrupteur a glissiere est connectee a GPIO17, tandis que deux LED sont connectees a GPIO22 et GPIO27. L'interrupteur bascule entre les deux LED, les allumant alternativement.

.. image:: img/fzz/2.1.4_sch.png
   :width: 80%
   :align: center




----------------------------------------------

**Schema de cablage**

Suivez ces etapes pour construire le circuit :

1. Connectez la broche centrale de l'interrupteur a glissiere a GPIO17.
2. Connectez une broche laterale de l'interrupteur a GND et l'autre a VCC.
3. Connectez l'anode de LED1 a GPIO22 via une resistance de limitation de courant.
4. Connectez l'anode de LED2 a GPIO27 via une resistance de limitation de courant.
5. Connectez les cathodes des deux LED a GND.

Ce script Python montre l'utilisation d'un interrupteur a glissiere pour controler deux LED sur le Fusion HAT+. Lors de l'execution :

1. **Interrupteur a glissiere active** :

   - Eteint LED1 (connectee a la broche GPIO 22).
   - Allume LED2 (connectee a la broche GPIO 27).

2. **Interrupteur a glissiere non active** :

   - Allume LED1.
   - Eteint LED2.

3. Le programme verifie en continu l'etat de l'interrupteur a glissiere toutes les 0,5 secondes et ajuste les LED en consequence.

4. Le script s'execute indefiniment jusqu'a ce qu'il soit interrompu en appuyant sur ``Ctrl+C``.

**Code**

Voici le code Python pour controler les LED en fonction de l'etat de l'interrupteur a glissiere :


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from time import sleep  # Import sleep for delay

   # Initialize slider (Button) on GPIO pin 17
   slider = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,mode=Mode.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,mode=Mode.OUT)

   try:
      # Continuously monitor the state of the slider and control LEDs accordingly
      while True:
         if slider.value() == 1:  # Check if the slider is pressed
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

2. **Initialisation des composants**

   Configurez l'interrupteur a glissiere comme un bouton et initialisez deux LED connectees aux broches GPIO 22 et 27.

**Depannage**


1. **L'interrupteur a glissiere ne repond pas**

   - **Cause** : L'interrupteur a glissiere n'est pas correctement connectee ou la configuration de la resistance pull-up est incorrecte.
   - **Solution** : Confirmez que l'interrupteur a glissiere est connectee a la broche GPIO 17 et a la masse. Assurez-vous que ``PULL_DOWN`` correspond a la configuration de l'interrupteur.


2. **Les LED scintillent ou se comportent de maniere erratique**

   - **Cause** : Problemes d'anti-rebond avec l'interrupteur a glissiere.
   - **Solution** : Ajoutez un anti-rebond logiciel pour stabiliser le signal d'entree :

   .. code-block:: python

      if slider.value() == 1:
         sleep(0.05)  # Debounce delay

**Idees d'extension**


1. **Controle a deux interrupteurs**

   Combinez deux interrupteurs a glissiere pour controler des LED dans une configuration plus complexe, comme un simple panneau de commande d'eclairage.


2. **Retour sonore**

   Ajoutez un buzzer qui emet un son lorsque l'interrupteur a glissiere est active :

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if slider.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
