1.2.1 Aktiver Summer
=========================================

**Introduction**

In diesem Projekt lernen wir, wie ein aktiver Summer über einen NPN-Transistor angesteuert werden kann, um ein Signalton-Muster zu erzeugen. Aktive Summer sind einfache Bauteile, die in vielen Elektronikprojekten zur Ausgabe von akustischen Signalen verwendet werden.

**Circuit Diagram**

Die Schaltung verwendet einen aktiven Summer, einen NPN-Transistor und einen 1kΩ-Widerstand. Der Widerstand schützt den Transistor, indem er den Basisstrom begrenzt. Gibt GPIO17 ein High-Signal (3,3V) aus, leitet der Transistor und Strom fließt durch den Summer, wodurch dieser ertönt. Bei Low-Pegel wird der Transistor gesperrt und der Summer bleibt stumm.

.. image:: img/fzz/1.2.1_sch.png


----------------------------------------------

**Wiring Diagram**

So bauen Sie die Schaltung auf:

1. Platzieren Sie den NPN-Transistor, den Summer und den Widerstand auf dem Breadboard.  
2. Verbinden Sie die Basis des Transistors über den Widerstand mit GPIO17.  
3. Verbinden Sie den Emitter des Transistors mit der Stromversorgung (+).  
4. Schließen Sie den Kollektor des Transistors an einen Anschluss des Summers an.  
5. Verbinden Sie den anderen Anschluss des Summers mit Masse (-).

**Writing the Code**

Das folgende Python-Skript lässt den aktiven Summer in einer Schleife im Wechsel ein- und ausschalten:


.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat import Buzzer,Pin
    from time import sleep

    # Initialize a Buzzer object on GPIO pin 17
    buzzer = Buzzer(Pin(17))

    try:
        while True:
            # Turn on the buzzer
            print('Buzzer On')
            buzzer.on()
            sleep(0.1)  # Keep the buzzer on for 0.1 seconds

            # Turn off the buzzer
            print('Buzzer Off')
            buzzer.off()
            sleep(0.1)  # Keep the buzzer off for 0.1 seconds

    except KeyboardInterrupt:
        # Handle KeyboardInterrupt (Ctrl+C) for clean script termination
        pass

Dieses Python-Skript steuert einen Summer, der an GPIO-Pin 17 eines Raspberry Pi angeschlossen ist. Beim Ausführen gilt:

1. Der Summer wechselt alle 0,1 Sekunden zwischen Ein- und Ausschalten und erzeugt so einen Piepton.  
2. Gleichzeitig gibt das Programm „Buzzer On“ und „Buzzer Off“ in der Konsole aus.  
3. Der Ton läuft ununterbrochen weiter, bis das Skript mit ``Ctrl+C`` beendet wird.  



----------------------------------------------

**Understanding the Code**

1. **Library Import**

   Die Bibliothek ``fusion_hat`` stellt eine einfache Schnittstelle zur GPIO-Steuerung bereit; ``time`` wird für Verzögerungen verwendet.

   .. code-block:: python

      from fusion_hat import Buzzer,Pin
      from time import sleep

2. **Buzzer Initialization**

   Der Summer wird als Objekt initialisiert und Pin 17 zugewiesen.

   .. code-block:: python

      buzzer = Buzzer(Pin(17))

3. **Control Loop**

   Eine Endlosschleife (``while True``) schaltet den Summer alle 0,1 Sekunden an und aus. Die ``print``-Ausgaben geben den Status in der Konsole wieder.

   .. code-block:: python

      while True:
         print('Buzzer On')
         buzzer.on()
         sleep(0.1)
         print('Buzzer Off')
         buzzer.off()
         sleep(0.1)

4. **Keyboard Interrupt Handling**

   Der ``try-except``-Block ermöglicht ein sauberes Beenden des Programms mit ``Ctrl+C`` ohne Fehlermeldungen.

   .. code-block:: python

      except KeyboardInterrupt:
         pass



----------------------------------------------

**Troubleshooting**

1. **Kein Ton hörbar**  

   - **Ursache**: Falsche Verdrahtung oder fehlerhafte GPIO-Zuordnung.  
   - **Lösung**: Überprüfen Sie die Verbindung des Summers mit GPIO17 und Masse (GND).  

2. **Summer bleibt ständig an oder aus**  

   - **Ursache**: Defekter Summer oder fehlerhafte GPIO-Konfiguration.  
   - **Lösung**: Testen Sie den Summer mit direkter Spannung, um die Funktion zu prüfen.  

3. **Skript reagiert nicht auf KeyboardInterrupt**  

   - **Ursache**: Der ``except``-Block greift nicht korrekt.  
   - **Lösung**: Stellen Sie sicher, dass der ``try...except KeyboardInterrupt``-Block richtig implementiert ist und keine weiteren Prozesse die Hauptschleife blockieren.  

4. **Signalton ist zu schnell oder störend**  

   - **Ursache**: Das Intervall ``sleep(0.1)`` ist zu kurz.  
   - **Lösung**: Erhöhen Sie die ``sleep()``-Dauer, um längere Pausen zwischen den Tönen zu erhalten.  


----------------------------------------------

**Extendable Ideas**

1. **Individuelle Signaltonmuster**  
   Erstellen Sie verschiedene Tonfolgen für bestimmte Ereignisse oder Benachrichtigungen:

   .. code-block:: python

      def beep_pattern():
         buzzer.on()
         sleep(0.3)
         buzzer.off()
         sleep(0.1)
         buzzer.on()
         sleep(0.1)
         buzzer.off()


2. **Benutzereingaben für Summer-Steuerung**  
   Ermöglichen Sie es, den Summer per Eingabe zu steuern:

   .. code-block:: python

      while True:
         command = input("Enter 'on', 'off', or 'pattern': ")
         if command == 'on':
            buzzer.on()
         elif command == 'off':
            buzzer.off()
         elif command == 'pattern':
            beep_pattern()
