2.2.4 Bodenfeuchtigkeitssensor
=====================================


**Einführung**

In diesem Tutorial lernst du, wie man einen Bodenfeuchtigkeitssensor mit einem Raspberry Pi und Python einrichtet und verwendet. Am Ende des Tutorials wirst du verstehen, wie man Feuchtigkeitswerte vom Sensor ausliest und die Daten für Anwendungen wie automatisierte Bewässerung weiterverarbeitet.

**Code schreiben**

Der folgende Python-Code wird in diesem Projekt verwendet:


.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat import ADC
    import time

    # Set up the soil moisture sensor
    moisture = ADC('A1')

    try:
        while True:
            # Get the current reading from the ADC port
            result = moisture.read()
            print('result = %d ' %result)

            # Wait for 1 seconds before reading again
            time.sleep(0.2)

    # Graceful exit when 'Ctrl+C' is pressed
    except KeyboardInterrupt: 
        pass

Dieses Skript initialisiert den Bodenfeuchtigkeitssensor und liest kontinuierlich die Feuchtigkeitswerte aus, die in der Konsole ausgegeben werden.  

Steckst du das Modul in die Erde und gießt Wasser darauf, wird der gemessene Wert kleiner.  

----------------------------------------------


**Code verstehen**

Dieses Skript beginnt mit dem Import der benötigten Module: ``fusion_hat`` für die ADC-Schnittstelle und ``time`` zur Steuerung der Abstände zwischen den Messungen.  

1. **Initialisierung**:  
   Das Objekt ``moisture`` wird als Instanz von ``ADC`` am Port ``'A1'`` erstellt. Dies ist der Anschluss für den Bodenfeuchtigkeitssensor.  

.. code-block:: python

    moisture = ADC('A1')

2. **Kontinuierliche Überwachungsschleife**:  
   Das Skript läuft in einer Endlosschleife, liest den Feuchtigkeitswert mit ``moisture.read()`` aus und speichert ihn in der Variablen ``result``, die anschließend ausgegeben wird.  

.. code-block:: python

    result = moisture.read()
    print('result = %d ' %result)

3. **Zeitsteuerung**:  
   Mit ``time.sleep(0.2)`` pausiert die Schleife 0,2 Sekunden, um einen kontrollierten Ablauf der Messungen zu gewährleisten.  

4. **Sauberer Abbruch**:  
   Der ``try`` - ``except`` -Block fängt eine vom Benutzer ausgelöste Unterbrechung (``Ctrl+C``) ab und beendet das Programm ohne Fehlermeldungen.  

----------------------------------------------

**Fehlerbehebung**

Beim Arbeiten mit Hardware und Sensoren können häufig typische Probleme auftreten. Hier einige Ansätze zur Fehlerbehebung:  

1. **Keine Ausgabe oder instabile Werte**:  
   Überprüfe zuerst alle Verbindungen. Lose oder fehlerhafte Kabelverbindungen zwischen Raspberry Pi Zero und Sensor können zu fehlender oder schwankender Ausgabe führen.  

2. **Konstant Null- oder Maximalwerte**:  

   - Ständige gleiche Werte deuten oft auf einen Defekt am Sensor oder eine falsche Konfiguration am ADC hin. Prüfe, ob der Sensor beschädigt ist und korrekt mit dem ADC-Port verbunden wurde.  

   - Achte auf die korrekte Spannung – der Sensor muss mit 3,3V betrieben werden.  

3. **Probleme beim Abbrechen mit Ctrl+C**:  
   Falls das Skript nicht sauber beendet wird, überprüfe die Ausnahmebehandlung. Stelle sicher, dass ``KeyboardInterrupt`` korrekt im try-except-Block behandelt wird.  

.. code-block:: python

    except KeyboardInterrupt: 
        pass

**Erweiterbare Ideen**

Um dieses Grundprojekt auszubauen, kannst du zusätzliche Funktionen implementieren und es mit anderen Technologien kombinieren. Hier einige Vorschläge:  

1. **Datenaufzeichnung und Visualisierung**:  
   Speichere die Feuchtigkeitswerte regelmäßig in einer Datei oder Datenbank. Diese Daten lassen sich später grafisch darstellen und analysieren.  

   .. code-block:: python

      import csv
      with open('moisture_data.csv', mode='a', newline='') as file:
         writer = csv.writer(file)
         writer.writerow([time.time(), result])

2. **Echtzeit-Benachrichtigungen**:  
   Richte ein System ein, das Warnungen per E-Mail oder SMS sendet, sobald die Bodenfeuchtigkeit unter einen definierten Schwellenwert fällt.  

   .. code-block:: python

      if result < threshold:
         send_alert("Soil moisture is low, consider watering.")

3. **Integration in ein Bewässerungssystem**:  
   Verbinde den Raspberry Pi mit einem Magnetventil oder einer Pumpe, um die Bewässerung automatisch anhand der Messwerte zu steuern.  

   .. code-block:: python

      if result < threshold:
         activate_pump()

4. **Erweiterung mit mehreren Sensoren**:  
   Ergänze weitere Umweltsensoren, z. B. für Temperatur, Luftfeuchtigkeit oder Licht. Damit erhältst du ein umfassenderes System für präzises Garten- oder Landwirtschaftsmanagement.
