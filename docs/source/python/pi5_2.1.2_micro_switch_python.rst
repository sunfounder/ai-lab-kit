2.1.2 Mikroschalter
=====================

**Introduction**

In diesem Projekt lernen wir, wie man einen Mikroschalter zur Steuerung von zwei LEDs einsetzt. Ein Mikroschalter ist ein hochsensibles Bauteil, das nur eine minimale Betätigungskraft benötigt. Er wird häufig in Sicherheitssystemen verwendet, um Maschinen oder Türen unter unsicheren Bedingungen zu blockieren.

**Writing the Code**

Der folgende Python-Code steuert zwei LEDs abhängig vom Zustand des Mikroschalters:


.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat import Pin  
    from time import sleep  # Import sleep function for delays

    # Initialize micro switch on GPIO pin 17
    micro_switch = Pin(17, Pin.IN, pull = Pin.PULL_DOWN)
    # Initialize LED1 connected to GPIO pin 22
    led1 = Pin(22,Pin.OUT)
    # Initialize LED2 connected to GPIO pin 27
    led2 = Pin(27,Pin.OUT)

    try:
        # Continuously check the state of the micro switch and control LEDs accordingly
        while True:
            if micro_switch.value() == 1:  # If the micro switch is pressed
                led1.high()       # Turn on LED1
                led2.low()      # Turn off LED2
            else:  # If the micro switch is not pressed
                led1.low()      # Turn off LED1
                led2.high()       # Turn on LED2

            sleep(0.5)  # Pause for 0.5 seconds before checking the switch again

    except KeyboardInterrupt:
        # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
        pass

Dieses Python-Skript steuert zwei LEDs über den Zustand eines Mikroschalters am Raspberry Pi. Beim Ausführen gilt:

1. **Mikroschalter gedrückt**:  

   - LED1 (an GPIO22) leuchtet.  
   - LED2 (an GPIO27) ist aus.  

2. **Mikroschalter losgelassen**:  

   - LED1 ist aus.  
   - LED2 leuchtet.  

3. Der Zustand des Mikroschalters wird alle 0,5 Sekunden überprüft, und die LEDs werden entsprechend angepasst.  

4. Das Skript läuft unbegrenzt, bis es mit ``Ctrl+C`` beendet wird.  


----------------------------------------------

**Understanding the Code**

1. **Library Import**

   Die Bibliothek ``fusion_hat`` ermöglicht eine einfache GPIO-Steuerung, während die Bibliothek ``time`` Verzögerungen einfügt.

   .. code-block:: python

      from fusion_hat import Pin  
      from time import sleep  

2. **Component Initialization**

   Der Mikroschalter ist mit GPIO17 und Pull-Down-Widerstand verbunden, die LEDs mit GPIO22 und GPIO27.

   .. code-block:: python

      # Initialize micro switch on GPIO pin 17
      micro_switch = Pin(17, Pin.IN, pull = Pin.PULL_DOWN)
      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,Pin.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,Pin.OUT)

3. **Switch State Handling**

   Der Programmcode prüft in einer Schleife den Zustand des Mikroschalters. Bei Betätigung leuchtet LED1 und LED2 ist aus; beim Loslassen ist es umgekehrt.

   .. code-block:: python

      while True:
         if micro_switch.value() == 1:
            led1.on()
            led2.off()
         else:
            led1.off()
            led2.on()
         sleep(0.5)

4. **Interrupt Handling**

   Mit dem ``try-except``-Block wird sichergestellt, dass das Skript sauber beendet werden kann, wenn es mit Ctrl+C unterbrochen wird.

   .. code-block:: python

      except KeyboardInterrupt:
         pass


----------------------------------------------


**Troubleshooting**

1. **LEDs reagieren nicht**  

   - **Ursache**: Falsche GPIO-Verbindungen oder fehlerhafte Pin-Konfiguration.  
   - **Lösung**: Stellen Sie sicher, dass LED1 an GPIO22, LED2 an GPIO27 angeschlossen ist, beide LEDs Vorwiderstände haben und der Mikroschalter mit GPIO17 verbunden ist.  

2. **Mikroschalter wird nicht erkannt**  

   - **Ursache**: Falsche Konfiguration oder fehlender Pull-up/Pull-down-Widerstand.  
   - **Lösung**: Prüfen Sie, ob ``pull = Pin.PULL_UP`` oder ``pull = Pin.PULL_DOWN`` Ihrer Schalterkonfiguration entspricht.  

3. **LEDs flackern oder verhalten sich unregelmäßig**  

   - **Ursache**: Entprellungsprobleme des Schalters.  
   - **Lösung**: Fügen Sie eine kurze Software-Entprellung ein:  

   .. code-block:: python

      if micro_switch.value() == 1:
         sleep(0.05)  # Debounce delay

**Extendable Ideas**

1. **Verstellbare Verzögerung**  

   Ermöglichen Sie dem Nutzer, die Verzögerung dynamisch anzupassen:  

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      while True:
         sleep(delay)



2. **Akustisches Feedback**  

   Fügen Sie einen Buzzer hinzu, der beim Betätigen oder Loslassen des Schalters ein Signal abgibt:  

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if micro_switch.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
