1.3 Zumbador Activo
=========================================

**Introducción**

En este proyecto, aprenderemos cómo activar un zumbador activo para producir un sonido de pitido utilizando un transistor NPN. Los zumbadores activos son componentes simples utilizados en muchos proyectos electrónicos para generar señales sonoras.

**Diagrama de Circuito**

El circuito utiliza un zumbador activo, un transistor NPN y una resistencia de 1kΩ. La resistencia protege al transistor limitando la corriente de base. Cuando GPIO17 emite un nivel alto (3.3V), el transistor conduce, permitiendo que la corriente fluya a través del zumbador, haciendo que suene. Cuando GPIO17 emite un nivel bajo, el transistor se corta y el zumbador permanece en silencio.

----------------------------------------------

**Diagrama de Conexiones**

Sigue estos pasos para construir el circuito:

1. Coloca el transistor NPN, el zumbador y la resistencia en la placa de prototipado.
2. Conecta la base del transistor a GPIO17 a través de la resistencia.
3. Conecta el emisor del transistor a la alimentación (+).
4. Conecta el colector del transistor a un terminal del zumbador.
5. Conecta el otro terminal del zumbador a tierra (-).

Este script Python controla un zumbador conectado al pin GPIO 17 de una Raspberry Pi. Cuando se ejecuta:

1. El zumbador alterna entre encenderse y apagarse cada 0.1 segundos, produciendo un sonido de pitido.
2. El programa imprime "Buzzer On" y "Buzzer Off" en la consola en sincronía con la operación del zumbador.
3. El zumbido continúa indefinidamente hasta que el usuario interrumpe el script presionando ``Ctrl+C``.


----------------------------------------------

**Código**

El siguiente código Python activa el zumbador activo para que pite en un bucle:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import Buzzer
   from fusion_hat.pin import Pin
   from time import sleep

   # Initialize a Buzzer object on GPIO pin 17
   buzzer = Buzzer(Pin(17))

   try:
      while True:
         # Turn on the buzzer
         print('Buzzer On')
         buzzer.on()
         sleep(0.1)  # Keep the buzzer on for 0.1 seconds

         # Turn off the buzzer
         print('Buzzer Off')
         buzzer.off()
         sleep(0.1)  # Keep the buzzer off for 0.1 seconds

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) for clean script termination
      pass

Después de ejecutar el script, el zumbador conectado a la Raspberry Pi pitará repetidamente encendiéndose y apagándose cada 0.1 segundos. Al mismo tiempo, la consola mostrará los mensajes "Buzzer On" y "Buzzer Off" que coinciden con el sonido del zumbador. El zumbador seguirá pitando hasta que detengas el programa presionando Ctrl + C.

----------------------------------------------

**Comprender el Código**

1. **Importación de Librerías**

   La librería ``fusion_hat`` proporciona una interfaz fácil de usar para controlar los pines GPIO, y ``time`` se usa para los retrasos.

   .. code-block:: python

      from fusion_hat.modules import Buzzer
      from fusion_hat.pin import Pin
      from time import sleep

2. **Inicialización del Zumbador**

   El objeto ``Buzzer`` se inicializa y se asocia con el Pin 17.

   .. code-block:: python

      buzzer = Buzzer(Pin(17))

3. **Bucle de Control**

   El programa utiliza un bucle infinito (``while True``) para alternar el zumbador cada 0.1 segundos, creando un sonido de pitido. Las declaraciones ``print`` proporcionan retroalimentación en la consola.

   .. code-block:: python

      while True:
         print('Buzzer On')
         buzzer.on()
         sleep(0.1)
         print('Buzzer Off')
         buzzer.off()
         sleep(0.1)

4. **Manejo de Interrupción por Teclado**

   El bloque ``try-except`` asegura que el programa pueda terminarse de forma limpia usando Ctrl+C sin generar errores.

   .. code-block:: python

      except KeyboardInterrupt:
         pass



----------------------------------------------

**Solución de Problemas**

1. **El Zumbador No Emite Sonido**

   - **Causa**: Conexión incorrecta del pin GPIO o cableado del zumbador.
   - **Solución**: Asegúrate de que el zumbador esté correctamente conectado al pin GPIO 17 y a tierra (GND).

2. **El Zumbador Siempre Encendido o Apagado**

   - **Causa**: Zumbador defectuoso o problema de configuración GPIO.
   - **Solución**: Verifica la funcionalidad del zumbador probándolo con voltaje directo.

3. **El Script No Responde a KeyboardInterrupt**

   - **Causa**: El bloque ``except`` puede no manejar correctamente la interrupción.
   - **Solución**: Asegúrate de que el bloque ``try...except KeyboardInterrupt`` esté correctamente implementado y que ningún otro proceso esté bloqueando el bucle principal.

4. **El Zumbido es Demasiado Rápido o Molesto**

   - **Causa**: El intervalo ``sleep(0.1)`` puede ser demasiado corto.
   - **Solución**: Aumenta la duración de ``sleep()`` para intervalos más largos entre pitidos.


----------------------------------------------

**Ideas para Extender**

1. **Patrones de Pitido Personalizados**
   Crea patrones de pitido distintivos para diferentes eventos o notificaciones:

   .. code-block:: python

      def beep_pattern():
         buzzer.on()
         sleep(0.3)
         buzzer.off()
         sleep(0.1)
         buzzer.on()
         sleep(0.1)
         buzzer.off()


2. **Entrada de Usuario para el Control del Zumbador**
   Permite al usuario iniciar, detener o cambiar el patrón del zumbador dinámicamente:

   .. code-block:: python

      while True:
         command = input("Enter 'on', 'off', or 'pattern': ")
         if command == 'on':
            buzzer.on()
         elif command == 'off':
            buzzer.off()
         elif command == 'pattern':
            beep_pattern()
