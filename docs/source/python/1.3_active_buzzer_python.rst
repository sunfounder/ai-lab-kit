1.3 Buzzer Attivo
=========================================

**Introduzione**

In questo progetto, impareremo come pilotare un buzzer attivo per produrre un suono intermittente usando un transistor NPN. I buzzer attivi sono componenti semplici usati in molti progetti elettronici per produrre segnali sonori.

**Schema Elettrico**

Il circuito utilizza un buzzer attivo, un transistor NPN e un resistore da 1kΩ. Il resistore protegge il transistor limitando la corrente di base. Quando GPIO17 emette un livello alto (3,3V), il transistor conduce, permettendo alla corrente di fluire attraverso il buzzer, facendolo suonare. Quando GPIO17 emette un livello basso, il transistor si interdice e il buzzer rimane silenzioso.

**Schema di Cablaggio**

Segui questi passaggi per costruire il circuito:

1. Posiziona il transistor NPN, il buzzer e il resistore sulla breadboard.
2. Collega la base del transistor a GPIO17 tramite il resistore.
3. Collega l'emettitore del transistor all'alimentazione (+).
4. Collega il collettore del transistor a un terminale del buzzer.
5. Collega l'altro terminale del buzzer a massa (-).

Questo script Python controlla un buzzer collegato al pin GPIO 17 su un Raspberry Pi. Quando eseguito:

1. Il buzzer alterna tra acceso e spento ogni 0,1 secondi, producendo un suono intermittente.
2. Il programma stampa "Buzzer On" e "Buzzer Off" sulla console in sincronia con il funzionamento del buzzer.
3. Il ronzio continua indefinitamente fino a quando l'utente interrompe lo script premendo ``Ctrl+C``.


----------------------------------------------

**Codice**

Il seguente codice Python pilota il buzzer attivo per emettere un suono acceso e spento in un ciclo:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import Buzzer
   from fusion_hat.pin import Pin
   from time import sleep

   # Initialize a Buzzer object on GPIO pin 17
   buzzer = Buzzer(Pin(17))

   try:
      while True:
         # Turn on the buzzer
         print('Buzzer On')
         buzzer.on()
         sleep(0.1)  # Keep the buzzer on for 0.1 seconds

         # Turn off the buzzer
         print('Buzzer Off')
         buzzer.off()
         sleep(0.1)  # Keep the buzzer off for 0.1 seconds

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) for clean script termination
      pass

Dopo aver eseguito lo script, il buzzer collegato al Raspberry Pi emetterà un suono intermittente accendendosi e spegnendosi ogni 0,1 secondi. Allo stesso tempo, la console visualizzerà i messaggi "Buzzer On" e "Buzzer Off" che corrispondono al suono del buzzer. Il buzzer continuerà a suonare fino a quando non si ferma il programma premendo Ctrl + C.

----------------------------------------------

**Comprendere il Codice**

1. **Importazione della Libreria**

   La libreria ``fusion_hat`` fornisce un'interfaccia facile da usare per controllare i pin GPIO, e ``time`` viene usato per i ritardi.

   .. code-block:: python

      from fusion_hat.modules import Buzzer
      from fusion_hat.pin import Pin
      from time import sleep

2. **Inizializzazione del Buzzer**

   L'oggetto ``Buzzer`` viene inizializzato e associato al Pin 17.

   .. code-block:: python

      buzzer = Buzzer(Pin(17))

3. **Ciclo di Controllo**

   Il programma usa un ciclo infinito (``while True``) per attivare e disattivare il buzzer ogni 0,1 secondi, creando un suono intermittente. Le istruzioni ``print`` forniscono un feedback sulla console.

   .. code-block:: python

      while True:
         print('Buzzer On')
         buzzer.on()
         sleep(0.1)
         print('Buzzer Off')
         buzzer.off()
         sleep(0.1)

4. **Gestione dell'Interruzione da Tastiera**

   Il blocco ``try-except`` assicura che il programma possa essere terminato in modo pulito usando Ctrl+C senza generare errori.

   .. code-block:: python

      except KeyboardInterrupt:
         pass



----------------------------------------------

**Risoluzione dei Problemi**

1. **Nessun Suono dal Buzzer**

   - **Causa**: Collegamento errato del pin GPIO o cablaggio del buzzer.
   - **Soluzione**: Assicurati che il buzzer sia correttamente collegato al pin GPIO 17 e a massa (GND).

2. **Buzzer Sempre Acceso o Spento**

   - **Causa**: Buzzer difettoso o problema di configurazione GPIO.
   - **Soluzione**: Verifica la funzionalità del buzzer testandolo con tensione diretta.

3. **Lo Script Non Risponde a KeyboardInterrupt**

   - **Causa**: Il blocco ``except`` potrebbe non gestire correttamente l'interruzione.
   - **Soluzione**: Assicurati che il blocco ``try...except KeyboardInterrupt`` sia implementato correttamente e che nessun altro processo stia bloccando il ciclo principale.

4. **Il Ronzio è Troppo Veloce o Fastidioso**

   - **Causa**: L'intervallo ``sleep(0.1)`` potrebbe essere troppo breve.
   - **Soluzione**: Aumenta la durata di ``sleep()`` per intervalli più lunghi tra i ronzii.

**Idee Estendibili**

1. **Schemi di Beep Personalizzati**
   Crea schemi di beep distinti per diversi eventi o notifiche:

   .. code-block:: python

      def beep_pattern():
         buzzer.on()
         sleep(0.3)
         buzzer.off()
         sleep(0.1)
         buzzer.on()
         sleep(0.1)
         buzzer.off()


2. **Input Utente per il Controllo del Buzzer**
   Permetti all'utente di avviare, fermare o cambiare lo schema del buzzer dinamicamente:

   .. code-block:: python

      while True:
         command = input("Enter 'on', 'off', or 'pattern': ")
         if command == 'on':
            buzzer.on()
         elif command == 'off':
            buzzer.off()
         elif command == 'pattern':
            beep_pattern()
