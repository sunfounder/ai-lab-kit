1.3 有源蜂鸣器
===============

**介绍**

在本项目中，我们将学习如何使用NPN三极管驱动有源蜂鸣器发出蜂鸣声。有源蜂鸣器是简单组件，广泛应用于许多电子项目中以产生声音信号。

**电路图**

该电路使用一个有源蜂鸣器、一个NPN三极管和一个1kΩ电阻。电阻通过限制基极电流来保护三极管。当GPIO17输出高电平（3.3V）时，三极管导通，电流流过蜂鸣器，使其发出蜂鸣声。当GPIO17输出低电平时，三极管截止，蜂鸣器保持静音。

   :width: 80%
   :align: center

**接线图**

请按照以下步骤搭建电路：

1. 将NPN三极管、蜂鸣器和电阻插入面包板。
2. 将三极管的基极通过电阻连接到GPIO17。
3. 将三极管的发射极连接到电源正极（+）。
4. 将三极管的集电极连接到蜂鸣器的一个端子。
5. 将蜂鸣器的另一个端子连接到电源负极（-）。

此Python脚本控制连接到Raspberry Pi的GPIO 17引脚上的蜂鸣器。执行时：

1. 蜂鸣器每0.1秒交替开关，产生蜂鸣声。
2. 程序在控制台上同步打印"Buzzer On"和"Buzzer Off"。
3. 蜂鸣持续不断，直到用户按下\ ``Ctrl+C``\ 中断脚本。

**代码**

以下Python代码驱动有源蜂鸣器在循环中开关蜂鸣：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import Buzzer
   from fusion_hat.pin import Pin
   from time import sleep

   # Initialize a Buzzer object on GPIO pin 17
   buzzer = Buzzer(Pin(17))

   try:
      while True:
         # Turn on the buzzer
         print('Buzzer On')
         buzzer.on()
         sleep(0.1)  # Keep the buzzer on for 0.1 seconds

         # Turn off the buzzer
         print('Buzzer Off')
         buzzer.off()
         sleep(0.1)  # Keep the buzzer off for 0.1 seconds

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) for clean script termination
      pass

运行脚本后，连接到Raspberry Pi的蜂鸣器将通过每0.1秒开和关的方式重复蜂鸣。同时，控制台将显示与蜂鸣器声音匹配的"Buzzer On"和"Buzzer Off"消息。蜂鸣器将持续蜂鸣，直到你按Ctrl + C停止程序。

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库提供了易于使用的GPIO引脚控制接口，\ ``time``\ 用于延迟。

   .. code-block:: python

      from fusion_hat.modules import Buzzer
      from fusion_hat.pin import Pin
      from time import sleep

2. **蜂鸣器初始化**

   ``Buzzer``\ 对象被初始化并与引脚17关联。

   .. code-block:: python

      buzzer = Buzzer(Pin(17))

3. **控制循环**

   程序使用无限循环（\ ``while True``\ ）每0.1秒切换蜂鸣器的开关状态，产生蜂鸣声。\ ``print``\ 语句提供控制台反馈。

   .. code-block:: python

      while True:
         print('Buzzer On')
         buzzer.on()
         sleep(0.1)
         print('Buzzer Off')
         buzzer.off()
         sleep(0.1)

4. **键盘中断处理**

   ``try-except``\ 块确保程序可以使用\ ``Ctrl+C``\ 干净地终止，而不会引发错误。

   .. code-block:: python

      except KeyboardInterrupt:
         pass



----------------------------------------------

**故障排除**

1. **蜂鸣器无声音**

   - **原因**：GPIO引脚连接或蜂鸣器接线错误。
   - **解决方案**：确保蜂鸣器正确连接到GPIO 17引脚和地（GND）。

2. **蜂鸣器常开或常关**

   - **原因**：蜂鸣器故障或GPIO设置问题。
   - **解决方案**：通过直接加电压测试蜂鸣器的功能。

3. **脚本对KeyboardInterrupt无响应**

   - **原因**：\ ``except``\ 块可能未正确处理中断。
   - **解决方案**：确保\ ``try...except KeyboardInterrupt``\ 块正确实现，且没有其他进程阻塞主循环。

4. **蜂鸣声太快或令人不适**

   - **原因**：\ ``sleep(0.1)``\ 间隔可能太短。
   - **解决方案**：增加\ ``sleep()``\ 的持续时间，以延长蜂鸣间隔。

**扩展思路**

1. **自定义蜂鸣模式**
   为不同事件或通知创建独特的蜂鸣模式：

   .. code-block:: python

      def beep_pattern():
         buzzer.on()
         sleep(0.3)
         buzzer.off()
         sleep(0.1)
         buzzer.on()
         sleep(0.1)
         buzzer.off()


2. **用户输入控制蜂鸣器**
   允许用户动态启动、停止或更改蜂鸣器的模式：

   .. code-block:: python

      while True:
         command = input("Enter 'on', 'off', or 'pattern': ")
         if command == 'on':
            buzzer.on()
         elif command == 'off':
            buzzer.off()
         elif command == 'pattern':
            beep_pattern()
