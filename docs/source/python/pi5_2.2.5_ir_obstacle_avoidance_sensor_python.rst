2.2.5 IR-Hinderniserkennungssensor
=====================================

**Einführung**

Der IR-Hinderniserkennungssensor ist ein vielseitiges und effizientes Modul zur Erkennung von Hindernissen auf kurze Distanz. Er arbeitet, indem er Infrarotlicht aussendet und das von Objekten reflektierte Licht erfasst. Dieses Modul wird häufig in Robotik, Automatisierung oder Förderbandsystemen eingesetzt, um Hindernisse zu erkennen, Objekte zu zählen und vieles mehr. In diesem Projekt lernst du, wie du das Modul mit einem Raspberry Pi verbindest und programmatisch auf Hindernisse reagieren kannst.

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin 
   from signal import pause  # Import pause function from signal module

   # Initialize a IR Obstacle Module object on GPIO pin 17
   IR_Obstacle = Pin(17, Pin.IN, pull= Pin.PULL_UP)

   def detect():
      if IR_Obstacle.value() == 1:  # Check if the IR Obstacle Module is activated
         print("Detected Barrier!")
      else:
         print("No Barrier")

   try:
      IR_Obstacle.when_activated = detect  # Set up an interrupt to detect changes in the reed sensor state
      IR_Obstacle.when_deactivated = detect
      
      # Run an event loop that waits for button events and keeps the script running
      print("CTRL + C to exit")
      pause()


   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Code verstehen**

1. **Imports:**


   .. code-block:: python

      from fusion_hat import Pin 
      from signal import pause  # Import pause function from signal module

   Das Skript nutzt ``fusion_hat`` zur Kommunikation mit dem Hindernissensor und ``time`` für das Pausieren im Ereignisloop.  


2. **Sensorinitialisierung:**

   .. code-block:: python

      IR_Obstacle = Pin(17, Pin.IN, pull= Pin.PULL_UP)

   Der Hindernissensor ist an GPIO-Pin 17 mit internem Pull-up-Widerstand angeschlossen, um stabile Signale sicherzustellen.  

3. **Hauptlogik:**

   .. code-block:: python

      def detect():
         if IR_Obstacle.value() == 1:  # Check if the IR Obstacle Module is activated
            print("Detected Barrier!")
         else:
            print("No Barrier")

      try:
         IR_Obstacle.when_activated = detect
         IR_Obstacle.when_deactivated = detect
      
         print("CTRL + C to exit")
         pause()


      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass

   Das Skript überwacht kontinuierlich den Sensorstatus:  

   * Wenn ein Hindernis erkannt wird, erscheint die Meldung „Detected Barrier!“.  
   * Ohne Hindernis wird „No Barrier“ ausgegeben.  

----------------------------------------------



**Fehlerbehebung**

1. **Keine Ausgabe bei vorhandenem Hindernis**:  

   - **Ursache**: Fehlerhafte Verdrahtung.  
   - **Lösung**: Überprüfe, ob der Sensor korrekt mit GPIO-Pin 17, Stromversorgung und Masse verbunden ist. Achte darauf, dass die ``PULL_UP`` -Konfiguration den Sensoreigenschaften entspricht.  

2. **Sensor immer ausgelöst oder nie ausgelöst**:  

   - **Ursache**: Defekter Sensor oder falsche Konfiguration.  
   - **Lösung**: Teste den Sensor mit einem Multimeter und überprüfe, ob er bei Hinderniserkennung seinen Status ändert. Kontrolliere auch die Pull-up-Einstellung.  


----------------------------------------------


**Erweiterbare Ideen**

1. **Visuelles Feedback**: Ergänze eine LED, die bei Hinderniserkennung leuchtet:  

   .. code-block:: python

      from fusion_hat import Pin
      led = Pin(27, Pin.OUT)
      if obstacle_sensor.value() == 1:
         led.on()
      else:
         led.off()

2. **Akustisches Feedback**: Füge einen Buzzer hinzu, der bei Hinderniserkennung einen Ton ausgibt:  

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if obstacle_sensor.value() == 1:
         buzzer.on()
         time.sleep(1)
         buzzer.off()

3. **Datenaufzeichnung**: Protokolliere erkannte Hindernisse in einer Datei:  

   .. code-block:: python

      with open("obstacle_log.txt", "a") as log_file:
         log_file.write(f"Obstacle detected at {time.time():.3f}\n")

**Fazit**

Dieses Projekt zeigt, wie ein IR-Hinderniserkennungssensor mit einem Fusion HAT genutzt werden kann, um Hindernisse zu erfassen. Dieses Grundlagenwissen eröffnet den Weg zu intelligenteren und interaktiveren Projekten.
