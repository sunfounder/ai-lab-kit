1.8 Display de 7 Segmentos de 4 Dígitos
==============================================

**Introducción**

En este proyecto, aprenderemos cómo controlar un display de 7 segmentos de 4 dígitos para crear un contador. El contador se incrementará en 1 cada segundo y el display se actualizará en consecuencia. Este proyecto destaca el uso de pines GPIO y un registro de desplazamiento 74HC595 para gestionar múltiples dígitos de manera eficiente.

**Código**

El código Python a continuación inicializa el display, actualiza el contador y gestiona el bucle de actualización del display:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   import time
   import threading

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17,mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4,mode=Mode.OUT)  # Register Clock
   SRCLK = Pin(27,mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Define segment codes for numbers 0-9 for the 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   counter = 0  # Initialize counter for display
   timer1 = 0   # Initialize timer for counter increment

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift a byte of data to the 74HC595 shift register. """
      for i in range(8):
         SDI.value(0x80 & (data << i))  # Set SDI high/low based on data bit
         SRCLK.high()  # Pulse the Shift Register Clock
         SRCLK.low()
      RCLK.high()  # Latch data on the output by pulsing Register Clock
      RCLK.low()

   def pickDigit(digit):
      """ Select a digit for display on the 7-segment display. """
      for pin in placePin:
         pin.low()  # Turn off all digit selection pins
      placePin[digit].high()  # Turn on the selected digit

   def timer():
      """ Timer function to increment the counter every second. """
      global counter, timer1
      timer1 = threading.Timer(1.0, timer)  # Reset timer for next increment
      timer1.start()
      counter += 1  # Increment counter
      print("%d" % counter)  # Print current counter value

   def setup():
      """ Setup initial state and start the timer. """
      global timer1
      timer1 = threading.Timer(1.0, timer)  # Initialize and start the timer
      timer1.start()

   def loop():
      """ Main loop to update the 7-segment display with counter value. """
      global counter
      while True:
         for i in range(4):  # Loop through each digit
               clearDisplay()  # Clear display before setting new digit
               pickDigit(i)    # Select digit for display

               # Choose the digit of counter to display
               digit = (counter // (10 ** (3-i))) % 10

               hc595_shift(number[digit])  # Shift digit value to 74HC595
               time.sleep(0.001)  # Short delay for display stability

   def destroy():
      """ Cleanup GPIO resources and stop timer on exit. """
      global timer1
      timer1.cancel()  # Stop the timer
      for device in [SDI, RCLK, SRCLK] + placePin:
         device.close()  # Close GPIO devices

   try:
      setup()  # Initialize the setup
      while True:
         loop()  # Start the main loop

   except KeyboardInterrupt:
      # Handle script interruption (e.g., Ctrl+C)
      destroy()  # Cleanup resources on exit




Este script Python controla un display de 7 segmentos de 4 dígitos usando una Raspberry Pi y un registro de desplazamiento 74HC595. Cuando se ejecuta:

1. El display muestra un contador que se incrementa, con los dígitos actualizándose cada segundo.
2. El valor del contador se imprime en la consola para fines de depuración.

El programa se ejecuta indefinidamente, incrementando el contador mostrado hasta que el usuario interrumpe el script presionando ``Ctrl+C``.

**Solución de Problemas**

1. **El Display No Muestra Nada**

   - **Causa**: Cableado incorrecto o configuración de pines GPIO.
   - **Solución**: Verifica las conexiones al registro de desplazamiento 74HC595 y asegúrate de que los pines GPIO (17, 4, 27) coincidan con las variables definidas (``SDI``, ``RCLK``, ``SRCLK``).

2. **Los Dígitos No se Actualizan Correctamente**

   - **Causa**: Problemas de temporización o multiplexación incorrecta.
   - **Solución**: Asegúrate de que ``time.sleep(0.001)`` en la función ``loop()`` sea suficiente para actualizaciones estables del display.

3. **El Contador se Reinicia Inesperadamente**

   - **Causa**: El temporizador ``timer1`` de threading puede no estar funcionando correctamente.
   - **Solución**: Confirma que la función ``setup()`` se ejecute antes del bucle principal ``loop()`` y que el temporizador se inicie correctamente.

4. **KeyboardInterrupt No Funciona**

   - **Causa**: La función ``destroy()`` puede no ejecutarse correctamente al interrumpir.
   - **Solución**: Asegúrate de que todos los dispositivos GPIO se cierren correctamente en ``destroy()`` y que se llame en el bloque ``except KeyboardInterrupt``.

   Modifica el contador para que cuente hacia atrás, se reinicie en un valor específico o muestre patrones específicos.
