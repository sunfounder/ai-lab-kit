1.8 Display a 7 Segmenti a 4 Cifre
====================================

**Introduzione**

In questo progetto, impareremo come controllare un display a 7 segmenti a 4 cifre per creare un contatore. Il contatore incrementerà di 1 ogni secondo e il display si aggiornerà di conseguenza. Questo progetto evidenzia l'uso dei pin GPIO e di un registro a scorrimento 74HC595 per gestire più cifre in modo efficiente.

**Schema di Cablaggio**

Segui questi passaggi per assemblare il circuito:

1. Posiziona il display a 7 segmenti a 4 cifre e il registro a scorrimento 74HC595 sulla breadboard.
2. Collega i pin di uscita del 74HC595 ai segmenti del display.
3. Usa i pin Digitali su Fusion HAT+ per l'ingresso dati (SER anche chiamato SDI), il clock del registro a scorrimento (SRCLK) e il clock del latch (RCLK).
4. Aggiungi resistori per limitare la corrente per i segmenti del display.

**Codice**

Il codice Python qui sotto inizializza il display, aggiorna il contatore e gestisce il ciclo di aggiornamento del display:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   import time
   import threading

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17,mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4,mode=Mode.OUT)  # Register Clock
   SRCLK = Pin(27,mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Define segment codes for numbers 0-9 for the 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   counter = 0  # Initialize counter for display
   timer1 = 0   # Initialize timer for counter increment

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift a byte of data to the 74HC595 shift register. """
      for i in range(8):
         SDI.value(0x80 & (data << i))  # Set SDI high/low based on data bit
         SRCLK.high()  # Pulse the Shift Register Clock
         SRCLK.low()
      RCLK.high()  # Latch data on the output by pulsing Register Clock
      RCLK.low()

   def pickDigit(digit):
      """ Select a digit for display on the 7-segment display. """
      for pin in placePin:
         pin.low()  # Turn off all digit selection pins
      placePin[digit].high()  # Turn on the selected digit

   def timer():
      """ Timer function to increment the counter every second. """
      global counter, timer1
      timer1 = threading.Timer(1.0, timer)  # Reset timer for next increment
      timer1.start()
      counter += 1  # Increment counter
      print("%d" % counter)  # Print current counter value

   def setup():
      """ Setup initial state and start the timer. """
      global timer1
      timer1 = threading.Timer(1.0, timer)  # Initialize and start the timer
      timer1.start()

   def loop():
      """ Main loop to update the 7-segment display with counter value. """
      global counter
      while True:
         for i in range(4):  # Loop through each digit
               clearDisplay()  # Clear display before setting new digit
               pickDigit(i)    # Select digit for display

               # Choose the digit of counter to display
               digit = (counter // (10 ** (3-i))) % 10

               hc595_shift(number[digit])  # Shift digit value to 74HC595
               time.sleep(0.001)  # Short delay for display stability

   def destroy():
      """ Cleanup GPIO resources and stop timer on exit. """
      global timer1
      timer1.cancel()  # Stop the timer
      for device in [SDI, RCLK, SRCLK] + placePin:
         device.close()  # Close GPIO devices

   try:
      setup()  # Initialize the setup
      while True:
         loop()  # Start the main loop

   except KeyboardInterrupt:
      # Handle script interruption (e.g., Ctrl+C)
      destroy()  # Cleanup resources on exit




Questo script Python controlla un display a 7 segmenti a 4 cifre usando un Raspberry Pi e un registro a scorrimento 74HC595. Quando eseguito:

1. Il display mostra un contatore crescente, con le cifre che si aggiornano ogni secondo.
2. Il valore del contatore viene stampato sulla console per scopi di debug.

Il programma viene eseguito indefinitamente, incrementando il contatore visualizzato fino a quando l'utente interrompe lo script premendo ``Ctrl+C``.

**Risoluzione dei Problemi**

1. **Il Display Non Mostra Nulla**

   - **Causa**: Cablaggio errato o configurazione errata dei pin GPIO.
   - **Soluzione**: Ricontrolla le connessioni al registro a scorrimento 74HC595 e assicurati che i pin GPIO (17, 4, 27) corrispondano alle variabili definite (``SDI``, ``RCLK``, ``SRCLK``).

2. **Le Cifre Non si Aggiornano Correttamente**

   - **Causa**: Problemi di temporizzazione o multiplexing errato.
   - **Soluzione**: Assicurati che ``time.sleep(0.001)`` nella funzione ``loop()`` sia sufficiente per aggiornamenti stabili del display.

3. **Il Contatore si Azzera Inaspettatamente**

   - **Causa**: Il timer ``timer1`` potrebbe non funzionare correttamente.
   - **Soluzione**: Conferma che la funzione ``setup()`` venga eseguita prima del ``loop()`` principale e che il timer sia avviato correttamente.

4. **KeyboardInterrupt Non Funziona**

   - **Causa**: La funzione ``destroy()`` potrebbe non essere eseguita correttamente all'interruzione.
   - **Soluzione**: Assicurati che tutti i dispositivi GPIO siano chiusi correttamente in ``destroy()`` e che sia chiamata nel blocco ``except KeyboardInterrupt``.
