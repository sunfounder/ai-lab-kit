1.8 Afficheur 7 segments a 4 chiffres
===========================================

**Introduction**

Dans ce projet, nous allons apprendre a controler un afficheur 7 segments a 4 chiffres pour creer un compteur. Le compteur s'incrementera de 1 chaque seconde et l'afficheur se mettra a jour en consequence. Ce projet met en evidence l'utilisation des broches GPIO et d'un registre a decalage 74HC595 pour gerer efficacement plusieurs chiffres.

**Schema de cablage**

Suivez ces etapes pour assembler le circuit :

1. Placez l'afficheur 7 segments a 4 chiffres et le registre a decalage 74HC595 sur la plaque d'essai.
2. Connectez les broches de sortie du 74HC595 aux segments de l'afficheur.
3. Utilisez les broches numeriques du Fusion HAT+ pour l'entree de donnees (SER, aussi appele SDI), l'horloge du registre a decalage (SRCLK) et l'horloge de verrouillage (RCLK).
4. Ajoutez des resistances pour limiter le courant des segments de l'afficheur.

**Code**

Le code Python ci-dessous initialise l'afficheur, met a jour le compteur et gere la boucle de rafraichissement de l'affichage :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode
   import time
   import threading

   # Define GPIO pins for the 74HC595 shift register
   SDI = Pin(17,mode=Mode.OUT)   # Serial Data Input
   RCLK = Pin(4,mode=Mode.OUT)  # Register Clock
   SRCLK = Pin(27,mode=Mode.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,mode=Mode.OUT) for pin in (23, 24, 25, 12)]

   # Define segment codes for numbers 0-9 for the 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   counter = 0  # Initialize counter for display
   timer1 = 0   # Initialize timer for counter increment

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift a byte of data to the 74HC595 shift register. """
      for i in range(8):
         SDI.value(0x80 & (data << i))  # Set SDI high/low based on data bit
         SRCLK.high()  # Pulse the Shift Register Clock
         SRCLK.low()
      RCLK.high()  # Latch data on the output by pulsing Register Clock
      RCLK.low()

   def pickDigit(digit):
      """ Select a digit for display on the 7-segment display. """
      for pin in placePin:
         pin.low()  # Turn off all digit selection pins
      placePin[digit].high()  # Turn on the selected digit

   def timer():
      """ Timer function to increment the counter every second. """
      global counter, timer1
      timer1 = threading.Timer(1.0, timer)  # Reset timer for next increment
      timer1.start()
      counter += 1  # Increment counter
      print("%d" % counter)  # Print current counter value

   def setup():
      """ Setup initial state and start the timer. """
      global timer1
      timer1 = threading.Timer(1.0, timer)  # Initialize and start the timer
      timer1.start()

   def loop():
      """ Main loop to update the 7-segment display with counter value. """
      global counter
      while True:
         for i in range(4):  # Loop through each digit
               clearDisplay()  # Clear display before setting new digit
               pickDigit(i)    # Select digit for display

               # Choose the digit of counter to display
               digit = (counter // (10 ** (3-i))) % 10

               hc595_shift(number[digit])  # Shift digit value to 74HC595
               time.sleep(0.001)  # Short delay for display stability

   def destroy():
      """ Cleanup GPIO resources and stop timer on exit. """
      global timer1
      timer1.cancel()  # Stop the timer
      for device in [SDI, RCLK, SRCLK] + placePin:
         device.close()  # Close GPIO devices

   try:
      setup()  # Initialize the setup
      while True:
         loop()  # Start the main loop

   except KeyboardInterrupt:
      # Handle script interruption (e.g., Ctrl+C)
      destroy()  # Cleanup resources on exit




Ce script Python controle un afficheur 7 segments a 4 chiffres en utilisant un Raspberry Pi et un registre a decalage 74HC595. Lors de l'execution :

1. L'afficheur montre un compteur qui s'incremente, les chiffres se mettant a jour chaque seconde.
2. La valeur du compteur est affichee sur la console a des fins de debogage.

Le programme s'execute indefiniment, incrementant le compteur affiche jusqu'a ce que l'utilisateur interrompe le script en appuyant sur ``Ctrl+C``.

**Depannage**

1. **L'afficheur ne montre rien**

   - **Cause** : Cablage incorrect ou configuration de broche GPIO.
   - **Solution** : Revérifiez les connexions au registre a decalage 74HC595 et assurez-vous que les broches GPIO (17, 4, 27) correspondent aux variables definies (``SDI``, ``RCLK``, ``SRCLK``).

2. **Les chiffres ne se mettent pas a jour correctement**

   - **Cause** : Problemes de temporisation ou multiplexage incorrect.
   - **Solution** : Assurez-vous que ``time.sleep(0.001)`` dans la fonction ``loop()`` est suffisant pour des mises a jour stables de l'affichage.

3. **Le compteur se remet a zero de maniere inattendue**

   - **Cause** : Le timer ``timer1`` peut ne pas fonctionner correctement.
   - **Solution** : Confirmez que la fonction ``setup()`` est executee avant la boucle principale ``loop()`` et que le timer est correctement demarre.

4. **KeyboardInterrupt ne fonctionne pas**

   - **Cause** : La fonction ``destroy()`` peut ne pas s'executer correctement lors de l'interruption.
   - **Solution** : Assurez-vous que tous les peripheriques GPIO sont correctement fermes dans ``destroy()`` et qu'elle est appelee dans le bloc ``except KeyboardInterrupt``.

**Idees d'extension**

1. **Comportement personnalise du compteur**

   Modifiez le compteur pour compter a rebours, se remettre a zero a une valeur specifique ou afficher des motifs specifiques.

2. **Affichage multi-mode**

   Ajoutez differents modes d'affichage, tels que :

   - Affichage d'un message statique.
   - Alternance entre le compteur et un message predefini.

3. **Vitesse de comptage variable**

   Permettez a l'utilisateur de modifier dynamiquement la vitesse d'incrementation du compteur :

   .. code-block:: python

      speed = float(input("Enter counter speed in seconds: "))
      timer1 = threading.Timer(speed, timer)

4. **Horloge en temps reel**

   Remplacez le compteur par une horloge en temps reel pour afficher l'heure actuelle :

   .. code-block:: python

      from datetime import datetime
      now = datetime.now()
      counter = now.hour * 100 + now.minute  # Display as HHMM
