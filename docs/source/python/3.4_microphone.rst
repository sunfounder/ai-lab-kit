3.4 Microfono Fusion HAT
==============================

**Introduzione**

Fusion HAT+ include un microfono integrato, che lo rende ideale per applicazioni di input audio come riconoscimento vocale, rilevamento sonoro o registrazione di log in progetti AI/IoT.

Questa guida ti aiuterà a verificare se il microfono è riconosciuto dal sistema e ti mostrerà come eseguire un test di registrazione di base.
