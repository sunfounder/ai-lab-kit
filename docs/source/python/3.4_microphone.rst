3.4 Fusion HAT Mikrofon
==============================

**Einführung**

Das Fusion HAT+ verfügt über ein integriertes Mikrofon und eignet sich daher ideal für Audioeingabe-Anwendungen wie Spracherkennung, Geräuscherkennung oder das Aufzeichnen von Audio-Logs in AI- oder IoT-Projekten.

Diese Anleitung zeigt Ihnen, wie Sie überprüfen können, ob das Mikrofon vom System erkannt wird, und wie Sie einen einfachen Aufnahmetest durchführen.
