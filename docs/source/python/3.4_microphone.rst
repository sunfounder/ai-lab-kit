3.4 Micrófono de Fusion HAT+
==============================

**Introducción**

El Fusion HAT+ incluye un micrófono integrado, lo que lo hace ideal para aplicaciones de entrada de audio como reconocimiento de voz, detección de sonido o grabación de registros en proyectos de IA/IoT.

Esta guía te ayudará a verificar si el micrófono es reconocido por el sistema y te mostrará cómo realizar una prueba básica de grabación.
