3.4 Microphone du Fusion HAT+
====================================

**Introduction**

Le Fusion HAT+ comprend un microphone integre, ce qui le rend ideal pour les applications d’entree audio telles que la reconnaissance vocale, la detection sonore ou l’enregistrement de journaux dans les projets AI/IoT.

Ce guide vous aidera a verifier si le microphone est reconnu par le systeme et vous montrera comment effectuer un test d’enregistrement de base.
