2.1.7 Potentiometer
===================

**Introduction**

Die ADC-Funktion (Analog-Digital-Wandlung) ist essenziell, um analoge Signale in digitale Werte umzusetzen. In diesem Experiment nutzen wir den Fusion HAT zusammen mit einem Potentiometer, um diese Wandlung durchzuführen. Das Potentiometer verändert die Spannung als physikalische Größe, die der ADC anschließend digitalisiert. Zudem zeigen wir, wie sich damit die Helligkeit einer LED steuern lässt.

**Writing the Code**

Nachfolgend der Code für das Experiment:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat import ADC, PWM
   import time

   # Initialize a PWM LED
   led = PWM('P0')

   # Set up the potentiometer
   pot = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):
      """
      Map a value from one range to another.
      :param x: The value to be mapped.
      :param in_min: The lower bound of the value's current range.
      :param in_max: The upper bound of the value's current range.
      :param out_min: The lower bound of the value's target range.
      :param out_max: The upper bound of the value's target range.
      :return: The mapped value.
      """
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = pot.read()
         voltage = pot.read_voltage() # Get the voltage from the ADC port, in Volts (0-3.3V)
         print('result = %d voltage = %.2f' %(result,voltage))

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt: 
      led.pulse_width_percent(0)  # Turn off the LED


Dieses Python-Skript nutzt einen Fusion HAT, um einen analogen Eingang auszulesen und die Helligkeit einer PWM-LED zu steuern. Beim Ausführen gilt:

1. Der Fusion HAT liest kontinuierlich ein analoges Signal und wandelt es in einen digitalen Wert zwischen 0 und 4095 um.
2. Dieser Wert wird auf den Bereich 0 bis 100 abgebildet, der die Helligkeit der LED in Prozent repräsentiert.
3. Die Helligkeit der PWM-LED wird dynamisch anhand des abgebildeten Werts angepasst.
4. Roh-ADC-Wert und Spannung werden in Echtzeit in der Konsole ausgegeben.
5. Das Programm läuft unbegrenzt, bis es mit ``Ctrl+C`` beendet wird; anschließend wird die LED ausgeschaltet.

**Understanding the Code**

1. **Imports:**


   .. code-block:: python

      from fusion_hat import ADC, PWM
      import time

   Das Skript verwendet ``fusion_hat`` für PWM-LED-Steuerung und Analog-Digital-Wandlung sowie ``time`` für Wartezeiten.

2. **Initialization:**


   .. code-block:: python

      # Initialize a PWM LED
      led = PWM('P0')

      # Set up the potentiometer
      pot = ADC('A0')

   Initialisiert werden eine PWM-LED an Pin ``P0`` und ein ADC an Pin ``A0``.

3. **MAP Function:**

   .. code-block:: python

       def MAP(x, in_min, in_max, out_min, out_max):
           return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   Die Funktion ``MAP`` wandelt Werte von einem Bereich in einen anderen um – hier zur Abbildung der ADC-Messwerte auf die LED-Helligkeit.


4. **Main Loop:**


   .. code-block:: python

      try:
         while True:
            # Get the current reading from the ADC port
            result = pot.read()
            voltage = pot.read_voltage()
            print('result = %d voltage = %.2f' %(result,voltage))

            # Map the ADC value to a range suitable for setting LED brightness
            value = MAP(result, 0, 4095, 0, 100)

            # Set the LED brightness
            led.pulse_width_percent(value)

            # Wait for 1 seconds before reading again
            time.sleep(0.2)

      # Graceful exit when 'Ctrl+C' is pressed
      except KeyboardInterrupt: 
         led.pulse_width_percent(0)  # Turn off the LED

   - Liest fortlaufend ADC-Werte ein.
   - Bildet den Bereich 0–4095 auf Helligkeitswerte von 0–100 ab.
   - Passt die LED-Helligkeit an und wartet 0,2 Sekunden bis zum nächsten Durchlauf.

**Troubleshooting**

1. **LED reagiert nicht**  

   - **Ursache**: Falsche Verdrahtung oder GPIO-Konfiguration.  
   - **Lösung**: Stellen Sie sicher, dass die LED an PWM 0 mit geeignetem Vorwiderstand angeschlossen ist.

2. **ADC-Werte sind immer Null**  

   - **Ursache**: Falsche Sensorverdrahtung.  
   - **Lösung**: Überprüfen Sie die Anschlüsse und die Funktion des Eingabesensors.

3. **Probleme bei der Abbildung**  

   - **Ursache**: Unpassende Parameter für ``MAP()``.  
   - **Lösung**: Achten Sie darauf, dass der Eingangsbereich (``in_min``, ``in_max``) dem ADC-Bereich (0–4095) entspricht und der Ausgangsbereich (``out_min``, ``out_max``) für die Helligkeitssteuerung (0–100) geeignet ist.
