**代码**

以下Python代码根据按钮的按下和释放来开关LED：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   # Initialize an LED object on GPIO pin 22
   led = Pin(22,mode=Mode.OUT)
   # Initialize a Button object on GPIO pin 17
   button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # # Link the button's "when_activated" event to the LED's high() method
   button.when_activated = led.high

   # # Link the button's "when_deactivated" event to the LED's low() method
   button.when_deactivated = led.low

   # Run an event loop that waits for button events and keeps the script running
   print("CTRL + C to exit")
   pause()



----------------------------------------------

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库提供了简单的GPIO控制接口，\ ``signal``\ 模块用于保持程序运行。

   .. code-block:: python

      #!/usr/bin/env python3
      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module


2. **组件初始化**

   LED连接到GPIO 22引脚，按钮连接到GPIO 17引脚。

   .. code-block:: python

      # Initialize an LED object on GPIO pin 22
      led = Pin(22,mode=Mode.OUT)
      # Initialize a Button object on GPIO pin 17
      button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **事件处理**

   ``when_activated``\ 和\ ``when_deactivated``\ 事件分别链接到LED的\ ``high()``\ 和\ ``low()``\ 方法。这确保按下按钮时LED点亮，释放按钮时LED熄灭。

   .. code-block:: python

       button.when_activated = led.high
       button.when_deactivated = led.low

4. **事件循环**

   ``pause()``\ 函数保持程序运行，监听按钮按下和释放事件。

   .. code-block:: python

       pause()

----------------------------------------------

**故障排除**

1. **LED不亮**

   - **原因**：GPIO引脚连接或LED接线错误。
   - **解决方案**：确认LED的正极连接到GPIO 22引脚，负极通过电阻连接到地。

2. **按钮按下去无效**

   - **原因**：按钮接线或GPIO引脚配置不正确。
   - **解决方案**：确保按钮正确连接到GPIO 17引脚和地。

3. **LED无论按钮状态如何都保持亮或灭**

   - **原因**：按钮可能未正确触发事件。
   - **解决方案**：通过直接用万用表或简单电路测试按钮的连通性来检查其功能。

**扩展思路**

1. **切换LED状态**

   修改脚本，使每次按下按钮时切换LED状态，而不是直接开关：

   .. code-block:: python

      def toggle():
         if led.value() == 1:
            led.off()
         else:
            led.on()

      button.when_activated = toggle

2. **多个LED**

   用一个按钮控制多个LED，循环切换不同模式：

   .. code-block:: python

      leds = [LED(17), LED(27), LED(22)]
      current_led = 0

      def cycle_leds():
         global current_led
         leds[current_led].off()
         current_led = (current_led + 1) % len(leds)
         leds[current_led].on()

      button.when_activated = cycle_leds

3. **按钮按下持续时间**

   根据按钮按下的时长执行不同操作：

   .. code-block:: python

      from time import time

      press_time = None

      def start_timer():
         global press_time
         press_time = time()

      def check_duration():
         global press_time
         duration = time() - press_time
         if duration < 2:
            led.on()
         else:
            led.off()

      button.when_activated = start_timer
      button.when_deactivated = check_duration

4. **消抖**

   实现软件消抖，以获得更准确的按钮按下检测：

   .. code-block:: python

      from time import time

      press_time = None
      debounce_time = 0.2

      def press():
         global press_time
         press_time = time()

      def debounce():
         global press_time
         current_time = time()
         duration = current_time - press_time
         if duration < debounce_time:
            return
         else:
            led.on()

      button.when_activated = press
      button.when_deactivated = debounce
