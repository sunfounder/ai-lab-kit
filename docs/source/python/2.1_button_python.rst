2.1 Botón
==============

**Introducción**

En este proyecto, aprenderemos cómo usar un botón para controlar un LED. Los botones son dispositivos de entrada fundamentales utilizados en varios proyectos electrónicos para interactuar con circuitos y sistemas.

----------------------------------------------

**Código**

El siguiente código de Python alterna el LED según las presiones y liberaciones del botón:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   # Initialize an LED object on GPIO pin 22
   led = Pin(22,mode=Mode.OUT)
   # Initialize a Button object on GPIO pin 17
   button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # # Link the button's "when_activated" event to the LED's high() method
   button.when_activated = led.high

   # # Link the button's "when_deactivated" event to the LED's low() method
   button.when_deactivated = led.low

   # Run an event loop that waits for button events and keeps the script running
   print("CTRL + C to exit")
   pause()



----------------------------------------------

**Comprender el Código**

1. **Importación de Librerías**

   La librería ``fusion_hat`` proporciona una interfaz simple para el control de GPIO, y el módulo ``signal`` se utiliza para mantener el programa en ejecución.

   .. code-block:: python

      #!/usr/bin/env python3
      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module


2. **Inicialización de Componentes**

   El LED está conectado al pin GPIO 22, y el botón está conectado al pin GPIO 17.

   .. code-block:: python

      # Initialize an LED object on GPIO pin 22
      led = Pin(22,mode=Mode.OUT)
      # Initialize a Button object on GPIO pin 17
      button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **Manejo de Eventos**

   Los eventos ``when_activated`` y ``when_deactivated`` están vinculados a los métodos ``high()`` y ``low()`` del LED, respectivamente. Esto asegura que el LED se encienda cuando se presiona el botón y se apague cuando se suelta.

   .. code-block:: python

       button.when_activated = led.high
       button.when_deactivated = led.low

4. **Bucle de Eventos**

   La función ``pause()`` mantiene el programa en ejecución y escucha eventos de presión y liberación del botón.

   .. code-block:: python

       pause()

----------------------------------------------

**Solución de Problemas**

1. **El LED No Enciende**

   - **Causa**: Conexión incorrecta del pin GPIO o del cableado del LED.
   - **Solución**: Verifica que la pata positiva del LED esté conectada al pin GPIO 22 y su pata negativa a una resistencia que lleve a tierra.

2. **Presionar el Botón No Tiene Efecto**

   - **Causa**: Cableado incorrecto del botón o configuración del pin GPIO.
   - **Solución**: Asegúrate de que el botón esté conectado correctamente al pin GPIO 17 y a tierra.

3. **El LED Permanece Encendido o Apagado Independientemente del Estado del Botón**

   - **Causa**: El botón puede no estar disparando eventos correctamente.
   - **Solución**: Verifica la funcionalidad del botón probando su conectividad directamente con un multímetro o un circuito simple.



----------------------------------------------

**Ideas para Extender**

1. **Alternar Estado del LED**

   Modifica el script para alternar el estado del LED con cada presión del botón en lugar de encenderlo/apagarlo directamente:

   .. code-block:: python

      def toggle():
         if led.value() == 1:
            led.off()
         else:
            led.on()

      button.when_activated = toggle

2. **Múltiples LEDs**

   Controla múltiples LEDs con un solo botón, recorriendo diferentes patrones:

   .. code-block:: python

      leds = [LED(17), LED(27), LED(22)]
      current_led = 0

      def cycle_leds():
         global current_led
         leds[current_led].off()
         current_led = (current_led + 1) % len(leds)
         leds[current_led].on()

      button.when_activated = cycle_leds

3. **Duración de Presión del Botón**

   Añade funcionalidad para realizar diferentes acciones según cuánto tiempo se mantenga presionado el botón:

   .. code-block:: python

      from time import time

      press_time = None

      def start_timer():
         global press_time
         press_time = time()

      def check_duration():
         global press_time
         duration = time() - press_time
         if duration < 2:
            led.on()
         else:
            led.off()

      button.when_activated = start_timer
      button.when_deactivated = check_duration

4. **Debouncing**

   Implementa debouncing por software para una detección más precisa de la presión del botón:

   .. code-block:: python

      from time import time

      press_time = None
      debounce_time = 0.2

      def press():
         global press_time
         press_time = time()

      def debounce():
         global press_time
         current_time = time()
         duration = current_time - press_time
         if duration < debounce_time:
            return
         else:
            led.on()

      button.when_activated = press
      button.when_deactivated = debounce
