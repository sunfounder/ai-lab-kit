**Schema Elettrico**

Utilizzeremo un pulsante normalmente aperto come input per il Raspberry Pi. Quando il pulsante viene premuto, GPIO17 riceverà un segnale di livello alto (3,3V). Il Raspberry Pi rileverà questo segnale e accenderà il LED. Le connessioni del circuito sono mostrate nei diagrammi qui sotto:

**Schema di Cablaggio**

Segui questi passaggi per costruire il circuito:

1. Collega l'anodo (pin lungo) del LED a un pin GPIO (GPIO22) tramite un resistore limitatore di corrente.
2. Collega il catodo (pin corto) del LED a massa (GND).
3. Collega un terminale del pulsante a GPIO17 e l'altro terminale a massa (GND).

Questo script Python dimostra una configurazione interattiva in cui un pulsante controlla un LED. Quando eseguito:

1. Premere il pulsante (collegato al pin GPIO 17) accende il LED (collegato al pin GPIO 22).
2. Rilasciare il pulsante spegne il LED.
3. Il programma viene eseguito indefinitamente, ascoltando gli eventi di pressione e rilascio del pulsante per controllare il LED.

----------------------------------------------

**Codice**

Il seguente codice Python attiva il LED in base alle pressioni e ai rilasci del pulsante:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   # Initialize an LED object on GPIO pin 22
   led = Pin(22,mode=Mode.OUT)
   # Initialize a Button object on GPIO pin 17
   button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # # Link the button's "when_activated" event to the LED's high() method
   button.when_activated = led.high

   # # Link the button's "when_deactivated" event to the LED's low() method
   button.when_deactivated = led.low

   # Run an event loop that waits for button events and keeps the script running
   print("CTRL + C to exit")
   pause()



----------------------------------------------

**Comprendere il Codice**

1. **Importazione della Libreria**

   La libreria ``fusion_hat`` fornisce un'interfaccia semplice per il controllo GPIO, e il modulo ``signal`` viene usato per mantenere il programma in esecuzione.

   .. code-block:: python

      #!/usr/bin/env python3
      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module


2. **Inizializzazione dei Componenti**

   Il LED è collegato al pin GPIO 22 e il pulsante è collegato al pin GPIO 17.

   .. code-block:: python

      # Initialize an LED object on GPIO pin 22
      led = Pin(22,mode=Mode.OUT)
      # Initialize a Button object on GPIO pin 17
      button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **Gestione degli Eventi**

   Gli eventi ``when_activated`` e ``when_deactivated`` sono collegati rispettivamente ai metodi ``high()`` e ``low()`` del LED. Questo assicura che il LED si accenda quando il pulsante viene premuto e si spenga quando il pulsante viene rilasciato.

   .. code-block:: python

       button.when_activated = led.high
       button.when_deactivated = led.low

4. **Ciclo di Eventi**

   La funzione ``pause()`` mantiene il programma in esecuzione e ascolta gli eventi di pressione e rilascio del pulsante.

   .. code-block:: python

       pause()

----------------------------------------------

**Risoluzione dei Problemi**

1. **Il LED Non Si Accende**

   - **Causa**: Collegamento errato del pin GPIO o cablaggio del LED.
   - **Soluzione**: Verifica che la gamba positiva del LED sia collegata al pin GPIO 22 e la sua gamba negativa a un resistore collegato a massa.

2. **La Pressione del Pulsante Non Ha Effetto**

   - **Causa**: Cablaggio errato del pulsante o configurazione errata del pin GPIO.
   - **Soluzione**: Assicurati che il pulsante sia collegato correttamente al pin GPIO 17 e a massa.

3. **Il LED Rimane Accesso o Spento Indipendentemente dallo Stato del Pulsante**

   - **Causa**: Il pulsante potrebbe non attivare correttamente gli eventi.
   - **Soluzione**: Controlla la funzionalità del pulsante testandone direttamente la connettività con un multimetro o un circuito semplice.



----------------------------------------------

**Idee Estendibili**

1. **Attivazione/Disattivazione del LED**

   Modifica lo script per attivare/disattivare lo stato del LED ad ogni pressione del pulsante invece di accenderlo/spegnerlo direttamente:

   .. code-block:: python

      def toggle():
         if led.value() == 1:
            led.off()
         else:
            led.on()

      button.when_activated = toggle

2. **LED Multipli**

   Controlla più LED con un singolo pulsante, ciclando attraverso diversi schemi:

   .. code-block:: python

      leds = [LED(17), LED(27), LED(22)]
      current_led = 0

      def cycle_leds():
         global current_led
         leds[current_led].off()
         current_led = (current_led + 1) % len(leds)
         leds[current_led].on()

      button.when_activated = cycle_leds

3. **Durata della Pressione del Pulsante**

   Aggiungi funzionalità per eseguire azioni diverse in base a quanto tempo il pulsante viene tenuto premuto:

   .. code-block:: python

      from time import time

      press_time = None

      def start_timer():
         global press_time
         press_time = time()

      def check_duration():
         global press_time
         duration = time() - press_time
         if duration < 2:
            led.on()
         else:
            led.off()

      button.when_activated = start_timer
      button.when_deactivated = check_duration

4. **Debouncing**

   Implementa il debouncing software per un rilevamento più accurato della pressione del pulsante:

   .. code-block:: python

      from time import time

      press_time = None
      debounce_time = 0.2

      def press():
         global press_time
         press_time = time()

      def debounce():
         global press_time
         current_time = time()
         duration = current_time - press_time
         if duration < debounce_time:
            return
         else:
            led.on()

      button.when_activated = press
      button.when_deactivated = debounce
