2.1 Bouton
===============

**Introduction**

**Schema de circuit**

Nous utiliserons un bouton normalement ouvert comme entree pour le Raspberry Pi. Lorsque le bouton est presse, GPIO17 recevra un signal de niveau haut (3,3 V). Le Raspberry Pi detectera ce signal et allumera la LED. Les connexions du circuit sont presentees dans les schemas ci-dessous :

**Schema de cablage**

Suivez ces etapes pour construire le circuit :

1. Connectez l'anode (broche longue) de la LED a une broche GPIO (GPIO22) via une resistance de limitation de courant.
2. Connectez la cathode (broche courte) de la LED a la masse (GND).
3. Connectez une borne du bouton a GPIO17 et l'autre borne a la masse (GND).

**Code**

Le code Python suivant active la LED en fonction des pressions et relachements du bouton :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   # Initialize an LED object on GPIO pin 22
   led = Pin(22,mode=Mode.OUT)
   # Initialize a Button object on GPIO pin 17
   button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

   # # Link the button's "when_activated" event to the LED's high() method
   button.when_activated = led.high

   # # Link the button's "when_deactivated" event to the LED's low() method
   button.when_deactivated = led.low

   # Run an event loop that waits for button events and keeps the script running
   print("CTRL + C to exit")
   pause()

**Comprendre le code**

1. **Importation de la bibliotheque**

   La bibliotheque ``fusion_hat`` fournit une interface simple pour le controle GPIO, et le module ``signal`` est utilise pour maintenir le programme en execution.

   .. code-block:: python

      #!/usr/bin/env python3
      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module


2. **Initialisation des composants**

   La LED est connectee a la broche GPIO 22, et le bouton est connecte a la broche GPIO 17.

   .. code-block:: python

      # Initialize an LED object on GPIO pin 22
      led = Pin(22,mode=Mode.OUT)
      # Initialize a Button object on GPIO pin 17
      button = Pin(17, mode=Mode.IN, pull=Pull.DOWN)

3. **Gestion des evenements**

   Les evenements ``when_activated`` et ``when_deactivated`` sont lies aux methodes ``high()`` et ``low()`` de la LED respectivement. Cela garantit que la LED s'allume lorsque le bouton est presse et s'eteint lorsque le bouton est relache.

   .. code-block:: python

       button.when_activated = led.high
       button.when_deactivated = led.low

4. **Boucle d'evenements**

   La fonction ``pause()`` maintient le programme en execution et ecoute les evenements d'appui et de relachement du bouton.

   .. code-block:: python

       pause()

----------------------------------------------

**Depannage**

1. **La LED ne s'allume pas**

   - **Cause** : Connexion de broche GPIO incorrecte ou cablage de la LED.
   - **Solution** : Verifiez que la patte positive de la LED est connectee a la broche GPIO 22 et sa patte negative a une resistance menant a la masse.

2. **L'appui sur le bouton n'a aucun effet**

   - **Cause** : Cablage incorrect du bouton ou configuration de broche GPIO.
   - **Solution** : Assurez-vous que le bouton est correctement connecte a la broche GPIO 17 et a la masse.

3. **La LED reste allumee ou eteinte independamment de l'etat du bouton**

   - **Cause** : Le bouton peut ne pas declencher correctement les evenements.
   - **Solution** : Verifiez le fonctionnement du bouton en testant directement sa connectivite avec un multimetre ou un circuit simple.

**Idees d'extension**

1. **Activer/Desactiver l'etat de la LED**

   Modifiez le script pour basculer l'etat de la LED a chaque pression du bouton au lieu de l'allumer/l'eteindre directement :

   .. code-block:: python

      def toggle():
         if led.value() == 1:
            led.off()
         else:
            led.on()

      button.when_activated = toggle

2. **LED multiples**

   Controlez plusieurs LED avec un seul bouton, en parcourant differents motifs :

   .. code-block:: python

      leds = [LED(17), LED(27), LED(22)]
      current_led = 0

      def cycle_leds():
         global current_led
         leds[current_led].off()
         current_led = (current_led + 1) % len(leds)
         leds[current_led].on()

      button.when_activated = cycle_leds

3. **Duree d'appui du bouton**

   Ajoutez la possibilite d'effectuer differentes actions en fonction de la duree d'appui du bouton :

   .. code-block:: python

      from time import time

      press_time = None

      def start_timer():
         global press_time
         press_time = time()

      def check_duration():
         global press_time
         duration = time() - press_time
         if duration < 2:
            led.on()
         else:
            led.off()

      button.when_activated = start_timer
      button.when_deactivated = check_duration

4. **Anti-rebond**

   Implementez un anti-rebond logiciel pour une detection plus precise des appuis sur le bouton :

   .. code-block:: python

      from time import time

      press_time = None
      debounce_time = 0.2

      def press():
         global press_time
         press_time = time()

      def debounce():
         global press_time
         current_time = time()
         duration = current_time - press_time
         if duration < debounce_time:
            return
         else:
            led.on()

      button.when_activated = press
      button.when_deactivated = debounce
