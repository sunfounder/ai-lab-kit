2.14 DHT-11
================

**Introduzione**

In questa lezione, imparerai come collegare e leggere i dati da un sensore di temperatura e umidità DHT11 usando un Raspberry Pi. Il DHT11 è un sensore digitale affidabile e a basso costo utilizzato in varie applicazioni, come il monitoraggio meteorologico e il controllo ambientale. Questo progetto ti introduce all'interfacciamento con sensori esterni, alla gestione di dati in tempo reale e alla gestione base delle eccezioni in Python. Alla fine, saprai come leggere i valori di temperatura (sia in Celsius che Fahrenheit) e umidità.

Questo script Python legge i dati di temperatura e umidità da un sensore DHT11 collegato a un Fusion HAT+ usando il pin GPIO 17. Quando eseguito:

1. I dati vengono stampati sulla console ogni 1 secondo, fornendo aggiornamenti in tempo reale.
2. Se la lettura dei dati non ha successo, lo script restituisce "time out", indicando un errore nella lettura dei dati.


----------------------------------------------

**Codice**


Qui sotto c'è il codice Python usato per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   # Import the DHT11 temperature & humidity sensor module
   from fusion_hat.modules import DHT11
   # Import sleep function for delays
   from time import sleep

   # Create a DHT11 sensor object on GPIO pin 17
   dht11 = DHT11(pin=17)

   # Loop forever
   while True:
      # Read data from the DHT11 sensor
      result = dht11.read()

      # If data was successfully read, unpack humidity and temperature
      if result:
         humidity, temperature = result

         # Print the humidity and temperature values
         print("humidity: %s %%,  Temperature: %s C" % (humidity, temperature))
      else:
         # Print timeout message if reading failed
         print("time out")

      # Wait 1 second before the next reading
      sleep(1)

**Comprendere il Codice**

1. **Importazione:**

   .. code-block:: python

      # Import the DHT11 temperature & humidity sensor module
      from fusion_hat.modules import DHT11
      # Import sleep function for delays
      from time import sleep

   Queste righe importano i moduli necessari per lo script.

2. **Inizializzazione del Sensore:**

   .. code-block:: python

      dht11 = DHT11(pin=17)

   Questa riga inizializza il sensore DHT11 sul pin GPIO 17.

3. **Lettura dei Dati:**

   .. code-block:: python

      while True:
         result = dht11.read()
         if result:
            humidity, temperature = result
            print ("humidity: %s %%,  Temperature: %s C`" % (humidity, temperature))
         else:
            print("time out")
         sleep(1)

   Il metodo ``read`` invia un segnale di avvio al DHT11.


----------------------------------------------

**Risoluzione dei Problemi**

1. **Nessun Output o Valori Costanti 0,0°C e 0,0%**:

   - **Causa**: Problemi di connessione del sensore.
   - **Soluzione**: Assicurati che il sensore DHT11 sia correttamente collegato al pin GPIO 17, all'alimentazione e a massa.

2. **Lo Script si Arresta con ValueError**:

   - **Causa**: Dati corrotti o incompleti dal sensore.
   - **Soluzione**: Controlla le connessioni stabili e assicurati che il DHT11 funzioni correttamente. Assicurati che la linea dati non sia rumorosa o flottante.

3. **Elevato Utilizzo della CPU**:

   - **Causa**: Polling continuo del pin GPIO senza ritardi.
   - **Soluzione**: Il codice ha già ritardi incorporati (ad es., ``time.sleep(2)``). Assicurati che non vengano rimossi.

4. **Valori di Temperatura o Umidità Errati**:

   - **Causa**: Problema di calibrazione o malfunzionamento del sensore.
   - **Soluzione**: Testa il DHT11 in un ambiente controllato per verificarne la precisione. Sostituisci il sensore se il problema persiste.

5. **Lo Script Non Esce in Modo Controllato**:

   - **Causa**: Lo script manca di una gestione appropriata delle eccezioni per le interruzioni manuali.
   - **Soluzione**: Avvolgi il ciclo principale in un blocco ``try...except KeyboardInterrupt`` per permettere una terminazione pulita.

   .. code-block:: python

      try:
         while True:
               humidity, temperature = dht11.read()
               print(f"{time.time():.3f}  Temperature: {temperature}°C  Humidity: {humidity}%")
               time.sleep(2)
      except KeyboardInterrupt:
         print("Exiting gracefully...")
