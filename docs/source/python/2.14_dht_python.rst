2.14 DHT-11
============

**介绍**

在本课中，你将学习如何使用Raspberry Pi连接并读取DHT11温湿度传感器的数据。DHT11是一款可靠、低成本的数字传感器，用于各种应用，如天气监测和环境控制。本项目向你介绍如何与外部传感器接口、处理实时数据以及Python中的基本异常处理。学习完成后，你将知道如何读取温度（摄氏度和华氏度）和湿度值。

此Python脚本从连接到Fusion HAT+（使用GPIO 17引脚）的DHT11传感器读取温度和湿度数据。执行时：

1. 数据每1秒打印到控制台，提供实时更新。
2. 如果数据读取不成功，脚本输出"time out"，表示数据读取错误。


----------------------------------------------

**代码**


以下是本项目使用的Python代码：


.. raw:: html

   <run></run>

.. code-block:: python

   # Import the DHT11 temperature & humidity sensor module
   from fusion_hat.modules import DHT11
   # Import sleep function for delays
   from time import sleep

   # Create a DHT11 sensor object on GPIO pin 17
   dht11 = DHT11(pin=17)

   # Loop forever
   while True:
      # Read data from the DHT11 sensor
      result = dht11.read()

      # If data was successfully read, unpack humidity and temperature
      if result:
         humidity, temperature = result

         # Print the humidity and temperature values
         print("humidity: %s %%,  Temperature: %s C" % (humidity, temperature))
      else:
         # Print timeout message if reading failed
         print("time out")

      # Wait 1 second before the next reading
      sleep(1)

**理解代码**

1. **导入：**

   .. code-block:: python

      # Import the DHT11 temperature & humidity sensor module
      from fusion_hat.modules import DHT11
      # Import sleep function for delays
      from time import sleep

   这些行导入脚本所需的模块。

2. **传感器初始化：**

   .. code-block:: python

      dht11 = DHT11(pin=17)

   此行在GPIO 17引脚上初始化DHT11传感器。

3. **数据读取：**

   .. code-block:: python

      while True:
         result = dht11.read()
         if result:
            humidity, temperature = result
            print ("humidity: %s %%,  Temperature: %s C`" % (humidity, temperature))
         else:
            print("time out")
         sleep(1)

   ``read``\ 方法向DHT11发送启动信号。

**故障排除**

1. **无输出或恒为0.0°C和0.0%值**：

   - **原因**：传感器连接问题。
   - **解决方案**：确保DHT11传感器正确连接到GPIO 17引脚、电源和地。

2. **脚本崩溃并出现ValueError**：

   - **原因**：来自传感器的数据损坏或不完整。
   - **解决方案**：检查连接是否稳定，确保DHT11功能正常。确保数据线没有噪声或处于浮动状态。

3. **高CPU使用率**：

   - **原因**：持续轮询GPIO引脚而无延迟。
   - **解决方案**：代码已内置延迟（例如\ ``time.sleep(2)``\ ）。确保这些延迟未被移除。

4. **温度或湿度值不正确**：

   - **原因**：校准问题或传感器故障。
   - **解决方案**：在受控环境中测试DHT11以验证精度。如果问题仍然存在，更换传感器。

5. **脚本不能优雅退出**：

   - **原因**：脚本缺少手动中断的适当异常处理。
   - **解决方案**：将主循环包装在\ ``try...except KeyboardInterrupt``\ 块中以允许干净地终止。

   .. code-block:: python

      try:
         while True:
               humidity, temperature = dht11.read()
               print(f"{time.time():.3f}  Temperature: {temperature}°C  Humidity: {humidity}%")
               time.sleep(2)
      except KeyboardInterrupt:
         print("Exiting gracefully...")
