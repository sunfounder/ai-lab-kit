2.14 DHT-11
===============

**Introduction**

Dans cette lecon, vous apprendrez comment connecter et lire les donnees d'un capteur de temperature et d'humidite DHT11 en utilisant un Raspberry Pi. Le DHT11 est un capteur numerique fiable et peu couteux utilise dans diverses applications, telles que la surveillance meteorologique et le controle environnemental. Ce projet vous initie a l'interface avec des capteurs externes, a la gestion des donnees en temps reel et a la gestion de base des exceptions en Python. A la fin, vous saurez lire les valeurs de temperature (en Celsius et Fahrenheit) et d'humidite.

Ce script Python lit les donnees de temperature et d'humidite d'un capteur DHT11 connecte a un Fusion HAT+ en utilisant la broche GPIO 17. Lors de l'execution :

1. Les donnees sont affichees sur la console toutes les 1 seconde, fournissant des mises a jour en temps reel.
2. Si la lecture des donnees n'est pas reussie, le script affiche "time out", indiquant une erreur de lecture des donnees.

**Code**


Voici le code Python utilise pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

   # Import the DHT11 temperature & humidity sensor module
   from fusion_hat.modules import DHT11
   # Import sleep function for delays
   from time import sleep

   # Create a DHT11 sensor object on GPIO pin 17
   dht11 = DHT11(pin=17)

   # Loop forever
   while True:
      # Read data from the DHT11 sensor
      result = dht11.read()

      # If data was successfully read, unpack humidity and temperature
      if result:
         humidity, temperature = result

         # Print the humidity and temperature values
         print("humidity: %s %%,  Temperature: %s C" % (humidity, temperature))
      else:
         # Print timeout message if reading failed
         print("time out")

      # Wait 1 second before the next reading
      sleep(1)

**Comprendre le code**

1. **Importation :**

   .. code-block:: python

      # Import the DHT11 temperature & humidity sensor module
      from fusion_hat.modules import DHT11
      # Import sleep function for delays
      from time import sleep

   Ces lignes importent les modules necessaires pour le script.

2. **Initialisation du capteur :**

   .. code-block:: python

      dht11 = DHT11(pin=17)

   Cette ligne initialise le capteur DHT11 sur la broche GPIO 17.

3. **Lecture des donnees :**

   .. code-block:: python

      while True:
         result = dht11.read()
         if result:
            humidity, temperature = result
            print ("humidity: %s %%,  Temperature: %s C`" % (humidity, temperature))
         else:
            print("time out")
         sleep(1)

   La methode ``read`` envoie un signal de depart au DHT11.


----------------------------------------------

**Depannage**

1. **Aucune sortie ou valeurs constantes a 0,0°C et 0,0%** :

   - **Cause** : Problemes de connexion du capteur.
   - **Solution** : Assurez-vous que le capteur DHT11 est correctement connecte a la broche GPIO 17, a l'alimentation et a la masse.

2. **Le script plante avec une ValueError** :

   - **Cause** : Donnees corrompues ou incompletes du capteur.
   - **Solution** : Verifiez les connexions stables et assurez-vous que le DHT11 fonctionne correctement. Assurez-vous que la ligne de donnees n'est pas bruyante ou flottante.

3. **Utilisation elevee du CPU** :

   - **Cause** : Scrutation continue de la broche GPIO sans pauses.
   - **Solution** : Le code a deja des pauses integrees (par exemple, ``time.sleep(2)``). Assurez-vous qu'elles ne sont pas supprimees.

4. **Valeurs de temperature ou d'humidite incorrectes** :

   - **Cause** : Probleme d'etalonnage ou dysfonctionnement du capteur.
   - **Solution** : Testez le DHT11 dans un environnement controle pour verifier la precision. Remplacez le capteur si le probleme persiste.

5. **Le script ne se termine pas proprement** :

   - **Cause** : Le script manque d'une gestion appropriee des exceptions pour les interruptions manuelles.
   - **Solution** : Encapsulez la boucle principale dans un bloc ``try...except KeyboardInterrupt`` pour permettre une terminaison propre.

   .. code-block:: python

      try:
         while True:
               humidity, temperature = dht11.read()
               print(f"{time.time():.3f}  Temperature: {temperature}°C  Humidity: {humidity}%")
               time.sleep(2)
      except KeyboardInterrupt:
         print("Exiting gracefully...")
