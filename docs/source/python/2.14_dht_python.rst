2.14 DHT-11
================

**Introducción**

En esta lección, aprenderás cómo conectar y leer datos de un sensor de temperatura y humedad DHT11 usando una Raspberry Pi. El DHT11 es un sensor digital confiable y de bajo costo utilizado en diversas aplicaciones, como monitoreo meteorológico y control ambiental. Este proyecto te introduce a la interconexión con sensores externos, el manejo de datos en tiempo real y el manejo básico de excepciones en Python. Al final, sabrás cómo leer la temperatura (tanto en grados Celsius como Fahrenheit) y los valores de humedad.

Este script de Python lee datos de temperatura y humedad de un sensor DHT11 conectado a un Fusion HAT+ usando el pin GPIO 17. Al ejecutarse:

1. Los datos se imprimen en la consola cada 1 segundo, proporcionando actualizaciones en tiempo real.
2. Si la lectura de datos no es exitosa, el script muestra "time out", indicando un error en la lectura de datos.

**Código**


A continuación se muestra el código Python utilizado en este proyecto:


.. raw:: html

   <run></run>

.. code-block:: python

   # Import the DHT11 temperature & humidity sensor module
   from fusion_hat.modules import DHT11
   # Import sleep function for delays
   from time import sleep

   # Create a DHT11 sensor object on GPIO pin 17
   dht11 = DHT11(pin=17)

   # Loop forever
   while True:
      # Read data from the DHT11 sensor
      result = dht11.read()

      # If data was successfully read, unpack humidity and temperature
      if result:
         humidity, temperature = result

         # Print the humidity and temperature values
         print("humidity: %s %%,  Temperature: %s C" % (humidity, temperature))
      else:
         # Print timeout message if reading failed
         print("time out")

      # Wait 1 second before the next reading
      sleep(1)

3. **Lectura de Datos:**

            humidity, temperature = result

         else:
            print("time out")
         sleep(1)

   El método ``read`` envía una señal de inicio al DHT11.

**Solución de Problemas**

1. **Sin salida o valores constantes de 0.0°C y 0.0%**:

   - **Causa**: Problemas de conexión del sensor.
   - **Solución**: Asegúrate de que el sensor DHT11 esté correctamente conectado al pin GPIO 17, alimentación y tierra.

2. **El script falla con ValueError**:

   - **Causa**: Datos corruptos o incompletos del sensor.
   - **Solución**: Verifica las conexiones estables y asegúrate de que el DHT11 funcione correctamente. Asegúrate de que la línea de datos no tenga ruido ni esté flotante.

3. **Alto uso de CPU**:

   - **Causa**: Sondeo continuo del pin GPIO sin retardos.
   - **Solución**: El código ya tiene retardos incorporados (ej., ``time.sleep(2)``). Asegúrate de que no se eliminen.

4. **Valores incorrectos de temperatura o humedad**:

   - **Causa**: Problema de calibración o mal funcionamiento del sensor.
   - **Solución**: Prueba el DHT11 en un entorno controlado para verificar la precisión. Reemplaza el sensor si el problema persiste.

5. **El script no sale de forma segura**:

   - **Causa**: El script carece de un manejo adecuado de excepciones para interrupciones manuales.
   - **Solución**: Envuelve el bucle principal en un bloque ``try...except KeyboardInterrupt`` para permitir una terminación limpia.

   .. code-block:: python

      try:
         while True:
               humidity, temperature = dht11.read()
               print(f"{time.time():.3f}  Temperature: {temperature}°C  Humidity: {humidity}%")
               time.sleep(2)
      except KeyboardInterrupt:
         print("Exiting gracefully...")
