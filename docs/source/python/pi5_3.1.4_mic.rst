3.1.4 Fusion HAT Mikrofon
==============================

**Introduction**

Das Fusion HAT verfügt über ein integriertes Mikrofon und eignet sich damit ideal für Audioeingaben wie Spracherkennung, Geräuscherfassung oder Aufzeichnungsprotokolle in AI-/IoT-Projekten.

Diese Anleitung zeigt dir, wie du überprüfst, ob das Mikrofon vom System erkannt wird, und wie du einen einfachen Aufnahmetest durchführst.

**Prüfen, ob das Mikrofon erkannt wird**


Verwende den folgenden Befehl, um zu prüfen, ob das System das Mikrofon erkannt hat:

.. code-block:: bash

   arecord -l

Damit werden alle verfügbaren Audio- **Capture** -Geräte deines Raspberry Pi aufgelistet. Beispielausgabe:

.. code-block:: text

   **** List of CAPTURE Hardware Devices ****
   card 0: sndrpigooglevoi [snd_rpi_googlevoicehat_soundcar], device 0: Google voiceHAT SoundCard HiFi voicehat-hifi-0 [Google voiceHAT SoundCard HiFi voicehat-hifi-0]
     Subdevices: 1/1
     Subdevice #0: subdevice #0

Wenn unter `card 0` ein Gerät wie `voicehat-hifi` angezeigt wird, ist die Mikrofon-Hardware korrekt erkannt worden.

**Audiomodul aktivieren**


Aus Sicherheitsgründen ist das Audiomodul auf dem Fusion HAT **disabled by default**. Du kannst es aktivieren mit:

.. code-block:: bash

   fusion_hat enable_speaker

.. note::

   Diese Einstellung bleibt aktiv, bis der Raspberry Pi ausgeschaltet wird.  
   Möchtest du das Audiomodul wieder deaktivieren, kannst du entweder neu starten oder folgenden Befehl ausführen:

   .. code-block:: bash

      fusion_hat disable_speaker

**Mikrofon testen**


Sobald das Mikrofon aktiviert ist, kannst du einen einfachen Aufnahmetest durchführen:

1. Eine kurze Audioaufnahme erstellen:

   .. code-block:: bash

      rec -c 1 test.wav

   **Parameter Explanation**:

   - ``rec``: Befehl zur Aufnahme (aus dem `sox`-Paket)
   - ``-c 1``: Aufnahme in Mono (1 Kanal)
   - ``test.wav``: Name der Ausgabedatei

2. Die Aufnahme abspielen:

   .. code-block:: bash

      aplay test.wav

   Wenn du deine Stimme hörst, funktioniert das Mikrofon korrekt.

3. Falls die Aufnahme zu leise ist, kannst du sie mit `sox` verstärken:

   .. code-block:: bash

      sox input.wav output.wav gain 5

   - ``input.wav``: Die Originalaufnahme
   - ``output.wav``: Die verstärkte Version
   - ``gain 5``: Erhöht die Lautstärke um 5 dB (anpassbar nach Bedarf)

**Mikrofonlautstärke anpassen**

Wenn die Aufnahme zu leise oder stumm ist, kannst du den Mikrofonpegel manuell erhöhen:

1. Starte den ALSA-Mixer:

   .. code-block:: bash

      alsamixer

2. Mit ``F6`` die richtige Soundkarte auswählen (z. B. USB oder voiceHAT Audio)

3. Mit den Pfeiltasten den Mikrofonpegel anpassen. Falls das Mikrofon stummgeschaltet ist (`MM` unten angezeigt), mit ``M`` umschalten.

.. tip::

   Falls `rec` oder `sox` nicht installiert sind, kannst du sie nachinstallieren mit:

   .. code-block:: bash

      sudo apt update
      sudo apt install sox

**Troubleshooting**


- **Keine Eingabe erkannt**:

  - Sicherstellen, dass das Mikrofon mit `fusion_hat enable_speaker` aktiviert ist
  - Prüfen, ob `arecord -l` das richtige Gerät anzeigt
  - Alternativ manuell mit `arecord` testen

- **Audio verzerrt oder verrauscht**:

  - Mikrofonverstärkung im `alsamixer` reduzieren
  - Aufnahme in ruhigerer Umgebung durchführen

- **`rec`-Befehl nicht gefunden**:

  - Mit `sudo apt install sox` das `sox`-Paket installieren
