2.1.3 Touch-Schalter-Modul
================================

**Introduction**

In diesem Projekt setzen wir ein Touch-Schalter-Modul ein. Dieses Bauteil ersetzt herkömmliche mechanische Schalter und bietet Vorteile wie präzise Steuerung, hohe Berührungsempfindlichkeit und minimale mechanische Abnutzung. Touch-Schalter kommen häufig in modernen Geräten zum Einsatz, in denen Zuverlässigkeit und einfache Bedienung entscheidend sind.

**Writing the Code**

Der folgende Python-Code steuert zwei LEDs abhängig vom Zustand des Touch-Schalter-Moduls:


.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin  
   from time import sleep  # Import sleep for delay

   # Initialize touch sensor (Button) on GPIO pin 17
   touch_sensor = Pin(17, Pin.IN, pull = Pin.PULL_DOWN) 

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,Pin.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,Pin.OUT)

   try:
      # Continuously monitor the state of the touch sensor and control LEDs accordingly
      while True:
         if touch_sensor.value() == 1:  # Check if the touch sensor is pressed
            print('You touch it!')  # Output message indicating sensor activation
            led1.off()  # Turn off LED1
            led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
            led1.on()   # Turn on LED1
            led2.off()  # Turn off LED2
         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass


Dieses Python-Skript verwendet einen Touch-Sensor, um zwei LEDs an einem Raspberry Pi zu steuern. Beim Ausführen gilt:

1. **Touch-Sensor gedrückt**:

   - „You touch it!“ wird in der Konsole ausgegeben.
   - LED1 (an GPIO22) erlischt.
   - LED2 (an GPIO27) leuchtet.

2. **Touch-Sensor nicht gedrückt**:

   - LED1 leuchtet.
   - LED2 erlischt.

3. Der Zustand des Touch-Sensors wird alle 0,5 Sekunden überprüft und die LEDs entsprechend geschaltet.

4. Das Skript läuft unbegrenzt, bis es mit ``Ctrl+C`` beendet wird.

----------------------------------------------


**Understanding the Code**

1. **Library Import**

   Die Bibliothek ``fusion_hat`` vereinfacht die GPIO-Ansteuerung, ``sleep`` sorgt für Wartezeiten.

   .. code-block:: python

      from fusion_hat import Pin  
      from time import sleep 

2. **Component Initialization**

   Der Touch-Sensor wird als Button an GPIO17 konfiguriert, zwei LEDs sind an GPIO22 bzw. GPIO27 angeschlossen.

   .. code-block:: python

      # Initialize touch sensor (Button) on GPIO pin 17
      touch_sensor = Pin(17, Pin.IN, pull = Pin.PULL_DOWN) 

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,Pin.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,Pin.OUT)

3. **Main Loop**

   Das Programm prüft fortlaufend den Zustand des Touch-Schalters. Bei Berührung geht LED2 an und LED1 aus; andernfalls ist LED1 an und LED2 aus.

   .. code-block:: python

       while True:
           if touch_sensor.value() == 1:
               led1.off()
               led2.on()
           else:
               led1.on()
               led2.off()
           sleep(0.5)

4. **Interrupt Handling**

   Ein ``try-except``-Block stellt sicher, dass das Programm bei ``Ctrl+C`` sauber beendet wird.

   .. code-block:: python

       except KeyboardInterrupt:
           pass

----------------------------------------------

**Troubleshooting**

1. **Keine Reaktion des Touch-Sensors**  

   - **Ursache**: Falsche Verdrahtung oder Pin-Konfiguration.  
   - **Lösung**: Stellen Sie sicher, dass der Sensor mit GPIO17 und GND verbunden ist und dass ``PULL_DOWN`` zur aktiven Logik des Sensors passt.

2. **Sensor meldet stets gedrückt oder nie gedrückt**  

   - **Ursache**: Defekter Sensor oder fehlerhafte Verdrahtung.  
   - **Lösung**: Sensor mit Multimeter prüfen oder austauschen; auf lose bzw. falsche Verbindungen achten.

3. **LEDs flackern oder verhalten sich unregelmäßig**  


   - **Ursache**: Entprellung fehlt.  
   - **Lösung**: Software-Entprellung hinzufügen, um das Eingangssignal zu stabilisieren:

   .. code-block:: python

      if touch_sensor.value() == 1:
         sleep(0.05)  # Debounce delay


----------------------------------------------

**Extendable Ideas**

1. **Erkennung der Berührungsdauer**  

   Ergänzen Sie eine Auswertung, wie lange der Sensor berührt wurde, und passen Sie das LED-Verhalten entsprechend an:

   .. code-block:: python

      from time import time
      start_time = None

      def handle_touch():
         global start_time
         if touch_sensor.value() == 1:
            start_time = time()
         else:
            duration = time() - start_time
            print(f"Sensor was touched for {duration:.2f} seconds")

2. **Anpassbare Verzögerung**  

   Ermöglichen Sie dem Nutzer, die Verzögerung zur Feinabstimmung der Reaktionszeit dynamisch zu ändern:

   .. code-block:: python

      delay = float(input("Enter delay in seconds: "))
      sleep(delay)
