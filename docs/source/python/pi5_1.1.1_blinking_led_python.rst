1.1.1 Blinkende LED
=======================

**Einführung**

Willkommen zu Ihrem ersten Projekt! In diesem Tutorial lernen wir, wie man mithilfe von Python und den GPIO-Pins eine LED zum Blinken bringt. Dieses Projekt bietet einen idealen Einstieg in die Integration von Hard- und Software und zeigt, wie einfacher Code direkt mit realen Bauteilen interagieren kann.

Bevor wir starten, hier eine kurze Erklärung der Grundlagen:

* **Was ist eine LED?**  

  Eine LED (Light Emitting Diode) ist ein kleines elektronisches Bauteil, das aufleuchtet, sobald Strom durch sie fließt. LEDs werden aufgrund ihrer Effizienz und Langlebigkeit in nahezu allen Bereichen der Elektronik eingesetzt.
  
* **Was ist ein GPIO-Pin?**  

  GPIO steht für **General Purpose Input/Output**. Diese Pins ermöglichen es dem Raspberry Pi, mit externen Geräten wie LEDs, Sensoren oder Tastern zu kommunizieren. Jeder Pin kann so programmiert werden, dass er Signale sendet (Output) oder empfängt (Input).

In diesem Tutorial verbinden wir eine LED mit einem GPIO-Pin und schreiben ein Python-Programm, das sie blinken lässt. Los geht’s!

**Erste Schritte: Einrichtung des Raspberry Pi**

Bevor wir mit dem Projekt beginnen, stellen Sie sicher, dass Ihr Raspberry Pi vorbereitet ist:

   Laden Sie Raspberry Pi OS herunter und installieren Sie es auf Ihrer SD-Karte. Verwenden Sie dazu das offizielle Tool `Raspberry Pi Imager <https://www.raspberrypi.org/software/>`_ .

2. **Peripheriegeräte anschließen:**  

   Schließen Sie Monitor, Tastatur und Maus an Ihren Raspberry Pi an. Alternativ können Sie SSH einrichten, um den Raspberry Pi von einem anderen Rechner aus zu steuern.

3. **Fusion HAT verbinden:**  

   Stecken Sie den Fusion HAT auf die GPIO-Pins des Raspberry Pi. Achten Sie auf die korrekte Ausrichtung der Pins.

   :ref:`assemble_hat`

4. **Fusion HAT-Bibliotheken installieren:**  

   Dieser Schritt sollte bereits erfolgt sein, wenn Sie den Code heruntergeladen haben. Siehe :ref:`download_the_lib`

**Schaltplan**

So sollte die Schaltung aussehen:

* **GPIO-Pin 17** ist mit der Anode (langes Bein) der LED verbunden.
* Die Kathode (kurzes Bein) der LED wird mit einem Ende des Widerstands verbunden.
* Das andere Ende des Widerstands wird mit dem **GND**-Pin (Masse) verbunden.

.. image:: img/fzz/1.1.1_sch.png
   :width: 800
   :align: center


**Warum einen Widerstand verwenden?**  

Der Widerstand begrenzt den Stromfluss durch die LED und verhindert, dass sie durchbrennt. Ohne Widerstand könnte die LED zu viel Strom ziehen und sowohl die LED als auch den Raspberry Pi beschädigen.

**Code**

Hier ist das vollständige Python-Skript für dieses Projekt:


.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat import Pin
   from time import sleep

   # Initialize an LED connected to GPIO pin 17 using the Fusion HAT library.
   led = Pin(17,mode=Pin.OUT)

   try:
      # Start an infinite loop to toggle the LED state.
      while True:
         # Turn on the LED and print a message to the console.
         led.high()
         print('...LED ON')

         # Wait for 0.5 seconds with the LED on.
         sleep(0.5)

         # Turn off the LED and print a message to the console.
         led.low()
         print('LED OFF...')

         # Wait for 0.5 seconds with the LED off.
         sleep(1)

   except KeyboardInterrupt:
      # Gracefully handle a keyboard interrupt (Ctrl+C) by breaking the loop.
      # GPIO Zero handles cleanup of GPIO settings automatically on exit.
      pass


Dieses Python-Skript steuert eine LED, die am GPIO-Pin 17 des Raspberry Pi angeschlossen ist. Beim Ausführen blinkt die LED in Intervallen von einer halben Sekunde. Gleichzeitig werden im Terminal die Meldungen „LED ON“ und „LED OFF“ angezeigt. Das Programm läuft endlos, bis es durch ``Ctrl+C`` beendet wird.



----------------------------------------------

**Den Code verstehen**

1. **Importe:**  

   Die Bibliothek ``fusion_hat`` erleichtert die Steuerung von GPIO-Geräten. Mit der ``Pin``-Klasse lassen sich LEDs mit einfachen Methoden wie ``on()`` und ``off()`` ansteuern. Die Funktion ``sleep`` sorgt für Pausen zwischen den Befehlen.

   .. note:: Zur Verwendung von fusion-hat siehe |link_api_fusion_hat|.


2. **Initialisierung:**  

   Die Zeile ``led = Pin(17,mode=Pin.OUT)`` teilt dem Raspberry Pi mit, dass an GPIO-Pin 17 eine LED angeschlossen ist.

3. **Hauptschleife:**  

   In der ``while True``-Schleife wird die LED eingeschaltet (``led.on()``) und ausgeschaltet (``led.off()``), jeweils mit einer Pause von 0,5 Sekunden (``sleep(0.5)``).

4. **Sauberes Beenden:**  

   Der ``try...except``-Block stellt sicher, dass das Programm bei einer Unterbrechung (z. B. durch ``Ctrl+C``) ordentlich beendet wird.



----------------------------------------------


**Fehlerbehebung**

1. **LED leuchtet nicht**  

   - **Ursache**: Falscher GPIO-Pin oder fehlerhafte Verdrahtung.  
   - **Lösung**: Überprüfen Sie, ob die LED korrekt an GPIO-Pin 17 angeschlossen ist und der Widerstand richtig platziert wurde.


2. **KeyboardInterrupt funktioniert nicht**  

   - **Ursache**: Das Programm beendet sich nicht sauber.  
   - **Lösung**: Stellen Sie sicher, dass das Skript in einem Terminal läuft, in dem ``Ctrl+C`` erkannt wird, und nicht als Hintergrundprozess.

3. **GPIO nicht korrekt eingerichtet**  

   - **Ursache**: Die ``fusion_hat``-Bibliothek ist nicht installiert.  
   - **Lösung**: Siehe :ref:`download_the_lib`.

4. **LED flackert oder verhält sich unregelmäßig**  

   - **Ursache**: Instabile Stromversorgung oder schlechte Verbindungen.  
   - **Lösung**: Sorgen Sie für eine stabile Stromquelle und überprüfen Sie die Verdrahtung.
