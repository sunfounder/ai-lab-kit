2.2.1 Photoresistor
===================

**Einführung**

Ein Photoresistor, auch als lichtabhängiger Widerstand (LDR) bekannt, ist ein Bauteil zur Erfassung der Lichtintensität. Sein Widerstand sinkt mit steigender Lichtintensität, weshalb er in Anwendungen wie automatischen Nachtlampen oder Umgebungslicht-Steuerungen eingesetzt wird.  

In diesem Projekt zeigen wir, wie ein Photoresistor mit dem Fusion HAT genutzt wird, um die Helligkeit einer LED abhängig vom Umgebungslicht anzupassen. Das Funktionsprinzip ähnelt dem eines Potentiometers, nur dass hier Licht anstelle einer manuellen Einstellung als Eingang dient.

**Code schreiben**


Der folgende Python-Code wird in diesem Projekt verwendet:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat import ADC, PWM
   import time

   # Initialize a PWM LED on GPIO pin 22
   led = PWM('P0')

   # Set up the potentiometer
   photoresistor = ADC('A0')

   def MAP(x, in_min, in_max, out_min, out_max):
      """
      Map a value from one range to another.
      :param x: The value to be mapped.
      :param in_min: The lower bound of the value's current range.
      :param in_max: The upper bound of the value's current range.
      :param out_min: The lower bound of the value's target range.
      :param out_max: The upper bound of the value's target range.
      :return: The mapped value.
      """
      return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   try:
      while True:
         # Get the current reading from the ADC port
         result = photoresistor.read()
         print('result = %d ' %result)

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   # Graceful exit when 'Ctrl+C' is pressed
   except KeyboardInterrupt: 
      led.pulse_width_percent(0)  # Turn off the LED

Dieses Python-Skript liest kontinuierlich die Werte des Photoresistors, skaliert diese auf einen Bereich zur Steuerung der LED-Helligkeit und passt die Helligkeit entsprechend an. Zudem sorgt es bei Abbruch durch den Benutzer für ein sauberes Abschalten der LED. Beim Ausführen gilt:  

1. Der Fusion HAT liest kontinuierlich Werte vom Photoresistor (0 bis 4095).  
2. Der analoge Wert, der die Lichtintensität repräsentiert, wird in der Konsole ausgegeben.  
3. Der Wert wird in ein PWM-Signal umgerechnet, das die Helligkeit der LED steuert.  
4. Die LED-Helligkeit passt sich dynamisch der Lichtintensität an und aktualisiert sich alle 0,2 Sekunden.  
5. Das Programm läuft unbegrenzt, bis es mit ``Ctrl+C`` beendet wird, wobei die LED automatisch ausgeschaltet wird.  



----------------------------------------------


**Code verstehen**

1. **Imports:**


   .. code-block:: python

      from fusion_hat import ADC, PWM
      import time

   Das Skript importiert die notwendigen Module zur Erfassung analoger Werte und zur Steuerung der LED-Helligkeit.  

2. **Initialisierung:**


   .. code-block:: python

      # Initialize a PWM LED
      led = PWM('P0')

      # Set up the potentiometer
      photoresistor = ADC('A0')

   Die LED am GPIO-Pin P0 wird initialisiert und der Eingang A0 für den Photoresistor vorbereitet.  


3. **Mapping-Funktion:**

   .. code-block:: python

       def MAP(x, in_min, in_max, out_min, out_max):
           return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   Die Funktion ``MAP`` wandelt ADC-Werte (0–4095) in einen für PWM geeigneten Bereich (0–100) um.  



4. **Hauptschleife:**

   .. code-block:: python

      while True:
         # Get the current reading from the ADC port
         result = photoresistor.read()
         print('result = %d ' %result)

         # Map the ADC value to a range suitable for setting LED brightness
         value = MAP(result, 0, 4095, 0, 100)

         # Set the LED brightness
         led.pulse_width_percent(value)

         # Wait for 1 seconds before reading again
         time.sleep(0.2)

   - Liest kontinuierlich die Lichtintensität.  
   - Passt die Helligkeit der LED proportional an.  
   - Enthält eine kurze Pause, um CPU-Last zu verringern und sichtbare Änderungen der LED-Helligkeit zu ermöglichen.  


5. **Sauberer Programmabbruch:**

   .. code-block:: python

      try:
         ...
      except KeyboardInterrupt:
         led.pulse_width_percent(0)  # Turn off the LED

   Stellt sicher, dass die LED beim Abbruch (z. B. mit ``Ctrl+C``) ausgeschaltet wird.  


----------------------------------------------


**Fehlerbehebung**

1. **LED leuchtet nicht**:  

   - **Ursache**: Falscher GPIO-Anschluss oder fehlerhafte Verdrahtung.  
   - **Lösung**: Überprüfe, ob die LED an P0 mit einem Vorwiderstand angeschlossen ist.  

2. **ADC-Werte sind immer Null oder Maximum**:  

   - **Ursache**: Falsche Verdrahtung.  
   - **Lösung**: Prüfe den Anschluss des Photoresistors am ADC-Pin.  

3. **LED-Helligkeit ändert sich nicht**:  

   - **Ursache**: Falsche Skalierung der ADC-Werte.  
   - **Lösung**: Stelle sicher, dass die Mapping-Funktion den Bereich korrekt auf 0–100 abbildet.

----------------------------------------------

**Fazit**

Dieses Experiment zeigt, wie ein Photoresistor mit dem Fusion HAT genutzt werden kann, um die Helligkeit einer LED abhängig von der Umgebungshelligkeit zu steuern. Durch das Verständnis der Analog-Digital-Wandlung und der PWM-Regelung lassen sich auf dieser Basis komplexere lichtgesteuerte Systeme wie automatische Beleuchtung oder smarte Geräte entwickeln.
