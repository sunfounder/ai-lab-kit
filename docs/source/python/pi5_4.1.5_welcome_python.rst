4.1.5 Welcome
==============================

**Introduction**

Ist dir schon einmal aufgefallen, wie sich in Convenience-Stores die automatischen Türen mit einem freundlichen Klingelton öffnen, sobald jemand näherkommt? Dieses Projekt bildet diese Funktion im Kleinformat nach. Mit einem PIR-Sensor, einem Servomotor, einer LED und einem Summer baust du ein miniaturisiertes „automatisches Tür“-System. Bei erkannter Bewegung schaltet das System die LED ein, „öffnet“ die Tür per Servo und spielt über den Summer einen Willkommensklang.

.. code-block:: python

   from fusion_hat import Pin, Servo, Buzzer,PWM
   import time

   # GPIO pin setup for LED, motion sensor (PIR), and buzzer
   ledPin = Pin(17, Pin.OUT)
   pirPin = Pin(22, Pin.IN, Pin.PULL_DOWN)
   buzPin = Buzzer(PWM('P0'))

   # Initialize servo with custom pulse widths
   servoPin = Servo('P4')

   # Musical tune for buzzer, with notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
         ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('C4', 0.2), ('B4', 0.2), (None, 0.2),
         ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
         ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
         ('A4', 0.2), ('G4', 0.2), ('E4', 0.2), 
         ('D4', 0.2), ('E4', 0.2)]

   def setAngle(angle):
      """
      Move the servo to a specified angle.
      :param angle: Angle in degrees (0-180).
      """
      servoPin.angle(angle)       # Set servo position
      time.sleep(0.001)           # Short delay for servo movement

   def doorbell():
      """
      Play a musical tune using the buzzer.
      """
      for note, duration in tune:
         buzPin.play(note,float(duration))       # Play the note
      buzPin.off()               # Stop buzzer after playing the tune

   def closedoor():
      # Turn off LED and move servo to close door
      ledPin.off()
      for i in range(180, -1, -1):
         setAngle(i)             # Move servo from 180 to 0 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait after closing door

   def opendoor():
      # Turn on LED, open door (move servo), play tune, close door
      ledPin.on()
      for i in range(0, 181):
         setAngle(i)             # Move servo from 0 to 180 degrees
         time.sleep(0.001)       # Short delay for smooth movement
      time.sleep(1)               # Wait before playing the tune
      doorbell()                  # Play the doorbell tune
      closedoor()                 # Close the door after the tune

   def loop():
      # Main loop to check for motion and operate door
      while True:
         if pirPin.value()==1:
               opendoor()               # Open door if motion detected
         time.sleep(0.1)              # Short delay in loop

   try:
      loop()
   except KeyboardInterrupt:
      # Clean up GPIO on user interrupt (e.g., Ctrl+C)
      buzPin.off()
      ledPin.off()

Dieses Python-Skript verbindet einen PIR-Bewegungssensor, einen Servomotor, eine LED und einen Summer zu einem automatisierten Begrüßungssystem. Beim Ausführen passiert Folgendes:

1. **Motion Detection**: Ein an GPIO-Pin 22 angeschlossener PIR-Sensor erkennt Bewegung.

2. **Door Automation**: Bei erkannter Bewegung:
     - Der Servomotor (an PWM 4) „öffnet“ die Tür, indem er sich von 0° auf 180° bewegt.
     - Die LED (an GPIO-Pin 17) schaltet sich ein.
     - Über den Summer (an PWM 0) wird ein Willkommensklang abgespielt.
     - Der Servomotor bewegt sich zurück von 180° auf 0° und „schließt“ die Tür.
     - Die LED schaltet sich aus.

3. **Continuous Monitoring**: Das System überwacht kontinuierlich Bewegungen und führt die Sequenz bei jeder Erkennung aus.

4. **Graceful Exit**: Bei ``Ctrl+C`` werden Summer und LED ausgeschaltet und das Skript sauber beendet.

----------------------------------------------

**Understanding the Code**

1. **Motion Detection:** Der PIR-Sensor erkennt Bewegung und triggert das System.

2. **Servo Control:** Der Servomotor öffnet und schließt die Tür mithilfe von Winkeln zwischen 0° und 180°.

3. **Buzzer Melody:** Über den ``Buzzer`` wird eine Willkommensmelodie abgespielt.

4. **Reset:** Nach dem Klingelton schließt das System die Tür, schaltet die LED aus und ist bereit für das nächste Ereignis.



----------------------------------------------


**Troubleshooting**

1. **Bewegung wird nicht erkannt**:

   - **Ursache**: PIR-Sensor falsch verdrahtet oder Umgebungsstörungen.
   - **Lösung**:

     - Prüfen, ob der PIR-Sensor an GPIO-Pin 22, Versorgung und Masse angeschlossen ist.
     - Empfindlichkeit und Verzögerung am Sensor (falls vorhanden) anpassen.

2. **Servo bewegt sich nicht**:

   - **Ursache**: Falsche Servokonfiguration oder Spannungsversorgung.
   - **Lösung**:

     - Sicherstellen, dass der Servo an P4 korrekt angeschlossen und versorgt wird.

3. **Klingelton wird nicht abgespielt**:

   - **Ursache**: Summer falsch konfiguriert oder falsches Melodieformat.
   - **Lösung**:

     - Prüfen, ob der Summer an P0 angeschlossen ist.
     - Verifizieren, dass die ``tune``-Liste gültige Noten-/Dauer-Paare enthält.

4. **LED schaltet nicht ein**:

   - **Ursache**: Fehler in LED-Verdrahtung oder GPIO-Konfiguration.
   - **Lösung**: Prüfen, ob die LED mit geeignetem Vorwiderstand an GPIO-Pin 17 angeschlossen ist.

----------------------------------------------


**Extendable Ideas**

1. **Anpassbarer Klingelton**: Weitere Melodien hinzufügen oder eine Auswahl je nach Ereignis anbieten.

2. **Zeitgesteuerter Betrieb**: Das System zu bestimmten Zeiten deaktivieren (z. B. nachts):

     .. code-block:: python

         from datetime import datetime
         if 8 <= datetime.now().hour < 22:  # Operate only between 8 AM and 10 PM
             opendoor()

3. **Datenlogging**: Bewegungsereignisse mit Zeitstempel in eine Datei schreiben:

     .. code-block:: python

         with open("motion_log.txt", "a") as log_file:
             log_file.write(f"{time.strftime('%Y-%m-%d %H:%M:%S')} - Motion detected\n")

4. **Sprachbegrüßung**: Den Summer durch vorab aufgenommene Sprachansagen über einen Lautsprecher ersetzen.
