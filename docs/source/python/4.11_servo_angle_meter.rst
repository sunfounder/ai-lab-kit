4.11 Misuratore Angolo Servomotore
==================================

**Introduzione**

In questa lezione, costruirai un **Misuratore Angolo Servomotore** -- un indicatore visivo dell'angolo del servo che usa un potenziometro per controllare un servomotore, visualizzando l'angolo corrente su uno schermo OLED.
Il potenziometro fornisce una tensione analogica attraverso l'interfaccia ADC di Fusion HAT+.
Il servo riceve comandi basati su questa lettura e uno schermo OLED 128x64 I2C mostra l'angolo numerico del servo e una barra grafica che si muove dolcemente attraverso il display.

Ruotando il potenziometro, il servo si muove tra circa -90 e +90, e l'OLED si aggiorna in tempo reale.

**Codice**

Ecco lo script Python per il Misuratore Angolo Servomotore:

.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat.adc import ADC
   from fusion_hat.servo import Servo
   from PIL import Image, ImageDraw, ImageFont
   import adafruit_ssd1306
   import board, time

   # ==== OLED setup ====
   WIDTH, HEIGHT = 128, 64
   i2c = board.I2C()
   oled = adafruit_ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c, addr=0x3C)
   oled.fill(0)
   oled.show()

   # Framebuffer for drawing
   image = Image.new("1", (WIDTH, HEIGHT))
   draw = ImageDraw.Draw(image)
   font = ImageFont.load_default()

   def text_size(font, text):
       l, t, r, b = font.getbbox(text)
       return (r - l, b - t)

   # ==== Servo & potentiometer ====
   servo = Servo('P0')   # servo on port P0
   pot   = ADC('A0')     # potentiometer on A0 (0..4095)

   def linear_map(x, in_min, in_max, out_min, out_max):
       """Map x from one range to another."""
       return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

   # ---- bar layout ----
   BAR_TOP     = 40
   BAR_HEIGHT  = 10
   BAR_MARGINX = 6
   BAR_WIDTH   = WIDTH - BAR_MARGINX * 2
   BAR_CENTERX = BAR_MARGINX + BAR_WIDTH // 2

   def draw_bar(angle_deg):
       """Draw a centered horizontal bar and pointer for -90..90 degrees."""
       draw.rectangle((0, 0, WIDTH, HEIGHT), outline=0, fill=0)

       # Title
       title = "Servo Angle"
       tw, th = text_size(font, title)
       draw.text(((WIDTH - tw) // 2, 4), title, font=font, fill=255)

       # Numeric angle
       txt = f"{angle_deg:>4} deg"
       nw, nh = text_size(font, txt)
       draw.text(((WIDTH - nw) // 2, 20), txt, font=font, fill=255)

       # Bar outline
       draw.rectangle(
           (BAR_MARGINX, BAR_TOP, BAR_MARGINX + BAR_WIDTH - 1, BAR_TOP + BAR_HEIGHT),
           outline=255, fill=0
       )

       # Ticks
       for x in (BAR_MARGINX, BAR_CENTERX, BAR_MARGINX + BAR_WIDTH - 1):
           draw.line((x, BAR_TOP - 3, x, BAR_TOP + BAR_HEIGHT + 3), fill=255)

       # Map angle to pixel position
       pos = int(linear_map(angle_deg, -90, 90, BAR_MARGINX, BAR_MARGINX + BAR_WIDTH - 1))

       draw.line((pos, BAR_TOP - 2, pos, BAR_TOP + BAR_HEIGHT + 2), fill=255)

       # Fill direction highlight
       if pos >= BAR_CENTERX:
           draw.rectangle((BAR_CENTERX, BAR_TOP + 1, pos, BAR_TOP + BAR_HEIGHT - 1), fill=255)
       else:
           draw.rectangle((pos, BAR_TOP + 1, BAR_CENTERX, BAR_TOP + BAR_HEIGHT - 1), fill=255)

   try:
       while True:
           raw = pot.read()
           angle = int(linear_map(raw, 0, 4095, -90, 90))

           servo.angle(angle)

           draw_bar(angle)
           oled.image(image)
           oled.show()

           time.sleep(0.05)

   except KeyboardInterrupt:
       servo.angle(0)
       oled.fill(0)
       oled.show()
       print("\nExited.")


----------------------------------------------

**Comprendere il Codice**

1. **Importazioni**

   - ``ADC`` legge i valori analogici dal potenziometro
   - ``Servo`` controlla la rotazione del servomotore
   - ``PIL`` gestisce tutta la grafica OLED
   - ``adafruit_ssd1306`` pilota il display OLED I2C
   - ``board`` fornisce I/O hardware
   - ``time`` controlla la velocit del ciclo

2. **Configurazione OLED**

   Un OLED SSD1306 128x64 viene inizializzato e cancellato.
   Un framebuffer fuori schermo contiene la grafica per ogni fotogramma prima di essere inviato al display.

3. **Servomotore e Potenziometro**

   - Servomotore collegato alla porta ``P0``
   - Potenziometro collegato all'ingresso analogico ``A0``
   - Intervallo ADC: ``0..4095``

4. **Mappatura dei Valori**

   ``linear_map()`` converte la lettura del potenziometro in un angolo del servo nell'intervallo ``-90..90``.

5. **Disegno dell'Interfaccia Utente**

   La funzione ``draw_bar()``:
   * Cancella il display
   * Disegna il titolo
   * Mostra l'angolo numerico
   * Disegna una barra orizzontale e segni di graduazione
   * Disegna un puntatore e un segmento riempito che indica la direzione dell'angolo

6. **Ciclo Principale**

   Lo script ripetutamente:
   * Legge l'ADC
   * Calcola l'angolo del servo
   * Aggiorna il servo
   * Disegna l'interfaccia utente aggiornata
   * Aggiorna l'OLED

7. **Uscita Controllata**

   Ctrl+C:
   - Il servo torna a 0
   - L'OLED viene cancellato


----------------------------------------------

**Risoluzione dei Problemi**

- **L'OLED non mostra nulla**

  - Controlla il cablaggio I2C
  - Verifica che l'indirizzo del dispositivo sia ``0x3C``
  - Assicurati che le librerie richieste siano installate

- **Il servomotore non risponde**

  - Controlla l'alimentazione del servo
  - Conferma che il servo sia collegato a ``P0``
  - Assicurati che il filo del segnale del servo sia corretto

- **Intervallo di movimento errato**

  Regola:

  .. code-block:: python

     angle = int(linear_map(raw, 0, 4095, -90, 90))

- **L'OLED sfarfalla**

  Aumenta il ritardo:

  .. code-block:: python

     time.sleep(0.1)

   Applica facilitazione o filtraggio passa-basso.

   Mostra il valore ADC grezzo insieme all'angolo.

5. **Avvisi**

   Fai lampeggiare il puntatore vicino ai limiti ( 75).
