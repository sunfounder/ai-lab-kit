2.1.8 Keypad
================

**Einführung**

Ein Keypad ist ein rechteckiges Tastenfeld, das üblicherweise zur Eingabe von Zeichen, Zahlen oder Befehlen verwendet wird. In diesem Projekt nutzen wir ein Keypad, um Zeichen einzugeben und die Werte der gedrückten Tasten auf dem Bildschirm anzuzeigen. Dieses Experiment zeigt, wie man ein Keypad mit einem Raspberry Pi verbindet und die Eingaben verarbeitet.

**Code schreiben**

Der folgende Python-Code wird in diesem Projekt verwendet:


.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat import Keypad
   from time import sleep

   try:
      # Configure rows, columns, and keypad layout
      # pin from left to right - 4 17 27 22 23 24 25 12
      rows_pins = [4, 17, 27, 22]
      cols_pins = [23, 24, 25, 12]
      keys = ["1", "2", "3", "A",
               "4", "5", "6", "B",
               "7", "8", "9", "C",
               "*", "0", "#", "D"]

      # Create an instance of the Keypad class
      keypad = Keypad(rows_pins, cols_pins, keys)
      last_key_pressed = []


      # Continuously read the keypad and print newly pressed keys
      while True:
         pressed_keys = keypad.read()
         if pressed_keys and pressed_keys != last_key_pressed:
               print(pressed_keys)  # Print the list of pressed keys
               last_key_pressed = pressed_keys
         sleep(0.1)  # Short delay to reduce CPU load

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit
      pass


Das bereitgestellte Python-Skript implementiert ein 4x4-Keypad mithilfe der GPIO-Pins des Raspberry Pi. Beim Ausführen:

1. **Keypad Initialization**:

   - Das Keypad nutzt die in ``rows_pins`` (Reihen) und ``cols_pins`` (Spalten) definierten GPIO-Pins.  
   - Jede Taste entspricht einem bestimmten Layout in ``keys`` (z. B. "1", "2", "A").  

2. **Key Press Detection**:

   - Das Programm scannt kontinuierlich das Keypad, um gedrückte Tasten zu erkennen.  
   - Sobald eine Taste gedrückt wird, erscheint ihr Wert (z. B. "1", "A") in der Konsole.  

3. **Continuous Monitoring**:

   - Das Skript läuft in einer Schleife und aktualisiert alle 0,1 Sekunden die Liste der gedrückten Tasten.  
   - Das Programm kann mit ``Ctrl+C`` beendet werden.

----------------------------------------------


**Fehlerbehebung**

1. **Keine Ausgabe bei Tastendruck**:

   - **Ursache**: Falsche Verdrahtung des Keypads oder der GPIO-Pins.  
   - **Lösung**: Überprüfe, ob das Keypad entsprechend den ``rows_pins``- und ``cols_pins``-Zuordnungen angeschlossen ist. Achte auf korrekte Masseverbindungen.  

2. **Falsche Tasterkennung**:

   - **Ursache**: Abweichung im Keypad-Layout von der ``keys``-Liste oder falsche Reihen-/Spaltenzuordnung.  
   - **Lösung**: Stelle sicher, dass die ``keys``-Liste dem physischen Layout des Keypads entspricht. Prüfe Reihen- und Spaltenzuordnung sorgfältig.

2. **LED- oder Summer-Feedback**: Visuelles oder akustisches Feedback beim Tastendruck geben:
     
      .. code-block:: python

         from fusion_hat import Pin
         led = Pin(26, Pin.OUT)
         if pressed_keys:
            led.on()
            sleep(0.1)
            led.off()


3. **Ereignisauslösung**: Bestimmte Aktionen abhängig von Tastendrücken starten, z. B. Steuerung von Geräten.  

----------------------------------------------

**Fazit**

Dieses Experiment zeigt, wie ein Keypad mit einem Fusion HAT verbunden und Eingaben in Python verarbeitet werden können. Durch das Verständnis der Reihen-Spalten-Scanmethode lassen sich interaktive Anwendungen wie Zugangskontrollsysteme, Taschenrechner oder individuelle Eingabegeräte entwickeln.
