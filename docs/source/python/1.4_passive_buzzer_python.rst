1.4 Buzzer Passivo
===========================

**Introduzione**

In questo progetto, impareremo come far suonare un buzzer passivo pilotandolo con diverse frequenze. I buzzer passivi, a differenza di quelli attivi, richiedono un segnale esterno per produrre suono.

**Schema Elettrico**

Il circuito utilizza un buzzer passivo, un transistor NPN e un resistore da 1kΩ. Il resistore protegge il transistor dalla corrente eccessiva. Variando la frequenza del pin GPIO collegato al transistor, il buzzer produce suoni diversi, permettendogli di suonare della musica.

.. image:: img/fzz/1.2.2_sch.png


----------------------------------------------

**Schema di Cablaggio**

Segui questi passaggi per costruire il circuito:

1. Collega la base del transistor NPN a PWM0 tramite il resistore.
2. Collega l'emettitore del transistor all'alimentazione (+).
3. Collega il collettore del transistor a un terminale del buzzer passivo.
4. Collega l'altro terminale del buzzer a massa (-).

Dopo aver eseguito lo script, il buzzer passivo suona una breve melodia attraverso PWM 0. Ogni nota viene suonata in sequenza per la sua durata prestabilita, e la nota corrente viene stampata sulla console mentre viene suonata. Quando la melodia termina, il buzzer si ferma automaticamente, con pause silenziose dove la nota è None. Puoi anche fermare il programma in qualsiasi momento premendo Ctrl + C.

**Codice**

Il seguente codice Python genera note musicali usando un buzzer passivo:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import Buzzer
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize a TonalBuzzer connected to PWM 0
   tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

   def play(tune):
      """
      Play a musical tune using the buzzer.
      :param tune: List of tuples (note, duration), where each tuple represents a note and its duration.
      """
      for note, duration in tune:
         print(note)  # Output the current note being played
         tb.play(note,float(duration))  # Play the note on the buzzer
      tb.off()  # Stop playing after the tune is complete

   # Define a musical tune as a sequence of notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('C4', 0.2), ('B4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
      ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
      ('D4', 0.2), ('E4', 0.2)]


      try:
         play(tune)  # Execute the play function to start playing the tune

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt for graceful termination
         pass

Questo script Python suona una melodia usando un buzzer passivo collegato a PWM 0. Quando eseguito:

1. Lo script scorre una sequenza predefinita di note musicali (``tune``), suonando ogni nota per una durata specificata.
2. Le note vengono stampate sulla console mentre vengono suonate, fornendo un riferimento visivo.
3. La melodia si ferma automaticamente una volta che tutte le note sono state suonate. Il buzzer non produce suono durante le pause (quando la nota è ``None``).
4. Il programma può essere interrotto in modo controllato usando ``Ctrl+C``.

**Comprendere il Codice**

1. **Importazione della Libreria**

   La classe ``Buzzer`` della libreria ``fusion_hat`` viene usata per generare toni, e ``time.sleep`` introduce ritardi per le durate delle note.

   .. code-block:: python

       from fusion_hat.modules import Buzzer
       from fusion_hat.pwm import PWM
       from time import sleep

2. **Inizializzazione del Buzzer**

   Il ``Buzzer`` viene associato a PWM0 per la generazione dei toni.

   .. code-block:: python

      # Initialize a TonalBuzzer connected to PWM 0
      tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

3. **Esecuzione delle Note**

   La funzione ``play`` scorre una lista di tuple che rappresentano note musicali e le loro durate. Ogni nota viene suonata per la sua durata specificata, seguita da una breve pausa.

   .. code-block:: python

      def play(tune):
         for note, duration in tune:
            print(note)  # Output the current note being played
            tb.play(note,float(duration))  # Play the note on the buzzer
         tb.off()  # Stop playing after the tune is complete

4. **Definizione della Melodia**

   La variabile ``tune`` contiene una sequenza di note (ad es., 'C#4') e durate (ad es., 0,2 secondi).

   .. code-block:: python

       tune = [
           ('C#4', 0.2), ('D4', 0.2), (None, 0.2),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('C4', 0.2), ('B4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
           ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
           ('D4', 0.2), ('E4', 0.2)
       ]

5. **Gestione dell'Interruzione da Tastiera**

   Il blocco ``try-except`` assicura che il programma si fermi in modo controllato quando viene interrotto (ad es., Ctrl+C).

   .. code-block:: python

       try:
           play(tune)
       except KeyboardInterrupt:
           pass



----------------------------------------------

**Risoluzione dei Problemi**

1. **Nessun Suono dal Buzzer**

   - **Causa**: Collegamento errato del pin GPIO o tipo di buzzer incompatibile.
   - **Soluzione**: Assicurati che il TonalBuzzer sia collegato a PWM 0.

2. **Suono Intermittente o Balbettante**

   - **Causa**: Incoerenze temporali nella funzione ``sleep()``.
   - **Soluzione**: Conferma che le durate nella lista ``tune`` siano calibrate appropriatamente per transizioni fluide.

**Idee Estendibili**

1. **Melodie Personalizzate**

   Permetti all'utente di inserire la propria sequenza di note e durate:

   .. code-block:: python

      user_tune = []
      while True:
         note = input("Enter a note (or 'stop' to finish): ")
         if note.lower() == 'stop':
            break
         duration = float(input("Enter duration for the note: "))
         user_tune.append((note, duration))
      play(user_tune)


2. **Multiple Melodie**

   Aggiungi melodie predefinite e lascia che l'utente scelga quale suonare:

   .. code-block:: python

      tunes = {
         "tune1": [('C4', 0.5), ('D4', 0.5), (None, 0.5)],
         "tune2": [('G4', 0.3), ('A4', 0.3), (None, 0.3)]
      }
      choice = input("Choose a tune (tune1/tune2): ")
      play(tunes[choice])


3. **Interazione in Tempo Reale**

   Usa pulsanti o una tastiera per suonare le note in modo interattivo, trasformando il buzzer in un semplice strumento musicale.

4. **Melodie in Catena**

   Collega automaticamente più melodie insieme per creare un brano più lungo.

5. **Regolazione Dinamica della Velocità**

   Permetti agli utenti di cambiare la velocità di riproduzione dinamicamente modificando le durate delle note:

   .. code-block:: python

      speed_factor = float(input("Enter speed factor (e.g., 1.0 for normal, 0.5 for faster): "))
      adjusted_tune = [(note, duration * speed_factor) for note, duration in tune]
      play(adjusted_tune)
