1.4 Zumbador Pasivo
============================

**Introducción**

En este proyecto, aprenderemos cómo hacer que un zumbador pasivo reproduzca música activándolo con diferentes frecuencias. Los zumbadores pasivos, a diferencia de los activos, requieren una señal externa para producir sonido.

**Diagrama de Circuito**

El circuito utiliza un zumbador pasivo, un transistor NPN y una resistencia de 1kΩ. La resistencia protege al transistor del exceso de corriente. Variando la frecuencia del pin GPIO conectado al transistor, el zumbador produce diferentes sonidos, lo que le permite reproducir música.

.. image:: img/fzz/1.2.2_sch.png


----------------------------------------------

**Diagrama de Conexiones**

Sigue estos pasos para construir el circuito:

1. Conecta la base del transistor NPN a PWM0 a través de la resistencia.
2. Conecta el emisor del transistor a la alimentación (+).
3. Conecta el colector del transistor a un terminal del zumbador pasivo.
4. Conecta el otro terminal del zumbador a tierra (-).

Después de ejecutar el script, el zumbador pasivo reproduce una breve melodía musical a través de PWM 0. Cada nota se reproduce en secuencia durante su duración establecida, y la nota actual se imprime en la consola mientras se reproduce. **Código**

El siguiente código Python genera notas musicales usando un zumbador pasivo:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import Buzzer
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize a TonalBuzzer connected to PWM 0
   tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

   def play(tune):
      """
      Play a musical tune using the buzzer.
      :param tune: List of tuples (note, duration), where each tuple represents a note and its duration.
      """
      for note, duration in tune:
         print(note)  # Output the current note being played
         tb.play(note,float(duration))  # Play the note on the buzzer
      tb.off()  # Stop playing after the tune is complete

   # Define a musical tune as a sequence of notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('C4', 0.2), ('B4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
      ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
      ('D4', 0.2), ('E4', 0.2)]


      try:
         play(tune)  # Execute the play function to start playing the tune

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt for graceful termination
         pass

Este script Python reproduce una melodía musical usando un zumbador pasivo conectado a PWM 0. Cuando se ejecuta:

1. El script itera a través de una secuencia predefinida de notas musicales (``tune``), reproduciendo cada nota durante una duración específica.
2. Las notas se muestran en la consola a medida que se reproducen, proporcionando una referencia visual.
3. La melodía se detiene automáticamente una vez que se han reproducido todas las notas. El zumbador no produce sonido durante las pausas (cuando la nota es ``None``).
4. El programa puede interrumpirse de forma controlada usando ``Ctrl+C``.

**Comprender el Código**

1. **Importación de Librerías**

   La clase ``Buzzer`` de la librería ``fusion_hat`` se utiliza para generar tonos, y ``time.sleep`` introduce retrasos para las duraciones de las notas.

   .. code-block:: python

       from fusion_hat.modules import Buzzer
       from fusion_hat.pwm import PWM
       from time import sleep

2. **Inicialización del Zumbador**

   El ``Buzzer`` se asocia con PWM0 para la generación de tonos.

   .. code-block:: python

      # Initialize a TonalBuzzer connected to PWM 0
      tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

3. **Reproducción de Notas**

   La función ``play`` itera sobre una lista de tuplas que representan notas musicales y sus duraciones. Cada nota se reproduce durante su duración especificada, seguida de una breve pausa.

   .. code-block:: python

      def play(tune):
         for note, duration in tune:
            print(note)  # Output the current note being played
            tb.play(note,float(duration))  # Play the note on the buzzer
         tb.off()  # Stop playing after the tune is complete

4. **Definición de la Melodía**

   La variable ``tune`` contiene una secuencia de notas (por ejemplo, 'C#4') y duraciones (por ejemplo, 0.2 segundos).

   .. code-block:: python

       tune = [
           ('C#4', 0.2), ('D4', 0.2), (None, 0.2),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('C4', 0.2), ('B4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
           ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
           ('D4', 0.2), ('E4', 0.2)
       ]

5. **Manejo de Interrupción por Teclado**

   El bloque ``try-except`` asegura que el programa se detenga de forma controlada cuando sea interrumpido (por ejemplo, Ctrl+C).

   .. code-block:: python

       try:
           play(tune)
       except KeyboardInterrupt:
           pass



----------------------------------------------

**Solución de Problemas**

1. **El Zumbador No Emite Sonido**

   - **Causa**: Conexión incorrecta del pin GPIO o tipo de zumbador incompatible.
   - **Solución**: Asegúrate de que el zumbador esté conectado a PWM 0.

2. **Sonido Intermitente o Entrecortado**

   - **Causa**: Inconsistencias de temporización en la función ``sleep()``.
   - **Solución**: Confirma que las duraciones en la lista ``tune`` estén calibradas apropiadamente para transiciones suaves.

**Ideas para Extender**

1. **Melodías Personalizadas**

   Permite al usuario introducir su propia secuencia de notas y duraciones:

   .. code-block:: python

      user_tune = []
      while True:
         note = input("Enter a note (or 'stop' to finish): ")
         if note.lower() == 'stop':
            break
         duration = float(input("Enter duration for the note: "))
         user_tune.append((note, duration))
      play(user_tune)


2. **Múltiples Melodías**

   Agrega melodías predefinidas y deja que el usuario seleccione cuál reproducir:

   .. code-block:: python

      tunes = {
         "tune1": [('C4', 0.5), ('D4', 0.5), (None, 0.5)],
         "tune2": [('G4', 0.3), ('A4', 0.3), (None, 0.3)]
      }
      choice = input("Choose a tune (tune1/tune2): ")
      play(tunes[choice])


3. **Interacción en Tiempo Real**

   Usa botones o un teclado para reproducir notas de forma interactiva, convirtiendo el zumbador en un instrumento simple.

4. **Melodías Encadenadas**

   Encadena automáticamente múltiples melodías para crear una pieza más larga.

5. **Ajuste Dinámico de Velocidad**

   Permite a los usuarios cambiar la velocidad de reproducción dinámicamente modificando las duraciones de las notas:

   .. code-block:: python

      speed_factor = float(input("Enter speed factor (e.g., 1.0 for normal, 0.5 for faster): "))
      adjusted_tune = [(note, duration * speed_factor) for note, duration in tune]
      play(adjusted_tune)
