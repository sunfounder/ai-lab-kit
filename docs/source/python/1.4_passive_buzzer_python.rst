1.4 无源蜂鸣器
===============

**介绍**

在本项目中，我们将学习如何通过不同频率驱动无源蜂鸣器播放音乐。与有源蜂鸣器不同，无源蜂鸣器需要外部信号才能产生声音。

**电路图**

该电路使用一个无源蜂鸣器、一个NPN三极管和一个1kΩ电阻。电阻保护三极管免受过大电流影响。通过改变连接到三极管的GPIO引脚的频率，蜂鸣器可以发出不同的声音，从而实现播放音乐。

.. image:: img/fzz/1.2.2_sch.png


----------------------------------------------

**接线图**

请按照以下步骤搭建电路：

1. 将NPN三极管的基极通过电阻连接到PWM0。
2. 将三极管的发射极连接到电源正极（+）。
3. 将三极管的集电极连接到无源蜂鸣器的一个端子。
4. 将蜂鸣器的另一个端子连接到电源负极（-）。

.. image:: img/fzz/1.2.2_bb.png

   :align: center

运行脚本后，无源蜂鸣器通过PWM 0播放一段简短的乐曲。每个音符按其设定时长依次播放，当前音符在播放时会打印到控制台。乐曲播放完毕后，蜂鸣器自动停止，其中音符为\ ``None``\ 处为静音停顿。你也可以随时按Ctrl + C停止程序。

**代码**

以下Python代码使用无源蜂鸣器生成音乐音符：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import Buzzer
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize a TonalBuzzer connected to PWM 0
   tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

   def play(tune):
      """
      Play a musical tune using the buzzer.
      :param tune: List of tuples (note, duration), where each tuple represents a note and its duration.
      """
      for note, duration in tune:
         print(note)  # Output the current note being played
         tb.play(note,float(duration))  # Play the note on the buzzer
      tb.off()  # Stop playing after the tune is complete

   # Define a musical tune as a sequence of notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('C4', 0.2), ('B4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
      ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
      ('D4', 0.2), ('E4', 0.2)]


      try:
         play(tune)  # Execute the play function to start playing the tune

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt for graceful termination
         pass

此Python脚本使用连接到PWM 0的无源蜂鸣器播放乐曲。执行时：

1. 脚本遍历预定义的音符序列（\ ``tune``\ ），每个音符按指定时长播放。
2. 音符播放时输出到控制台，提供视觉参考。
3. 所有音符播放完毕后，乐曲自动停止。在停顿期间（音符为\ ``None``\ ），蜂鸣器不发声。
4. 可通过\ ``Ctrl+C``\ 优雅地中断程序。


----------------------------------------------

**理解代码**

1. **库导入**

   ``fusion_hat``\ 库中的\ ``Buzzer``\ 类用于生成音调，\ ``time.sleep``\ 用于引入音符时长的延迟。

   .. code-block:: python

       from fusion_hat.modules import Buzzer
       from fusion_hat.pwm import PWM
       from time import sleep

2. **蜂鸣器初始化**

   ``Buzzer``\ 与PWM0关联以生成音调。

   .. code-block:: python

      # Initialize a TonalBuzzer connected to PWM 0
      tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

3. **播放音符**

   ``play``\ 函数遍历代表音乐音符及其时长的元组列表。每个音符按指定时长播放，然后短暂停止。

   .. code-block:: python

      def play(tune):
         for note, duration in tune:
            print(note)  # Output the current note being played
            tb.play(note,float(duration))  # Play the note on the buzzer
         tb.off()  # Stop playing after the tune is complete

4. **乐曲定义**

   ``tune``\ 变量包含一系列音符（例如'C#4'）和时长（例如0.2秒）。

   .. code-block:: python

       tune = [
           ('C#4', 0.2), ('D4', 0.2), (None, 0.2),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('C4', 0.2), ('B4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
           ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
           ('D4', 0.2), ('E4', 0.2)
       ]

5. **键盘中断处理**

   ``try-except``\ 块确保程序在被中断时（例如\ ``Ctrl+C``\ ）优雅地停止。

   .. code-block:: python

       try:
           play(tune)
       except KeyboardInterrupt:
           pass



----------------------------------------------

**故障排除**

1. **蜂鸣器无声音**

   - **原因**：GPIO引脚连接错误或蜂鸣器类型不兼容。
   - **解决方案**：确保TonalBuzzer连接到PWM 0。

2. **声音断续或卡顿**

   - **原因**：\ ``sleep()``\ 函数的时序不一致。
   - **解决方案**：确认\ ``tune``\ 列表中的时长已适当校准，以实现平滑过渡。

**扩展思路**

1. **自定义乐曲**

   允许用户输入自己的音符和时长序列：

   .. code-block:: python

      user_tune = []
      while True:
         note = input("Enter a note (or 'stop' to finish): ")
         if note.lower() == 'stop':
            break
         duration = float(input("Enter duration for the note: "))
         user_tune.append((note, duration))
      play(user_tune)


2. **多首乐曲**

   添加预定义乐曲并让用户选择播放哪一首：

   .. code-block:: python

      tunes = {
         "tune1": [('C4', 0.5), ('D4', 0.5), (None, 0.5)],
         "tune2": [('G4', 0.3), ('A4', 0.3), (None, 0.3)]
      }
      choice = input("Choose a tune (tune1/tune2): ")
      play(tunes[choice])


3. **实时交互**

   使用按钮或键盘交互式地播放音符，将蜂鸣器变成简单的乐器。

4. **串联乐曲**

   自动将多首乐曲串联在一起，形成更长的曲目。

5. **动态速度调节**

   允许用户通过修改音符时长动态改变播放速度：

   .. code-block:: python

      speed_factor = float(input("Enter speed factor (e.g., 1.0 for normal, 0.5 for faster): "))
      adjusted_tune = [(note, duration * speed_factor) for note, duration in tune]
      play(adjusted_tune)
