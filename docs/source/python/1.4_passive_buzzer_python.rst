1.4 Buzzer Passif
=====================

**Introduction**

Dans ce projet, nous allons apprendre a faire jouer de la musique a un buzzer passif en le pilotant avec differentes frequences. Les buzzers passifs, contrairement aux buzzers actifs, necessitent un signal externe pour produire du son.

**Schema de circuit**

Le circuit utilise un buzzer passif, un transistor NPN et une resistance de 1kΩ. La resistance protege le transistor d'un courant excessif. En faisant varier la frequence de la broche GPIO connectee au transistor, le buzzer produit differents sons, lui permettant de jouer de la musique.

.. image:: img/fzz/1.2.2_sch.png


----------------------------------------------

**Schema de cablage**

Suivez ces etapes pour construire le circuit :

1. Connectez la base du transistor NPN a PWM0 via la resistance.
2. Connectez l'emetteur du transistor a l'alimentation (+).
3. Connectez le collecteur du transistor a une borne du buzzer passif.
4. Connectez l'autre borne du buzzer a la masse (-).

**Code**

Le code Python suivant genere des notes de musique en utilisant un buzzer passif :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.modules import Buzzer
   from fusion_hat.pwm import PWM
   from time import sleep

   # Initialize a TonalBuzzer connected to PWM 0
   tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

   def play(tune):
      """
      Play a musical tune using the buzzer.
      :param tune: List of tuples (note, duration), where each tuple represents a note and its duration.
      """
      for note, duration in tune:
         print(note)  # Output the current note being played
         tb.play(note,float(duration))  # Play the note on the buzzer
      tb.off()  # Stop playing after the tune is complete

   # Define a musical tune as a sequence of notes and durations
   tune = [('C#4', 0.2), ('D4', 0.2), (None, 0.2),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
      ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('C4', 0.2), ('B4', 0.2), (None, 0.2),
      ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
      ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
      ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
      ('D4', 0.2), ('E4', 0.2)]


      try:
         play(tune)  # Execute the play function to start playing the tune

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt for graceful termination
         pass

Ce script Python joue un air musical en utilisant un buzzer passif connecte a PWM 0. Lors de l'execution :

1. Le script parcourt une sequence predefinie de notes de musique (``tune``), jouant chaque note pendant une duree specifiee.
2. Les notes sont affichees sur la console au fur et a mesure qu'elles sont jouees, fournissant une reference visuelle.
3. L'air s'arrete automatiquement une fois que toutes les notes ont ete jouees. Le buzzer ne produit aucun son pendant les pauses (lorsque la note est ``None``).
4. Le programme peut etre interrompu proprement avec ``Ctrl+C``.


----------------------------------------------

**Comprendre le code**

1. **Importation de la bibliotheque**

   La classe ``Buzzer`` de la bibliotheque ``fusion_hat`` est utilisee pour generer des tons, et ``time.sleep`` introduit des pauses pour les durees des notes.

   .. code-block:: python

       from fusion_hat.modules import Buzzer
       from fusion_hat.pwm import PWM
       from time import sleep

2. **Initialisation du buzzer**

   Le ``Buzzer`` est associe a PWM0 pour la generation de tons.

   .. code-block:: python

      # Initialize a TonalBuzzer connected to PWM 0
      tb = Buzzer(PWM('P0'))  # Update this pin number based on your setup

3. **Jouer des notes**

   La fonction ``play`` parcourt une liste de tuples representant des notes de musique et leurs durees. Chaque note est jouee pendant sa duree specifiee, suivie d'un bref arret.

   .. code-block:: python

      def play(tune):
         for note, duration in tune:
            print(note)  # Output the current note being played
            tb.play(note,float(duration))  # Play the note on the buzzer
         tb.off()  # Stop playing after the tune is complete

4. **Definition de l'air**

   La variable ``tune`` contient une sequence de notes (par exemple, 'C#4') et de durees (par exemple, 0,2 seconde).

   .. code-block:: python

       tune = [
           ('C#4', 0.2), ('D4', 0.2), (None, 0.2),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.6),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.6),
           ('Eb4', 0.2), ('E4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('C4', 0.2), ('B4', 0.2), (None, 0.2),
           ('F#4', 0.2), ('G4', 0.2), (None, 0.2),
           ('B4', 0.2), ('Bb4', 0.5), (None, 0.6),
           ('A4', 0.2), ('G4', 0.2), ('E4', 0.2),
           ('D4', 0.2), ('E4', 0.2)
       ]

5. **Gestion des interruptions clavier**

   Le bloc ``try-except`` garantit que le programme s'arrete proprement lorsqu'il est interrompu (par exemple, Ctrl+C).

   .. code-block:: python

       try:
           play(tune)
       except KeyboardInterrupt:
           pass



----------------------------------------------

**Depannage**

1. **Aucun son du buzzer**

   - **Cause** : Connexion de broche GPIO incorrecte ou type de buzzer incompatible.
   - **Solution** : Assurez-vous que le TonalBuzzer est connecte a PWM 0.

2. **Son intermittent ou saccade**

   - **Cause** : Incoherences de temporisation dans la fonction ``sleep()``.
   - **Solution** : Confirmez que les durees dans la liste ``tune`` sont correctement calibrees pour des transitions fluides.

**Idees d'extension**

1. **Airs personnalises**

   Permettez a l'utilisateur de saisir sa propre sequence de notes et durees :

   .. code-block:: python

      user_tune = []
      while True:
         note = input("Enter a note (or 'stop' to finish): ")
         if note.lower() == 'stop':
            break
         duration = float(input("Enter duration for the note: "))
         user_tune.append((note, duration))
      play(user_tune)


2. **Airs multiples**

   Ajoutez des airs predefinis et laissez l'utilisateur choisir lequel jouer :

   .. code-block:: python

      tunes = {
         "tune1": [('C4', 0.5), ('D4', 0.5), (None, 0.5)],
         "tune2": [('G4', 0.3), ('A4', 0.3), (None, 0.3)]
      }
      choice = input("Choose a tune (tune1/tune2): ")
      play(tunes[choice])


3. **Interaction en temps reel**

   Utilisez des boutons ou un clavier pour jouer des notes de maniere interactive, transformant le buzzer en un instrument simple.

4. **Airs enchaines**

   Enchainez automatiquement plusieurs airs pour creer un morceau plus long.

5. **Ajustement dynamique de la vitesse**

   Permettez aux utilisateurs de modifier la vitesse de lecture dynamiquement en changeant les durees des notes :

   .. code-block:: python

      speed_factor = float(input("Enter speed factor (e.g., 1.0 for normal, 0.5 for faster): "))
      adjusted_tune = [(note, duration * speed_factor) for note, duration in tune]
      play(adjusted_tune)
