4.1.14 SPIEL – Zahlenraten
==============================

**Introduction**

Das Spiel „Guess the Number“ ist ein klassischer Party-Klassiker: Spielende raten reihum eine verborgene Zahl innerhalb eines vorgegebenen Bereichs. Mit jedem Versuch wird der Bereich – abhängig davon, ob der Tipp zu hoch oder zu niedrig war – weiter eingegrenzt, bis jemand die richtige Zahl trifft. In diesem Projekt setzt du das Spiel mit einem Raspberry Pi um: Eine Tastatur dient zur Eingabe und ein LCD zeigt Hinweise und Ergebnisse an.

**Writing the Code**


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin,LCD1602,Keypad
   from time import sleep
   import random

   # Game-related variables
   count = 0
   pointValue = 0
   upper = 99
   lower = 0

   """
   Setup function for initializing the keypad and LCD display.
   """
   global keypad, last_key_pressed, keys
   # Configure rows, columns, and keypad layout
   # pin from left to right - 4 17 27 22 23 24 25 12
   rows_pins = [4, 17, 27, 22]
   cols_pins = [23, 24, 25, 12]
   keys = ["1", "2", "3", "A",
         "4", "5", "6", "B",
         "7", "8", "9", "C",
         "*", "0", "#", "D"]

   # Create an instance of the Keypad class
   keypad = Keypad(rows_pins, cols_pins, keys)
   last_key_pressed = []

   lcd = LCD1602(address=0x27, backlight=1)
   lcd.clear()
   lcd.write(0, 0, 'Welcome!')
   lcd.write(0, 1, 'Press A to Start!')

   def init_new_value():
      """
      Initialize a new target value and reset game parameters.
      """
      global pointValue, upper, lower, count
      pointValue = random.randint(0, 99)
      upper = 99
      lower = 0
      count = 0
      print('point is %d' % pointValue)

   def detect_point():
      """
      Check if the guessed number is the target, too high, or too low.
      :return: 1 if correct guess, 0 otherwise.
      """
      global count, upper, lower
      if count > pointValue and count < upper:
         upper = count
      elif count < pointValue and count > lower:
         lower = count
      elif count == pointValue:
         count = 0
         return 1
      count = 0
      return 0

   def lcd_show_input(result):
      """
      Display the current game state and results on the LCD.
      :param result: Result of the last guess (0 or 1).
      """
      lcd.clear()
      if result == 1:
         lcd.write(0, 1, 'You have got it!')
         sleep(5)
         init_new_value()
         lcd_show_input(0)
      else:
         lcd.write(0, 0, 'Enter number:')
         lcd.write(13, 0, str(count))
         lcd.write(0, 1, str(lower))
         lcd.write(3, 1, ' < Point < ')
         lcd.write(13, 1, str(upper))

   def loop():
      """
      Main game loop for handling keypad input and updating game state.
      """
      global keypad, last_key_pressed, count
      while True:
         result = 0
         pressed_keys = keypad.read()
         if pressed_keys and pressed_keys != last_key_pressed:
               if pressed_keys == ["A"]:
                  init_new_value()
                  lcd_show_input(0)
               elif pressed_keys == ["D"]:
                  result = detect_point()
                  lcd_show_input(result)
               elif pressed_keys[0] in keys:
                  if pressed_keys[0] in ["A", "B", "C", "D", "#", "*"]:
                     continue
                  count = count * 10 + int(pressed_keys[0])
                  if count >= 10:
                     result = detect_point()
                  lcd_show_input(result)
               print(pressed_keys)
         last_key_pressed = pressed_keys
         sleep(0.1)

   try:
      loop()
   except KeyboardInterrupt:
      lcd.clear()  # Clear LCD on interrupt



* Beim Programmstart zeigt das LCD folgende Aufforderung:

   .. code-block::

      Welcome!
      Press A to go!

* Drücke auf der Tastatur ``A``, um das Spiel zu starten. Die Spielseite zeigt:

   .. code-block::

      Enter number:
      0 < point < 99

* Der Raspberry Pi erzeugt eine verborgene Zufallszahl (``point``) im Bereich 0 bis 99. Die Spielenden müssen anhand des auf dem LCD angezeigten Bereichs raten. Nach der Eingabe einer Zahl:

  * Mit ``D`` bestätigst du den Tipp.
  * Ist der Tipp falsch, wird der Bereich eingegrenzt.
  * Bei korrekter Zahl erscheint auf dem LCD:

   .. code-block::

      You've got it!

**Understanding the Code**

1. **Keypad Class:**  

   * Initialisiert Zeilen- und Spaltenpins der Tastatur.  
   * Erkennt gedrückte Tasten und gibt sie zurück.

2. **Game Logic:**  

   - Spielende geben über die Tastatur ihre Tipps ein.  
   - Mit „D“ wird der aktuelle Tipp bestätigt.  
   - Das LCD liefert Feedback:

     - Es zeigt den geratenen Wert und den aktuellen Zielbereich.
     - Der Bereich wird dynamisch angepasst, je nachdem, ob der Tipp zu hoch oder zu niedrig war.

3. **Win Condition**:  

   - Bei der richtigen Zahl zeigt das LCD: ``You have got it!``  
   - Nach kurzer Verzögerung wird automatisch eine neue Zielzahl generiert.


4. **Continuous Play**: Nach jedem Sieg setzt sich das Spiel zurück und ermöglicht weitere Runden.

5. **Graceful Exit**: Mit ``Ctrl+C`` wird das LCD geleert und das Programm sauber beendet.

----------------------------------------------


**Troubleshooting**

1. **Tastatur reagiert nicht**:

   - **Ursache**: Falsche Verdrahtung oder GPIO-Konfiguration.  
   - **Lösung**:

      - Prüfe, ob die Zeilen- und Spaltenpins wie in ``rowsPins`` und ``colsPins`` definiert verbunden sind.
      - Teste die Tastatur separat mit einem einfachen Skript.

2. **LCD zeigt Inhalte nicht korrekt an**:

   - **Ursache**: Falsche I2C-Adresse oder Verdrahtung.  
   - **Lösung**:

      - Bestätige die I2C-Adresse mit ``i2cdetect -y 1``.
      - Passe ``lcd = LCD1602(address=0x27, backlight=1)`` an die korrekte Adresse an.

3. **Spiellogik fehlerhaft (z. B. falsche Bereichsaktualisierung)**:

   - **Ursache**: Logikfehler in ``detect_point()``.  
   - **Lösung**:

      - Prüfe die Bedingungen zum Aktualisieren von ``upper`` und ``lower``.
      - Nutze Debug-Ausgaben zur Kontrolle der Variablen:

      .. code-block:: python

         print(f"Target: {pointValue}, Guess: {count}, Lower: {lower}, Upper: {upper}")

4. **Keine Reaktion auf Tasten „A“ oder „D“**:

   - **Ursache**: Spezielle Tasten werden nicht korrekt verarbeitet.  
   - **Lösung**: Stelle sicher, dass „A“ und „D“ in der ``loop()``-Funktion erkannt und behandelt werden.

5. **Probleme bei der Zifferneingabe**:

   - **Ursache**: Falsche Verarbeitung numerischer Eingaben.  
   - **Lösung**: Stelle sicher, dass nur gültige Ziffern (0–9) ``count`` verändern.

**Extendable Ideas**

1. **Schwierigkeitsgrade**: Auswahl unterschiedlicher Bereiche (z. B. Easy: 0–50, Medium: 0–99, Hard: 0–999).

2. **Spieltimer**: Begrenze die Rundenzeit und zeige die Restzeit auf dem LCD an.

3. **Punktesystem**: Zähle die Versuche und gib nach jeder Runde eine Bewertung aus.

4. **Hinweissystem**: Liefere Hinweise („Deutlich höher“, „Etwas niedriger“) je nach Abstand zur Zielzahl.

5. **Mehrspielermodus**: Zwei Spielende raten abwechselnd; gewinnt, wer zuerst richtig liegt.

6. **Zufällige Gratulationen**: Variiere Gewinn-Meldungen wie „Great Job!“ oder „You Nailed It!“.

7. **Akustisches Feedback**: Nutze einen Buzzer für unterschiedliche Töne bei richtigen/falschen Tipps.
