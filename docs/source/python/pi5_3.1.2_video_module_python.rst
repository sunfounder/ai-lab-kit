3.1.2 Videomodul
======================

**Introduction**

Neben der Aufnahme von Fotos ermöglicht das Raspberry Pi Kameramodul auch das Aufzeichnen von hochwertigen Videos. Dieses Projekt zeigt, wie du das Modul für Videoaufnahmen mit einstellbarer Auflösung, Bildrate und Bitrate konfigurierst und die Videos direkt auf deinem Raspberry Pi speicherst.

**Experimental Procedures**

1. **Zugriff auf den Raspberry Pi Desktop:**

   Du kannst den Raspberry Pi Desktop auch remote nutzen. Ausführliche Schritte findest du unter :ref:`remote_desktop`.

2. **Öffne ein Terminal:**

   Wechsle in das Projektverzeichnis:

   .. code-block:: bash

3. **Starte das Python-Skript:**

   Führe das Skript aus, um die Aufnahme zu starten:

   .. code-block:: bash

      sudo python3 3.1.2_VideoModule_zero.py

   Die Kamera startet die Aufzeichnung. Drücke ``Ctrl+C``, um die Aufnahme zu stoppen. Das Video wird als ``my_video.mp4`` im ``~``-Verzeichnis (dein Home-Ordner) gespeichert.

.. note::
   Du kannst die Datei ``3.1.2_VideoModule_zero.py`` auch in einer Python-IDE öffnen, das Skript mit "Run" starten und mit "Stop" wieder beenden.

Anleitungen zum Übertragen des Videos auf deinen PC findest du unter :ref:`filezilla`.

**Code**

Das folgende Python-Skript wird für dieses Projekt verwendet:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import time
   from picamera2 import Picamera2, Preview
   from picamera2.encoders import H264Encoder
   from picamera2.outputs import FfmpegOutput
   import os

   # Get the current user's home directory
   user_home = os.path.expanduser('~')

   # Create a Picamera2 instance
   camera = Picamera2()
   # Retrieve the default preview configuration
   preview_config = camera.preview_configuration

   try:
       # Configure preview size and format
       preview_config.size = (800, 600)
       preview_config.format = 'XRGB8888'
       # Start the camera preview in QTGL mode
       # camera.start_preview(Preview.QTGL)

       # Define video configuration with resolution and frame rate
       conf = {'size': (800, 600)}
       controls = {'FrameRate': 40}
       config = camera.create_video_configuration(main=conf, controls=controls, buffer_count=12)

       # Set up the video encoder and output file
       encoder = H264Encoder(bitrate=10000000)
       output = FfmpegOutput(f'{user_home}/my_video.mp4')

       # Configure and start recording
       camera.configure(config)
       camera.start_recording(encoder, output)
       print("Recording started. Press Ctrl+C to stop.")

       # Record for 10 seconds (or until interrupted)
       time.sleep(10)
       camera.stop_recording()

   except KeyboardInterrupt:
       # Gracefully handle interruptions
       print("Recording stopped by user.")
       camera.stop_preview()

Dieses Python-Skript nutzt die ``Picamera2``-Bibliothek zur Videoaufzeichnung mit der Raspberry Pi Kamera. Beim Ausführen passiert Folgendes:

1. **Kamerainitialisierung**:  

   - Die Kamera wird für eine Vorschau mit einer Auflösung von ``800x600`` im hardwarebeschleunigten ``QTGL``-Modus eingerichtet.  

2. **Videokonfiguration**:  

   - Aufnahme mit einer Auflösung von ``800x600`` bei 40 FPS.  
   - Kodierung mit dem H.264-Encoder bei 10 Mbit/s.  

3. **Aufnahmeprozess**:  

   - Das Video wird als ``my_video.mp4`` im Home-Verzeichnis gespeichert.  
   - Die Aufnahme läuft 10 Sekunden oder bis sie mit ``Ctrl+C`` abgebrochen wird.  

4. **Sauberes Beenden**: 

   - Bei Unterbrechung stoppt die Kamera die Aufnahme und beendet die Vorschau ordnungsgemäß.  


----------------------------------------------


**Understanding the Code**

1. **Imports:**  

   Das Skript verwendet die ``picamera2``-Bibliothek zur Kamerasteuerung, ``H264Encoder`` für die Videokodierung und ``FfmpegOutput`` zur Definition der Ausgabedatei. Das Modul ``os`` dient zur Verwaltung von Dateipfaden.  

   .. code-block:: python

      import time
      from picamera2 import Picamera2, Preview
      from picamera2.encoders import H264Encoder
      from picamera2.outputs import FfmpegOutput
      import os

2. **Benutzerverzeichnis festlegen:**  

   Ermittelt das Home-Verzeichnis des aktuellen Benutzers zum Speichern des Videos.  

   .. code-block:: python

      user_home = os.path.expanduser('~')

3. **Kamerainitialisierung:**  

   Erstellt eine ``Picamera2``-Instanz und ruft die Standard-Vorschaukonfiguration ab.  

   .. code-block:: python

      camera = Picamera2()
      preview_config = camera.preview_configuration

4. **Vorschaukonfiguration:**  

   Setzt die Vorschaugröße auf 800x600 Pixel und das Format auf ``XRGB8888``.  

   .. code-block:: python

      preview_config.size = (800, 600)
      preview_config.format = 'XRGB8888'

5. **Videoaufzeichnung einrichten:**  

   Erstellt eine Videokonfiguration mit 800x600 Pixeln bei 40 FPS. Das Video wird mit 10 Mbit/s im H.264-Format aufgezeichnet und als ``my_video.mp4`` gespeichert.  

   .. code-block:: python

      conf = {'size': (800, 600)}
      controls = {'FrameRate': 40}
      config = camera.create_video_configuration(main=conf, controls=controls, buffer_count=12)
      encoder = H264Encoder(bitrate=10000000)
      output = FfmpegOutput(f'{user_home}/my_video.mp4')

6. **Aufnahme und Beenden:**  

   Die Kamera wird konfiguriert und startet die Aufnahme. Diese läuft 10 Sekunden oder bis zum Abbruch mit ``Ctrl+C``. Unterbrechungen werden abgefangen, sodass die Vorschau sauber beendet wird.  

   .. code-block:: python

      try:
         camera.configure(config)
         camera.start_recording(encoder, output)
         time.sleep(10)
         camera.stop_recording()
      except KeyboardInterrupt:
         camera.stop_preview()

**Troubleshooting**

1. **Vorschaufenster erscheint nicht**:  

   - **Ursache**: Fehlende Abhängigkeiten oder fehlerhafte Kameraeinstellungen.  
   - **Lösung**:  

     - Stelle sicher, dass das Kameramodul korrekt angeschlossen und in ``raspi-config`` aktiviert ist.  
     - Installiere die benötigten Bibliotheken:  

      .. code-block:: python

         sudo apt update
         sudo apt install -y python3-picamera2 qtbase5-dev


2. **Videodatei wird nicht erstellt**:  

   - **Ursache**: Fehlende Schreibrechte oder falscher Dateipfad.  
   - **Lösung**:  

     - Überprüfe den Pfad mit ``print(user_home)``.  
     - Stelle sicher, dass das Skript Schreibrechte im Home-Verzeichnis hat.  

3. **Skript bricht mit Encoder-Fehler ab**:  

   - **Ursache**: H.264-Encoder nicht korrekt eingerichtet.  
   - **Lösung**:  

     - Prüfe, ob die Raspberry Pi Hardware H.264 unterstützt.  
     - Stelle sicher, dass ``ffmpeg`` installiert ist:  


      .. code-block:: python

         sudo apt install -y ffmpeg


4. **Aufnahme wird unterbrochen**:  

   - **Ursache**: Das Skript wird vorzeitig vom Benutzer beendet.  
   - **Lösung**: ``KeyboardInterrupt`` abfangen, um Ressourcen freizugeben und die Videodatei korrekt zu schließen.  

   .. code-block:: python

       except KeyboardInterrupt:
           print("Recording stopped by user.")
           camera.stop_recording()
           camera.stop_preview()

**Extendable Ideas**

1. **Flexible Aufnahmedauer**: Ermögliche dem Nutzer, die Dauer per Skriptargument festzulegen:  

   .. code-block:: python

      import argparse
      parser = argparse.ArgumentParser()
      parser.add_argument("--duration", type=int, default=10, help="Recording duration in seconds")
      args = parser.parse_args()
      time.sleep(args.duration)


2. **Zeitraffer-Videos**: Mit niedriger Bildrate aufnehmen, um einen Zeitraffereffekt zu erzeugen:  

   .. code-block:: python

      controls = {'FrameRate': 5}

3. **Mehrere Auflösungen**: Optionen für verschiedene Auflösungen wie HD, Full HD oder 4K anbieten.
