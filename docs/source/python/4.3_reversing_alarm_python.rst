4.3 倒车报警器
==============

**简介**

将汽车安全停入车库通常需要仔细操作，尤其是在狭小空间内。在本项目中，您将使用超声波传感器和蜂鸣器创建一个倒车报警系统。该系统模拟真实停车传感器的功能，根据与障碍物的距离提供声音反馈。

此 Python 脚本集成了超声波距离传感器和蜂鸣器，创建了一个实时距离监控系统。运行时：


1. **距离测量**：超声波传感器测量前方最近物体的距离，并将值转换为厘米。


2. **蜂鸣器警报**：根据测量的距离：

     - **超过 50 cm**：蜂鸣器不发声。
     - **20 cm 至 50 cm 之间**：蜂鸣器以短间隔响两声。
     - **20 cm 或以下**：蜂鸣器快速鸣响，提示距离极近。

**代码**

以下是本项目的 Python 代码：


.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3

    import time
    from fusion_hat.modules import Ultrasonic, Buzzer
    from fusion_hat.pin import Pin

    # Ultrasonic sensor: Trig -> GPIO 27, Echo -> GPIO 22
    sensor = Ultrasonic(trig=Pin(27), echo=Pin(22))

    # Buzzer connected to GPIO 17
    buzzer = Buzzer(Pin(17))

    def get_distance():
        """
        Read distance from ultrasonic sensor and print it.
        Returns distance in centimeters.
        """
        dis = sensor.read()
        print(f"Distance: {dis:.2f} cm")
        return dis


    def beep(times, on_time, off_time):
        """
        Make the buzzer beep with given timing.
        """
        for _ in range(times):
            buzzer.on()
            time.sleep(on_time)
            buzzer.off()
            time.sleep(off_time)


    def loop():
        """
        Continuously measure distance and control buzzer frequency.
        """
        while True:
            dis = get_distance()

            if dis >= 50:
                # Far distance: buzzer silent
                time.sleep(0.5)

            elif 20 < dis < 50:
                # Medium distance: slow beeping
                beep(times=2, on_time=0.05, off_time=0.2)

            else:
                # Close distance (<= 20 cm): fast beeping
                beep(times=5, on_time=0.05, off_time=0.05)

            time.sleep(0.3)  # Measurement interval

    try:
        loop()
    except KeyboardInterrupt:
        buzzer.off()
        print("\nProgram stopped, buzzer turned off.")

**故障排除**

1. **无法测量距离**：

   - **原因**：接线错误或传感器故障。
   - **解决方法**：

     - 确保超声波传感器的 ``echo`` 和 ``trigger`` 引脚分别连接到 GPIO 22 和 GPIO 27。
     - 独立测试传感器以确认功能正常。

2. **蜂鸣器不发声**：

   - **原因**：蜂鸣器未连接或损坏。
   - **解决方法**：

     - 验证蜂鸣器是否连接到 GPIO 17 和 GND。
     - 通过手动打开蜂鸣器进行测试：

       .. code-block:: python

           buzzer.on()
           time.sleep(1)
           buzzer.off()
