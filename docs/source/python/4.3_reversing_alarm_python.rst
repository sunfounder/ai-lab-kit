4.3 Allarme di Retromarcia
==============================

**Introduzione**

Parcheggiare un'auto in sicurezza in un garage richiede spesso una navigazione attenta, specialmente in spazi stretti. In questo progetto, creerai un sistema di allarme di retromarcia usando un sensore ultrasonico e un buzzer. Questo sistema imita la funzionalità di un sensore di parcheggio reale, fornendo feedback acustico sulla distanza dagli ostacoli.

Questo script Python integra un sensore di distanza ultrasonico e un buzzer per creare un sistema di monitoraggio della distanza in tempo reale. Quando eseguito:


1. **Misurazione della Distanza**: Il sensore ultrasonico misura la distanza dall'oggetto più vicino di fronte a sé e converte il valore in centimetri.


2. **Avvisi del Buzzer**: In base alla distanza misurata:

     - **Più di 50 cm**: Nessun suono del buzzer.
     - **Tra 20 cm e 50 cm**: Il buzzer emette due beep con un breve intervallo.
     - **20 cm o meno**: Il buzzer emette beep rapidi per indicare la prossimità.

**Codice**

Ecco il codice Python per il progetto:


.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3

    import time
    from fusion_hat.modules import Ultrasonic, Buzzer
    from fusion_hat.pin import Pin

    # Ultrasonic sensor: Trig -> GPIO 27, Echo -> GPIO 22
    sensor = Ultrasonic(trig=Pin(27), echo=Pin(22))

    # Buzzer connected to GPIO 17
    buzzer = Buzzer(Pin(17))

    def get_distance():
        """
        Read distance from ultrasonic sensor and print it.
        Returns distance in centimeters.
        """
        dis = sensor.read()
        print(f"Distance: {dis:.2f} cm")
        return dis


    def beep(times, on_time, off_time):
        """
        Make the buzzer beep with given timing.
        """
        for _ in range(times):
            buzzer.on()
            time.sleep(on_time)
            buzzer.off()
            time.sleep(off_time)


    def loop():
        """
        Continuously measure distance and control buzzer frequency.
        """
        while True:
            dis = get_distance()

            if dis >= 50:
                # Far distance: buzzer silent
                time.sleep(0.5)

            elif 20 < dis < 50:
                # Medium distance: slow beeping
                beep(times=2, on_time=0.05, off_time=0.2)

            else:
                # Close distance (<= 20 cm): fast beeping
                beep(times=5, on_time=0.05, off_time=0.05)

            time.sleep(0.3)  # Measurement interval

    try:
        loop()
    except KeyboardInterrupt:
        buzzer.off()
        print("\nProgram stopped, buzzer turned off.")

**Risoluzione dei Problemi**

1. **Distanza Non Misurata**:

   - **Causa**: Cablaggio errato o malfunzionamento del sensore.
   - **Soluzione**:

     - Assicurati che i pin ``echo`` e ``trigger`` del sensore ultrasonico siano collegati rispettivamente a GPIO 22 e GPIO 27.
     - Testa il sensore indipendentemente per confermarne la funzionalità.

2. **Il Buzzer Non Suona**:

   - **Causa**: Buzzer non collegato o difettoso.
   - **Soluzione**:

     - Verifica che il buzzer sia collegato a GPIO 17 e a massa.
     - Testa il buzzer accendendolo manualmente:

       .. code-block:: python

           buzzer.on()
           time.sleep(1)
           buzzer.off()
