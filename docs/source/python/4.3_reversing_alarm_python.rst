4.3 Alarme de recul
=============================

**Introduction**

Garer une voiture en toute securite dans un garage necessite souvent une navigation prudente, surtout dans les espaces restreints. Dans ce projet, vous allez creer un systeme d’alarme de recul utilisant un capteur ultrasonique et un buzzer. Ce systeme imite la fonctionnalite d’un capteur de stationnement reel, fournissant un retour auditif sur la distance aux obstacles.

Ce script Python integre un capteur de distance ultrasonique et un buzzer pour creer un systeme de surveillance de distance en temps reel. Lors de l’execution :


1. **Mesure de distance** : Le capteur ultrasonique mesure la distance jusqu’a l’objet le plus proche et convertit la valeur en centimetres.


2. **Alertes sonores** : En fonction de la distance mesuree :

     - **Plus de 50 cm** : Aucun son du buzzer.
     - **Entre 20 cm et 50 cm** : Le buzzer emet deux bip avec un court intervalle.
     - **20 cm ou moins** : Le buzzer emet des bip rapides pour indiquer la proximite.

**Code**

Voici le code Python pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3

    import time
    from fusion_hat.modules import Ultrasonic, Buzzer
    from fusion_hat.pin import Pin

    # Ultrasonic sensor: Trig -> GPIO 27, Echo -> GPIO 22
    sensor = Ultrasonic(trig=Pin(27), echo=Pin(22))

    # Buzzer connected to GPIO 17
    buzzer = Buzzer(Pin(17))

    def get_distance():
        """
        Read distance from ultrasonic sensor and print it.
        Returns distance in centimeters.
        """
        dis = sensor.read()
        print(f"Distance: {dis:.2f} cm")
        return dis


    def beep(times, on_time, off_time):
        """
        Make the buzzer beep with given timing.
        """
        for _ in range(times):
            buzzer.on()
            time.sleep(on_time)
            buzzer.off()
            time.sleep(off_time)


    def loop():
        """
        Continuously measure distance and control buzzer frequency.
        """
        while True:
            dis = get_distance()

            if dis >= 50:
                # Far distance: buzzer silent
                time.sleep(0.5)

            elif 20 < dis < 50:
                # Medium distance: slow beeping
                beep(times=2, on_time=0.05, off_time=0.2)

            else:
                # Close distance (<= 20 cm): fast beeping
                beep(times=5, on_time=0.05, off_time=0.05)

            time.sleep(0.3)  # Measurement interval

    try:
        loop()
    except KeyboardInterrupt:
        buzzer.off()
        print("\nProgram stopped, buzzer turned off.")

**Depannage**

1. **Distance non mesuree** :

   - **Cause :** Cablage incorrect ou dysfonctionnement du capteur.
   - **Solution :**

     - Assurez-vous que les broches ``echo`` et ``trigger`` du capteur ultrasonique sont connectees respectivement a la GPIO 22 et a la GPIO 27.
     - Testez le capteur independamment pour confirmer son fonctionnement.

2. **Le buzzer ne sonne pas** :

   - **Cause :** Buzzer non connecte ou defectueux.
   - **Solution :**

     - Verifiez que le buzzer est connecte a la GPIO 17 et a la masse.
     - Testez le buzzer en l'activant manuellement :

       .. code-block:: python

           buzzer.on()
           time.sleep(1)
           buzzer.off()
