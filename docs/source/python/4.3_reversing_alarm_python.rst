4.3 Alarma de Reversa
==============================

**Introducción**

Estacionar un automóvil de manera segura en un garaje a menudo requiere una navegación cuidadosa, especialmente en espacios reducidos. En este proyecto, crearás un sistema de alarma de reversa utilizando un sensor ultrasónico y un zumbador. Este sistema imita la funcionalidad de un sensor de estacionamiento real, proporcionando retroalimentación auditiva sobre la distancia a los obstáculos.

Este script de Python integra un sensor de distancia ultrasónico y un zumbador para crear un sistema de monitoreo de distancia en tiempo real. Cuando se ejecuta:


1. **Medición de Distancia**: El sensor ultrasónico mide la distancia al objeto más cercano frente a él y convierte el valor a centímetros.


2. **Alertas del Zumbador**: Según la distancia medida:

     - **Más de 50 cm**: Sin sonido del zumbador.
     - **Entre 20 cm y 50 cm**: El zumbador emite dos pitidos con un intervalo corto.
     - **20 cm o menos**: El zumbador emite pitidos rápidos para indicar proximidad.

**Código**

Aquí está el código Python para el proyecto:


.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3

    import time
    from fusion_hat.modules import Ultrasonic, Buzzer
    from fusion_hat.pin import Pin

    # Ultrasonic sensor: Trig -> GPIO 27, Echo -> GPIO 22
    sensor = Ultrasonic(trig=Pin(27), echo=Pin(22))

    # Buzzer connected to GPIO 17
    buzzer = Buzzer(Pin(17))

    def get_distance():
        """
        Read distance from ultrasonic sensor and print it.
        Returns distance in centimeters.
        """
        dis = sensor.read()
        print(f"Distance: {dis:.2f} cm")
        return dis


    def beep(times, on_time, off_time):
        """
        Make the buzzer beep with given timing.
        """
        for _ in range(times):
            buzzer.on()
            time.sleep(on_time)
            buzzer.off()
            time.sleep(off_time)


    def loop():
        """
        Continuously measure distance and control buzzer frequency.
        """
        while True:
            dis = get_distance()

            if dis >= 50:
                # Far distance: buzzer silent
                time.sleep(0.5)

            elif 20 < dis < 50:
                # Medium distance: slow beeping
                beep(times=2, on_time=0.05, off_time=0.2)

            else:
                # Close distance (<= 20 cm): fast beeping
                beep(times=5, on_time=0.05, off_time=0.05)

            time.sleep(0.3)  # Measurement interval

    try:
        loop()
    except KeyboardInterrupt:
        buzzer.off()
        print("\nProgram stopped, buzzer turned off.")

**Solución de Problemas**

1. **No Se Mide la Distancia**:

   - **Causa**: Cableado incorrecto o mal funcionamiento del sensor.
   - **Solución**:

     - Asegúrate de que los pines ``echo`` y ``trigger`` del sensor ultrasónico estén conectados a GPIO 22 y GPIO 27, respectivamente.
     - Prueba el sensor de forma independiente para confirmar su funcionalidad.

2. **El Zumbador No Suena**:

   - **Causa**: Zumbador no conectado o defectuoso.
   - **Solución**:

     - Verifica que el zumbador esté conectado a GPIO 17 y a tierra.
     - Prueba el zumbador encendiéndolo manualmente:

       .. code-block:: python

           buzzer.on()
           time.sleep(1)
           buzzer.off()
