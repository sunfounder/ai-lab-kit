3.1.1 Fotografiemodul
==========================

**Introduction**

Dieses Projekt zeigt dir, wie du das Raspberry Pi Kameramodul verwenden kannst, um ein Foto aufzunehmen. Das Kameramodul ermöglicht hochqualitative Fotos und Videos und ist damit ein vielseitiges Werkzeug – von Fotografie bis hin zu Computer-Vision-Projekten.

**Experimental Procedures**

1. **Zugriff auf den Raspberry Pi Desktop:**

   Du kannst den Raspberry Pi Desktop auch remote nutzen. Detaillierte Schritte findest du unter :ref:`remote_desktop`.

2. **Öffne ein Terminal:**

   Wechsle in das Verzeichnis, das den Code enthält:

   .. code-block:: bash

      cd ~/ai-explorer-lab-kit/python

3. **Führe das Python-Skript aus:**

   Starte das Skript, um ein Foto aufzunehmen:

   .. code-block:: bash

      sudo python3 3.1.1_PhotographModule_zero.py

   Nach dem Ausführen des Skripts nimmt die Kamera ein Foto auf. Das Bild wird als ``my_photo.jpg`` im ``~``-Verzeichnis (dein Home-Ordner) gespeichert.

.. note::
    
   Du kannst die Datei ``3.1.1_PhotographModule.py`` auch in einer Python-IDE öffnen, das Skript über die Schaltfläche "Run" starten und mit "Stop" wieder anhalten.

Wenn du das Foto auf deinen PC herunterladen möchtest, folge der Anleitung unter :ref:`filezilla`.

**Code**

Hier das für dieses Projekt verwendete Python-Skript:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3    
   from picamera2 import Picamera2, Preview
   import os

   # Get the current user's login name
   user = os.getlogin()
   # Get the path to the user's home directory
   user_home = os.path.expanduser(f'~{user}')

   # Create a Picamera2 instance
   camera = Picamera2()
   # Retrieve the default preview configuration
   preview_config = camera.preview_configuration

   try:
       # Set preview size and format
       preview_config.size = (800, 600)
       preview_config.format = 'XRGB8888'  
       # Start the camera preview in QTGL mode
       # camera.start_preview(Preview.QTGL)
       # Start the camera
       camera.start()
       # Capture and save a photo to the user's home directory
       camera.capture_file(f'{user_home}/my_photo.jpg')

   except KeyboardInterrupt:
       # Stop the camera preview if a KeyboardInterrupt (e.g., Ctrl+C) occurs
       camera.stop_preview()
       pass

Dieses Python-Skript nutzt die ``Picamera2``-Bibliothek, um mit der Raspberry Pi Kamera zu arbeiten, und führt folgende Aufgaben aus:

1. **Kamerainitialisierung**: Initialisiert die Kamera und richtet eine Vorschaukonfiguration mit einer Auflösung von ``800x600`` und dem Format ``XRGB8888`` ein.
   
2. **Live-Vorschau**: Startet eine Live-Vorschau im ``QTGL``-Modus, die hardwarebeschleunigt angezeigt wird.

3. **Fotoaufnahme**: Nimmt ein Foto auf und speichert es im Home-Verzeichnis des Benutzers unter dem Namen ``my_photo.jpg``.

4. **Keyboard-Interrupt-Behandlung**: Bei ``KeyboardInterrupt`` (z. B. ``Ctrl+C``) wird die Vorschau sauber beendet.

**Understanding the Code**

1. **Imports:**

   Die ``picamera2``-Bibliothek wird genutzt, um die Kamera anzusprechen, das Modul ``os`` dient zur Verwaltung von Dateipfaden.

   .. code-block:: python

       from picamera2 import Picamera2, Preview
       import os

2. **Benutzerverzeichnis festlegen:**

   Ermittelt den aktuellen Benutzer und dessen Home-Verzeichnis, um dort das Foto zu speichern.

   .. code-block:: python

       user = os.getlogin()
       user_home = os.path.expanduser(f'~{user}')

3. **Kamerainitialisierung:**

   Erstellt eine ``Picamera2``-Instanz und lädt die Standard-Vorschaukonfiguration.

   .. code-block:: python

       camera = Picamera2()
       preview_config = camera.preview_configuration

4. **Vorschaukonfiguration einstellen:**

   Setzt die Vorschauauflösung auf 800x600 Pixel und das Format auf ``XRGB8888``.

   .. code-block:: python

       preview_config.size = (800, 600)
       preview_config.format = 'XRGB8888'

5. **Fotoaufnahme:**

   Startet die Kamera und speichert ein Foto als ``my_photo.jpg`` im Home-Verzeichnis des Benutzers.

   .. code-block:: python

       # camera.start_preview(Preview.QTGL)
       camera.start()
       camera.capture_file(f'{user_home}/my_photo.jpg')

6. **Sauberes Beenden:**

   Behandelt ``KeyboardInterrupt`` (z. B. durch Drücken von Ctrl+C), sodass die Vorschau ohne Absturz beendet wird.

   .. code-block:: python

       except KeyboardInterrupt:
           camera.stop_preview()
           pass

.. note::
   Für Serienaufnahmen kannst du eine ``for``-Schleife mit der ``capture``-Funktion verwenden und Intervalle zwischen den Aufnahmen definieren:

   .. code-block:: python

       for i in range(5):
           camera.capture(f'{user_home}/my_photo_{i}.jpg')

**Troubleshooting**

1. **Vorschaufenster wird nicht angezeigt**:

   - **Ursache**: Fehlende oder falsch konfigurierte Kameratreiber.  
   - **Lösung**:  

     - Stelle sicher, dass das Raspberry Pi Kameramodul korrekt angeschlossen und in ``raspi-config`` aktiviert ist.  
     - Führe ``sudo raspi-config`` aus, gehe zu ``Interface Options`` > ``Camera`` und aktiviere die Kamera.  

2. **Foto wird nicht gespeichert**:

   - **Ursache**: Falscher Dateipfad oder fehlende Berechtigungen.  
   - **Lösung**:  

     - Überprüfe den Pfad zum Home-Verzeichnis mit ``print(user_home)``.  
     - Stelle sicher, dass das Skript Schreibrechte für dieses Verzeichnis hat.  

3. **Fehler: ModuleNotFoundError: No Module Named 'picamera2'**:

   - **Ursache**: Die ``Picamera2``-Bibliothek ist nicht installiert.  
   - **Lösung**: Installiere die Bibliothek mit:  

   .. code-block:: shell

     sudo apt update
     sudo apt install -y python3-picamera2


4. **Kamerainitialisierung schlägt fehl**:

   - **Ursache**: Kamera wird nicht erkannt oder ist von einem anderen Prozess belegt.  
   - **Lösung**:  

     - Überprüfe aktive Kameraprozesse mit ``sudo lsof /dev/video*`` und beende ggf. störende Prozesse.  
     - Stelle sicher, dass die Kamera korrekt verbunden ist, und starte den Raspberry Pi neu.  

5. **QTGL Preview Mode Error**:

   - **Ursache**: Fehlende Abhängigkeiten für den ``QTGL``-Modus.  
   - **Lösung**: Installiere die benötigten Bibliotheken:  

   .. code-block:: shell

     sudo apt install -y qtbase5-dev


6. **Skript beendet sich nicht sauber**:

   - **Ursache**: Der ``try...except``-Block beendet die Kamera nicht korrekt.  
   - **Lösung**: Ergänze ``camera.stop()`` und ``camera.stop_preview()`` im ``except KeyboardInterrupt``-Block.  

   .. code-block:: python

       except KeyboardInterrupt:
           camera.stop_preview()
           camera.stop()
           pass

**Extendable Ideas**

1. **Timelapse-Aufnahmen**: Nimm Fotos in regelmäßigen Abständen auf und speichere sie mit Zeitstempeln:  

     .. code-block:: python

         import time
         for i in range(10):
             camera.capture_file(f'{user_home}/photo_{i}.jpg')
             time.sleep(5)

2. **Echtzeit-Filter**: Wende Filter wie Graustufen oder Kantenerkennung auf die Live-Vorschau an.  

3. **Individuelle Bildformate**: Speichere Fotos in anderen Formaten wie PNG oder BMP, indem du die ``capture_file``-Methode anpasst.  

4. **Dynamische Vorschau-Einstellungen**: Erlaube es dem Benutzer, Auflösung oder Helligkeit per Tasteneingabe anzupassen.
