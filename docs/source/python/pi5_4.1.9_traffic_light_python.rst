4.1.9 Traffic Light Simulation
==============================

**Introduction**

Dieses Projekt zeigt, wie mit LEDs und einer 4-stelligen 7-Segment-Anzeige ein Ampelsystem aus der Praxis simuliert werden kann. Die LEDs stehen für Rot, Gelb und Grün, während die 7-Segment-Anzeige die restliche Zeit je Signal herunterzählt. So lernst du auf anschauliche Weise GPIO-Steuerung, Timing und den Umgang mit 7-Segment-Anzeigen – ideal für Ausbildung und Prototyping.

**Writing the Code**

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat import Pin
   import threading

   # Setup GPIO pins for 74HC595 shift register
   SDI = Pin(17,Pin.OUT)   # Serial Data Input
   RCLK = Pin(4,Pin.OUT)  # Register Clock
   SRCLK = Pin(27,Pin.OUT) # Shift Register Clock

   # Define GPIO pins for digit selection on the 7-segment display
   placePin = [Pin(pin,Pin.OUT) for pin in (23, 24, 25, 12)]

   # Segment codes for numbers 0-9 on 7-segment display
   number = (0xc0, 0xf9, 0xa4, 0xb0, 0x99, 0x92, 0x82, 0xf8, 0x80, 0x90)

   # Setup GPIO pins for traffic light LEDs
   ledPinR = Pin(5,Pin.OUT) # Red LED
   ledPinG = Pin(6,Pin.OUT)  # Green LED
   ledPinY = Pin(13,Pin.OUT)  # Yellow LED

   # Duration settings for traffic lights
   greenLight = 30
   yellowLight = 5
   redLight = 60

   # Traffic light color names
   lightColor = ("Red", "Green", "Yellow")

   # Initialize state variables
   colorState = 0
   counter = 60
   timer1 = None

   def setup():
      """ Initialize the traffic light system and start the timer. """
      global timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()

   def clearDisplay():
      """ Clear the 7-segment display. """
      for _ in range(8):
         SDI.high()
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def hc595_shift(data):
      """ Shift data to the 74HC595 shift register for digit display. """
      for i in range(8):
         SDI.value(0x80 & (data << i))
         SRCLK.high()
         SRCLK.low()
      RCLK.high()
      RCLK.low()

   def pickDigit(digit):
      """ Select a specific digit to display on the 7-segment display. """
      for pin in placePin:
         pin.low()
      placePin[digit].high()

   def timer():
      """ Handle the timing for traffic light changes. """
      global counter, colorState, timer1
      timer1 = threading.Timer(1.0, timer)
      timer1.start()
      counter -= 1
      if counter == 0:
         counter = [greenLight, yellowLight, redLight][colorState]
         colorState = (colorState + 1) % 3
      print(f"counter : {counter}    color: {lightColor[colorState]}")

   def lightup():
      """ Update the traffic light LED based on the current state. """
      global colorState
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()
      [ledPinR, ledPinG, ledPinY][colorState].high()

   def display():
      """ Display the current counter value on the 7-segment display. """
      global counter

      for i in range(4):
         digit = counter // (10 ** (3 - i)) % 10
         if i == 0 and digit == 0:
               continue
         clearDisplay()
         pickDigit(i)
         hc595_shift(number[digit])

   def loop():
      """ Main loop to continuously update display and lights. """
      while True:
         display()
         lightup()

   def destroy():
      """ Clean up resources when the script is terminated. """
      global timer1
      timer1.cancel()
      ledPinR.low()
      ledPinG.low()
      ledPinY.low()

   try:
      setup()
      loop()
   except KeyboardInterrupt:
      destroy()

**Understanding the Code**

1. **Initialisierung:**

   * Richtet die GPIO-Pins für Schieberegister, 7-Segment-Anzeige und Ampel-LEDs ein.
   * Definiert die Dauer je Signalphase und initialisiert Statusvariablen.

2. **Funktionen für die 7-Segment-Anzeige:**

   * ``clearDisplay``: Löscht alle Segmente.
   * ``hc595_shift``: Sendet Daten an das Schieberegister zur Segmentsteuerung.
   * ``pickDigit``: Aktiviert für das Multiplexing die jeweilige Stelle.

3. **Timer-Funktion:**

   * Steuert den Countdown und die Übergänge zwischen den Lichtzuständen.

4. **Ampelsteuerung:**

   * Aktualisiert die LEDs entsprechend dem aktuellen Zustand.

5. **Hauptschleife:**

   * Aktualisiert kontinuierlich Anzeige und LEDs.

6. **Aufräumen:**

   * Gibt beim Beenden alle Ressourcen sauber frei.


----------------------------------------------


**Troubleshooting**

1. **Ampel-LEDs funktionieren nicht**:

   - **Ursache**: Falsche Verdrahtung oder defekte LEDs.
   - **Lösung**:

     - Prüfe die Anschlüsse an GPIO 5 (Rot), 6 (Grün) und 13 (Gelb).
     - Teste jede LED einzeln mit einem einfachen GPIO-Skript.

2. **7-Segment-Anzeige zählt nicht herunter**:

   - **Ursache**: Falsche Verdrahtung oder Schieberegister-Konfiguration.
   - **Lösung**:

     - Stelle sicher, dass ``SDI``, ``RCLK`` und ``SRCLK`` korrekt mit GPIO 17, 4 und 27 verbunden sind.
     - Prüfe, ob die Stellenauswahl-Pins zur ``placePin``-Konfiguration passen.

3. **Countdown friert ein**:

   - **Ursache**: Timer-Thread wird nicht erneut gestartet.
   - **Lösung**: Sicherstellen, dass ``timer()`` ``timer1.start()`` erneut aufruft.

4. **Falsche Phasendauern**:

   - **Ursache**: Unpassende Zeitwerte oder fehlerhafte Zustandsübergänge.
   - **Lösung**:

     - Prüfe die Werte für ``redLight``, ``greenLight`` und ``yellowLight``.
     - Kontrolliere die Logik in ``timer()`` für korrekte Übergänge.

**Extendable Ideas**

1. **Fußgängerüberweg**: Füge einen Taster hinzu, der den Zyklus kurz unterbricht und Fußgängern sicheres Queren ermöglicht.

   .. code-block:: python

      from fusion_hat import Pin
      pedestrian_button = Pin(22, Pin.IN, Pin.PULL_DOWN)

      def handle_pedestrian():
            global colorState, counter
            if colorState == 1:  # If Green Light
               counter = 5  # Shorten green light duration
      pedestrian_button.when_activated = handle_pedestrian

2. **Adaptive Steuerung**: Passe die Phasendauern dynamisch an die aktuelle Verkehrsdichte an.
