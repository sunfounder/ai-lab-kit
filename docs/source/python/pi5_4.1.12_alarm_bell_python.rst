4.1.12 Alarmglocke
======================

**Introduction**

In diesem Projekt bauen wir ein einfaches manuelles Alarmsystem mit Schiebeschalter, LEDs und einem Buzzer. Der Schalter löst den Alarm aus: Der Buzzer gibt einen Ton aus und die LEDs blinken abwechselnd. Alternativ kannst du den Schiebeschalter durch einen Thermistor oder einen Lichtsensor ersetzen, um daraus ein Temperatur- oder Lichtalarmsystem zu machen.

**Writing the Code**


Unten findest du den Python-Code für das Alarmsystem:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin,Buzzer,PWM
   import time
   import threading

   # Initialize TonalBuzzer on PWM 0
   BeepPin = Buzzer(PWM('P0'))  # Update this pin number based on your setup

   # Initialize LEDs on GPIO pins 22 and 27
   ALedPin = Pin(22,Pin.OUT)
   BLedPin = Pin(27,Pin.OUT)

   # Initialize Button on GPIO pin 17
   switchPin = Pin(17,Pin.IN, Pin.PULL_DOWN)

   # Global flag to control the buzzer and LED states
   flag = 0

   def ledWork():
      """
      Control LED blinking pattern based on the flag state.
      When flag is set, alternately blink ALedPin and BLedPin.
      """
      while True:
         if flag:
               # Alternate blinking of LEDs
               ALedPin.on()
               time.sleep(0.5)
               ALedPin.off()
               BLedPin.on()
               time.sleep(0.5)
               BLedPin.off()
         else:
               # Turn off both LEDs if flag is not set
               ALedPin.off()
               BLedPin.off()

   # Define the musical tune as a list of notes and their durations
   tune = [
      ('C4', 0.1), ('E4', 0.1), ('G4', 0.1), 
      (None, 0.1), 
      ('E4', 0.1), ('G4', 0.1), ('C5', 0.1), 
      (None, 0.1), 
      ('C5', 0.1), ('G4', 0.1), ('E4', 0.1), 
      (None, 0.1), 
      ('G4', 0.1), ('E4', 0.1), ('C4', 0.1), 
      (None, 0.1)
   ]

   def buzzerWork():
      """
      Play a tune using the buzzer based on the flag state.
      The tune is played only when the flag is set.
      """
      while True:
         for note, duration in tune:
               if flag == 0:
                  break
               print(note)  # Output the current note to the console
               BeepPin.play(note,duration)  # Play the current note
         BeepPin.off()  # Stop the buzzer after playing the tune

   def main():
      """
      Monitor button press to update the flag state.
      Sets the flag when the button is pressed.
      """
      global flag
      while True:
         flag = 1 if switchPin.value()==1 else 0


   try:
      # Initialize and start threads for buzzer and LED control
      tBuzz = threading.Thread(target=buzzerWork)
      tBuzz.start()
      tLed = threading.Thread(target=ledWork)
      tLed.start()
      main()

   except KeyboardInterrupt:
      # Stop the buzzer and turn off LEDs on program interruption
      BeepPin.off()
      ALedPin.off()    
      BLedPin.off()


Dieses Python-Skript realisiert ein Alarmsystem mit LEDs, Buzzer und Schalter. Die Funktionsweise:

1. **Alarmaktivierung**: Wird der Button (``switchPin``) gedrückt, wird der Alarm ausgelöst:
   
   - **LEDs**: Die beiden LEDs (``ALedPin`` und ``BLedPin``) blinken abwechselnd im 0,5-Sekunden-Takt.  
   - **Buzzer**: Der Buzzer spielt fortlaufend eine vordefinierte Melodie.

2. **Alarmdeaktivierung**: Beim Loslassen des Buttons wird der Alarm sofort beendet:
   
   - Die LEDs gehen aus.  
   - Der Buzzer verstummt.

3. **Multithreading**: LEDs und Buzzer laufen in separaten Threads für flüssiges, reaktionsschnelles Verhalten.

4. **Kontinuierliche Überwachung**: Der Button-Zustand wird permanent abgefragt und der Alarm entsprechend ein- bzw. ausgeschaltet.

5. **Sauberes Beenden**: Bei ``Ctrl+C`` werden alle Ausgaben gestoppt und die LEDs sowie der Buzzer ausgeschaltet.


----------------------------------------------


**Understanding the Code**

1. **Komponenten-Setup:**
   
   * Der Buzzer ist an P0 angeschlossen.  
   * Zwei LEDs liegen an GPIO 22 und 27.  
   * Ein Button an GPIO 17 dient als Schalter.

2. **Globales Flag:**
   
   Die Variable ``flag`` steuert den Alarmzustand. Bei gedrücktem Schalter ist ``flag`` = 1 und Buzzer/LEDs werden aktiviert.

3. **LED-Blinkmuster:**
   
   Die Funktion ``ledWork`` lässt die LEDs abwechselnd blinken, solange ``flag`` gesetzt ist.

4. **Buzzer-Melodie:**
   
   ``buzzerWork`` spielt eine vordefinierte Tonfolge. Wird ``flag`` zurückgesetzt, stoppt die Wiedergabe sofort.

5. **Main-Funktion:**
   
   Überwacht fortlaufend den Button und setzt das Flag entsprechend.

6. **Threads:**
   
   ``ledWork`` und ``buzzerWork`` laufen parallel in eigenen Threads.



----------------------------------------------

**Troubleshooting**

1. **LEDs blinken nicht**:

   - **Ursache**: Falsche Verdrahtung oder GPIO-Konfiguration.  
   - **Lösung**:

     - Prüfe die Anschlüsse von ``ALedPin`` (GPIO 22) und ``BLedPin`` (GPIO 27).
     - Teste beide LEDs mit einem einfachen GPIO-Skript.

2. **Buzzer gibt keinen Ton aus**:

   - **Ursache**: Fehlerhafte Verbindung oder falscher Pin.  
   - **Lösung**:

     - Stelle sicher, dass der Buzzer an P0 und GND hängt.
     - Teste den Buzzer mit einem einzelnen Ton via ``BeepPin.play()``.

3. **Button schaltet den Alarm nicht**:

   - **Ursache**: Falsche Verdrahtung oder Pin-Mismatch.  
   - **Lösung**:

     - Prüfe den Anschluss des Buttons an GPIO 17.
     - Verifiziere, dass der Button den Stromkreis beim Drücken schließt.

4. **Hohe CPU-Auslastung**:

   - **Ursache**: Threads laufen ohne Pause, wenn der Alarm aus ist.  
   - **Lösung**: Kleine Verzögerung einfügen, wenn ``flag`` = 0:

   .. code-block:: python

      if not flag:
            time.sleep(0.1)

5. **Buzzer spielt falsche Noten**:

   - **Ursache**: Fehler in ``tune`` oder im Timing.  
   - **Lösung**: Prüfe die Paare aus Note und Dauer in der ``tune``-Liste.

**Extendable Ideas**

1. **Einstellbare Alarmdauer**: Füge einen Timer hinzu, der die aktive Alarmzeit begrenzt.

2. **Status-LED**: Eine zusätzliche LED zeigt an, ob der Alarm scharf geschaltet ist.

3. **Mehrere Alarmmodi**: Unterschiedliche Blink-/Tonmuster je nach Auslöser oder Nutzereingabe.

4. **Eigene Melodie**: Erlaube das Einspielen benutzerdefinierter Tonfolgen.

5. **Notabschaltung**: Ein zweiter Button zum sofortigen Deaktivieren des Alarms.


----------------------------------------------

**Conclusion**

Dieses Projekt zeigt, wie sich grundlegende Elektronikkomponenten zu einem Alarmsystem kombinieren lassen. Durch Austausch des Eingabesensors (z. B. Thermistor oder Lichtsensor) kann es leicht zu einem Temperatur- oder Lichtalarm erweitert werden. Probiere weitere Varianten aus und passe das System an deine Anforderungen an!
