1.1.7 I2C LCD1602
======================

**Introduction**

Das LCD1602 ist ein 16×2-Zeichen-LCD, das bis zu 32 Zeichen gleichzeitig darstellen kann. Es nutzt das I2C-Kommunikationsprotokoll und reduziert dadurch die Anzahl benötigter GPIO-Pins. In diesem Projekt zeigen wir, wie Sie das LCD1602 ansteuern, um Textnachrichten anzuzeigen.

**Writing the Code**

Das folgende Python-Skript initialisiert das LCD1602 und zeigt eine einfache Begrüßung an:


.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat import LCD1602
   from time import sleep

   lcd = LCD1602(address=0x27, backlight=1)

   while True:
      lcd.clear()
      lcd.write(0, 0, 'Greetings!')
      lcd.write(1, 1, 'From SunFounder')
      sleep(1)
      lcd.clear()
      lcd.message('Hello\n   World!')
      sleep(1)

Dieses Skript steuert ein LCD1602-Modul über I2C und zeigt kurze Nachrichten an. Beim Ausführen gilt:

1. Das LCD1602 wird mit der Standard-I2C-Adresse ``0x27`` initialisiert.
2. In der ersten Zeile erscheint „Greetings!“.
3. In der zweiten Zeile steht „From SunFounder“.
4. Jede Nachricht bleibt 1 Sekunde sichtbar, bevor die nächste angezeigt wird.

Das Display wird geleert, wenn Sie das Skript mit ``Ctrl+C`` unterbrechen.


----------------------------------------------

**Understanding the Code**

1. **Library Import**

   Die Klasse ``LCD1602`` vereinfacht die Ansteuerung des I2C-Displays. Sie stellt Funktionen zur Initialisierung und Textausgabe bereit.

   .. code-block:: python

      from fusion_hat import LCD1602

2. **Initialization**

   Initialisiert das LCD mit der I2C-Adresse (in der Regel 0x27). Die Hintergrundbeleuchtung wird dabei aktiviert.

   .. code-block:: python

      lcd = LCD1602(address=0x27, backlight=1)

3. **Displaying Text**

   .. code-block:: python

      lcd.clear()
      lcd.write(0, 0, 'Greetings!')
      lcd.write(1, 1, 'From SunFounder')
      sleep(1)
      lcd.clear()
      lcd.message('Hello\n   World!')
      sleep(1)

   * Mit ``write`` wird Text an einer bestimmten Position ausgegeben (Zeile, Spalte, Text).  
   * Mit ``message`` können mehrzeilige Texte dargestellt werden; die Zeilen werden automatisch umgebrochen.  
   * ``clear`` löscht den Display-Inhalt.

----------------------------------------------

**Troubleshooting**

1. **Kein Text auf dem Display**  

   - **Ursache**: Falsche I2C-Adresse oder Verdrahtungsfehler.  
   - **Lösung**: Prüfen Sie die I2C-Adresse des Moduls (mit ``i2cdetect -y 1`` auf dem Raspberry Pi) und stellen Sie sicher, dass SDA und SCL korrekt angeschlossen sind.

2. **Hintergrundbeleuchtung funktioniert nicht**  

   - **Ursache**: Fehlerhafte Einstellung oder Verdrahtungsproblem.  
   - **Lösung**: Überprüfen Sie die Verbindung und stellen Sie sicher, dass der Parameter ``backlight`` korrekt gesetzt ist.

3. **Probleme mit der Textausrichtung**  

   - **Ursache**: Falsche Spalten- oder Zeilenangabe in ``write()``.  
   - **Lösung**: Passen Sie die Parameter ``write(row, column, text)`` an, um den Text richtig auszurichten.

**Extendable Ideas**

1. **Eigene Nachrichten**  

   Lassen Sie Benutzer eigene Texte eingeben, die auf dem LCD angezeigt werden:

   .. code-block:: python

      user_message1 = input("Enter first line: ")
      user_message2 = input("Enter second line: ")
      lcd.write(0, 0, user_message1)
      lcd.write(1, 0, user_message2)


2. **Echtzeituhr-Anzeige**  

   Zeigen Sie Datum und Uhrzeit dynamisch an:


   .. code-block:: python

      import datetime
      while True:
         now = datetime.datetime.now()
         lcd.write(0, 0, now.strftime("%H:%M:%S"))
         lcd.write(1, 0, now.strftime("%d-%m-%Y"))
         time.sleep(1)


3. **Interaktive Anzeige**  

   Nutzen Sie Tasten oder Sensoren, um zwischen vordefinierten Nachrichten umzuschalten.

4. **Lauftext**

   .. code-block:: python

      def scroll_text(row, message, delay=0.3):
         for i in range(len(message) - 16 + 1):
            lcd.write(row, 0, message[i:i+16])
            time.sleep(delay)


5. **Dynamische Hintergrundbeleuchtung**
