4.7 Smarter Ventilator
=========================

**Einführung**

In diesem Projekt bauen Sie einen „smarten Ventilator", der sowohl im manuellen als auch im automatischen Modus betrieben werden kann. Durch die Kombination von Motor, Tastern und einem Thermistor kann der Ventilator verschiedene Geschwindigkeiten einstellen und auf Temperaturänderungen reagieren. Dieses Experiment eignet sich hervorragend, um Motorsteuerung, Temperaturmessung und die Nutzung von GPIO kennenzulernen.

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   markTemp = None

   last_button_state = 0
   last_press_time = 0
   _last_print = 0.0

   DEBOUNCE_TIME = 0.3
   PRINT_INTERVAL = 1.0
   MANUAL_HOLD_TIME = 2.0
   TEMP_THRESHOLD = 5.0


   def temperature(samples=5, delay=0.01):
       """Read thermistor temperature and return average Celsius value."""

       vals = []

       for _ in range(samples):
           analogVal = thermistor.read()
           Vr = 3.3 * float(analogVal) / 4095.0

           if Vr <= 0 or (3.3 - Vr) <= 0.1:
               sleep(delay)
               continue

           Rt = 10000.0 * Vr / (3.3 - Vr)

           if Rt <= 0:
               sleep(delay)
               continue

           tempK = 1.0 / (
               ((math.log(Rt / 10000.0)) / 3950.0)
               + (1.0 / (273.15 + 25.0))
           )

           vals.append(tempK - 273.15)
           sleep(delay)

       if not vals:
           return None

       return sum(vals) / len(vals)


   def motor_run(lv):
       """Set motor power according to level."""

       lv = max(0, min(4, lv))
       power_table = [0, 25, 50, 75, 100]
       motor.power(power_table[lv])

       return lv


   def read_button():
       """Read current button state."""

       try:
           return BtnPin.value()
       except TypeError:
           return BtnPin.value


   def main():
       """Main loop for button control and temperature auto adjustment."""

       global level, markTemp, last_button_state, last_press_time, _last_print

       while markTemp is None:
           markTemp = temperature()
           sleep(0.1)

       while True:
           now = time()

           button_state = read_button()

           if button_state == 1 and last_button_state == 0:
               if now - last_press_time >= DEBOUNCE_TIME:
                   old = level
                   level = (level + 1) % 5
                   last_press_time = now

                   currentTemp = temperature()
                   if currentTemp is not None:
                       markTemp = currentTemp

                   level = motor_run(level)

                   print(
                       f"[Button] {old} -> {level} | "
                       f"Power: {0 if level == 0 else level * 25}%"
                   )

           last_button_state = button_state

           currentTemp = temperature()

           if currentTemp is None:
               print("Sensor read failed.")
               sleep(0.5)
               continue

           auto_allowed = (now - last_press_time) >= MANUAL_HOLD_TIME

           if auto_allowed and level != 0:
               diff = currentTemp - markTemp

               if diff >= TEMP_THRESHOLD:
                   level = min(4, level + 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp up -> Level {level}")

               elif diff <= -TEMP_THRESHOLD:
                   level = max(0, level - 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp down -> Level {level}")

           if now - _last_print >= PRINT_INTERVAL:
               print(
                   f"Temp: {currentTemp:.2f} C | "
                   f"Mark: {markTemp:.2f} C | "
                   f"Level: {level}"
               )
               _last_print = now

           level = motor_run(level)

           sleep(0.05)


   try:
       main()

   except KeyboardInterrupt:
       print("\nExiting...")

   finally:
       motor.stop()
       sleep(0.1)



Dieses Python-Skript kombiniert einen Motor, einen Taster und einen Temperatursensor zu einem temperaturgesteuerten Ventilatorsystem mit einstellbarer Geschwindigkeit. Bei der Ausführung:

1. **Temperaturmessung**: Liest die aktuelle Temperatur in Celsius mithilfe des Thermistors. Mehrere Messwerte werden für die Genauigkeit gemittelt, und ungültige Messwerte werden übersprungen, anstatt sofort einen Fehler zu verursachen.

2. **Manuelle Geschwindigkeitsanpassung**:

   - Ein Taster, der mit GPIO 22 verbunden ist, ermöglicht es dem Benutzer, zwischen fünf Geschwindigkeitsstufen (0 bis 4) zu wechseln.
   - Jeder Tastendruck erhöht die Geschwindigkeitsstufe, und der Motor läuft mit der entsprechenden Leistung (0%, 25%, 50%, 75% oder 100%). Stufe 0 stoppt den Motor.
   - Die Tastereingabe verfügt über einen **Entprellschutz** (0,3 Sekunden), um Fehlauslösungen durch Kontaktprellen zu verhindern.

3. **Manuelles Prioritätsfenster**: Nach einem Tastendruck wird die automatische Geschwindigkeitsanpassung für **2 Sekunden** (``MANUAL_HOLD_TIME``) unterdrückt. Dies stellt sicher, dass die manuelle Einstellung des Benutzers nicht sofort durch eine automatische Anpassung überschrieben wird.

4. **Automatische Geschwindigkeitsregelung**: Nach Ablauf des manuellen Prioritätsfensters (und wenn der Ventilator nicht ausgeschaltet ist) passt das System die Motorgeschwindigkeit automatisch an Temperaturänderungen an:

   - Wenn die Temperatur um **5°C** oder mehr steigt, erhöht sich die Geschwindigkeitsstufe (bis maximal Stufe 4).
   - Wenn die Temperatur um **5°C** oder mehr sinkt, verringert sich die Geschwindigkeitsstufe (bis minimal Stufe 0).

5. **Kontinuierliche Überwachung**: Das System überwacht kontinuierlich die Temperatur und den Tasterzustand mit einem schnellen 0,05-Sekunden-Schleifenintervall und gewährleistet so reaktionsschnelle Anpassungen.

6. **Sauberes Beenden**: Bei ``Ctrl+C`` wird der Motor gestoppt, und das Skript wird ordnungsgemäß beendet.

**Code verstehen**

1. **Temperaturberechnung:**

   .. code-block:: python

      def temperature(samples=5, delay=0.01):

   Die Funktion ``temperature()`` nimmt mehrere Messwerte vom Thermistor auf, wandelt jeden Analogwert in einen Widerstandswert um und berechnet die Temperatur in Celsius mithilfe der Steinhart-Hart-Gleichung. Einzelne fehlerhafte Messwerte (Spannung zu niedrig oder Widerstand null) werden mittels ``continue`` **übersprungen**, anstatt die gesamte Messung fehlschlagen zu lassen. Nur wenn **alle** Messwerte ungültig sind, gibt die Funktion ``None`` zurück. Das Endergebnis ist der arithmetische Mittelwert aller gültigen Messwerte und liefert eine stabile und rauschresistente Messung.


2. **Motor-Geschwindigkeitssteuerung:**

   .. code-block:: python

      def motor_run(lv):
          """Set motor power according to level."""

          lv = max(0, min(4, lv))
          power_table = [0, 25, 50, 75, 100]
          motor.power(power_table[lv])

          return lv


   Die Funktion ``motor_run()`` ordnet die numerische Stufe (0–4) mithilfe einer Lookup-Tabelle einem Prozentsatz der Motorleistung zu. Stufe 0 sendet 0% Leistung (aus), während die Stufen 1 bis 4 jeweils 25%, 50%, 75% und 100% Leistung entsprechen. Die Stufe wird zunächst mit ``max(0, min(4, lv))`` auf den gültigen Bereich begrenzt.


3. **Tasterabfrage mit Entprellung:**

   .. code-block:: python

   Anstatt einen Interrupt-Callback zu verwenden, **pollt** der Code den Tasterzustand in der Hauptschleife. Ein Tastendruck wird durch eine **steigende Flanke** erkannt: Der Tasterzustand wechselt von ``0`` auf ``1`` (``last_button_state == 0`` → ``button_state == 1``). Ein **Entprell-Timer** (``DEBOUNCE_TIME = 0,3`` Sekunden) verhindert, dass Kontaktprellen mehrere Auslösungen verursacht. Wenn ein gültiger Tastendruck erkannt wird, wechselt die Stufe zyklisch 0→1→2→3→4→0, die Referenztemperatur (``markTemp``) wird aktualisiert und die Motorgeschwindigkeit wird sofort übernommen.


4. **Hauptschleife und automatische Anpassung:**

   .. code-block:: python

              # ... periodische Ausgabe ...

   Die Funktion ``main()`` führt eine schnelle Regelschleife (0,05-Sekunden-Intervall) aus. Wichtige Verhaltensweisen:

   - **Initialisierung**: Sie liest wiederholt die Temperatur, bis ein gültiger ``markTemp`` ermittelt wurde, um sicherzustellen, dass das System mit einer bekannten Referenz startet.

   - **Manuelle Priorität**: Nach einem Tastendruck werden automatische Anpassungen für ``MANUAL_HOLD_TIME`` (2 Sekunden) blockiert. Diese ``auto_allowed``-Sperre verhindert, dass das System die manuelle Änderung des Benutzers sofort konterkariert.

   - **Automatische Anpassung**: Wenn die Automatik erlaubt ist und der Ventilator nicht auf Stufe 0 steht, prüft der Code, ob die aktuelle Temperatur um ``TEMP_THRESHOLD`` (±5°C) von der Referenz abgewichen ist. Falls ja, wird die Stufe um eins erhöht oder verringert und die Referenz auf die aktuelle Temperatur zurückgesetzt — dies erzeugt ein **rastendes** Verhalten, das Oszillation um den Schwellwert verhindert.

   - **Periodische Ausgabe**: Alle ``PRINT_INTERVAL`` (1 Sekunde) werden die aktuelle Temperatur, die Referenztemperatur und die Stufe zur Überwachung ausgegeben.

**Fehlerbehebung**

1. **Motor läuft nicht**:

   - **Ursache**: Falsche Verdrahtung oder unzureichende Stromversorgung.
   - **Lösung**:

     - Überprüfen Sie, ob der Motor mit M0 verbunden ist.
     - Stellen Sie sicher, dass die Stromversorgung des Motors zu seiner erforderlichen Betriebsspannung passt.

2. **Temperaturmessung ist ungenau**:

   - **Ursache**: Defekter Thermistor.
   - **Lösung**:

     - Überprüfen Sie die Verdrahtung des Thermistors und stellen Sie sicher, dass er innerhalb des vorgesehenen Messbereichs arbeitet.

3. **Tastendruck wird nicht erkannt**:

   - **Ursache**: Falsche Verdrahtung oder falsche GPIO-Konfiguration.
   - **Lösung**:

     - Überprüfen Sie, ob der Taster mit GPIO 22 und GND verbunden ist.
     - Testen Sie den Taster separat, um sicherzustellen, dass er beim Drücken den Stromkreis schließt.

4. **Geschwindigkeitsstufe ändert sich nicht automatisch**:

   - **Ursache**: Fehler bei der Berechnung der Temperaturdifferenz.
   - **Lösung**: Stellen Sie sicher, dass die Werte ``currentTemp`` und ``markTemp`` in der Funktion ``main()`` korrekt aktualisiert werden.
