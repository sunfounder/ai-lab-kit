4.7 Ventilador Inteligente
============================

**Introducción**

En este proyecto, construirás un "ventilador inteligente" que funciona tanto en modo manual como automático. Combinando motores, botones y un termistor, el ventilador puede tener velocidades de viento ajustables y responder a cambios de temperatura. Esto lo convierte en un experimento perfecto para aprender sobre control de motores, detección de temperatura y uso de GPIO.

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   markTemp = None

   last_button_state = 0
   last_press_time = 0
   _last_print = 0.0

   DEBOUNCE_TIME = 0.3
   PRINT_INTERVAL = 1.0
   MANUAL_HOLD_TIME = 2.0
   TEMP_THRESHOLD = 5.0


   def temperature(samples=5, delay=0.01):
       """Read thermistor temperature and return average Celsius value."""

       vals = []

       for _ in range(samples):
           analogVal = thermistor.read()
           Vr = 3.3 * float(analogVal) / 4095.0

           if Vr <= 0 or (3.3 - Vr) <= 0.1:
               sleep(delay)
               continue

           Rt = 10000.0 * Vr / (3.3 - Vr)

           if Rt <= 0:
               sleep(delay)
               continue

           tempK = 1.0 / (
               ((math.log(Rt / 10000.0)) / 3950.0)
               + (1.0 / (273.15 + 25.0))
           )

           vals.append(tempK - 273.15)
           sleep(delay)

       if not vals:
           return None

       return sum(vals) / len(vals)


   def motor_run(lv):
       """Set motor power according to level."""

       lv = max(0, min(4, lv))
       power_table = [0, 25, 50, 75, 100]
       motor.power(power_table[lv])

       return lv


   def read_button():
       """Read current button state."""

       try:
           return BtnPin.value()
       except TypeError:
           return BtnPin.value


   def main():
       """Main loop for button control and temperature auto adjustment."""

       global level, markTemp, last_button_state, last_press_time, _last_print

       while markTemp is None:
           markTemp = temperature()
           sleep(0.1)

       while True:
           now = time()

           button_state = read_button()

           if button_state == 1 and last_button_state == 0:
               if now - last_press_time >= DEBOUNCE_TIME:
                   old = level
                   level = (level + 1) % 5
                   last_press_time = now

                   currentTemp = temperature()
                   if currentTemp is not None:
                       markTemp = currentTemp

                   level = motor_run(level)

                   print(
                       f"[Button] {old} -> {level} | "
                       f"Power: {0 if level == 0 else level * 25}%"
                   )

           last_button_state = button_state

           currentTemp = temperature()

           if currentTemp is None:
               print("Sensor read failed.")
               sleep(0.5)
               continue

           auto_allowed = (now - last_press_time) >= MANUAL_HOLD_TIME

           if auto_allowed and level != 0:
               diff = currentTemp - markTemp

               if diff >= TEMP_THRESHOLD:
                   level = min(4, level + 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp up -> Level {level}")

               elif diff <= -TEMP_THRESHOLD:
                   level = max(0, level - 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp down -> Level {level}")

           if now - _last_print >= PRINT_INTERVAL:
               print(
                   f"Temp: {currentTemp:.2f} C | "
                   f"Mark: {markTemp:.2f} C | "
                   f"Level: {level}"
               )
               _last_print = now

           level = motor_run(level)

           sleep(0.05)


   try:
       main()

   except KeyboardInterrupt:
       print("\nExiting...")

   finally:
       motor.stop()
       sleep(0.1)



Este script de Python integra un motor, un botón y un sensor de temperatura para crear un sistema de ventilador controlado por temperatura con velocidad ajustable. Cuando se ejecuta:

1. **Detección de Temperatura**: Lee la temperatura actual en grados Celsius usando el termistor. Se promedian múltiples muestras para mayor precisión, y las lecturas no válidas se omiten en lugar de causar un fallo inmediato.

2. **Ajuste Manual de Velocidad**:

   - Un botón conectado a GPIO 22 permite al usuario recorrer cinco niveles de velocidad (0 a 4).
   - Presionar el botón aumenta el nivel de velocidad, y el motor funciona a la potencia correspondiente (0%, 25%, 50%, 75% o 100%). El nivel de velocidad 0 detiene el motor.
   - La entrada del botón incluye **protección anti-rebote** (0.3 segundos) para evitar disparos falsos por rebote de contacto.

3. **Ventana de Prioridad Manual**: Después de presionar un botón, el ajuste automático de velocidad se suprime durante **2 segundos** (``MANUAL_HOLD_TIME``). Esto asegura que la configuración manual del usuario no sea anulada inmediatamente por un ajuste automático.

4. **Control Automático de Velocidad**: Después de que expira la ventana de prioridad manual (y cuando el ventilador no está apagado), el sistema ajusta la velocidad del motor automáticamente según los cambios de temperatura:

   - Si la temperatura aumenta en **5°C** o más, el nivel de velocidad aumenta (hasta el nivel 4).
   - Si la temperatura disminuye en **5°C** o más, el nivel de velocidad disminuye (hasta el nivel 0).

5. **Monitoreo Continuo**: El sistema monitorea continuamente la temperatura y el estado del botón con un intervalo de bucle rápido de 0.05 segundos, asegurando ajustes receptivos.

6. **Salida Ordenada**: Al presionar ``Ctrl+C``, el motor se detiene y el script termina limpiamente.

**Comprender el Código**

1. **Cálculo de Temperatura:**

   .. code-block:: python

      def temperature(samples=5, delay=0.01):
          """Read thermistor temperature and return average Celsius value."""

          vals = []

          for _ in range(samples):
              analogVal = thermistor.read()
              Vr = 3.3 * float(analogVal) / 4095.0

              if Vr <= 0 or (3.3 - Vr) <= 0.1:
                  sleep(delay)
                  continue

              Rt = 10000.0 * Vr / (3.3 - Vr)

              if Rt <= 0:
                  sleep(delay)
                  continue

              tempK = 1.0 / (
                  ((math.log(Rt / 10000.0)) / 3950.0)
                  + (1.0 / (273.15 + 25.0))
              )

              vals.append(tempK - 273.15)
              sleep(delay)

          if not vals:
              return None

          return sum(vals) / len(vals)


   La función ``temperature()`` toma múltiples muestras del termistor, convierte cada lectura analógica en un valor de resistencia y calcula la temperatura en grados Celsius usando la ecuación de Steinhart-Hart. Las lecturas individuales incorrectas (voltaje demasiado bajo o resistencia cero) se **saltan** mediante ``continue`` en lugar de hacer fallar toda la medición. Solo si **todas** las muestras son inválidas, la función retorna ``None``. El resultado final es la media aritmética de todas las muestras válidas, proporcionando una lectura estable y resistente al ruido.


2. **Control de Velocidad del Motor:**

   .. code-block:: python

      def motor_run(lv):
          """Set motor power according to level."""

          lv = max(0, min(4, lv))
          power_table = [0, 25, 50, 75, 100]
          motor.power(power_table[lv])

   La función ``motor_run()`` asigna el nivel numérico (0–4) a un porcentaje de potencia del motor usando una tabla de consulta. El nivel 0 envía 0% de potencia (apagado), mientras que los niveles 1 a 4 corresponden a 25%, 50%, 75% y 100% de potencia respectivamente. El nivel se limita primero al rango válido con ``max(0, min(4, lv))``.


3. **Lectura del Botón con Anti-Rebote:**

   .. code-block:: python

      def read_button():

   En lugar de usar una devolución de llamada de interrupción, el código **sondea** el estado del botón en el bucle principal. Una pulsación se detecta por un **flanco ascendente**: la transición del estado del botón de ``0`` a ``1`` (``last_button_state == 0`` → ``button_state == 1``). Un **temporizador anti-rebote** (``DEBOUNCE_TIME = 0.3`` segundos) evita que el rebote de contacto genere múltiples pulsaciones. Cuando se detecta una pulsación válida, el nivel avanza cíclicamente 0→1→2→3→4→0, la temperatura de referencia (``markTemp``) se actualiza y la velocidad del motor se aplica inmediatamente.


4. **Bucle Principal y Ajuste Automático:**

   La función ``main()`` ejecuta un bucle de control rápido (intervalo de 0.05 segundos). Comportamientos clave:

   - **Inicialización**: Lee la temperatura repetidamente hasta obtener un ``markTemp`` válido, asegurando que el sistema comience con una referencia conocida.

   - **Prioridad Manual**: Después de una pulsación de botón, los ajustes automáticos se bloquean durante ``MANUAL_HOLD_TIME`` (2 segundos). Esta compuerta ``auto_allowed`` evita que el sistema contrarreste inmediatamente el cambio manual del usuario.

   - **Ajuste Automático**: Cuando el ajuste automático está permitido y el ventilador no está en nivel 0, el código verifica si la temperatura actual se ha desviado en ``TEMP_THRESHOLD`` (±5°C) de la referencia. Si es así, el nivel se incrementa o disminuye en uno, y la referencia se restablece a la temperatura actual — esto crea un comportamiento de **enclavamiento** que evita la oscilación alrededor del umbral.

   - **Salida Periódica**: Cada ``PRINT_INTERVAL`` (1 segundo), se imprimen la temperatura actual, la temperatura de referencia y el nivel para monitoreo.

**Solución de Problemas**

1. **El Motor No Funciona**:

   - **Causa**: Cableado incorrecto o alimentación insuficiente.
   - **Solución**:

     - Verifica que el motor esté conectado a M0.
     - Asegúrate de que la fuente de alimentación del motor coincida con sus requisitos de voltaje.

2. **La Lectura de Temperatura es Incorrecta**:

   - **Causa**: Termistor defectuoso.
   - **Solución**:

     - Verifica el cableado del termistor y asegúrate de que esté dentro del rango especificado.

3. **No Se Detecta la Pulsación del Botón**:

   - **Causa**: Cableado incorrecto del botón o configuración de GPIO.
   - **Solución**:

     - Verifica que el botón esté conectado a GPIO 22 y a tierra.
     - Prueba el botón de forma independiente para confirmar que cierra el circuito al presionarlo.

4. **El Nivel de Velocidad No Cambia Automáticamente**:

   - **Causa**: Cálculo incorrecto de la diferencia de temperatura.
   - **Solución**: Asegúrate de que los valores ``currentTemp`` y ``markTemp`` se actualicen correctamente en la función ``main()``.
