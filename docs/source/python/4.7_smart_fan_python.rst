4.7 智能风扇
============

**简介**

在本项目中，您将构建一个兼具手动和自动模式的"智能风扇"。通过组合电机、按钮和热敏电阻，风扇可以实现可调风速并响应温度变化。这使其成为学习电机控制、温度感应和 GPIO 使用的理想实验。

**代码**

以下是本项目的 Python 脚本：



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   markTemp = None

   last_button_state = 0
   last_press_time = 0
   _last_print = 0.0

   DEBOUNCE_TIME = 0.3
   PRINT_INTERVAL = 1.0
   MANUAL_HOLD_TIME = 2.0
   TEMP_THRESHOLD = 5.0


   def temperature(samples=5, delay=0.01):
       """Read thermistor temperature and return average Celsius value."""

       vals = []

       for _ in range(samples):
           analogVal = thermistor.read()
           Vr = 3.3 * float(analogVal) / 4095.0

           if Vr <= 0 or (3.3 - Vr) <= 0.1:
               sleep(delay)
               continue

           Rt = 10000.0 * Vr / (3.3 - Vr)

           if Rt <= 0:
               sleep(delay)
               continue

           tempK = 1.0 / (
               ((math.log(Rt / 10000.0)) / 3950.0)
               + (1.0 / (273.15 + 25.0))
           )

           vals.append(tempK - 273.15)
           sleep(delay)

       if not vals:
           return None

       return sum(vals) / len(vals)


   def motor_run(lv):
       """Set motor power according to level."""

       lv = max(0, min(4, lv))
       power_table = [0, 25, 50, 75, 100]
       motor.power(power_table[lv])

       return lv


   def read_button():
       """Read current button state."""

       try:
           return BtnPin.value()
       except TypeError:
           return BtnPin.value


   def main():
       """Main loop for button control and temperature auto adjustment."""

       global level, markTemp, last_button_state, last_press_time, _last_print

       while markTemp is None:
           markTemp = temperature()
           sleep(0.1)

       while True:
           now = time()

           button_state = read_button()

           if button_state == 1 and last_button_state == 0:
               if now - last_press_time >= DEBOUNCE_TIME:
                   old = level
                   level = (level + 1) % 5
                   last_press_time = now

                   currentTemp = temperature()
                   if currentTemp is not None:
                       markTemp = currentTemp

                   level = motor_run(level)

                   print(
                       f"[Button] {old} -> {level} | "
                       f"Power: {0 if level == 0 else level * 25}%"
                   )

           last_button_state = button_state

           currentTemp = temperature()

           if currentTemp is None:
               print("Sensor read failed.")
               sleep(0.5)
               continue

           auto_allowed = (now - last_press_time) >= MANUAL_HOLD_TIME

           if auto_allowed and level != 0:
               diff = currentTemp - markTemp

               if diff >= TEMP_THRESHOLD:
                   level = min(4, level + 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp up -> Level {level}")

               elif diff <= -TEMP_THRESHOLD:
                   level = max(0, level - 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp down -> Level {level}")

           if now - _last_print >= PRINT_INTERVAL:
               print(
                   f"Temp: {currentTemp:.2f} C | "
                   f"Mark: {markTemp:.2f} C | "
                   f"Level: {level}"
               )
               _last_print = now

           level = motor_run(level)

           sleep(0.05)


   try:
       main()

   except KeyboardInterrupt:
       print("\nExiting...")

   finally:
       motor.stop()
       sleep(0.1)



此 Python 脚本集成了电机、按钮和温度传感器，创建了一个带可调速度的温控风扇系统。运行时：

1. **温度感应**：使用热敏电阻读取当前摄氏度温度。多次采样取平均值以提高准确性，无效读数会被跳过而不是立即导致失败。

2. **手动速度调节**：

   - 连接到 GPIO 22 的按钮允许用户在五个速度级别（0 到 4）之间循环。
   - 按下按钮增加速度级别，电机以相应的功率运行（0%、25%、50%、75% 或 100%）。速度级别 0 停止电机。
   - 按钮输入包含**去抖动保护**（0.3 秒），防止触点抖动引起的误触发。

3. **手动优先窗口**：按下按钮后，自动速度调整被抑制 **2 秒**\ （``MANUAL_HOLD_TIME``）。这确保用户的手动设置不会立即被自动调整覆盖。

4. **自动速度控制**：手动优先窗口过期后（且风扇未关闭时），系统会根据温度变化自动调整电机速度：

   - 如果温度升高 **5°C** 或更多，速度级别增加（最高到级别 4）。
   - 如果温度降低 **5°C** 或更多，速度级别降低（最低到级别 0）。

5. **持续监控**：系统以 0.05 秒的快速循环间隔持续监控温度和按钮状态，确保响应及时的调整。

6. **优雅退出**：按下 ``Ctrl+C`` 时，电机停止，脚本安全退出。

**理解代码**

1. **温度计算：**

   .. code-block:: python

      def temperature(samples=5, delay=0.01):

   ``temperature()`` 函数从热敏电阻采集多个样本，将每个模拟读数转换为电阻值，并使用 Steinhart-Hart 方程计算摄氏温度。个别的错误读数（电压过低或电阻为零）通过 ``continue`` **跳过**，而不是导致整个测量失败。只有在**所有**样本都无效时，函数才返回 ``None``。最终结果是所有有效样本的算术平均值，提供稳定且抗噪声的读数。


2. **电机速度控制：**

   .. code-block:: python

      def motor_run(lv):
          """Set motor power according to level."""

          lv = max(0, min(4, lv))
          power_table = [0, 25, 50, 75, 100]
          motor.power(power_table[lv])

          return lv


   ``motor_run()`` 函数使用查找表将数值级别（0-4）映射到电机功率百分比。级别 0 发送 0% 功率（关闭），而级别 1 到 4 分别对应 25%、50%、75% 和 100% 的功率。级别首先通过 ``max(0, min(4, lv))`` 限制在有效范围内。


3. **带去抖动的按钮读取：**

   .. code-block:: python

   代码不使用中断回调，而是在主循环中**轮询**按钮状态。通过**上升沿**\ 检测按钮按下：按钮状态从 ``0`` 转换为 ``1``（``last_button_state == 0`` → ``button_state == 1``）。**去抖动定时器**（``DEBOUNCE_TIME = 0.3`` 秒）防止触点抖动触发多次按下。检测到有效按下时，级别循环 0→1→2→3→4→0，更新参考温度（``markTemp``），并立即应用电机速度。


4. **主循环和自动调整：**

   .. code-block:: python

              # ... periodic print ...

   ``main()`` 函数运行一个快速控制循环（0.05 秒间隔）。关键行为：

   - **初始化**：重复读取温度，直到获得有效的 ``markTemp``，确保系统以已知参考值启动。

   - **手动优先**：按下按钮后，自动调整被阻止 ``MANUAL_HOLD_TIME``（2 秒）。这个 ``auto_allowed`` 门控防止系统立即抵消用户的手动更改。

   - **自动调整**：当允许自动调整且风扇不在级别 0 时，代码检查当前温度是否与参考值偏差 ``TEMP_THRESHOLD``\ （±5°C）。如果是，级别逐级增加或减少，参考值重置为当前温度——这创建了一种**锁定**行为，防止在阈值附近振荡。

   - **定期输出**：每 ``PRINT_INTERVAL``\ （1 秒）打印当前温度、参考温度和级别，以便监控。

**故障排除**

1. **电机不运行**：

   - **原因**：接线错误或电源供电不足。
   - **解决方法**：

     - 验证电机是否连接到 M0。
     - 确保电机的电源满足其电压要求。

2. **温度读数不正确**：

   - **原因**：热敏电阻故障。
   - **解决方法**：

     - 检查热敏电阻的接线，确保其在指定范围内。

3. **按钮按下未被检测到**：

   - **原因**：按钮接线或 GPIO 配置错误。
   - **解决方法**：

     - 验证按钮是否连接到 GPIO 22 和 GND。
     - 独立测试按钮，确认按下时能闭合电路。

4. **速度级别不自动变化**：

   - **原因**：温差计算错误。
   - **解决方法**：确保 ``main()`` 函数中的 ``currentTemp`` 和 ``markTemp`` 值正确更新。
