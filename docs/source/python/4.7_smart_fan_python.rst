4.7 Ventilatore Intelligente
=============================

**Introduzione**

In questo progetto, costruirai un "ventilatore intelligente" che funziona sia in modalità manuale che automatica. Combinando motori, pulsanti e un termistore, il ventilatore può avere velocità regolabili e rispondere ai cambiamenti di temperatura. Questo lo rende un esperimento perfetto per imparare il controllo motori, il rilevamento della temperatura e l'uso dei GPIO.

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   markTemp = None

   last_button_state = 0
   last_press_time = 0
   _last_print = 0.0

   DEBOUNCE_TIME = 0.3
   PRINT_INTERVAL = 1.0
   MANUAL_HOLD_TIME = 2.0
   TEMP_THRESHOLD = 5.0


   def temperature(samples=5, delay=0.01):
       """Read thermistor temperature and return average Celsius value."""

       vals = []

       for _ in range(samples):
           analogVal = thermistor.read()
           Vr = 3.3 * float(analogVal) / 4095.0

           if Vr <= 0 or (3.3 - Vr) <= 0.1:
               sleep(delay)
               continue

           Rt = 10000.0 * Vr / (3.3 - Vr)

           if Rt <= 0:
               sleep(delay)
               continue

           tempK = 1.0 / (
               ((math.log(Rt / 10000.0)) / 3950.0)
               + (1.0 / (273.15 + 25.0))
           )

           vals.append(tempK - 273.15)
           sleep(delay)

       if not vals:
           return None

       return sum(vals) / len(vals)


   def motor_run(lv):
       """Set motor power according to level."""

       lv = max(0, min(4, lv))
       power_table = [0, 25, 50, 75, 100]
       motor.power(power_table[lv])

       return lv


   def read_button():
       """Read current button state."""

       try:
           return BtnPin.value()
       except TypeError:
           return BtnPin.value


   def main():
       """Main loop for button control and temperature auto adjustment."""

       global level, markTemp, last_button_state, last_press_time, _last_print

       while markTemp is None:
           markTemp = temperature()
           sleep(0.1)

       while True:
           now = time()

           button_state = read_button()

           if button_state == 1 and last_button_state == 0:
               if now - last_press_time >= DEBOUNCE_TIME:
                   old = level
                   level = (level + 1) % 5
                   last_press_time = now

                   currentTemp = temperature()
                   if currentTemp is not None:
                       markTemp = currentTemp

                   level = motor_run(level)

                   print(
                       f"[Button] {old} -> {level} | "
                       f"Power: {0 if level == 0 else level * 25}%"
                   )

           last_button_state = button_state

           currentTemp = temperature()

           if currentTemp is None:
               print("Sensor read failed.")
               sleep(0.5)
               continue

           auto_allowed = (now - last_press_time) >= MANUAL_HOLD_TIME

           if auto_allowed and level != 0:
               diff = currentTemp - markTemp

               if diff >= TEMP_THRESHOLD:
                   level = min(4, level + 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp up -> Level {level}")

               elif diff <= -TEMP_THRESHOLD:
                   level = max(0, level - 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp down -> Level {level}")

           if now - _last_print >= PRINT_INTERVAL:
               print(
                   f"Temp: {currentTemp:.2f} C | "
                   f"Mark: {markTemp:.2f} C | "
                   f"Level: {level}"
               )
               _last_print = now

           level = motor_run(level)

           sleep(0.05)


   try:
       main()

   except KeyboardInterrupt:
       print("\nExiting...")

   finally:
       motor.stop()
       sleep(0.1)



Questo script Python integra un motore, un pulsante e un sensore di temperatura per creare un sistema di ventilazione controllato dalla temperatura con velocità regolabile. Quando eseguito:

1. **Rilevamento Temperatura**: Legge la temperatura corrente in Celsius usando il termistore. Vengono calcolate più campioni per l'accuratezza e le letture non valide vengono saltate invece di causare un fallimento immediato.

2. **Regolazione Manuale della Velocità**:

   - Un pulsante collegato a GPIO 22 permette all'utente di scorrere cinque livelli di velocità (da 0 a 4).
   - Premendo il pulsante si aumenta il livello di velocità e il motore funziona alla potenza corrispondente (0%, 25%, 50%, 75% o 100%). Il livello di velocità 0 ferma il motore.
   - L'input del pulsante include **protezione anti-rimbalzo** (0,3 secondi) per prevenire falsi attivazioni dal rimbalzo dei contatti.

3. **Finestra di Priorità Manuale**: Dopo una pressione del pulsante, la regolazione automatica della velocità viene soppressa per **2 secondi** (``MANUAL_HOLD_TIME``). Questo assicura che l'impostazione manuale dell'utente non venga immediatamente sovrascritta da una regolazione automatica.

4. **Controllo Automatico della Velocità**: Dopo la scadenza della finestra di priorità manuale (e quando il ventilatore non è spento), il sistema regola automaticamente la velocità del motore in base ai cambiamenti di temperatura:

   - Se la temperatura aumenta di **5°C** o più, il livello di velocità aumenta (fino al livello 4).
   - Se la temperatura diminuisce di **5°C** o più, il livello di velocità diminuisce (fino al livello 0).

5. **Monitoraggio Continuo**: Il sistema monitora continuamente la temperatura e lo stato del pulsante con un intervallo di ciclo veloce di 0,05 secondi, garantendo regolazioni reattive.

6. **Uscita Controllata**: Con ``Ctrl+C``, il motore si ferma e lo script esce in modo pulito.
