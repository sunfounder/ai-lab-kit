4.7 Ventilateur intelligent
==================================

**Introduction**

Dans ce projet, vous allez construire un "ventilateur intelligent" qui fonctionne a la fois en modes manuel et automatique. En combinant des moteurs, des boutons et une thermistance, le ventilateur peut avoir des vitesses de ventilation reglables et reagir aux changements de temperature. Cela en fait une experience parfaite pour apprendre le controle des moteurs, la detection de temperature et l’utilisation des GPIO.

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.motor import Motor
   from fusion_hat.pin import Pin, Mode, Pull
   from fusion_hat.adc import ADC
   from time import sleep, time
   import math

   BtnPin = Pin(22, mode=Mode.IN, pull=Pull.DOWN)
   motor = Motor("M0")
   thermistor = ADC("A3")

   level = 0
   markTemp = None

   last_button_state = 0
   last_press_time = 0
   _last_print = 0.0

   DEBOUNCE_TIME = 0.3
   PRINT_INTERVAL = 1.0
   MANUAL_HOLD_TIME = 2.0
   TEMP_THRESHOLD = 5.0


   def temperature(samples=5, delay=0.01):
       """Read thermistor temperature and return average Celsius value."""

       vals = []

       for _ in range(samples):
           analogVal = thermistor.read()
           Vr = 3.3 * float(analogVal) / 4095.0

           if Vr <= 0 or (3.3 - Vr) <= 0.1:
               sleep(delay)
               continue

           Rt = 10000.0 * Vr / (3.3 - Vr)

           if Rt <= 0:
               sleep(delay)
               continue

           tempK = 1.0 / (
               ((math.log(Rt / 10000.0)) / 3950.0)
               + (1.0 / (273.15 + 25.0))
           )

           vals.append(tempK - 273.15)
           sleep(delay)

       if not vals:
           return None

       return sum(vals) / len(vals)


   def motor_run(lv):
       """Set motor power according to level."""

       lv = max(0, min(4, lv))
       power_table = [0, 25, 50, 75, 100]
       motor.power(power_table[lv])

       return lv


   def read_button():
       """Read current button state."""

       try:
           return BtnPin.value()
       except TypeError:
           return BtnPin.value


   def main():
       """Main loop for button control and temperature auto adjustment."""

       global level, markTemp, last_button_state, last_press_time, _last_print

       while markTemp is None:
           markTemp = temperature()
           sleep(0.1)

       while True:
           now = time()

           button_state = read_button()

           if button_state == 1 and last_button_state == 0:
               if now - last_press_time >= DEBOUNCE_TIME:
                   old = level
                   level = (level + 1) % 5
                   last_press_time = now

                   currentTemp = temperature()
                   if currentTemp is not None:
                       markTemp = currentTemp

                   level = motor_run(level)

                   print(
                       f"[Button] {old} -> {level} | "
                       f"Power: {0 if level == 0 else level * 25}%"
                   )

           last_button_state = button_state

           currentTemp = temperature()

           if currentTemp is None:
               print("Sensor read failed.")
               sleep(0.5)
               continue

           auto_allowed = (now - last_press_time) >= MANUAL_HOLD_TIME

           if auto_allowed and level != 0:
               diff = currentTemp - markTemp

               if diff >= TEMP_THRESHOLD:
                   level = min(4, level + 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp up -> Level {level}")

               elif diff <= -TEMP_THRESHOLD:
                   level = max(0, level - 1)
                   markTemp = currentTemp
                   level = motor_run(level)
                   print(f"[Auto] Temp down -> Level {level}")

           if now - _last_print >= PRINT_INTERVAL:
               print(
                   f"Temp: {currentTemp:.2f} C | "
                   f"Mark: {markTemp:.2f} C | "
                   f"Level: {level}"
               )
               _last_print = now

           level = motor_run(level)

           sleep(0.05)


   try:
       main()

   except KeyboardInterrupt:
       print("\nExiting...")

   finally:
       motor.stop()
       sleep(0.1)



Ce script Python integre un moteur, un bouton et un capteur de temperature pour creer un systeme de ventilateur controle par la temperature avec une vitesse reglable. Lors de l’execution :

1. **Detection de temperature** : Lit la temperature actuelle en Celsius a l’aide de la thermistance. Plusieurs echantillons sont moyennes pour plus de precision, et les lectures invalides sont ignorees plutot que de provoquer une erreur immediate.

2. **Reglage manuel de la vitesse** :

   - Un bouton connecte a la GPIO 22 permet a l’utilisateur de parcourir cinq niveaux de vitesse (0 a 4).
   - Appuyer sur le bouton augmente le niveau de vitesse et le moteur fonctionne a la puissance correspondante (0%, 25%, 50%, 75% ou 100%). Le niveau 0 arrete le moteur.
   - La saisie du bouton inclut une **protection anti-rebond** (0,3 seconde) pour empecher les declenchements intempestifs dus aux rebonds de contact.

3. **Fenetre de priorite manuelle** : Apres une pression sur le bouton, le reglage automatique de la vitesse est suspendu pendant **2 secondes** (``MANUAL_HOLD_TIME``). Cela garantit que le reglage manuel de l’utilisateur n’est pas immediatement annule par un reglage automatique.

4. **Controle automatique de la vitesse** : Apres l’expiration de la fenetre de priorite manuelle (et lorsque le ventilateur n’est pas arrete), le systeme ajuste automatiquement la vitesse du moteur en fonction des changements de temperature :

   - Si la temperature augmente de **5°C** ou plus, le niveau de vitesse augmente (jusqu’au niveau 4).
   - Si la temperature diminue de **5°C** ou plus, le niveau de vitesse diminue (jusqu’au niveau 0).

5. **Surveillance continue** : Le systeme surveille en permanence la temperature et l’etat du bouton avec un intervalle de boucle rapide de 0,05 seconde, garantissant des ajustements reactifs.

6. **Sortie propre** : Sur ``Ctrl+C``, le moteur s’arrete et le script se termine correctement.

**Comprendre le code**

1. **Calcul de la temperature :**

   .. code-block:: python

      def temperature(samples=5, delay=0.01):
          """Read thermistor temperature and return average Celsius value."""

          vals = []

          for _ in range(samples):
              analogVal = thermistor.read()

                  continue

                  ((math.log(Rt / 10000.0)) / 3950.0)

              )

              sleep(delay)

              return None

          return sum(vals) / len(vals)


   La fonction ``temperature()`` prend plusieurs echantillons de la thermistance, convertit chaque lecture analogique en valeur de resistance et calcule la temperature en Celsius a l’aide de l’equation de Steinhart-Hart. Les lectures defectueuses individuelles (tension trop basse ou resistance nulle) sont **ignorees** via ``continue`` plutot que de faire echouer l’ensemble de la mesure. Ce n’est que si **tous** les echantillons sont invalides que la fonction retourne ``None``. Le resultat final est la moyenne arithmetique de tous les echantillons valides, donnant une lecture stable et resistante au bruit.


2. **Controle de la vitesse du moteur :**

   .. code-block:: python

      def motor_run(lv):
          """Set motor power according to level."""

          lv = max(0, min(4, lv))
          power_table = [0, 25, 50, 75, 100]
          motor.power(power_table[lv])

          return lv


   La fonction ``motor_run()`` convertit le niveau numerique (0-4) en un pourcentage de puissance du moteur a l’aide d’une table de correspondance. Le niveau 0 envoie 0% de puissance (arret), tandis que les niveaux 1 a 4 correspondent respectivement a 25%, 50%, 75% et 100% de puissance. Le niveau est d’abord limite a la plage valide avec ``max(0, min(4, lv))``.


3. **Lecture du bouton avec anti-rebond :**

   .. code-block:: python

   Au lieu d’utiliser un rappel d’interruption, le code **interroge** l’etat du bouton dans la boucle principale. Une pression sur le bouton est detectee par un **front montant** : l’etat du bouton passe de ``0`` a ``1`` (``last_button_state == 0`` → ``button_state == 1``). Un **timer anti-rebond** (``DEBOUNCE_TIME = 0.3`` secondes) empeche les rebonds de contact de declencher plusieurs pressions. Lorsqu’une pression valide est detectee, le niveau parcourt 0→1→2→3→4→0, la temperature de reference (``markTemp``) est mise a jour et la vitesse du moteur est appliquee immediatement.


4. **Boucle principale et reglage automatique :**

   .. code-block:: python

   La fonction ``main()`` execute une boucle de controle rapide (intervalle de 0,05 seconde). Comportements cles :

   - **Initialisation** : Elle lit la temperature de maniere repetee jusqu’a ce qu’un ``markTemp`` valide soit obtenu, garantissant que le systeme demarre avec une reference connue.

   - **Priorite manuelle** : Apres une pression sur le bouton, les reglages automatiques sont bloques pendant ``MANUAL_HOLD_TIME`` (2 secondes). Cette barriere ``auto_allowed`` empeche le systeme de contrer immediatement le changement manuel de l’utilisateur.

   - **Reglage automatique** : Lorsque le mode automatique est autorise et que le ventilateur n’est pas au niveau 0, le code verifie si la temperature actuelle s’est ecartee de ``TEMP_THRESHOLD`` (±5°C) de la reference. Si c’est le cas, le niveau est augmente ou diminue d’un cran et la reference est reinitialisee a la temperature actuelle — cela cree un comportement de **verrouillage** qui empeche l’oscillation autour du seuil.

   - **Sortie periodique** : Toutes les ``PRINT_INTERVAL`` (1 seconde), la temperature actuelle, la temperature de reference et le niveau sont affiches pour le suivi.

**Depannage**

1. **Le moteur ne fonctionne pas** :

   - **Cause :** Cablage incorrect ou alimentation insuffisante.
   - **Solution :**

     - Verifiez que le moteur est connecte a M0.
     - Assurez-vous que l’alimentation du moteur correspond a ses exigences de tension.

2. **La lecture de temperature est incorrecte** :

   - **Cause :** Thermistance defectueuse.
   - **Solution :**

     - Verifiez le cablage de la thermistance et assurez-vous qu’elle est dans la plage specifiee.

3. **La pression du bouton n’est pas detectee** :

   - **Cause :** Cablage incorrect du bouton ou configuration GPIO erronee.
   - **Solution :**

     - Verifiez que le bouton est connecte a la GPIO 22 et a la masse.
     - Testez le bouton independamment pour confirmer qu’il ferme le circuit lorsqu’il est presse.

4. **Le niveau de vitesse ne change pas automatiquement** :

   - **Cause :** Calcul incorrect de la difference de temperature.
   - **Solution :** Assurez-vous que les valeurs ``currentTemp`` et ``markTemp`` se mettent correctement a jour dans la fonction ``main()``.
