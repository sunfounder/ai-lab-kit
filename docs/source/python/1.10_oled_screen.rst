1.10 Display OLED
===========================================

**Introduzione**

In questo progetto, impareremo come interfacciarci con un display OLED basato su SSD1306 usando la comunicazione I2C su un Raspberry Pi. I display OLED (Organic Light-Emitting Diode) sono noti per il loro alto contrasto, ampi angoli di visualizzazione e basso consumo energetico. Questo progetto dimostra come inizializzare il display, disegnare forme base e renderizzare testo.

**Schema di Cablaggio**

Segui questi passaggi per costruire il circuito:

1. Collega il pin VCC del display OLED a 3,3V su Fusion HAT+
2. Collega il pin GND del display OLED a GND su Fusion HAT+
3. Collega il pin SCL del display OLED a SCL (GPIO 3) su Fusion HAT+
4. Collega il pin SDA del display OLED a SDA (GPIO 2) su Fusion HAT+

**Codice**

Il seguente codice Python inizializza un display OLED e disegna il testo "Hello World!":

.. raw:: html

   <run></run>

.. code-block:: python

   import board
   import digitalio
   from PIL import Image, ImageDraw, ImageFont
   import adafruit_ssd1306

   # Initialize OLED display dimensions
   WIDTH = 128
   HEIGHT = 64

   # Set up I2C communication with the OLED display
   i2c = board.I2C()  # Utilizes board's SCL and SDA pins
   oled = adafruit_ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c, addr=0x3C)

   # Clear the OLED display
   oled.fill(0)
   oled.show()

   # Create a new image with 1-bit color for drawing
   image = Image.new("1", (oled.width, oled.height))

   # Obtain a drawing object to manipulate the image
   draw = ImageDraw.Draw(image)

   # Draw a filled white rectangle as the background
   draw.rectangle((0, 0, oled.width, oled.height), outline=255, fill=255)

   # Define border size for an inner rectangle
   BORDER = 5
   # Draw a smaller black rectangle inside the larger one
   draw.rectangle(
      (BORDER, BORDER, oled.width - BORDER - 1, oled.height - BORDER - 1),
      outline=0,
      fill=0,
   )

   # Load the default font for text
   font = ImageFont.load_default()

   def getfontsize(font, text):
      # Calculate the size of the text in pixels
      left, top, right, bottom = font.getbbox(text)
      return right - left, bottom - top

   # Define the text to be displayed
   text = "Hello World!"
   # Get the width and height of the text in pixels
   (font_width, font_height) = getfontsize(font, text)
   # Draw the text, centered on the display
   draw.text(
      (oled.width // 2 - font_width // 2, oled.height // 2 - font_height // 2),
      text,
      font=font,
      fill=255,
   )

   # Send the image to the OLED display
   oled.image(image)
   oled.show()

Questo script Python crea un display "Hello World!" su uno schermo OLED SSD1306. Quando eseguito:

1. Lo script inizializza la comunicazione I2C con il display OLED
2. Crea un buffer immagine in bianco e nero per il disegno
3. Disegna uno sfondo bianco con un rettangolo bordato nero
4. Calcola il posizionamento del testo per centrare "Hello World!" sul display
5. Renderizza l'immagine finale sul display OLED
6. Il display mostra il testo fino a quando non viene spento o aggiornato

**Comprendere il Codice**

1. **Importazione della Libreria**

   Il codice importa le librerie necessarie per il controllo del display e la manipolazione delle immagini.

   .. code-block:: python

      import board
      import digitalio
      from PIL import Image, ImageDraw, ImageFont
      import adafruit_ssd1306

2. **Inizializzazione del Display**

   Il display OLED viene inizializzato con dimensioni specificate e indirizzo I2C.

   .. code-block:: python

      WIDTH = 128
      HEIGHT = 64
      i2c = board.I2C()
      oled = adafruit_ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c, addr=0x3C)

3. **Pulizia del Display**

   Il display viene pulito riempiendolo con zeri (nero) e aggiornando.

   .. code-block:: python

      oled.fill(0)
      oled.show()

4. **Creazione del Buffer Immagine**

   Un buffer immagine a 1 bit viene creato per le operazioni di disegno.

   .. code-block:: python

      image = Image.new("1", (oled.width, oled.height))
      draw = ImageDraw.Draw(image)

5. **Operazioni di Disegno**

   Rettangoli e testo vengono disegnati sul buffer immagine.

   .. code-block:: python

      # Background rectangle
      draw.rectangle((0, 0, oled.width, oled.height), outline=255, fill=255)
      # Inner bordered rectangle
      draw.rectangle((BORDER, BORDER, oled.width - BORDER - 1, oled.height - BORDER - 1), outline=0, fill=0)

6. **Renderizzazione del Testo**

   Il testo viene centrato sul display usando le metriche del font.

   .. code-block:: python

      font = ImageFont.load_default()
      (font_width, font_height) = getfontsize(font, text)
      draw.text((oled.width // 2 - font_width // 2, oled.height // 2 - font_height // 2), text, font=font, fill=255)

7. **Aggiornamento del Display**

   L'immagine finale viene inviata al display OLED.

   .. code-block:: python

      oled.image(image)
      oled.show()

**Risoluzione dei Problemi**

1. **Il Display Non Mostra Nulla**

   - **Causa**: Indirizzo I2C errato, problemi di cablaggio o I2C non abilitato.
   - **Soluzione**: Verifica l'indirizzo I2C (prova 0x3C o 0x3D), controlla tutte le connessioni e abilita I2C nella configurazione del Raspberry Pi (``sudo raspi-config``).

2. **Errori di Comunicazione I2C**

   - **Causa**: Problemi del bus I2C o dispositivo non rilevato.
   - **Soluzione**: Controlla se il dispositivo viene rilevato con il comando ``i2cdetect -y 1``. Assicurati che nessun altro dispositivo sia in conflitto sul bus I2C.

3. **Testo o Grafica Non Visualizzati Correttamente**

   - **Causa**: Valori di colore errati o problemi di coordinate.
   - **Soluzione**: Ricorda che 0 = nero e 255 = bianco in modalità colore a 1 bit. Verifica che le coordinate siano entro i limiti del display (0-127 per larghezza, 0-63 per altezza).

4. **Errori di Importazione della Libreria**

   - **Causa**: Dipendenze mancanti o installazione errata.
   - **Soluzione**: Assicurati che tutte le librerie richieste siano installate nell'ambiente corretto e prova a eseguire con ``sudo`` se si verificano problemi di autorizzazione.

**Idee Estendibili**

1. **Display di Informazioni di Sistema**

   Crea un monitor di sistema in tempo reale che mostra l'utilizzo della CPU, la memoria e la temperatura:

   .. code-block:: python

      import psutil
      import time

      while True:
          # Clear and redraw
          draw.rectangle((0, 0, oled.width, oled.height), fill=0)

          # Get system info
          cpu_percent = psutil.cpu_percent()
          memory = psutil.virtual_memory()
          temp = psutil.sensors_temperatures()['cpu_thermal'][0].current

          # Display info
          draw.text((0, 0), f"CPU: {cpu_percent}%", font=font, fill=255)
          draw.text((0, 16), f"RAM: {memory.percent}%", font=font, fill=255)
          draw.text((0, 32), f"Temp: {temp}C", font=font, fill=255)

          oled.image(image)
          oled.show()
          time.sleep(2)

2. **Testo Scorrevole**

   Crea effetti di testo scorrevole per messaggi più lunghi:

   .. code-block:: python

      text = "This is a scrolling text message!"
      text_width = getfontsize(font, text)[0]

      for x in range(oled.width, -text_width, -1):
          draw.rectangle((0, 0, oled.width, oled.height), fill=0)
          draw.text((x, oled.height//2), text, font=font, fill=255)
          oled.image(image)
          oled.show()
          time.sleep(0.05)

3. **Grafica Animata**

          draw.rectangle((i, 20, i+10, 30), fill=255)  # Moving rectangle

          oled.show()
