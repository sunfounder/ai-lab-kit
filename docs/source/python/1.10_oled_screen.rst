1.10 Pantalla OLED
===============================================


**Introducción**

En este proyecto, aprenderemos cómo interactuar con una pantalla OLED basada en SSD1306 usando comunicación I2C en una Raspberry Pi. Las pantallas OLED (diodo orgánico emisor de luz) son conocidas por su alto contraste, amplios ángulos de visión y bajo consumo de energía. Este proyecto demuestra cómo inicializar la pantalla, dibujar formas básicas y renderizar texto.

2. Conecta el pin GND de la pantalla OLED a GND en la Fusion HAT+
3. Conecta el pin SCL de la pantalla OLED a SCL (GPIO 3) en la Fusion HAT+

**Código**

El siguiente código Python inicializa una pantalla OLED y dibuja el texto "Hello World!":

.. raw:: html

   <run></run>

.. code-block:: python

   import board
   import digitalio
   from PIL import Image, ImageDraw, ImageFont
   import adafruit_ssd1306

   # Initialize OLED display dimensions
   WIDTH = 128
   HEIGHT = 64

   # Set up I2C communication with the OLED display
   i2c = board.I2C()  # Utilizes board's SCL and SDA pins
   oled = adafruit_ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c, addr=0x3C)

   # Clear the OLED display
   oled.fill(0)
   oled.show()

   # Create a new image with 1-bit color for drawing
   image = Image.new("1", (oled.width, oled.height))

   # Obtain a drawing object to manipulate the image
   draw = ImageDraw.Draw(image)

   # Draw a filled white rectangle as the background
   draw.rectangle((0, 0, oled.width, oled.height), outline=255, fill=255)

   # Define border size for an inner rectangle
   BORDER = 5
   # Draw a smaller black rectangle inside the larger one
   draw.rectangle(
      (BORDER, BORDER, oled.width - BORDER - 1, oled.height - BORDER - 1),
      outline=0,
      fill=0,
   )

   # Load the default font for text
   font = ImageFont.load_default()

   def getfontsize(font, text):
      # Calculate the size of the text in pixels
      left, top, right, bottom = font.getbbox(text)
      return right - left, bottom - top

   # Define the text to be displayed
   text = "Hello World!"
   # Get the width and height of the text in pixels
   (font_width, font_height) = getfontsize(font, text)
   # Draw the text, centered on the display
   draw.text(
      (oled.width // 2 - font_width // 2, oled.height // 2 - font_height // 2),
      text,
      font=font,
      fill=255,
   )

   # Send the image to the OLED display
   oled.image(image)
   oled.show()

Este script Python crea una visualización de "Hello World!" en una pantalla OLED SSD1306. Cuando se ejecuta:

1. El script inicializa la comunicación I2C con la pantalla OLED
2. Crea un búfer de imagen en blanco y negro para dibujar
3. Dibuja un fondo blanco con un rectángulo con borde negro
4. Calcula el posicionamiento del texto para centrar "Hello World!" en la pantalla
5. Renderiza la imagen final en la pantalla OLED
6. La pantalla muestra el texto hasta que se apague o se actualice

**Comprender el Código**

1. **Importación de Librerías**

   El código importa las librerías necesarias para el control de la pantalla y la manipulación de imágenes.

   .. code-block:: python

      import board
      import digitalio
      from PIL import Image, ImageDraw, ImageFont
      import adafruit_ssd1306

2. **Inicialización de la Pantalla**

   La pantalla OLED se inicializa con dimensiones y dirección I2C especificadas.

   .. code-block:: python

      WIDTH = 128
      HEIGHT = 64
      i2c = board.I2C()
      oled = adafruit_ssd1306.SSD1306_I2C(WIDTH, HEIGHT, i2c, addr=0x3C)

3. **Limpieza de la Pantalla**

   La pantalla se limpia llenándola con ceros (negro) y actualizándola.

   .. code-block:: python

      oled.fill(0)
      oled.show()

4. **Creación del Búfer de Imagen**

   Se crea un búfer de imagen de color de 1 bit para las operaciones de dibujo.

   .. code-block:: python

      image = Image.new("1", (oled.width, oled.height))
      draw = ImageDraw.Draw(image)

5. **Operaciones de Dibujo**

   Se dibujan rectángulos y texto en el búfer de imagen.

   .. code-block:: python

      # Background rectangle
      draw.rectangle((0, 0, oled.width, oled.height), outline=255, fill=255)
      # Inner bordered rectangle
      draw.rectangle((BORDER, BORDER, oled.width - BORDER - 1, oled.height - BORDER - 1), outline=0, fill=0)

6. **Renderizado de Texto**

   El texto se centra en la pantalla usando métricas de fuente.

   .. code-block:: python

      font = ImageFont.load_default()
      (font_width, font_height) = getfontsize(font, text)
      draw.text((oled.width // 2 - font_width // 2, oled.height // 2 - font_height // 2), text, font=font, fill=255)

7. **Actualización de la Pantalla**

   La imagen final se envía a la pantalla OLED.

   .. code-block:: python

      oled.image(image)
      oled.show()

**Solución de Problemas**

1. **La Pantalla No Muestra Nada**

   - **Causa**: Dirección I2C incorrecta, problemas de cableado o I2C no habilitado.
   - **Solución**: Verifica la dirección I2C (prueba 0x3C o 0x3D), revisa todas las conexiones y habilita I2C en la configuración de Raspberry Pi (``sudo raspi-config``).

2. **Errores de Comunicación I2C**

   - **Causa**: Problemas en el bus I2C o dispositivo no detectado.
   - **Solución**: Verifica si el dispositivo se detecta con el comando ``i2cdetect -y 1``. Asegúrate de que ningún otro dispositivo esté en conflicto en el bus I2C.

3. **El Texto o los Gráficos No se Muestran Correctamente**

   - **Causa**: Valores de color incorrectos o problemas de coordenadas.
   - **Solución**: Recuerda que 0=negro y 255=blanco en modo de color de 1 bit. Verifica que las coordenadas estén dentro de los límites de la pantalla (0-127 para ancho, 0-63 para alto).

4. **Errores de Importación de Librerías**

   - **Causa**: Dependencias faltantes o instalación incorrecta.
   - **Solución**: Asegúrate de que todas las librerías requeridas estén instaladas en el entorno correcto y prueba ejecutando con ``sudo`` si ocurren problemas de permisos.

**Ideas para Extender**

1. **Pantalla de Información del Sistema**

   Crea un monitor del sistema en tiempo real que muestre el uso de CPU, memoria y temperatura:

   .. code-block:: python

      import psutil
      import time

      while True:
          # Clear and redraw
          draw.rectangle((0, 0, oled.width, oled.height), fill=0)

          # Get system info
          cpu_percent = psutil.cpu_percent()
          memory = psutil.virtual_memory()
          temp = psutil.sensors_temperatures()['cpu_thermal'][0].current

          # Display info
          draw.text((0, 0), f"CPU: {cpu_percent}%", font=font, fill=255)
          draw.text((0, 16), f"RAM: {memory.percent}%", font=font, fill=255)
          draw.text((0, 32), f"Temp: {temp}C", font=font, fill=255)

          oled.image(image)
          oled.show()
          time.sleep(2)

2. **Texto Desplazable**

   Crea efectos de texto desplazable para mensajes más largos:

   .. code-block:: python

      text = "This is a scrolling text message!"
      text_width = getfontsize(font, text)[0]

      for x in range(oled.width, -text_width, -1):
          draw.rectangle((0, 0, oled.width, oled.height), fill=0)
          draw.text((x, oled.height//2), text, font=font, fill=255)
          oled.image(image)
          oled.show()
          time.sleep(0.05)

3. **Gráficos Animados**

   Crea animaciones simples usando formas básicas:

   .. code-block:: python

      for i in range(0, oled.width-10, 5):
          draw.rectangle((0, 0, oled.width, oled.height), fill=0)
          draw.rectangle((i, 20, i+10, 30), fill=255)  # Moving rectangle
          oled.image(image)
          oled.show()
          time.sleep(0.1)

4. **Múltiples Páginas**

   Crea una pantalla multipágina con control por botón:

   .. code-block:: python

      pages = ["Page 1: Info", "Page 2: Stats", "Page 3: Graph"]
      current_page = 0

      # Use buttons to change pages
      def next_page():
          global current_page
          current_page = (current_page + 1) % len(pages)
          update_display()

5. **Fuentes Personalizadas**

   Utiliza diferentes fuentes para una mejor apariencia visual:

   .. code-block:: python

      # Load custom font (requires font file)
      try:
          custom_font = ImageFont.truetype("/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf", 12)
      except:
          custom_font = ImageFont.load_default()

6. **Gráficos y Diagramas**

   Muestra gráficos de barras o diagramas simples:

   .. code-block:: python

      data = [10, 25, 45, 30, 60, 15]
      for i, value in enumerate(data):
          x = i * 20 + 5
          height = int(value / 100 * oled.height)
          draw.rectangle((x, oled.height-height, x+15, oled.height), fill=255)

**Conclusión**

Este proyecto demuestra cómo interactuar con pantallas OLED SSD1306 usando comunicación I2C en una Raspberry Pi. Las pantallas OLED proporcionan una salida visual nítida y de alto contraste adecuada para diversas aplicaciones, incluyendo monitoreo de sistemas, interfaces de usuario y pantallas de información. Combinando texto, formas y gráficos, puedes crear pantallas informativas y visualmente atractivas para tus proyectos. Las habilidades aprendidas aquí pueden extenderse para crear interfaces de usuario complejas, visualizaciones de datos y sistemas de monitoreo en tiempo real.
