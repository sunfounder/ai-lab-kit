4.1.8 Battery Indicator
===================================

**Introduction**

In diesem Projekt erstellst du einen einfachen, aber wirkungsvollen Batterieindikator, der den Ladezustand mit einer LED-Balkenanzeige visualisiert. Das ist eine praxisnahe Anwendung von Analog-/Digital-Wandlung (ADC) und GPIO-Steuerung und eignet sich hervorragend, um zu lernen, wie man Spannungspegel misst und visualisiert.

.. warning::  Miss in diesem Beispiel bitte keine Spannungsquellen über 3,3 V. Konkret empfehlen wir, nur eine einzelne AA-Batterie zu messen. Andernfalls könnte der Fusion HAT beschädigt werden.

**Writing the Code**


Hier ist der Python-Code für den Batterieindikator:



.. raw:: html

   <run></run>

.. code-block:: python

    #!/usr/bin/env python3
    from fusion_hat import Pin,ADC
    from time import sleep

    # Define GPIO pins where LEDs are connected
    led_pins = [4, 17, 27, 22, 23, 24, 25, 5, 13, 26]

    # Create LED objects for each pin
    leds = [Pin(pin, Pin.OUT) for pin in led_pins]

    # Set up the detection pin for the battery
    btr = ADC('A0')

    def MAP(x, in_min, in_max, out_min, out_max):
        """
        Map a value from one range to another.
        :param x: The value to be mapped.
        :param in_min: The lower bound of the value's current range.
        :param in_max: The upper bound of the value's current range.
        :param out_min: The lower bound of the value's target range.
        :param out_max: The upper bound of the value's target range.
        :return: The mapped value.
        """
        return (x - in_min) * (out_max - out_min) / (in_max - in_min) + out_min

    def LedBarGraph(value):
        # Turn off all LEDs
        for i in range(10):
            leds[i].off()
        # Turn on LEDs up to the specified value
        for i in range(value):
            leds[i].on()

    try:
        # Main loop to continuously update LED bar graph
        while True:
            # Read voltage value 
            voltage = btr.read_voltage()
            print('voltage = %.2f' %(voltage))

            # Convert analog value to LED bar graph level
            LedBarGraph(int(MAP(voltage, 0, 3.3, 0, 10)))
            sleep(0.5)
            
    except KeyboardInterrupt: 
        # Turn off all LEDs when program is interrupted
        for i in range(10):
            leds[i].off()

Dieses Python-Skript steuert eine 10-LED-Balkenanzeige basierend auf einem Analogwert. Beim Ausführen gilt:

1. **Analog Input Reading**:

   - Der Fusion HAT liest kontinuierlich den analogen Eingangswert einer Batterie.

2. **LED Bar Graph Display**:

   - Die Spannung wird auf den Bereich 0–10 skaliert.
   - Entsprechend viele LEDs der Balkenanzeige leuchten, um den Eingangspegel darzustellen.

3. **Dynamic Updates**:

   - Ändert sich der Analogwert, passt sich die Anzahl der leuchtenden LEDs in Echtzeit an und bildet den Wert visuell ab.

4. **Graceful Exit**:

   - Bei ``Ctrl+C`` werden alle LEDs ausgeschaltet und das Skript beendet sich sauber.

**Understanding the Code**

1. **Library Imports:**

   .. code-block:: python

      from fusion_hat import Pin,ADC
      from time import sleep

   * ``fusion_hat`` dient zur Ansteuerung des ADC-Moduls und der LED-Balkenanzeige.
   * ``time`` stellt zeitbezogene Funktionen bereit.

2. **LED Initialization:**

   .. code-block:: python

      # Define GPIO pins where LEDs are connected
      led_pins = [4, 17, 27, 22, 23, 24, 25, 5, 13, 26]

      # Create LED objects for each pin
      leds = [Pin(pin, Pin.OUT) for pin in led_pins]

   * Die GPIO-Pins der LEDs werden definiert und als LED-Objekte zur einfachen Steuerung initialisiert.

3. **ADC Setup:**

   .. code-block:: python

      # Set up the detection pin for the battery
      btr = ADC('A0')

   * Das ADC-Objekt wird initialisiert, um die Analog-/Digital-Wandlung zu ermöglichen.

4. **Bar Graph Logic:**

   .. code-block:: python

       def LedBarGraph(value):
           for i in range(10):
               leds[i].off()
           for i in range(value):
               leds[i].on()


   * Die Funktion ``LedBarGraph`` schaltet entsprechend dem Batteriestand die passenden LEDs ein.



5. **Main Loop:**


   .. code-block:: python

      try:
         # Main loop to continuously update LED bar graph
         while True:
            # Read voltage value 
            voltage = btr.read_voltage()
            print('voltage = %.2f' %(voltage))

            # Convert analog value to LED bar graph level
            LedBarGraph(int(MAP(voltage, 0, 3.3, 0, 10)))
            sleep(0.5)
            
      except KeyboardInterrupt: 
         # Turn off all LEDs when program is interrupted
         for i in range(10):
            leds[i].off()

   * Liest fortlaufend die Batteriespannung, skaliert sie und aktualisiert die LED-Balkenanzeige.
   * Behandelt einen Keyboard-Interrupt, damit vor dem Beenden alle LEDs ausgeschaltet werden.



----------------------------------------------

**Troubleshooting**

1. **LEDs leuchten nicht**:

   - **Ursache**: Falsche Verdrahtung oder GPIO-Konfiguration.
   - **Lösung**:

     - Prüfe, ob jede LED am korrekten GPIO-Pin aus ``led_pins`` hängt.
     - Überzeuge dich davon, dass die LEDs funktionsfähig und korrekt versorgt sind.

2. **Balkenanzeige aktualisiert nicht**:

   - **Ursache**: Falsche ADC-Skalierung oder Logikfehler in ``LedBarGraph``.
   - **Lösung**:

     - Prüfe, ob ``voltage`` korrekt gelesen und auf 0–10 skaliert wird.
     - Füge Debug-Ausgaben hinzu:

       .. code-block:: python

           print(f"Analog Value: {voltage}, LEDs On: {int(MAP(voltage, 0, 3.3, 0, 10))}")


4. **Flackernde LEDs**:

   - **Ursache**: Zu schnelle Aktualisierung ohne ausreichende Pause.
   - **Lösung**: Eine kleine Verzögerung in der Hauptschleife stabilisiert die Anzeige:

     .. code-block:: python

         time.sleep(0.1)

**Extendable Ideas**

1. **Echtzeit-Logging**: Protokolliere Analogwerte und LED-Stufen zur späteren Analyse:

   .. code-block:: python

      with open("log.txt", "a") as log_file:
            log_file.write(f"Analog Value: {voltage}, LEDs On: {int(MAP(voltage, 0, 3.3, 0, 10))}\n")

2. **Interaktive Steuerung**: Nutze Taster oder einen Drehencoder, um Skalierungsfaktoren bzw. Empfindlichkeit der Balkenanzeige anzupassen.

3. **Schwellwert-Warnungen**: Löse bei Überschreiten eines Grenzwerts Alarme aus (z. B. Summer oder blinkende LEDs):

     .. code-block:: python

        if voltage > 2.5:
            for led in leds:
                led.on()
                time.sleep(0.5)
            for led in leds:
                led.off()
