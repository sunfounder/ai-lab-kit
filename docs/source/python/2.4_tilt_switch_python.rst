2.4 Interruptor de Inclinación
==============================

**Introducción**

En este proyecto, exploraremos el módulo de interruptor de inclinación, un interruptor de inclinación de bola que contiene una pequeña bola metálica en su interior. Este interruptor está diseñado para detectar ligeras inclinaciones y puede utilizarse en diversas aplicaciones como detección de movimiento, medición de ángulos y monitoreo de equilibrio.

Este script de Python utiliza un sensor de inclinación para controlar dos LEDs y mostrar mensajes de estado en la consola. Cuando se ejecuta:

1. Si el sensor de inclinación (conectado al pin GPIO 17) detecta una inclinación:

   - Imprime un mensaje en la consola.
   - Enciende el LED rojo (conectado al pin GPIO 22).
   - Apaga el LED verde (conectado al pin GPIO 27).

2. Si el sensor de inclinación permanece vertical (en su posición normal):

   - Apaga el LED rojo.
   - Enciende el LED verde.

3. El programa monitorea continuamente el estado del sensor de inclinación y ajusta los LEDs en consecuencia.

4. El script se ejecuta indefinidamente hasta que se interrumpe presionando ``Ctrl+C``.

**Código**

A continuación se muestra el script de Python para controlar el interruptor de inclinación y los LEDs:

.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   TiltPin = Pin(17, mode=Mode.IN, pull=Pull.DOWN)  # Tilt sensor connected to GPIO pin 17
   green_led = Pin(27,mode=Mode.OUT)  # Green LED connected to GPIO pin 27
   red_led = Pin(22,mode=Mode.OUT)   # Red LED connected to GPIO pin 22

   def detect():
      """
      Detect the tilt sensor state and control the LEDs.
      Turns on the red LED and turns off the green LED when tilted.
      Turns off the red LED and turns on the green LED when not tilted.
      """
      if TiltPin.value() == 0:  # Check if the sensor is tilted
         print('    *************')
         print('    *   Tilt!   *')
         print('    *************')
         red_led.high()   # Turn on red LED
         green_led.low()  # Turn off green LED
      else:  # If the sensor is not tilted
         red_led.low()  # Turn off red LED
         green_led.high()  # Turn on green LED

   try:
      # Set up a callback to detect changes in the tilt sensor state
      TiltPin.when_activated = detect
      TiltPin.when_deactivated = detect
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

   El script importa las clases necesarias para el control de LED y botón, y las inicializa con los pines GPIO apropiados.

2. **Inicialización**

   Configura el interruptor de inclinación y los LEDs conectados a los pines GPIO 17, 27 y 22.

   .. code-block:: python

   La función ``detect`` verifica el estado del interruptor de inclinación y actualiza los LEDs en consecuencia. Si el interruptor está inclinado, el LED rojo se enciende y el LED verde se apaga.

**Solución de Problemas**

1. **El Script No Responde a la Inclinación**

   - **Causa**: Los listeners de eventos (``when_activated`` y ``when_deactivated``) no funcionan correctamente.
   - **Solución**: Confirma que ``detect()`` esté correctamente vinculada a ambos eventos ``when_activated`` y ``when_deactivated``.


2. **Los LEDs Parpadean**

   - **Causa**: Ruido del sensor o problemas de debounce.
   - **Solución**: Añade un breve retardo para estabilizar la señal:


   .. code-block:: python


      from time import sleep
      def detect():
            sleep(0.05)  # Debounce delay
            if TiltPin.value() == 0:
               red_led.on()
               green_led.off()
            else:
               red_led.off()
               green_led.on()

**Ideas para Extender**

1. **Retroalimentación de Sonido**

   Añade un zumbador para proporcionar retroalimentación de audio cuando se active el sensor de inclinación:

   .. code-block:: python

      from fusion_hat import Buzzer,Pin
      buzzer = Buzzer(Pin(4))
      if TiltPin.value() == 0:
         buzzer.on()
      else:
         buzzer.off()


2. **Alertas Temporizadas**

   Activa una alerta si el sensor permanece inclinado durante un tiempo específico:

   .. code-block:: python

      from threading import Timer
      def alert():
         print("Tilt detected for too long!")
         red_led.on()
         sleep(0.5)
         red_led.off()

      if TiltPin.value() == 0:
         Timer(5, alert).start()  # Trigger alert if tilted for 5 seconds
