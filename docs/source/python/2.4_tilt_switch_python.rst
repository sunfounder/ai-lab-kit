2.4 Interrupteur d'inclinaison
=================================

**Introduction**

Dans ce projet, nous allons explorer le module d'interrupteur d'inclinaison, un interrupteur a bille contenant une petite bille metallique a l'interieur. Cet interrupteur est concu pour detecter de legeres inclinaisons et peut etre utilise dans diverses applications comme la detection de mouvement, la mesure d'angle et la surveillance de l'equilibre.

Ce script Python utilise un capteur d'inclinaison pour controler deux LED et afficher des messages d'etat sur la console. Lors de l'execution :

1. Si le capteur d'inclinaison (connecte a la broche GPIO 17) detecte une inclinaison :

   - Affiche un message sur la console.
   - Allume la LED rouge (connectee a la broche GPIO 22).
   - Eteint la LED verte (connectee a la broche GPIO 27).

2. Si le capteur d'inclinaison reste droit (dans sa position verticale normale) :

   - Eteint la LED rouge.
   - Allume la LED verte.

3. Le programme surveille en continu l'etat du capteur d'inclinaison et ajuste les LED en consequence.

4. Le script s'execute indefiniment jusqu'a ce qu'il soit interrompu en appuyant sur ``Ctrl+C``.

**Code**

Ci-dessous le script Python pour controler l'interrupteur d'inclinaison et les LED :

.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   TiltPin = Pin(17, mode=Mode.IN, pull=Pull.DOWN)  # Tilt sensor connected to GPIO pin 17
   green_led = Pin(27,mode=Mode.OUT)  # Green LED connected to GPIO pin 27
   red_led = Pin(22,mode=Mode.OUT)   # Red LED connected to GPIO pin 22

   def detect():
      """
      Detect the tilt sensor state and control the LEDs.
      Turns on the red LED and turns off the green LED when tilted.
      Turns off the red LED and turns on the green LED when not tilted.
      """
      if TiltPin.value() == 0:  # Check if the sensor is tilted
         print('    *************')
         print('    *   Tilt!   *')
         print('    *************')
         red_led.high()   # Turn on red LED
         green_led.low()  # Turn off green LED
      else:  # If the sensor is not tilted
         red_led.low()  # Turn off red LED
         green_led.high()  # Turn on green LED

   try:
      # Set up a callback to detect changes in the tilt sensor state
      TiltPin.when_activated = detect
      TiltPin.when_deactivated = detect
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Comprendre le code**

1. **Importations**

   Le script importe les classes necessaires pour le controle des LED et du bouton et les initialise avec les broches GPIO appropriees.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module


2. **Initialisation**

   Configurez l'interrupteur d'inclinaison et les LED connectees aux broches GPIO 17, 27 et 22.

   .. code-block:: python

      TiltPin = Pin(17, mode=Mode.IN, pull=Pull.DOWN)  # Tilt sensor connected to GPIO pin 17
      green_led = Pin(27,mode=Mode.OUT)  # Green LED connected to GPIO pin 27
      red_led = Pin(22,mode=Mode.OUT)   # Red LED connected to GPIO pin 22

3. **Fonction de detection**

   La fonction ``detect`` verifie l'etat de l'interrupteur d'inclinaison et met a jour les LED en consequence. Si l'interrupteur est incline, la LED rouge s'allume et la LED verte s'eteint.

   .. code-block:: python

      def detect():
         if TiltPin.value() == 0:  # Check if the sensor is tilted
            print('    *************')
            print('    *   Tilt!   *')
            print('    *************')
            red_led.high()   # Turn on red LED
            green_led.low()  # Turn off green LED
         else:  # If the sensor is not tilted
            red_led.low()  # Turn off red LED
            green_led.high()  # Turn on green LED

4. **Boucle principale**

   Assignez la fonction ``detect`` pour gerer les evenements ``when_pressed`` et ``when_released`` du capteur d'inclinaison. La boucle continue jusqu'a interruption.

   .. code-block:: python

      try:
         # Set up a callback to detect changes in the tilt sensor state
         TiltPin.when_activated = detect
         TiltPin.when_deactivated = detect
         pause()

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass

**Depannage**

1. **Le script ne repond pas a l'inclinaison**

   - **Cause** : Les ecouteurs d'evenements (``when_activated`` et ``when_deactivated``) ne fonctionnent pas correctement.
   - **Solution** : Confirmez que ``detect()`` est correctement liee aux evenements ``when_activated`` et ``when_deactivated``.


2. **Les LED scintillent**

   - **Cause** : Bruit du capteur ou problemes d'anti-rebond.
   - **Solution** : Ajoutez une breve pause pour stabiliser le signal :


   .. code-block:: python


      from time import sleep
      def detect():
            sleep(0.05)  # Debounce delay
            if TiltPin.value() == 0:
               red_led.on()
               green_led.off()
            else:
               red_led.off()
               green_led.on()

**Idees d'extension**

1. **Retour sonore**

   Ajoutez un buzzer pour fournir un retour audio lorsque le capteur d'inclinaison est active :

   .. code-block:: python

      from fusion_hat import Buzzer,Pin
      buzzer = Buzzer(Pin(4))
      if TiltPin.value() == 0:
         buzzer.on()
      else:
         buzzer.off()


2. **Alertes temporisees**

   Declenchez une alerte si le capteur reste incline pendant une duree specifiee :

   .. code-block:: python

      from threading import Timer
      def alert():
         print("Tilt detected for too long!")
         red_led.on()
         sleep(0.5)
         red_led.off()

      if TiltPin.value() == 0:
         Timer(5, alert).start()  # Trigger alert if tilted for 5 seconds

**Conclusion**

Ce projet montre comment utiliser un interrupteur d'inclinaison avec un Fusion HAT+ pour detecter les inclinaisons et controler des LED. Les interrupteurs d'inclinaison sont une solution economique pour la detection simple de mouvement et d'angle, offrant des applications pratiques en robotique et en automatisation residentielle.
