2.4 倾斜开关
=============

**介绍**

在本项目中，我们将探索倾斜开关模块，这是一种包含一个小金属球的滚珠倾斜开关。该开关设计用于检测轻微倾斜，可用于运动检测、角度测量和平衡监测等各种应用。

此Python脚本使用倾斜传感器控制两个LED并在控制台上显示状态消息。执行时：

1. 如果倾斜传感器（连接到GPIO 17引脚）检测到倾斜：

   - 在控制台打印消息。
   - 点亮红色LED（连接到GPIO 22引脚）。
   - 熄灭绿色LED（连接到GPIO 27引脚）。

   - 熄灭红色LED。
   - 点亮绿色LED。

3. 程序持续监测倾斜传感器的状态并相应调整LED。

4. 脚本无限运行，直到按下\ ``Ctrl+C``\ 中断。

**代码**

以下是控制倾斜开关和LED的Python脚本：

.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   TiltPin = Pin(17, mode=Mode.IN, pull=Pull.DOWN)  # Tilt sensor connected to GPIO pin 17
   green_led = Pin(27,mode=Mode.OUT)  # Green LED connected to GPIO pin 27
   red_led = Pin(22,mode=Mode.OUT)   # Red LED connected to GPIO pin 22

   def detect():
      """
      Detect the tilt sensor state and control the LEDs.
      Turns on the red LED and turns off the green LED when tilted.
      Turns off the red LED and turns on the green LED when not tilted.
      """
      if TiltPin.value() == 0:  # Check if the sensor is tilted
         print('    *************')
         print('    *   Tilt!   *')
         print('    *************')
         red_led.high()   # Turn on red LED
         green_led.low()  # Turn off green LED
      else:  # If the sensor is not tilted
         red_led.low()  # Turn off red LED
         green_led.high()  # Turn on green LED

   try:
      # Set up a callback to detect changes in the tilt sensor state
      TiltPin.when_activated = detect
      TiltPin.when_deactivated = detect
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

----------------------------------------------

**理解代码**

1. **导入**

   脚本导入LED和按钮控制所需的类，并用适当的GPIO引脚初始化它们。

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module


2. **初始化**

   配置连接到GPIO 17、27和22引脚的倾斜开关和LED。

   .. code-block:: python

      TiltPin = Pin(17, mode=Mode.IN, pull=Pull.DOWN)  # Tilt sensor connected to GPIO pin 17
      green_led = Pin(27,mode=Mode.OUT)  # Green LED connected to GPIO pin 27
      red_led = Pin(22,mode=Mode.OUT)   # Red LED connected to GPIO pin 22

3. **检测函数**

   ``detect``\ 函数检查倾斜开关的状态并相应更新LED。如果开关倾斜，红色LED亮起，绿色LED熄灭。

   .. code-block:: python

      def detect():
         if TiltPin.value() == 0:  # Check if the sensor is tilted
            print('    *************')
            print('    *   Tilt!   *')
            print('    *************')
            red_led.high()   # Turn on red LED
            green_led.low()  # Turn off green LED
         else:  # If the sensor is not tilted
            red_led.low()  # Turn off red LED
            green_led.high()  # Turn on green LED

4. **主循环**

   将\ ``detect``\ 函数分配给倾斜传感器的\ ``when_pressed``\ 和\ ``when_released``\ 事件处理。循环持续运行直到中断。

   .. code-block:: python

      try:
         # Set up a callback to detect changes in the tilt sensor state
         TiltPin.when_activated = detect
         TiltPin.when_deactivated = detect
         pause()

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass

----------------------------------------------


**故障排除**

1. **脚本对倾斜无响应**

   - **原因**：事件监听器（\ ``when_activated``\ 和\ ``when_deactivated``\ ）未正常运行。
   - **解决方案**：确认\ ``detect()``\ 已正确链接到\ ``when_activated``\ 和\ ``when_deactivated``\ 事件。

2. **LED闪烁**

   - **原因**：传感器噪声或消抖问题。
   - **解决方案**：添加短暂延迟以稳定信号：


   .. code-block:: python


      from time import sleep
      def detect():
            sleep(0.05)  # Debounce delay
            if TiltPin.value() == 0:
               red_led.on()
               green_led.off()
            else:
               red_led.off()
               green_led.on()

**扩展思路**

1. **声音反馈**

   添加蜂鸣器，在倾斜传感器激活时提供音频反馈：

   .. code-block:: python

      from fusion_hat import Buzzer,Pin
      buzzer = Buzzer(Pin(4))
      if TiltPin.value() == 0:
         buzzer.on()
      else:
         buzzer.off()


2. **定时警报**

   如果传感器保持倾斜超过指定时长，触发警报：

   .. code-block:: python

      from threading import Timer
      def alert():
         print("Tilt detected for too long!")
         red_led.on()
         sleep(0.5)
         red_led.off()

      if TiltPin.value() == 0:
         Timer(5, alert).start()  # Trigger alert if tilted for 5 seconds
