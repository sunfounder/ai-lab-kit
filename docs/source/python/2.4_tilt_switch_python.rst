2.4 Interruttore a Inclinazione
==================================

**Introduzione**

In questo progetto, esploreremo il modulo interruttore a inclinazione, un interruttore a sfera che contiene una piccola sfera metallica all'interno. Questo interruttore è progettato per rilevare lievi inclinazioni e può essere utilizzato in varie applicazioni come rilevamento del movimento, misurazione dell'angolo e monitoraggio dell'equilibrio.

Questo script Python usa un sensore di inclinazione per controllare due LED e visualizzare messaggi di stato sulla console. Quando eseguito:

1. Se il sensore di inclinazione (collegato al pin GPIO 17) rileva un'inclinazione:

   - Stampa un messaggio sulla console.
   - Accende il LED rosso (collegato al pin GPIO 22).
   - Spegne il LED verde (collegato al pin GPIO 27).

2. Se il sensore di inclinazione rimane in posizione verticale (nella sua normale posizione verticale):

   - Spegne il LED rosso.
   - Accende il LED verde.

3. Il programma monitora continuamente lo stato del sensore di inclinazione e regola i LED di conseguenza.

4. Lo script viene eseguito indefinitamente fino a quando non viene interrotto premendo ``Ctrl+C``.

**Codice**

Qui sotto c'è lo script Python per controllare l'interruttore a inclinazione e i LED:

.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat.pin import Pin, Mode, Pull
   from signal import pause  # Import pause function from signal module

   TiltPin = Pin(17, mode=Mode.IN, pull=Pull.DOWN)  # Tilt sensor connected to GPIO pin 17
   green_led = Pin(27,mode=Mode.OUT)  # Green LED connected to GPIO pin 27
   red_led = Pin(22,mode=Mode.OUT)   # Red LED connected to GPIO pin 22

   def detect():
      """
      Detect the tilt sensor state and control the LEDs.
      Turns on the red LED and turns off the green LED when tilted.
      Turns off the red LED and turns on the green LED when not tilted.
      """
      if TiltPin.value() == 0:  # Check if the sensor is tilted
         print('    *************')
         print('    *   Tilt!   *')
         print('    *************')
         red_led.high()   # Turn on red LED
         green_led.low()  # Turn off green LED
      else:  # If the sensor is not tilted
         red_led.low()  # Turn off red LED
         green_led.high()  # Turn on green LED

   try:
      # Set up a callback to detect changes in the tilt sensor state
      TiltPin.when_activated = detect
      TiltPin.when_deactivated = detect
      pause()

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
      pass

**Comprendere il Codice**

1. **Importazioni**

   Lo script importa le classi necessarie per il controllo dei LED e del pulsante e le inizializza con i pin GPIO appropriati.

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      from signal import pause  # Import pause function from signal module


2. **Inizializzazione**

   Configura l'interruttore a inclinazione e i LED collegati ai pin GPIO 17, 27 e 22.

   .. code-block:: python

      TiltPin = Pin(17, mode=Mode.IN, pull=Pull.DOWN)  # Tilt sensor connected to GPIO pin 17
      green_led = Pin(27,mode=Mode.OUT)  # Green LED connected to GPIO pin 27
      red_led = Pin(22,mode=Mode.OUT)   # Red LED connected to GPIO pin 22

3. **Funzione Detect**

   La funzione ``detect`` controlla lo stato dell'interruttore a inclinazione e aggiorna i LED di conseguenza. Se l'interruttore è inclinato, il LED rosso si accende e il LED verde si spegne.

   .. code-block:: python

      def detect():
         if TiltPin.value() == 0:  # Check if the sensor is tilted
            print('    *************')
            print('    *   Tilt!   *')
            print('    *************')
            red_led.high()   # Turn on red LED
            green_led.low()  # Turn off green LED
         else:  # If the sensor is not tilted
            red_led.low()  # Turn off red LED
            green_led.high()  # Turn on green LED

4. **Ciclo Principale**

   Assegna la funzione ``detect`` per gestire gli eventi ``when_pressed`` e ``when_released`` del sensore di inclinazione. Il ciclo continua fino all'interruzione.

   .. code-block:: python

      try:
         # Set up a callback to detect changes in the tilt sensor state
         TiltPin.when_activated = detect
         TiltPin.when_deactivated = detect
         pause()

      except KeyboardInterrupt:
         # Handle KeyboardInterrupt (Ctrl+C) to exit the loop gracefully
         pass

**Risoluzione dei Problemi**

1. **Lo Script Non Risponde all'Inclinazione**

   - **Causa**: I listener di eventi (``when_activated`` e ``when_deactivated``) non funzionano correttamente.
   - **Soluzione**: Conferma che ``detect()`` sia correttamente collegato sia all'evento ``when_activated`` che a ``when_deactivated``.


2. **I LED Sfarfallano**

   - **Causa**: Rumore del sensore o problemi di debounce.
   - **Soluzione**: Aggiungi un breve ritardo per stabilizzare il segnale:

   .. code-block:: python

      from time import sleep
      def detect():
            sleep(0.05)  # Debounce delay
            if TiltPin.value() == 0:
               red_led.on()
               green_led.off()
            else:
               red_led.off()
               green_led.on()

**Idee Estendibili**

1. **Feedback Sonoro**

   Aggiungi un buzzer per fornire feedback audio quando il sensore di inclinazione viene attivato:

   .. code-block:: python

      from fusion_hat import Buzzer,Pin
      buzzer = Buzzer(Pin(4))
      if TiltPin.value() == 0:
         buzzer.on()
      else:
         buzzer.off()


2. **Avvisi Temporizzati**

   Attiva un avviso se il sensore rimane inclinato per una durata specificata:

   .. code-block:: python

      from threading import Timer
      def alert():
         print("Tilt detected for too long!")
         red_led.on()
         sleep(0.5)
         red_led.off()

      if TiltPin.value() == 0:
         Timer(5, alert).start()  # Trigger alert if tilted for 5 seconds
