2.2.3 DHT-11
================

**Einführung**

In dieser Lektion lernst du, wie du einen DHT11-Temperatur- und Luftfeuchtigkeitssensor an einen Raspberry Pi anschließt und dessen Daten ausliest. Der DHT11 ist ein zuverlässiger und kostengünstiger Digitalsensor, der in zahlreichen Anwendungen wie Wetterüberwachung oder Umweltkontrollsystemen eingesetzt wird. Dieses Projekt führt dich in die Anbindung externer Sensoren, die Verarbeitung von Echtzeitdaten sowie in die grundlegende Fehlerbehandlung mit Python ein. Am Ende wirst du in der Lage sein, Temperatur (in Celsius und Fahrenheit) und Luftfeuchtigkeit auszulesen.

**Code schreiben**


Der folgende Python-Code wird in diesem Projekt verwendet:


.. raw:: html

   <run></run>

.. code-block:: python

   from fusion_hat import DHT11
   from time import sleep

   dht11 = DHT11(pin=17)

   while True:
      result = dht11.read()
      if result:
         humidity, temperature = result
         print ("humidity: %s %%,  Temperature: %s C`" % (humidity, temperature))
      else:
         print("time out")
      sleep(1)


Dieses Python-Skript liest Temperatur- und Luftfeuchtigkeitsdaten von einem am Fusion HAT angeschlossenen DHT11-Sensor über GPIO-Pin 17 aus. Beim Ausführen:  

1. Die Daten werden jede Sekunde in der Konsole ausgegeben und liefern Echtzeitwerte.  
2. Falls das Auslesen fehlschlägt, gibt das Skript „time out“ aus, was auf einen Fehler beim Lesen hinweist.  


----------------------------------------------

**Code verstehen**

1. **Import:**

   .. code-block:: python

      from fusion_hat import DHT11
      from time import sleep

   Diese Zeilen importieren die für das Skript erforderlichen Module.  

2. **Sensorinitialisierung:**

   .. code-block:: python

      dht11 = DHT11(pin=17)

   Initialisiert den DHT11-Sensor am GPIO-Pin 17.  

3. **Datenauswertung:**

   .. code-block:: python

      while True:
         result = dht11.read()
         if result:
            humidity, temperature = result
            print ("humidity: %s %%,  Temperature: %s C`" % (humidity, temperature))
         else:
            print("time out")
         sleep(1)

   Die Methode ``read`` sendet ein Startsignal an den DHT11 und gibt die Messwerte zurück.  


----------------------------------------------

**Fehlerbehebung**

1. **Keine Ausgabe oder konstante Werte 0.0°C und 0.0%**:  

   - **Ursache**: Sensoranschluss fehlerhaft.  
   - **Lösung**: Prüfe, ob der DHT11 korrekt an GPIO-Pin 17 sowie an Stromversorgung und Masse angeschlossen ist.  

2. **Skript bricht mit ValueError ab**: 

   - **Ursache**: Beschädigte oder unvollständige Daten vom Sensor.  
   - **Lösung**: Stelle stabile Verbindungen sicher und prüfe, ob der Sensor korrekt arbeitet. Achte darauf, dass die Datenleitung nicht gestört ist.  

3. **Hohe CPU-Auslastung**:  

   - **Ursache**: Ständiges Abfragen des GPIO-Pins ohne Verzögerung.  
   - **Lösung**: Das Skript enthält bereits Verzögerungen (z. B. ``time.sleep(2)``). Stelle sicher, dass diese nicht entfernt wurden.  

4. **Falsche Temperatur- oder Luftfeuchtigkeitswerte**:  

   - **Ursache**: Kalibrierungsproblem oder defekter Sensor.  
   - **Lösung**: Teste den DHT11 in einer kontrollierten Umgebung. Tausche den Sensor aus, falls das Problem bestehen bleibt.  

5. **Skript beendet sich nicht sauber**:  

   - **Ursache**: Fehlende Ausnahmebehandlung für manuelle Unterbrechungen.  
   - **Lösung**: Umfasse die Hauptschleife mit einem ``try...except KeyboardInterrupt``-Block für einen sauberen Abbruch.  

   .. code-block:: python

      try:
         while True:
               humidity, temperature = dht11.read()
               print(f"{time.time():.3f}  Temperature: {temperature}°C  Humidity: {humidity}%")
               time.sleep(2)
      except KeyboardInterrupt:
         print("Exiting gracefully...")

**Erweiterbare Ideen**

1. **Datenaufzeichnung**: Temperatur- und Luftfeuchtigkeitswerte in einer Datei speichern:  

  .. code-block:: python

      with open("dht11_log.txt", "a") as log_file:
          log_file.write(f"{time.time():.3f}, {temperature}°C, {humidity}%\n")


2. **Schwellenwertbasierte Alarme**: Warnungen auslösen, wenn Temperatur oder Luftfeuchtigkeit einen bestimmten Wert überschreiten:  

  .. code-block:: python

      if temperature > 30:
          print("Warning: High temperature!")
      if humidity > 70:
          print("Warning: High humidity!")

----------------------------------------------

**Fazit**

Dieses Projekt zeigt, wie man mit einem DHT11-Temperatur- und Luftfeuchtigkeitssensor über den Fusion HAT arbeitet. Durch das Verständnis der Datenerfassung und -verarbeitung kannst du solche Sensoren in vielfältige praktische Anwendungen integrieren – von Wetterstationen bis hin zu automatisierten Klimasteuerungen.
