4.1 Camera
=================

**Introduction**

Ce projet demontre comment creer un systeme de camera simple avec un declencheur a bouton en utilisant le Raspberry Pi. Lorsque vous appuyez sur le bouton, la camera capture une photo et une LED s’allume pour indiquer l’action. C’est une excellente facon d’acquérir une experience pratique avec le controle GPIO et le module camera Raspberry Pi.

#. Accedez au bureau Raspberry Pi :

   * :ref:`remote_desktop` : Utilisez **VNC** pour une experience de bureau complete.
   * |link_rpi_connect| : Utilisez **Raspberry Pi Connect** pour acceder a votre Pi en toute securite depuis n’importe quel navigateur.

#. Ouvrez un terminal et rendez-vous dans le dossier des codes :

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. Executez le script pour demarrer la camera :

   .. raw:: html

      <run></run>

   .. code-block:: shell

         sudo python3 4.1_Camera.py

#. Apres l’execution du programme, la camera commence a fonctionner.

   - Appuyez sur le bouton pour prendre une photo :

     - La LED s’allume.
     - Une photo est capturee et enregistree dans le dossier ``Pictures``
       (par exemple, ``photo_001.jpg``, ``photo_002.jpg``).

   - Relachez le bouton :

     - La LED s’eteint.

   - Le programme continue de fonctionner jusqu’a ce que vous appuyiez sur **Ctrl + C**, puis se termine proprement
     sans messages d’erreur.

   .. note::
      L’apercu QT necessite un environnement de bureau.
      Si l’apercu ne peut pas etre lance (par exemple, via SSH),
      la camera peut toujours capturer et enregistrer des photos normalement.

**Code**

Voici le code Python utilise pour ce projet :



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize LED and button
   led = Pin(17, mode=Mode.OUT)
   button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nCapturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available (remote SSH often has no DISPLAY)
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:
               preview_started = False
               print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("Press the button to take a photo.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo
                  time.sleep(0.3)        # Simple debounce (avoid multiple shots)
                  while button.value():  # Wait until button is released
                     time.sleep(0.01)
                  led.off()              # LED off after release

               time.sleep(0.01)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         # Turn off LED
         try:
               led.off()
         except Exception:
               pass

         # Stop the camera first
         try:
               camera.stop()
         except Exception:
               pass

         # Stop preview only if it was started
         if preview_started:
               try:
                  camera.stop_preview()
               except Exception:
                  pass

         try:
               camera.close()
         except Exception:
               pass

   if __name__ == "__main__":
      main()

**Comprendre le code**

1. **Importations et objectif**

   .. code-block:: python

      import os
      import time
      import threading
      from picamera2 import Picamera2, Preview
      from fusion_hat.pin import Pin, Mode, Pull

   Ces modules sont responsables de :

   - ``os`` : gerer les variables d’environnement et les chemins de fichiers.
   - ``time`` : fournir des temporisations et maintenir la boucle principale en execution.
   - ``threading`` : garantir que la capture photo est thread-safe.
   - ``Picamera2`` et ``Preview`` : controler la camera Raspberry Pi et les modes d’apercu.
   - ``Pin``, ``Mode`` et ``Pull`` : controler la LED et lire le bouton poussoir via Fusion HAT.

2. **Resolution du repertoire de sauvegarde (fonctionne avec sudo)**

   .. code-block:: python

      REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
      USER_HOME = f"/home/{REAL_USER}"
      PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
      os.makedirs(PICTURES_DIR, exist_ok=True)

   Cette section garantit que les photos sont toujours enregistrees dans le repertoire
   ``~/Pictures`` de l’utilisateur reel :

   - Lorsque le script est execute avec ``sudo``, ``SUDO_USER`` pointe vers l’utilisateur d’origine.
   - Lorsque ``sudo`` n’est pas utilise, l’utilisateur connecte actuel est utilise.
   - Le dossier ``Pictures`` est cree automatiquement s’il n’existe pas.

3. **Initialisation et configuration de la camera**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   La camera est initialisee et configuree pour l’apercu et la capture photo :

   - Une resolution d’apercu de ``800 × 600`` est utilisee.
   - Cette configuration fonctionne avec ou sans fenetre d’apercu visible.

4. **Index photo et securite des threads**

   .. code-block:: python

      photo_index = 1
      photo_lock = threading.Lock()

   - ``photo_index`` stocke le numero de photo actuel.
   - ``photo_lock`` empeche que plusieurs pressions sur le bouton ne declenchent
     des captures photo simultanees.

5. **Suivi de l’etat de l’apercu**

   .. code-block:: python

      preview_started = False

   Ce drapeau enregistre si une fenetre d’apercu a ete demarree avec succes,
   afin que le programme tente d’arreter l’apercu seulement lorsqu’il existe reellement.

6. **Configuration de la LED et du bouton**

   .. code-block:: python

      led = Pin(17, mode=Mode.OUT)
      button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   - La LED est connectee a la GPIO 17 et configuree comme sortie.
   - Le bouton est connecte a la GPIO 4 et configure comme entree avec
     une resistance de tirage vers le bas interne.
   - Un signal HIGH indique que le bouton est presse.

7. **Fonction de capture photo**

   .. code-block:: python

      def take_photo():
         """Capture one photo and increment the index."""
         global photo_index
         with photo_lock:
            filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
            print(f"\nCapturing: {filepath}")
            camera.capture_file(filepath)
            print("Saved.")
            photo_index += 1

   Cette fonction :

   - Construit un nom de fichier tel que ``photo_001.jpg``.
   - Capture une image a l’aide de la camera.
   - Incremente l’index photo pour que la photo suivante utilise un nouveau nom.

8. **Apercu conditionnel pour usage local et distance**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:
               preview_started = False
               print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

   - Si un environnement de bureau est disponible, une fenetre d’apercu QT est affichee.
   - Si l’execution se fait a distance via SSH sans affichage, l’apercu est ignore.
   - La capture photo fonctionne normalement dans les deux cas.

9. **Boucle principale et logique du bouton**

   .. code-block:: python

      try:
         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo
                  time.sleep(0.3)        # Simple debounce (avoid multiple shots)
                  while button.value():  # Wait until button is released
                     time.sleep(0.01)
                  led.off()              # LED off after release

               time.sleep(0.01)

   Dans la boucle principale :

   - Appuyer sur le bouton allume la LED.
   - Une photo est capturee immediatement.
   - Le programme attend que le bouton soit relache pour eviter les prises repetees.
   - La LED s’eteint apres le relachement du bouton.

10. **Sortie propre et nettoyage des ressources**

    .. code-block:: python

         except KeyboardInterrupt:
            print("\nExiting...")

         finally:
            # Turn off LED
            try:
                  led.off()
            except Exception:

         ...

    Lorsque ``Ctrl+C`` est presse :

    - La LED est eteinte.
    - Le pipeline de la camera est arrete.
    - L’apercu est arrete seulement s’il a ete demarre.
    - Les ressources de la camera sont liberees proprement.

    Cela garantit que le programme se termine sans erreurs, qu’il soit execute localement
    avec un ecran ou a distance en mode sans tete.

**Depannage**

1. **Photo non capturee** :

   - **Cause :** Le bouton n’est pas correctement branche ou la camera n’est pas initialisee.
   - **Solution :**

     - Assurez-vous que le bouton est connecte a la broche GPIO 4 et a la masse.
     - Verifiez que la camera est correctement connectee et activee via ``raspi-config``.

2. **La LED ne clignote pas** :

   - **Cause :** Cablage incorrect de la LED ou configuration GPIO erronee.
   - **Solution :**

     - Assurez-vous que la LED est connectee a la broche GPIO 17 avec une resistance appropriee.
     - Testez la LED separement pour confirmer son bon fonctionnement.

3. **Le script plante avec une erreur de camera** :

   - **Cause :** Le module camera n’est pas detecte ou est utilise par un autre processus.
   - **Solution :**

     - Assurez-vous que la camera est correctement connectee et redemarrez le Raspberry Pi.
     - Verifiez les processus concurrents avec ``sudo lsof /dev/video*``.

**Idees d’extension**

1. **Photos multiples** : Permettez de capturer plusieurs photos dans une session, chacune avec un nom de fichier unique :

     .. code-block:: python

         counter = 0
         camera.capture_file(f’{user_home}/photo_{counter}.jpg’)
         counter += 1

2. **Enregistrement video** : Etendez la fonctionnalite pour enregistrer des videos lorsque le bouton est presse :

     .. code-block:: python

         camera.start_recording(f’{user_home}/my_video.h264’)
         time.sleep(10)
         camera.stop_recording()

3. **Indicateur d’etat LED** : Utilisez la LED pour indiquer l’etat de preparation ou le statut de la camera :

     - Lumière fixe : Pret.
     - Clignotement : Capture d’une photo.

4. **Gestion de galerie photo** : Organisez les photos capturees dans des dossiers bases sur la date ou l’evenement.

5. **Photographie en timelapse** : Capturez des photos a intervalles reguliers pour creer un timelapse :

     .. code-block:: python

         for i in range(10):
             camera.capture_file(f’{user_home}/timelapse_{i}.jpg’)
             time.sleep(5)
