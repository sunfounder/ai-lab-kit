4.1 摄像头
==========

**简介**

本项目演示如何使用树莓派 Zero 创建一个带有快门按钮的简单摄像头系统。按下按钮时，摄像头拍摄一张照片，LED 闪烁以指示拍摄动作。这是体验 GPIO 控制和树莓派摄像头模块的绝佳方式。

**运行示例**

#. 访问树莓派桌面：

   * :ref:`remote_desktop`：使用\ **VNC**\ 获得完整的桌面体验。
   * |link_rpi_connect|：使用\ **Raspberry Pi Connect**\ 从任何浏览器安全地访问树莓派。

#. 打开终端并进入代码文件夹：

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. 运行脚本启动摄像头：

   .. raw:: html

      <run></run>

   .. code-block:: shell

         sudo python3 4.1_Camera.py

#. 运行程序后，摄像头开始工作。

   - 按下按钮拍照：

     - LED 点亮。
     - 拍摄一张照片并保存到 ``Pictures`` 文件夹
       （例如 ``photo_001.jpg``、``photo_002.jpg``）。

   - 松开按钮：

     - LED 熄灭。

   - 程序持续运行，直到按下 **Ctrl + C**，然后无错误信息地
     安全退出。

   .. note::
      QT 预览需要桌面环境。
      如果无法启动预览（例如通过 SSH 连接），
      摄像头仍可正常拍摄和保存照片。

**代码**

以下是本项目使用的 Python 代码：



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize LED and button
   led = Pin(17, mode=Mode.OUT)
   button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nCapturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available (remote SSH often has no DISPLAY)
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:
               preview_started = False
               print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("Press the button to take a photo.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo
                  time.sleep(0.3)        # Simple debounce (avoid multiple shots)
                  while button.value():  # Wait until button is released
                     time.sleep(0.01)
                  led.off()              # LED off after release

               time.sleep(0.01)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         # Turn off LED
         try:
               led.off()
         except Exception:
               pass

         # Stop the camera first
         try:
               camera.stop()
         except Exception:
               pass

         # Stop preview only if it was started
         if preview_started:
               try:
                  camera.stop_preview()
               except Exception:
                  pass

         try:
               camera.close()
         except Exception:
               pass

   if __name__ == "__main__":
      main()

**理解代码**

1. **导入与目的**

   .. code-block:: python

      import os
      import time
      import threading
      from picamera2 import Picamera2, Preview
      from fusion_hat.pin import Pin, Mode, Pull

   这些模块负责：

   - ``os``：处理环境变量和文件路径。
   - ``time``：提供延时并保持主循环运行。
   - ``threading``：确保拍照过程线程安全。
   - ``Picamera2`` 和 ``Preview``：控制树莓派摄像头和预览模式。
   - ``Pin``、``Mode`` 和 ``Pull``：通过 Fusion HAT 控制 LED 和读取按钮。

2. **解析保存目录（兼容 sudo）**

   .. code-block:: python

      REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
      USER_HOME = f"/home/{REAL_USER}"
      PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
      os.makedirs(PICTURES_DIR, exist_ok=True)

   此部分确保照片始终保存到真实用户的 ``~/Pictures`` 目录：

   - 使用 ``sudo`` 运行脚本时，``SUDO_USER`` 指向原始用户。
   - 未使用 ``sudo`` 时，使用当前登录用户。
   - 如果 ``Pictures`` 文件夹不存在，则自动创建。

3. **摄像头初始化和配置**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   摄像头被初始化并配置为预览和拍照：

   - 使用 ``800 × 600`` 的预览分辨率。
   - 此配置在有或没有可见预览窗口的情况下均可工作。

4. **照片索引和线程安全**

   .. code-block:: python

      photo_index = 1
      photo_lock = threading.Lock()

   - ``photo_index`` 存储当前照片编号。
   - ``photo_lock`` 防止多次按钮按下触发重叠的拍照操作。

5. **预览状态跟踪**

   .. code-block:: python

      preview_started = False

   此标志记录预览窗口是否成功启动，
   以便程序仅在实际存在预览时才尝试停止它。

6. **LED 和按钮设置**

   .. code-block:: python

      led = Pin(17, mode=Mode.OUT)
      button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   - LED 连接到 GPIO 17，配置为输出。
   - 按钮连接到 GPIO 4，配置为输入并启用内部下拉电阻。
   - HIGH 信号表示按钮已按下。

7. **拍照功能**

   .. code-block:: python

      def take_photo():
         """Capture one photo and increment the index."""
         global photo_index
         with photo_lock:
            filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
            print(f"\nCapturing: {filepath}")
            camera.capture_file(filepath)
            print("Saved.")
            photo_index += 1

   此功能：

   - 构建文件名，例如 ``photo_001.jpg``。
   - 使用摄像头捕获图像。
   - 递增照片索引，使下一张照片使用新名称。

8. **本地和远程使用的条件预览**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:
               preview_started = False
               print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

   - 如果图形桌面可用，则显示 QT 预览窗口。
   - 如果通过 SSH 远程运行且没有显示器，则跳过预览。
   - 拍照功能在两种情况下均正常工作。

9. **主循环和按钮逻辑**

   .. code-block:: python

      try:
         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo
                  time.sleep(0.3)        # Simple debounce (avoid multiple shots)
                  while button.value():  # Wait until button is released
                     time.sleep(0.01)
                  led.off()              # LED off after release

               time.sleep(0.01)

   在主循环中：

   - 按下按钮点亮 LED。
   - 立即拍摄一张照片。
   - 程序等待按钮松开以避免重复拍摄。
   - 按钮松开后 LED 熄灭。

10. **安全退出和资源清理**

    .. code-block:: python

         except KeyboardInterrupt:
            print("\nExiting...")

         finally:
            # Turn off LED
            try:
                  led.off()
            except Exception:

         ...

    当按下 ``Ctrl+C`` 时：

    - LED 关闭。
    - 摄像头管道停止。
    - 仅当预览已启动时才停止预览。
    - 干净地释放摄像头资源。

    无论在有屏幕的本地模式下运行还是在无头的远程模式下运行，
    这都能确保程序无错误退出。

**故障排除**

1. **照片未拍摄**：

   - **原因**：按钮接线不正确或摄像头未初始化。
   - **解决方法**：

     - 确保按钮连接到 GPIO 引脚 4 和 GND。
     - 通过 ``raspi-config`` 验证摄像头是否正确连接并已启用。

2. **LED 不闪烁**：

   - **原因**：LED 接线或 GPIO 配置不正确。
   - **解决方法**：

     - 确保 LED 通过适当的电阻连接到 GPIO 引脚 17。
     - 单独测试 LED 以确认其功能正常。

3. **脚本因摄像头错误崩溃**：

   - **原因**：摄像头模块未被检测到或被其他进程使用。
   - **解决方法**：

     - 确保摄像头正确连接并重启树莓派。
     - 使用 ``sudo lsof /dev/video*`` 检查冲突进程。

1. **多张照片**：允许在会话中捕获多张照片，每张使用唯一的文件名：

     .. code-block:: python

         counter = 0
         camera.capture_file(f'{user_home}/photo_{counter}.jpg')
         counter += 1

2. **视频录制**：扩展功能，在按下按钮时录制视频：

     .. code-block:: python

         camera.start_recording(f'{user_home}/my_video.h264')
         time.sleep(10)
         camera.stop_recording()

3. **LED 状态指示**：使用 LED 指示摄像头的就绪状态：

     - 常亮：就绪。
     - 闪烁：拍照中。

4. **照片库管理**：根据日期或事件将捕获的照片整理到文件夹中。

5. **延时摄影**：按固定间隔捕获照片以创建延时摄影：

     .. code-block:: python

         for i in range(10):
             camera.capture_file(f'{user_home}/timelapse_{i}.jpg')
             time.sleep(5)
