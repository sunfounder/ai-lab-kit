4.1 Fotocamera
===================

**Introduzione**

Questo progetto dimostra come creare un semplice sistema fotografico con un pulsante di scatto usando un Raspberry Pi Zero. Quando premi il pulsante, la fotocamera acquisisce una foto e un LED lampeggia per indicare l'azione. Questo è un ottimo modo per fare esperienza pratica con il controllo GPIO e il modulo fotocamera del Raspberry Pi.

**Esecuzione dell'Esempio**

#. Accedi al Desktop del Raspberry Pi:

   * :ref:`remote_desktop`: Usa **VNC** per un'esperienza desktop completa.
   * |link_rpi_connect|: Usa **Raspberry Pi Connect** per accedere al tuo Pi in modo sicuro da qualsiasi browser.

#. Apri un Terminale e vai alla cartella del codice:

   .. raw:: html

      <run></run>

      cd ~/ai-lab-kit/python

#. Esegui lo script per avviare la fotocamera:

   .. raw:: html

      <run></run>

   .. code-block:: shell

         sudo python3 4.1_Camera.py

#. Dopo aver eseguito il programma, la fotocamera inizia a funzionare.

   - Premi il pulsante per scattare una foto:

     - Il LED si accende.
     - Una foto viene acquisita e salvata nella cartella ``Pictures``
       (ad esempio, ``photo_001.jpg``, ``photo_002.jpg``).

   - Rilascia il pulsante:

     - Il LED si spegne.

   - Il programma continua a funzionare fino a quando non premi **Ctrl + C**, poi esce in modo pulito
     senza messaggi di errore.

   .. note::
      L'anteprima QT richiede un ambiente desktop.
      Se l'anteprima non può essere avviata (ad esempio, tramite SSH),
      la fotocamera può comunque catturare e salvare le foto normalmente.

**Codice**

Ecco il codice Python usato per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize LED and button
   led = Pin(17, mode=Mode.OUT)
   button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nCapturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available (remote SSH often has no DISPLAY)
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:
               preview_started = False
               print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("Press the button to take a photo.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo
                  time.sleep(0.3)        # Simple debounce (avoid multiple shots)
                  while button.value():  # Wait until button is released
                     time.sleep(0.01)
                  led.off()              # LED off after release

               time.sleep(0.01)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         # Turn off LED
         try:
               led.off()
         except Exception:
               pass

         # Stop the camera first
         try:
               camera.stop()
         except Exception:
               pass

         # Stop preview only if it was started
         if preview_started:
               try:
                  camera.stop_preview()
               except Exception:
                  pass

         try:
               camera.close()
         except Exception:
               pass

   if __name__ == "__main__":
      main()

**Comprendere il Codice**

1. **Importazioni e Scopo**

   .. code-block:: python

      import os
      import time
      import threading
      from picamera2 import Picamera2, Preview
      from fusion_hat.pin import Pin, Mode, Pull

   Questi moduli sono responsabili di:

   - ``os``: gestire le variabili d'ambiente e i percorsi file.
   - ``time``: fornire ritardi e mantenere il ciclo principale in esecuzione.
   - ``threading``: garantire che l'acquisizione foto sia thread-safe.
   - ``Picamera2`` e ``Preview``: controllare la fotocamera del Raspberry Pi e le modalità di anteprima.
   - ``Pin``, ``Mode`` e ``Pull``: controllare il LED e leggere il pulsante tramite Fusion HAT.

2. **Risoluzione della Directory di Salvataggio (Funziona con sudo)**

   .. code-block:: python

      REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
      USER_HOME = f"/home/{REAL_USER}"
      PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
      os.makedirs(PICTURES_DIR, exist_ok=True)

   Questa sezione assicura che le foto siano sempre salvate nella directory ``~/Pictures`` dell'utente reale:

   - Quando lo script viene eseguito con ``sudo``, ``SUDO_USER`` punta all'utente originale.
   - Quando non si usa ``sudo``, viene usato l'utente di login corrente.
   - La cartella ``Pictures`` viene creata automaticamente se non esiste.

3. **Inizializzazione e Configurazione della Fotocamera**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   La fotocamera viene inizializzata e configurata per anteprima e acquisizione foto:

   - Viene usata una risoluzione di anteprima di ``800 × 600``.
   - Questa configurazione funziona sia con che senza una finestra di anteprima visibile.

4. **Indice Foto e Sicurezza dei Thread**

   .. code-block:: python

      photo_index = 1
      photo_lock = threading.Lock()

   - ``photo_index`` memorizza il numero corrente della foto.
   - ``photo_lock`` impedisce a pressioni multiple del pulsante di attivare acquisizioni foto sovrapposte.

5. **Tracciamento dello Stato dell'Anteprima**

   .. code-block:: python

      preview_started = False

   Questo flag registra se una finestra di anteprima è stata avviata con successo, in modo che il programma tenti di fermare l'anteprima solo quando esiste effettivamente.

6. **Configurazione del LED e del Pulsante**

   .. code-block:: python

      led = Pin(17, mode=Mode.OUT)
      button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   - Il LED è collegato a GPIO 17 e configurato come uscita.
   - Il pulsante è collegato a GPIO 4 e configurato come ingresso con un resistore pull-down interno.
   - Un segnale HIGH indica che il pulsante è premuto.

7. **Funzione di Acquisizione Foto**

   .. code-block:: python

      def take_photo():
         """Capture one photo and increment the index."""
         global photo_index
         with photo_lock:
            filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
            print(f"\nCapturing: {filepath}")
            camera.capture_file(filepath)
            print("Saved.")
            photo_index += 1

   Questa funzione:

   - Costruisce un nome file come ``photo_001.jpg``.
   - Acquisisce un'immagine usando la fotocamera.
   - Incrementa l'indice foto in modo che la foto successiva usi un nuovo nome.

8. **Anteprima Condizionale per Uso Locale e Remoto**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:
               preview_started = False
               print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

   - Se è disponibile un desktop grafico, viene mostrata una finestra di anteprima QT.
   - Se si esegue in remoto tramite SSH senza display, l'anteprima viene saltata.
   - L'acquisizione foto funziona normalmente in entrambi i casi.

9. **Ciclo Principale e Logica del Pulsante**

   .. code-block:: python

      try:
         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo
                  time.sleep(0.3)        # Simple debounce (avoid multiple shots)
                  while button.value():  # Wait until button is released
                     time.sleep(0.01)
                  led.off()              # LED off after release

               time.sleep(0.01)

   All'interno del ciclo principale:

   - Premere il pulsante accende il LED.
   - Una foto viene acquisita immediatamente.
   - Il programma attende fino al rilascio del pulsante per evitare scatti ripetuti.
   - Il LED si spegne dopo il rilascio del pulsante.

10. **Uscita Pulita e Pulizia delle Risorse**

    .. code-block:: python

         except KeyboardInterrupt:
            print("\nExiting...")

         finally:
            # Turn off LED
            try:
                  led.off()
            except Exception:

         ...

    Quando viene premuto ``Ctrl+C``:

    - Il LED viene spento.
    - La pipeline della fotocamera viene fermata.
    - L'anteprima viene fermata solo se è stata avviata.
    - Le risorse della fotocamera vengono rilasciate in modo pulito.

    Questo assicura che il programma esca senza errori, sia eseguito localmente con uno schermo che in remoto in modalità headless.

**Risoluzione dei Problemi**

1. **Foto Non Acquisita**:

   - **Causa**: Il pulsante non è cablato correttamente o la fotocamera non è inizializzata.
   - **Soluzione**:

     - Assicurati che il pulsante sia collegato al pin GPIO 4 e a massa.
     - Verifica che la fotocamera sia collegata e abilitata tramite ``raspi-config``.

2. **Il LED Non Lampeggia**:

   - **Causa**: Cablaggio LED errato o configurazione GPIO.
   - **Soluzione**:

     - Assicurati che il LED sia collegato al pin GPIO 17 con un resistore appropriato.
     - Testa il LED separatamente per confermare che funzioni correttamente.

3. **Lo Script si Arresta con Errore della Fotocamera**:

   - **Causa**: Il modulo fotocamera non viene rilevato o è in uso da un altro processo.
   - **Soluzione**:

     - Assicurati che la fotocamera sia collegata correttamente e riavvia il Raspberry Pi.
     - Controlla i processi in conflitto usando ``sudo lsof /dev/video*``.

**Idee Estendibili**

1. **Foto Multiple**: Permetti di acquisire più foto in una sessione, ciascuna con un nome file univoco:

     .. code-block:: python

         counter = 0
         camera.capture_file(f'{user_home}/photo_{counter}.jpg')
         counter += 1

2. **Registrazione Video**: Estendi la funzionalità per registrare video quando il pulsante viene premuto:

     .. code-block:: python

         camera.start_recording(f'{user_home}/my_video.h264')
         time.sleep(10)
         camera.stop_recording()

3. **Indicatore LED di Stato**: Usa il LED per indicare la prontezza o lo stato della fotocamera:

     - Luce fissa: Pronto.
     - Lampeggiante: Acquisizione foto in corso.

4. **Gestione Galleria Foto**: Organizza le foto acquisite in cartelle basate su data o evento.

5. **Fotografia Time-lapse**: Acquisisci foto a intervalli regolari per creare un time-lapse:

     .. code-block:: python

         for i in range(10):
             camera.capture_file(f'{user_home}/timelapse_{i}.jpg')
             time.sleep(5)
