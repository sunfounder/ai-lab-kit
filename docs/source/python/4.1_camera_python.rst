4.1 Cámara
==========

**Introducción**

Este proyecto demuestra cómo crear un sistema de cámara simple con un botón de disparo utilizando la Raspberry Pi Zero. Cuando presionas el botón, la cámara captura una foto y un LED parpadea para indicar la acción. Esta es una excelente manera de obtener experiencia práctica con el control de GPIO y el Módulo de Cámara de Raspberry Pi.

#. Accede al escritorio de Raspberry Pi:

   * :ref:`remote_desktop`: Usa **VNC** para una experiencia de escritorio completa.
   * |link_rpi_connect|: Usa **Raspberry Pi Connect** para acceder a tu Pi de forma segura desde cualquier navegador.

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. Ejecuta el script para iniciar la cámara:

   .. raw:: html

      <run></run>

   .. code-block:: shell

         sudo python3 4.1_Camera.py

#. Después de ejecutar el programa, la cámara comienza a funcionar.

   - Presiona el botón para tomar una foto:

     - El LED se enciende.
     - Se captura una foto y se guarda en la carpeta ``Pictures``
       (por ejemplo, ``photo_001.jpg``, ``photo_002.jpg``).

   - Suelta el botón:

     - El LED se apaga.

   - El programa sigue ejecutándose hasta que presiones **Ctrl + C**, luego se cierra limpiamente
     sin mensajes de error.

   .. note::
      La vista previa QT requiere un entorno de escritorio.
      Si la vista previa no puede iniciarse (por ejemplo, a través de SSH),
      la cámara aún puede capturar y guardar fotos normalmente.

**Código**

Aquí está el código Python utilizado para este proyecto:



.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   import os
   import time
   import threading
   from picamera2 import Picamera2, Preview
   from fusion_hat.pin import Pin, Mode, Pull

   # Resolve the correct user's home directory (works with sudo)
   REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
   USER_HOME = f"/home/{REAL_USER}"
   PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
   os.makedirs(PICTURES_DIR, exist_ok=True)

   # Initialize camera
   camera = Picamera2()
   camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   # Photo counter with thread safety
   photo_index = 1
   photo_lock = threading.Lock()

   # Track whether preview was started successfully
   preview_started = False

   # Initialize LED and button
   led = Pin(17, mode=Mode.OUT)
   button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   def take_photo():
      """Capture one photo and increment the index."""
      global photo_index
      with photo_lock:
         filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
         print(f"\nCapturing: {filepath}")
         camera.capture_file(filepath)
         print("Saved.")
         photo_index += 1

   def main():
      global preview_started

      # Start preview only when a GUI display is available (remote SSH often has no DISPLAY)
      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:
               preview_started = False
               print(f"Preview start failed (continue without preview): {e}")
      else:
         print("No DISPLAY detected (running headless without preview).")

      camera.start()

      print("Camera is running.")
      print("Press the button to take a photo.")
      print(f"Photos will be saved to: {PICTURES_DIR}")
      print("Press Ctrl+C to exit.\n")

      try:
         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo
                  time.sleep(0.3)        # Simple debounce (avoid multiple shots)
                  while button.value():  # Wait until button is released
                     time.sleep(0.01)
                  led.off()              # LED off after release

               time.sleep(0.01)

      except KeyboardInterrupt:
         print("\nExiting...")

      finally:
         # Turn off LED
         try:
               led.off()
         except Exception:
               pass

         # Stop the camera first
         try:
               camera.stop()
         except Exception:
               pass

         # Stop preview only if it was started
         if preview_started:
               try:
                  camera.stop_preview()
               except Exception:
                  pass

         try:
               camera.close()
         except Exception:
               pass

   if __name__ == "__main__":
      main()

**Comprender el Código**

1. **Importaciones y Propósito**

   .. code-block:: python

      import os
      import time
      import threading
      from picamera2 import Picamera2, Preview
      from fusion_hat.pin import Pin, Mode, Pull

   Estos módulos se encargan de:

   - ``os``: manejar variables de entorno y rutas de archivos.
   - ``time``: proporcionar retardos y mantener el bucle principal en ejecución.
   - ``threading``: garantizar que la captura de fotos sea segura para hilos.
   - ``Picamera2`` y ``Preview``: controlar la cámara Raspberry Pi y los modos de vista previa.
   - ``Pin``, ``Mode`` y ``Pull``: controlar el LED y leer el pulsador a través de Fusion HAT.

2. **Resolución del Directorio de Guardado (Funciona con sudo)**

   .. code-block:: python

      REAL_USER = os.getenv("SUDO_USER") or os.getlogin()
      USER_HOME = f"/home/{REAL_USER}"
      PICTURES_DIR = os.path.join(USER_HOME, "Pictures")
      os.makedirs(PICTURES_DIR, exist_ok=True)

   Esta sección asegura que las fotos siempre se guarden en el directorio
   ``~/Pictures`` del usuario real:

   - Cuando el script se ejecuta con ``sudo``, ``SUDO_USER`` apunta al usuario original.
   - Cuando no se usa ``sudo``, se utiliza el usuario de inicio de sesión actual.
   - La carpeta ``Pictures`` se crea automáticamente si no existe.

3. **Inicialización y Configuración de la Cámara**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_preview_configuration(main={"size": (800, 600)}))

   La cámara se inicializa y configura para la vista previa y captura de fotos:

   - Se utiliza una resolución de vista previa de ``800 × 600``.
   - Esta configuración funciona tanto con una ventana de vista previa visible como sin ella.

4. **Índice de Fotos y Seguridad de Hilos**

   .. code-block:: python

      photo_index = 1
      photo_lock = threading.Lock()

   - ``photo_index`` almacena el número de foto actual.
   - ``photo_lock`` evita que múltiples pulsaciones de botón disparen
     capturas de fotos superpuestas.

5. **Seguimiento del Estado de la Vista Previa**

   .. code-block:: python

      preview_started = False

   Esta bandera registra si una ventana de vista previa se inició correctamente,
   para que el programa solo intente detener la vista previa cuando realmente existe.

6. **Configuración del LED y el Botón**

   .. code-block:: python

      led = Pin(17, mode=Mode.OUT)
      button = Pin(4, mode=Mode.IN, pull=Pull.DOWN)

   - El LED está conectado al GPIO 17 y configurado como salida.
   - El botón está conectado al GPIO 4 y configurado como entrada con
     una resistencia de pull-down interna.
   - Una señal HIGH indica que el botón está presionado.

7. **Función de Captura de Fotos**

   .. code-block:: python

      def take_photo():
         """Capture one photo and increment the index."""
         global photo_index
         with photo_lock:
            filepath = os.path.join(PICTURES_DIR, f"photo_{photo_index:03d}.jpg")
            print(f"\nCapturing: {filepath}")
            camera.capture_file(filepath)
            print("Saved.")
            photo_index += 1

   Esta función:

   - Construye un nombre de archivo como ``photo_001.jpg``.
   - Captura una imagen usando la cámara.
   - Incrementa el índice de fotos para que la siguiente foto use un nuevo nombre.

8. **Vista Previa Condicional para Uso Local y Remoto**

   .. code-block:: python

      preview_started = False
      if os.getenv("DISPLAY"):
         try:
               camera.start_preview(Preview.QT)
               preview_started = True
         except Exception as e:

   - Si hay un escritorio gráfico disponible, se muestra una ventana de vista previa QT.
   - Si se ejecuta de forma remota a través de SSH sin pantalla, la vista previa se omite.
   - La captura de fotos funciona normalmente en ambos casos.

9. **Bucle Principal y Lógica del Botón**

   .. code-block:: python

         while True:
               if button.value():         # Button pressed (HIGH)
                  led.on()               # LED on
                  take_photo()           # Take photo

                  while button.value():  # Wait until button is released

   Dentro del bucle principal:

   - Presionar el botón enciende el LED.
   - Se captura una foto inmediatamente.
   - El programa espera hasta que se suelte el botón para evitar tomas repetidas.
   - El LED se apaga después de soltar el botón.

10. **Salida Limpia y Liberación de Recursos**

    .. code-block:: python

         except KeyboardInterrupt:
            print("\nExiting...")

         finally:

            try:
                  led.off()
            except Exception:

         ...

    Cuando se presiona ``Ctrl+C``:

    - El LED se apaga.
    - El pipeline de la cámara se detiene.
    - La vista previa se detiene solo si se inició.
    - Los recursos de la cámara se liberan limpiamente.

    Esto asegura que el programa termine sin errores, ya sea que se ejecute localmente
    con pantalla o de forma remota en modo headless.

**Solución de Problemas**

1. **Foto No Capturada**:

   - **Causa**: El botón no está cableado correctamente o la cámara no está inicializada.
   - **Solución**:

     - Asegúrate de que el botón esté conectado al pin GPIO 4 y a tierra.
     - Verifica que la cámara esté correctamente conectada y habilitada mediante ``raspi-config``.

2. **El LED No Parpadea**:

   - **Causa**: Cableado incorrecto del LED o configuración de GPIO.
   - **Solución**:

     - Asegúrate de que el LED esté conectado al pin GPIO 17 con una resistencia adecuada.
     - Prueba el LED por separado para confirmar que funciona correctamente.

3. **El Script Falló con Error de Cámara**:

   - **Causa**: El módulo de la cámara no se detecta o está en uso por otro proceso.
   - **Solución**:

     - Asegúrate de que la cámara esté correctamente conectada y reinicia la Raspberry Pi.
     - Verifica si hay procesos conflictivos usando ``sudo lsof /dev/video*``.

**Ideas para Extender**

1. **Múltiples Fotos**: Permite capturar múltiples fotos en una sesión, cada una con un nombre de archivo único:

     .. code-block:: python

         counter = 0
         camera.capture_file(f'{user_home}/photo_{counter}.jpg')
         counter += 1

2. **Grabación de Video**: Extiende la funcionalidad para grabar videos cuando se presiona el botón:

     .. code-block:: python

         camera.start_recording(f'{user_home}/my_video.h264')
         time.sleep(10)
         camera.stop_recording()

3. **Indicador de Estado LED**: Usa el LED para indicar la disponibilidad o el estado de la cámara:

     - Luz fija: Listo.
     - Parpadeo: Capturando una foto.

4. **Gestión de Galería de Fotos**: Organiza las fotos capturadas en carpetas según la fecha o el evento.

5. **Fotografía Time-lapse**: Captura fotos a intervalos regulares para crear un time-lapse:

     .. code-block:: python

         for i in range(10):
             camera.capture_file(f'{user_home}/timelapse_{i}.jpg')
             time.sleep(5)
