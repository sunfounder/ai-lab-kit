4.1.2 Automatische Aufnahmekamera
===================================

**Introduction**

Stell dir vor, du bist nicht zu Hause, und ein neugieriges Eichhörnchen besucht dein Fensterbrett. Mit diesem Projekt kannst du eine automatische Kamera einrichten, die solche besonderen Momente einfängt. Mithilfe eines Bewegungssensors erkennt die Kamera Bewegungen und macht in regelmäßigen Abständen Fotos.

**Writing the Code**


Hier ist der Python-Code für dieses Projekt:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   from picamera2 import Picamera2, Preview
   from fusion_hat import Pin
   import time
   import os

   # Retrieve the current user's login name and home directory
   user = os.getlogin()
   user_home = os.path.expanduser(f'~{user}')

   # Initialize the camera
   camera = Picamera2()
   camera.start()

   # Initialize the motion sensor on GPIO pin 17
   pir = Pin(17, Pin.IN, Pin.PULL_DOWN) 

   try:
      i = 1  # Initialize the image count
      while True:
         if pir.value() == 1:
               # Capture an image when motion is detected and save it with a unique number
               camera.capture_file(f'{user_home}/capture%s.jpg' % i)
               print('The number is %s' % i)  # Print the image count
               time.sleep(3)  # Wait for 3 seconds before next detection
               i += 1  # Increment the image count
         else:
               # print('waiting')  # Print 'waiting' when no motion is detected
               time.sleep(0.5)  # Check for motion every 0.5 seconds

   except KeyboardInterrupt:
      # Stop the camera and turn off the LED if a KeyboardInterrupt occurs
      camera.stop_preview()
      pass


Dieses Python-Skript kombiniert einen PIR-Bewegungssensor mit einer Raspberry-Pi-Kamera, um ein bewegungsgesteuertes Aufnahmesystem zu realisieren. Beim Ausführen gilt:

1. **Setup**:

   - Der PIR-Sensor wird an GPIO-Pin 17 initialisiert.  
   - Die Kamera wird gestartet und ist aufnahmebereit.  

2. **Motion Detection**:

   - Erkennt der PIR-Sensor eine Bewegung, nimmt die Kamera ein Foto auf und speichert es im Home-Verzeichnis des Benutzers mit Dateinamen wie ``capture_1.jpg``, ``capture_2.jpg`` usw.  
   - Im Terminal erscheint eine Ausgabe wie ``Captured photo #<i>``.  

3. **Continuous Monitoring**:

   - Wird keine Bewegung erkannt, prüft das Skript alle 0,5 Sekunden erneut.  
   - Nach einer Aufnahme pausiert das Skript 3 Sekunden, bevor es weiter prüft.  

4. **Graceful Exit**:

   - Mit ``Ctrl+C`` wird die Kameravorschau gestoppt und das Skript sauber beendet.  


----------------------------------------------

**Understanding the Code**

1. **Imports:**


   .. code-block:: python

      from picamera2 import Picamera2, Preview
      from fusion_hat import Pin
      import time
      import os

   Hier werden Bibliotheken für Kamerasteuerung (``Picamera2``), Bewegungserkennung (``Pin``) sowie Systemfunktionen (``os`` und ``time``) eingebunden.


2. **Camera Initialization:**

   .. code-block:: python

       camera = Picamera2()
       camera.start()

   Erstellt eine Instanz von ``Picamera2`` und startet die Kamera.

3. **PIR Sensor Setup:**

   .. code-block:: python

      # Initialize the motion sensor on GPIO pin 17
      pir = Pin(17, Pin.IN, Pin.PULL_DOWN) 

   Konfiguriert den PIR-Bewegungssensor an GPIO-Pin 17.

4. **Motion Detection Loop:**

   .. code-block:: python

       i = 1
       while True:
           if pir.motion_detected:
               camera.capture_file(f'{user_home}/capture_{i}.jpg')
               print(f'Captured photo #{i}')
               time.sleep(3)
               i += 1
           else:
               print('Waiting for motion...')
               time.sleep(0.5)

   Die Hauptschleife:  

   - Erkennt Bewegung, erstellt und speichert ein Foto.  
   - Gibt die Anzahl aufgenommener Fotos aus.  
   - Wartet 3 Sekunden zwischen Aufnahmen.  
   - Gibt „Waiting for motion…“ aus, wenn keine Bewegung erkannt wird.  

5. **Graceful Exit:**

   .. code-block:: python

      except KeyboardInterrupt:
         camera.stop_preview()

   Behandelt einen Abbruch mit ``Ctrl+C`` und stoppt die Vorschau.

**Troubleshooting**

1. **Keine Fotos aufgenommen**:

   - **Ursache**: PIR-Sensor nicht funktionsfähig oder falsch verdrahtet.  
   - **Lösung**:  

     - Prüfe die Verbindung des Sensors an GPIO 17, Strom und Masse.  
     - Stelle Empfindlichkeit und Verzögerung des PIR-Moduls ein.  

2. **Dateien werden überschrieben**:

   - **Ursache**: Fotos werden unter gleichem Namen gespeichert.  
   - **Lösung**: Das Skript nutzt bereits einen Zähler ``i``. Stelle sicher, dass er korrekt hochgezählt wird.  

3. **PIR erkennt ständig Bewegung**:

   - **Ursache**: Defekter Sensor oder starke Störquellen.  
   - **Lösung**:  

     - Teste den Sensor mit einem Multimeter.  
     - Platziere ihn in einer ruhigen Umgebung, um Fehlalarme zu vermeiden.  

4. **Skript stürzt mit Kamera-Fehler ab**:

   - **Ursache**: Kamera nicht richtig initialisiert oder durch anderen Prozess belegt.  
   - **Lösung**:  

     - Prüfe die Kameraverbindung und aktiviere sie in ``raspi-config``.  
     - Starte den Raspberry Pi neu, um Konflikte zu beseitigen.

      else:
         led.off()

3. **Fotoverwaltung**: Aufnahmen automatisch nach Datum oder Ereignis in Ordner sortieren.

**Conclusion**

Dieses Projekt zeigt, wie man mit einem PIR-Sensor und dem Raspberry-Pi-Kameramodul ein automatisches Aufnahmesystem erstellt. Damit lassen sich unvorhersehbare Momente festhalten und die Möglichkeiten von IoT und Computer Vision erkunden. Mit Erweiterungen wie Videoaufzeichnung oder Cloud-Upload kannst du das System noch vielseitiger einsetzen.
