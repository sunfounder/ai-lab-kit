2.15 Module Capteur IMU 10 Axes
====================================

**Introduction**

Le module IMU (Unite de Mesure Inertielle) 10 axes combine plusieurs capteurs pour fournir des donnees completes de mouvement et environnementales. Il integre un capteur de pression barometrique (SPL06_001) pour la mesure d'altitude, un capteur de mouvement 6 axes (SH3001) pour l'acceleration et la rotation, et un magnetometre 3 axes (QMC6310) pour le cap compas. Ce module sophistique est ideal pour la robotique, les systemes de navigation et les applications de suivi de mouvement.

Ce script Python lit les donnees completes de mouvement et environnementales du module IMU 10 axes. Lors de l'execution :

1. Le script initialise la communication avec les trois capteurs integres via I2C.
2. Chaque capteur est detecte et son adresse I2C est affichee a des fins de verification.
3. La boucle principale lit et affiche en continu les donnees, notamment :

   - L'altitude (pression barometrique)
   - Le cap compas (azimut)
   - L'acceleration 3 axes
   - La vitesse angulaire 3 axes (gyroscope)
   - L'intensite du champ magnetique 3 axes
   - La temperature et la pression atmospherique

4. Les donnees sont mises a jour toutes les 0,5 secondes, fournissant un suivi de mouvement en temps reel.
5. Le programme s'execute jusqu'a ce qu'il soit interrompu avec ``Ctrl+C``, puis se termine proprement.

**Code**

Voici le code Python pour lire les donnees du module IMU 10 axes :

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   """
   Read data from all three sensors on the 10 Axis IMU module:
   - SPL06_001: temperature, pressure, altitude
   - SH3001: temperature, accelerometer, gyroscope
   - QMC6310: compass heading

   Gracefully exits when Ctrl+C is pressed.
   """

   from time import sleep

   # Import Sunfounder sensor modules
   from sunfounder_imu import IMU

   def main():
       imu = IMU()
       sensors = imu.find_sensor()
       if len(sensors) == 0:
           print("No sensor found.")
           return
       for address, class_type in sensors.items():
           name = class_type.__name__
           print(f"Found sensor {name} at address 0x{address:02X}")
       sleep(3)

       try:
           while True:
               data = imu.read()

               print(f"Altitude={data['altitude']:7.2f} m")
               print(f"Azimuth={data['azimuth']:7.2f} °")
               print(f"Acceleration:")
               print(f"  X={data['acceleration'].x:7.2f} m/s²")
               print(f"  Y={data['acceleration'].y:7.2f} m/s²")
               print(f"  Z={data['acceleration'].z:7.2f} m/s²")
               print(f"Gyroscrope:")
               print(f"  X={data['gyroscrope'].x:7.2f} °/s")
               print(f"  Y={data['gyroscrope'].y:7.2f} °/s")
               print(f"  Z={data['gyroscrope'].z:7.2f} °/s")
               print(f"Magenatic:")
               print(f"  X={data['magenatic'].x:7.2f} μT")
               print(f"  Y={data['magenatic'].y:7.2f} μT")
               print(f"  Z={data['magenatic'].z:7.2f} μT")
               print(f"Temperature={data['temperature']:7.2f} °C")
               print(f"Pressure={data['pressure']:7.2f} hPa")

               sleep(0.5)

       except KeyboardInterrupt:
           print("\nExiting program...")


   if __name__ == "__main__":
       main()

**Comprendre le code**

1. **Importations et configuration :**

   .. code-block:: python

      from time import sleep
      from sunfounder_imu import IMU

   Le script importe les modules necessaires : ``sleep`` pour les pauses de temporisation et la classe ``IMU`` de la bibliotheque Sunfounder pour communiquer avec le module capteur.

2. **Initialisation du capteur :**

   .. code-block:: python

      imu = IMU()
      sensors = imu.find_sensor()
      if len(sensors) == 0:
          print("No sensor found.")

   Cree un objet IMU et recherche les capteurs connectes sur le bus I2C. Si aucun capteur n'est trouve, le programme se termine.

3. **Detection du capteur :**

   .. code-block:: python

          name = class_type.__name__
          print(f"Found sensor {name} at address 0x{address:02X}")

   Affiche les informations sur chaque capteur detecte, y compris son type et son adresse I2C a des fins de debogage.

4. **Boucle principale de lecture des donnees :**

   .. code-block:: python

          data = imu.read()
          # Display all sensor readings with formatted output

   - Appelle ``imu.read()`` pour obtenir toutes les donnees des capteurs dans un seul dictionnaire.
   - Formate et affiche chaque parametre avec une precision decimale coherente.
   - Inclut une pause de 0,5 seconde pour equilibrer le taux de mise a jour et la lisibilite.

5. **Arret propre :**

   .. code-block:: python

          print("\nExiting program...")

   Capture l'exception KeyboardInterrupt pour permettre une terminaison propre du programme lorsque ``Ctrl+C`` est presse.

**Depannage**

1. **Aucun capteur trouve** :

   - **Cause** : Cablage incorrect ou problemes de communication I2C.
   - **Solution** :

      - Verifiez toutes les connexions : VCC, GND, SDA, SCL.
      - Verifiez si I2C est active sur le Raspberry Pi : ``sudo raspi-config`` → Interface Options → I2C.
      - Executez ``i2cdetect -y 1`` pour voir si les capteurs apparaissent a leurs adresses.

2. **Lectures incoherentes ou erratiques** :

   - **Cause** : Interferences electriques ou problemes d'etalonnage du capteur.
   - **Solution** :

      - Eloignez le module des champs magnetiques puissants ou des moteurs.
      - Assurez-vous d'une alimentation stable avec des condensateurs de decouplage appropries.
      - Placez le module sur une surface stable pendant la mesure.

3. **Lectures d'altitude incorrectes** :

   - **Cause** : Reference de pression barometrique non etalonnee.
   - **Solution** : L'altitude est calculee par rapport a la pression au niveau de la mer. Pour des lectures precises, calibrez avec une altitude connue ou mettez a jour la reference de pression au niveau de la mer.

4. **Cap compas imprecis** :

   - **Cause** : Interferences magnetiques locales ou etalonnage incorrect.
   - **Solution** :

      - Effectuez l'etalonnage du magnetometre en faisant pivoter le module en forme de 8.
      - Eloignez-vous des objets metalliques, des ordinateurs et d'autres sources magnetiques.
