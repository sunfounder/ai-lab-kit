2.15 10轴IMU传感器模块
=======================

**介绍**

10轴IMU（惯性测量单元）模块结合了多个传感器，提供全面的运动和環境数据。它集成了用于海拔测量的气压传感器（SPL06_001）、用于加速度和角速度测量的6轴运动传感器（SH3001）以及用于罗盘航向的3轴磁力计（QMC6310）。这款精密的模块非常适合用于机器人、导航系统和运动跟踪应用。

此Python脚本从10轴IMU模块读取全面的运动和環境数据。执行时：

1. 脚本通过I2C初始化与所有三个集成传感器的通信。
2. 每个传感器都被检测到，并显示其I2C地址以供验证。
3. 主循环持续读取并显示数据，包括：

   - 海拔高度（来自气压）
   - 罗盘航向（方位角）
   - 三轴加速度
   - 三轴角速度（陀螺仪）
   - 三轴磁场强度
   - 温度和大气压力

4. 数据每0.5秒更新一次，提供实时运动跟踪。
5. 程序运行直到用\ ``Ctrl+C``\ 中断，然后优雅退出。

**代码**

以下是读取10轴IMU模块数据的Python代码：

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   """
   Read data from all three sensors on the 10 Axis IMU module:
   - SPL06_001: temperature, pressure, altitude
   - SH3001: temperature, accelerometer, gyroscope
   - QMC6310: compass heading

   Gracefully exits when Ctrl+C is pressed.
   """

   from time import sleep

   # Import Sunfounder sensor modules
   from sunfounder_imu import IMU

   def main():
       imu = IMU()
       sensors = imu.find_sensor()
       if len(sensors) == 0:
           print("No sensor found.")
           return
       for address, class_type in sensors.items():
           name = class_type.__name__
           print(f"Found sensor {name} at address 0x{address:02X}")
       sleep(3)

       try:
           while True:
               data = imu.read()

               print(f"Altitude={data['altitude']:7.2f} m")
               print(f"Azimuth={data['azimuth']:7.2f} °")
               print(f"Acceleration:")
               print(f"  X={data['acceleration'].x:7.2f} m/s²")
               print(f"  Y={data['acceleration'].y:7.2f} m/s²")
               print(f"  Z={data['acceleration'].z:7.2f} m/s²")
               print(f"Gyroscrope:")
               print(f"  X={data['gyroscrope'].x:7.2f} °/s")
               print(f"  Y={data['gyroscrope'].y:7.2f} °/s")
               print(f"  Z={data['gyroscrope'].z:7.2f} °/s")
               print(f"Magenatic:")
               print(f"  X={data['magenatic'].x:7.2f} μT")
               print(f"  Y={data['magenatic'].y:7.2f} μT")
               print(f"  Z={data['magenatic'].z:7.2f} μT")
               print(f"Temperature={data['temperature']:7.2f} °C")
               print(f"Pressure={data['pressure']:7.2f} hPa")

               sleep(0.5)

       except KeyboardInterrupt:
           print("\nExiting program...")


   if __name__ == "__main__":
       main()

**理解代码**

1. **导入和设置：**

   .. code-block:: python

      from time import sleep
      from sunfounder_imu import IMU

   脚本导入必要的模块：\ ``sleep``\ 用于定时延迟，\ ``IMU``\ 类来自Sunfounder库，用于与传感器模块通信。

2. **传感器初始化：**

   .. code-block:: python

      imu = IMU()
      sensors = imu.find_sensor()
      if len(sensors) == 0:
          print("No sensor found.")
          return

   创建IMU对象并在I2C总线上扫描连接的传感器。如果未找到传感器，程序退出。

3. **传感器检测：**

   .. code-block:: python

      for address, class_type in sensors.items():
          name = class_type.__name__
          print(f"Found sensor {name} at address 0x{address:02X}")

   显示每个检测到的传感器的信息，包括其类型和I2C地址，用于调试目的。

4. **主数据读取循环：**

   .. code-block:: python

      while True:
          data = imu.read()
          # Display all sensor readings with formatted output
          sleep(0.5)

   - 调用\ ``imu.read()``\ 获取单个字典中的所有传感器数据。
   - 以一致的小数精度格式化并显示每个参数。
   - 包含0.5秒的延迟以平衡更新速率和可读性。

5. **优雅退出：**

   .. code-block:: python

      except KeyboardInterrupt:
          print("\nExiting program...")

   捕获KeyboardInterrupt异常，允许在按下\ ``Ctrl+C``\ 时干净地终止程序。

**故障排除**

1. **未找到传感器**：

   - **原因**：接线错误或I2C通信问题。
   - **解决方案**：

      - 检查所有连接：VCC、GND、SDA、SCL。
      - 检查Raspberry Pi上是否已启用I2C：\ ``sudo raspi-config``\ → 接口选项 → I2C。
      - 运行\ ``i2cdetect -y 1``\ 查看传感器是否在其地址处出现。

2. **读数不一致或不稳定**：

   - **原因**：电气干扰或传感器校准问题。
   - **解决方案**：

      - 使模块远离强磁场或电机。
      - 确保稳定的电源并配有合适的去耦电容。
      - 在测量时将模块放置在稳定表面上。

3. **海拔读数不正确**：

   - **原因**：气压参考未校准。
   - **解决方案**：海拔是相对于海平面压力计算的。为获得准确读数，请使用已知海拔校准或更新海平面压力参考。

4. **罗盘航向不准确**：

   - **原因**：局部磁场干扰或校准不当。
   - **解决方案**：

      - 通过以8字形旋转模块来执行磁力计校准。
      - 远离金属物体、计算机和其他磁源。
