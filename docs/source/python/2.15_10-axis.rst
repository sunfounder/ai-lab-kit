2.15 Módulo de Sensor IMU de 10 Ejes
======================================

**Introducción**

El módulo IMU (Unidad de Medición Inercial) de 10 Ejes combina múltiples sensores para proporcionar datos completos de movimiento y entorno. Integra un sensor de presión barométrica (SPL06_001) para medición de altitud, un sensor de movimiento de 6 ejes (SH3001) para aceleración y rotación, y un magnetómetro de 3 ejes (QMC6310) para rumbo de brújula. Este módulo sofisticado es ideal para robótica, sistemas de navegación y aplicaciones de seguimiento de movimiento.

Este script de Python lee datos completos de movimiento y entorno del módulo IMU de 10 Ejes. Al ejecutarse:

1. El script inicializa la comunicación con los tres sensores integrados a través de I2C.
2. Cada sensor se detecta y su dirección I2C se muestra para verificación.
3. El bucle principal lee y muestra continuamente datos que incluyen:

   - Altitud (de la presión barométrica)
   - Rumbo de brújula (acimut)
   - Aceleración de 3 ejes
   - Velocidad angular de 3 ejes (giróscopo)
   - Intensidad del campo magnético de 3 ejes
   - Temperatura y presión atmosférica

4. Los datos se actualizan cada 0.5 segundos, proporcionando seguimiento de movimiento en tiempo real.
5. El programa se ejecuta hasta que se interrumpe con ``Ctrl+C``, luego sale de forma segura.

**Código**

A continuación se muestra el código Python para leer datos del módulo IMU de 10 Ejes:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   """
   Read data from all three sensors on the 10 Axis IMU module:
   - SPL06_001: temperature, pressure, altitude
   - SH3001: temperature, accelerometer, gyroscope
   - QMC6310: compass heading

   Gracefully exits when Ctrl+C is pressed.
   """

   from time import sleep

   # Import Sunfounder sensor modules
   from sunfounder_imu import IMU

   def main():
       imu = IMU()
       sensors = imu.find_sensor()
       if len(sensors) == 0:
           print("No sensor found.")
           return
       for address, class_type in sensors.items():
           name = class_type.__name__
           print(f"Found sensor {name} at address 0x{address:02X}")
       sleep(3)

       try:
           while True:
               data = imu.read()

               print(f"Altitude={data['altitude']:7.2f} m")
               print(f"Azimuth={data['azimuth']:7.2f} °")
               print(f"Acceleration:")
               print(f"  X={data['acceleration'].x:7.2f} m/s²")
               print(f"  Y={data['acceleration'].y:7.2f} m/s²")
               print(f"  Z={data['acceleration'].z:7.2f} m/s²")
               print(f"Gyroscrope:")
               print(f"  X={data['gyroscrope'].x:7.2f} °/s")
               print(f"  Y={data['gyroscrope'].y:7.2f} °/s")
               print(f"  Z={data['gyroscrope'].z:7.2f} °/s")
               print(f"Magenatic:")
               print(f"  X={data['magenatic'].x:7.2f} μT")
               print(f"  Y={data['magenatic'].y:7.2f} μT")
               print(f"  Z={data['magenatic'].z:7.2f} μT")
               print(f"Temperature={data['temperature']:7.2f} °C")
               print(f"Pressure={data['pressure']:7.2f} hPa")

               sleep(0.5)

       except KeyboardInterrupt:
           print("\nExiting program...")


   if __name__ == "__main__":
       main()

**Comprender el Código**

1. **Importaciones y Configuración:**

   .. code-block:: python

      from time import sleep
      from sunfounder_imu import IMU

   El script importa los módulos necesarios: ``sleep`` para retardos de tiempo y la clase ``IMU`` de la biblioteca Sunfounder para comunicarse con el módulo sensor.

2. **Inicialización del Sensor:**

   .. code-block:: python

      imu = IMU()
      sensors = imu.find_sensor()
      if len(sensors) == 0:
          print("No sensor found.")
          return

   Crea un objeto IMU y escanea en busca de sensores conectados en el bus I2C. Si no se encuentran sensores, el programa sale.

3. **Detección de Sensores:**

   .. code-block:: python

          name = class_type.__name__
          print(f"Found sensor {name} at address 0x{address:02X}")

   Muestra información sobre cada sensor detectado, incluyendo su tipo y dirección I2C para fines de depuración.

4. **Bucle Principal de Lectura de Datos:**

   .. code-block:: python

          # Display all sensor readings with formatted output
          sleep(0.5)

   - Llama a ``imu.read()`` para obtener todos los datos del sensor en un solo diccionario
   - Formatea y muestra cada parámetro con precisión decimal consistente

**Solución de Problemas**

1. **No se encuentran sensores**:

   - **Causa**: Cableado incorrecto o problemas de comunicación I2C.
   - **Solución**:

      - Verifica todas las conexiones: VCC, GND, SDA, SCL
      - Comprueba si I2C está habilitado en Raspberry Pi: ``sudo raspi-config`` → Interface Options → I2C
      - Ejecuta ``i2cdetect -y 1`` para ver si los sensores aparecen en sus direcciones

2. **Lecturas inconsistentes o erráticas**:

   - **Causa**: Interferencia eléctrica o problemas de calibración del sensor.
   - **Solución**:

      - Mantén el módulo alejado de campos magnéticos fuertes o motores
      - Asegura una fuente de alimentación estable con condensadores de desacoplo adecuados
      - Coloca el módulo sobre una superficie estable durante la medición

3. **Lecturas de altitud incorrectas**:

   - **Causa**: Referencia de presión barométrica sin calibrar.
   - **Solución**: La altitud se calcula en relación con la presión a nivel del mar. Para lecturas precisas, calibra con una altitud conocida o actualiza la referencia de presión a nivel del mar.

4. **Rumbo de brújula inexacto**:

   - **Causa**: Interferencia magnética local o calibración incorrecta.
   - **Solución**:

      - Realiza la calibración del magnetómetro rotando el módulo en un patrón de figura 8
      - Mantén alejado de objetos metálicos, computadoras y otras fuentes magnéticas
