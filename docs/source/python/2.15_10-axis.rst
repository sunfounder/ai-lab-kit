2.15 Modulo Sensore IMU a 10 Assi
===============================

**Introduzione**

Il modulo IMU (Inertial Measurement Unit) a 10 assi combina più sensori per fornire dati completi sul movimento e sull'ambiente. Integra un sensore di pressione barometrica (SPL06_001) per la misurazione dell'altitudine, un sensore di movimento a 6 assi (SH3001) per accelerazione e rotazione, e un magnetometro a 3 assi (QMC6310) per la direzione bussola. Questo modulo sofisticato è ideale per applicazioni di robotica, sistemi di navigazione e tracciamento del movimento.

**Codice**

Qui sotto c'è il codice Python per leggere i dati dal modulo IMU a 10 assi:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   """
   Read data from all three sensors on the 10 Axis IMU module:
   - SPL06_001: temperature, pressure, altitude
   - SH3001: temperature, accelerometer, gyroscope
   - QMC6310: compass heading

   Gracefully exits when Ctrl+C is pressed.
   """

   from time import sleep

   # Import Sunfounder sensor modules
   from sunfounder_imu import IMU

   def main():
       imu = IMU()
       sensors = imu.find_sensor()
       if len(sensors) == 0:
           print("No sensor found.")
           return
       for address, class_type in sensors.items():
           name = class_type.__name__
           print(f"Found sensor {name} at address 0x{address:02X}")
       sleep(3)

       try:
           while True:
               data = imu.read()

               print(f"Altitude={data['altitude']:7.2f} m")
               print(f"Azimuth={data['azimuth']:7.2f} °")
               print(f"Acceleration:")
               print(f"  X={data['acceleration'].x:7.2f} m/s²")
               print(f"  Y={data['acceleration'].y:7.2f} m/s²")
               print(f"  Z={data['acceleration'].z:7.2f} m/s²")
               print(f"Gyroscrope:")
               print(f"  X={data['gyroscrope'].x:7.2f} °/s")
               print(f"  Y={data['gyroscrope'].y:7.2f} °/s")
               print(f"  Z={data['gyroscrope'].z:7.2f} °/s")
               print(f"Magenatic:")
               print(f"  X={data['magenatic'].x:7.2f} μT")
               print(f"  Y={data['magenatic'].y:7.2f} μT")
               print(f"  Z={data['magenatic'].z:7.2f} μT")
               print(f"Temperature={data['temperature']:7.2f} °C")
               print(f"Pressure={data['pressure']:7.2f} hPa")

               sleep(0.5)

       except KeyboardInterrupt:
           print("\nExiting program...")


   if __name__ == "__main__":
       main()

2. **Inizializzazione del Sensore:**

   .. code-block:: python

   Crea un oggetto IMU e cerca i sensori collegati sul bus I2C. Se non vengono trovati sensori, il programma esce.

**Risoluzione dei Problemi**

1. **Nessun Sensore Trovato**:

   - **Causa**: Cablaggio errato o problemi di comunicazione I2C.
   - **Soluzione**:

      - Verifica tutte le connessioni: VCC, GND, SDA, SCL
      - Controlla se I2C è abilitato sul Raspberry Pi: ``sudo raspi-config`` → Opzioni di Interfaccia → I2C
      - Esegui ``i2cdetect -y 1`` per vedere se i sensori appaiono ai loro indirizzi

2. **Letture Inconsistenti o Irregolari**:

   - **Causa**: Interferenza elettrica o problemi di calibrazione del sensore.
   - **Soluzione**:

      - Tieni il modulo lontano da campi magnetici forti o motori
      - Assicura un'alimentazione stabile con condensatori di disaccoppiamento adeguati
      - Posiziona il modulo su una superficie stabile durante la misurazione

3. **Letture di Altitudine Errate**:

   - **Causa**: Riferimento di pressione barometrica non calibrato.
   - **Soluzione**: L'altitudine viene calcolata rispetto alla pressione a livello del mare. Per letture accurate, calibra con un'altitudine nota o aggiorna il riferimento di pressione a livello del mare.

4. **Direzione Bussola Imprecisa**:

   - **Causa**: Interferenza magnetica locale o calibrazione impropria.
   - **Soluzione**:

      - Esegui la calibrazione del magnetometro ruotando il modulo con un movimento a figura 8
      - Tienilo lontano da oggetti metallici, computer e altre fonti magnetiche

**Conclusione**

Questo progetto dimostra come usare un modulo IMU a 10 assi per ottenere dati completi sul movimento e sull'ambiente con un Raspberry Pi. Integrando sensori di pressione, accelerazione, rotazione e campo magnetico, questo modulo fornisce una soluzione di misura inerziale completa adatta per applicazioni avanzate come la stabilizzazione di droni, la navigazione robotica e i sistemi di tracciamento del movimento.
