3.2 Módulo de Video
=====================

**Introducción**

Además de tomar fotos, el Módulo de Cámara Raspberry Pi también te permite grabar videos de alta calidad. Este proyecto demuestra cómo configurar el módulo de cámara para grabar videos con resolución, velocidad de fotogramas y tasa de bits configurables, guardándolos directamente en tu Raspberry Pi.

**Procedimientos Experimentales**

#. Para usar el módulo de cámara de forma conveniente, se recomienda :ref:`assemble_fusion_hat_pan_tilt`.

   .. note::

     El montaje del pan-tilt puede obstruir algunos pines, por lo que se recomienda ensamblarlo solo cuando se use la cámara, o colocarlo en la parte exterior después del montaje.


   .. image:: ../quick_start/img/gimbal_assemble.png

#. Accede al escritorio de Raspberry Pi:

   * :ref:`remote_desktop`: Usa **VNC** para una experiencia de escritorio completa.
   * |link_rpi_connect|: Usa **Raspberry Pi Connect** para acceder a tu Pi de forma segura desde cualquier navegador.

#. Abre una Terminal y navega a la carpeta del proyecto:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. Ejecuta el script de grabación de video:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 3.2_Video.py

#. Después de que el script se inicie, presiona el **botón USR de Fusion HAT+** para controlar la grabación.

   .. image:: img/3.1_user_button.png
      :width: 50%

   * Primera pulsación → **Iniciar grabación** con vista previa en vivo.
   * Segunda pulsación → **Detener grabación**.
   * Los videos se guardan en tu directorio ``~/Videos`` con nombres como:
     ``video_20250101_153045.mp4``.
   * Presiona ``Ctrl+C`` en la terminal para salir del programa.

   .. image:: img/3.2_record_video.png
      :width: 70%


.. note::
   La vista previa QT requiere un entorno de escritorio.
   Si la vista previa no se puede iniciar (por ejemplo, a través de SSH),
   la cámara aún puede capturar y guardar fotos con normalidad.

**Código**

A continuación se muestra el código Python utilizado para este proyecto:

.. raw:: html

   <run></run>

.. code-block:: python

   import os
   import time
   import pwd
   from picamera2 import Picamera2, Preview
   from picamera2.encoders import H264Encoder
   from picamera2.outputs import FfmpegOutput
   from fusion_hat.user_button import UserButton

   # ----- Paths (works correctly even when using sudo) -----
   sudo_user = os.getenv("SUDO_USER")
   home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
   videos_dir = os.path.join(home, "Videos")
   os.makedirs(videos_dir, exist_ok=True)

   # ----- Camera / encoder -----
   camera = Picamera2()
   camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
   encoder = H264Encoder(bitrate=10_000_000)

   is_recording = False
   output = None
   preview_started = False

   def start_recording():
      """Start recording to a timestamped MP4 file."""
      global is_recording, output
      ts = time.strftime("%Y%m%d_%H%M%S")
      path = os.path.join(videos_dir, f"video_{ts}.mp4")
      output = FfmpegOutput(path)  # keep a reference while recording
      camera.start_recording(encoder, output)
      is_recording = True
      print(f"\nStart recording: {path}")

   def stop_recording():
      """Stop recording safely."""
      global is_recording, output
      camera.stop_recording()
      is_recording = False
      output = None
      print("\nStop recording.")

   def toggle():
      """USR button callback: toggle start/stop."""
      if not is_recording:
         start_recording()
      else:
         stop_recording()

   # ----- Button -----
   UserButton().set_on_click(toggle)

   # ----- Preview (only if a GUI display is available) -----
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception:
         preview_started = False  # continue without preview

   # ----- Run -----
   camera.start()
   print("Press USR to START/STOP recording. Ctrl+C to exit.")

   try:
      while True:
         time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      # Stop recording if still active
      if is_recording:
         try:
               camera.stop_recording()
         except Exception:
               pass

      # Stop preview only if it was started
      if preview_started:
         try:
               camera.stop_preview()
         except Exception:
               pass
      try:
         camera.stop()
      except Exception:
         pass
      try:
         camera.close()
      except Exception:
         pass

**Comprender el Código**


**Comprender el Código**

1. **Importaciones y Propósito**

   .. code-block:: python

      import os
      import time
      import pwd
      from picamera2 import Picamera2, Preview
      from picamera2.encoders import H264Encoder
      from picamera2.outputs import FfmpegOutput
      from fusion_hat.user_button import UserButton

   Estos módulos se utilizan para:

   - ``os``: leer variables de entorno (por ejemplo, ``DISPLAY``, ``SUDO_USER``) y construir rutas de archivos.
   - ``time``: generar nombres de archivo con marca de tiempo y mantener el programa ejecutándose en un bucle.
   - ``pwd``: encontrar el directorio principal del usuario real cuando el script se ejecuta con ``sudo``.
   - ``Picamera2`` / ``Preview``: controlar el pipeline de la cámara y los modos de vista previa.
   - ``H264Encoder``: codificar fotogramas de video en formato H.264.
   - ``FfmpegOutput``: guardar el flujo codificado en un archivo ``.mp4`` usando FFmpeg.
   - ``UserButton``: leer el botón USR de Fusion HAT+ y vincular una devolución de llamada de clic.

2. **Selección del Directorio de Guardado Correcto (Funciona con sudo)**

   .. code-block:: python

      sudo_user = os.getenv("SUDO_USER")
      home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
      videos_dir = os.path.join(home, "Videos")
      os.makedirs(videos_dir, exist_ok=True)

   Esto asegura que los videos se guarden en la carpeta ``~/Videos`` del *usuario real*:

   - Cuando se ejecuta con ``sudo``, ``SUDO_USER`` apunta al usuario original.
   - ``pwd.getpwnam(...).pw_dir`` devuelve el directorio principal de ese usuario.
   - Si no se usa ``sudo``, se usa el directorio principal del usuario actual (``~``).
   - Se crea ``~/Videos`` si no existe.

3. **Inicialización de la Cámara y el Codificador de Video**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
      encoder = H264Encoder(bitrate=10_000_000)

   - ``create_video_configuration(...)`` configura el pipeline de la cámara para grabar video.
   - ``size=(800, 600)`` elige la resolución de grabación.
   - ``FrameRate=30`` graba a 30 FPS.
   - ``H264Encoder`` comprime el flujo a H.264 a aproximadamente 10 Mbps.

4. **Variables de Estado de Grabación**

   .. code-block:: python

      is_recording = False
      output = None
      preview_started = False

   - ``is_recording`` rastrea si la grabación está activa actualmente.
   - ``output`` almacena el objeto ``FfmpegOutput`` para mantenerlo vivo durante la grabación.
   - ``preview_started`` registra si una ventana de vista previa se inició correctamente,
     para que solo detengamos la vista previa si realmente existe.

5. **Iniciar una Grabación**

   .. code-block:: python

      def start_recording():
         """Start recording to a timestamped MP4 file."""
         global is_recording, output
         ts = time.strftime("%Y%m%d_%H%M%S")
         path = os.path.join(videos_dir, f"video_{ts}.mp4")
         output = FfmpegOutput(path)  # keep a reference while recording
         camera.start_recording(encoder, output)
         is_recording = True
         print(f"\nStart recording: {path}")

   Cuando comienza la grabación:

   - Se genera un nombre de archivo con marca de tiempo (por ejemplo, ``video_20260203_154500.mp4``).
   - Se crea un nuevo ``FfmpegOutput`` para ese archivo.
   - ``camera.start_recording(...)`` comienza a codificar y escribir el flujo de video.

6. **Detener una Grabación**

   .. code-block:: python

      def stop_recording():
         """Stop recording safely."""
         global is_recording, output
         camera.stop_recording()
         is_recording = False
         output = None
         print("\nStop recording.")

   Cuando se detiene la grabación:

   - ``camera.stop_recording()`` finaliza el archivo de salida correctamente.
   - La referencia de salida se limpia para que el objeto pueda ser liberado.

7. **Control de Alternancia del Botón USR**

   .. code-block:: python

      def toggle():
          if not is_recording:
              start_recording()
          else:
              stop_recording()

      UserButton().set_on_click(toggle)

   Cada pulsación del botón USR de Fusion HAT+ alterna la grabación:

   - Primera pulsación → iniciar grabación.
   - Segunda pulsación → detener grabación.

8. **Lógica de Vista Previa (Funciona con o sin Pantalla)**

   .. code-block:: python

      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception:
              preview_started = False

   - Si hay una interfaz gráfica de escritorio disponible (``DISPLAY`` está configurada), el script intenta una vista previa QT.
   - Si no hay pantalla/interfaz gráfica disponible (como SSH sin X11), omite la vista previa de forma segura
     y la grabación sigue funcionando con normalidad.

9. **Bucle Principal y Salida Limpia (Ctrl+C)**

   .. code-block:: python

      camera.start()
      try:
          while True:
              time.sleep(0.1)
      except KeyboardInterrupt:
          pass
      finally:
          if is_recording:
              camera.stop_recording()
          if preview_started:
              camera.stop_preview()
          camera.stop()
          camera.close()

   - ``camera.start()`` inicia el pipeline de la cámara.
   - El bucle mantiene el script en ejecución para que pueda responder a las pulsaciones de botones.
   - Cuando se presiona Ctrl+C, se ejecuta el bloque ``finally``:
     - Detiene la grabación si está activa (evita archivos de video corruptos).
     - Detiene la vista previa solo si se inició (evita errores relacionados con la vista previa).
     - Detiene y cierra la cámara para liberar los recursos del hardware de forma limpia.


-----------

**Solución de Problemas**


1. **Sin Ventana de Vista Previa**

   - **Causa:** Ejecución sin un entorno de escritorio o falta de soporte GUI de Picamera2.
   - **Solución:** Usa Raspberry Pi Desktop/VNC e instala Picamera2:

   .. raw:: html

      <run></run>

   .. code-block:: shell

        sudo apt install -y python3-picamera2

2. **El Botón USR No Funciona**

   - **Causa:** Fusion HAT+ no conectado o permisos insuficientes.
   - **Solución:** Vuelve a colocar el HAT, ejecuta el script con ``sudo`` e imprime registros de depuración en ``toggle_recording()`` si es necesario.

3. **Video No Guardado**

   - **Causa:** Directorio principal incorrecto al usar ``sudo`` o falta la carpeta ``~/Videos``.
   - **Solución:** Verifica los valores de ``REAL_USER`` y ``VIDEOS_DIR``. Asegúrate de que ``~/Videos`` exista y sea escribible.

4. **La Grabación se Inicia/Detiene Inesperadamente**

   - **Causa:** Cámara en uso por otro proceso o el sistema bajo carga pesada.
   - **Solución:** Cierra otras aplicaciones de cámara, reinicia la Pi y asegúrate de que ``ffmpeg`` esté instalado.

5. **Archivo No Finalizado**

   - **Causa:** Script terminado abruptamente antes de detener la grabación.
   - **Solución:** Siempre sal con ``Ctrl+C`` para que el script pueda detener la grabación correctamente.

------

**Conclusión**

Este script te permite iniciar y detener la grabación de video usando el botón USR de Fusion HAT+ mientras ves una vista previa en vivo. Los videos se guardan automáticamente en ``~/Videos`` con nombres de archivo con marca de tiempo.

Proporciona una base simple para la captura de video controlada por botón y se puede ampliar para cámaras DIY, demostraciones en clase o proyectos de grabación activados por sensores.
