3.2 视频模块
============

**简介**

除了拍摄照片，树莓派摄像头模块还可以录制高质量视频。本项目演示如何设置摄像头模块，以可配置的分辨率、帧率和比特率录制视频，并直接保存到树莓派中。

**实验步骤**

#. 为方便使用摄像头模块，建议先\ :ref:`assemble_fusion_hat_pan_tilt`\ 。

   .. note::

     安装云台可能会遮挡部分引脚，因此建议仅在使用摄像头时安装，或在安装后将其置于外侧。


   .. image:: ../quick_start/img/gimbal_assemble.png

#. 访问树莓派桌面：

   * :ref:`remote_desktop`：使用\ **VNC**\ 获得完整的桌面体验。
   * |link_rpi_connect|：使用\ **Raspberry Pi Connect**\ 从任何浏览器安全地访问树莓派。

#. 打开终端并导航到项目文件夹：

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. 运行视频录制脚本：

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 3.2_Video.py

#. 脚本启动后，按下\ **Fusion HAT+ USR 按钮**\ 来控制录制。

   .. image:: img/3.1_user_button.png
      :width: 50%

   * 第一次按下 → **开始录制**，同时显示实时预览。
   * 第二次按下 → **停止录制**。
   * 视频保存在您的 ``~/Videos`` 目录中，文件名格式如：
     ``video_20250101_153045.mp4``。
   * 在终端中按 ``Ctrl+C`` 退出程序。

   .. image:: img/3.2_record_video.png
      :width: 70%


.. note::
   QT 预览需要桌面环境。
   如果无法启动预览（例如通过 SSH 连接），
   摄像头仍可正常拍摄和保存照片。

**代码**

以下是本项目使用的 Python 代码：

.. raw:: html

   <run></run>

.. code-block:: python

   import os
   import time
   import pwd
   from picamera2 import Picamera2, Preview
   from picamera2.encoders import H264Encoder
   from picamera2.outputs import FfmpegOutput
   from fusion_hat.user_button import UserButton

   # ----- Paths (works correctly even when using sudo) -----
   sudo_user = os.getenv("SUDO_USER")
   home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
   videos_dir = os.path.join(home, "Videos")
   os.makedirs(videos_dir, exist_ok=True)

   # ----- Camera / encoder -----
   camera = Picamera2()
   camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
   encoder = H264Encoder(bitrate=10_000_000)

   is_recording = False
   output = None
   preview_started = False

   def start_recording():
      """Start recording to a timestamped MP4 file."""
      global is_recording, output
      ts = time.strftime("%Y%m%d_%H%M%S")
      path = os.path.join(videos_dir, f"video_{ts}.mp4")
      output = FfmpegOutput(path)  # keep a reference while recording
      camera.start_recording(encoder, output)
      is_recording = True
      print(f"\nStart recording: {path}")

   def stop_recording():
      """Stop recording safely."""
      global is_recording, output
      camera.stop_recording()
      is_recording = False
      output = None
      print("\nStop recording.")

   def toggle():
      """USR button callback: toggle start/stop."""
      if not is_recording:
         start_recording()
      else:
         stop_recording()

   # ----- Button -----
   UserButton().set_on_click(toggle)

   # ----- Preview (only if a GUI display is available) -----
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception:
         preview_started = False  # continue without preview

   # ----- Run -----
   camera.start()
   print("Press USR to START/STOP recording. Ctrl+C to exit.")

   try:
      while True:
         time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      # Stop recording if still active
      if is_recording:
         try:
               camera.stop_recording()
         except Exception:
               pass

      # Stop preview only if it was started
      if preview_started:
         try:
               camera.stop_preview()
         except Exception:
               pass
      try:
         camera.stop()
      except Exception:
         pass
      try:
         camera.close()
      except Exception:
         pass


----------------------------------------------

**理解代码**

1. **导入与目的**

   .. code-block:: python

      import os
      import time
      import pwd
      from picamera2 import Picamera2, Preview
      from picamera2.encoders import H264Encoder
      from picamera2.outputs import FfmpegOutput
      from fusion_hat.user_button import UserButton

   这些模块用于：

   - ``os``：读取环境变量（如 ``DISPLAY``、``SUDO_USER``）和构建文件路径。
   - ``time``：生成带时间戳的文件名并保持程序在循环中运行。
   - ``pwd``：在脚本使用 ``sudo`` 运行时查找真实用户的主目录。
   - ``Picamera2`` / ``Preview``：控制摄像头管道和预览模式。
   - ``H264Encoder``：将视频帧编码为 H.264 格式。
   - ``FfmpegOutput``：使用 FFmpeg 将编码流保存为 ``.mp4`` 文件。
   - ``UserButton``：读取 Fusion HAT+ USR 按钮并绑定点击回调。

2. **选择正确的保存目录（兼容 sudo）**

   .. code-block:: python

      sudo_user = os.getenv("SUDO_USER")
      home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
      videos_dir = os.path.join(home, "Videos")
      os.makedirs(videos_dir, exist_ok=True)

   这确保视频保存在*真实用户*的 ``~/Videos`` 文件夹中：

   - 使用 ``sudo`` 运行时，``SUDO_USER`` 指向原始用户。
   - ``pwd.getpwnam(...).pw_dir`` 返回该用户的主目录。
   - 如果未使用 ``sudo``，则回退到当前用户的主目录（``~``）。
   - 如果 ``~/Videos`` 不存在，则自动创建。

3. **摄像头和视频编码器初始化**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
      encoder = H264Encoder(bitrate=10_000_000)

   - ``create_video_configuration(...)`` 设置用于录制视频的摄像头管道。
   - ``size=(800, 600)`` 选择录制分辨率。
   - ``FrameRate=30`` 以 30 FPS 录制。
   - ``H264Encoder`` 以约 10 Mbps 的比特率将流压缩为 H.264。

4. **录制状态变量**

   .. code-block:: python

      is_recording = False
      output = None
      preview_started = False

   - ``is_recording`` 跟踪录制是否当前处于活动状态。
   - ``output`` 存储 ``FfmpegOutput`` 对象，以在录制期间保持其存活。
   - ``preview_started`` 记录预览窗口是否成功启动，
     以便我们仅在实际存在预览时才停止它。

5. **开始录制**

   .. code-block:: python

      def start_recording():
         """Start recording to a timestamped MP4 file."""
         global is_recording, output
         ts = time.strftime("%Y%m%d_%H%M%S")
         path = os.path.join(videos_dir, f"video_{ts}.mp4")
         output = FfmpegOutput(path)  # keep a reference while recording
         camera.start_recording(encoder, output)
         is_recording = True
         print(f"\nStart recording: {path}")

   录制开始时：

   - 生成带时间戳的文件名（例如 ``video_20260203_154500.mp4``）。
   - 为该文件创建一个新的 ``FfmpegOutput``。
   - ``camera.start_recording(...)`` 开始编码和写入视频流。

6. **停止录制**

   .. code-block:: python

      def stop_recording():
         """Stop recording safely."""
         global is_recording, output
         camera.stop_recording()
         is_recording = False
         output = None
         print("\nStop recording.")

   录制停止时：

   - ``camera.stop_recording()`` 正确完成输出文件。
   - 清除输出引用，以便释放对象。

7. **USR 按钮切换控制**

   .. code-block:: python

      def toggle():
          if not is_recording:
              start_recording()
          else:
              stop_recording()

      UserButton().set_on_click(toggle)

   每次按下 Fusion HAT+ USR 按钮切换录制状态：

   - 第一次按下 → 开始录制。
   - 第二次按下 → 停止录制。

8. **预览逻辑（有屏或无屏均可工作）**

   .. code-block:: python

      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception:
              preview_started = False

   - 如果桌面 GUI 可用（设置了 ``DISPLAY``），则脚本尝试启动 QT 预览。
   - 如果没有屏幕/GUI（例如没有 X11 的 SSH），则安全地跳过预览，
     录制仍然正常工作。

9. **主循环和安全退出（Ctrl+C）**

   .. code-block:: python

      camera.start()
      try:
          while True:
              time.sleep(0.1)
      except KeyboardInterrupt:
          pass
      finally:
          if is_recording:
              camera.stop_recording()
          if preview_started:
              camera.stop_preview()
          camera.stop()
          camera.close()

   - ``camera.start()`` 启动摄像头管道。
   - 循环使脚本保持运行，以便响应按钮按下。
   - 当按下 Ctrl+C 时，执行 ``finally`` 块：
     - 如果录制处于活动状态，则停止录制（防止视频文件损坏）。
     - 仅当预览已启动时才停止预览（防止预览相关错误）。
     - 停止并关闭摄像头以干净地释放硬件资源。


-----------

**故障排除**


1. **无预览窗口**

   - **原因：** 在没有桌面环境的情况下运行，或缺少 Picamera2 GUI 支持。
   - **解决方法：** 使用树莓派桌面/VNC 并安装 Picamera2：

   .. raw:: html

      <run></run>

   .. code-block:: shell

        sudo apt install -y python3-picamera2

2. **USR 按钮不工作**

   - **原因：** Fusion HAT+ 未连接或权限不足。
   - **解决方法：** 重新插拔 HAT，使用 ``sudo`` 运行脚本，如有需要可在 ``toggle_recording()`` 中添加调试日志。

3. **视频未保存**

   - **原因：** 使用 ``sudo`` 时主目录不正确，或缺少 ``~/Videos`` 文件夹。
   - **解决方法：** 检查 ``REAL_USER`` 和 ``VIDEOS_DIR`` 的值。确保 ``~/Videos`` 存在且可写。

4. **录制意外开始/停止**

   - **原因：** 摄像头被其他进程使用，或系统负载过高。
   - **解决方法：** 关闭其他摄像头应用程序，重启树莓派，确保已安装 ``ffmpeg``。

5. **文件未完成**

   - **原因：** 脚本在停止录制前意外终止。
   - **解决方法：** 始终使用 ``Ctrl+C`` 退出，以便脚本正确停止录制。

------

**总结**

本脚本让您可以使用 Fusion HAT+ USR 按钮开始和停止视频录制，同时查看实时预览。视频会自动保存到 ``~/Videos`` 目录，并带有时间戳文件名。

它提供了一个简单的按钮控制视频捕获基础，可扩展用于 DIY 相机、课堂演示或传感器触发的录制项目。
