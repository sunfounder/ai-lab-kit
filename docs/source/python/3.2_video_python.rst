3.2 Module Video
======================

**Introduction**

Au-dela de la prise de photos, le module camera Raspberry Pi vous permet egalement d’enregistrer des videos de haute qualite. Ce projet demontre comment configurer le module camera pour enregistrer des videos avec une resolution, une frequence d’images et un debit binaire configurables, en les sauvegardant directement sur votre Raspberry Pi.

**Code**

Voici le code Python utilise pour ce projet :

.. raw:: html

   <run></run>

.. code-block:: python

   import os
   import time
   import pwd
   from picamera2 import Picamera2, Preview
   from picamera2.encoders import H264Encoder
   from picamera2.outputs import FfmpegOutput
   from fusion_hat.user_button import UserButton

   # ----- Paths (works correctly even when using sudo) -----
   sudo_user = os.getenv("SUDO_USER")
   home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
   videos_dir = os.path.join(home, "Videos")
   os.makedirs(videos_dir, exist_ok=True)

   # ----- Camera / encoder -----
   camera = Picamera2()
   camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
   encoder = H264Encoder(bitrate=10_000_000)

   is_recording = False
   output = None
   preview_started = False

   def start_recording():
      """Start recording to a timestamped MP4 file."""
      global is_recording, output
      ts = time.strftime("%Y%m%d_%H%M%S")
      path = os.path.join(videos_dir, f"video_{ts}.mp4")
      output = FfmpegOutput(path)  # keep a reference while recording
      camera.start_recording(encoder, output)
      is_recording = True
      print(f"\nStart recording: {path}")

   def stop_recording():
      """Stop recording safely."""
      global is_recording, output
      camera.stop_recording()
      is_recording = False
      output = None
      print("\nStop recording.")

   def toggle():
      """USR button callback: toggle start/stop."""
      if not is_recording:
         start_recording()
      else:
         stop_recording()

   # ----- Button -----
   UserButton().set_on_click(toggle)

   # ----- Preview (only if a GUI display is available) -----
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception:
         preview_started = False  # continue without preview

   # ----- Run -----
   camera.start()
   print("Press USR to START/STOP recording. Ctrl+C to exit.")

   try:
      while True:
         time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      # Stop recording if still active
      if is_recording:
         try:
               camera.stop_recording()
         except Exception:
               pass
         
      # Stop preview only if it was started
      if preview_started:
         try:
               camera.stop_preview()
         except Exception:
               pass
      try:
         camera.stop()
      except Exception:
         pass
      try:
         camera.close()
      except Exception:
         pass

**Comprendre le code**


**Comprendre le code**

1. **Importations et objectif**

   .. code-block:: python

      import os
      import time
      import pwd
      from picamera2 import Picamera2, Preview
      from picamera2.encoders import H264Encoder
      from picamera2.outputs import FfmpegOutput
      from fusion_hat.user_button import UserButton

   Ces modules sont utilises pour :

   - ``os`` : lire les variables d’environnement (par exemple, ``DISPLAY``, ``SUDO_USER``) et construire les chemins de fichiers.
   - ``time`` : generer des noms de fichiers horodates et maintenir le programme en execution dans une boucle.
   - ``pwd`` : trouver le repertoire personnel de l’utilisateur reel lorsque le script est execute avec ``sudo``.
   - ``Picamera2`` / ``Preview`` : controler le pipeline de la camera et les modes d’apercu.
   - ``H264Encoder`` : encoder les images video au format H.264.
   - ``FfmpegOutput`` : sauvegarder le flux encode dans un fichier ``.mp4`` en utilisant FFmpeg.
   - ``UserButton`` : lire le bouton USR du Fusion HAT+ et lier une fonction de rappel au clic.

2. **Selection du repertoire de sauvegarde correct (fonctionne avec sudo)**

   .. code-block:: python

      sudo_user = os.getenv("SUDO_USER")
      home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
      videos_dir = os.path.join(home, "Videos")
      os.makedirs(videos_dir, exist_ok=True)

   Cela garantit que les videos sont enregistrees dans le dossier ``~/Videos`` de l’utilisateur *reel* :

   - Lorsqu’il est execute avec ``sudo``, ``SUDO_USER`` pointe vers l’utilisateur d’origine.
   - ``pwd.getpwnam(...).pw_dir`` retourne le repertoire personnel de cet utilisateur.
   - Si ``sudo`` n’est pas utilise, il revient au repertoire personnel de l’utilisateur actuel (``~``).
   - ``~/Videos`` est cree s’il n’existe pas.

3. **Initialisation de la camera et de l’encodeur video**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
      encoder = H264Encoder(bitrate=10_000_000)

   - ``create_video_configuration(...)`` configure le pipeline de la camera pour l’enregistrement video.
   - ``size=(800, 600)`` choisit la resolution d’enregistrement.
   - ``FrameRate=30`` enregistre a 30 images par seconde.
   - ``H264Encoder`` compresse le flux en H.264 a environ 10 Mbps.

4. **Variables d’etat de l’enregistrement**

   .. code-block:: python

      is_recording = False
      output = None
      preview_started = False

   - ``is_recording`` indique si l’enregistrement est actuellement actif.
   - ``output`` stocke l’objet ``FfmpegOutput`` pour le maintenir en vie pendant l’enregistrement.
   - ``preview_started`` enregistre si une fenetre d’apercu a ete demarree avec succes,
     afin de ne l’arreter que si elle existe reellement.

5. **Demarrage d’un enregistrement**

   .. code-block:: python

      def start_recording():
         """Start recording to a timestamped MP4 file."""
         global is_recording, output
         ts = time.strftime("%Y%m%d_%H%M%S")
         path = os.path.join(videos_dir, f"video_{ts}.mp4")
         output = FfmpegOutput(path)  # keep a reference while recording
         camera.start_recording(encoder, output)
         is_recording = True
         print(f"\nStart recording: {path}")

   Lorsque l’enregistrement commence :

   - Un nom de fichier horodate est genere (par exemple, ``video_20260203_154500.mp4``).
   - Un nouvel objet ``FfmpegOutput`` est cree pour ce fichier.
   - ``camera.start_recording(...)`` commence l’encodage et l’ecriture du flux video.

6. **Arret d’un enregistrement**

   .. code-block:: python

      def stop_recording():
         """Stop recording safely."""
         global is_recording, output
         camera.stop_recording()
         is_recording = False
         output = None
         print("\nStop recording.")

   Lorsque l’enregistrement s’arrete :

   - ``camera.stop_recording()`` finalise correctement le fichier de sortie.
   - La reference de sortie est effacee pour que l’objet puisse etre libere.

7. **Controle par bascule du bouton USR**

   .. code-block:: python

      def toggle():
          if not is_recording:
              start_recording()
          else:
              stop_recording()

      UserButton().set_on_click(toggle)

   Chaque pression du bouton USR du Fusion HAT+ alterne l’enregistrement :

   - Premiere pression → demarrer l’enregistrement.
   - Deuxieme pression → arreter l’enregistrement.

8. **Logique d’apercu (fonctionne avec ou sans ecran)**

   .. code-block:: python

      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception:
              preview_started = False

   - Si un environnement de bureau est disponible (``DISPLAY`` est defini), le script tente un apercu QT.
   - Si aucun ecran/environnement graphique n’est disponible (comme SSH sans X11), il ignore l’apercu en toute securite
     et l’enregistrement fonctionne toujours normalement.

9. **Boucle principale et sortie propre (Ctrl+C)**

   .. code-block:: python

      camera.start()
      try:
          while True:
              time.sleep(0.1)
      except KeyboardInterrupt:
          pass
      finally:
          if is_recording:
              camera.stop_recording()
          if preview_started:
              camera.stop_preview()
          camera.stop()
          camera.close()

   - ``camera.start()`` demarre le pipeline de la camera.
   - La boucle maintient le script en execution afin qu’il puisse repondre aux pressions sur le bouton.
   - Lorsque Ctrl+C est presse, le bloc ``finally`` s’execute :
     - Arrete l’enregistrement s’il est actif (empeche la corruption des fichiers video).
     - Arrete l’apercu seulement s’il a ete demarre (empeche les erreurs liees a l’apercu).
     - Arrete et ferme la camera pour liberer proprement les ressources materielles.


-----------

**Depannage**


1. **Pas de fenetre d’apercu**

   - **Cause :** Execution sans environnement de bureau ou support GUI Picamera2 manquant.
   - **Solution :** Utilisez Raspberry Pi Desktop/VNC et installez Picamera2 :

   .. raw:: html

      <run></run>

   .. code-block:: shell

        sudo apt install -y python3-picamera2

2. **Le bouton USR ne fonctionne pas**

   - **Cause :** Fusion HAT+ non connecte ou permissions insuffisantes.
   - **Solution :** Reinserez le HAT, executez le script avec ``sudo`` et imprimez des journaux de debogage dans ``toggle_recording()`` si necessaire.

3. **Video non sauvegardee**

   - **Cause :** Repertoire personnel incorrect lors de l’utilisation de ``sudo`` ou dossier ``~/Videos`` manquant.
   - **Solution :** Verifiez les valeurs ``REAL_USER`` et ``VIDEOS_DIR``. Assurez-vous que ``~/Videos`` existe et est accessible en ecriture.

4. **L’enregistrement demarre/ s’arrete de maniere inattendue**

   - **Cause :** Camera utilisee par un autre processus ou systeme sous forte charge.
   - **Solution :** Fermez les autres applications de camera, redemarrez le Pi et assurez-vous que ``ffmpeg`` est installe.

5. **Fichier non finalise**

   - **Cause :** Script termine brusquement avant l’arret de l’enregistrement.
   - **Solution :** Quittez toujours avec ``Ctrl+C`` pour que le script puisse arreter l’enregistrement correctement.

------

**Conclusion**

Ce script vous permet de demarrer et d’arreter l’enregistrement video a l’aide du bouton USR du Fusion HAT+ tout en visualisant un apercu en direct. Les videos sont automatiquement sauvegardees dans ``~/Videos`` avec des noms de fichiers horodates.

Il fournit une base simple pour la capture video controlee par bouton et peut etre etendu pour des cameras DIY, des demonstrations en classe ou des projets d’enregistrement declenche par capteur.
