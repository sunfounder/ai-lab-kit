3.2 Modulo Video
=====================

**Introduzione**

Oltre a scattare foto, il modulo telecamera del Raspberry Pi permette anche di registrare video di alta qualità. Questo progetto dimostra come configurare il modulo telecamera per registrare video con risoluzione, framerate e bitrate configurabili, salvandoli direttamente sul tuo Raspberry Pi.

**Procedure Sperimentali**

#. Per usare il modulo telecamera comodamente, si consiglia :ref:`assemble_fusion_hat_pan_tilt`.

   .. note::

     L'assemblaggio del pan-tilt potrebbe oscurare alcuni pin, quindi si consiglia di assemblarlo solo quando si usa la telecamera, o di posizionarlo all'esterno dopo l'assemblaggio.


   .. image:: ../quick_start/img/gimbal_assemble.png

#. Accedi al Desktop del Raspberry Pi:

   * :ref:`remote_desktop`: Usa **VNC** per un'esperienza desktop completa.
   * |link_rpi_connect|: Usa **Raspberry Pi Connect** per accedere al tuo Pi in modo sicuro da qualsiasi browser.

#. Apri un Terminale e naviga alla cartella del progetto:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      cd ~/ai-lab-kit/python

#. Esegui lo script di registrazione video:

   .. raw:: html

      <run></run>

   .. code-block:: shell

      sudo python3 3.2_Video.py

#. Dopo l'avvio dello script, premi il **pulsante USR di Fusion HAT+** per controllare la registrazione.

   .. image:: img/3.1_user_button.png
      :width: 50%

   * Prima pressione → **Avvia registrazione** con anteprima dal vivo.
   * Seconda pressione → **Ferma registrazione**.
   * I video vengono salvati nella tua directory ``~/Videos`` con nomi come:
     ``video_20250101_153045.mp4``.
   * Premi ``Ctrl+C`` nel terminale per uscire dal programma.

   .. image:: img/3.2_record_video.png
      :width: 70%


.. note::
   L'anteprima QT richiede un ambiente desktop.
   Se l'anteprima non può essere avviata (ad esempio, tramite SSH),
   la telecamera può comunque catturare e salvare le foto normalmente.

**Codice**

Qui sotto c'è il codice Python usato per questo progetto:

.. raw:: html

   <run></run>

.. code-block:: python

   import os
   import time
   import pwd
   from picamera2 import Picamera2, Preview
   from picamera2.encoders import H264Encoder
   from picamera2.outputs import FfmpegOutput
   from fusion_hat.user_button import UserButton

   # ----- Paths (works correctly even when using sudo) -----
   sudo_user = os.getenv("SUDO_USER")
   home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
   videos_dir = os.path.join(home, "Videos")
   os.makedirs(videos_dir, exist_ok=True)

   # ----- Camera / encoder -----
   camera = Picamera2()
   camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
   encoder = H264Encoder(bitrate=10_000_000)

   is_recording = False
   output = None
   preview_started = False

   def start_recording():
      """Start recording to a timestamped MP4 file."""
      global is_recording, output
      ts = time.strftime("%Y%m%d_%H%M%S")
      path = os.path.join(videos_dir, f"video_{ts}.mp4")
      output = FfmpegOutput(path)  # keep a reference while recording
      camera.start_recording(encoder, output)
      is_recording = True
      print(f"\nStart recording: {path}")

   def stop_recording():
      """Stop recording safely."""
      global is_recording, output
      camera.stop_recording()
      is_recording = False
      output = None
      print("\nStop recording.")

   def toggle():
      """USR button callback: toggle start/stop."""
      if not is_recording:
         start_recording()
      else:
         stop_recording()

   # ----- Button -----
   UserButton().set_on_click(toggle)

   # ----- Preview (only if a GUI display is available) -----
   if os.getenv("DISPLAY"):
      try:
         camera.start_preview(Preview.QT)
         preview_started = True
      except Exception:
         preview_started = False  # continue without preview

   # ----- Run -----
   camera.start()
   print("Press USR to START/STOP recording. Ctrl+C to exit.")

   try:
      while True:
         time.sleep(0.1)
   except KeyboardInterrupt:
      pass
   finally:
      # Stop recording if still active
      if is_recording:
         try:
               camera.stop_recording()
         except Exception:
               pass

      # Stop preview only if it was started
      if preview_started:
         try:
               camera.stop_preview()
         except Exception:
               pass
      try:
         camera.stop()
      except Exception:
         pass
      try:
         camera.close()
      except Exception:
         pass

**Comprendere il Codice**


**Comprendere il Codice**

1. **Importazioni e Scopo**

   .. code-block:: python

      import os
      import time
      import pwd
      from picamera2 import Picamera2, Preview
      from picamera2.encoders import H264Encoder
      from picamera2.outputs import FfmpegOutput
      from fusion_hat.user_button import UserButton

   Questi moduli vengono usati per:

   - ``os``: leggere le variabili d'ambiente (ad es., ``DISPLAY``, ``SUDO_USER``) e costruire percorsi file.
   - ``time``: generare nomi file con timestamp e mantenere il programma in esecuzione in un ciclo.
   - ``pwd``: trovare la directory home dell'utente reale quando lo script viene eseguito con ``sudo``.
   - ``Picamera2`` / ``Preview``: controllare la pipeline della telecamera e le modalità di anteprima.
   - ``H264Encoder``: codificare i fotogrammi video in formato H.264.
   - ``FfmpegOutput``: salvare lo stream codificato in un file ``.mp4`` usando FFmpeg.
   - ``UserButton``: leggere il pulsante USR di Fusion HAT+ e collegare un callback di click.

2. **Selezione della Directory di Salvataggio Corretta (Funziona con sudo)**

   .. code-block:: python

      sudo_user = os.getenv("SUDO_USER")
      home = pwd.getpwnam(sudo_user).pw_dir if sudo_user else os.path.expanduser("~")
      videos_dir = os.path.join(home, "Videos")
      os.makedirs(videos_dir, exist_ok=True)

   Questo assicura che i video siano salvati nella cartella ``~/Videos`` dell'*utente reale*:

   - Quando eseguito con ``sudo``, ``SUDO_USER`` punta all'utente originale.
   - ``pwd.getpwnam(...).pw_dir`` restituisce la directory home di quell'utente.
   - Se non si usa ``sudo``, viene usata la home dell'utente corrente (``~``).
   - ``~/Videos`` viene creata se non esiste.

3. **Inizializzazione della Telecamera e del Codificatore Video**

   .. code-block:: python

      camera = Picamera2()
      camera.configure(camera.create_video_configuration(main={"size": (800, 600)}, controls={"FrameRate": 30}))
      encoder = H264Encoder(bitrate=10_000_000)

   - ``create_video_configuration(...)`` configura la pipeline della telecamera per la registrazione video.
   - ``size=(800, 600)`` sceglie la risoluzione di registrazione.
   - ``FrameRate=30`` registra a 30 FPS.
   - ``H264Encoder`` comprime lo stream in H.264 a ~10 Mbps.

4. **Variabili di Stato della Registrazione**

   .. code-block:: python

      is_recording = False
      output = None
      preview_started = False

   - ``is_recording`` tiene traccia se la registrazione è attualmente attiva.
   - ``output`` memorizza l'oggetto ``FfmpegOutput`` per mantenerlo in vita durante la registrazione.
   - ``preview_started`` registra se una finestra di anteprima è stata avviata con successo, in modo da fermare l'anteprima solo se esiste effettivamente.

5. **Avvio di una Registrazione**

   .. code-block:: python

      def start_recording():
         """Start recording to a timestamped MP4 file."""
         global is_recording, output
         ts = time.strftime("%Y%m%d_%H%M%S")
         path = os.path.join(videos_dir, f"video_{ts}.mp4")
         output = FfmpegOutput(path)  # keep a reference while recording
         camera.start_recording(encoder, output)
         is_recording = True
         print(f"\nStart recording: {path}")

   Quando la registrazione inizia:

   - Viene generato un nome file con timestamp (ad es., ``video_20260203_154500.mp4``).
   - Viene creato un nuovo ``FfmpegOutput`` per quel file.
   - ``camera.start_recording(...)`` inizia la codifica e la scrittura dello stream video.

6. **Fermata di una Registrazione**

   .. code-block:: python

      def stop_recording():
         """Stop recording safely."""
         global is_recording, output
         camera.stop_recording()
         is_recording = False
         output = None
         print("\nStop recording.")

   Quando la registrazione si ferma:

   - ``camera.stop_recording()`` finalizza correttamente il file di output.
   - Il riferimento all'output viene cancellato in modo che l'oggetto possa essere rilasciato.

7. **Controllo di Attivazione/Disattivazione tramite Pulsante USR**

   .. code-block:: python

      def toggle():
          if not is_recording:
              start_recording()
          else:
              stop_recording()

      UserButton().set_on_click(toggle)

   Ogni pressione del pulsante USR di Fusion HAT+ attiva/disattiva la registrazione:

   - Prima pressione → avvia registrazione.
   - Seconda pressione → ferma registrazione.

8. **Logica dell'Anteprima (Funziona Con o Senza Schermo)**

   .. code-block:: python

      if os.getenv("DISPLAY"):
          try:
              camera.start_preview(Preview.QT)
              preview_started = True
          except Exception:
              preview_started = False

   - Se è disponibile un desktop GUI (``DISPLAY`` è impostato), lo script tenta un'anteprima QT.
   - Se non è disponibile alcuno schermo/GUI (come SSH senza X11), salta l'anteprima in sicurezza e la registrazione funziona comunque normalmente.

9. **Ciclo Principale e Uscita Pulita (Ctrl+C)**

   .. code-block:: python

      camera.start()
      try:
          while True:
              time.sleep(0.1)
      except KeyboardInterrupt:
          pass
      finally:
          if is_recording:
              camera.stop_recording()
          if preview_started:
              camera.stop_preview()
          camera.stop()
          camera.close()

   - ``camera.start()`` avvia la pipeline della telecamera.
   - Il ciclo mantiene lo script in esecuzione in modo che possa rispondere alle pressioni del pulsante.
   - Quando viene premuto Ctrl+C, il blocco ``finally`` viene eseguito:
     - Ferma la registrazione se è attiva (previene file video corrotti).
     - Ferma l'anteprima solo se è stata avviata (previene errori relativi all'anteprima).
     - Ferma e chiude la telecamera per rilasciare le risorse hardware in modo pulito.


-----------

**Risoluzione dei Problemi**


1. **Nessuna Finestra di Anteprima**

   - **Causa:** Esecuzione senza ambiente desktop o supporto GUI Picamera2 mancante.
   - **Soluzione:** Usa Raspberry Pi Desktop/VNC e installa Picamera2:

   .. raw:: html

      <run></run>

   .. code-block:: shell

        sudo apt install -y python3-picamera2

2. **Il Pulsante USR Non Funziona**

   - **Causa:** Fusion HAT+ non collegato o permessi insufficienti.
   - **Soluzione:** Reinserisci HAT, esegui lo script con ``sudo`` e stampa log di debug in ``toggle_recording()`` se necessario.

3. **Video Non Salvato**

   - **Causa:** Directory home errata quando si usa ``sudo`` o cartella ``~/Videos`` mancante.
   - **Soluzione:** Controlla i valori ``REAL_USER`` e ``VIDEOS_DIR``. Assicurati che ``~/Videos`` esista e sia scrivibile.

4. **La Registrazione Inizia/Ferma Inaspettatamente**

   - **Causa:** Telecamera in uso da un altro processo o sistema sotto carico elevato.
   - **Soluzione:** Chiudi altre app della telecamera, riavvia il Pi e assicurati che ``ffmpeg`` sia installato.

5. **File Non Finalizzato**

   - **Causa:** Script terminato bruscamente prima di fermare la registrazione.
   - **Soluzione:** Esci sempre con ``Ctrl+C`` in modo che lo script possa fermare correttamente la registrazione.

------

**Conclusione**

Questo script ti permette di avviare e fermare la registrazione video usando il pulsante USR di Fusion HAT+ mentre visualizzi un'anteprima dal vivo. I video vengono salvati automaticamente in ``~/Videos`` con nomi file con timestamp.

Fornisce una base semplice per l'acquisizione video controllata da pulsante e può essere esteso per telecamere fai-da-te, dimostrazioni in classe o progetti di registrazione attivati da sensori.
