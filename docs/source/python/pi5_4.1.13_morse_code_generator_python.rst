4.1.13 Morsecode-Generator
=============================

**Introduction**

In diesem Projekt erstellen wir einen Morsecode-Generator mit einem Raspberry Pi. Du gibst Zeichenfolgen über das Terminal ein, und das System gibt die entsprechenden Morsezeichen mittels Buzzer und LED aus. Das Projekt demonstriert nicht nur die grundlegende GPIO-Ansteuerung, sondern führt auch in den Morsecode ein – ein faszinierendes Kommunikationsverfahren aus der Telegrafiegeschichte.

**Writing the Code**

Unten findest du den Python-Code für dieses Projekt:


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin
   import time

   # Initialize Buzzer and LED to GPIO pins
   BeepPin = Pin(22, Pin.OUT)
   ALedPin = Pin(17, Pin.OUT)

   # Morse code representation for characters
   MORSECODE = {
      'A': '01', 'B': '1000', 'C': '1010', 'D': '100', 'E': '0', 'F': '0010', 'G': '110',
      'H': '0000', 'I': '00', 'J': '0111', 'K': '101', 'L': '0100', 'M': '11', 'N': '10',
      'O': '111', 'P': '0110', 'Q': '1101', 'R': '010', 'S': '000', 'T': '1',
      'U': '001', 'V': '0001', 'W': '011', 'X': '1001', 'Y': '1011', 'Z': '1100',
      '1': '01111', '2': '00111', '3': '00011', '4': '00001', '5': '00000',
      '6': '10000', '7': '11000', '8': '11100', '9': '11110', '0': '11111',
      '?': '001100', '/': '10010', ',': '110011', '.': '010101', ';': '101010',
      '!': '101011', '@': '011010', ':': '111000',
   }

   def on():
      """ Turn on the buzzer and LED. """
      BeepPin.on()
      ALedPin.on()

   def off():
      """ Turn off the buzzer and LED. """
      BeepPin.off()
      ALedPin.off()

   def beep(dt):  # dt for delay time.
      """
      Produce a beep sound and LED flash for the specified duration.
      :param dt: Duration for the beep and flash.
      """
      on()
      time.sleep(dt)
      off()
      time.sleep(dt)

   def morsecode(code):
      """
      Convert the input code into Morse code and signal it using the buzzer and LED.
      :param code: The text to be converted to Morse code.
      """
      pause = 0.25
      for letter in code:
         for tap in MORSECODE[letter]:
               if tap == '0':
                  beep(pause / 2)  # Short beep for dot
               if tap == '1':
                  beep(pause)      # Long beep for dash
         time.sleep(pause)  # Pause between letters

   def destroy():
      """ Clean up resources on script termination. """
      print("")
      BeepPin.off()
      ALedPin.off()

   try:
      while True:
         code = input("Please input the messenger:")
         code = code.upper()  # Convert to uppercase for Morse code lookup
         print(code)
         morsecode(code)
   except KeyboardInterrupt:
      destroy()


Dieses Python-Skript wandelt eine vom Benutzer eingegebene Nachricht in Morsecode um und gibt sie über Buzzer und LED aus. So funktioniert es:

1. **Morsecode-Umsetzung**: Der eingegebene Text (Buchstaben, Ziffern und einige Sonderzeichen) wird mithilfe des vordefinierten Wörterbuchs ``MORSECODE`` in Morsezeichen übersetzt.

2. **Audio-visuelle Ausgabe**:

   - Für jeden Punkt (``0``) werden Buzzer und LED kurz aktiviert (halbe Pausenzeit).
   - Für jeden Strich (``1``) werden Buzzer und LED länger aktiviert (volle Pausenzeit).

3. **Benutzerinteraktion**:

   - Nutzer geben eine Nachricht ein; das System konvertiert sie und gibt die entsprechenden Morsezeichen aus.
   - Das Programm fragt fortlaufend nach neuen Eingaben, bis es beendet wird.

4. **Sauberes Beenden**: Mit ``Ctrl+C`` stoppt das Skript, schaltet Buzzer und LED aus und beendet sich ordnungsgemäß.

----------------------------------------------

**Understanding the Code**

1. **Komponenten-Setup:**  

   Buzzer und LED sind an den GPIO-Pins 22 bzw. 17 initialisiert.

2. **Morsecode-Wörterbuch:**  

   Punkte werden durch „0“ (kurze Signale) und Striche durch „1“ (lange Signale) dargestellt. Beispiel: „A“ = „01“.

3. **Signalfunktionen:**  

   * ``on()`` und ``off()`` schalten Buzzer/LED ein bzw. aus.  
   * ``beep()`` erzeugt ein Signal mit definierter Dauer.

4. **Morse-Konvertierung:**  

   ``morsecode()`` verarbeitet jeden Buchstaben der Eingabe und gibt die zugehörige Folge von Punkten/Strichen aus.

5. **Hauptschleife:**  

   Das Programm fordert kontinuierlich Eingaben an und wandelt sie in Morseausgaben. Mit ``Ctrl+C`` kann sicher beendet werden.

**Troubleshooting**

1. **Buzzer oder LED ohne Funktion**:

   - **Ursache**: Falsche Verdrahtung oder GPIO-Konfiguration.  
   - **Lösung**:

     - Prüfe, ob der Buzzer an GPIO 22 und die LED an GPIO 17 angeschlossen ist.
     - Teste beide Komponenten mit einfachen GPIO-Skripten.

2. **Morseausgabe ist fehlerhaft**:

   - **Ursache**: Zeichen nicht im ``MORSECODE``-Wörterbuch.  
   - **Lösung**:
   
     - Stelle sicher, dass nur unterstützte Zeichen (A–Z, 0–9 und ausgewählte Symbole) verwendet werden.
     - Erweitere bei Bedarf das Wörterbuch.

3. **Zu schnelle/überlappende Signale**:

   - **Ursache**: Unzureichende Pausen oder Signaldauern.  
   - **Lösung**: Passe die Variable ``pause`` in ``morsecode()`` an, um die Ausgabe zu verlangsamen:

       .. code-block:: python

           pause = 0.5  # Längere Pause für langsamere Ausgabe

4. **Keine Eingabe erkannt**:

   - **Ursache**: Laufzeitumgebung ohne Konsoleneingabe.  
   - **Lösung**: Stelle sicher, dass das Skript in einem Terminal mit ``input()``-Unterstützung läuft.

**Extendable Ideas**

1. **Einstellbare Geschwindigkeit**: Erlaube Nutzern, die Morsegeschwindigkeit über eine benutzerdefinierte Pausenzeit zu setzen.

     .. code-block:: python

         pause = float(input("Enter pause duration (seconds): "))

2. **Mehrgeräte-Ausgabe**: Eine zusätzliche LED oder ein zweiter Buzzer für parallele Ausgabe.

3. **Morse-Logging**: Protokolliere die erzeugten Morsecodes pro Nachricht in eine Datei:

     .. code-block:: python

         with open("morse_log.txt", "a") as log_file:
             log_file.write(f"{message} -> {morse_sequence}\n")

4. **Echtzeit-Anzeige**: Zeige die Morsezeichen (Punkte/Striche) während der Ausgabe in der Konsole an.

5. **Eingabevalidierung**: Weisen Nutzer auf nicht unterstützte Zeichen hin.

6. **Interaktive Dekodierung**: Modus, in dem Nutzer Morse über einen Taster eingeben und in Text dekodieren lassen.

7. **Drahtlose Morse-Kommunikation**: Übertrage Morsecodes per RF-Modul an ein zweites Gerät.
