2.10 热敏电阻
==============

**介绍**

热敏电阻是一种对温度敏感的电阻，广泛应用于温度传感和控制应用中。与检测光线的光敏电阻不同，热敏电阻通过改变其阻值来响应温度变化。这使得它们非常适合用于热警报、恒温器和温度监测系统等项目。在本项目中，我们将使用热敏电阻测量环境温度，并以摄氏度和华氏度显示。

**代码**

以下是本项目使用的Python代码：


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   # -*- coding: utf-8 -*-

   from fusion_hat.adc import ADC
   import time
   import math

   thermistor = ADC('A3')

   # Run the process in a try-except block
   try:
      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
               print("Please check the sensor")
               continue
         else:
               Rt = 10000 * Vr / (3.3 - Vr)
               # Calculate the temperature in Kelvin
               temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25)))
               # Convert Kelvin to Celsius
               Cel = temp - 273.15
               # Convert Celsius to Fahrenheit
               Fah = Cel * 1.8 + 32
               # Print the temperature in both Celsius and Fahrenheit
               print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
               # Wait for 0.2 seconds before the next read
               time.sleep(0.2)

   # Handle KeyboardInterrupt for graceful termination
   except KeyboardInterrupt:
      pass

**理解代码**

1. **导入：**

   .. code-block:: python

      from fusion_hat.adc import ADC
      import time
      import math


   此脚本导入所需模块：\ ``fusion_hat``\ 库中的\ ``ADC``\ 用于读取电压，\ ``time``\ 用于睡眠功能，\ ``math``\ 用于数学计算。


2. **初始化：**

   .. code-block:: python

      thermistor = ADC('A3')

   在引脚A3上初始化ADC对象。

3. **数据处理：**

   .. code-block:: python

      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
            print("Please check the sensor")
            continue
         else:
            Rt = 10000 * Vr / (3.3 - Vr)
            temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25))) # Calculate the temperature in Kelvin
            Cel = temp - 273.15 # Convert Kelvin to Celsius
            Fah = Cel * 1.8 + 32 # Convert Celsius to Fahrenheit

   - 从热敏电阻读取电压。
   - 计算热敏电阻的阻值。
   - 使用Steinhart-Hart方程计算开尔文温度。
   - 将开尔文转换为摄氏度和华氏度。


4. **输出：**

   .. code-block:: python

      print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
      time.sleep(0.2)

   计算出的温度以摄氏度和华氏度显示在屏幕上。包含延迟以使温度读数稳定并防止CPU使用率过高。

**故障排除**


1. **温度值不正确或不稳定**：

   - **原因**：热敏电阻参数不正确或输入信号有噪声。
   - **解决方案**：

     - 确保热敏电阻在25°C时的阻值（本脚本中为\ ``10000``\ ）和\ ``3950``\ B值对你的热敏电阻型号是准确的。
     - 添加电容或软件滤波以减少信号噪声。

2. **除零错误**：

   - **原因**：电压\ ``Vr``\ 太接近0或3.3V，导致阻值计算中出现除以零的情况。
   - **解决方案**：确保ADC输入电压保持在0–3.3V范围内，并检查连接是否存在短路或断开。
