2.10 Thermistance
=====================

**Introduction**

Une thermistance est une resistance sensible a la temperature, largement utilisee dans les applications de detection et de controle de la temperature. Contrairement aux photoresistances qui detectent la lumiere, les thermistances repondent aux changements de temperature en faisant varier leur resistance. Cela les rend ideales pour des projets comme les alarmes de chaleur, les thermostats et les systemes de surveillance de temperature. Dans ce projet, nous utiliserons une thermistance pour mesurer la temperature ambiante et l'afficher en degres Celsius et Fahrenheit.

Ce script Python lit un signal analogique d'une thermistance via le fusion hat et calcule la temperature correspondante. Lors de l'execution :

1. Le script lit en continu la tension.
2. Il calcule la resistance de la thermistance (``Rt``) et determine la temperature en Kelvin, Celsius et Fahrenheit.
3. Les temperatures calculees sont affichees sur la console en Celsius et Fahrenheit, formatees a deux decimales, sous la forme ``Celsius: <value> C  Fahrenheit: <value> F``.
4. Le processus se repete toutes les 0,2 secondes jusqu'a ce que le script soit interrompu avec ``Ctrl+C``.

**Code**

Voici le code Python utilise pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   # -*- coding: utf-8 -*-

   from fusion_hat.adc import ADC
   import time
   import math

   thermistor = ADC('A3')

   # Run the process in a try-except block
   try:
      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
               print("Please check the sensor")
               continue
         else:
               Rt = 10000 * Vr / (3.3 - Vr)
               # Calculate the temperature in Kelvin
               temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25)))
               # Convert Kelvin to Celsius
               Cel = temp - 273.15
               # Convert Celsius to Fahrenheit
               Fah = Cel * 1.8 + 32
               # Print the temperature in both Celsius and Fahrenheit
               print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
               # Wait for 0.2 seconds before the next read
               time.sleep(0.2)

   # Handle KeyboardInterrupt for graceful termination
   except KeyboardInterrupt:
      pass

1. **Importations :**

   .. code-block:: python

      import time
      import math


   Ce script importe les modules necessaires : ``ADC`` de la bibliotheque ``fusion_hat`` pour lire la tension, ``time`` pour la fonction sleep, et ``math`` pour les calculs mathematiques.


2. **Initialisation :**

   .. code-block:: python

      thermistor = ADC('A3')

   Initialise l'objet ADC sur la broche A3.

3. **Traitement des donnees :**

   .. code-block:: python

      while True:

         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
            print("Please check the sensor")

   - Calcule la resistance de la thermistance.
   - Utilise l'equation de Steinhart-Hart pour calculer la temperature en Kelvin.
   - Convertit Kelvin en Celsius et Fahrenheit.


4. **Sortie :**

   .. code-block:: python

   La temperature calculee est affichee a l'ecran en Celsius et Fahrenheit. Une pause est incluse pour permettre aux lectures de temperature de se stabiliser et pour eviter une utilisation excessive du CPU.

**Depannage**


1. **Les valeurs de temperature sont incorrectes ou erratiques** :

   - **Cause** : Parametres de thermistance incorrects ou signal d'entree bruyant.
   - **Solution** :

     - Assurez-vous que la resistance de la thermistance a 25°C (``10000`` dans ce script) et la valeur B de ``3950`` sont exactes pour votre modele de thermistance.
     - Ajoutez un condensateur ou un filtrage logiciel pour reduire le bruit du signal.

2. **Erreur de division par zero** :

   - **Cause** : La tension ``Vr`` est trop proche de 0 ou 3,3 V, ce qui entraine une division par zero dans le calcul de la resistance.
   - **Solution** : Assurez-vous que la tension d'entree ADC reste dans la plage 0-3,3 V et verifiez les connexions pour les courts-circuits ou les deconnexions.

      else:
