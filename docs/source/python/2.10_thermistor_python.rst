2.10 Termistore
====================================

**Introduzione**

Un termistore è un resistore sensibile alla temperatura ampiamente utilizzato in applicazioni di rilevamento e controllo della temperatura. A differenza dei fotoresistori che rilevano la luce, i termistori rispondono ai cambiamenti di temperatura variando la loro resistenza. Questo li rende ideali per progetti come allarmi di calore, termostati e sistemi di monitoraggio della temperatura. In questo progetto, useremo un termistore per misurare la temperatura ambiente e visualizzarla sia in gradi Celsius che Fahrenheit.

Questo script Python legge un segnale analogico da un termistore tramite fusion hat e calcola la temperatura corrispondente. Quando eseguito:

1. Lo script legge continuamente la tensione.
2. Calcola la resistenza del termistore (``Rt``) e determina la temperatura in Kelvin, Celsius e Fahrenheit.
3. Le temperature calcolate vengono stampate sulla console sia in Celsius che in Fahrenheit, formattate con due decimali, come ``Celsius: <value> C  Fahrenheit: <value> F``.
4. Il processo si ripete ogni 0,2 secondi fino a quando lo script non viene interrotto con ``Ctrl+C``.

**Codice**

Qui sotto c'è il codice Python usato per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   # -*- coding: utf-8 -*-

   from fusion_hat.adc import ADC
   import time
   import math

   thermistor = ADC('A3')

   # Run the process in a try-except block
   try:
      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
               print("Please check the sensor")
               continue
         else:
               Rt = 10000 * Vr / (3.3 - Vr)
               # Calculate the temperature in Kelvin
               temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25)))
               # Convert Kelvin to Celsius
               Cel = temp - 273.15
               # Convert Celsius to Fahrenheit
               Fah = Cel * 1.8 + 32
               # Print the temperature in both Celsius and Fahrenheit
               print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
               # Wait for 0.2 seconds before the next read
               time.sleep(0.2)

   # Handle KeyboardInterrupt for graceful termination
   except KeyboardInterrupt:
      pass

**Comprendere il Codice**

1. **Importazioni:**

   .. code-block:: python

      from fusion_hat.adc import ADC
      import time
      import math


   Questo script importa i moduli necessari: ``ADC`` dalla libreria ``fusion_hat`` per leggere la tensione, ``time`` per la funzionalità sleep e ``math`` per i calcoli matematici.


2. **Inizializzazione:**

   .. code-block:: python

      thermistor = ADC('A3')

   Inizializza l'oggetto ADC sul pin A3.

3. **Elaborazione dei Dati:**

   .. code-block:: python

      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
            print("Please check the sensor")
            continue
         else:
            Rt = 10000 * Vr / (3.3 - Vr)
            temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25))) # Calculate the temperature in Kelvin
            Cel = temp - 273.15 # Convert Kelvin to Celsius
            Fah = Cel * 1.8 + 32 # Convert Celsius to Fahrenheit

   - Legge la tensione dal termistore.
   - Calcola la resistenza del termistore.
   - Usa l'equazione di Steinhart-Hart per calcolare la temperatura in Kelvin.
   - Converte Kelvin in Celsius e Fahrenheit.


4. **Uscita:**

   .. code-block:: python

      print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
      time.sleep(0.2)

   La temperatura calcolata viene visualizzata sullo schermo sia in Celsius che in Fahrenheit. Un ritardo è incluso per permettere alle letture di temperatura di stabilizzarsi e per prevenire un uso eccessivo della CPU.

**Risoluzione dei Problemi**


1. **I Valori di Temperatura Sono Errati o Irregolari**:

   - **Causa**: Parametri del termistore errati o segnale di ingresso rumoroso.
   - **Soluzione**:

     - Assicurati che la resistenza del termistore a 25°C (``10000`` in questo script) e il valore B ``3950`` siano accurati per il tuo modello di termistore.
     - Aggiungi un condensatore o un filtraggio software per ridurre il rumore del segnale.

2. **Errore di Divisione per Zero**:

   - **Causa**: La tensione ``Vr`` è troppo vicina a 0 o 3,3V, portando a una divisione per zero nel calcolo della resistenza.
   - **Soluzione**: Assicurati che la tensione di ingresso ADC rimanga nell'intervallo 0-3,3V e controlla le connessioni per cortocircuiti o disconnessioni.

            led.on()
      else:
            led.off()
