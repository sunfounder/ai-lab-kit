2.10 Termistor
====================================

**Introducción**

Un termistor es un resistor sensible a la temperatura ampliamente utilizado en aplicaciones de detección y control de temperatura. A diferencia de los fotoresistores que detectan luz, los termistores responden a los cambios de temperatura variando su resistencia. Esto los hace ideales para proyectos como alarmas de calor, termostatos y sistemas de monitoreo de temperatura. En este proyecto, usaremos un termistor para medir la temperatura ambiente y mostrarla tanto en grados Celsius como Fahrenheit.

**Código**

A continuación se muestra el código Python utilizado en este proyecto:


.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3
   # -*- coding: utf-8 -*-

   from fusion_hat.adc import ADC
   import time
   import math

   thermistor = ADC('A3')

   # Run the process in a try-except block
   try:
      while True:
         # Read the voltage from the sensor
         Vr = thermistor.read_voltage()
         # Calculate the resistance of the thermistor
         if 3.3 - Vr < 0.1:
               print("Please check the sensor")
               continue
         else:
               Rt = 10000 * Vr / (3.3 - Vr)
               # Calculate the temperature in Kelvin
               temp = 1 / (((math.log(Rt / 10000)) / 3950) + (1 / (273.15 + 25)))
               # Convert Kelvin to Celsius
               Cel = temp - 273.15
               # Convert Celsius to Fahrenheit
               Fah = Cel * 1.8 + 32
               # Print the temperature in both Celsius and Fahrenheit
               print('Celsius: %.2f C  Fahrenheit: %.2f F' % (Cel, Fah))
               # Wait for 0.2 seconds before the next read
               time.sleep(0.2)

   # Handle KeyboardInterrupt for graceful termination
   except KeyboardInterrupt:
      pass

2. **Inicialización:**

**Solución de Problemas**


1. **Los valores de temperatura son incorrectos o erráticos**:

   - **Causa**: Parámetros incorrectos del termistor o señal de entrada ruidosa.
   - **Solución**:

     - Asegúrate de que la resistencia del termistor a 25°C (``10000`` en este script) y el valor B de ``3950`` sean precisos para tu modelo de termistor.
     - Agrega un capacitor o filtrado por software para reducir el ruido de la señal.

2. **Error de división entre cero**:

   - **Causa**: El voltaje ``Vr`` está demasiado cerca de 0 o 3.3V, lo que provoca una división entre cero en el cálculo de la resistencia.
   - **Solución**: Asegúrate de que el voltaje de entrada del ADC se mantenga dentro del rango de 0–3.3V y verifica las conexiones en busca de cortocircuitos o desconexiones.

**Ideas para Extender**

1. **Mostrar temperaturas en un LCD u OLED**: Utiliza una pantalla LCD u OLED para mostrar los valores de temperatura de forma dinámica.

2. **Registro de datos**: Guarda las lecturas de temperatura en un archivo para su análisis:

   .. code-block:: python

      with open("temperature_log.txt", "a") as log_file:
         log_file.write(f"Celsius: {Cel:.2f}, Fahrenheit: {Fah:.2f}\n")

3. **Alertas basadas en umbrales**: Activa alertas cuando la temperatura supere un umbral predefinido:

   .. code-block:: python

      if Cel > 30:
         print("Warning: High temperature!")

4. **Retroalimentación con LED o Zumbador**: Proporciona retroalimentación visual o auditiva según los niveles de temperatura:

   .. code-block:: python

      from fusion_hat import Pin
      led = Pin(27.Pin.OUT)
      if Cel > 30:
            led.on()
      else:
            led.off()
