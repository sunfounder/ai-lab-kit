2.13 Modulo Sensore Ultrasonico
===============================

**Introduzione**

Il modulo sensore ultrasonico utilizza onde ultrasoniche per misurare le distanze con notevole precisione. Emette onde ultrasoniche e ascolta il loro eco, calcolando la distanza in base al tempo impiegato dall'eco per tornare. Questa tecnologia versatile è comunemente usata in robotica, rilevamento ostacoli e applicazioni di telemetria.

**Esecuzione dell'Esempio**


Tutto il codice di esempio usato in questo tutorial è disponibile nella directory ``ai-lab-kit``.
Segui questi passaggi per eseguire l'esempio:

.. raw:: html

   <run></run>

.. code-block:: shell

   cd ~/ai-lab-kit/python/
   sudo python3 2.13_Ultrasonic.py

Questo script Python usa un sensore di distanza ultrasonico per misurare la distanza da un oggetto e visualizza il risultato sulla console. Quando eseguito:

1. Il sensore, collegato ai pin GPIO 27 (trigger) e 22 (echo), misura continuamente la distanza dall'oggetto più vicino.
2. La distanza viene calcolata in metri e convertita in centimetri, poi visualizzata nel formato: ``Distance: <value> cm`` con due decimali di precisione.
3. La distanza viene aggiornata ogni 0,3 secondi, permettendo un monitoraggio quasi in tempo reale.
4. Il programma viene eseguito indefinitamente fino a quando non viene interrotto con ``Ctrl+C``, a quel punto esce in modo controllato.

**Codice**


Qui sotto c'è il codice Python per questo progetto:


.. raw:: html

   <run></run>

.. code-block:: python

   # Import Ultrasonic and Pin class
   from fusion_hat.modules import Ultrasonic
   from fusion_hat.pin import Pin
   from time import sleep

   # Create Ultrasonic object
   sensor = Ultrasonic(Pin(27), Pin(22))

   try:
      # Main loop to continuously measure and report distance
      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to gracefully exit the loop
      pass

**Comprendere il Codice**

1. **Importazioni:**


   .. code-block:: python

      from fusion_hat.modules import Ultrasonic
      from fusion_hat.pin import Pin
      from time import sleep

   Lo script importa la classe ``Ultrasonic`` dalla libreria ``fusion_hat`` per interagire con il sensore ultrasonico e la funzione ``sleep`` dal modulo ``time`` per introdurre ritardi.


2. **Inizializzazione:**

   .. code-block:: python

      sensor = Ultrasonic(Pin(27), Pin(22))

   Il sensore ultrasonico viene inizializzato con il pin Echo collegato a GPIO 22 e il pin Trigger a GPIO 27. Questa configurazione permette al Raspberry Pi di inviare e ricevere segnali ultrasonici.

3. **Ciclo Principale:**


   .. code-block:: python

      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   * Misura continuamente la distanza dall'oggetto più vicino.
   * Converte la distanza da metri a centimetri.
   * Stampa la distanza con due decimali di precisione.
   * Include un ritardo di 0,3 secondi per permettere al sensore di stabilizzarsi tra le misurazioni.



4. **Uscita Controllata:**

   Il blocco ``try-except`` assicura che il programma esca pulitamente quando interrotto con ``Ctrl+C``.

   .. code-block:: python

      except KeyboardInterrupt:
         pass

**Risoluzione dei Problemi**

1. **Nessun Output di Distanza**:

   - **Causa**: Il sensore non è collegato o alimentato correttamente.
   - **Soluzione**:

      - Assicurati che il pin trigger sia collegato a GPIO 27 e il pin echo a GPIO 22.
      - Verifica che il sensore abbia un'alimentazione stabile.

2. **Valori di Distanza Costanti o Errati**:

   - **Causa**: Gli ostacoli sono troppo vicini o troppo lontani dal sensore, oppure c'è interferenza.
   - **Soluzione**:

      - Assicurati che l'oggetto sia nel raggio effettivo del sensore (tipicamente da 2 cm a 400 cm).
      - Controlla la presenza di interferenze da altri dispositivi ultrasonici o superfici riflettenti.

3. **Distanza Sempre Zero**:

   - **Causa**: Sensore difettoso o cablaggio errato.
   - **Soluzione**: Testa il sensore su un'altra configurazione GPIO o sostituiscilo se difettoso. Ricontrolla la configurazione del cablaggio.
