2.13 超声波传感器模块
======================

**介绍**

超声波传感器模块利用超声波以惊人的精度测量距离。它发出超声波并监听其回波，根据回波返回所需的时间计算距离。这种多功能技术常用于机器人、障碍物检测和测距应用。

此Python脚本使用超声波距离传感器测量到物体的距离，并将结果显示在控制台上。执行时：

1. 连接到GPIO引脚27（触发）和22（回波）的传感器持续测量到最近物体的距离。
2. 距离以米为单位计算并转换为厘米，以格式：\ ``Distance: <value> cm``\ 显示，精度为两位小数。
3. 每0.3秒更新一次距离，实现近实时的监测。
4. 程序无限运行，直到用\ ``Ctrl+C``\ 中断，此时优雅退出。

**代码**


以下是本项目的Python代码：


.. raw:: html

   <run></run>

.. code-block:: python

   # Import Ultrasonic and Pin class
   from fusion_hat.modules import Ultrasonic
   from fusion_hat.pin import Pin
   from time import sleep

   # Create Ultrasonic object
   sensor = Ultrasonic(Pin(27), Pin(22))

   try:
      # Main loop to continuously measure and report distance
      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to gracefully exit the loop
      pass

**理解代码**

1. **导入：**


   .. code-block:: python

      from fusion_hat.modules import Ultrasonic
      from fusion_hat.pin import Pin
      from time import sleep

   脚本导入\ ``fusion_hat``\ 库中的\ ``Ultrasonic``\ 类以与超声波传感器交互，并导入\ ``time``\ 模块中的\ ``sleep``\ 函数以引入延迟。


2. **初始化：**

   .. code-block:: python

      sensor = Ultrasonic(Pin(27), Pin(22))

   超声波传感器初始化，Echo引脚连接到GPIO 22，Trigger引脚连接到GPIO 27。此配置使Raspberry Pi能够发送和接收超声波信号。

3. **主循环：**


   .. code-block:: python

      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   * 持续测量到最近物体的距离。
   * 将距离从米转换为厘米。
   * 以两位小数的精度打印距离。
   * 包含0.3秒的延迟以使传感器在两次测量之间稳定。



4. **优雅退出：**

   ``try-except``\ 块确保程序在用\ ``Ctrl+C``\ 中断时能干净退出。

   .. code-block:: python

      except KeyboardInterrupt:
         pass

**故障排除**

1. **无距离输出**：

   - **原因**：传感器未正确连接或未供电。
   - **解决方案**：

      - 确保触发引脚连接到GPIO 27，回波引脚连接到GPIO 22。
      - 确认传感器有稳定的电源。

2. **距离值恒定或不正确**：

   - **原因**：障碍物离传感器太近或太远，或存在干扰。
   - **解决方案**：

      - 确保物体在传感器的有效范围内（通常为2 cm到400 cm）。
      - 检查是否有其他超声波设备或反射表面的干扰。

3. **距离始终为零**：

   - **原因**：传感器故障或接线错误。
   - **解决方案**：在其他GPIO设置上测试传感器，如有故障则更换传感器。仔细检查接线配置。
