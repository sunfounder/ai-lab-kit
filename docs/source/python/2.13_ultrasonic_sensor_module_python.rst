2.13 Module Capteur Ultrason
=================================

**Introduction**

Le module capteur ultrason utilise des ondes ultrasonores pour mesurer les distances avec une precision remarquable. Il emet des ondes ultrasonores et ecoute leur echo, calculant la distance en fonction du temps necessaire au retour de l'echo. Cette technologie polyvalente est couramment utilisee en robotique, dans la detection d'obstacles et les applications de telemetrie.

Ce script Python utilise un capteur de distance ultrason pour mesurer la distance d'un objet et affiche le resultat sur la console. Lors de l'execution :

1. Le capteur, connecte aux broches GPIO 27 (trigger) et 22 (echo), mesure en continu la distance de l'objet le plus proche.
2. La distance est calculee en metres et convertie en centimetres, puis affichee au format : ``Distance: <value> cm`` avec une precision de deux decimales.
3. La distance est mise a jour toutes les 0,3 secondes, permettant une surveillance quasi temps reel.
4. Le programme s'execute indefiniment jusqu'a ce qu'il soit interrompu avec ``Ctrl+C``, moment auquel il se termine proprement.

**Code**


Voici le code Python pour ce projet :


.. raw:: html

   <run></run>

.. code-block:: python

   # Import Ultrasonic and Pin class
   from fusion_hat.modules import Ultrasonic
   from fusion_hat.pin import Pin
   from time import sleep

   # Create Ultrasonic object
   sensor = Ultrasonic(Pin(27), Pin(22))

   try:
      # Main loop to continuously measure and report distance
      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to gracefully exit the loop
      pass

      from fusion_hat.pin import Pin

   Le capteur ultrason est initialise avec la broche Echo connectee a GPIO 22 et la broche Trigger a GPIO 27. Cette configuration permet au Raspberry Pi d'envoyer et de recevoir des signaux ultrasonores.

**Depannage**

1. **Aucune sortie de distance** :

   - **Cause** : Le capteur n'est pas correctement connecte ou alimente.
   - **Solution** :

      - Assurez-vous que la broche trigger est connectee a GPIO 27 et la broche echo a GPIO 22.
      - Verifiez que le capteur dispose d'une alimentation stable.

2. **Valeurs de distance constantes ou incorrectes** :

   - **Cause** : Les obstacles sont trop proches ou trop eloignes du capteur, ou il y a des interférences.
   - **Solution** :

      - Assurez-vous que l'objet se trouve dans la plage effective du capteur (generalement 2 cm a 400 cm).
      - Verifiez la presence d'interferences provenant d'autres dispositifs ultrasonores ou de surfaces reflectives.

3. **Distance toujours a zero** :

   - **Cause** : Capteur defectueux ou cablage incorrect.
   - **Solution** : Testez le capteur sur une autre configuration GPIO ou remplacez-le s'il est defectueux. Revérifiez la configuration du cablage.
