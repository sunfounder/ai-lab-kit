2.13 Módulo de Sensor Ultrasónico
===================================

**Introducción**

El módulo de sensor ultrasónico utiliza ondas ultrasónicas para medir distancias con una precisión notable. Emite ondas ultrasónicas y escucha su eco, calculando la distancia basándose en el tiempo que tarda el eco en regresar. Esta tecnología versátil se utiliza comúnmente en robótica, detección de obstáculos y aplicaciones de medición de distancia.

Este script de Python utiliza un sensor de distancia ultrasónico para medir la distancia a un objeto y muestra el resultado en la consola. Al ejecutarse:

1. El sensor, conectado a los pines GPIO 27 (trigger) y 22 (echo), mide continuamente la distancia al objeto más cercano.
2. La distancia se calcula en metros y se convierte a centímetros, luego se muestra en el formato: ``Distance: <valor> cm`` con dos decimales de precisión.
3. La distancia se actualiza cada 0.3 segundos, permitiendo un monitoreo casi en tiempo real.
4. El programa se ejecuta indefinidamente hasta que se interrumpe con ``Ctrl+C``, momento en el cual sale de forma segura.

**Código**


A continuación se muestra el código Python para este proyecto:


.. raw:: html

   <run></run>

.. code-block:: python

   # Import Ultrasonic and Pin class
   from fusion_hat.modules import Ultrasonic
   from fusion_hat.pin import Pin
   from time import sleep

   # Create Ultrasonic object
   sensor = Ultrasonic(Pin(27), Pin(22))

   try:
      # Main loop to continuously measure and report distance
      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision
         sleep(0.3)  # Wait for 0.3 seconds before the next measurement

   except KeyboardInterrupt:
      # Handle KeyboardInterrupt (Ctrl+C) to gracefully exit the loop
      pass

**Comprender el Código**

1. **Imports:**


   .. code-block:: python

      from fusion_hat.modules import Ultrasonic
      from fusion_hat.pin import Pin
      from time import sleep

   El script importa la clase ``Ultrasonic`` de la biblioteca ``fusion_hat`` para interactuar con el sensor ultrasónico y la función ``sleep`` del módulo ``time`` para introducir retardos.


2. **Inicialización:**


   .. code-block:: python

      sensor = Ultrasonic(Pin(27), Pin(22))

   El sensor ultrasónico se inicializa con el pin Echo conectado a GPIO 22 y el pin Trigger a GPIO 27. Esta configuración permite a la Raspberry Pi enviar y recibir señales ultrasónicas.

3. **Bucle Principal:**


   .. code-block:: python

      while True:
         dis = sensor.read() # Measure distance in centimeters
         print('Distance: {:.2f} cm'.format(dis))  # Print the distance with two decimal precision

   * Mide continuamente la distancia al objeto más cercano.
   * Convierte la distancia de metros a centímetros.
   * Imprime la distancia con dos decimales de precisión.
   * Incluye un retardo de 0.3 segundos para permitir que el sensor se estabilice entre mediciones.

   El bloque ``try-except`` garantiza que el programa salga limpiamente cuando se interrumpe con ``Ctrl+C``.

   .. code-block:: python

**Solución de Problemas**

1. **No hay salida de distancia**:

   - **Causa**: El sensor no está correctamente conectado o alimentado.
   - **Solución**:

      - Asegúrate de que el pin trigger esté conectado a GPIO 27 y el pin echo a GPIO 22.
      - Verifica que el sensor tenga una fuente de alimentación estable.

2. **Valores de distancia constantes o incorrectos**:

   - **Causa**: Los obstáculos están demasiado cerca o demasiado lejos del sensor, o hay interferencia.
   - **Solución**:

      - Asegúrate de que el objeto esté dentro del rango efectivo del sensor (típicamente de 2 cm a 400 cm).
      - Verifica si hay interferencias de otros dispositivos ultrasónicos o superficies reflectantes.

3. **La distancia siempre es cero**:

   - **Causa**: Sensor defectuoso o cableado incorrecto.
   - **Solución**: Prueba el sensor en otra configuración GPIO o reemplázalo si está defectuoso. Vuelve a verificar la configuración del cableado.

      else:
