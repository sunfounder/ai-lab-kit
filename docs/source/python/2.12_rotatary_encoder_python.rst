2.12 Encoder Rotativo
=======================

**Introduzione**

Un encoder rotativo è un dispositivo di input che converte il movimento rotatorio in segnali digitali. È comunemente usato per navigare nei menu, regolare valori o scorrere elementi. In questo progetto, collegherai un encoder rotativo (con pulsante integrato) a un Raspberry Pi tramite Fusion HAT+, leggerai i passi di rotazione e reimposterai il contatore con l'interruttore dell'encoder.

Questo esperimento illustra come interfacciare un encoder rotativo usando callback di eventi per una gestione fluida e a bassa latenza degli input.

**Mappatura Pin Usata nell'Esempio**

- **CLK** → **GPIO 17**
- **DT** → **GPIO 4**
- **SW (pulsante)** → **GPIO 27** (con pull-up interno)
- **+** → **3,3V**
- **GND** → **GND**

Assicurati che tutte le connessioni siano sicure. Se il tuo encoder ha pin **C (COM)** e **NO/NC** separati per l'interruttore, collega **C** a GND e **NO** al pin SW (pull-up interno abilitato nel software).

**Codice**

Qui sotto c'è il codice Python usato per questo progetto:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # GPIO pins (BCM numbering)
   CLK_PIN = 17
   DT_PIN  = 4
   SW_PIN  = 27

   # Initialize pins with internal pull-ups
   clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
   dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
   sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)  # Button is active LOW

   raw = 0                 # Raw quadrature transitions
   last_clk = clk.value()  # Previous CLK state
   last_detent = None      # Last displayed detent value

   print("Rotate the knob. Press the button to reset. CTRL + C to exit.")
   try:
      while True:
         c = clk.value()
         if c != last_clk:
               # Direction: DT != CLK means one direction, else the other
               raw += 1 if dt.value() != c else -1

               # Most encoders generate 2 transitions per detent (click)
               detent = raw // 2

               # Only update output when the detent value changes
               if detent != last_detent:
                  print(f"\rCounter: {detent}   ", end="", flush=True)
                  last_detent = detent

               last_clk = c

         # Reset when button is pressed
         if sw.value() == 0:
               raw = 0
               detent = 0
               print("\rCounter: 0   ", end="", flush=True)
               last_detent = 0
               time.sleep(0.25)  # Button debounce

         time.sleep(0.001)  # Polling interval (1 ms)

   except KeyboardInterrupt:
      print("\nExit")

**Comprendere il Codice**

1. **Importazioni**

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      import time

   - ``Pin`` viene usato per configurare e leggere i pin GPIO per l'encoder rotativo.
   - ``Mode`` e ``Pull`` definiscono la direzione del pin e i resistori pull-up interni.
   - ``time`` viene usato per controllare gli intervalli di polling e il tempo di debounce del pulsante.

2. **Configurazione dei Pin GPIO**

   .. code-block:: python

      CLK_PIN = 17
      DT_PIN  = 4
      SW_PIN  = 27

      clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
      dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
      sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)

   - ``CLK`` e ``DT`` sono i due pin del segnale in quadratura dell'encoder rotativo.
   - ``SW`` è il pulsante integrato dell'encoder.
   - I resistori pull-up interni mantengono il segnale stabile quando l'encoder è inattivo.
   - Il pulsante è attivo LOW e legge ``0`` quando premuto.

3. **Variabili di Stato**

   .. code-block:: python

      raw = 0
      last_clk = clk.value()
      last_detent = None

   - ``raw`` conta le transizioni di quadratura di basso livello dell'encoder.
   - ``last_clk`` memorizza lo stato CLK precedente per rilevare i cambiamenti di segnale.
   - ``last_detent`` tiene traccia dell'ultimo valore del contatore visualizzato per evitare output ripetuti.

4. **Rilevamento della Rotazione**

   .. code-block:: python

      c = clk.value()
      if c != last_clk:
          raw += 1 if dt.value() != c else -1

   - Lo script esegue il polling continuo del pin CLK.
   - Un cambiamento in CLK indica un movimento dell'encoder.
   - La direzione di rotazione viene determinata confrontando DT con CLK.

5. **Calcolo dello Scatto (Click)**

   .. code-block:: python

      detent = raw // 2

   - La maggior parte degli encoder rotativi genera due transizioni di segnale per clic fisico.
   - Dividere per 2 converte le transizioni grezze in conteggi di scatto puliti.

6. **Output Pulito sulla Console**

   .. code-block:: python

      if detent != last_detent:
          print(f"\rCounter: {detent}   ", end="", flush=True)

   - L'output viene aggiornato solo quando il valore del contatore cambia.
   - ``\r`` sposta il cursore all'inizio della riga per aggiornamenti in-place.
   - ``flush=True`` assicura la visualizzazione immediata sul terminale.

7. **Gestione del Reset tramite Pulsante**

   .. code-block:: python

      if sw.value() == 0:
          raw = 0
          detent = 0
          print("\rCounter: 0   ", end="", flush=True)
          time.sleep(0.25)

   - Premere il pulsante reimposta il contatore a zero.
   - Un breve ritardo viene usato per il debounce del pulsante per evitare attivazioni multiple.

8. **Intervallo di Polling e Uscita dal Programma**

   .. code-block:: python

      time.sleep(0.001)

   - Un ritardo di polling di 1 ms bilancia reattività e utilizzo della CPU.
   - Premere ``Ctrl + C`` esce dal programma in modo controllato.

----------------------------------------------

**Risoluzione dei Problemi**

1. **Nessun Output in Rotazione**

   - **Causa**: CLK/DT cablati male o connessione di massa scarsa.
   - **Soluzione**: Verifica **CLK→GPIO17**, **DT→GPIO4**, **GND comune**. Assicurati che l'alimentazione a 3,3V sia corretta (non **usare** encoder a 5V direttamente sui GPIO).

2. **Il Contatore Salta in Modo Irregolare (Rimbalzi/Rumore)**

   - **Causa**: Rimbalzo meccanico o cavi lunghi che raccolgono rumore.
   - **Soluzione**: Mantieni i cavi corti e attorcigliati come coppia se possibile; aggiungi piccoli condensatori (ad es., 0,01-0,1 µF) da CLK/DT a GND se necessario.

3. **Pulsante Non Rilevato**

   - **Causa**: Contatti dell'interruttore collegati a 3,3V invece che a GND o configurazione pull-up errata.
   - **Soluzione**: Assicurati che **SW** sia collegato a **GND** quando premuto; conferma che ``pull=Pin.PULL_UP`` sia impostato.

4. **Direzione Invertita**

   - **Causa**: CLK e DT scambiati rispetto alla direzione desiderata.
   - **Soluzione**: Scambia i fili **CLK** e **DT** o inverti a livello applicativo (ad es., sottrai i passi).

**Idee Estendibili**

1. **Regola una Variabile (ad es., Volume/Luminosità) in Modo Fluido**

   .. code-block:: python

      value = 50  # 0..100
      def rotary_change():
          global value
          value = max(0, min(100, 50 + encoder.steps()))
          print(f'Value = {value}')

2. **Usa il Pulsante per Attivare/Disattivare una Modalità**

   .. code-block:: python

      mode = ['Fine', 'Coarse']
      idx = 0
      def reset_counter():
          global idx
          idx = 1 - idx
          encoder.reset()
          print(f'Mode switched to: {mode[idx]}')

3. **Feedback LED/Buzzer**

   .. code-block:: python

      from fusion_hat import Pin
      led = Pin(26, Pin.OUT)
      def rotary_change():
          print('Counter =', encoder.steps())
          led.on()
          # brief flash without blocking callbacks is recommended
          led.off()

4. **Pressione Lunga per Eseguire un'Azione Speciale**

   - Traccia la durata della pressione usando timestamp in ``sw.when_activated`` e (se disponibile) ``sw.when_deactivated`` per attivare azioni diverse per pressioni brevi/lunghe.
