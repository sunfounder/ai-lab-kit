2.12 Codeur Rotatif
=======================

**Introduction**

Un codeur rotatif est un dispositif d'entree qui convertit le mouvement de rotation en signaux numeriques. Il est couramment utilise pour naviguer dans les menus, ajuster des valeurs ou faire defiler des elements. Dans ce projet, vous connecterez un codeur rotatif (avec un bouton-poussoir integre) a un Raspberry Pi via le Fusion HAT+, lirez les pas de rotation et reinitialiserez le compteur avec l'interrupteur du codeur.

Cette experience illustre comment interfacer un codeur rotatif en utilisant des rappels d'evenements pour une gestion fluide et a faible latence des entrees.

**Correspondance des broches utilisee dans l'exemple**

- **CLK** → **GPIO 17**
- **DT** → **GPIO 4**
- **SW (bouton)** → **GPIO 27** (avec pull-up interne)
- **+** → **3,3 V**
- **GND** → **GND**

Assurez-vous que toutes les connexions sont securisees. Si votre codeur a des broches **C (COM)** et **NO/NC** separees pour l'interrupteur, connectez **C** a GND et **NO** a la broche SW (pull-up interne active dans le logiciel).

**Code**

Voici le code Python utilise pour ce projet :

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # GPIO pins (BCM numbering)
   CLK_PIN = 17
   DT_PIN  = 4
   SW_PIN  = 27

   # Initialize pins with internal pull-ups
   clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
   dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
   sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)  # Button is active LOW

   raw = 0                 # Raw quadrature transitions
   last_clk = clk.value()  # Previous CLK state
   last_detent = None      # Last displayed detent value

   print("Rotate the knob. Press the button to reset. CTRL + C to exit.")
   try:
      while True:
         c = clk.value()
         if c != last_clk:
               # Direction: DT != CLK means one direction, else the other
               raw += 1 if dt.value() != c else -1

               # Most encoders generate 2 transitions per detent (click)
               detent = raw // 2

               # Only update output when the detent value changes
               if detent != last_detent:
                  print(f"\rCounter: {detent}   ", end="", flush=True)
                  last_detent = detent

               last_clk = c

         # Reset when button is pressed
         if sw.value() == 0:
               raw = 0
               detent = 0
               print("\rCounter: 0   ", end="", flush=True)
               last_detent = 0
               time.sleep(0.25)  # Button debounce

         time.sleep(0.001)  # Polling interval (1 ms)

   except KeyboardInterrupt:
      print("\nExit")



----------------------------------------------

**Comprendre le code**

1. **Importations**

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      import time

   - ``Pin`` est utilise pour configurer et lire les broches GPIO du codeur rotatif.
   - ``Mode`` et ``Pull`` definissent la direction de la broche et les resistances pull-up internes.
   - ``time`` est utilise pour controler les intervalles de scrutation et la temporisation d'anti-rebond du bouton.

2. **Configuration des broches GPIO**

   .. code-block:: python

      CLK_PIN = 17
      DT_PIN  = 4
      SW_PIN  = 27

      clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
      dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
      sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)

   - ``CLK`` et ``DT`` sont les deux broches de signal en quadrature du codeur rotatif.
   - ``SW`` est le bouton-poussoir integre du codeur.
   - Les resistances pull-up internes maintiennent le signal stable lorsque le codeur est au repos.
   - Le bouton est actif a l'etat BAS et lit ``0`` lorsqu'il est presse.

3. **Variables d'etat**

   .. code-block:: python

      raw = 0
      last_clk = clk.value()
      last_detent = None

   - ``raw`` compte les transitions de quadrature de bas niveau du codeur.
   - ``last_clk`` stocke l'etat CLK precedent pour detecter les changements de signal.
   - ``last_detent`` garde la trace de la derniere valeur de compteur affichee pour eviter les sorties repetees.

4. **Detection de rotation**

   .. code-block:: python

      c = clk.value()
      if c != last_clk:
          raw += 1 if dt.value() != c else -1

   - Le script scrute en continu la broche CLK.
   - Un changement sur CLK indique un mouvement du codeur.
   - La direction de rotation est determinee en comparant DT avec CLK.

5. **Calcul du cran (clic)**

   .. code-block:: python

      detent = raw // 2

   - La plupart des codeurs rotatifs generent deux transitions de signal par clic physique.
   - La division par 2 convertit les transitions brutes en nombres de crans propres.

6. **Affichage console propre**

   .. code-block:: python

      if detent != last_detent:
          print(f"\\rCounter: {detent}   ", end="", flush=True)

   - La sortie est mise a jour uniquement lorsque la valeur du compteur change.
   - ``\\r`` replace le curseur au debut de la ligne pour des mises a jour sur place.
   - ``flush=True`` garantit un affichage immediat sur le terminal.

7. **Gestion de la reinitialisation par bouton**

   .. code-block:: python

      if sw.value() == 0:
          raw = 0
          detent = 0
          print("\\rCounter: 0   ", end="", flush=True)
          time.sleep(0.25)

   - Appuyer sur le bouton remet le compteur a zero.
   - Une breve pause est utilisee pour l'anti-rebond du bouton afin d'eviter les declenchements multiples.

8. **Intervalle de scrutation et sortie du programme**

   .. code-block:: python

      time.sleep(0.001)

   - Une pause de scrutation de 1 ms equilibre la reactivite et l'utilisation du CPU.
   - Appuyer sur ``Ctrl + C`` termine le programme proprement.

----------------------------------------------

**Depannage**

1. **Aucune sortie lors de la rotation**

   - **Cause** : CLK/DT mal câblees ou mauvaise connexion a la masse.
   - **Solution** : Verifiez **CLK→GPIO17**, **DT→GPIO4**, **GND commun**. Assurez-vous que l'alimentation 3,3 V est correcte (n'utilisez **pas** de codeurs 5 V directement sur les GPIO).

2. **Le compteur saute de maniere erratique (rebond/bruit)**

   - **Cause** : Rebond mecanique ou fils longs captant du bruit.
   - **Solution** : Gardez les fils courts et torsades par paire si possible ; ajoutez de petits condensateurs (par exemple, 0,01-0,1 µF) de CLK/DT a GND si necessaire ; activez toutes les options d'anti-rebond disponibles dans votre version de bibliotheque.

3. **Bouton non detecte**

   - **Cause** : Contacts de l'interrupteur cablés a 3,3 V au lieu de GND ou mauvaise configuration de pull-up.
   - **Solution** : Assurez-vous que **SW** se connecte a **GND** lorsqu'il est presse ; confirmez que ``pull=Pin.PULL_UP`` est defini.

4. **Direction inversee**

   - **Cause** : CLK et DT echangees par rapport a la direction souhaitee.
   - **Solution** : Echangez les fils **CLK** et **DT** ou inversez au niveau de la couche applicative (par exemple, soustrayez les pas).

**Idees d'extension**

1. **Ajuster une variable (par exemple, Volume/Luminosite) en douceur**

   .. code-block:: python

      value = 50  # 0..100
      def rotary_change():
          global value
          value = max(0, min(100, 50 + encoder.steps()))
          print(f'Value = {value}')

2. **Utiliser le bouton pour basculer un mode**

   .. code-block:: python

      mode = ['Fine', 'Coarse']
      idx = 0
      def reset_counter():
          global idx
          idx = 1 - idx
          encoder.reset()
          print(f'Mode switched to: {mode[idx]}')

3. **Retour LED/Buzzer**

   .. code-block:: python

      from fusion_hat import Pin
      led = Pin(26, Pin.OUT)
      def rotary_change():
          print('Counter =', encoder.steps())
          led.on()
          # brief flash without blocking callbacks is recommended
          led.off()

4. **Appui long pour effectuer une action speciale**

   - Suivez la duree d'appui en utilisant des horodatages dans ``sw.when_activated`` et (si disponible) ``sw.when_deactivated`` pour declencher differentes actions pour les appuis courts/longs.
