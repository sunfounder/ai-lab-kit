2.12 Codificador Rotatorio
============================

**Introducción**

Un codificador rotatorio es un dispositivo de entrada que convierte el movimiento rotatorio en señales digitales. Se utiliza comúnmente para navegar por menús, ajustar valores o desplazarse por elementos. En este proyecto, conectarás un codificador rotatorio (con un pulsador integrado) a una Raspberry Pi a través del Fusion HAT+, leerás los pasos de rotación y restablecerás el contador con el interruptor del codificador.

Este experimento ilustra cómo interconectar un codificador rotatorio utilizando devoluciones de llamada de eventos para un manejo de entrada suave y de baja latencia.

**Asignación de Pines Utilizada en el Ejemplo**

- **CLK** → **GPIO 17**
- **DT** → **GPIO 4**
- **SW (botón)** → **GPIO 27** (con pull-up interno)
- **+** → **3.3V**
- **GND** → **GND**

Asegúrate de que todas las conexiones estén seguras. Si tu codificador tiene **C (COM)** y **NO/NC** separados para el interruptor, conecta **C** a GND y **NO** al pin SW (pull-up interno habilitado en el software).

**Código**

A continuación se muestra el código Python utilizado en este proyecto:

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # GPIO pins (BCM numbering)
   CLK_PIN = 17
   DT_PIN  = 4
   SW_PIN  = 27

   # Initialize pins with internal pull-ups
   clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
   dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
   sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)  # Button is active LOW

   raw = 0                 # Raw quadrature transitions
   last_clk = clk.value()  # Previous CLK state
   last_detent = None      # Last displayed detent value

   print("Rotate the knob. Press the button to reset. CTRL + C to exit.")
   try:
      while True:
         c = clk.value()
         if c != last_clk:
               # Direction: DT != CLK means one direction, else the other
               raw += 1 if dt.value() != c else -1

               # Most encoders generate 2 transitions per detent (click)
               detent = raw // 2

               # Only update output when the detent value changes
               if detent != last_detent:
                  print(f"\rCounter: {detent}   ", end="", flush=True)
                  last_detent = detent

               last_clk = c

         # Reset when button is pressed
         if sw.value() == 0:
               raw = 0
               detent = 0
               print("\rCounter: 0   ", end="", flush=True)
               last_detent = 0
               time.sleep(0.25)  # Button debounce

         time.sleep(0.001)  # Polling interval (1 ms)

   except KeyboardInterrupt:
      print("\nExit")



----------------------------------------------

**Comprender el Código**

1. **Imports**

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      import time

   - ``Pin`` se utiliza para configurar y leer los pines GPIO del codificador rotatorio.
   - ``Mode`` y ``Pull`` definen la dirección del pin y las resistencias de pull-up internas.
   - ``time`` se utiliza para controlar los intervalos de sondeo y el tiempo de antirrebote del botón.

2. **Configuración de Pines GPIO**

   .. code-block:: python

      CLK_PIN = 17
      DT_PIN  = 4
      SW_PIN  = 27

      clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
      dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
      sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)

   - ``CLK`` y ``DT`` son los dos pines de señal en cuadratura del codificador rotatorio.
   - ``SW`` es el pulsador incorporado del codificador.
   - Las resistencias de pull-up internas mantienen la señal estable cuando el codificador está inactivo.
   - El botón es activo en BAJO y se lee como ``0`` cuando está presionado.

3. **Variables de Estado**

   .. code-block:: python

      raw = 0
      last_clk = clk.value()
      last_detent = None

   - ``raw`` cuenta las transiciones de cuadratura de bajo nivel del codificador.
   - ``last_clk`` almacena el estado anterior de CLK para detectar cambios en la señal.
   - ``last_detent`` realiza un seguimiento del último valor del contador mostrado para evitar salidas repetidas.

4. **Detección de Rotación**

   .. code-block:: python

      c = clk.value()
      if c != last_clk:
          raw += 1 if dt.value() != c else -1

   - El script sondea continuamente el pin CLK.
   - Un cambio en CLK indica movimiento del codificador.
   - La dirección de rotación se determina comparando DT con CLK.

5. **Cálculo de Detención (Clic)**

   .. code-block:: python

      detent = raw // 2

   - La mayoría de los codificadores rotatorios generan dos transiciones de señal por clic físico.
   - Dividir entre 2 convierte las transiciones brutas en conteos de detención limpios.

6. **Salida Limpia en Consola**

   .. code-block:: python

      if detent != last_detent:
          print(f"\rCounter: {detent}   ", end="", flush=True)

   - La salida se actualiza solo cuando cambia el valor del contador.
   - ``\r`` mueve el cursor al principio de la línea para actualizaciones en el mismo lugar.
   - ``flush=True`` asegura la visualización inmediata en la terminal.

7. **Manejo del Reinicio con el Botón**

   .. code-block:: python

      if sw.value() == 0:
          raw = 0
          detent = 0
          print("\rCounter: 0   ", end="", flush=True)
          time.sleep(0.25)

   - Presionar el botón restablece el contador a cero.
   - Se utiliza un breve retardo para el antirrebote del botón y evitar múltiples disparos.

8. **Intervalo de Sondeo y Salida del Programa**

   .. code-block:: python

      time.sleep(0.001)

   - Un retardo de sondeo de 1 ms equilibra la capacidad de respuesta y el uso de la CPU.
   - Presionar ``Ctrl + C`` sale del programa de forma segura.

**Solución de Problemas**

1. **No hay salida al girar**

   - **Causa**: Cableado incorrecto de CLK/DT o mala conexión a tierra.
   - **Solución**: Verifica **CLK→GPIO17**, **DT→GPIO4**, **GND común**. Asegúrate de que la alimentación de 3.3V sea correcta (no uses codificadores de 5V directamente en GPIO).

2. **El contador salta erráticamente (rebotes/ruido)**

   - **Causa**: Rebote mecánico o cables largos que captan ruido.
   - **Solución**: Mantén los cables cortos y trenzados en par si es posible; agrega pequeños condensadores (ej., 0.01–0.1 µF) desde CLK/DT a GND si es necesario; habilita las opciones de antirrebote disponibles en tu versión de la biblioteca.

3. **Botón no detectado**

   - **Causa**: Contactos del interruptor conectados a 3.3V en lugar de GND o configuración incorrecta de pull-up.
   - **Solución**: Asegúrate de que **SW** se conecte a **GND** cuando se presione; confirma que ``pull=Pin.PULL_UP`` esté configurado.

4. **Dirección invertida**

   - **Causa**: CLK y DT intercambiados con respecto a la dirección deseada.
   - **Solución**: Intercambia los cables **CLK** y **DT** o invierte a nivel de aplicación (por ejemplo, resta pasos).

**Ideas para Extender**

1. **Ajustar una variable (ej., Volumen/Brillo) de forma suave**

   .. code-block:: python

      value = 50  # 0..100
      def rotary_change():
          global value
          value = max(0, min(100, 50 + encoder.steps()))
          print(f'Value = {value}')

2. **Usar el Botón para Alternar un Modo**

   .. code-block:: python

      mode = ['Fine', 'Coarse']
      idx = 0
      def reset_counter():
          global idx
          idx = 1 - idx
          encoder.reset()
          print(f'Mode switched to: {mode[idx]}')

3. **Retroalimentación con LED/Zumbador**

   .. code-block:: python

      from fusion_hat import Pin
      led = Pin(26, Pin.OUT)
      def rotary_change():
          print('Counter =', encoder.steps())
          led.on()
          # brief flash without blocking callbacks is recommended
          led.off()

4. **Pulsación Larga para Realizar una Acción Especial**

   - Realiza un seguimiento de la duración de la pulsación usando marcas de tiempo en ``sw.when_activated`` y (si está disponible) ``sw.when_deactivated`` para activar diferentes acciones para pulsaciones cortas/largas.
