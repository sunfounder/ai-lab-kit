2.12 旋转编码器
================

**介绍**

旋转编码器是一种将旋转运动转换为数字信号的输入设备。它通常用于导航菜单、调整数值或滚动浏览项目。在本项目中，你将通过Fusion HAT+将旋转编码器（带集成按钮）连接到Raspberry Pi，读取旋转步数，并使用编码器的开关重置计数器。

本实验演示了如何使用事件回调来接口旋转编码器，以实现平滑、低延迟的输入处理。

**示例中使用的引脚映射**

- **CLK** → **GPIO 17**
- **DT** → **GPIO 4**
- **SW（按钮）** → **GPIO 27**（带内部上拉）
- **+** → **3.3V**
- **GND** → **GND**

确保所有连接牢固可靠。如果你的编码器为开关配有独立的 **C（COM）** 和 **NO/NC**，请将 **C** 连接到 GND，**NO** 连接到 SW 引脚（软件中启用内部上拉）。

**代码**

以下是本项目使用的Python代码：

.. raw:: html

   <run></run>

.. code-block:: python

   #!/usr/bin/env python3

   from fusion_hat.pin import Pin, Mode, Pull
   import time

   # GPIO pins (BCM numbering)
   CLK_PIN = 17
   DT_PIN  = 4
   SW_PIN  = 27

   # Initialize pins with internal pull-ups
   clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
   dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
   sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)  # Button is active LOW

   raw = 0                 # Raw quadrature transitions
   last_clk = clk.value()  # Previous CLK state
   last_detent = None      # Last displayed detent value

   print("Rotate the knob. Press the button to reset. CTRL + C to exit.")
   try:
      while True:
         c = clk.value()
         if c != last_clk:
               # Direction: DT != CLK means one direction, else the other
               raw += 1 if dt.value() != c else -1

               # Most encoders generate 2 transitions per detent (click)
               detent = raw // 2

               # Only update output when the detent value changes
               if detent != last_detent:
                  print(f"\rCounter: {detent}   ", end="", flush=True)
                  last_detent = detent

               last_clk = c

         # Reset when button is pressed
         if sw.value() == 0:
               raw = 0
               detent = 0
               print("\rCounter: 0   ", end="", flush=True)
               last_detent = 0
               time.sleep(0.25)  # Button debounce

         time.sleep(0.001)  # Polling interval (1 ms)

   except KeyboardInterrupt:
      print("\nExit")

**理解代码**

1. **导入**

   .. code-block:: python

      from fusion_hat.pin import Pin, Mode, Pull
      import time

   - ``Pin``\ 用于配置和读取旋转编码器的GPIO引脚。
   - ``Mode``\ 和\ ``Pull``\ 定义引脚方向和内部上拉电阻。
   - ``time``\ 用于控制轮询间隔和按钮消抖时序。

2. **GPIO引脚设置**

   .. code-block:: python

      CLK_PIN = 17
      DT_PIN  = 4
      SW_PIN  = 27

      clk = Pin(CLK_PIN, mode=Mode.IN, pull=Pull.UP)
      dt  = Pin(DT_PIN,  mode=Mode.IN, pull=Pull.UP)
      sw  = Pin(SW_PIN,  mode=Mode.IN, pull=Pull.UP)

   - ``CLK``\ 和\ ``DT``\ 是旋转编码器的两个正交信号引脚。
   - ``SW``\ 是编码器内置的按钮。
   - 内部上拉电阻在编码器空闲时保持信号稳定。
   - 按钮为低电平有效，按下时读取\ ``0``\ 。

3. **状态变量**

   .. code-block:: python

      raw = 0
      last_clk = clk.value()
      last_detent = None

   - ``raw``\ 统计编码器的低电平正交转换次数。
   - ``last_clk``\ 存储先前的CLK状态以检测信号变化。
   - ``last_detent``\ 跟踪上次显示的计数器值，避免重复输出。

4. **旋转检测**

   .. code-block:: python

      c = clk.value()
      if c != last_clk:
          raw += 1 if dt.value() != c else -1

   - 脚本持续轮询CLK引脚。
   - CLK的变化表示编码器移动。
   - 通过比较DT与CLK确定旋转方向。

5. **定位点（咔嗒）计算**

   .. code-block:: python

      detent = raw // 2

   - 大多数旋转编码器每次物理点击产生两次信号转换。
   - 除以2将原始转换转换为清晰的定位点计数。

6. **干净的控制台输出**

   .. code-block:: python

      if detent != last_detent:
          print(f"\\rCounter: {detent}   ", end="", flush=True)

   - 仅在计数器值变化时更新输出。
   - ``\\r``\ 将光标移回行首以进行原地更新。
   - ``flush=True``\ 确保立即显示在终端上。

7. **按钮重置处理**

   .. code-block:: python

      if sw.value() == 0:
          raw = 0
          detent = 0
          print("\\rCounter: 0   ", end="", flush=True)
          time.sleep(0.25)

   - 按下按钮将计数器重置为零。
   - 使用短暂延迟进行按钮消抖，防止多次触发。

8. **轮询间隔和程序退出**

   .. code-block:: python

      time.sleep(0.001)

   - 1ms的轮询延迟平衡了响应速度和CPU使用率。
   - 按下\ ``Ctrl + C``\ 优雅退出程序。

**故障排除**

1. **旋转时无输出**

   - **原因**：CLK/DT接线错误或接地不良。
   - **解决方案**：确认**CLK→GPIO17**、**DT→GPIO4**、**GND共地**。确保3.3V供电正确（请勿在GPIO上直接使用5V编码器）。

2. **计数器跳变不稳定（抖动/噪声）**

   - **原因**：机械触点抖动或长线缆引入噪声。
   - **解决方案**：尽可能保持线缆短且双绞；如有需要可在CLK/DT到GND之间添加小电容（如0.01–0.1µF）；在可用的库版本中启用消抖选项。

3. **按钮未检测到**

   - **原因**：开关触点连接到3.3V而非GND，或上拉配置错误。
   - **解决方案**：确保**SW**按下时连接到**GND**；确认已设置\ ``pull=Pin.PULL_UP``\ 。

4. **方向反转**

   - **原因**：相对于所需方向，CLK和DT接反了。
   - **解决方案**：交换**CLK**和**DT**的接线，或在应用层取反（例如，减去步数）。

**扩展思路**

1. **平滑调节变量（如音量/亮度）**

   .. code-block:: python

      value = 50  # 0..100
      def rotary_change():
          global value
          value = max(0, min(100, 50 + encoder.steps()))
          print(f'Value = {value}')

2. **使用按钮切换模式**

   .. code-block:: python

      mode = ['Fine', 'Coarse']
      idx = 0
      def reset_counter():
          global idx
          idx = 1 - idx
          encoder.reset()
          print(f'Mode switched to: {mode[idx]}')

3. **LED/蜂鸣器反馈**

   .. code-block:: python

      from fusion_hat import Pin
      led = Pin(26, Pin.OUT)
      def rotary_change():
          print('Counter =', encoder.steps())
          led.on()
          # brief flash without blocking callbacks is recommended
          led.off()

4. **长按执行特殊操作**

   - 使用时间戳在\ ``sw.when_activated``\ 和（如果可用）\ ``sw.when_deactivated``\ 中跟踪按下时长，以触发的短按/长按的不同操作。
