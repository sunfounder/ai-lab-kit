2.1.4 Schiebeschalter
==============================================

**Introduction**

In diesem Projekt lernen wir, wie man mit einem Schiebeschalter zwei LEDs steuert. Schiebeschalter werden häufig als Netzschalter in elektronischen Schaltungen eingesetzt. Hier demonstrieren wir ihre Funktion mithilfe eines Breadboards. Während Schiebeschalter üblicherweise für mehr Stabilität auf Leiterplatten verlötet werden, nutzen wir ihn in einer flexiblen Breadboard-Konfiguration, um seine Funktionsweise besser zu verstehen.

**Writing the Code**

Hier der Python-Code, um die LEDs abhängig vom Zustand des Schiebeschalters zu steuern:

.. raw:: html

   <run></run>


.. code-block:: python

   #!/usr/bin/env python3
   from fusion_hat import Pin 
   from time import sleep  # Import sleep for delay

   # Initialize slider (Button) on GPIO pin 17
   slider = Pin(17, Pin.IN, pull = Pin.PULL_DOWN) 

   # Initialize LED1 connected to GPIO pin 22
   led1 = Pin(22,Pin.OUT)
   # Initialize LED2 connected to GPIO pin 27
   led2 = Pin(27,Pin.OUT)

   try:
      # Continuously monitor the state of the slider and control LEDs accordingly
      while True:
         if slider.value() == 1:  # Check if the slider is pressed
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

   except KeyboardInterrupt:
      # Handle a keyboard interrupt (Ctrl+C) for a clean exit from the loop
      pass

Dieses Python-Skript zeigt, wie sich mit einem Schiebeschalter zwei LEDs am Fusion HAT steuern lassen. Beim Ausführen gilt:

1. **Schiebeschalter aktiviert**:  
   - LED1 (GPIO22) erlischt.  
   - LED2 (GPIO27) leuchtet.  

2. **Schiebeschalter nicht aktiviert**:  
   - LED1 leuchtet.  
   - LED2 erlischt.  

3. Das Programm überprüft alle 0,5 Sekunden den Zustand des Schalters und steuert die LEDs entsprechend.  

4. Das Skript läuft unbegrenzt, bis es mit ``Ctrl+C`` beendet wird.

**Understanding the Code**

1. **Library Imports**

   Notwendige Bibliotheken für GPIO-Steuerung und Wartezeiten importieren.

   .. code-block:: python

      from fusion_hat import Pin 
      from time import sleep  # Import sleep for delay

2. **Component Initialization**

   Der Schiebeschalter wird als Button auf GPIO17 konfiguriert, zwei LEDs werden an GPIO22 und GPIO27 initialisiert.

   .. code-block:: python

      # Initialize slider (Button) on GPIO pin 17
      slider = Pin(17, Pin.IN, pull = Pin.PULL_DOWN) 

      # Initialize LED1 connected to GPIO pin 22
      led1 = Pin(22,Pin.OUT)
      # Initialize LED2 connected to GPIO pin 27
      led2 = Pin(27,Pin.OUT)

3. **State Monitoring and LED Control**

   In der Hauptschleife wird der Zustand des Schalters überwacht. Je nach Schalterstellung wird entweder LED1 oder LED2 eingeschaltet.

   .. code-block:: python

      # Continuously monitor the state of the slider and control LEDs accordingly
      while True:
         if slider.value() == 1:  # Check if the slider is pressed
               led1.off()  # Turn off LED1
               led2.on()   # Turn on LED2
         else:  # If the sensor is not pressed
               led1.on()   # Turn on LED1
               led2.off()  # Turn off LED2

         sleep(0.5)  # Pause for 0.5 seconds before rechecking the sensor state

4. **Graceful Exit**

   Das Skript beendet sich sauber, wenn es mit Ctrl+C unterbrochen wird.

   .. code-block:: python

       except KeyboardInterrupt:
           pass

**Troubleshooting**


1. **Schiebeschalter reagiert nicht**  

   - **Ursache**: Falsche Verdrahtung oder Pull-up/Pull-down-Konfiguration.  
   - **Lösung**: Überprüfen Sie die Verbindung des Schalters mit GPIO17 und GND. Achten Sie darauf, dass ``PULL_DOWN`` korrekt zur Schalterkonfiguration passt.  


2. **LEDs flackern oder verhalten sich unregelmäßig**  

   - **Ursache**: Entprellungsprobleme am Schalter.  
   - **Lösung**: Software-Entprellung hinzufügen, um das Signal zu stabilisieren:  

   .. code-block:: python

      if slider.value() == 1:
         sleep(0.05)  # Debounce delay

**Extendable Ideas**


1. **Zwei-Wege-Schaltersteuerung**  

   Zwei Schiebeschalter kombinieren, um LEDs in komplexeren Mustern zu steuern – z. B. als einfaches Bedienpanel.  


2. **Akustisches Feedback**  

   Einen Buzzer hinzufügen, der ertönt, wenn der Schiebeschalter betätigt wird:  

   .. code-block:: python

      from fusion_hat import Buzzer
      buzzer = Buzzer(Pin(22))
      if slider.value() == 1:
         buzzer.on()
      else:
         buzzer.off()
