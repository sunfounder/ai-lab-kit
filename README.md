## 关于本套件：

本套件包含多种电子元器件，包括显示器、声音模块、驱动器、控制器和传感器，让您能够全面了解电子设备。

为了帮助您快速上手，每种语言都提供了有针对性和趣味性的项目，您可以根据需要选择合适的项目。

## 关于 SunFounder
SunFounder 是一家专注于 STEAM 教育的公司，产品包括开源机器人、开发板、STEAM 套件、模块、工具及其他智能设备，业务覆盖全球。在 SunFounder，我们致力于帮助中小学生及爱好者，通过 STEAM 教育加强动手实践和问题解决能力。以此方式，我们希望以寓教于乐的方式传播知识并提供技能培训，从而培养您对编程和制作的兴趣，让您接触迷人的科学与工程世界。为了迎接人工智能的未来，学习丰富的 STEAM 知识既紧迫又有意义。
